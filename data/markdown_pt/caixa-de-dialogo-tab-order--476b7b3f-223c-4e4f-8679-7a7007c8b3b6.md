# Caixa de Diálogo Tab Order

Ajusta a ordem em que os objetos são acessados no formulário quando você usa o teclado. Esta caixa de diálogo aparece quando você escolhe a opção Assign by List em Tab Order no menu View.
 **Object List**
Lista todos os objetos, exceto objetos gráficos e de texto, no formulário ou na classe. Os objetos são listados na ordem em que estão atualmente acessíveis via teclado. Altere a ordem clicando no botão à esquerda da imagem do objeto e arrastando o objeto para a posição na lista que corresponde ao seu lugar na ordem de acesso desejada.
**By Row**
Ajusta a ordem dos objetos para que sejam acessados por linha, da esquerda para a direita, pelo formulário começando no topo.
**By Column**
Ajusta a ordem dos objetos para que sejam acessados por coluna, de cima para baixo, pelo formulário começando no lado esquerdo.

Para obter mais informações, consulte How to: Set Tab Order for Controls.
