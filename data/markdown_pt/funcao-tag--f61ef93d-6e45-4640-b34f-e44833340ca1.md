# Função TAG( )

Retorna um nome de tag de um arquivo de índice composto (.cdx) aberto ou o nome de um arquivo de índice de entrada única (.idx) aberto.

```foxpro
TAG([CDXFileName[, nTagNumber[, nWorkArea | cTableAlias]]])
```

#### Parâmetros
 **CDXFileName**
Especifica o nome do arquivo .cdx do qual retornar um nome de tag.
**nTagNumber**
Especifica um número correspondente à ordem em que uma tag foi criada no arquivo de índice composto. Por exemplo, se nTagNumber é 1, TAG( ) retorna o nome da primeira tag criada no arquivo de índice composto. Se nTagNumber é 2, TAG( ) retorna o nome da segunda tag criada, e assim por diante. TAG( ) retorna a cadeia de caracteres vazia quando nTagNumber excede o número de nomes de tag. Se você omitir CDXFileName , TAG( ) retorna nomes de tag de arquivo de índice composto e nomes de arquivo de índice de entrada única em uma ordem específica da seguinte forma: Nomes de arquivos de índice de entrada única são retornados baseados em sua ordem na cláusula INDEX de USE ou SET INDEX . Para obter mais informações, consulte Comando USE e Comando SET INDEX . Nomes de tag do arquivo de índice composto estrutural (se existir um para a tabela) são retornados. Nomes de tag de outros arquivos de índice composto abertos são retornados, novamente na ordem em que as tags foram criadas nos arquivos de índice composto e na ordem em que os arquivos de índice composto são especificados na cláusula INDEX para USE ou SET INDEX .
**nWorkArea | cTableAlias**
Retorna nomes de tag e nomes de arquivo de índice de arquivos abertos em outra área de trabalho. nWorkArea especifica um número de área de trabalho e cTableAlias especifica um alias de tabela. Por padrão, nomes de tag e nomes de arquivo de índice são retornados de arquivos na área de trabalho atual.

# Valor de retorno

Character. TAG( ) retorna um nome de tag de índice como uma cadeia de caracteres em maiúsculas.

# Observações

Tags são entradas de índice em arquivos de índice composto (.cdx) criados com o comando INDEX. Arquivos de índice de entrada única (.idx) contêm apenas uma entrada; portanto, TAG( ) retorna o nome do arquivo para arquivos .idx.

> **Observação:** Um arquivo de índice composto estrutural (.cdx) abre com sua tabela automaticamente. Você pode abrir arquivos .cdx não estruturais e arquivos de índice .idx para uma tabela usando a cláusula INDEX no comando USE ou usando o comando SET INDEX.

# Exemplo

O exemplo a seguir fecha todos os outros bancos de dados abertos e abre a tabela Customer no banco de dados de exemplo TestData do Visual FoxPro localizado no diretório ..\Microsoft Visual FoxPro\Samples\Data. O comando FOR ... ENDFOR usa a função TAGCOUNT( ) para criar um loop numerando da primeira tag de índice até o número total de tags de índice no arquivo de índice composto estrutural (.cdx) aberto. As funções TAG( ) e CDX( ) recuperam as tags de índice do arquivo e as exibem usando o comando ?.

```foxpro
CLOSE DATABASES
OPEN DATABASE (HOME(2) + 'Data\TestData')
USE Customer
CLEAR
FOR nCount = 1 TO TAGCOUNT()
   ? TAG(CDX(1),nCount)
ENDFOR
```

Para obter mais informações, consulte Comando FOR ... ENDFOR, Função TAGCOUNT( ), Função CDX( ) e Comando ? | ??.
