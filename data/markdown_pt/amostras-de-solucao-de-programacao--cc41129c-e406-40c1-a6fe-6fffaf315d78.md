# Amostras de solução de programação

Essas amostras Solution ilustram tarefas de desenvolvimento de aplicações que você pode realizar com o Visual FoxPro.

# Nesta seção
 **Bind, Raise, Unbind, and Retrieve Events Sample**
Demonstra vinculação de eventos, disparo de eventos programaticamente, desvinculação de eventos e recuperação de eventos.
**Member Classes Sample**
Demonstra como especificar e fazer subclasse de member classes torna possível selecionar um contêiner pai, definir a biblioteca de classes de membro, aumentar ou diminuir a contagem de membros e visualizar o comportamento em tempo de design ou em tempo de execução.
**OLE Drag-and-Drop Events Sample**
Demonstra formas de usar OLE drag and drop adicionando código aos eventos OLEDragDrop e OLEDragOver.
**OLE Drag-and-Drop Data Formats Sample**
Demonstra como usar OLE drag and drop para reportar dados sobre o item arrastado adicionando código aos eventos OLEDragDrop e OLEDragOver.
**Pass Strongly Typed Arrays Sample**
Demonstra como você pode passar uma matriz fortemente tipada por referência a um servidor COM usando a função COMARRAY. Esta amostra também demonstra a sintaxe de declaração de interface para especificar matrizes de tipo ByRef na biblioteca de tipos COM gerada.
**SCATTER NAME...ADDITIVE Sample**
Demonstra como atualizar e salvar algumas propriedades de formulário de e para uma tabela usando o comando SCATTER com as cláusulas NAME e ADDITIVE e o comando GATHER com a cláusula NAME.
**Structured Exception Handling Sample (Visual FoxPro)**
Esta amostra demonstra como capturar exceções usando os blocos TRY e CATCH, limpar recursos usando o bloco FINALLY e lançar, ou escalar, exceções usando uma instrução THROW.
**Taskbar Icon Sample**
Demonstra alguns usos comuns da classe Systray, que suporta o uso de ícones na Área de Notificação da Barra de Tarefas. A classe Systray também suporta eventos de mouse, dicas de balão e menus de atalho do Visual FoxPro para seu ícone da Barra de Tarefas, para que você possa usar todos os recursos do Menu Designer do Visual FoxPro.
**Windows XP Themes Support Sample**
Demonstra diferentes níveis de suporte do Visual FoxPro para Temas do Windows XP.
