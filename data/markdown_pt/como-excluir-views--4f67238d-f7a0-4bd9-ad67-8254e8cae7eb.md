# Como: excluir views

Você pode excluir uma view de um banco de dados.

### Para excluir uma view
- Abra o projeto de aplicação que contém a view no Project Manager .
- No Project Manager , expanda o nó Data e, em seguida, o nó Databases.
- No nó Local Views ou Remote Views, clique na view que deseja excluir e, em seguida, Remove . O Visual FoxPro exibe uma caixa de diálogo de confirmação para você confirmar a exclusão da view.
- Na caixa de diálogo de confirmação, clique em Remove .

Para obter mais informações, consulte Project Manager Window.

### Para excluir uma view programaticamente
- Abra o banco de dados que contém a view.
- Use o comando DELETE VIEW ou o comando DROP VIEW. Observação Esses comandos executam a mesma tarefa. DROP VIEW usa a sintaxe padrão ANSI SQL para excluir uma view SQL.

Para obter mais informações, consulte DELETE VIEW Command e DROP VIEW Command.
