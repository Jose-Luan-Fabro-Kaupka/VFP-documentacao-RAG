# Método DoCmd

Executa um comando do Visual FoxPro para uma instância do servidor de automação do aplicativo Visual FoxPro.

```foxpro
ApplicationObject.DoCmd(cCommand)
```

#### Parâmetros
 **bstrCmd**
Especifica o comando do Visual FoxPro a ser executado.

# Observações

Aplica-se a: Objeto Application | Variável de sistema _VFP

cCommand deve ser avaliado como um comando legal do Visual FoxPro.
