# Guia Fields, Query and View Designers

Especifica campos, funções agregadas e outras expressões para a saída de consulta ou view. Esta guia aparece no Query and View Designers.
 **Available fields**
Lista todos os campos disponíveis nas tabelas da consulta ou view. Você pode selecionar todas as tabelas disponíveis e seus campos escolhendo o asterisco (*), todos os campos de uma tabela específica escolhendo table .*, ou campos individuais para sua consulta ou view. Suas seleções aparecem na instrução SELECT na janela SQL quando você clica no botão SQL ou escolhe View SQL no menu Query. Se você selecionar um campo na lista Available Fields, seu nome aparece automaticamente na caixa de edição Functions and expressions e na caixa de edição Expression do Expression Builder, que abre quando você clica no botão reticências (...).
**Functions and expressions**
Especifica uma função ou expressão. Você pode digitar uma expressão diretamente na caixa ou selecionar uma função de uma lista no Expression Builder, que abre quando você clica no botão reticências (...). Depois de criar sua expressão, você pode adicioná-la à caixa Selected fields clicando no botão Add.
**Selected fields**
Lista os campos selecionados, funções agregadas e outras expressões que aparecem nos resultados da consulta ou view. Você pode reorganizar a ordem da saída arrastando a seta dupla vertical à esquerda dos campos.
**Add**
Adiciona o item selecionado da caixa Available fields ou da caixa Functions and expressions à caixa Selected fields.
**Add All**
Adiciona todos os campos da caixa Available fields à caixa Selected fields.
**Remove**
Remove o item selecionado da caixa Selected fields.
**Remove All**
Remove todos os itens da caixa Selected fields.
**Properties**
Exibe a View Field Properties Dialog Box, que permite especificar opções para campos em uma view da mesma forma que você faz para campos em tabelas de banco de dados. Esta opção está disponível apenas no View Designer.
