# Tipo de campo Integer

Para armazenar valores numéricos não decimais quando desempenho e limitações de armazenamento de tabela são especialmente importantes, use o tipo de campo Integer. Para gerar valores, como números de ID, use Integer (Autoinc) que incrementa automaticamente o valor.

Em tabelas, o tipo de campo Integer é armazenado como um valor binário de 4 bytes. Como resultado, requer menos memória que outros tipos de dados Numeric. Como valor binário, não requer ASCII

Para especificações sobre os tipos de campo Integer e Integer (Autoinc), consulte Visual FoxPro Data and Field Types.
