# Caixa de diálogo Edit Relationship

Esta caixa de diálogo permite editar uma relação persistente entre tabelas. Para obter mais informações, consulte Como: gerenciar relações persistentes entre tabelas.

Esta caixa de diálogo aparece quando você seleciona uma linha de relação no Database Designer e seleciona Edit Relationship no menu Database, ou dá um clique duplo na linha de relação.
 **Table**
Mostra o nome da tabela pai atual e permite selecionar uma tag de índice diferente.
**Related Table**
Mostra o nome da tabela filha atual e permite selecionar uma tag de índice diferente.
**Relationship Type**
Mostra o tipo de relação entre as tabelas pai e filha.
**Referential Integrity**
Exibe o construtor Referential Integrity para que você possa definir regras que controlam como registros são inseridos, atualizados ou excluídos em tabelas relacionadas. Observação Se suas tabelas ainda não estão indexadas, você precisa abri-las no Table designer e criar índices antes de usar o construtor Referential Integrity .
