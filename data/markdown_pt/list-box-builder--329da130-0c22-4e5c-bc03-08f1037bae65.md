# List Box Builder

O List Box builder facilita a definição de propriedades para um controle list box. List boxes fornecem ao usuário uma lista rolável que contém várias opções ou informações. Em um list box, vários itens podem estar visíveis o tempo todo. Você define as propriedades do list box selecionando opções exibidas na caixa de diálogo List Box Builder.

 Para usar o List Box builder
 - Usando a barra de ferramentas Form Controls, coloque um controle list box em um formulário.
- Selecione e clique com o botão direito no controle list box e escolha Builder no menu de atalho do Form Designer.
- Escolha as opções desejadas na caixa de diálogo e escolha OK. Quando você escolhe OK, o builder fecha, aplicando as configurações de propriedade de todas as guias.

# Guias do Builder
 **List Items**
Especifica itens para preencher o list box e as fontes desses dados.
**Style**
Especifica o estilo (3D ou simples) e o número de linhas, e habilita ou desabilita a pesquisa incremental.
**Layout**
Controla a largura e a exibição das colunas.
**Value**
Especifica de qual coluna obter valores de retorno e em qual campo armazená-los.
