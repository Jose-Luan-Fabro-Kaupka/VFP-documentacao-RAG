# Método AddToSCC

Adiciona um arquivo em um projeto ao controle de código-fonte.

```foxpro
Object.AddToSCC()
```

# Observações

Aplica-se a: Objeto File (Visual FoxPro)

True (.T.) é retornado se o arquivo for adicionado com sucesso ao controle de código-fonte. False (.F.) é retornado se o arquivo não puder ser adicionado ao controle de código-fonte ou se o projeto não estiver sob controle de código-fonte.
