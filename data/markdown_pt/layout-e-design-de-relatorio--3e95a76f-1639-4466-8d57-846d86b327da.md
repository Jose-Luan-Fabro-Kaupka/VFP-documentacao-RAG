# Layout e design de relatório

Quando você cria um relatório ou etiqueta, pode personalizar a aparência do relatório ou etiqueta fazendo as seguintes alterações no layout da página no Report Designer ou Label Designer:
 - Alterar configurações e propriedades da página.
- Organizar dados e informações especificando onde e quando aparecem usando bandas de relatório.
- Agrupar registros usando grupos de dados.

Muitos dos tópicos nesta seção se aplicam à organização de dados em etiquetas, bem como em relatórios.

# Nesta seção
 **Working with Page Layouts**
Apresenta como especificar uma variedade de configurações para um layout de página.
**Working with Report Bands**
Apresenta como especificar onde, quando e como exibir dados e informações em relatórios.
**Working with Report Data Groups**
Apresenta como usar grupos de dados para agrupar registros em relatórios.
**Working with Report Controls**
Apresenta como adicionar dados e informações a relatórios usando controles.
**Working with Report Variables**
Descreve como usar variáveis de relatório para armazenar, manipular e exibir valores calculados.
