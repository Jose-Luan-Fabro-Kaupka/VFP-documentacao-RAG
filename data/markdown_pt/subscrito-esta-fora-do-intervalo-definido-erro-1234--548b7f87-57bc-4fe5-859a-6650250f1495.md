# Subscrito está fora do intervalo definido (Erro 1234)

Foi feita uma tentativa de referenciar um elemento de matriz com um subscrito fora do intervalo definido para a matriz usando o comando DIMENSION.

Por exemplo, copiar uma matriz membro para uma matriz não membro existente com determinadas dimensões usando a função ACOPY( ) pode gerar este erro. Você pode evitar este erro alterando a dimensão da matriz de destino para um único elemento antes de chamar ACOPY( ). Para obter mais informações, consulte ACOPY( ) Function e DIMENSION Command.
