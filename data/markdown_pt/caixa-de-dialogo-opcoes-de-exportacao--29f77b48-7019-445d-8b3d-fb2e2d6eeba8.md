# Caixa de diálogo Opções de exportação

Especifica quais registros e campos exportar. Esta caixa de diálogo é exibida quando você escolhe Opções na caixa de diálogo Exportar. Para obter mais informações, consulte Caixa de diálogo Exportar.

# Critérios

Especifica opções que controlam quais registros e campos exportar e as condições sob as quais eles são exportados.
 **Escopo**
Exibe a caixa de diálogo Escopo para que você possa especificar quais registros exportar. Para obter mais informações, consulte Caixa de diálogo Escopo .
**For**
Exibe a caixa de diálogo Construtor de expressões para que você possa criar uma expressão lógica que deve ser verdadeira para cada registro a exportar. Para obter mais informações, consulte Caixa de diálogo Construtor de expressões .
**While**
Exibe a caixa de diálogo Construtor de expressões para que você possa criar uma expressão lógica que deve ser verdadeira para continuar exportando registros. Para obter mais informações, consulte Caixa de diálogo Construtor de expressões
**Fields**
Exibe a caixa de diálogo Seletor de campos para que você possa escolher os campos a exportar. Para obter mais informações, consulte Caixa de diálogo Seletor de campos .
