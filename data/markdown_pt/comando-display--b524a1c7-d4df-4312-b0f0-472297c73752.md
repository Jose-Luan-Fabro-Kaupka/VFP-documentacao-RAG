# Comando DISPLAY

Exibe o conteúdo de registros e resultados de expressões da tabela atual na janela principal do Visual FoxPro ou em uma janela definida pelo usuário.

```foxpro
DISPLAY [[FIELDS] FieldList] [Scope] [FOR lExpression1]
   [WHILE lExpression2] [OFF] [NOCONSOLE] [NOOPTIMIZE]
   [TO PRINTER [PROMPT] | TO FILE FileName [ADDITIVE]]
```

#### Parâmetros
 **[[FIELDS] FieldList ]**
Especifica os campos a exibir. Se você omitir a cláusula FIELDS, todos os campos da tabela são exibidos por padrão. Observação O conteúdo de campos Memo não é exibido, a menos que o nome do campo memo seja explicitamente incluído na lista de campos. A largura exibida de campos memo é determinada pelo comando SET MEMOWIDTH. Para mais informações, consulte o comando SET MEMOWIDTH .
**[ Scope ]**
Especifica um intervalo de registros a exibir. Somente os registros que estão dentro do intervalo de escopo são exibidos. O escopo padrão para DISPLAY é o registro atual (NEXT 1). Para mais informações sobre cláusulas de escopo, consulte Scope Clauses . Observação Comandos que incluem Scope operam somente na tabela na área de trabalho ativa.
**[FOR lExpression1 ]**
Especifica exibir somente os registros que satisfazem a condição lógica lExpression1 . As expressões podem consistir em combinações de literais, variáveis de memória, elementos de matriz, campos e campos memo. Se lExpression1 puder ser otimizada, a Rushmore Query Optimization otimiza uma consulta criada com DISPLAY ... FOR . Para melhor desempenho, use uma expressão que possa ser otimizada na cláusula FOR. Para mais informações, consulte o comando SET OPTIMIZE e Using Rushmore Query Optimization to Speed Data Access .
**[WHILE lExpression2 ]**
Especifica uma condição para exibir registros enquanto a expressão lógica lExpression2 avaliar como True (.T.).
**[OFF]**
Suprime a exibição de números de registro. Se você omitir OFF , o número do registro é exibido antes de cada registro.
**[NOCONSOLE]**
Suprime a saída para a janela principal do Visual FoxPro ou para a janela definida pelo usuário ativa.
**[NOOPTIMIZE]**
Desabilita a otimização Rushmore para DISPLAY . Para mais informações, consulte o comando SET OPTIMIZE e Using Rushmore Query Optimization to Speed Data Access .
**[TO PRINTER [PROMPT]**
Direciona a saída de DISPLAY para uma impressora. A palavra-chave PROMPT especifica exibir uma caixa de diálogo Print antes do início da impressão. As configurações da impressora que você pode ajustar dependem do driver de impressora instalado atualmente.
**TO FILE FileName [ADDITIVE]]**
Direciona a saída de DISPLAY para o arquivo especificado com FileName . Se o arquivo já existir e SET SAFETY estiver ON , o Visual FoxPro solicita que você escolha se deseja substituir o arquivo. A palavra-chave ADDITIVE anexa a saída ao final do arquivo especificado. Se você omitir ADDITIVE , o Visual FoxPro substitui o arquivo pelo valor da expressão.

# Observações

DISPLAY é semelhante ao comando LIST, exceto que DISPLAY exibe informações uma tela por vez e faz pausas entre as telas. LIST exibe as mesmas informações sem pausas. Para ver a próxima tela, pressione qualquer tecla ou clique em qualquer lugar na janela do Visual FoxPro. Para mais informações, consulte LIST Commands.

> **Dica:** Para exibir nomes de campos e expressões, defina o comando SET HEADINGS como ON . Para mais informações, consulte o comando SET HEADINGS .

DISPLAY mostra dados de campos Varbinary em formato hexadecimal e é limitado a 256 caracteres, incluindo o prefixo 0h e 127 bytes codificados em hexadecimal. Para mais informações, consulte Varbinary Data Type.

# Exemplo

O exemplo a seguir abre o banco de dados de amostra do Visual FoxPro, TestData.dbc, usando o comando OPEN DATABASE e a tabela Customer usando o comando USE. O exemplo limpa a janela principal do Visual FoxPro usando o comando CLEAR e exibe o conteúdo do primeiro registro usando o comando DISPLAY.

```foxpro
CLOSE DATABASES
OPEN DATABASE (HOME(2) + 'Data\TestData')
USE Customer
CLEAR
DISPLAY FIELD cust_id, company, contact OFF NEXT 10
```
