# Método Clear

Limpa o conteúdo de um controle ComboBox ou ListBox.

```foxpro
Object.Clear
```

# Observações

Aplica-se a: Controle ComboBox | Controle ListBox

O método Clear remove todos os itens de um controle ComboBox ou ListBox, mas somente se a propriedade RowSourceType estiver definida como 0 (None). Além disso, define a propriedade ListCount como 0.
