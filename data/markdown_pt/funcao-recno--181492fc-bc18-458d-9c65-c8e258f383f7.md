# Função RECNO( )

Retorna o número do registro atual na tabela atual ou especificada.

```foxpro
RECNO([nWorkArea | cTableAlias])
```

#### Parâmetros
 **nWorkArea**
Especifica o número da área de trabalho para uma tabela aberta em outra área de trabalho. RECNO( ) retorna 0 se uma tabela não estiver aberta na área de trabalho que você especificar.
**cTableAlias**
Especifica o alias da tabela para uma tabela aberta em outra área de trabalho.

# Valor de retorno

Numeric

# Observações

O registro atual é o registro no qual o ponteiro de registro está posicionado.

RECNO( ) retorna números negativos para registros anexados em um buffer de tabela.

RECNO( ) retorna um valor que é um a mais que o número de registros na tabela se o ponteiro de registro estiver posicionado além do último registro na tabela. RECNO( ) retorna 1 se o ponteiro de registro estiver posicionado antes do primeiro registro na tabela ou a tabela não tiver registros. Se uma tabela não tiver registros, EOF( ) sempre retorna true (.T.).

RECNO( ) emitido sem os argumentos opcionais nWorkArea ou cTableAlias retorna o número do registro atual para a tabela na área de trabalho atualmente selecionada.

Se você emitiu SEEK sem sucesso em uma tabela indexada, pode especificar 0 para nWorkArea para usar a lógica de "soft seek" para retornar o número do registro do registro correspondente mais próximo. RECNO(0) retorna 0 se uma correspondência próxima não puder ser encontrada. O Visual FoxPro gera uma mensagem de erro se você emitir GO RECNO(0) quando uma correspondência próxima não é encontrada.

Evite usar RECNO( ) na expressão de índice para um cursor com buffer de tabela. Como RECNO( ) muda para novos registros quando são confirmados por TABLEUPDATE( ), pode ocorrer corrupção de índice.

# Exemplo

O exemplo a seguir pesquisa a tabela `customer` por um nome de empresa e, se o nome da empresa não for encontrado, usa RECNO(0) para retornar a empresa correspondente mais próxima.

```foxpro
CLOSE DATABASES
OPEN DATABASE (HOME(2) + 'data\testdata')
USE customer  && Opens Customer table
SET ORDER TO company
SEEK 'Ernst'
IF FOUND()
   DISPLAY company, contact
ELSE
   GOTO RECNO(0)
   CLEAR
   ? 'Closest matching company is ' + company
   ? 'Record number: ' + ALLTRIM(STR(RECNO()))
ENDIF
```
