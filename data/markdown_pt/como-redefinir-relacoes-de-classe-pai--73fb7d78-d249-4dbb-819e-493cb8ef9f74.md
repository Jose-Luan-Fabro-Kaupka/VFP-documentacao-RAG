# Como: redefinir relações de classe pai

Você pode redefinir a relação entre uma classe e sua classe pai.

> **Cuidado:** Quando você redefine uma classe, formulários que contêm essa classe e subclasses em outras bibliotecas de classes que não aparecem atualmente no Class Browser podem não funcionar corretamente.

### Para alterar a classe pai de uma classe
- Abra a biblioteca de classes no Class Browser. Para obter mais informações sobre como abrir bibliotecas de classes, consulte How to: Open Class Libraries.
- Na lista de classes do Class Browser, selecione a classe que deseja redefinir.
- No Class Browser, clique no botão Redefine.
- Na lista As da caixa de diálogo Redefine, selecione o nome da nova classe pai. -OU- Clique no botão de reticências (...) para selecionar uma classe.
- Clique em Redefine.
