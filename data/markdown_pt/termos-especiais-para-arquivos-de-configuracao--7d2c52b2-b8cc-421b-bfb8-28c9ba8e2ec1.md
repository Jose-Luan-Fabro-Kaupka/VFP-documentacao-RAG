# Termos especiais para arquivos de configuração

A tabela a seguir lista termos especiais que você pode usar em arquivos de configuração. Você também pode usar comandos SET, variáveis de sistema e a configuração _STARTUP em arquivos de configuração para personalizar o ambiente do Visual FoxPro.

# Observações

| Termo e sintaxe | Descrição |
| --- | --- |
| ALLOWEXTERNAL ON | OFF | Especifica se as configurações de um arquivo de configuração externo conforme especificado pela opção de linha de comando -C (ou localizado no caminho) são lidas após as de um interno. O termo ALLOWEXTERNAL é ignorado, a menos que esteja vinculado dentro de um aplicativo. Padrão: OFF |
| BITMAP ON | OFF | Especifica se o Visual FoxPro primeiro grava atualizações de tela ou formulário em um bitmap fora da tela e depois executa uma transferência de bloco de bits (bitblt) para a tela. BITMAP = OFF pode melhorar o desempenho quando aplicativos são acessados usando clientes Windows Terminal Server. Padrão: ON |
| CODEPAGE = nValue | AUTO | Especifica um número que identifica o conjunto de caracteres usado para arquivos. Definir CODEPAGE como AUTO seleciona a página de código do sistema operacional atual. Para os valores possíveis que você pode usar, consulte Páginas de código suportadas pelo Visual FoxPro. |
| COMMAND = cVisualFoxProCommand | Especifica um comando do Visual FoxPro a executar quando o Visual FoxPro é iniciado. O cVisualFoxProCommand especifica o comando a executar. |
| EDITWORK path | Especifica onde o editor de texto deve colocar seus arquivos de trabalho. Como os arquivos de trabalho podem ficar grandes, especifique um local com bastante espaço livre. Padrão: Dependente do sistema operacional. Para obter mais informações, consulte Otimizando o ambiente operacional. |
| INDEX extension | Especifica a extensão para arquivos de índice do Visual FoxPro. Padrão: .idx |
| LABEL extension | Especifica a extensão para arquivos de definição de etiqueta do Visual FoxPro. Padrão: .lbx |
| _MENUDESIGNER = cProgramName | Especifica um aplicativo externo de design de menu. Padrão: A cadeia de caracteres vazia "". |
| MVCOUNT | Define o número máximo de variáveis que o Visual FoxPro pode manter. Este valor pode variar de 128 a 65.000. Padrão: 16.384 |
| OUTSHOW = ON | OFF | Desabilita a capacidade de ocultar todas as janelas à frente da saída atual pressionando SHIFT+CTRL+ALT. Padrão: ON |
| PROGCACHE = nMemoryPages | Especifica a quantidade de memória (espaço de endereço) em páginas que o Visual FoxPro aloca na inicialização ou que um servidor COM MTDLL do Visual FoxPro aloca por thread para o cache interno de programa (memória usada para executar programas). Cada página de memória equivale a 64K, portanto a configuração padrão equivale a uma alocação um pouco acima de 9MB. À medida que o cache é preenchido, o Visual FoxPro tentará liberá-lo para remover itens não usados. É possível que o Visual FoxPro não consiga liberar memória suficiente, caso em que um Erro 1202 é gerado (Program is too large). Ajustar a configuração PROGCACHE pode impedir que este erro ocorra. Observação Embora esta configuração possa ser usada para o produto de desenvolvimento do Visual FoxPro ou aplicativos de runtime normais, ela é destinada principalmente a servidores COM MTDLL, onde muitas threads são frequentemente criadas para um único servidor. No Visual FoxPro 9.0, o valor padrão para servidores COM MTDLL é -2. Quando o valor de nMemoryPages é maior que 0, o Visual FoxPro aloca um cache de programa fixo. Você pode especificar entre 1 e 65000. Se você especificar 0 para nMemoryPages, nenhum cache de programa é usado. Em vez disso, o Visual FoxPro usa alocação dinâmica de memória baseada em determinações feitas pelo sistema operacional. Se você passar um valor para nMemoryPages que seja menor que 0, o Visual FoxPro usa alocação dinâmica de memória, mas é limitado à memória especificada (nMemoryPages * 64K). Quando o limite é atingido, o Visual FoxPro liberará programas alocados para liberar memória. Você pode chamar SYS(3065) para determinar a configuração atual de PROGCACHE. CLEAR PROGRAM tentará limpar código não referenciado independentemente desta configuração. Observação O Provedor OLE DB do Visual FoxPro ignora esta configuração, pois usa alocação dinâmica de memória (PROGCACHE=0). Padrão: 144 (-2 para MTDLL) |
| PROGWORK path | Especifica onde o Visual FoxPro armazena o arquivo de cache de programa. Para melhor desempenho, especialmente em um ambiente multiusuário, especifique um disco rápido, como um disco local ou memória, se disponível. Forneça pelo menos 256K para o cache, embora o arquivo possa crescer mais. Padrão: Dependente do sistema operacional. Para obter mais informações, consulte Otimizando o ambiente operacional. |
| REPORT extension | Especifica a extensão para arquivos de definição de relatório do Visual FoxPro. Padrão: .frx |
| RESOURCE path[\file] | OFF | Especifica o local do arquivo de recursos FoxUser.dbf ou impede que o Visual FoxPro use um arquivo de recursos. O argumento file é opcional. Se file for omitido, o Visual FoxPro procura o arquivo FoxUser.dbf. Se o arquivo especificado não existir, ele é criado. Padrão: Diretório de inicialização como path e FoxUser.dbf como file. |
| SCREEN = ON | OFF | Especifica se a janela principal do Visual FoxPro aparece ao abrir o Visual FoxPro. Quando um aplicativo consiste em um ou mais formulários de nível superior exibidos na área de trabalho do Windows, definir SCREEN como OFF pode ser útil, tornando a janela principal do Visual FoxPro desnecessária. Para obter mais informações sobre formulários de nível superior, consulte Controlando o comportamento de formulários. Padrão: ON |
| SORTWORK path | Especifica onde comandos como SORT e INDEX devem colocar arquivos de trabalho. Como os arquivos de trabalho podem ter até duas vezes o tamanho das tabelas sendo classificadas, especifique um local com bastante espaço livre. Para melhor desempenho, especialmente em um ambiente multiusuário, especifique um disco rápido, como um disco local. Padrão: Dependente do sistema operacional. Para obter mais informações, consulte Otimizando o ambiente operacional. |
| STACKSIZE = nValue | Especifica o número de níveis de aninhamento de 32 a 64.000 para operações como o comando DO. Observação Você pode alterar o nível de aninhamento somente durante a inicialização do Visual FoxPro. Padrão: 128 |
| TEDIT [/N] editor | Especifica o nome do editor de texto usado quando você edita arquivos de programa com MODIFY COMMAND ou MODIFY FILE. Inclua a cláusula opcional /N com TEDIT para especificar um editor de texto do Windows. Padrão: Editor do Visual FoxPro |
| TITLE title | Especifica o título que aparece na barra de legenda da janela principal do Visual FoxPro. Padrão: "Microsoft Visual FoxPro" |
| TMPFILES path | Especifica onde arquivos de trabalho temporários especificados pelas configurações EDITWORK, SORTWORK e PROGWORK em arquivos de configuração são armazenados se não forem especificados. Como os arquivos de trabalho podem ficar muito grandes, especifique um local com bastante espaço livre. Para melhor desempenho, especialmente em um ambiente multiusuário, especifique um disco rápido, como um disco local. Padrão: Dependente do sistema operacional. Para obter mais informações, consulte Otimizando o ambiente operacional. |
