# Exceção OLE IDispatch código "number" de "name": "name" (Erro 1428)

Você recebeu um código de erro retornado por um objeto Automation. É específico do objeto OLE. Neste caso, o objeto retorna uma descrição textual do erro, bem como a origem (geralmente o nome do objeto OLE) do erro.

Consulte a documentação do objeto para obter informações mais detalhadas.
