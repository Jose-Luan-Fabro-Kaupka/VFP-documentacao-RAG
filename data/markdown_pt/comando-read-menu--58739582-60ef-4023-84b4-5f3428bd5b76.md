# Comando READ MENU

Incluído para compatibilidade com versões anteriores. Use os Menu and Shortcut Designers para criar menus.

Ativa um pop-up.

```foxpro
READ MENU TO memvar [SAVE]
```

# Observações

READ MENU está incluído para compatibilidade com versões anteriores. Use o FoxPro Menu Builder para criar menus.

Este comando ativa o pop-up de menu criado com @ ... MENU.

O valor inicialmente contido na variável de memória ou elemento de matriz memvar especifica qual opção do pop-up é selecionada quando o pop-up é ativado. Quando você escolhe uma opção do pop-up, um valor é armazenado em memvar correspondente à opção escolhida. Se você pressionar Esc para sair do pop-up, memvar contém 0.

SAVE

 A cláusula SAVE mantém uma imagem do pop-up de menu na janela principal do FoxPro ou em uma janela definida pelo usuário depois que uma escolha é feita no menu ou Esc é pressionado. Normalmente, o menu é limpo da janela principal do FoxPro ou de uma janela definida pelo usuário depois que você faz uma escolha.
