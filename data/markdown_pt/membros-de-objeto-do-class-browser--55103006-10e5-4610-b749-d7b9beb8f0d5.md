# Membros de objeto do Class Browser

Você pode referenciar os objetos membros do Class Browser. A referência à janela do Class Browser em si é `_oBrowser`. Para obter mais informações, consulte How to: Customize the Class Browser and Class Browser Window.

A tabela a seguir lista os nomes dos objetos membros e reflete a ordem em que os objetos membros aparecem no Class Browser.

| Objeto do Class Browser | Nome do objeto |
| --- | --- |
| Caixa de edição de descrição da classe | edtClassDesc |
| Caixa de edição de membro da classe | edtMemberDesc |
| Botão de comando Open | cmdOpen |
| Botão de comando Add Additional File | cmdAdd |
| Botão de comando View Class Code | cmdExport |
| Botão de comando Find | cmdFind |
| Botão de comando New Class | cmdSubclass |
| Botão de comando Rename | cmdRename |
| Botão de comando Redefine | cmdRedefine |
| Botão de comando Remove | cmdRemove |
| Botão de comando Clean Up Library | cmdCleanup |
| Imagem Class Icon | imgClassIcon |
| Botão Class Icon | cmdClassIcon |
| Etiqueta Type para a caixa de combinação Type | lblClassType |
| Caixa de combinação Type | cboClassType |
| Controle de efeito 3D Class List | txtClassList3D |
| Contêiner OLE Class List | oleClassList |
| Contêiner OLE Member List | oleMembers |
| Controle de efeito 3D Member List | txtMembers3D |
| Caixa de listagem Object Member | lstMembers* |
| Caixa de listagem Methods | lstClassList* |
| Caixa de edição Class Description | edtClassDesc |
| Caixa de edição Member Description | edtMemberDesc |

* Esses objetos existem apenas quando lOutlineOCX é False (.F.).
