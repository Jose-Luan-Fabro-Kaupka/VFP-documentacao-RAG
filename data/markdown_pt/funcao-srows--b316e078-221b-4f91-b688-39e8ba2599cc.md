# Função SROWS( )

Retorna o número de linhas disponíveis na janela principal do Visual FoxPro.

```foxpro
SROWS()
```

# Valor de retorno

Numérico

# Observações

No Visual FoxPro para Windows, o valor retornado por SROWS( ) depende do modo de exibição atual. O modo de exibição pode ser alterado com SET DISPLAY.

# Exemplo

```foxpro
CLEAR
? SROWS()
```
