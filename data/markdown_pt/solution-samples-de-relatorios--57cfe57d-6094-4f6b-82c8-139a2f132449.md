# Solution Samples de relatórios

Estes exemplos da Solution ilustram tarefas que você pode realizar com relatórios.

# Nesta seção
 **Exemplo Print a Percent of Total in a Report**
Ilustra como calcular e exibir valores no início de um relatório antes que todos os registros da fonte de registros tenham sido impressos.
**Exemplo Print an Invoice**
Ilustra como um relatório usa uma view para combinar informações de várias tabelas, uma função para coletar dados do usuário e um layout de relatório um-para-muitos.
**Exemplo Print Customer Mailing Labels**
Ilustra como imprimir etiquetas de correspondência.
**Exemplo Print Data Dictionary Information**
Ilustra como gerar um relatório com o conteúdo de um banco de dados do Visual FoxPro.
**Exemplo Print in Catalog Format**
Ilustra como imprimir um diretório, envolver texto em torno de gráficos, alternar a posição de impressão de controles e posicionar campos flutuantes abaixo de campos que se expandem.
**Exemplo Print Product Orders By Quarter**
Ilustra como gerar e imprimir gráficos sem suspender operações normais.
**Exemplo Print Report Details in a Ledger Style**
Ilustra como imprimir uma lista de registros com cor de fundo alternada.
**Exemplo Use Conditional Formatting in a Report**
Ilustra como alterar a formatação de campos com base nos valores dos registros.
