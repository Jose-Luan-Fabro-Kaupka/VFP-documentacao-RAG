# Comando @ ... BOX

Incluído para compatibilidade com versões anteriores. Use o controle Shape em seu lugar.

Desenha uma caixa usando as coordenadas especificadas.

```foxpro
@ row1, column1, row2, column2
BOX [expC]
```

#### Parâmetros
 row1, column1, row2, column2
 row1, column1 são as coordenadas do canto superior esquerdo da caixa, e row2, column2 são as coordenadas do canto inferior direito da caixa. Se row1 e row2 forem iguais, uma linha horizontal será desenhada. Se column1 e column2 forem iguais, uma linha vertical será desenhada.

 expC

 Os caracteres usados para desenhar a caixa podem ser especificados incluindo expC, a expressão de caracteres, que pode conter nove caracteres — um para cada canto, um para cada lado e um para preencher a caixa. Os caracteres são exibidos começando pelo canto superior esquerdo e seguindo no sentido horário. Se um nono caractere for especificado, ele será usado para preencher o interior da caixa. Se apenas um caractere for especificado, ele será usado para desenhar toda a borda. Se expC for omitido, a caixa será desenhada usando uma linha simples.

# Observações

Este comando desenha uma caixa na janela principal do FoxPro ou em uma janela definida pelo usuário.

# Exemplo

Este exemplo desenha uma caixa de linha simples:

```foxpro
@ 10,20,14,60 BOX
```
