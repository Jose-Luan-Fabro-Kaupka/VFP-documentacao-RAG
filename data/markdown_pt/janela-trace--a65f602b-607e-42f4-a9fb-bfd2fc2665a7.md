# Janela Trace

Permite que você veja suas linhas de código conforme elas são executadas.

Esta janela é ativada quando você escolhe Trace no menu Window, Debugger Window.
 **Object**
Disponível ao executar código de objeto. O código na janela Trace está associado ao objeto exibido na lista Object. A lista Object contém todos os objetos contidos no contêiner pai de nível mais alto do objeto cujo código está sendo executado no momento.
**Procedure**
Disponível ao executar código de objeto. O código na janela Trace está associado ao método ou evento exibido na lista Procedure. A lista Procedure contém todos os métodos do objeto na lista Object que têm código associado a eles.

A área esquerda da janela Trace pode conter os seguintes símbolos.

| Símbolo | Descrição |
| --- | --- |
| Linha de código em execução no momento. | |
| Breakpoint ativo. | |
| Breakpoint inativo. | |
| Posição na pilha de chamadas se você estiver examinando código em um nível diferente do código em execução no momento. | |
