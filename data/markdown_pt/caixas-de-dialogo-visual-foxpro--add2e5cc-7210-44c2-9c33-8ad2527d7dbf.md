# Caixas de diálogo (Visual FoxPro)

Esta seção explica as opções que aparecem em várias caixas de diálogo.

# Nesta seção
 **About Microsoft Visual FoxPro Dialog Box**
Displays the Visual FoxPro copyright, licensing, and version information, as well as your product identification number.
**Caixa de diálogo Add Files to Source Control**
Adiciona um arquivo ou arquivos selecionados em seu projeto ao controle de código-fonte.
Adds a file or selected files in your project to source code control.
**Caixa de diálogo Add Table or View**
Permite selecionar uma ou mais tabelas ou views existentes como base para sua nova consulta ou view local.
Allows you to select one or more existing tables or views on which to base your new query or local view.
**Caixa de diálogo Advanced Options**
Permite ajustar como os registros são recuperados em uma view ou como as atualizações são feitas no servidor ou nas tabelas de origem.
Makes it possible for you to fine-tune how records are retrieved in a view or how updates are made to the server or source tables.
**Caixa de diálogo Append From**
Permite adicionar registros à tabela ou view atual de outra tabela, planilha ou arquivo de texto.
Makes it possible for you to add records to the current table or view from another table, a spreadsheet, or text file.
**Caixa de diálogo Append From Options**
Especifica campos a anexar e permite construir uma expressão que deve ser atendida pelos registros a serem anexados.
Specifies fields to append and allows you to build an expression that must be met by records that are to be appended.
**Caixa de diálogo Arrange Tables and Views**
Permite alterar o layout de tabelas e views em seu banco de dados.
Allows you to change the layout of tables and views in your database.
**Caixa de diálogo Beautify Options**
Permite especificar estilos de capitalização e indentação para texto em janelas de edição.
Makes it possible for you to specify capitalization and indentation styles for editing window text.
**Caixa de diálogo Breakpoints**
Permite especificar opções para pontos de interrupção.
Allows you to specify options for breakpoints.
**Caixa de diálogo Build Options**

**Caixa de diálogo Calculate Field**

Makes it possible for you to select a mathematical operation to create a computed field.
**Caixa de diálogo Change Icon**

Specifies an icon to be used for a linked or embedded object on a form or in a General field of a table.
**Caixa de diálogo Check In Files**
Faz check-in das alterações feitas no diretório de trabalho do ambiente de desenvolvimento no banco de dados de controle de código-fonte.
Checks in changes made in your development environment working directory to your source code control database.
**Caixa de diálogo Check Out Files**
Faz check-out de uma cópia dos arquivos selecionados do provedor de controle de código-fonte e coloca uma cópia gravável no diretório de trabalho correspondente do ambiente de desenvolvimento.
Checks out a copy of the selected files from your source code control provider and places a writable copy in the corresponding development environment working directory.
**Caixa de diálogo Choose Field/Variable**
Especifica um campo de tabela ou variável.
Specifies a table field or variable.
**Caixa de diálogo Class Info**
Mostra vários atributos dos membros da classe, sua aparência em tempo de design e se estão protegidos ou não.
Shows various attributes of class members, their design-time appearance, and whether or not they are protected.
**Caixa de diálogo Code Page**
Permite atribuir uma página de código a um arquivo .dbf ou arquivo de texto que não possui uma.
Allows you to assign a code page to a .dbf file or text file that does not have one.
**Caixa de diálogo Comment**
Permite inserir notas ou comentários para identificar a consulta ou view e sua finalidade.
Allows you to enter notes or comments to identify the query or view and its purpose.
**Caixa de diálogo Compile**

**Caixa de diálogo Connections**

**Caixa de diálogo Create**

Allows you to specify the directory, name, and type of the new file.
**Caixa de diálogo Create One-To-Many Relationships**

Establishes a one-to-many relationship, in which the child table can contain multiple records that correspond to one record in the parent table.
**Caixa de diálogo Customize Toolbox**

Displays options for changing settings and editing categories or items for the Toolbox.
**Caixa de diálogo Data Grouping**

**Caixa de diálogo Define Window Layout**

**Caixa de diálogo Edit Properties**

**Caixa de diálogo Edit Property/Method**

**Caixa de diálogo Expression Builder**

Makes it possible for you to create and edit expressions. An expression can be as simple as a field name or as complex as a calculation involving immediate IF functions, concatenations, and data type conversions.
