# Incompatibilidade de revisão da biblioteca API. Reconstrua a biblioteca (Erro 1711)

A biblioteca API que você está usando não corresponde à sua versão do Visual FoxPro.
 - Você está usando uma versão mais antiga de um arquivo .FLL. Reconstrua o arquivo .FLL ou obtenha uma versão atualizada.
- O controle ActiveX que chama a API do Visual FoxPro está desatualizado. Reconstrua o controle ActiveX ou obtenha uma versão atualizada.

Para obter mais informações, consulte Accessing the Visual FoxPro API.
