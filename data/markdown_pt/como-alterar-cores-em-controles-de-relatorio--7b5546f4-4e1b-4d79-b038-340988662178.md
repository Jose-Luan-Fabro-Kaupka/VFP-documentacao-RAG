# Como: alterar cores em controles de relatório

Você pode alterar as cores nos controles Field, Label, Line, Rectangle e Rounded Rectangle. Cores de primeiro plano e de fundo estão disponíveis dependendo do controle de relatório.

> **Observação:** As cores de fundo podem não ser exibidas se o controle estiver definido como transparente. Para obter mais informações, consulte Como: alterar a opacidade de controles de relatório.

### Para alterar cores em controles de relatório
- Abra o relatório ou etiqueta no designer apropriado.
- No designer, clique no controle que deseja alterar.
- No menu Format, clique em Foreground Color ou Background Color, dependendo da disponibilidade para o controle.
- Na caixa de diálogo Color, selecione a cor desejada e clique em OK.

Você também pode alterar as cores de primeiro plano e de fundo clicando duas vezes no controle de relatório para abrir a caixa de diálogo de propriedades do controle de relatório. Clique na guia Style, desmarque as caixas de seleção Use default foreground color ou Use default background color e clique nos botões de reticências (…) para selecionar cores diferentes. Para obter mais informações, consulte Guia Style, Caixa de diálogo Propriedades do controle de relatório (Report Builder).

> **Observação:** Se a variável de sistema _REPORTBUILDER não estiver definida para o Report Builder padrão ou estiver definida para um builder de terceiros, a caixa de diálogo do controle de relatório é exibida ou uma caixa de diálogo diferente pode ser exibida. Para obter mais informações, consulte Variável de sistema _REPORTBUILDER.
