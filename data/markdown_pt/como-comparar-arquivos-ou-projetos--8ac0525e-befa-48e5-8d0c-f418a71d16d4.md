# Como: comparar arquivos ou projetos

Ao trabalhar com arquivos e com um projeto, você pode precisar comparar a cópia local atual no seu diretório de trabalho com a cópia principal atual no projeto controlado por fonte. Isso pode ajudar a determinar se outro usuário alterou um arquivo ou ajudar a identificar onde você fez alterações desde que fez o check-out do arquivo.

A maioria dos sistemas de controle de fonte só pode comparar e exibir diferenças entre arquivos se estiverem em formato de texto. Quando o Visual FoxPro compara formulários, relatórios, menus, etiquetas e bibliotecas de classes, ele usa as representações de texto desses arquivos.

> **Observação:** Se o seu provedor de controle de fonte não suportar opções de comparação de arquivos, elas não estarão disponíveis no menu.

### Para ver diferenças entre projetos
- No menu Project, escolha Source Control e, em seguida, escolha Show Project Differences. O relatório resultante é produzido pelo seu software de controle de fonte, portanto as informações específicas fornecidas podem variar. Em geral, no entanto, o sistema de controle de fonte exibirá uma janela com dois painéis e destacará ou marcará de outra forma as diferenças entre as cópias local e principal do arquivo.

### Para ver diferenças entre arquivos ou a lista do projeto
- Se você estiver visualizando diferenças para um único arquivo, no Project Manager, selecione o arquivo para o qual deseja ver diferenças.
- Para um único arquivo, no menu Project, escolha Source Control e, em seguida, escolha Show Differences. Para a lista do projeto, no menu Project, escolha Source Control e, em seguida, escolha Show Project List Differences. O relatório resultante é produzido pelo seu software de controle de fonte, portanto as informações específicas fornecidas podem variar. Em geral, no entanto, o sistema de controle de fonte exibirá as duas versões lado a lado e destacará ou marcará de outra forma linhas novas, excluídas e alteradas.
