# Caixa de diálogo Escolher campo/variável

Especifica um campo de tabela ou variável.
 **Escolher um campo ou variável**
Digite o campo ou variável desejado.
**Fields**
Exibe campos na tabela especificada na caixa Field da caixa de diálogo Report Picture. Clique duas vezes no campo desejado para mover o campo para a caixa Escolher um campo ou variável.
**Variables**
Exibe variáveis disponíveis. Clique duas vezes na variável desejada para moverla para a caixa de texto Escolher um campo ou variável.
**Comment**
Permite adicionar comentários. Os comentários são inteiramente para sua referência e não aparecem no relatório ou etiqueta impressa.
