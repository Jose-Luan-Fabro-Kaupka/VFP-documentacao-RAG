# Manipulação de matrizes

Estes comandos e funções permitem trabalhar com matrizes de variáveis.

| Para | Use |
| --- | --- |
| Função ACOPY( ) | Copia elementos de uma matriz para outra matriz. |
| Função ADEL( ) | Exclui um elemento de uma matriz unidimensional ou uma linha ou coluna de uma matriz bidimensional. |
| Função ADIR( ) | Coloca informações sobre arquivos em uma matriz e retorna o número de arquivos. |
| Função AELEMENT( ) | Retorna o número de um elemento de matriz a partir dos subscritos do elemento. |
| Função AFIELDS( ) | Recupera e armazena informações sobre a estrutura da tabela em uma área de trabalho especificada, especificada por um alias de tabela, ou na área de trabalho atualmente selecionada em uma matriz e retorna o número de campos na tabela. |
| Função AFONT( ) | Coloca informações sobre fontes disponíveis, como seus nomes, em uma matriz. |
| Função AINS( ) | Insere um elemento em uma matriz unidimensional ou uma linha ou coluna em uma matriz bidimensional. |
| Função ALEN( ) | Retorna o número de elementos, linhas ou colunas em uma matriz. |
| Comando APPEND FROM ARRAY | Adiciona um registro à tabela atualmente selecionada para cada linha em uma matriz e preenche cada registro com dados da linha correspondente da matriz. |
| Função ASESSIONS( ) | Cria uma matriz de IDs de sessão de dados existentes. |
| Função ASCAN( ) | Pesquisa uma matriz por um elemento que contenha os mesmos dados e tipo de dados de uma expressão. |
| Função ASORT( ) | Classifica elementos em uma matriz em ordem crescente ou decrescente. |
| Função ASUBSCRIPT( ) | Retorna o subscrito de linha ou coluna de um elemento a partir do número do elemento. |
| Comando COPY TO ARRAY | Copia dados da tabela atualmente selecionada para uma matriz. |
| Comando DECLARE | Cria uma matriz unidimensional ou bidimensional. |
| Comando DIMENSION | Cria uma matriz unidimensional ou bidimensional de variáveis. |
| Comando GATHER | Substitui os dados no registro atual da tabela atualmente selecionada por dados de uma matriz, um conjunto de variáveis ou um objeto. |
| Comando SCATTER | Copia dados do registro atual para um conjunto de variáveis ou para uma matriz. |
