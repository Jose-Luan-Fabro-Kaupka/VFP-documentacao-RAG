# Amostra Use Common Application Dialog Boxes

Arquivo: ...\Samples\Solution\Ffc\Dialogs.scx

Esta amostra contém as seguintes classes.

| Classe | Biblioteca | Descrição |
| --- | --- | --- |
| _splash | _dialogs.vcx | Fornece uma tela de abertura para um aplicativo. |
| _login | _dialogs.vcx | Fornece uma caixa de Login para um aplicativo. |
| _aboutbox | _dialogs.vcx | Fornece uma caixa About para um aplicativo. |
| _keywords | _dialogs.vcx | Fornece acesso à tabela de palavras-chave (.dbf). |
| _locateitem | _dialogs.vcx | Exibe caixas de diálogo Locate Item para um aplicativo. |

Para obter detalhes sobre todas as classes disponíveis nas foundation classes, consulte Visual FoxPro Foundation Classes A-Z.
