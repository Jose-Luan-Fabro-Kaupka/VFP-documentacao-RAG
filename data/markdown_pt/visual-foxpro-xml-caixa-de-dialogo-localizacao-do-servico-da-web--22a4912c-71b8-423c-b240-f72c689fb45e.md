# Visual FoxPro XML Caixa de diálogo Localização do serviço da Web

Especifica um Uniform Resource Locator local (URL) ou um diretório virtual para publicar um serviço Web XML.

A caixa de diálogo Local do serviço Web do Visual FoxPro XML aparece na primeira vez que você seleciona o assistente do Web Services Publisher no menu Assistentes. Você pode abrir a caixa de diálogo clicando em Avançado na caixa de diálogo Visual FoxPro XML Web Services Publisher. Para obter mais informações, consulte Caixa de diálogo Visual FoxPro XML Web Services Publisher.

> **Observação:** Todas as configurações anteriores de serviços da Web XML publicados anteriormente são preservadas, portanto, você não precisa redefinir esses valores sempre que quiser republicar um serviço da Web XML publicado anteriormente.
 **Existente**
Selecione um local existente na caixa Selecionar local (diretório virtual) para publicar um serviço Web XML. Deve ser um local URL URL (diretório virtual) disponível em um servidor Web IIS acessível.
**Novo**
Especifica um novo diretório virtual na caixa Selecionar local (diretório virtual) para publicar um serviço Web XML e para digitar um nome para o diretório virtual na caixa Novo nome do diretório virtual.
**Selecione o local (diretório virtual)**
Especifica o URL local (diretório virtual) para publicar um serviço Web XML. A caixa lista todos os diretórios virtuais disponíveis em seu servidor Web padrão IIS. Se Novo for selecionado, o URL especificado será usado como o local raiz do novo diretório virtual que aparece na caixa Novo Nome do Diretório Virtual.
**Caminho de saída do arquivo**
Exibe o caminho físico para o novo local do diretório virtual e está disponível somente quando Novo é selecionado. Clique no botão Reticências (...) à direita da caixa Caminho de Saída do Arquivo para selecionar um diretório físico para o novo diretório virtual.
**Novo nome do diretório virtual**
Especifica o nome do novo diretório virtual e está disponível somente quando Novo é selecionado.
