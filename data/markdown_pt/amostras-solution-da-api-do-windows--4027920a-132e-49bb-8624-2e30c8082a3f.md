# Amostras Solution da API do Windows

Estas amostras Solution ilustram tarefas de desenvolvimento de aplicativos que você pode realizar com a API do Windows.

# Nesta seção
 **Get Application Information from the Windows Registry Sample**
Ilustra como obter informações do Registro do Windows sobre outros aplicativos usando a linguagem Visual FoxPro.
**Get Version Information Sample**
Ilustra como exibir as informações de versão de um arquivo .dll ou .exe.
**Play Multimedia Files Using MCI Commands Sample**
Ilustra como usar a Media Control Interface (MCI) para reproduzir arquivos multimídia.
**Read and Write Visual FoxPro Registry Values Sample**
Ilustra como obter configurações do Visual FoxPro no Registro do Windows usando a linguagem Visual FoxPro.
**Read ODBC Registry Values Sample**
Ilustra como obter informações de driver ODBC e fonte de dados no Registro do Windows usando a linguagem Visual FoxPro.
**Use API Functions that Require a STRUCT Sample**
Ilustra como chamar a função da API do Windows GetSystemTime para preencher uma estrutura de valores WORD com informações de hora do sistema.
**Use API Functions That Require Pointers to Arrays Sample**
Ilustra como chamar duas funções da API do Windows para recuperar e redefinir configurações de cores do sistema usando ponteiros para matrizes.
**View Type Library Information Sample**
Ilustra como usar a classe TypeLib para ler informações de Type Library de qualquer arquivo .dll, .exe ou .tlb.

# Referência
 **Sample Class Libraries**
Contém bibliotecas de classes de amostra que fornecem funcionalidade encapsulada que você pode adicionar aos seus aplicativos.

**Reference (Visual FoxPro)**
Inclui tópicos de referência geral, de linguagem de programação, de interface do usuário e de mensagens de erro do Visual FoxPro.
