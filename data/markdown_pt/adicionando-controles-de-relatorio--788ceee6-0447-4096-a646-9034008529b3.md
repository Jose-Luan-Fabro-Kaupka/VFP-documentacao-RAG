# Adicionando controles de relatório

Você pode adicionar uma variedade de controles a relatórios e etiquetas. A tabela a seguir descreve os controles de relatório que você pode adicionar e usar.

| Controle de relatório | Exibe |
| --- | --- |
| Field | Valores avaliados a partir de variáveis, expressões ou campos em tabelas e views. Esses valores podem ser diferentes cada vez que você gera saída para o relatório ou etiqueta. |
| Label | Texto que aparece da mesma forma cada vez que você gera saída para o relatório ou etiqueta. |
| Line | Linhas retas horizontais ou verticais. |
| Rectangle | Caixas e bordas. |
| Rounded Rectangle | Caixas com cantos arredondados, bordas, círculos e ovais. |
| Picture/OLE Bound | Arquivos de imagem ou conteúdo de campos General. |
