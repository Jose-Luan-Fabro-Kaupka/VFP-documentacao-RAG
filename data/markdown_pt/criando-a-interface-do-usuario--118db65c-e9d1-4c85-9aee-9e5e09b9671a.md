# Criando a interface do usuário

Uma interface bem projetada pode orientar os usuários pelo seu aplicativo. Formulários, classes, controles, menus e barras de ferramentas oferecem um rico conjunto de ferramentas para projetar uma excelente interface do usuário.

# Nesta seção
 **Trabalhando com formulários**
Depois de criar seu formulário, você pode executá-lo, ocultá-lo ou alterá-lo de diferentes maneiras.
**Usando controles**
Os controles gerenciam as interações entre os usuários e seu aplicativo. O Microsoft Visual FoxPro oferece vários controles para aprimorar a interface do aplicativo.
**Projetando menus e barras de ferramentas**
Um bom sistema de menus informa muito aos usuários sobre o projeto e a estrutura do aplicativo. Planejar cuidadosamente menus e barras de ferramentas pode melhorar a usabilidade do aplicativo e fornecer acesso imediato a tarefas comuns.

# Seções relacionadas
 **Desenvolvendo aplicativos Visual FoxPro**
Esta seção inclui informações conceituais sobre como desenvolver aplicativos Visual FoxPro, instruções para criar bancos de dados e a interface do usuário, além de outras tarefas necessárias para criar aplicativos Visual FoxPro.
**Criando aplicativos**
Discute como criar um aplicativo Visual FoxPro, que pode incluir um ou mais bancos de dados, um programa principal que configura o ambiente de sistema do aplicativo e uma interface do usuário composta por formulários, barras de ferramentas e menus.
**Como: definir o ponto inicial**
Descreve como o arquivo principal é o ponto inicial do aplicativo e pode consistir em um programa ou formulário. Quando o aplicativo é executado, o Visual FoxPro inicia o arquivo principal, que, por sua vez, executa todos os outros componentes conforme necessário.
**Como: inicializar o ambiente**
Configurar o ambiente do aplicativo é a primeira tarefa que um arquivo principal ou objeto de aplicativo deve realizar.
**Como: controlar o loop de eventos**
Saiba como estabelecer um loop de eventos, fazendo com que o Visual FoxPro comece a processar eventos do usuário, como cliques do mouse e pressionamentos de tecla. Isso ocorre depois que o ambiente é configurado e a interface inicial do usuário é exibida.
**Criando aplicativos com o Application Framework**
Explica como criar aplicativos com o Application Framework usando o Application Wizard e o Application Builder.
**Otimizando o desempenho cliente/servidor**
Saiba como ajustar seu aplicativo para obter o desempenho máximo, aumentando a taxa de transferência de dados.
**Migrando bancos de dados do Visual FoxPro**
Explica como usar os assistentes de migração para mover bancos de dados, tabelas e exibições do seu sistema para um Microsoft SQL Server remoto.
**Criando aplicativos internacionais**
Descreve como projetar e desenvolver aplicativos Visual FoxPro para que sejam tão eficazes internacionalmente quanto no mercado nacional.
