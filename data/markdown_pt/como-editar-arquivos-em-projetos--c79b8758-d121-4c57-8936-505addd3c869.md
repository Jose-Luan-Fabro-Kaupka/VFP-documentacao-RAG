# Como: editar arquivos em projetos

Você pode editar arquivos que adiciona a um projeto. Quando cria ou adiciona um novo arquivo, pode adicionar uma descrição ao arquivo. Essa descrição é exibida na parte inferior do Project Manager quando o arquivo é selecionado.

### Para editar um arquivo de projeto
- Abra o projeto da sua aplicação.
- No Project Manager, expanda os nós na hierarquia do projeto que contêm o arquivo que deseja editar.
- Clique no arquivo que deseja editar.
- No menu Project, clique em Modify File. Dica Você também pode clicar em Modify no Project Manager.

A janela ou designer apropriado abre para que você possa modificar o arquivo. Para obter mais informações, consulte a janela Project Manager.

### Para editar um projeto programaticamente
- Use o comando MODIFY PROJECT para abrir o Project Manager.

Para obter mais informações, consulte o comando MODIFY PROJECT.

### Para adicionar uma descrição a um arquivo
- Abra o projeto da sua aplicação.
- No Project Manager, selecione o arquivo.
- No menu Project, clique em Edit Description.
- Na caixa de diálogo Description, digite uma descrição para o arquivo.
- Quando terminar, clique em OK.

Para obter mais informações, consulte a janela Project Manager.
