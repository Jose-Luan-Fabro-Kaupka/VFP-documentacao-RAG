# Caixa de diálogo Task Pane Options

A caixa de diálogo Task Pane Options permite personalizar o Task Pane Manager e cada painel que ele contém. Você também pode adicionar novos painéis e acessar a caixa de diálogo Pane Customization para criar seus próprios painéis.
 **Move Up**
Move para cima o item selecionado na exibição em árvore.
**Move Down**
Move para baixo o item selecionado na exibição em árvore.
**Tree View**
Exibe as diferentes áreas do Task Pane Manager nas quais você pode definir opções. Ao clicar em um item, o nó é expandido para mostrar categorias adicionais e as opções apropriadas são exibidas à direita. A ordem dos painéis na árvore também determina a ordem em que aparecem na parte superior do Task Pane Manager.
**Help**
Abre o arquivo da Ajuda do Visual FoxPro.

# Task Pane Manager, General

Exibe opções que podem ser definidas para o Task Pane Manager.
 **Pane**
Especifica o painel inicial exibido quando o Task Pane Manager é aberto.
**Check for New Internet Content**
Seleciona a frequência de verificação de novo conteúdo para painéis baseados na Web. Esta opção é o padrão, mas há configurações diferentes conforme o painel.
**Open the Task Pane when Visual FoxPro starts**
Especifica se o Task Pane Manager é aberto automaticamente quando o Visual FoxPro é iniciado.

# Task Pane Manager, Customize

Exibe opções para personalizar painéis e gerenciar o Task Pane Manager.
 **Install Pane**
Exibe uma caixa de diálogo para selecionar um painel da Microsoft ou de terceiros a ser adicionado.
**Customize Panes**
Exibe a caixa de diálogo Pane Customization, que permite visualizar e personalizar painéis e criar painéis personalizados.
**Cleanup Tables**
Remove registros excluídos das tabelas do Task Pane Manager e limpa seu diretório de cache.
**Restore to Default**
Restaura as configurações e os painéis padrão.
**Folder for Take Pane Manager content tables**
Especifica a pasta na qual o Task Pane Manager acessa suas tabelas.
**Folder for cached files**
Especifica a pasta na qual o Task Pane Manager armazena arquivos em cache.
