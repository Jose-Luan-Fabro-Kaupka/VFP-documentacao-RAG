# Como: adicionar arquivos a um projeto sob controle de código-fonte

Depois de colocar um projeto do Visual FoxPro sob controle de código-fonte, você pode adicionar arquivos individuais ao projeto controlado. Se o projeto já contiver arquivos nesse momento, também poderá adicioná-los.

> **Observação:** Se o software de controle aceitar esse recurso, o Visual FoxPro permitirá manter o arquivo em check-out ao adicioná-lo. Caso contrário, o arquivo será incluído por check-in e você precisará fazer check-out novamente para trabalhar nele.

### Para adicionar arquivos existentes a um projeto controlado
- No menu Projeto, escolha Controle de Código-Fonte e Adicionar Arquivos ao Controle de Código-Fonte.
- Na caixa Adicionar Arquivos ao Controle de Código-Fonte, selecione os arquivos. As opções Manter em check-out e Comentário aparecem somente se forem aceitas pelo software.
- Clique em OK. O Visual FoxPro gera os arquivos de controle necessários e adiciona os arquivos ao projeto. Se houver muitos arquivos, isso poderá levar algum tempo.

Você pode configurar o Visual FoxPro para solicitar a inclusão no controle de código-fonte quando um arquivo for adicionado ao projeto.

### Para fazer o Visual FoxPro solicitar a inclusão de novos arquivos no controle
- Na guia Projetos da caixa Opções, selecione Adicionar automaticamente novos projetos ao controle de código-fonte e clique em OK. Para tornar essa configuração padrão, clique em Definir como Padrão e em OK.

Depois de adicionar arquivos, atualize a lista do projeto para que outros desenvolvedores possam trabalhar com eles.
