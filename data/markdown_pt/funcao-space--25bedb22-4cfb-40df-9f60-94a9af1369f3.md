# Função SPACE( )

Retorna uma cadeia de caracteres composta pelo número especificado de espaços.

```foxpro
SPACE(nSpaces)
```

#### Parâmetros
 **nSpaces**
Especifica o número de espaços retornados por SPACE( ). O valor máximo de nSpaces é limitado apenas pela memória disponível no Microsoft Visual FoxPro.

# Valor de retorno

Character
