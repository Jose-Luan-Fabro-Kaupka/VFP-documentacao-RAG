# Propriedade Interval

Especifica o número de milissegundos entre chamadas ao evento Timer de um controle Timer. Disponível em tempo de design e em tempo de execução.

```foxpro
Timer.Interval[ = nTime]
```

# Valor de retorno
 **nTime**
Especifica o número de milissegundos entre eventos Timer. O valor padrão é 0, o que impede que o evento Timer seja disparado.

# Observações

Aplica-se a: Timer Control

Para obter mais informações sobre a propriedade Interval, consulte "Initializing a Timer Control" em Performing Specific Actions at Given Intervals.
