# Arquitetura de aplicativos

A arquitetura de aplicativos do Visual FoxPro varia com o tipo de aplicativo que você decide criar. Ao projetar a estrutura do seu aplicativo, considere a função que cada componente fornece e sua relação com outros componentes.

Por exemplo, um aplicativo de banco de dados típico consiste em estruturas de dados, uma interface do usuário, opções de consulta e capacidades de relatório. Um aplicativo Visual FoxPro montado típico fornece ao usuário um menu e um ou mais formulários para inserir ou exibir dados. Você pode fornecer funcionalidade e manter integridade e segurança dos dados anexando código a certos eventos. Consultas e relatórios permitem que seus usuários extraiam informações do banco de dados.

**Rapid Application Development**
Descreve as etapas fundamentais no desenvolvimento de aplicativos, prototipagem, upsizing, implementação e otimização.
**Application Creation with Accuracy and Data Integrity**
Descreve como usar regras de validação de dados e procedimentos armazenados do Visual FoxPro com as regras de validação de dados e procedimentos armazenados da fonte de dados para construir aplicativos cliente/servidor que protegem a integridade dos dados.
**Planning Enterprise Applications**
Explica como você pode usar o Visual FoxPro como parte de um aplicativo de maior escala que envolve duas ou mais ferramentas de desenvolvimento, o que permite aproveitar as capacidades exclusivas de cada produto.
