# Catálogos da Galeria de Componentes

Quando você abre a Galeria de Componentes, o painel esquerdo, Catálogo, exibe o catálogo padrão fornecido com a Galeria de Componentes. Um catálogo é uma representação visual de itens que pertencem a um grupo de itens do Visual FoxPro ou definido pelo usuário. Dentro de um catálogo, você pode criar pastas para organizar ainda mais subgrupos de itens. Os itens podem ser formulários, consultas, programas, modelos, arquivos de arte, arquivos de som ou outros objetos. O catálogo padrão da Galeria de Componentes do Visual FoxPro inclui itens agrupados em várias categorias, incluindo formulários, controles e outros. O catálogo padrão também inclui uma pasta vazia chamada Favorites que você pode usar para criar ou copiar itens da galeria. Você também pode copiar e renomear o catálogo padrão ou criar seus próprios catálogos.

As opções de catálogo da Galeria de Componentes são definidas para o conteúdo do catálogo e o comportamento de abertura. Catálogos globais podem conter qualquer tipo de item da Galeria de Componentes. Catálogos padrão abrem automaticamente quando você inicia a Galeria de Componentes. Para detalhes, consulte a guia Catalogs, Caixa de diálogo Opções da Galeria de Componentes da caixa de diálogo Opções da Galeria de Componentes na Ajuda.

A Galeria de Componentes inclui os seguintes catálogos.

| Catálogo | Descrição |
| --- | --- |
| VFPGLRY | Contém componentes usados por outros catálogos na galeria. Contém todos os catálogos fornecidos com o Visual FoxPro. Catálogo padrão e global. |
| Visual FoxPro | Contém as classes Foundation do Visual FoxPro. Catálogo padrão. |
| Favorites | Uma pasta vazia. Catálogo global |
| My Base Classes | Contém classes base do Visual FoxPro subclassificadas. Catálogo padrão |
| ActiveX | Um catálogo dinâmico contendo uma lista de todos os controles ActiveX registrados ou uma lista de todos os controles ActiveX do Visual FoxPro. Catálogo padrão. |
| World Wide Web | Uma coleção de URLs de sites da Web |
| Multimedia | Uma variedade de imagens, sons e itens de vídeo que você pode usar em seus aplicativos |
| Samples | Referências às amostras Solutions, ActiveX Servers e Client/Server |

Quando você clica em um catálogo na exibição de lista, o painel direito, Objeto, exibe o conteúdo desse catálogo. Você pode abrir outros catálogos clicando duas vezes no catálogo em qualquer um dos painéis. Vários catálogos estão incluídos na pasta Gallery.
