# Objeto Hyperlink

Cria um objeto Hyperlink.

```foxpro
Hyperlink
```

# Observações

Um objeto Hyperlink fornece capacidades de navegação para aplicações do Visual FoxPro hospedadas em containers como o Microsoft Internet Explorer.

Observe que o objeto Hyperlink é suportado apenas no Microsoft Internet Explorer. Use a Foundation Class Hyperlink Button, Hyperlink Image Foundation Class ou Hyperlink Label Foundation Class na Using the Component Gallery para capacidades de navegação independentes de navegador.
