# Gerenciamento de arquivos

Estes comandos e funções gerenciam e manipulam arquivos em disco.

| Uso | Para |
| --- | --- |
| ADDBS( ) Function | Adicionar uma barra invertida a uma expressão de caminho. |
| ADIR( ) Function | Colocar informações sobre arquivos em uma matriz e retornar o número de arquivos. |
| CD | CHDIR Command | Alterar o diretório padrão do Visual FoxPro para o diretório que você especifica. |
| CLOSE Commands | Fechar vários tipos de arquivo. |
| COPY FILE Command | Duplicar qualquer tipo de arquivo. |
| CREATE VIEW Command | Criar um arquivo de view a partir do ambiente do Visual FoxPro. |
| CURDIR( ) Function | Retornar o diretório atual. |
| DEFAULTEXT( ) Function | Retornar um nome de arquivo com uma nova extensão se ainda não existir. |
| DELETE FILE Command | Excluir um arquivo de um disco. |
| DIR or DIRECTORY Command | Exibir informações sobre os arquivos em um diretório. |
| DISPLAY FILES Command | Exibir informações sobre arquivos. |
| DISKSPACE( ) Function | Retornar o número de bytes disponíveis na unidade ou volume de disco padrão ou especificado. |
| DO Command | Executar um programa ou procedimento do Visual FoxPro. |
| DRIVETYPE( ) Function | Retornar o tipo da unidade especificada. |
| EDITSOURCE( ) Function | Abrir o editor do Visual FoxPro e, opcionalmente, posicionar o cursor. |
| ERASE Command | Apagar um arquivo do disco. |
| FDATE( ) Function | Retornar a última data ou DateTime de modificação de um arquivo. |
| FTIME( ) Function | Retornar a última hora de modificação de um arquivo. |
| FILE( ) Function | Localizar o arquivo especificado. |
| FILETOSTR( ) Function | Retornar o conteúdo de um arquivo como uma cadeia de caracteres. |
| FLUSH Command | Salvar alterações de tabela e índice no disco. |
| FORCEEXT( ) Function | Retornar uma cadeia de caracteres com a extensão antiga do nome de arquivo substituída por uma nova extensão. |
| FORCEPATH( ) Function | Retornar um nome de arquivo com um novo nome de caminho substituindo o antigo. |
| FULLPATH( ) Function | Retornar o caminho para um arquivo especificado ou o caminho relativo a outro arquivo. |
| GETFILE( ) Function | Exibir a caixa de diálogo Abrir e retornar o nome do arquivo escolhido. |
| GETPICT( ) Function | Exibir a caixa de diálogo Abrir imagem e retornar o nome do arquivo de imagem escolhido. |
| ISNULL( ) Function | Retornar true (.T.) se uma expressão avalia para um valor nulo; caso contrário, ISNULL( ) retorna false (.F.). |
| JUSTDRIVE( ) Function | Retornar a letra da unidade de um caminho completo. |
| JUSTEXT( ) Function | Retornar a porção do nome de arquivo de um caminho e nome de arquivo completos. |
| JUSTFNAME( ) Function | Retornar a porção do nome de arquivo de um caminho e nome de arquivo completos. |
| JUSTPATH( ) Function | Retornar a porção do caminho de um caminho e nome de arquivo completos. |
| JUSTSTEM( ) Function | Retornar o nome base (o nome do arquivo antes da extensão) de um caminho e nome de arquivo completos. |
| LIST Commands | Exibir informações de tabela ou ambiente sem pausar a janela principal do Visual FoxPro ou definida pelo usuário. |
| LOCFILE( ) Function | Localizar um arquivo no disco e retornar o nome do arquivo com seu caminho. |
| MD | MKDIR Command | Criar um novo diretório ou subdiretório no disco. |
| MODIFY COMMAND Command | Abrir uma janela de edição para modificar ou criar um arquivo de programa. |
| MODIFY FILE Command | Abrir uma janela de edição para modificar ou criar um arquivo de texto. |
| NVL( ) Function | Retornar um valor não nulo de duas expressões. |
| OPEN DATABASE Command | Abre um banco de dados. |
| PUTFILE( ) Function | Invocar a caixa de diálogo Salvar como e retornar o nome de arquivo que você especifica. |
| RD | RMDIR Command | Remover um diretório ou pasta do disco. |
| RENAME Command | Alterar o nome de um arquivo para um novo nome. |
| SET ALTERNATE Command | Direcionar saída de tela ou impressora criada com ?, ??, DISPLAY ou LIST para um arquivo de texto. |
| SET DEFAULT Command | Especificar a unidade e o diretório padrão. |
| SET FULLPATH Command | Especificar se CDX( ), DBF( ), MDX( ) e NDX( ) retornam o caminho em um nome de arquivo. |
| SET PATH Command | Especificar um caminho para pesquisas de arquivo. |
| SET SAFETY Command | Exibir uma caixa de diálogo antes de substituir um arquivo existente, ou avaliar regras de tabela ou campo, valores padrão e mensagens de erro quando alterações são feitas no Table Designer ou com ALTER TABLE. |
| SET VIEW Command | Abrir ou fechar a janela Data Session ou restaurar o ambiente do Visual FoxPro a partir de um arquivo de view. |
| STRTOFILE( ) Function | Gravar o conteúdo de uma cadeia de caracteres em um arquivo. |
| SYS(3) - Legal File Name | Retornar um nome de arquivo válido que pode ser usado para criar arquivos temporários. |
| SYS(2000) - File Name Wildcard Match | Retornar o nome do primeiro arquivo em ordem alfabética por nome de arquivo e extensão que corresponde a um esqueleto de nome de arquivo. |
| SYS(2014) - Minimum Path | Retorna o caminho mínimo relativo ao diretório atual ou especificado para um arquivo especificado. |
| TYPE Command | Exibir o conteúdo de um arquivo. |
