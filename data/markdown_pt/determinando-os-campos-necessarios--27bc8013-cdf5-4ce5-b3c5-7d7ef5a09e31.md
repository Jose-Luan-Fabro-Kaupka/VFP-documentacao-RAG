# Determinando os campos necessários

Para determinar os campos de uma tabela, decida o que você precisa saber sobre as pessoas, coisas ou eventos registrados nela. Você pode considerar os campos como atributos da tabela. Cada registro (ou linha) contém o mesmo conjunto de campos ou atributos. Por exemplo, um campo de endereço em uma tabela de clientes contém os endereços dos clientes. Cada registro contém dados sobre um cliente, e o campo de endereço contém o endereço desse cliente.
