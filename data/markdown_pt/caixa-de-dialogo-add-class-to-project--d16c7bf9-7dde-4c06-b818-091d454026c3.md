# Caixa de diálogo Add Class to Project

Adiciona uma classe do Component Gallery a um projeto.
 **Adicionar classe ao projeto**
Adiciona a classe ao projeto.
**Criar nova classe a partir da classe selecionada**
Cria uma nova classe e, em seguida, adiciona a nova classe a um projeto. A caixa de diálogo New Class é exibida, permitindo que você especifique um nome para a nova classe e a biblioteca de classes na qual a nova classe é armazenada.
**Criar novo formulário a partir da classe selecionada**
Adiciona um formulário ao projeto. Esta opção está disponível apenas ao adicionar um formulário ao projeto.
