# Como: adicionar bancos de dados a projetos

Você pode adicionar bancos de dados a um projeto para um aplicativo.

### Para adicionar um banco de dados a um projeto
- Abra o projeto na Project Manager Window.
- No Project Manager, expanda o nó Data.
- Clique no nó Databases e, em seguida, em Add.
- Na caixa de diálogo Select database name, navegue até e selecione o arquivo de banco de dados (.dbc) do banco de dados que deseja adicionar e clique em OK. O banco de dados selecionado aparece no nó Databases do Project Manager.
