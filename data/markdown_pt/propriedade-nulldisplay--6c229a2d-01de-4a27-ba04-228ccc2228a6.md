# Propriedade NullDisplay

Especifica o texto que é exibido para indicar valores nulos. Disponível em tempo de design e em tempo de execução.

```foxpro
Object.NullDisplay[ = cNullText]
```

# Valor de retorno
 **cNullText**
Especifica o texto que é exibido para valores nulos. .NULL. é o valor padrão.

# Observações

Aplica-se a: ComboBox Control | EditBox Control | ListBox Control | Spinner Control | TextBox Control (Visual FoxPro)

Esta propriedade altera a exibição de nulos apenas para objetos individuais. Para alterar a exibição de nulos para todos os objetos, use SET NULLDISPLAY.
