# Função FFLUSH( )

Grava em disco um arquivo aberto com uma função de baixo nível.

```foxpro
FFLUSH(nFileHandle [, lForce])
```

#### Parâmetros
 **nFileHandle**
Especifica o identificador de arquivo do arquivo a gravar em disco.
**lForce**
Se você especificar um valor lógico true (.T.) para lForce , o Windows é usado para gravar imediatamente o arquivo em disco. Se você especificar um valor lógico false (.F.) (o padrão se lForce for omitido), o Visual FoxPro grava o arquivo em disco na primeira oportunidade.

# Valor de retorno

Logical

# Observações

FFLUSH( ) também libera a memória usada pelo buffer do arquivo.

FLUSH é diferente da função FFLUSH( ). FLUSH não opera em arquivos de baixo nível, mas em tabelas e índices.

# Exemplo

O exemplo a seguir abre e grava em um arquivo chamado Input.dat. Após gravar as duas primeiras cadeias de caracteres, o programa grava os buffers para garantir que as cadeias de caracteres sejam gravadas em disco. Em seguida, grava as duas próximas cadeias de caracteres, grava os buffers novamente e fecha o arquivo.

```foxpro
IF FILE('input.dat')
   gnTestFile = FOPEN('input.dat',2)
ELSE
   gnTestFile = FCREATE('input.dat')
ENDIF
gnIOBytes = FWRITE(gnTestFile,'Test output')
gnIOBytes = FWRITE(gnTestFile,' for low-level file I/O')
glFlushOk = FFLUSH(gnTestFile, .T.)
gnIOBytes = FWRITE(gnTestFile,'Test output2')
gnIOBytes = FWRITE(gnTestFile,' for low-level file I/O')
glFlushOk = FFLUSH(gnTestFile)
glCloseOk = FCLOSE(gnTestFile)
MODIFY FILE input.dat NOWAIT NOEDIT
```
