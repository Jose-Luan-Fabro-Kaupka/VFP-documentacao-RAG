# Programas utilitários

Essas ferramentas são fornecidas com o Microsoft Visual FoxPro para ajudar a acelerar o processo de desenvolvimento de aplicações.

# Nesta seção
 **How to: Add a Label Definition Using Addlabel.app**
Adiciona tamanhos de etiqueta à caixa de diálogo New Label no Label designer.
**Code Analyzer**
Fornece controles visuais, um menu e opções de teclado para navegar pelo código de arquivos de aplicação usando a saída do Documenting wizard.
**Cpzero.prg**
Remove a marca de página de código de qualquer arquivo que tenha estrutura de arquivo de tabela.
**Filer.dll**
Suporta os recursos mais populares do Filer, incluindo suporte para pesquisar arquivos por cadeias de caracteres de texto e abrir vários arquivos para edição.
**Gendbc.prg**
Gera um programa que pode recriar um banco de dados.
**Genhtml.prg**
Gera uma página Web baseada em dados em uma tabela.
**HexEdit**
Examina ou altera valores de endereço, byte e ASCII de dados em um arquivo.
