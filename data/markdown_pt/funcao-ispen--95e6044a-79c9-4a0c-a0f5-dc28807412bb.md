# Função ISPEN( )

Determina se o último evento de mouse do Tablet PC foi um toque com a caneta.

```foxpro
ISPEN()
```

# Observações

A função ISPEN( ) retorna um valor lógico true (.T.) se o último evento de mouse do Tablet PC foi um toque com a caneta. Um valor lógico false (.F.) é retornado se o último evento de mouse não foi um toque com a caneta.
