# Caixa de diálogo Organizar Tabelas e Exibições

Esta caixa de diálogo permite alterar o layout de tabelas e exibições no seu banco de dados. Use-a para organizar, alinhar ou redimensionar as tabelas e exibições no layout do banco de dados. Para obter mais informações, consulte Como: organizar tabelas e exibições em bancos de dados.

Esta caixa de diálogo aparece quando você seleciona Organizar no menu Banco de dados.

# Organizar

Essas opções permitem ordenar o conteúdo do layout do banco de dados.
 **Por nome**
Ordena as tabelas e exibições por nome.
**Por tipo**
Ordena as tabelas juntas e as exibições juntas.

# Alinhar objetos

Essas opções permitem posicionar o conteúdo do layout do banco de dados em linha.
 **Verticalmente**
Posiciona os objetos em linha verticalmente na janela Database Designer.
**Horizontalmente**
Posiciona os objetos em linha horizontalmente na janela Database Designer.
**Redimensionar objetos para altura e largura padrão**
Por padrão, os objetos no banco de dados exibem cinco dos campos. Se você alterou o tamanho dos objetos para visualizar mais do conteúdo do objeto, pode retornar ao tamanho padrão.
