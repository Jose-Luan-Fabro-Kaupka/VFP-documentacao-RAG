# Funções DDE

Troca dados entre o Visual FoxPro e outros aplicativos baseados em Microsoft Windows.

# Observações

O Visual FoxPro pode atuar tanto como servidor quanto como cliente para enviar e receber dados de e para outros aplicativos baseados em Microsoft Windows.

As seguintes convenções de nomenclatura são usadas em aplicativos que suportam DDE (dynamic data exchange).

| Name | Description |
| --- | --- |
| Service Name | Um nome ao qual o servidor responde quando um cliente tenta acessar o servidor. Um servidor pode suportar muitos nomes de serviço. |
| Topic Name | Um nome que especifica um conjunto lógico de dados. Para aplicativos baseados em arquivo, nomes de tópico geralmente são nomes de arquivo. Em outros aplicativos, nomes de tópico são específicos do aplicativo. Para acessar o servidor, o cliente deve especificar um nome de tópico além do nome de serviço do servidor. |
| Item Name | Um nome que especifica uma unidade de dados que o servidor pode passar ao cliente que solicita os dados. |

Para solicitar dados de outro aplicativo, crie um programa Visual FoxPro que estabeleça o Visual FoxPro como cliente. O seguinte é um breve esboço para criar um programa Visual FoxPro simples que solicita dados de outro aplicativo:
 - Estabeleça um link para o aplicativo servidor com DDEInitiate( ) .
- Se o link for estabelecido com sucesso, use DDERequest( ) para solicitar dados do aplicativo servidor. DDERequest( ) pode ser emitido repetidamente para solicitar dados adicionais.
- Depois que os dados foram recebidos, emita DDETerminate( ) para encerrar o link para o aplicativo servidor e liberar recursos do sistema.

As funções acima estabelecem um cold link. Um cold link existe quando o cliente inicia todas as comunicações entre os aplicativos. Para uma discussão sobre outros tipos de links, consulte DDEAdvise( ) Function.

O seguinte é um breve esboço para um programa que estabelece o Visual FoxPro como servidor:
 - Use DDESetService( ) para criar um serviço e especificar o tipo de serviço.
- Use DDESetTopic( ) para criar um tópico de serviço e especificar o procedimento a ser executado quando o tópico é especificado em uma solicitação do cliente.
- Crie o procedimento especificado em DDESetTopic( ) para aceitar os parâmetros passados ao procedimento.
- Dentro do procedimento, processe a solicitação e, se apropriado, retorne os dados solicitados ao cliente.

Observe que essas funções DDE diferem das convenções de funções anteriores do Visual FoxPro das seguintes maneiras:
 - Os primeiros quatro caracteres dessas funções não são únicos.
- Os nomes das funções excedem 10 caracteres e não podem ser abreviados. DDE Function Description DDEAbortTrans( ) Encerra uma transação DDE assíncrona. DDEAdvise( ) Cria um notify link ou um automatic link usado em DDE. DDEEnabled( ) Habilita ou desabilita o processamento DDE ou retorna o status do processamento DDE. DDEExecute( ) Usando DDE, envia um comando para outro aplicativo. DDEInitiate( ) Estabelece um canal DDE entre o Visual FoxPro e outro aplicativo baseado em Microsoft Windows. DDELastError( ) Retorna um número de erro para a última função DDE. DDEPoke( ) Envia dados entre aplicativos cliente e servidor em uma conversa DDE. DDERequest( ) Solicita dados de um aplicativo servidor em uma conversa DDE dinâmica. DDESetOption( ) Altera ou retorna configurações DDE. DDESetService( ) Cria, libera ou modifica nomes de serviço e configurações no Visual FoxPro. DDESetTopic( ) Em uma conversa DDE, cria ou libera um nome de tópico de um nome de serviço. DDETerminate( ) Fecha um canal DDE estabelecido com DDEInitiate( ).
