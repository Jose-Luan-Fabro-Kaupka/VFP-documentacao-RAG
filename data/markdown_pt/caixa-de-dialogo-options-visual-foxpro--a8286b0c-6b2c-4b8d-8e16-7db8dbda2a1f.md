# Caixa de diálogo Options (Visual FoxPro)

Permite definir diferentes categorias de opções. A caixa de diálogo Options aparece quando você seleciona Options no menu Tools.

Quando você clica em Set As Default, o Visual FoxPro salva todas as opções em todas as guias.

A tabela a seguir descreve as guias que aparecem na caixa de diálogo Options.

| Guia | Opções disponíveis |
| --- | --- |
| Controls Tab, Options Dialog Box | Define opções para as bibliotecas de classes visuais e controles ActiveX a disponibilizar no botão View Classes da barra de ferramentas Form Controls. |
| Data Tab, Options Dialog Box | Define opções de tabela, como se deve usar Rushmore Query Optimization, impor registros exclusivos em índices e especificar a sequência de ordenação, tamanho de bloco memo, intervalo do contador de registros para pesquisas e opções de bloqueio/buffering a usar. |
| Debug Tab, Options Dialog Box | Define opções de exibição e trace do debugger, como janelas, fonte e cores. |
| Editor Tab, Options Dialog Box | Define opções de fonte e cor para identificar elementos de programa, como comentários e palavras-chave na janela Command e em todas as janelas de edição, exceto aquelas abertas com os comandos MODIFY FILE ou MODIFY MEMO. |
| Field Mapping Tab, Options Dialog Box | Define opções para os controles a criar ao arrastar tabelas ou campos para um formulário a partir do Data Environment Designer, Database Designer ou Project Manager Window. |
| File Locations Tab, Options Dialog Box | Define locais para o diretório padrão do Visual FoxPro, onde a Ajuda é armazenada e onde arquivos auxiliares são armazenados. |
| Forms Tab, Options Dialog Box | Define opções do Form Designer, como o espaçamento da grade, as unidades de escala a usar, a área de design máxima e quais classes de modelo usar. |
| General Tab, Options Dialog Box | Define opções de entrada de dados e programação, como especificar o som de aviso, se deve registrar erros de compilação, se deve preencher automaticamente novos registros, quais teclas de navegação usar, qual paleta de cores usar e se deve avisar antes de sobrescrever arquivos. |
| IDE Tab, Options Dialog Box | Define configurações de formatação, aparência e comportamento para tipos de arquivo Visual FoxPro. |
| Projects Tab, Options Dialog Box | Define opções do Project Manager, como se deve solicitar wizards, se deve executar ou modificar arquivos ao clicar duas vezes e opções para controle de origem. Para obter mais informações, consulte Project Manager Window. |
| Regional Tab, Options Dialog Box | Define formatos para datas, horas, moeda e números. |
| Remote Data Tab, Options Dialog Box | Define opções de acesso a dados remotos, como valores de timeout de conexão, o número de registros a buscar de uma vez e como usar SQL para atualizações. |
| Reports Tab, Options Dialog Box | Configura definições para o Report Designer ao criar relatórios. |
| View Tab, Options Dialog Box | Define opções de interface, como se deve exibir uma barra de status, relógio, resultados de comando, mensagens do sistema ou uma lista de projetos usados recentemente. |
