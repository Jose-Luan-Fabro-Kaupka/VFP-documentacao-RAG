# Classe base Password Dialog Box Foundation

Esta classe é uma caixa de diálogo simples de login com senha para aplicativos personalizados.

| Categoria | Misc Forms |
| --- | --- |
| Catálogo padrão | Visual FoxPro Catalog\Foundation Classes\Dialogs |
| Classe | _login |
| Classe base | Form |
| Biblioteca de classes | _dialogs.vcx |
| Classe pai | _form |
| Exemplo | ...\Samples\Solution\Ffc\dialogs.scx |

# Observações

Para usar, solte a classe em um projeto ou, no menu de atalho Item da Component Gallery, selecione Create Form ou Add to Project. Quando você solta a classe em um projeto, pode escolher entre adicionar a classe, criar uma subclasse ou criar um formulário. Se você escolher Create a new form from the selected class, o Visual FoxPro abre um construtor para que você possa especificar o nome do formulário de login e depois cria e abre o formulário no Form Designer.

| Propriedades, eventos, métodos | Descrição |
| --- | --- |
| Propriedade cAlias | Especifica o alias da tabela de senhas. Padrão: "" |
| Propriedade cFieldName | Especifica o nome do campo que contém o nome do usuário. Padrão: "" |
| Propriedade cPassword | Especifica o nome do campo que contém a senha do usuário. Padrão: "" |
| Propriedade cTable | Especifica o nome da tabela que contém as informações de senha do usuário. Padrão: "" |
