# Caixa de Diálogo Nova View Remota

Esta caixa de diálogo permite criar uma nova view remota usando o View Designer ou o Assistente de View Remota.

> **Observação:** Antes de criar uma nova view remota, você deve estabelecer uma conexão ou fonte de dados ODBC. Para estabelecer uma conexão, use o Connection Designer.

Para obter mais informações, consulte Trabalhando com views (Visual FoxPro).
 **Assistente de View**
Abre o assistente de View Remota, que cria uma view remota.
**Nova View**
Abre a caixa de diálogo Selecionar Conexão ou Fonte de Dados para que você possa selecionar uma fonte de dados remota para usar em sua view remota. Para obter mais informações, consulte Caixa de Diálogo Selecionar Conexão ou Fonte de Dados .
