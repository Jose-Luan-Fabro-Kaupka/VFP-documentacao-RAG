# Linguagem de manipulação de tabelas

Esses comandos e funções tornam possível criar, manipular e monitorar arquivos de tabela.

| Use | Para |
| --- | --- |
| Comando ADD TABLE | Adicionar uma tabela livre ao banco de dados atual. |
| Função ALINES( ) | Copiar cada linha em um campo memo para uma linha correspondente em uma matriz. |
| Comando ALTER TABLE - SQL | Modificar a estrutura de uma tabela. |
| Comando APPEND | Adicionar registros ao final de uma tabela. |
| Função AUSED( ) | Colocar aliases de tabela e áreas de trabalho para uma sessão de dados em uma matriz de variáveis. |
| Comando AVERAGE | Calcular a média aritmética de expressões numéricas ou campos. |
| Comando BEGIN TRANSACTION | Iniciar uma transação. |
| Comando BROWSE | Abrir a janela browse e exibir registros de uma tabela. |
| Comando CHANGE | Exibir campos para edição. |
| Comandos CLOSE | Fechar tabelas abertas. |
| Comando COPY MEMO | Copiar o conteúdo de um campo memo para um arquivo de texto. |
| Comando COPY STRUCTURE | Criar uma nova tabela vazia com a mesma estrutura da tabela atualmente selecionada. |
| Comando COPY STRUCTURE EXTENDED | Criar uma nova tabela com campos contendo a estrutura da tabela atualmente selecionada. |
| Comando COPY TO | Criar um novo arquivo a partir do conteúdo de uma tabela. |
| Comando COUNT | Contar registros da tabela. |
| Função CPCURRENT( ) | Retornar as configurações atuais de página de código. |
| Função CPDBF( ) | Retornar as informações de página de código com as quais uma tabela foi marcada. |
| Comando CREATE | Criar uma nova tabela. |
| Comando CREATE FROM | Criar uma tabela a partir de uma tabela criada com o comando COPY STRUCTURE EXTENDED. |
| Comando CREATE QUERY | Abrir o Query designer. |
| Comando CREATE TABLE - SQL | Criar uma nova tabela. |
| Função CURVAL( ) | Retornar valores de campo. |
| Comando DELETE | Marcar registros para exclusão. |
| Comando DELETE - SQL | Marcar registros para exclusão. |
| Função DELETED( ) | Determinar se um registro está marcado para exclusão. |
| Comando DISPLAY STRUCTURE | Exibir a estrutura de uma tabela. |
| Comando DISPLAY TABLES | Exibir os nomes e informações sobre todas as tabelas em um banco de dados. |
| Comando EDIT | Exibir campos para edição. |
| Comando END TRANSACTION | Encerrar uma transação. |
| Comando EXPORT | Copiar dados de uma tabela para um arquivo em um formato diferente. |
| Comando FLUSH | Salvar alterações de tabela e índice no disco. |
| Função GETFLDSTATE( ) | Retornar um valor numérico indicando o status de um campo em uma tabela ou cursor. |
| Função GETNEXTMODIFIED( ) | Obter o número do registro do próximo registro modificado em uma tabela ou cursor em buffer. |
| Comando IMPORT | Importar dados de um formato de arquivo externo para criar uma nova tabela. |
| Função ISEXCLUSIVE( ) | Determinar se uma tabela está aberta de forma exclusiva. |
| Função ISREADONLY( ) | Determinar se uma tabela está aberta como somente leitura. |
| Comando LIST TABLES | Exibir os nomes e informações sobre todas as tabelas em um banco de dados |
| Função MEMLINES( ) | Retornar o número de linhas em um campo memo. |
| Função MLINE( ) | Retornar uma linha específica em um memo como uma cadeia de caracteres |
| Comando MODIFY GENERAL | Abrir janelas de edição para campos general no registro atual. |
| Comando MODIFY MEMO | Abrir uma janela de edição para um campo memo ou blob na janela atual. |
| Comando MODIFY QUERY | Abrir o Query Designer. |
| Comando MODIFY STRUCTURE | Exibir o Table Designer. |
| Função OLDVAL( ) | Retornar os valores originais para campos que foram modificados, mas não atualizados. |
| Comando PACK | Remover permanentemente todos os registros em uma tabela que foram marcados para exclusão e reduzir o tamanho de um arquivo memo associado à tabela. |
| Comando RECALL | Desmarcar registros marcados para exclusão em uma tabela. |
| Função REFRESH( ) | Atualizar dados em uma view SQL remota ou local atualizável, ou cursor CursorAdapter. |
| Comando REMOVE TABLE | Remover uma tabela do banco de dados atual. |
| Comando REPLACE (Visual FoxPro) | Atualizar registros da tabela. |
| Comando REPLACE FROM ARRAY | Atualizar dados em campos com valores de uma matriz de variáveis. |
| Comando RENAME TABLE | Renomear uma tabela. |
| Comando ROLLBACK | Cancelar quaisquer alterações feitas durante a transação atual. |
| Comando SELECT | Ativar a área de trabalho especificada. |
| Comando SELECT - SQL | Recuperar dados de uma ou mais tabelas. |
| Comando SET ANSI | Determinar se uma cadeia de caracteres mais curta deve ser preenchida com espaços ao fazer uma comparação de cadeia de caracteres SQL ou uma expressão binária com bytes zero (0) ao fazer uma comparação de expressão binária em comandos SQL usando o operador de igual (=). |
| Comando SET AUTOSAVE | Determinar se o Visual FoxPro grava buffers de dados no disco quando você sai de um READ ou retorna à janela Command. |
| Comando SET DATASESSION | Ativar uma sessão de dados de formulários especificada. |
| Comando SET DELETED | Especificar se o Visual FoxPro processa registros marcados para exclusão e se estão disponíveis para uso com outros comandos. |
| Comando SET FIELDS | Especificar quais campos em uma tabela podem ser acessados. |
| Comando SET NULL | Especificar como valores null são suportados por vários comandos. |
| Comando SET OLEOBJECT | Especificar se o Visual FoxPro pesquisa o registro quando um objeto não pode ser localizado. |
| Comando SET OPTIMIZE | Habilitar ou desabilitar a otimização de consulta Rushmore. |
| Comando SORT | Ordenar registros em uma tabela e enviar os registros ordenados para uma nova tabela. |
| Comando SUM | Totalizar campos numéricos em uma tabela. |
| SYS(2029) - Tipo de tabela | Retornar um valor correspondente ao tipo de tabela. |
| Função TABLEREVERT( ) | Descartar alterações feitas em uma linha em buffer ou uma tabela ou cursor em buffer e restaurar os dados OLDVAL( ). |
| Função TABLEUPDATE( ) | Confirmar alterações feitas em uma linha em buffer, uma tabela em buffer ou um cursor adapter. |
| Comando TOTAL | Calcular totais para campos numéricos em uma tabela. |
| Função TXNLEVEL( ) | Retornar um valor numérico indicando o nível de transação atual. |
| Comando UPDATE - SQL | Atualizar registros em uma tabela com novos valores. |
| Comando USE | Abrir uma tabela. |
| Função USED( ) | Determinar se um alias está em uso ou se uma tabela está aberta em uma área de trabalho específica. |
| Comando ZAP | Remover todos os registros de uma tabela, deixando apenas a estrutura da tabela. |
