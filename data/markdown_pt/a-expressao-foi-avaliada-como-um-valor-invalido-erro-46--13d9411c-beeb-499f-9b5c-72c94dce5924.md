# A expressão foi avaliada como um valor inválido (Erro 46)

Ocorre quando uma expressão especificada por Comando SET MEMOWIDTH, Comando BROWSE ou por um comando @ ... TO é avaliada como um valor inválido.

-ou-

Ocorre quando o valor especificado para as propriedades LockColumns ou LockColumnsLeft é maior que o número de colunas visíveis em um painel de grade.
