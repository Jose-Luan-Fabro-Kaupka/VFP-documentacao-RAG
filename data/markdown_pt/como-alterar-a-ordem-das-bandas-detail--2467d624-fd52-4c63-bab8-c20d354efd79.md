# Como: alterar a ordem das bandas Detail

Você pode alterar a ordem em que as bandas Detail aparecem no layout de página do relatório ou da etiqueta.

> **Observação:** Se a variável de sistema _REPORTBUILDER não estiver definida para o Report Builder padrão, talvez você não consiga alterar a ordem das bandas Detail depois de adicioná-las. Para mais informações, consulte _REPORTBUILDER System Variable.

### Para alterar a ordem das bandas Detail
- Abra o relatório ou a etiqueta para edição no designer apropriado.
- No menu Report, clique em Optional Bands. A caixa de diálogo Report Properties é aberta. Observação Se a variável de sistema _REPORTBUILDER não estiver definida para o Report Builder padrão, a caixa de diálogo Optional Bands é aberta em vez disso. Se _REPORTBUILDER estiver definido para um builder de terceiros, uma caixa de diálogo diferente pode ser exibida. Para mais informações, consulte Optional Bands Dialog Box.
- Na caixa de diálogo Report Properties, clique na guia Optional Bands.
- Na área Detail bands, arraste o botão de movimentação ao lado da banda Detail desejada para a posição desejada na lista.

Para mais informações, consulte Optional Bands Tab, Report Properties Dialog Box (Report Builder).
