# Comando UNLOCK

Libera um bloqueio de registro, vários bloqueios de registro ou um bloqueio de arquivo de uma tabela, ou libera todos os bloqueios de registros e arquivos de todas as tabelas abertas.

```foxpro
UNLOCK    [RECORD nRecordNumber]   [IN nWorkArea | cTableAlias]   [ALL]
```

#### Parâmetros
 **RECORD nRecordNumber**
Libera o bloqueio do registro de número nRecordNumber. Você pode especificar 0 para nRecordNumber a fim de desbloquear um cabeçalho de tabela bloqueado com LOCK("0", <alias>) ou RLOCK("0", <alias>). Emitir UNLOCK RECORD nRecordNumber para um registro em uma tabela com bloqueio de arquivo libera o bloqueio do arquivo.
**IN nWorkArea | cTableAlias**
Libera um ou mais bloqueios de registro ou um bloqueio de arquivo de uma tabela em uma área de trabalho específica. nWorkArea especifica o número de uma área de trabalho e cTableAlias especifica um alias de tabela. Se você não incluir nWorkArea nem cTableAlias, UNLOCK liberará um ou mais bloqueios de registro ou um bloqueio de arquivo da tabela na área de trabalho selecionada no momento.
**ALL**
Libera todos os bloqueios de registros e arquivos em todas as áreas de trabalho. Para obter mais informações sobre bloqueio de registros e arquivos e compartilhamento de tabelas em uma rede, consulte Programação para acesso compartilhado.

# Observações

Os bloqueios de registros e arquivos só podem ser removidos de uma tabela pelo usuário que os criou. UNLOCK não pode desbloquear uma tabela aberta para uso exclusivo.

Um ou mais bloqueios de registro ou um bloqueio de arquivo serão liberados da tabela na área de trabalho atual se você emitir UNLOCK sem argumentos adicionais.

Se houver relações estabelecidas entre tabelas, liberar um ou mais bloqueios de registro ou um bloqueio de arquivo de uma das tabelas não libera os bloqueios dos registros ou arquivos relacionados. Você deve liberar explicitamente os bloqueios de registros ou arquivos em cada um dos arquivos relacionados. É possível liberar todos os bloqueios de qualquer tabela relacionada emitindo UNLOCK ALL (isso também libera bloqueios em arquivos não relacionados).

# Exemplo

```foxpro
CLOSE DATABASES
SET REPROCESS TO 3 AUTOMATIC
STORE '1,2,3,4' TO gcRecList     && Lock records 1 through 4
gcOldExc = SET('EXCLUSIVE')     && Save the EXCLUSIVE setting
SET EXCLUSIVE OFF  && Allow sharing of tables
CLOSE DATABASES
OPEN DATABASE (HOME(2) + 'Data\testdata')
USE customer  && Opens Customer table
SELECT 0
USE employee  && Opens Employee table
? LOCK('1,2,3,4', 'customer')  && Lock the first 4 records in customer
? RLOCK(gcRecList, 'employee') && Lock the first 4 records in employee
UNLOCK IN customer
UNLOCK IN employee
SET EXCLUSIVE &gcOldExc  && Restore original EXCLUSIVE setting
```
