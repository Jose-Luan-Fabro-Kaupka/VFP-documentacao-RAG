# Propriedade ProgID (Visual FoxPro)

Contém o PROGID (Identificador Programático) registrado de um servidor em um projeto. Somente leitura em tempo de design e de execução.

```foxpro
Object.ProgID
```

# Observações

Aplica-se a: Objeto Server

Um PROGID é criado no Registro do Windows para um servidor quando você compila um arquivo executável (.exe) ou uma biblioteca de vínculo dinâmico (.dll) a partir de um projeto.
