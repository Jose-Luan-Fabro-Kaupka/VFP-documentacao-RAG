# Função CTOT( )

Retorna um valor DateTime de uma expressão de caracteres.

```foxpro
CTOT(cCharacterExpression)
```

#### Parâmetros
 **cCharacterExpression**
Especifica a expressão de caracteres da qual um valor DateTime é retornado.

# Valor de retorno

DateTime. CTOT( ) retorna um valor DateTime de uma expressão de caracteres.

# Observações

> **Observação:** CTOT() pode criar valores DateTime ambíguos e gera um erro de compilação quando SET STRICTDATE está definido como 2. Para criar valores Date não ambíguos, use a função DATETIME( ) em vez disso.

O Visual FoxPro suporta os tipos de dados SQL nativos Datetime e Smalldatetime, que são retornados em formato de 24 horas em SQL XML.

> **Observação:** A função CTOT() não aborda as 19 maneiras diferentes pelas quais a função T-SQL Convert() retorna valores datetime e smalldatetime.

Para converter formatos de data do Access, SQL Server, Visual Studio e XML, você deve chamar a configuração SET DATE apropriada para interpretar cadeias de caracteres DateTime corretamente. No entanto, se um T maiúsculo estiver na cadeia de caracteres de data XML, o Visual FoxPro substitui a configuração de data atual chamando internamente SET DATE YMD e restaura a configuração de data atual ao sair de CTOT( ).

> **Observação:** CTOT( ) resolve essas datas aos limites de precisão do tipo de dados DateTime do Visual FoxPro. Portanto, a precisão pode ser perdida ao usar CTOT( ) com certos formatos. O tipo de dados DateTime do Visual FoxPro não suporta milissegundos ou fusos horários.

CTOT( ) respeita a configuração do comando SET CENTURY. Para mais informações, consulte SET CENTURY Command.

# Exemplos

Os exemplos a seguir mostram como CTOT( ) trata valores DateTime de diferentes fontes. Em todos os exemplos, CTOT( ) converte os valores DateTime corretamente sem precisar chamar SET DATE YMD.
 - Access 2000 XML date format * 2000-10-24T13:30:00 (24-hour format is exported from Access, * whether original was in 12- or 24-hour format) ? CTOT("2000-10-24T13:30:00")
- SQL Server 2000 XML date format ? CTOT("2000-10-24T20:47:58.170") && datetime (24-hour format) ? CTOT("2000-10-24T21:11:00") && Small DT (24-hour format) ? CTOT("2000-10-03T02:02:02")
- Visual Studio XML ? CTOT("2002-10-05T04:04:04.0000000-07:00")
- Simple Object Access Protocol (SOAP) ? CTOT("2001-09-14T07:00:00Z")
