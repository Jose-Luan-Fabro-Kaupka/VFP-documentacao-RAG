# Comandos e funções de janelas

Esses comandos e funções permitem criar, exibir e ativar janelas definidas pelo usuário.

| Use | Para |
| --- | --- |
| ACTIVATE WINDOW Command | Exibir e ativar uma ou mais janelas definidas pelo usuário ou janelas do sistema Visual FoxPro. |
| BorderStyle Property | Especificar o estilo de borda de um objeto. |
| CLEAR Commands | Liberar da memória o item ou itens especificados. |
| CREATE FORM Command | Abrir o Form Designer . |
| DEACTIVATE WINDOW Command | Desativar janelas definidas pelo usuário ou janelas do sistema Visual FoxPro e removê-las da tela, mas não da memória. |
| DEFINE WINDOW Command | Criar uma janela e especificar seus atributos. |
| HIDE WINDOW Command | Ocultar uma janela definida pelo usuário ativa ou uma janela do sistema Microsoft Visual FoxPro. |
| MODIFY FORM Command | Abrir o Form Designer para modificar ou criar um formulário. |
| MODIFY WINDOW Command | Modificar uma janela definida pelo usuário ou a janela principal do Visual FoxPro. |
| MOVE WINDOW Command | Mover uma janela definida pelo usuário criada com DEFINE WINDOW, ou uma janela do sistema Visual FoxPro, para um novo local. |
| Refresh Method | Repintar um formulário ou controle e atualizar quaisquer valores, ou atualizar a exibição visual de um projeto. |
| RELEASE WINDOWS Command | Remover janelas definidas pelo usuário ou janelas do sistema Visual FoxPro da memória. |
| RESTORE WINDOW Command | Restaurar na memória definições de janela e status de janela salvos em um arquivo de janela ou campo memo. |
| SAVE WINDOWS Command | Salvar todas ou as definições de janela especificadas em um arquivo de janela ou campo memo. |
| SHOW WINDOW Command | Exibir uma ou mais janelas definidas pelo usuário ou janelas do sistema Visual FoxPro sem ativá-las. |
| SIZE WINDOW Command | Alterar o tamanho de uma janela criada com DEFINE WINDOW ou uma janela do sistema Visual FoxPro. |
| TextBox Control | Criar uma caixa de texto. |
| WBORDER( ) Function | Determinar se a janela ativa ou especificada tem uma borda. |
| WCHILD( ) Function | Retornar o número de janelas filhas em uma janela pai ou os nomes das janelas filhas na ordem em que estão empilhadas na janela pai. |
| WCOLS( ) Function | Retornar o número de colunas na janela ativa ou especificada. |
| WEXIST( ) Function | Determinar se a janela definida pelo usuário especificada existe. |
| WFONT( ) Function | Retornar o nome, tamanho ou estilo da fonte atual para uma janela no Visual FoxPro for Windows. |
| WLAST( ) Function | Retornar o nome da janela que estava ativa antes da janela atual ou determinar se a janela especificada estava ativa antes da janela atual. |
| WLCOL( ) Function | Retornar a coordenada de coluna do canto superior esquerdo da janela ativa ou especificada. |
| WLROW( ) Function | Retornar a coordenada de linha do canto superior esquerdo da janela ativa ou especificada. |
| WMAXIMUM( ) Function | Determinar se a janela ativa ou especificada está maximizada. |
| WMINIMUM( ) Function | Determinar se a janela ativa ou especificada está minimizada. |
| WONTOP( ) Function | Determinar se a janela ativa ou especificada está na frente de todas as outras janelas. |
| WOUTPUT( ) Function | Determinar se a saída está sendo direcionada para a janela ativa ou especificada. |
| WPARENT( ) Function | Retornar o nome da janela pai da janela ativa ou especificada. |
| WREAD( ) Function | Incluída para compatibilidade com versões anteriores. Use o Form Designer em vez disso. |
| WROWS( ) Function | Retornar o número de linhas na janela ativa ou especificada. |
| WTITLE( ) Function | Retornar o título atribuído à janela ativa ou especificada. |
| WVISIBLE( ) Function | Determinar se a janela especificada foi ativada e não está oculta. |
| ZOOM WINDOW Command | Alterar o tamanho e a posição de uma janela definida pelo usuário ou uma janela do sistema Visual FoxPro. |
