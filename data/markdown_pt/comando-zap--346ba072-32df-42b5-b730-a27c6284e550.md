# Comando ZAP

Remove todos os registros de uma tabela, deixando apenas a estrutura da tabela.

```foxpro
ZAP   [IN nWorkArea | cTableAlias]
```

#### Parâmetros
 **IN nWorkArea**
Especifica a área de trabalho da tabela na qual todos os registros são removidos.
**IN cTableAlias**
Especifica o alias da tabela na qual todos os registros são removidos. Se você omitir nWorkArea e cTableAlias, todos os registros são removidos na tabela na área de trabalho atualmente selecionada.

# Observações

Emitir ZAP é equivalente a emitir DELETE ALL seguido de PACK, mas ZAP é muito mais rápido.

Se SET SAFETY estiver ON, o Microsoft Visual FoxPro pergunta se você deseja remover os registros da tabela atual.

Emitir ZAP não faz que um trigger Delete ocorra. Para obter mais informações sobre criar triggers para uma tabela, consulte Comando CREATE TRIGGER.

> **Cuidado:** Registros removidos com ZAP da tabela atual não podem ser recuperados.
