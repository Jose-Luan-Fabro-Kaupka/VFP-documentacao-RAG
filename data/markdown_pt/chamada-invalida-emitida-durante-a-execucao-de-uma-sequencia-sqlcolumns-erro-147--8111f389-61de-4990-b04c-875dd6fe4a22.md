# Chamada inválida emitida durante a execução de uma sequência SQLCOLUMNS( ) (Erro 1477)

Uma chamada inválida de função SQL pass-through (SPT) foi feita enquanto era esperada a continuação da sequência de chamadas SPT de uma chamada da função SQLCOLUMNS( ).

Chame a função SQLCANCEL( ) para cancelar a sequência SPT ou faça chamadas SPT válidas para concluir a sequência de chamadas.
