# Exemplo Display Data Reporting Output Options

Arquivo: ...\Samples\Solution\Ffc\Output.scx

Este exemplo contém as classes a seguir.

| Class | Library | Description |
| --- | --- | --- |
| _showtext | _reports.vcx | Fornece um editor de texto simples em uma caixa de diálogo que também contém botões para formatar ou salvar texto e para fechar o editor. |
| _outputdialog | _reports.vcx | Exibe uma caixa de diálogo que solicita ao usuário uma opção de saída de relatório. |

Para detalhes sobre todas as classes disponíveis nas foundation classes, consulte Visual FoxPro Foundation Classes A-Z.
