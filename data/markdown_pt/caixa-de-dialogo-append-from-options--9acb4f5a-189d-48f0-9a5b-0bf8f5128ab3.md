# Caixa de diálogo Append From Options

Especifica campos a anexar e permite que você construa uma expressão que deve ser atendida pelos registros a serem anexados. Esta caixa de diálogo aparece quando você escolhe Options na Caixa de diálogo Append From.

# Critérios
 **Fields**
Exibe a Caixa de diálogo Field Picker , onde você seleciona campos a anexar.
**For**
Exibe a Caixa de diálogo Expression Builder , onde você cria uma expressão For que todo registro deve atender para ser anexado.
