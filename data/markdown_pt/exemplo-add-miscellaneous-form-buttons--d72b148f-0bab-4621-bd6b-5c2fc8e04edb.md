# Exemplo Add Miscellaneous Form Buttons

Arquivo: ...\Samples\Solution\Ffc\Buttons.scx

Este exemplo contém as seguintes classes.

| Classe | Biblioteca | Descrição |
| --- | --- | --- |
| _shellexecute | _environ.vcx | Executa aplicativos diferentes do Visual FoxPro no shell do Windows. |
| _mailbtn | _miscbtns.vcx | Usa o controle ActiveX MAPI para enviar uma mensagem de e-mail de um formulário. |
| _cmdlaunch | _miscbtns.vcx | Fornece um botão para iniciar um aplicativo usando o comando Run. |
| _cmdok | _miscbtns.vcx | Libera um formulário e atualiza quaisquer dados em buffer pendentes. |
| _cmdcancel | _miscbtns.vcx | Libera um formulário e descarta quaisquer dados em buffer pendentes. |
| _cmdhelp | _miscbtns.vcx | Fornece um botão que exibe um tópico de Ajuda. |
| _cmdrunform | _miscbtns.vcx | Fornece um botão para executar um formulário. |
| _cmdrunreport | _miscbtns.vcx | Fornece um botão para executar um relatório. |

Este exemplo demonstra a adição de botões de comando ao seu aplicativo. Os botões de comando executam as seguintes funções:
 - Iniciar um aplicativo
- Abrir uma página Web no shell do Windows
- Exibir um formulário
- Visualizar um relatório
- Parar um programa com opções OK ou Cancel
- Exibir um tópico de Ajuda

Para detalhes sobre todas as classes disponíveis nas classes de fundação, consulte Visual FoxPro Foundation Classes A-Z.
