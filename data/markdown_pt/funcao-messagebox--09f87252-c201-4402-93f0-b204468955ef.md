# Função MESSAGEBOX( )

Exibe uma caixa de diálogo definida pelo usuário.

```foxpro
MESSAGEBOX(eMessageText [, nDialogBoxType ][, cTitleBarText][, nTimeout])
```

#### Parâmetros
 **eMessageText**
Especifica o texto exibido na caixa de diálogo. Você também pode especificar qualquer função, objeto ou tipo de dados válido do Visual FoxPro em vez de eMessageText. O máximo é 1.024 caracteres. Observação O Visual FoxPro converte referências de objeto na cadeia "(Object)". Se você especificar uma função que resulte em um valor não caractere, o Visual FoxPro usará TRANSFORM( ) automaticamente para fornecer o equivalente em caracteres. Exemplo: MESSAGEBOX(DATE()). Dica Para mover parte da mensagem para a próxima linha, use um retorno de carro, CHR(13), em eMessageText. A caixa aumenta de altura e largura conforme necessário.
**nDialogBoxType**
Especifica os botões e ícones exibidos, o botão padrão e o comportamento da caixa. Os valores de botão de 0 a 5 especificam: 0 somente OK; 1 OK e Cancel; 2 Abort, Retry e Ignore; 3 Yes, No e Cancel; 4 Yes e No; 5 Retry e Cancel. Os valores de ícone são: 16 sinal de parada; 32 ponto de interrogação; 48 exclamação; 64 informação. Os valores padrão são: 0 primeiro botão; 256 segundo; 512 terceiro. Omitir nDialogBoxType equivale a 0. nDialogBoxType pode ser a soma de até três valores, um de cada grupo. Por exemplo, 290 (2+32+256) cria botões Abort, Retry e Ignore, exibe o ícone de interrogação e define Retry como padrão. Informações adicionais sobre as constantes estão em FoxPro.h. Constantes como MB_ABORTRETRYIGNORE + MB_ICONQUESTION + MB_DEFBUTTON2 podem ser mais legíveis que 2 + 32 + 256. Observação O ícone de interrogação não é mais recomendado porque não representa claramente um tipo específico de mensagem e pode ser confundido com informações de Ajuda. O sistema continua a aceitá-lo somente para compatibilidade com versões anteriores.
**cTitleBarText**
Especifica o texto da barra de título. Se omitido, aparece "Microsoft Visual FoxPro".
**nTimeout**
Especifica por quantos milissegundos o Visual FoxPro exibe eMessageText sem entrada do teclado ou mouse antes de limpá-la. Um valor menor que 1 nunca expira até o usuário fornecer uma entrada e equivale a omitir nTimeout.

# Valor de retorno

Tipo de dados Numeric. MESSAGEBOX( ) retorna um valor que indica o botão escolhido.

| Valor de retorno | Botão |
| --- | --- |
| 1 | OK |
| 2 | Cancel |
| 3 | Abort |
| 4 | Retry |
| 5 | Ignore |
| 6 | Yes |
| 7 | No |

Em caixas com Cancel, pressionar ESC retorna o mesmo valor (2) que escolher Cancel.

MESSAGEBOX( ) retorna -1 quando ocorre um tempo limite.

# Observações

A abreviação mais curta de MESSAGEBOX( ) é MESSAGEB( ).

MESSAGEBOX( ) usa parâmetros inteligentes: o tipo determina qual parâmetro é usado. O primeiro é obrigatório e sempre corresponde a eMessageText. O segundo opcional pode ser nDialogBoxType, se Numeric, ou cTitleBarText, se Character. nTimeout é sempre considerado o segundo parâmetro numérico opcional. Exemplos válidos:

```foxpro
MESSAGEBOX("HELLO","MyTitle",68,6000)
MESSAGEBOX("HELLO",68,"MyTitle",6000)
MESSAGEBOX("HELLO",68,6000)
MESSAGEBOX("HELLO",68,6000,"MyTitle")
```

# Exemplo

O exemplo a seguir exibe uma caixa de diálogo definida pelo usuário. A mensagem "Record not found. Would you like to search again?" é exibida como legenda, e "My Application" aparece na barra de título.

A caixa contém os botões Yes e No e o ícone de parada, e o segundo botão (No) é o padrão. Ao escolher um botão, sua escolha é exibida.

```foxpro
eMessageTitle = 'My Application'
eMessageText = 'Record not found. Would you like to search again?'
nDialogType = 4 + 16 + 256
*  4 = Yes and No buttons
*  16 = Stop sign icon
*  256 = Second button is default
nAnswer = MESSAGEBOX(eMessageText, nDialogType, eMessageTitle)
DO CASE
   CASE nAnswer = 6
      WAIT WINDOW 'You chose Yes'
   CASE nAnswer = 7
      WAIT WINDOW 'You chose No'
ENDCASE
```
