# Categorias de linguagem

Esta seção contém categorias básicas que descrevem a funcionalidade do Visual FoxPro.

# Nesta seção
 **Databases**
Links para informações sobre como manipular bancos de dados, tabelas, registros e campos, bem como índices e relações.
**Input and Output (Visual FoxPro)**
Contém links para informações sobre controle de entrada e saída das suas aplicações.
**Programming**
Contém links para mais informações de programação, incluindo manipulação de matrizes, depuração e tratamento de erros, programação estruturada e assim por diante.
**Shared Access to Data**
Contém comandos e funções que permitem gerenciar vários usuários.
**Visual FoxPro Environment**
Lista comandos e funções que permitem acessar o ambiente do Visual FoxPro.

# Seções relacionadas
 **Language Reference (Visual FoxPro)**
Contém uma lista de tópicos de referência de linguagem em ordem alfabética.
**Naming Conventions**
Discute como escolher nomes para objetos, propriedades e métodos expostos que possam ser facilmente compreendidos pelos usuários da aplicação.
**Developing Visual FoxPro Applications**
Inclui informações conceituais sobre como desenvolver aplicações Visual FoxPro, instruções para criar bancos de dados e a interface do usuário e outras tarefas necessárias para criar aplicações Visual FoxPro.
**Programming in Visual FoxPro**
Discute como você pode acessar todo o poder do Visual FoxPro criando aplicações. Compreender técnicas de programação orientada a objetos e o modelo orientado a eventos pode maximizar sua produtividade de programação.
**Visual FoxPro and Other Programming Languages**
Fornece uma comparação entre Visual FoxPro e outras linguagens de programação.
