# Caixa de diálogo Conversor do Visual FoxPro

Converte arquivos criados no FoxPro 2.6 e em versões anteriores do Visual FoxPro para o formato atual do Visual FoxPro. Isso é necessário quando você deseja usar esses arquivos com versões posteriores do Visual FoxPro.

Para obter informações sobre a conversão desses arquivos mais antigos, consulte Como: converter arquivos anteriores do Visual FoxPro.
 **Manter valores de propriedade padrão do Visual FoxPro 3.0**
Aplica-se somente ao converter projetos do Visual FoxPro 3.0. As configurações de propriedade padrão de formato do Visual FoxPro para fontes e cores estão em conformidade com o Windows 98. Às vezes, elas são diferentes das configurações atuais do Visual FoxPro. Se você selecionar esta opção, seus formulários convertidos manterão as configurações de propriedade do Visual FoxPro 3.0.
**Arquivo**
Visível ao usar o aplicativo Converter.app como ferramenta de conversão. Você pode especificar o arquivo que deseja converter. Para procurar um arquivo, clique no botão de reticências (...).
**Diretório**
Visível ao usar o aplicativo Converter.app como ferramenta de conversão. Você pode converter todos os arquivos em um diretório. Quando você seleciona esta opção, pode especificar ou procurar o diretório.
**Arquivos SCX**
Habilitado quando você seleciona Diretório. Indica se você deve converter os arquivos de tela no diretório.
**Arquivos VCX**
Habilitado quando você seleciona Diretório. Indica se você deve converter os arquivos de biblioteca de classes visuais no diretório.
**Verificar subdiretórios**
Habilitado quando você seleciona Diretório. Indica se você também deve converter os arquivos nos subdiretórios do diretório especificado.
**Continuar**
Conclui o processo de conversão de arquivos. Quando você clica em Continuar, a caixa de diálogo Transportador do Visual FoxPro aparece somente quando você converte arquivos Macintosh ou MS-DOS que nunca antes contiveram registros do Windows. Para obter mais informações, consulte Caixa de diálogo Transportador do Visual FoxPro.
