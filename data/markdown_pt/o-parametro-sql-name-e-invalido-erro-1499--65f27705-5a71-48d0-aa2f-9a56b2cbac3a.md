# O parâmetro SQL "name" é inválido (Erro 1499)

A definição de parâmetro SQL em uma chamada SQLEXEC( ) ou em uma definição de view contém um erro de sintaxe.
 - Está faltando o caractere de fechamento para uma constante de cadeia de caracteres ou um parêntese direito de fechamento. Verifique a definição de parâmetro após o operador "?" na cadeia SQL e corrija a sintaxe do parâmetro.
