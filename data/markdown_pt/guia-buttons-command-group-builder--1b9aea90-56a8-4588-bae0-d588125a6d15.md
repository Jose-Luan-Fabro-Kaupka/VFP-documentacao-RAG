# Guia Buttons, Command Group Builder

Esta guia do Command Group Builder especifica o número de botões, suas legendas e elementos gráficos.
 **Number of Buttons**
Especifica o número de botões do grupo de comandos. Esta opção corresponde à propriedade ButtonCount. O intervalo é de 0 a 100.
**Caption Column**
Especifica a legenda exibida no botão. Digite-a na célula da grade. Esta opção corresponde à propriedade Caption.
**Graphic Column**
Especifica o caminho e o nome do arquivo de bitmap exibido no botão. Digite-os na caixa ou clique no botão de diálogo para abrir a caixa Open e selecionar um arquivo. Essa imagem será sempre exibida no botão de comando, independentemente do estado do botão. Esta opção corresponde à propriedade Picture. Os botões são redimensionados automaticamente para acomodar novas legendas e imagens. O contêiner do grupo também é redimensionado automaticamente e os botões vizinhos são reposicionados, se necessário, para preservar o espaçamento desejado.
