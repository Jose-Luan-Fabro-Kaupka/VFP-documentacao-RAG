# Loops WHILE (Visual FoxPro)

Você pode comparar como os loops WHILE diferem entre o Visual FoxPro e outras linguagens de programação.

| Visual FoxPro | BASIC |
| --- | --- |
| DO WHILE n < 100 n = n + n ENDDO | Do While n < 100 n = n + n Loop |

| Pascal | C/C++ |
| --- | --- |
| while n < 100 do n := n + n; | while(n < 100) n += n; |
