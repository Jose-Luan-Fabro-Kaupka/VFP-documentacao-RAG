# Método Unnest

Remove a relação hierárquica de um objeto XMLTable aninhado, mantendo os XMLTables aninhados.

```foxpro
XMLTable.Unnest()
```

# Observações

Aplica-se a: XMLTable Class

Se um objeto XMLTable estiver aninhado usando o Nest Method, o método Unnest remove a relação hierárquica com o XMLTable. Se o XMLTable não estiver atualmente aninhado, o método Unnest não faz nada.
