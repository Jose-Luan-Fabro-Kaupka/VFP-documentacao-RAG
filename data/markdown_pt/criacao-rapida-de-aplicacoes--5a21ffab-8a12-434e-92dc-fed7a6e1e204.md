# Criação rápida de aplicações

Você pode desenvolver aplicações rapidamente com a ajuda dos assistentes, builders, barras de ferramentas e designers do Visual FoxPro. Além disso, com o modelo de objetos e eventos do Visual FoxPro, você pode criar protótipos e implementar aplicações rapidamente.

# Obtendo resultados rápidos com assistentes e builders

Usando assistentes e builders, você pode ter qualquer ou todos os componentes da sua aplicação concluídos em questão de minutos. Além disso, se algum componente que você criou com um assistente ou builder não atender totalmente às suas necessidades, você pode alterar o componente usando um designer.

Para resultados rápidos, os assistentes são a resposta. Eles fornecem prompts passo a passo para tarefas comuns que você realiza no Visual FoxPro. Por exemplo, o Table Wizard orienta você no processo de criação de uma tabela, o Form Wizard cria um formulário e o Web Publishing Wizard ajuda você a criar uma página Web que pesquisa suas tabelas.

Veja o que você pode fazer:
 - Desenvolver aplicações instantâneas Usando o Application Wizard, você pode criar rapidamente uma aplicação usando suas tabelas e formulários, ou usando um conjunto de exemplo de componentes de aplicação.
- Criar uma página Web na Internet Você pode criar uma página Web que fornece aos usuários da Web acesso de pesquisa e recuperação às suas tabelas.
- Adicionar page frames a formulários Se você escolher mais campos do que cabem no formulário, pode adicionar um page frame para exibir os campos adicionais em páginas adicionais.
- Popular tabelas dinâmicas por ODBC ou OLE DB O PivotTable Wizard usa o driver ODBC ou OLE DB do Visual FoxPro.
- Mostrar nulos em um relatório de tabulação cruzada O Cross-Tab Wizard agora suporta a exibição de valores nulos.
- Mover seus dados para um servidor back-end Você pode mover bancos de dados, tabelas e views do Visual FoxPro do seu sistema para um servidor back-end com o SQL Server Upsizing Wizard.

Se você estiver com pressa, use a tabela em Assistentes (Visual FoxPro) para selecionar um assistente e começar a criar sua aplicação ou componente.

Se você não quiser experimentar com seus próprios dados e componentes de aplicação, use os exemplos fornecidos com o Visual FoxPro, localizados no diretório ...\Samples\Data.

# Atalhos com barras de ferramentas

Como outras aplicações da Microsoft, o Visual FoxPro inclui barras de ferramentas contendo botões que representam tarefas comuns que você realiza ou objetos que usa frequentemente. Para realizar uma tarefa específica ou usar um objeto particular, escolha o botão apropriado.

Você pode personalizar as barras de ferramentas que vêm com o Visual FoxPro. Você também pode definir barras de ferramentas personalizadas para as aplicações que você escreve. Para obter mais informações sobre barras de ferramentas, consulte Personalizando o ambiente do Visual FoxPro ou Projetando menus e barras de ferramentas.

# Construindo controles rapidamente

Assim como os assistentes podem ajudar a criar relatórios e formulários, os builders são ferramentas visuais que ajudam você a projetar controles conforme suas especificações. Os builders podem economizar tempo quando você está configurando muitos formulários ou criando protótipos de aplicações. Tudo o que você faz é iniciar o builder e responder a uma série de perguntas. Usando suas respostas, o builder define propriedades para o controle que você está adicionando.

Adicionar um Combo Box ao seu formulário Suponha que você deseja aprimorar um formulário simples que criou adicionando a capacidade de selecionar valores de campo de uma lista, em vez de percorrer todos os registros com botões VCR e visualizar os valores em uma caixa de texto. Basta substituir a caixa de texto atual por uma caixa de combinação e usar um builder para definir as propriedades.

Modificar controles existentes com um builder Se você deseja alterar um controle existente, pode selecionar o controle e usar um builder para ajudar a definir as propriedades do controle.

Por exemplo, o Combo Box Builder é uma caixa de diálogo com guias que ajuda você a projetar uma caixa de combinação em um formulário. Uma caixa de combinação oferece a mesma visualização de um valor que um controle de caixa de texto, mas permite escolher de uma lista como um controle de caixa de listagem. Com este builder você pode definir propriedades de uma caixa de combinação. À medida que você define cada propriedade, o controle no formulário é alterado para corresponder às configurações.

Construir um controle Grid Para exibir uma visualização semelhante a uma planilha pequena dos seus dados, você pode usar um controle Grid. Mesmo se você não estiver familiarizado com todas as propriedades de um controle Grid, ainda pode aproveitar sua funcionalidade usando um builder. O builder ajuda você a escolher os campos para sua grade, selecionar um estilo e layout e estabelecer relacionamentos entre tabelas vinculadas ao controle Grid. À medida que você faz alterações no builder, elas são refletidas no Form Designer.

Para obter mais informações, consulte Builders.
