# Guia Data, Application Builder

Nesta guia do Application Builder, especifique a fonte de dados e o formato dos formulários e relatórios do aplicativo. O grid mostra as tabelas selecionadas.
 **Database Wizard**
Cria um novo banco de dados com o assistente e lista suas tabelas e views.
**Table Wizard**
Cria uma nova tabela com o assistente.
**Select**
Seleciona um banco de dados, tabela ou view existente.
**Clear**
Remove todas as tabelas do grid.
**Generate**
Gera relatórios ou formulários a partir da tabela selecionada e dos estilos especificados.
**Form Style**
Seleciona um estilo de formulário.
**Report Style**
Seleciona um estilo de relatório. Para usar estilos diferentes, selecione os itens e estilos e gere-os em grupos.

Ao escolher OK, o builder fecha e aplica as configurações de todas as guias.
