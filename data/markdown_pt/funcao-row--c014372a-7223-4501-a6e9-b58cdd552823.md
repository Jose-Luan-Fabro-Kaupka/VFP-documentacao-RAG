# Função ROW( )

Incluída para compatibilidade com versões anteriores. Use as propriedades CurrentX, CurrentY.

Retorna a posição de linha atual do cursor.

```foxpro
ROW()
```

# Valor de retorno

Valor de retorno - Numérico

# Observações

ROW() é especialmente útil para direcionar a saída na tela para uma posição relativa à posição de linha atual do cursor.

O operador especial $ pode ser usado no lugar da função ROW().

# Exemplo

```foxpro
@ 5,5 SAY ' '
@ ROW() + 6, COL() SAY 'Contact person'
@ $ + 6, COL() SAY 'Contact person'
```
