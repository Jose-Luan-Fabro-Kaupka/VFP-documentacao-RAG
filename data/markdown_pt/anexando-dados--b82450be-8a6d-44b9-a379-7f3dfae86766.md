# Anexando dados

Você pode adicionar seus dados de texto, planilha ou tabela a uma tabela Visual FoxPro existente. Por padrão, o Visual FoxPro usa o tipo de arquivo para mapear os campos de origem para a tabela de destino. Você também pode selecionar campos e registros para anexar. Se deseja controlar o mapeamento de campos, pode usar o Import Wizard, mas as opções de seleção de campos e expressão lógica não estão disponíveis.

# Escolhendo um tipo de arquivo para anexar

A tabela a seguir lista os tipos de arquivo que você pode anexar ao Visual FoxPro:

| File Type | File Extension | Description |
| --- | --- | --- |
| Table | dbf | Uma tabela FoxPro® de um banco de dados fora do banco de dados atual ou um arquivo dBASE. |
| Tab delimited | txt | Um arquivo de texto com uma tabulação separando cada campo. |
| Comma delimited | txt | Um arquivo de texto com uma vírgula separando cada campo. |
| Space delimited | txt | Um arquivo de texto com um espaço separando cada campo. |
| System Data Format | sdf | Um arquivo de texto com registros de comprimento fixo terminando com retorno de carro e avanço de linha. |
| Microsoft Excel | xls | Um formato de planilha do Microsoft Excel (versões 2.0, 3.0, 4.0, 5.0 e 97). As células de coluna tornam-se campos e as linhas tornam-se registros. |
| Lotus 1-2-3 | wks wk1 wk3 | Uma planilha Lotus 1-2-3 para as versões 1-A, 2.x e 3.x. As células de coluna tornam-se campos e as linhas tornam-se registros. |
| Borland Paradox | db | Uma tabela Paradox para as versões 3.5 e 4.0. |

Para obter mais informações sobre como anexar arquivos, consulte o comando APPEND FROM Command.
