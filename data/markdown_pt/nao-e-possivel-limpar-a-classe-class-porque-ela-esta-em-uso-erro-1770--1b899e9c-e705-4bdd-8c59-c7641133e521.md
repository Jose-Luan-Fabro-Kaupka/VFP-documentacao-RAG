# Não é possível limpar a classe "class" porque ela está em uso. (Erro 1770)

A classe especificada não pode ser excluída de um arquivo de biblioteca .vcx enquanto sua definição estiver em uso. Esse erro pode ocorrer ao usar o comando REMOVE CLASS, a cláusula OVERWRITE do comando ADD CLASS ou o comando RENAME CLASS.
 - Execute CLEAR ALL para remover todas as referências à classe e tente novamente.
