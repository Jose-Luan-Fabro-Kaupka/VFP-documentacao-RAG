# Propriedade AllowTabs

Especifica se deve permitir tabulações em um controle EditBox.

```foxpro
EditBox.AllowTabs[ = lExpr]
```

# Valor de retorno
 **lExpr**
Especifica um valor lógico que determina se tabulações são permitidas em um controle EditBox. A tabela a seguir lista as configurações para lExpr: lExpr Descrição True (.T.) Permite tabulações na caixa de edição. Para sair do controle, pressione CTRL+TAB. False (.F.) Não permite tabulações na caixa de edição. (Padrão) Para sair e mover o foco para o próximo controle na ordem de tabulação, pressione a tecla TAB.

# Observações

Aplica-se a: EditBox Control
