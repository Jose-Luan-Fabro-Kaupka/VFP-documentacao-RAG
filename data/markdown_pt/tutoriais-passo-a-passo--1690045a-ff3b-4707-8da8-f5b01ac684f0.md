# Tutoriais passo a passo

Os tutoriais passo a passo fornecem instruções detalhadas para cenários comuns, o que os torna um bom ponto de partida para aprender sobre o Visual FoxPro ou uma área de funcionalidade específica.

# Nesta Seção
 **Tutorial passo a passo: Criar aplicativos com o Visual FoxPro**
Fornece etapas para criar um programa simples, incluindo movimentação de dados e criação de formulários, e mostra como usá-lo como base para um aplicativo.
**Tutorial passo a passo: Criar relatórios com o Visual FoxPro**
Fornece etapas para criar relatórios usando o assistente de relatórios e o designer de relatórios, e discute questões a considerar ao planejar e criar relatórios.
**Tutorial passo a passo: Recuperar dados de diferentes fontes de dados**
Fornece etapas para recuperar dados de tabelas nativas do Visual FoxPro ou de dados usando Open Database Connectivity (ODBC), ActiveX Data Objects (ADO) ou fontes de dados XML.
**Tutorial passo a passo: Criar serviços Web XML com o Visual FoxPro**
Fornece etapas para criar e publicar um servidor COM do Visual FoxPro como um serviço Web XML.
**Tutorial passo a passo: Criar um programa de instalação de aplicativo Visual FoxPro usando o InstallShield**
Fornece etapas para empacotar e implantar seus aplicativos usando o InstallShield Express, tornando possível que os usuários instalem e configurem seus produtos com eficiência.

# Seções Relacionadas
 **Usando o Visual FoxPro**
O Microsoft Visual FoxPro fornece as ferramentas necessárias para criar e gerenciar aplicativos e componentes de banco de dados de 32 bits de alto desempenho. Com suas ferramentas robustas e linguagem orientada a dados, você pode criar aplicativos modernos e escaláveis de várias camadas que integram computação cliente/servidor e a Internet.
**Desenvolvendo aplicativos Visual FoxPro**
Inclui informações conceituais sobre como desenvolver aplicativos Visual FoxPro, instruções para criar bancos de dados e a interface do usuário, e outras tarefas necessárias para criar aplicativos Visual FoxPro.
**Programação no Visual FoxPro**
Explica como compreender técnicas de programação orientada a objetos e o modelo orientado a eventos pode maximizar sua produtividade de programação para que você possa acessar todo o poder do Visual FoxPro.
**Ferramentas de produtividade para desenvolvimento**
Explica que o Visual FoxPro fornece ferramentas de desenvolvedor para desenvolvimento de aplicativos dentro do aplicativo FoxPro e da linguagem FoxPro.
**Exemplos e tutoriais passo a passo**
Fornece amplos exemplos para desenvolvimento de bancos de dados e aplicativos.
