# Variável de sistema _BROWSER

Especifica o nome do aplicativo class browser a ser usado para navegar em classes.

```foxpro
_BROWSER = cProgramName
```

#### Parâmetros
 **cProgramName**
Especifica o nome de um aplicativo class browser. Por padrão, _BROWSER é definido como Browser.app, que é instalado no mesmo diretório do Visual FoxPro. Para obter mais informações, consulte Operando o Class Browser. Observação Se o class browser estiver em um diretório ou pasta diferente do diretório ou pasta padrão atual, inclua um caminho ao especificar o nome do aplicativo class browser.
