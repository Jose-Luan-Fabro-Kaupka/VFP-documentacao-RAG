# Caixa de diálogo Nova etiqueta

Exibe tipos predefinidos de etiquetas Avery. Essa caixa aparece quando você seleciona Etiqueta na caixa de diálogo Novo e escolhe Novo arquivo. O tipo selecionado torna-se a base da nova etiqueta criada no Designer de Etiquetas. A coluna Colunas indica quantas colunas desse tipo de etiqueta cabem em uma página.

As colunas a seguir exibem informações sobre a etiqueta (essas configurações não podem ser alteradas):
 **Nº Avery**
O número de identificação do fabricante para um tipo específico de etiqueta.
**Altura**
A altura, em polegadas, de uma etiqueta individual.
**Largura**
A largura, em polegadas, de uma etiqueta individual.
**Colunas**
Quantas colunas desse tipo de etiqueta cabem em uma página de 8 1/2 x 11 polegadas. Observação: você pode adicionar um novo tamanho de etiqueta à lista usando o aplicativo ADDLABEL.APP, localizado no diretório ...\Tools do Visual FoxPro.
