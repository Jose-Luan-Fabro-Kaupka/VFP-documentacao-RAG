# Ferramentas de produtividade de desenvolvimento

O Visual FoxPro continua a fornecer ferramentas de desenvolvedor para desenvolvimento de aplicativos dentro do aplicativo FoxPro e da linguagem FoxPro. O Visual FoxPro adicionou e aprimorou linguagem e comportamentos orientados a objetos. Esta versão do Visual FoxPro inclui linguagem e ferramentas voltadas para Web projetadas para ajudar no desenvolvimento rápido de aplicativos em ambientes de várias camadas e para simplificar suas tarefas de manutenção.
