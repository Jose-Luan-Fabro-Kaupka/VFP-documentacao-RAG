# Trabalhando com views (Visual FoxPro)

Quando você precisa de um conjunto de dados personalizado e atualizável para seu aplicativo, pode criar e usar views. As views combinam as características de tabelas e consultas, fornecendo uma forma de recuperar registros de uma ou mais tabelas ou views relacionadas. Você pode criar views usando tabelas ou views únicas ou múltiplas, usar views para atualizar dados em tabelas e exibir dados, atualizar views e mover dados offline para manipulação.
