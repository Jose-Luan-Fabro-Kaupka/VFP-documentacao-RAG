# Caixa de diálogo Set Index Order

Define a ordem de índice para uma tabela filha. Esta caixa de diálogo aparece quando você define a tabela pai de uma relação na Data Session Window e, em seguida, clica em uma tabela filha na lista Aliases da janela Data Session se a tabela filha ainda não tiver ordem de índice definida.
 **Set Index Order List**
Lista quaisquer ordens de índice predefinidas existentes para a tabela filha selecionada.
**No Order Button**
Abre a caixa de diálogo Expression Builder, onde você pode definir sua própria relação para a tabela filha. Você também pode clicar duas vezes em um índice de tabela listado na caixa de diálogo para abrir a caixa de diálogo ExpressionBuilder.
