# Comando ASSIST

Incluído para compatibilidade com versões anteriores. Use o comando DO em vez disso.

Exibe o Catalog Manager.

```foxpro
ASSIST
```

# Observações

Incluído para compatibilidade com dBASE.

O Catalog Manager é uma interface gráfica que permite gerenciar catálogos (arquivos .FPC ou .CAT) com facilidade. Catálogos podem conter tabelas, consultas, telas, relatórios, etiquetas e programas. Deste local central, você pode criar, modificar e executar esses arquivos FoxPro. Você também pode usar AutoMigrate para migrar arquivos dBASE III e dBASE IV existentes. O Catalog Manager, escrito inteiramente em FoxPro, é um exemplo do tipo de aplicação que você pode desenvolver no FoxPro.
