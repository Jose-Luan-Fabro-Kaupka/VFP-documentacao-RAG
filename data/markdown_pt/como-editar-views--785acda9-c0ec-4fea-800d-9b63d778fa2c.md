# Como: editar views

Você pode abrir views para realizar tarefas, como adicionar tabelas, alterar condições de junção ou outras modificações que deseja fazer em uma view.

### Para abrir uma view para edição
- Execute uma das seguintes opções: Abra o projeto do aplicativo contendo a view no Project Manager . Clique na view e, em seguida, Modificar . -OU- Abra o banco de dados contendo a view no Database Designer . Clique na view e, no menu Banco de dados, clique em Modificar . O View Designer é aberto para exibir a view.

Para obter mais informações, consulte Como: abrir bancos de dados e Como: editar arquivos em projetos.

### Para abrir uma view programaticamente
- Abra um banco de dados contendo a view.
- Use o comando MODIFY VIEW com o nome da view.

Para obter mais informações, consulte Comando MODIFY VIEW.
