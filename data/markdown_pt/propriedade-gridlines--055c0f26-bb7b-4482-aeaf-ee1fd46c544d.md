# Propriedade GridLines

Determina se linhas horizontais e verticais são exibidas no controle Grid. Disponível em tempo de design; leitura/gravação em tempo de execução.

```foxpro
Grid.GridLines[ = nSetting]
```

# Valor de retorno
 **nSetting**
As configurações são: 0, nenhuma linha; 1, somente linhas horizontais; 2, somente linhas verticais; 3 (padrão), linhas horizontais e verticais.

# Observações

Aplica-se a: controle Grid
