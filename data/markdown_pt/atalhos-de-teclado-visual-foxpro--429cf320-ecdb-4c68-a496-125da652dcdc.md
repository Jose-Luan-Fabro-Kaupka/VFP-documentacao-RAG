# Atalhos de teclado (Visual FoxPro)

O Visual FoxPro suporta atalhos de teclado nestas áreas:
 - Janela Browse
- Class Browser
- Janela Code
- Controles
- Editor
- Form Designer e Class Designer
- Ajuda
- Comandos de menu
- Janela Print Preview
- Janela Properties
- Report Designer e Label Designer
- Manipulação de janelas
 Janela Browse
| Atalho | Ação |
| --- | --- |
| CTRL+HOME | Move para o primeiro registro de um cursor ou tabela em uma grade e ao usar o comando BROWSE. |
| CTRL+END | Move para o último registro de um cursor ou tabela em uma grade e ao usar o comando BROWSE. |
| CTRL+HOME CTRL+SHIFT+HOME CTRL+PAGE UP CTRL+PAGE DOWN | Abre uma janela de edição quando pressionado em um campo memo. |
 Class Browser
| Atalho | Ação |
| --- | --- |
| F5 | Atualiza a visualização atual. |
| SHIFT+F10 | Exibe um menu de atalho. |
| Right-click+Open button Right-click+Add button Right-click+Component Gallery button | Exibe um histórico dos últimos 32 arquivos carregados. |
| Right-click+View Class Code button | Exibe o código da classe em um formulário webview. |
| CTRL+Right-click+Class icon (in upper left corner of the Class Browser) | Cria uma instância da classe com a função NEWOBJECT( ) na janela Command. Idêntico a arrastar o ícone Class para a janela Command. |
| SHIFT+Right-click+Class icon (in upper left corner of the Class Browser) | Para formulários, executa o formulário. Para outros controles e objetos, cria uma instância do controle ou objeto. Para controles, também adiciona o controle à área de trabalho do Visual FoxPro em 0,0. Idêntico a arrastar o ícone Class para a área de trabalho do Visual FoxPro. |
 Janela Code
| Atalho | Ação |
| --- | --- |
| ALT+I | Pressiona o botão View Parent Code. |
 Controles
| Atalho | Ação |
| --- | --- |
| CTRL+TAB | Quando um controle Grid tem foco, sai da grade. Quando um controle EditBox tem foco e a propriedade EditBox AllowTabs é True (.T.), sai da edit box. Dentro de um formulário ou caixa de diálogo contendo um controle PageFrame, move para a próxima page no page frame. No entanto, este comportamento não é suportado em arquivos de projeto ou quando o page frame contém um controle ActiveX. |
| CTRL+SHIFT+TAB | Se dentro de um formulário ou caixa de diálogo contendo um controle PageFrame, move para a page anterior no page frame. No entanto, este comportamento não é suportado em arquivos de projeto ou quando o page frame contém um controle ActiveX. |
| TAB | Quando um controle Grid tem foco, move para o próximo campo. |
 Editor
| Atalho | Ação |
| --- | --- |
| ALT+Drag | Recorta e cola. Observação Para alterar o comportamento padrão de arrastar e soltar de arrastar texto em palavras para arrastar texto entre palavras, no menu Tools, clique na guia Editor e selecione a opção Drag drop between words. Para alternar entre arrastar texto dentro de palavras e arrastar texto entre palavras, pressione ALT+Drag. |
| CTRL+Drag | Copia e cola. |
| CTRL+I | Mostrar IntelliSense Quick Info. |
| CTRL+J | Mostrar IntelliSense List Members ou List Values. |
| F2 | Move para a linha contendo o próximo bookmark. |
| SHIFT+F2 | Move para a linha contendo o bookmark anterior. |
| ALT+SHIFT+F2 | Alterna um bookmark para a linha atual ligado e desligado. |
| F3 | Encontra a próxima ocorrência do texto especificado. |
| CTRL+F3 CTRL+G | Encontra a próxima ocorrência do texto selecionado. |
| SHIFT+F3 | Encontra a ocorrência anterior do texto especificado. |
| CTRL+SHIFT+F3 | Encontra a ocorrência anterior do texto selecionado. |
| CTRL+DOWNARROW | Rola a janela para cima sem mover o cursor. |
| CTRL+UPARROW | Rola a janela para baixo sem mover o cursor. |
| CTRL+LEFTARROW | Move o cursor uma palavra para a esquerda. |
| CTRL+RIGHTARROW | Move o cursor uma palavra para a direita. |
| F9 | Insere ou remove um breakpoint. |
| CTRL+F9 | Habilita ou desabilita um breakpoint. |
| CTRL+B | Abre a caixa de diálogo Breakpoints. |
| ALT+F2 | Adiciona/remove atalho Task List. |
| CTRL+U | Torna a seleção toda em minúsculas. |
| CTRL+SHIFT+U | Torna a seleção toda em maiúsculas. |
| CTRL+BACKSPACE | Exclui uma palavra à esquerda. |
 Form Designer e Class Designer
| Atalho | Ação |
| --- | --- |
| Teclas de seta | Move o(s) controle(s) selecionado(s) em incrementos de pixel. |
| CTRL+E | Executa o formulário no Form Designer. |
| CTRL+SHIFT+Click the control | Aprofunda em um controle em um contêiner. |
| CTRL+Click the container | Aprofunda através do contêiner. |
| Tecla de seta SHIFT | Altera a altura ou largura do(s) controle(s) selecionado(s) em incrementos de pixel. |
 Ajuda
| Atalho | Ação |
| --- | --- |
| F1 | Displays Ajuda topics or context-sensitive Ajuda on active items, for example, a highlighted keyword in the Command window or the current property in the Properties window. |
| SHIFT+F1 | Enables user-prompted context-sensitive Ajuda. The insertion pointer changes to a question mark so that you can click an item, for example, a menu command or toolbar, to display context-sensitive Ajuda. |

 Janela Properties
| Atalho | Ação |
| --- | --- |
| ALT+DOWN ARROW | Expande a lista de objetos. |
| ALT+UP ARROW | Fecha a lista de objetos. |
| CTRL+PAGE DOWN DOWN ARROW RIGHT ARROW | Move para o próximo objeto na lista de objetos. |
| CTRL+PAGE UP UP ARROW LEFT ARROW | Move para o objeto anterior na lista de objetos. |
| CTRL+END | Move para o último objeto na lista de objetos. |

| SHIFT+TAB | Move para o controle anterior na janela Properties. |
| SHIFT+F10 | Exibe o menu de atalho apropriado. |
| CTRL+ALT+ letter | Seleciona a próxima propriedade na lista de propriedades que começa com o caractere da letra. Por exemplo, pressionar CTRL+ALT+B seleciona a próxima propriedade que começa com B. |
 Report Designer e Label Designer
| Atalho | Ação |
| --- | --- |
| ALT+ENTER | Abre a caixa de diálogo de configurações apropriada do controle de relatório. |
| Teclas de seta | Move o(s) controle(s) selecionado(s) em incrementos de pixel. |
| CTRL+E | Entra no modo Edit para um controle Label quando selecionado no Report designer. |
| ESC | Sai do modo Edit para um controle Label e retorna ao modo Select. |
| Tecla de seta SHIFT | Altera a altura ou largura do(s) controle(s) selecionado(s) em incrementos de pixel. |
| SHIFT+TAB | Move para o objeto anterior no Report Designer quando no modo Tab. |
| SHIFT+Double Click on a report band | Seleciona todos os objetos na banda. |
| TAB | Entra no modo Tab automaticamente e move para o próximo objeto no Report Designer. |
 Manipulação de janelas
| Atalho | Ação |
| --- | --- |
| CTRL+F1 | Percorre as janelas. |
| CTRL+TAB | Move para a próxima janela. |
| CTRL+SHIFT+TAB | Move para a janela anterior. |
| CTRL+F2 | Exibe a janela Command. |
| CTRL+F4 | Fecha a janela ativa. |
| CTRL+F6 | Move para a próxima janela. |
| CTRL+ALT+SHIFT | Oculta todas as janelas filhas enquanto as teclas estão pressionadas. Ocultar janelas facilita ver a saída exibida na janela principal do aplicativo. |
| CTRL+F10 | Alterna o tamanho da janela entre máximo e restaurar. |

O Visual FoxPro preserva a ordem das janelas e traz a janela mais recente para o primeiro plano em vez de deslocar a última janela para o fundo ao percorrer as janelas.
