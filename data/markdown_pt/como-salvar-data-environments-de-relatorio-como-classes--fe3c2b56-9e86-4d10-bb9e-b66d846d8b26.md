# Como: salvar data environments de relatório como classes

Você pode salvar os data environments que usa para relatórios e etiquetas como classes. Em seguida, você pode especificar essas classes de data environment para outros relatórios e etiquetas ou usá-las com formulários ou outras partes do seu aplicativo que exijam a mesma configuração de dados.

### Para salvar o data environment de um relatório como classe
- Abra o relatório ou a etiqueta no designer apropriado.
- No menu Exibir, clique em Data Environment. O designer Data Environment é aberto.
- No menu Arquivo, clique em Salvar como classe.
- Na caixa Nome, digite o nome da classe.
- Na caixa Arquivo, digite o arquivo de biblioteca de classes visuais (.vcx) para armazenar a classe ou clique no botão de reticências ( … ) para procurar e selecionar um arquivo.
- Na caixa Descrição, digite uma descrição opcional para a classe.

Para obter mais informações, consulte Caixa de diálogo Salvar como classe.
