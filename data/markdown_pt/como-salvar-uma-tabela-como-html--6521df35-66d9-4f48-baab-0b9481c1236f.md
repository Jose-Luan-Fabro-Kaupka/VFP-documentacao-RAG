# Como: salvar uma tabela como HTML

Quando você navega em uma tabela, pode salvar o conteúdo de uma tabela como um arquivo HTML.

### Para salvar uma tabela como HTML
- Abra a tabela em uma janela de navegação.
- No menu Arquivo, clique em Save As HTML .
- Na caixa de diálogo Save As HTML, clique na opção desejada.
- Para especificar um local diferente para salvar o arquivo, clique no botão de reticências ( ... ). Caso contrário, clique em OK .

Para obter mais informações, consulte How to: View Records in Tables.
