# Função ISFLOCKED( )

Retorna o status de bloqueio da tabela.

```foxpro
ISFLOCKED([nWorkArea | cTableAlias])
```

#### Parâmetros
 **nWorkArea**
Especifica o número da área de trabalho da tabela para a qual o status de bloqueio é retornado. Se você omitir cTableAlias e nWorkArea , o status de bloqueio é retornado para a tabela aberta na área de trabalho atual.
**cTableAlias**
Especifica o alias da tabela para a qual o status de bloqueio é retornado. Uma mensagem de erro "Alias not found" é gerada se você especificar um alias de uma tabela que não está aberta.

# Valor de retorno

Logical

# Observações

ISFLOCKED( ) retorna um valor lógico true (.T.) se a tabela estiver bloqueada; caso contrário, um valor lógico false (.F.) é retornado. ISFLOCKED( ) é semelhante a SYS(2011), mas retorna um valor lógico que não requer localização para aplicativos internacionais.

> **Observação:** ISFLOCKED() retorna .T. apenas na estação de trabalho que aplicou o bloqueio de arquivo.
