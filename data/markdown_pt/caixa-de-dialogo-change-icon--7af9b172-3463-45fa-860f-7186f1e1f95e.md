# Caixa de diálogo Change Icon

Esta caixa de diálogo especifica um ícone a ser usado para um objeto vinculado ou incorporado em um formulário ou em um campo General de uma tabela Visual FoxPro. Esta caixa de diálogo é exibida quando você seleciona Display as Icon na caixa de diálogo Insert Object ou Paste Special e escolhe Change Icon.
 **Icon**
Current Especifica que o ícone atual seja usado. Default Especifica que o ícone padrão seja usado. From File Especifica o arquivo do qual o novo ícone deve ser obtido. Digite o caminho e o nome do arquivo na caixa e depois clique em OK para mostrar todos os ícones disponíveis. Percorra os ícones, selecione o ícone que deseja usar e depois clique em OK .
**Label**
Especifica o label que será exibido abaixo do ícone. Digite o label desejado na caixa.
**Browse**
Exibe a caixa de diálogo Browse para que você possa selecionar um arquivo contendo o ícone desejado.
