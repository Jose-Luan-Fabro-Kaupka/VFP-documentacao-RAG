# Caixa de diálogo Check In Files

Faz check-in das alterações feitas no diretório de trabalho do ambiente de desenvolvimento no banco de dados de controle de código-fonte.
 **Files To Be Checked In**
Lista os arquivos disponíveis para check-in. Clique nos arquivos que deseja fazer check-in ou clique em Select All para selecionar todos os arquivos listados.
**Comment**
Digite um comentário opcional.
**Keep Checked Out**
Atualiza o banco de dados de controle de código-fonte com suas alterações, mas mantém o arquivo em check-out para você.
