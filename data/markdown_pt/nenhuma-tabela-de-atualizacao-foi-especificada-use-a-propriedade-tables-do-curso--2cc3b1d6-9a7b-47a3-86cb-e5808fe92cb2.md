# Nenhuma tabela de atualização foi especificada. Use a propriedade Tables do cursor (Erro 1491)

Nenhuma tabela base foi especificada na propriedade Tables da view.

Defina a propriedade Tables para especificar a tabela base ou tabelas que devem ser atualizadas a partir da view. Para a maioria das views, você pode usar os Designers de Consulta e View para definir as propriedades de atualização da view e depois salvar a view de volta no banco de dados. Para obter mais informações, consulte a função CURSORGETPROP( ).
