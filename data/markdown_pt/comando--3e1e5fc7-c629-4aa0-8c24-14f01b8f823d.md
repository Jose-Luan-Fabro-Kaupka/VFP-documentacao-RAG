# Comando =

Avalia uma ou mais expressões.

```foxpro
= Expression1 [, Expression2 ...]
```

#### Parâmetros
 **Expression1 [, Expression2 ...]**
Especifica a expressão ou expressões que o comando = avalia.

# Observações

O comando = avalia uma ou mais expressões, Expression1, Expression2 ..., e descarta os valores de retorno. Essa opção é particularmente útil quando uma função do Visual FoxPro ou uma função definida pelo usuário tem um efeito desejado, mas não há necessidade de atribuir o valor de retorno da função a uma variável, elemento de matriz ou campo.

Por exemplo, para ativar o modo de inserção, você pode emitir o seguinte comando:

```foxpro
= INSMODE(.T.)
```

INSMODE normalmente retorna um valor True (.T.) ou False (.F.). No exemplo acima, a função é executada, mas o valor de retorno é descartado.

Se apenas uma expressão (Expression1) for incluída, o sinal de igual é opcional.

> **Observação:** Há dois usos não relacionados para o sinal de igual (=). Ele pode ser usado como operador em expressões lógicas para fazer uma comparação, ou para atribuir valores a variáveis e elementos de matriz. Nesses dois casos, o sinal de igual (=) é um operador e não um comando. Consulte Relational Operators para obter mais informações sobre o uso do sinal de igual (=) como operador em expressões lógicas. Consulte STORE Command para obter mais informações sobre o uso do sinal de igual (=) para atribuir valores a variáveis e elementos de matriz.
