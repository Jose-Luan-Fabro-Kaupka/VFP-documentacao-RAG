# Criação de sistema de menu

Grande parte do trabalho envolvido na criação de um sistema de menu é feito no Menu Designer, onde você cria os menus, submenus e opções de menu reais.

Criar um sistema de menu envolve várias etapas. Independentemente do tamanho do seu aplicativo e das complexidades dos menus que você planeja usar, você deve:
 - Planejar e projetar o sistema. Decida quais menus você precisa, onde eles aparecem na interface, quais precisam de submenus e assim por diante.
- Criar os menus e submenus. Defina os títulos de menu, itens de menu e submenus usando o Menu Designer.
- Atribuir tarefas ao sistema para que ele faça o que você deseja. Especifique tarefas para os menus executarem, como exibir formulários e caixas de diálogo. Além disso, inclua código de configuração e código de limpeza, se apropriado. O código de configuração é executado antes de o sistema de menu ser definido e pode incluir código para abrir arquivos, declarar variáveis ou colocar o sistema de menu em uma pilha para que possa ser recuperado posteriormente. O código de limpeza contém código a ser executado após o código de definição do menu e torna menus e itens de menu disponíveis ou indisponíveis para seleção.
- Gerar o programa de menu.
- Executar o programa para testar o sistema.
