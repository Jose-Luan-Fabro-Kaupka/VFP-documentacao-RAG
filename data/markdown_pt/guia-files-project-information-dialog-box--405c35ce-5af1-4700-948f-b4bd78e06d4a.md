# Guia Files, Project Information Dialog Box

Exibe uma lista alfabética de todos os arquivos do projeto, seu tipo e status de inclusão/exclusão, data e hora da última modificação e informações de página de código.
 **Type**
Exibe um ícone representando o tipo de arquivo.
**Name**
Exibe o nome do arquivo.
**Last Modified**
Exibe a data e a hora em que o arquivo foi modificado pela última vez.
**Included**
Se você selecionar esta caixa, o arquivo é incluído. Se você limpar a caixa, o arquivo é excluído.
**Code Page**
Exibe o número da página de código.
**Update native code page**
Atualiza as páginas de código para cada arquivo listado.
