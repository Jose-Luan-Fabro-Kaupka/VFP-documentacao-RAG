# Upsizing de bancos de dados Visual FoxPro

Depois de projetar seu aplicativo cliente/servidor, você está pronto para construir e fazer upsizing de um protótipo local. Um protótipo local é um modelo funcional do seu aplicativo usando tabelas, views e bancos de dados do Microsoft Visual FoxPro para representar dados que eventualmente serão acessados em um servidor remoto. Use os assistentes de upsizing para mover bancos de dados, tabelas e views do seu sistema para um servidor remoto Microsoft SQL Server.

# Nesta seção
 **Goals for Prototyping**
Quando você usa o Microsoft Visual FoxPro para construir um protótipo do seu aplicativo, você aproveita o poder de formulários visuais, assistentes, builders, designers e o Project Manager para desenvolver rapidamente um aplicativo funcional.
**How to: Build a Local Prototype of an Application**
Ao construir um protótipo local do seu aplicativo, você pode estar começando do zero ou convertendo um aplicativo Microsoft Visual FoxPro existente em um aplicativo cliente/servidor.
**Database Creation with Upsizing Wizards**
O Visual FoxPro SQL Server Upsizing Wizard cria SQL Servers que duplicam, tanto quanto possível, a funcionalidade de um conjunto de tabelas em um banco de dados Microsoft Visual FoxPro.
