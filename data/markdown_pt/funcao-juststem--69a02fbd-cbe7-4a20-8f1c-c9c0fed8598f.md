# Função JUSTSTEM( )

Retorna o nome base (o nome do arquivo antes da extensão) de um caminho completo e nome de arquivo.

```foxpro
JUSTSTEM(cFileName)
```

#### Parâmetros
 **cFileName**
Especifica o nome (incluindo o caminho) do arquivo para o qual você deseja apenas o nome base. O comprimento máximo da cadeia de caracteres passada para cFileName é de 259 bytes.

# Valor de retorno

Caractere
