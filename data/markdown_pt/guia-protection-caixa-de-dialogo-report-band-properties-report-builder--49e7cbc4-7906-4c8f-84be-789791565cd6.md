# Guia Protection, Caixa de Diálogo Report Band Properties (Report Builder)

Permite restringir certas ações para uma banda de relatório no Report Designer ou Label Designer, impedindo que o usuário altere a banda ao modificar o relatório ou etiqueta no modo protegido. Para obter mais informações, consulte Setting Protection for Reports.
 - How to: Protect Report Bands

# When in PROTECTED mode

Especifica opções de proteção para a banda de relatório.
 **Band cannot be resized**
Especifica que os usuários não podem redimensionar a banda de relatório ao modificar o relatório ou etiqueta no modo protegido. A caixa de seleção Band cannot be resized está atualmente indisponível.
**Properties dialog box is not available**
Especifica que os usuários não podem alterar propriedades da banda ao modificar o relatório ou etiqueta no modo protegido.
