# Comando RELEASE LIBRARY

Remove da memória uma única biblioteca externa de API.

```foxpro
RELEASE LIBRARY LibraryName
```

#### Parâmetros
**LibraryName**
Especifica o nome da biblioteca de API a ser removida da memória.

# Observações

Emita SET LIBRARY TO para remover da memória todas as bibliotecas de API. Uma biblioteca externa de rotinas de API é carregada na memória com SET LIBRARY. Para obter mais informações, consulte o comando SET LIBRARY.
