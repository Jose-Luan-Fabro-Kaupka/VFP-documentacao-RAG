# Comentários

Você pode comparar como a formatação de comentários difere entre o Visual FoxPro e outras linguagens de programação. Visual FoxPro, C e C++ têm formatos diferentes para comentários de linha inteira e comentários em partes de linhas.

| Visual FoxPro | BASIC |
| --- | --- |
| * Comentário de linha inteira. USE && Comentário embutido. NOTE Comentário ; de várias linhas | ' Comentário |

| Pascal | C/C++ |
| --- | --- |
| { Comentário } | // Comentário /* Comentário de várias linhas */ |
