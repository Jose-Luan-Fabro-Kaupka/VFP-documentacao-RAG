# Propriedade TypeLibCLSID

O CLSID (Class Identifier) de registro de uma biblioteca de tipos criada para classes de servidor em um projeto. Somente leitura.

```foxpro
Object.TypeLibCLSID
```

# Observações

Aplica-se a: Project Object (Visual FoxPro)

Uma biblioteca de tipos é criada e registrada quando você compila um .dll ou .exe a partir de um projeto que contém classes de servidor. Bibliotecas de tipos têm extensão .tlb e são colocadas no mesmo diretório do .dll ou .exe compilado.
