# Rotina de biblioteca de API _WGetObjectClientWindow( )

Retorna o identificador da janela cliente na qual o objeto especificado está contido.

```foxpro
WHANDLE _WGetObjectClientWindow(Value FAR *objct)
```

# Observações

Use a função da rotina de biblioteca de API _WhToHwnd( ) para converter o WHANDLE em um HWND do Windows.
