# Classe base dos botões Find (Findnext)

Esta classe fornece um conjunto genérico de botões de localização/localização do próximo.

| Categoria | Data Query |
| --- | --- |
| Catálogo padrão | Visual FoxPro Catalog\Foundation Classes\Data Query |
| Classe | _findnextbuttons |
| Classe base | Container |
| Biblioteca de classes | _table.vcx |
| Classe pai | _findbutton |
| Exemplo | ...\Samples\Solution\Ffc\dataqry.scx |

# Observações

Para usar, solte a classe em um projeto ou formulário ou selecione Add to Project ou Add to Form no menu de atalho do item da Component Gallery. Ao adicioná-la a um formulário, o Visual FoxPro abre um builder para especificar os valores apropriados. Em um projeto, você pode adicionar a classe ou criar uma subclasse.

Quando colocada em um formulário ou outro contêiner, esta classe localiza um registro usando um objeto Find com base nos critérios especificados. Para obter detalhes, consulte Find Button ou _findbutton na biblioteca _table.vcx no Class Browser.
