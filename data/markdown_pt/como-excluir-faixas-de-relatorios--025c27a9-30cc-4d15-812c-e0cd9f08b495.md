# Como: excluir faixas de relatórios

Você pode excluir as faixas Title, Summary e Detail de um relatório ou rótulo. Para excluir grupos de dados, consulte Como: excluir grupos de dados em relatórios.

> **Observação:** Não é possível reduzir a zero o número de faixas Detail. O layout deve sempre conter uma. Ao reduzir esse número, a faixa de maior número, adicionada por último e situada no nível inferior do layout, é excluída.

> **Cuidado:** Se uma faixa Detail contiver itens, o designer solicitará confirmação. Porém, não solicitará confirmação quando você desmarcar Title ou Summary, o que exclui a faixa e todos os controles nela contidos.

### Para excluir uma faixa Title, Summary ou Detail
- Abra o relatório ou rótulo no designer apropriado.
- No menu Report, clique em Optional Bands. A caixa Report Properties será aberta. Se _REPORTBUILDER não estiver definido como o Report Builder padrão, poderá ser exibida outra caixa.
- Em Report Properties, clique na guia Optional Bands.
- Selecione as faixas a remover: para Title, desmarque Report has title band; para Summary, desmarque Report has summary band; para Detail, selecione a faixa na lista Detail bands e clique em Remove. Confirme com Yes quando solicitado.
- Ao terminar, clique em OK.

Para obter mais informações, consulte Guia Optional Bands, caixa de diálogo Report Properties (Report Builder).
