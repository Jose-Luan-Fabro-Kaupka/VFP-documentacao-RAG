# Caixa de diálogo Dynamic Script Preview (Report Builder)

Permite visualizar o código que será executado em tempo de execução para criar a exibição de propriedade dinâmica.

> **Observação:** Quaisquer alterações feitas nesta caixa de diálogo não serão salvas. Porém, você pode copiar o código em uma função definida pelo usuário e personalizar o código lá.

Você pode abrir esta caixa de diálogo selecionando uma condição e clicando em Script na guia Dynamics da caixa de diálogo Report Control Properties.
 - Como: formatar controles de relatório dinamicamente
 **Font**
Abre a caixa de diálogo Font para que você possa especificar o nome, estilo e tamanho da fonte do código.
**Code Zoom**
Abre o código em uma janela de edição separada para que você possa ver o código com a coloração de sintaxe do Visual FoxPro.
