# Application Builder

A caixa de diálogo com guias do Application Builder simplifica a criação e a modificação de formulários, controles complexos e outros elementos opcionais de aplicações eficazes e satisfatórias.

 Para usar o Application Builder
 - No menu Tools, aponte para Wizards e clique em All Wizards. A caixa de diálogo Wizard Selection é exibida.
- Na caixa de diálogo Wizard Selection, escolha Application Builder.

O Application Builder se integra aos arquivos do framework de aplicação criados pelo Application Wizard, para que você possa construir uma aplicação completa sem precisar escrever código. Você também pode fazer o seguinte:
 - Adicionar, editar ou remover componentes específicos da aplicação, como tabelas, formulários e relatórios.
- Especificar estilos visuais para formulários e relatórios.
- Adicionar elementos comuns de aplicação, incluindo uma tela de abertura, uma caixa de diálogo About, um menu Favorites, uma caixa de diálogo User Login e uma barra de ferramentas padrão.
- Especificar créditos de produção e informações de versão para a aplicação.
- Exibir arquivos de tabela em um banco de dados na guia Data.

Como em todos os builders do Visual FoxPro, o Application Builder é reentrante, o que significa que você pode fechá-lo e reabri-lo para modificar quaisquer configurações feitas pelo builder. Você pode reabrir o Application Builder clicando com o botão direito no projeto e selecionando Builder.

> **Observação:** Alterações adicionais feitas pelo builder não aparecerão na aplicação até que a aplicação seja reconstruída.

Para obter mais informações, consulte Creating Applications with the Application Framework.

### Guias do Builder

General Tab, Application Builder

Especifica o nome da aplicação e outros recursos opcionais, como tela de abertura, formulário de inicialização e o tipo de aplicação.

Credits Tab, Application Builder

Especifica créditos de produção da aplicação, como autor, empresa, versão, copyright e marca registrada.

Data Tab, Application Builder

Especifica a fonte de dados e o formato para formulários e relatórios incluídos na aplicação.

Forms Tab, Application Builder

Especifica tipos de menu, o menu a partir do qual um formulário é chamado, barras de ferramentas e se um formulário pode ser instanciado várias vezes.

Reports Tab, Application Builder

Especifica nomes amigáveis para relatórios na aplicação.

Advanced Tab, Application Builder

Especifica o nome do arquivo de Help e o diretório padrão da aplicação. Você também pode especificar a inclusão de uma barra de ferramentas padrão e de um menu Favorites na aplicação.
