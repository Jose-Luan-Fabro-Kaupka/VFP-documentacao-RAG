# Variável de sistema _GENXTAB

Incluída para compatibilidade com versões anteriores. Use o Cross-Tab Wizard em vez disso.

Especifica o programa usado para gerar resultados RQBE em formato de tabela cruzada.

```foxpro
_GENXTAB = program name
```

# Observações

Com _GENXTAB você pode especificar o programa que o FoxPro usa para gerar resultados RQBE no Microsoft Graph no FoxPro for Windows e FoxPro for Macintosh, FoxGraph no FoxPro for MS-DOS, um formulário de relatório ou uma tabela em formato de tabela cruzada.

Por padrão, _GENXTAB usa o programa GENXTAB.PRG.
