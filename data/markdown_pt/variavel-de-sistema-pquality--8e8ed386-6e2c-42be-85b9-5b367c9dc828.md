# Variável de sistema _PQUALITY

Incluída para compatibilidade com versões anteriores. Use o Report Designer.

Define a qualidade de impressão.

```foxpro
_PQUALITY = expL
```

# Observações

_PQUALITY é incluída para compatibilidade com versões anteriores. Use o Report Writer.

A aplicação de driver de impressora GENPD.APP fornecida com o FoxPro para MS-DOS não usa _PQUALITY. Qualquer valor armazenado no valor de memória de sistema _PQUALITY não tem efeito sobre a saída impressa.

_PQUALITY está disponível para uso em uma aplicação de driver de impressora que você criar.
