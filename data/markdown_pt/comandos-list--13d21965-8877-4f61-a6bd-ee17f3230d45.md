# Comandos LIST

Exibe informações da tabela ou do ambiente sem pausar a janela principal do Visual FoxPro ou uma janela definida pelo usuário. Há várias versões da sintaxe.

```foxpro
LIST [FIELDS FieldList] [Scope] [FOR lExpression1]
   [WHILE lExpression2] [OFF] [NOCONSOLE] [NOOPTIMIZE]
   [TO PRINTER [PROMPT] | TO FILE FileName [ADDITIVE]]
```

```foxpro
LIST FILES [ON Drive] [LIKE FileSkeleton]
   [TO PRINTER [PROMPT] | TO FILE FileName [ADDITIVE]]
```

```foxpro
LIST MEMORY [LIKE FileSkeleton] [NOCONSOLE]
   [TO PRINTER [PROMPT] | TO FILE FileName [ADDITIVE]]
```

```foxpro
LIST STATUS [NOCONSOLE]
   [TO PRINTER [PROMPT] | TO FILE FileName [ADDITIVE]]
```

```foxpro
LIST STRUCTURE [IN nWorkArea | cTableAlias] [NOCONSOLE]
   [TO PRINTER [PROMPT] | TO FILE FileName [ADDITIVE]]
```

# Observações

Os comandos LIST são idênticos aos comandos DISPLAY, exceto pelas seguintes diferenças:
 - LIST exibe informações sem pausar, enquanto DISPLAY exibe a primeira tela de informações e então pausa. Para obter mais informações, consulte Comando DISPLAY.
- A cláusula ADDITIVE acrescenta ao final do arquivo indicado. Se você omitir ADDITIVE, o arquivo será sobrescrito com o valor da expressão.
- O escopo padrão de LIST é ALL registros.
- LIST não exibe registros marcados para exclusão quando SET DELETED está ON. Para obter mais informações, consulte Comando SET DELETED.
