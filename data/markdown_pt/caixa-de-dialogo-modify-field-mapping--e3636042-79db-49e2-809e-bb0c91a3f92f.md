# Caixa de diálogo Modify Field Mapping

Use esta caixa de diálogo para alterar o mapeamento entre um tipo de campo de banco de dados e o tipo de classe (controle) que o Visual FoxPro cria quando você arrasta uma tabela ou campo para um formulário a partir do Data Environment Designer, Database Designer (Visual FoxPro) ou Project Manager Window.

Esta caixa de diálogo aparece quando você escolhe Modify na Field Mapping Tab, Options Dialog Box.
 **Type**
Selecione o tipo de campo de banco de dados para o qual deseja alterar o mapeamento. Por padrão, o tipo de campo selecionado é o que estava selecionado na guia Field Type Mapping.

# Informações da classe
 **Library**
Insira uma biblioteca de classes que contém a classe que você deseja que o Visual FoxPro crie quando um campo do tipo especificado é arrastado para um formulário. Se esta caixa estiver em branco, o tipo de campo é mapeado para uma classe base do Visual FoxPro.
**Browse**
Escolha esta opção para exibir a Open Dialog Box, na qual você pode selecionar uma biblioteca de classes.
**Name**
Selecione o nome de uma classe para mapear ao tipo de campo especificado. A lista contém somente as classes na biblioteca escolhida; para exibir as classes base do Visual FoxPro nesta caixa, limpe a caixa Library. A classe base e a descrição da classe selecionada, se disponível, são exibidas abaixo do nome da classe.
**Apply**
Escolha esta opção para criar o mapeamento. Escolha Apply se desejar alterar um mapeamento, mas manter a caixa de diálogo Field Type Mapping aberta para alterar outro mapeamento. Para alterar um único mapeamento, escolha OK.
