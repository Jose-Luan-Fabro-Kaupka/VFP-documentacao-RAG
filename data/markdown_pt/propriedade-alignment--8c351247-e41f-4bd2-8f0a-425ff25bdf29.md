# Propriedade Alignment

Especifica o alinhamento do texto em um controle. Disponível em tempo de design e em tempo de execução.

```foxpro
Control.Alignment[ = nAlign]
```

# Valor de retorno

# Controles CheckBox, OptionButton e CommandButton
 **nAlign**
Especifica um valor numérico que representa o alinhamento do texto em um controle. nAlign Descrição 0 Centralizado verticalmente à esquerda. (Padrão para caixas de seleção e botões de opção) Alinha o texto à esquerda e centralizado verticalmente no controle. 1 Centralizado verticalmente à direita. (Padrão para versões do Windows do Oriente Médio) Alinha o texto à direita e centralizado verticalmente no controle. 2 Centralizado. (Padrão para botões de comando) Centraliza o texto verticalmente e horizontalmente. Observação Para botões de comando, a imagem e o texto aparecem no centro do controle. No entanto, quando uma imagem é especificada para a propriedade Picture, esta configuração exibe o comportamento padrão apenas quando as propriedades PictureMargin e PictureSpacing estão definidas como 0. Observação Para caixas de seleção e botões de opção, esta configuração se aplica apenas quando a propriedade Style do controle está definida como 1. Definir a propriedade Style afeta a aparência do controle. Para obter mais informações, consulte Style Property. 4 Superior esquerdo. Alinha o texto no canto superior esquerdo do controle. Observação Para caixas de seleção e botões de opção, esta configuração se aplica apenas quando a propriedade Style do controle está definida como 1. Definir a propriedade Style afeta a aparência do controle. Para obter mais informações, consulte Style Property. 5 Superior direito. Alinha o texto no canto superior direito do controle. Observação Para caixas de seleção e botões de opção, esta configuração se aplica apenas quando a propriedade Style do controle está definida como 1. Definir a propriedade Style afeta a aparência do controle. Para obter mais informações, consulte Style Property. 6 Superior centralizado. Alinha o texto na parte superior e centralizado horizontalmente no controle. Observação Esta configuração se aplica apenas quando a propriedade Style do controle está definida como 1. Definir a propriedade Style afeta a aparência do controle. Para obter mais informações, consulte Style Property. 7 Inferior esquerdo. Alinha o texto no canto inferior esquerdo do controle. Observação Para caixas de seleção e botões de opção, esta configuração se aplica apenas quando a propriedade Style do controle está definida como 1. Definir a propriedade Style afeta a aparência do controle. Para obter mais informações, consulte Style Property. 8 Inferior direito. Alinha o texto no canto inferior direito do controle. Observação Para caixas de seleção e botões de opção, esta configuração se aplica apenas quando a propriedade Style do controle está definida como 1. Definir a propriedade Style afeta a aparência do controle. Para obter mais informações, consulte Style Property. 9 Inferior centralizado. Alinha o texto na parte inferior e centralizado verticalmente no controle. Observação Para caixas de seleção e botões de opção, esta configuração se aplica apenas quando a propriedade Style do controle está definida como 1. Definir a propriedade Style afeta a aparência do controle. Para obter mais informações, consulte Style Property. Observação Para controles CommandButton, você pode definir a propriedade Alignment sem especificar uma imagem para a propriedade Picture. No entanto, certas configurações de Alignment são visíveis apenas quando você especifica uma imagem para a propriedade Picture e define a propriedade PicturePosition com um valor diferente do padrão. Além disso, algumas configurações de Alignment não são visíveis, a menos que a propriedade WordWrap esteja definida como True (.T.) e o texto Caption seja exibido em várias linhas. Quando você não especifica uma imagem para a propriedade Picture, a configuração PicturePosition não afeta a propriedade Alignment. Observação Para controles CheckBox e OptionButton, quando Style está definido como 0, a propriedade PicturePosition afeta a posição das caixas de seleção ou botões de opção no controle. Quando você especifica uma imagem para a propriedade Picture, a propriedade PicturePosition pode afetar a propriedade Alignment. Por exemplo, a configuração padrão para PicturePosition resulta em um alinhamento centralizado independentemente da configuração de Alignment. Para obter mais informações, consulte Picture Property (Visual FoxPro) e PicturePosition Property.

# Controles ComboBox, EditBox, Label e Spinner
 **nAlign**
Especifica um valor numérico que representa o alinhamento do texto em um controle. nAlign Descrição 0 Esquerda. Alinha o texto à esquerda. (Padrão para caixas de combinação, caixas de edição e etiquetas) 1 Direita. Alinha o texto à direita. (Padrão para spinners e para versões do Windows do Oriente Médio) 2 Centro. Centraliza o texto verticalmente e horizontalmente no controle. 3 Automático. Alinha o texto com base no tipo de dados da fonte de controle. Observação A configuração Automatic não se aplica a controles EditBox, Header ou Label. Observação Para controles ComboBox, a propriedade Alignment se aplica apenas quando a propriedade Style está definida como 0.

# Objetos Header e Column
 **nAlign**
Especifica um valor numérico que representa o alinhamento do texto em um controle. nAlign Descrição 0 Centralizado verticalmente à esquerda. Alinha o texto à esquerda e centraliza verticalmente na coluna. 1 Centralizado verticalmente à direita. Alinha o texto à direita e centraliza verticalmente na coluna. 2 Centralizado. Centraliza o texto verticalmente e horizontalmente. 3 Automático. Alinha o texto na coluna com base no tipo de dados da fonte de controle. (Padrão) Observação A configuração Automatic alinha o texto com base no tipo de dados da fonte de controle, especificado pela propriedade ControlSource. Para fontes de controle com tipos numéricos, como Numeric, Double, Float, Currency e Integer, o texto é alinhado à direita. Para fontes de controle com outros tipos de dados, o texto é alinhado à esquerda. 4 Superior esquerdo. Alinha o texto à esquerda na parte superior da coluna. 5 Superior direito. Alinha o texto à direita na parte superior da coluna. 6 Superior centralizado. Alinha o texto na parte superior e centralizado horizontalmente na coluna. 7 Inferior esquerdo. Alinha o texto à esquerda na parte inferior da coluna. 8 Inferior direito. Alinha o texto à direita na parte inferior da coluna. 9 Inferior centralizado. Alinha o texto na parte inferior e centralizado horizontalmente na coluna. Para um objeto Header, se a propriedade WordWrap estiver definida como False (.F.), os valores 0-2, 4-9 estão disponíveis. Se a propriedade WordWrap estiver definida como True (.T.), os valores 0-2 são efetivos.

# Controle TextBox
 **nAlign**
Especifica um valor numérico que representa o alinhamento do texto no controle TextBox. nAlign Descrição 0 Esquerda. Alinha o texto à esquerda. 1 Direita. Alinha o texto à direita. 2 Centro. Alinha o texto centralizado horizontalmente e verticalmente no controle. 3 Automático. (Padrão) Observação Para um controle TextBox não contido em uma coluna, a configuração Automatic alinha o texto com base no tipo de dados da fonte de controle, especificado pela propriedade ControlSource. Para fontes de controle com tipos numéricos, como Numeric, Double, Float, Currency e Integer, o texto é alinhado à direita. Para fontes de controle com outros tipos de dados, o texto é alinhado à esquerda. Para obter mais informações, consulte ControlSource Property. Observação Para um controle TextBox em uma coluna, a configuração Alignment da coluna determina o alinhamento do texto na caixa de texto.

# Observações

Aplica-se a: CommandButton Control | CheckBox Control | Column Object | ComboBox Control | EditBox Control | Header Object | Label Control (Visual FoxPro) | OptionButton Control | Spinner Control | TextBox Control (Visual FoxPro)
