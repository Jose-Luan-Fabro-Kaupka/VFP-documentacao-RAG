# Como: executar aplicativos

Depois de concluir a criação de um arquivo de aplicativo redistribuível, você pode executá-lo. Você pode executar arquivos de aplicativo no menu Program ou usando o comando DO. Para obter mais informações, consulte DO Command.

### Para executar um arquivo de aplicativo (.app)
- No menu Program, escolha Do .
- Na caixa de diálogo Do, selecione o arquivo .app que deseja executar.

### Para executar um arquivo executável (.exe)
- No Windows, clique duas vezes no ícone do arquivo .exe.

Você também pode executar arquivos .exe no menu Program ou usando o comando DO.
