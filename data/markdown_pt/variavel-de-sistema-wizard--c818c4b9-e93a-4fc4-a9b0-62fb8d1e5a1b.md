# Variável de sistema _WIZARD

Contém o nome da aplicação de assistente do Visual FoxPro.

```foxpro
_WIZARD = cProgramName
```

#### Parâmetros
 **cProgramName**
Especifica uma aplicação de assistente. Se sua aplicação de assistente estiver em um diretório diferente do diretório padrão atual do Visual FoxPro, inclua um caminho com o nome da aplicação. Você também pode especificar uma aplicação de assistente no arquivo de configuração do Visual FoxPro incluindo uma linha usando a seguinte sintaxe: _WIZARD = cProgramName

# Observações

A variável de sistema _WIZARD contém o nome da aplicação que o Visual FoxPro usa quando você escolhe um assistente para executar. Por padrão, _WIZARD contém Wizard.app, instalado no diretório do Visual FoxPro. Você pode especificar um nome diferente para a aplicação de assistente.
