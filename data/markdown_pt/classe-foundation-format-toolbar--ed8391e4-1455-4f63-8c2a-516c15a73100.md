# Classe Foundation Format Toolbar

Esta classe, quando colocada em um formulário, fornece uma barra de ferramentas para aplicar formatação de fonte ao texto no controle ativo.

| Categoria | Text Format |
| --- | --- |
| Catálogo padrão | Visual FoxPro Catalog\Foundation Classes\Text Formatting |
| Classe | _tbrediting |
| Classe base | Toolbar |
| Biblioteca de classes | _format.vcx |
| Classe pai | _toolbars |
| Exemplo | ...\Samples\Solution\Toolbars\format.scx |

# Observações

Para usar, solte a classe em um projeto ou, no menu de atalho do item do Component Gallery, selecione Add to Project. Quando você adiciona a classe a um projeto, pode escolher entre adicionar a classe ou criar uma subclasse.

| Propriedades, eventos, métodos | Descrição |
| --- | --- |
| Propriedade nAppliesTo | Especifica o escopo da formatação. 1 = aplicar ao controle selecionado 3 = aplicar a todos os controles Padrão: 1 |
