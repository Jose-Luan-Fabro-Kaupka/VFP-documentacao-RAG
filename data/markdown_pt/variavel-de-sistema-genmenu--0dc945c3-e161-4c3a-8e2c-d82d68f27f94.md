# Variável de sistema _GENMENU

Especifica um programa de geração de menus.

```foxpro
_GENMENU = ProgramName
```

#### Parâmetros
 **ProgramName**
Especifica um programa usado por versões anteriores para gerar código de menu a partir de uma tabela de definição de menu .mnx. Se o programa estiver em um diretório diferente do diretório padrão atual, inclua um caminho com o nome do programa.

# Observações

_GENMENU contém Genmenu.prg por padrão. Uma diretiva (#IMAGEPATHS) controla se caminhos completos são gerados para imagens de menu.
