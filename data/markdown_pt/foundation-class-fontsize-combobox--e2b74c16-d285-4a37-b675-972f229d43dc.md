# Foundation Class Fontsize Combobox

Esta classe é uma combobox que lista os tamanhos de fonte disponíveis. Também é usada pelas classes tbrEditing e RTFControls de _format.scx.

| Categoria | Formatação de texto |
| --- | --- |
| Catálogo padrão | Visual FoxPro Catalog\Foundation Classes\Text Formatting |
| Classe | _cbofontsize |
| Classe base | ComboBox |
| Biblioteca de classes | _format.vcx |
| Classe pai | _combobox |
| Exemplo | ...\Samples\Solution\Toolbars\format.scx |

# Observações

Para usar, solte a classe em um projeto ou formulário ou, no menu de atalho do item da Component Gallery, selecione Add to Project ou Add to Form. Ao adicionar a classe a um formulário, o Visual FoxPro coloca uma combobox no formulário para que você possa especificar valores de tamanho de fonte apropriados para objetos no formulário ativo. Ao soltar a classe em um projeto, você pode escolher entre adicionar a classe ou criar uma subclasse.

| Propriedades, eventos, métodos | Descrição |
| --- | --- |
| Propriedade nSmallestFont | Para fontes escaláveis, especifica o menor tamanho de fonte permitido. Padrão: 8 |
| Propriedade nLargestFont | Para fontes escaláveis, especifica o maior tamanho de fonte permitido. Padrão: 48 |
