# Propriedade TabStretch

Especifica o comportamento quando as guias não cabem no quadro de página. Disponível em tempo de design e em tempo de execução. TabStretch estará disponível somente se Tabs estiver definida como verdadeiro (.T.).

```foxpro
PageFrame.TabStretch[ = nSetting]
```

# Valor de retorno
 **nSetting**
As configurações da propriedade TabStretch são: Configuração Descrição 0 Stack. Uma segunda linha de guias é criada. 1 (Padrão) Clip. As guias são recortadas conforme necessário.
