# Rotinas de tratamento de erros

Essas rotinas de API permitem determinar a causa de um erro e o tipo de erro.
 **_Error( ) API Library Routine**
Sinaliza o erro especificado pelo valor em code para o runtime do Visual FoxPro.
**_ErrorInfo( ) API Library Routine**
Retorna o número de erro externo que reflete o número de erro interno especificado por code .
**_UserError( ) API Library Routine**
Relata um erro com o texto terminado em nulo especificado em message .
