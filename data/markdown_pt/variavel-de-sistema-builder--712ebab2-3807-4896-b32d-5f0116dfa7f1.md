# Variável de sistema _BUILDER

Contém o nome do aplicativo builder do Visual FoxPro.

```foxpro
_BUILDER = cProgramName
```

#### Parâmetros
 **cProgramName**
Especifica um aplicativo builder. Se seu aplicativo builder estiver em um diretório diferente do diretório padrão atual do Visual FoxPro, inclua um caminho com o nome do aplicativo.

# Observações

A variável de sistema _BUILDER contém o nome do aplicativo que o Visual FoxPro usa quando você escolhe um builder no Form Designer. Por padrão, _BUILDER contém BUILDER.APP, instalado em seu diretório do Visual FoxPro. Você pode especificar um nome diferente para o aplicativo builder.
