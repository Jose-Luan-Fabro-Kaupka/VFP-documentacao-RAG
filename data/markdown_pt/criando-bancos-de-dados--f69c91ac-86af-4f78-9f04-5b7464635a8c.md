# Criando bancos de dados

Depois de ter projetado seu banco de dados e determinado os campos que pode precisar, você está pronto para criar seu banco de dados.

# Nesta seção
 **Como: criar bancos de dados**
Descreve como criar bancos de dados.
**Como: visualizar e definir propriedades de banco de dados**
Descreve como você pode visualizar e definir propriedades para bancos de dados.
**Trabalhando com itens em bancos de dados**
Apresenta e descreve como executar tarefas com itens em bancos de dados, como exibi-los, organizá-los, adicionar itens, definir relacionamentos, atualizar links entre um banco de dados e suas tabelas, criar regras que governam a adição, atualização e exclusão de registros, e assim por diante.
**Como: criar e gerenciar procedimentos armazenados**
Descreve como armazenar código escrito para operar em um banco de dados específico e que pode se mover com o banco de dados.
**Trabalhando com eventos de contêiner de banco de dados**
Apresenta eventos de contêiner de banco de dados que você pode usar para executar código de procedimento quando eventos de banco de dados ocorrem.
