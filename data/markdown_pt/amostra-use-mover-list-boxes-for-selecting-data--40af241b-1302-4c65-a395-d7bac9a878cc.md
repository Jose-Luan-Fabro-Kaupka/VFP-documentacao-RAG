# Amostra Use Mover List Boxes for Selecting Data

Arquivo: ...\Samples\Solution\Ffc\Movers.scx

Esta amostra contém as seguintes classes.

| Classe | Biblioteca | Descrição |
| --- | --- | --- |
| _tablemover | _movers.scx | Carrega automaticamente tabelas e campos da fonte de dados atualmente selecionada. |
| _fieldmover | _movers.scx | Carrega automaticamente campos da fonte de dados atual. |
| _sortmover | _movers.scx | Trata automaticamente a ordenação de dados. |
| _supermover | _movers.scx | Fornece uma caixa de lista mover com botões Move, Remove, Move All e Remove All. |

Para obter detalhes sobre todas as classes disponíveis nas foundation classes, consulte Visual FoxPro Foundation Classes A-Z.
