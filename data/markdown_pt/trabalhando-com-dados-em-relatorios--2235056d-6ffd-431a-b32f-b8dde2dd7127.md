# Trabalhando com dados em relatórios

Ao criar relatórios ou rótulos, você pode especificar os dados a serem incluídos no relatório ou rótulo and para controlar o ambiente no qual o relatório acessa os dados.

# Nesta seção
 **Controlando dados em relatórios**
Discute o fornecimento de dados para relatórios e rótulos, o controle de registros selecionados e a classificação e ordenação desses registros.
**Como: especificar a sessão de dados de um relatório**
Explica como definir uma sessão de dados privados para um relatório.
**Como: carregar ambientes de dados para relatórios**
Descreve como usar uma definição de classe DataEnvironment criada para uso com formulários ou registros de ambiente de dados salvos com outro relatório ou rótulo para fornecer dados para um relatório.
**Como salvar ambientes de dados de relatório como classes**
Descreve como salvar a definição de ambiente de dados criada para um relatório ou rótulo como uma classe visual, para que você possa reutilizar essa definição para outros relatórios em outras áreas do seu aplicativo, como design de formulário.
**Trabalhando com tabelas relacionadas usando diversas faixas de detalhes em relatórios**
Discute diferentes maneiras de exibir dados de diferentes tabelas e como o mecanismo de relatório lida com diversas tabelas em tempo de execução.
