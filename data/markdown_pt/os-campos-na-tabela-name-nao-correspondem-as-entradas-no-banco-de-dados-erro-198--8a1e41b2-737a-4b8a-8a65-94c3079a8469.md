# Os campos na tabela "name" não correspondem às entradas no banco de dados (Erro 1984)

Ao abrir uma tabela pertencente a um banco de dados, o Visual FoxPro tenta confirmar que cada campo da tabela tem um objeto de campo correspondente no banco de dados.
 - O banco de dados ou a tabela foi corrompido. Use VALIDATE DATABASE para identificar o problema.
- A tabela sendo aberta é a errada. Remova e adicione novamente a tabela ao banco de dados.
