# Função ISCOLOR( )

Determina se um computador pode exibir cores.

```foxpro
ISCOLOR()
```

# Valor de retorno

Logical

# Observações

ISCOLOR( ) retorna true (.T.) se o computador tem capacidade de cor (mesmo que um monitor colorido não esteja sendo usado de fato). Se o computador não oferece suporte a cores, ISCOLOR( ) retorna false (.F.).
