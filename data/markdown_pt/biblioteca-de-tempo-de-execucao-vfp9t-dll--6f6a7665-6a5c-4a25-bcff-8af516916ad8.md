# Biblioteca de tempo de execução VFP9T.DLL

A biblioteca de tempo de execução multithread do Visual FoxPro, VFP9T.dll, ajuda a eliminar os problemas de bloqueio associados à biblioteca de tempo de execução do Visual FoxPro, VFP9R.dll. Com a biblioteca de tempo de execução multithread do Visual FoxPro, você pode implantar servidores in-process sem bloqueio da execução de código. Esta biblioteca de tempo de execução está localizada no diretório ..\Program Files\Common Files\Microsoft Shared\VFP.

Como a biblioteca de tempo de execução multithread do Visual FoxPro é uma biblioteca de tempo de execução leve projetada apenas para servidores in-process, muitos comandos e funções relacionados a recursos visuais e de entrada do usuário foram desabilitados.

Como não ocorre bloqueio na biblioteca de tempo de execução multithread do Visual FoxPro, um objeto que executa um procedimento excepcionalmente longo, como imprimir um relatório, não impedirá que outros objetos executem rotinas rápidas. Por exemplo, com a biblioteca de tempo de execução do Visual FoxPro, um objeto que executa uma rotina de consulta de banco de dados de 1 segundo pode ter que aguardar 15 minutos por um objeto que imprime um relatório longo e complexo. Se você compilar com a biblioteca de tempo de execução multithread do Visual FoxPro, não terá o mesmo gargalo.

Além de abordar problemas de bloqueio, a implementação de threading no modelo Apartment na biblioteca de tempo de execução multithread do Visual FoxPro também elimina conflitos no acesso a dados globais de várias threads, dando a cada apartment sua própria cópia de dados globais. A biblioteca de tempo de execução multithread do Visual FoxPro usa armazenamento local de thread para dar a cada instância de classe seu próprio conjunto de dados. Isso significa que uma variável que você declara PUBLIC é global apenas para a thread; cada thread tem uma instância da variável.

> **Observação:** Propriedades de leitura/gravação do objeto Application, como AutoYield, são globais para o projeto.

O Visual FoxPro torna possível que a mesma biblioteca de tempo de execução multithread do Visual FoxPro seja implantada com vários servidores de automação .dll in-process chamados simultaneamente, estejam ou não no mesmo processo/thread. A biblioteca de tempo de execução original do Visual FoxPro cria uma cópia renomeada da biblioteca para cada servidor .dll in-process em execução no mesmo processo.

O Visual FoxPro oferece uma classe Session, que você deve usar para classes de servidor OLEPUBLIC. Como com formulários, a propriedade DataSession torna possível criar uma sessão de dados privada para seu objeto na instanciação. A vantagem da classe Session é que ela usa muito menos memória que um formulário. A biblioteca de tempo de execução multithread do Visual FoxPro protege automaticamente globais e dados do usuário por meio de armazenamento local de thread, mas isso se aplica apenas entre apartments (threads). Objetos na mesma thread instanciados do mesmo .dll podem acessar os dados uns dos outros. A classe Session auxilia na proteção de dados dentro da thread.

Como a biblioteca de tempo de execução multithread do Visual FoxPro é projetada para uso apenas com servidores in-process, ela foi reduzida em tamanho. Muitos comandos e funções de interface do usuário foram eliminados, incluindo suporte antigo do FoxPro 2.x para READ e @...Get/Say. Além disso, alguns designers, como Table Designer e Report Designer, que existem na biblioteca de tempo de execução principal do Visual FoxPro, também foram removidos. A biblioteca de tempo de execução multithread do Visual FoxPro ainda suporta classes visuais, como formulários.
