# Caixa de diálogo Propriedades do item

Permite personalizar o comportamento dos itens do Component Gallery.

Esta caixa de diálogo aparece quando você clica em Propriedades no menu de atalho de um item selecionado. Quando você seleciona Edição avançada habilitada na caixa de diálogo Opções do Component Gallery, esta caixa de diálogo também exibirá as guias Tipo, Scripts, Exibições e Comentários.

# Guia Geral

Permite especificar as seguintes configurações nesta guia:
 **Nome**
Exibe o valor no campo Text como a etiqueta do componente no Component Gallery.
**Descrição**
Informações opcionais do campo Desc deste registro na tabela selecionada (especificada na guia Nó. ID ). Este item é exibido no painel de descrição do Component Gallery.
**Imagem**
Valor no campo Folderpict que especifica o caminho e o nome do arquivo do gráfico usado para representar o item na galeria.

# Guia Exibições

Permite especificar características que controlam a exibição deste item no Component Gallery.
 **Exibições**
Especifica o nome da exibição e da pasta que contém o item selecionado na seguinte sintaxe: <viewName>=<folderName>
**Palavras-chave**
Exibe as palavras-chave pelas quais o item selecionado pode ser encontrado. Você pode adicionar a esta lista clicando no botão da caixa de diálogo e selecionando da lista padrão de palavras-chave da galeria.

# Guia Nó

Um nó é qualquer item selecionável da galeria. Permite especificar configurações para o item selecionado. As seguintes configurações estão disponíveis nesta guia:
 **ID**
O nome da tabela mais o valor no campo ID do registro do item selecionado em seu catálogo pai.
**Link**
Se o item selecionado é um link, especifica o nome do item de origem.
**Nome da classe**
Especifica a classe de galeria do item selecionado
**Biblioteca de classes**
Especifica o caminho e o arquivo para a biblioteca que contém a classe de galeria do item selecionado.

# Guia Scripts

Fornece um local para especificar eventos ou propriedades que são globais para todos os itens. As seguintes áreas estão disponíveis nesta guia:
 **Script**
O valor no campo Script do registro deste item em seu catálogo pai. O campo contém qualquer script de evento relacionado a este item.
**Propriedades**
O valor no campo Properties que pode conter atribuições de valor a propriedades do item.

# Guia Comentários

Permite especificar configurações para o item selecionado. As seguintes configurações estão disponíveis nesta guia:
 **Comentários**
O valor no campo Comment deste registro no catálogo pai (especificado na guia Nó. ID ) que contém comentários do usuário sobre uso, características ou qualquer outra coisa.
**Usuário**
O valor no campo User deste registro no catálogo pai (especificado na guia Nó. ID ) que contém comentários do usuário sobre uso, características ou qualquer outra coisa.

# Guias de item

As guias de item são geradas pelo Component Gallery e adicionadas à caixa de diálogo Propriedades do item para a maioria dos itens que você adiciona à galeria. Cada guia de item fornece um conjunto de informações de propriedades específicas para o item particular desse tipo. Uma caixa de diálogo Propriedades do item pode incluir a guia Item de classe, guia Item de arquivo, guia Item de formulário, guia Item de menu, guia Item de programa, guia Item de projeto e guia Item de relatório.

# Guia Item de classe

Permite especificar a classe e a biblioteca de classes que contém o item da galeria.
 **Nome da classe**
Especifica o nome da classe.
**Biblioteca de classes**
Especifica o nome e o caminho para a biblioteca de classes que contém o item da galeria.
**Classe base**
Especifica a classe da qual este item da galeria é subclasse.
**Arquivo de amostra**
Especifica o nome e o caminho para um arquivo contendo um exemplo deste item da galeria.

# Guia Item de arquivo

Permite especificar o caminho e o nome do arquivo do item da galeria.
 **Nome do arquivo**
Especifica o caminho e o nome do arquivo.

# Guia Item de formulário

Permite especificar o caminho e o nome do arquivo .scx do item da galeria.
 **Nome do formulário**
Especifica o caminho e o nome do formulário.

# Guia Item de menu

Permite especificar o caminho e o nome do arquivo .mnx do item da galeria.
 **Nome do menu**
Especifica o caminho e o nome do formulário.

# Guia Item de programa

Permite especificar o caminho e o nome do arquivo do item da galeria.
 **Nome do arquivo**
Especifica o caminho e o nome do arquivo.

# Guia Item de projeto

Permite especificar o caminho e o nome do arquivo .pjx do item da galeria.
 **Nome do arquivo**
Especifica o caminho e o nome do arquivo do projeto de origem.
**Nome de saída**
Especifica o caminho e o nome do arquivo de saída.
**Ação de compilação**
Especifica qual opção de compilação ( Rebuild Project , Build Application , Build Executable ou Build OLE DLL ) é usada quando você compila este projeto.
**Recompilar tudo**
Permite recompilar todos os arquivos ou apenas aqueles que foram alterados desde a última compilação.
**Mostrar erros**
Permite exibir erros de opção de compilação em uma caixa de edição após a conclusão da compilação.
**Executar após compilar**
Permite executar o aplicativo após a conclusão da compilação.

# Guia Item de relatório

Permite especificar a classe e a biblioteca de classes que contém o item da galeria.
 **Nome do relatório**
Especifica o caminho e o nome do arquivo do relatório de origem.
