# Propriedade VersionDescription

A descrição de um projeto.

```foxpro
Object.VersionDescription[ = cDescription]
```

# Valor de retorno
 **cDescription**
Especifica a descrição de um projeto. O valor padrão é a cadeia de caracteres vazia.

# Observações

Aplica-se a: Project Object (Visual FoxPro)

A propriedade VersionDescription corresponde ao valor do item File Description na caixa de diálogo EXE Version Dialog Box.
