# Exemplo Apresentar Múltiplas Opções ao Usuário

Arquivo: ...\Samples\Solution\Controls\Buttons\Quiz.scx

Este exemplo ilustra o uso de um grupo de botões de opção sem seleção padrão e a vinculação de um campo de caractere ao grupo de opções.

### Para exibir um grupo de opções sem botão selecionado, faça uma das seguintes opções:
- Defina a propriedade Value de cada um dos botões de opção no grupo como 0 ou .F.
- Defina a propriedade Value do grupo de botões de opção como 0.

### Para armazenar o Caption dos botões de opção em um campo de tabela
- Defina o ControlSource do grupo de botões de opção para o campo.
