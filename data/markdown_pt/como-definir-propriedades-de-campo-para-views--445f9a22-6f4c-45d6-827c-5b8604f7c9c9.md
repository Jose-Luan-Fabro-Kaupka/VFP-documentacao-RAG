# Como: definir propriedades de campo para views

Você pode definir algumas das mesmas propriedades que estão disponíveis para campos em tabelas porque sua view faz parte de um banco de dados. Por exemplo, você pode atribuir captions, adicionar comentários ou definir regras de validação para controlar a entrada de dados. Para obter mais informações, consulte Working with Fields.

### Para visualizar e definir propriedades para campos em views
- Abra a view no View Designer e clique na guia Fields.
- Na lista Selected fields, clique em um campo e depois em Properties .
- Na caixa de diálogo View Field Properties, configure as configurações desejadas.
- Quando terminar, clique em OK .

Para obter mais informações, consulte Fields Tab, Query and View Designers e View Field Properties Dialog Box.
