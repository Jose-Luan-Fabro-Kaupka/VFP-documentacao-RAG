# Caixa de diálogo Query Destination

Permite enviar os resultados da sua consulta para sete saídas diferentes.

Esta caixa de diálogo aparece quando você seleciona Query Destination no menu Query e está disponível somente para consultas.
 **Destinos de saída**
Exibe botões para você escolher o tipo de saída para os resultados da sua consulta. A tabela a seguir lista e descreve os tipos de saída. Botão Descrição Botão Browse, Caixa de diálogo Query Destination Exibe os resultados da sua consulta em uma janela Browse. Botão Cursor, Caixa de diálogo Query Destination Salva os resultados da sua consulta em um cursor. Botão Table, Caixa de diálogo Query Destination Salva os resultados da sua consulta como um arquivo de tabela. Botão Screen, Caixa de diálogo Query Destination Exibe os resultados da sua consulta na janela de saída ativa.
