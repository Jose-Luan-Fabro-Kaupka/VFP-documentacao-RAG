# Trabalhando com programas

Arquivos de programa contêm código para executar uma série de instruções. Armazenar código em um arquivo de programa (.prg) oferece benefícios como os seguintes:
 - Você pode criar e salvar programas para executar depois em vez de executá-los imediatamente.
- Você pode editar programas em janelas de edição do Visual FoxPro e formatar blocos de código ou arquivos de programa inteiros.
- Você pode editar e executar programas várias vezes.
- Você pode executar programas a partir de menus, formulários e barras de ferramentas.
- Você pode usar programas para executar outros programas.

Quando seu programa faz parte de um projeto, você também pode pesquisar e substituir referências de código e texto e visualizar definições de elementos de código encontrados em pesquisas no arquivo de programa atual. Para obter mais informações, consulte How to: Search For Code References e How to: View Code Definitions.
