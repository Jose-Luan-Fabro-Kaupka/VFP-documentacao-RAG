# Amostras COM+

O Windows 2000 introduz um novo conjunto de serviços de componentes (COM+ Services) que ampliam a capacidade de criar soluções transacionais distribuídas ricas para suas aplicações Windows ou Web. O Visual FoxPro inclui recursos de servidor novos e aprimorados para melhor suportar muitos desses serviços. As amostras COM+ são muito simples e destinam-se a mostrar conceitos básicos de uso de um serviço COM+ específico. Amostras para usar Queued Components, COM+ Events e Compensation Resource Managers estão localizadas na pasta ...\Samples\COM+. Para obter mais informações, consulte o arquivo Readme.htm na pasta.

Alguns dos serviços COM+, como Transactions, existiam antes do Windows 2000 e eram suportados pelo Visual FoxPro. Novos serviços, como COM+ Events e Queued Components, oferecem novas opções para suas aplicações que não estavam disponíveis anteriormente no Visual FoxPro.
