# Método CloneObject

Duplica um objeto, incluindo todas as propriedades, eventos e métodos do objeto. Disponível somente em tempo de design.

```foxpro
Object.CloneObject(NewName)
```

#### Parâmetros
 **NewName**
Especifica o nome do novo objeto, ou duplicado.

# Observações

Aplica-se a: CheckBox Control | ComboBox Control | CommandButton Control | CommandGroup Control | Custom Object | EditBox Control | Grid Control | Image Control (Visual FoxPro) | Label Control (Visual FoxPro) | Line Control | ListBox Control | OLE Bound Control | OLE Container Control | OptionButton Control | OptionGroup Control | Page Object | PageFrame Control | Shape Control | Spinner Control | TextBox Control (Visual FoxPro) | Timer Control | ToolBar Object
