# Caixa de diálogo Generate Menu

Permite especificar um nome para o programa de menu gerado e depois gerar o programa. Se você não salvou seu menu, será solicitado a fazer isso.

Esta caixa de diálogo aparece quando você seleciona Generate no menu Menu.
 **Output File**
Especifica o caminho para o programa de menu gerado. Escolha o botão de diálogo para selecionar um diretório e nome de arquivo, ou substitua por um nome de arquivo de sua escolha digitando sobre o nome exibido.
**Generate**
Produz um arquivo de programa de menu, que tem a extensão .mpr.
