# Classe XMLField

Em um objeto XMLTable, a coleção Fields contém objetos XMLField. Cada objeto XMLField representa a estrutura de um campo que é significativo para o Visual FoxPro.

As informações em cada objeto XMLField fornecem os detalhes necessários, como o tipo de dados correto, tamanho e outras informações, para criar cada campo no cursor. Quando o Visual FoxPro gera XML de um cursor, os objetos XMLField fornecem as informações para criar o documento XML e o esquema.

```foxpro
XMLField
```
