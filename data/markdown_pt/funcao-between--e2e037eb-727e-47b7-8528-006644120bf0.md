# Função BETWEEN( )

Determina se o valor de uma expressão está inclusivamente entre os valores de duas expressões do mesmo tipo.

```foxpro
BETWEEN(eTestValue, eLowValue, eHighValue)
```

#### Parâmetros
 **eTestValue**
Especifica uma expressão a ser avaliada.
**eLowValue**
Especifica o valor inferior no intervalo.
**eHighValue**
Especifica o valor superior no intervalo.

# Valor de retorno

Logical ou null. BETWEEN( ) retorna True (.T.) se o valor da expressão especificada for igual a um dos valores ou maior que o valor inferior e menor que o valor superior das duas expressões. Caso contrário, BETWEEN( ) retorna False (.F.). BETWEEN( ) retorna um valor nulo se eLowValue ou eHighValue for um valor nulo.

# Exemplo

O exemplo a seguir percorre a tabela `orders` em busca de todos os registros no campo `order_amt` com valores entre 950 e 1000 inclusive e exibe o campo `cust_id` e o campo `order_amt`.

```foxpro
CLOSE DATABASES
OPEN DATABASE (HOME(2) + 'Data\testdata')
USE orders  && Open order table
CLEAR
SCAN FOR BETWEEN(order_amt,950,1000)
   ? cust_id, order_amt
ENDSCAN
```
