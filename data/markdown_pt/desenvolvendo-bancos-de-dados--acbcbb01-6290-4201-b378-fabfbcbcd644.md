# Desenvolvendo bancos de dados

No Visual FoxPro, você pode projetar, criar e gerenciar bancos de dados para associar, organizar e trabalhar com tabelas e views como um grupo. Antes de começar a criar e trabalhar com bancos de dados, é importante entender as considerações de design sobre a criação de bancos de dados.

# Nesta seção
 **Databases in Visual FoxPro**
Apresenta bancos de dados no Visual FoxPro e fornece informações sobre seus aspectos.
**Designing Databases**
Descreve considerações de design para criar bancos de dados bem planejados.
**Creating Databases**
Descreve a criação de bancos de dados e o trabalho com tabelas associadas a bancos de dados.
**Managing Databases**
Descreve diversas tarefas para gerenciar bancos de dados.

# Referência
 **Database Wizard**
Permite criar bancos de dados usando um assistente.
**Database Designer (Visual FoxPro)**
Permite criar bancos de dados começando com um contêiner de banco de dados vazio ou modificar bancos de dados existentes.
**Janela Project Manager**
Permite organizar arquivos em um projeto de aplicativo.

# Seções relacionadas
 **Working with Data**
Fornece uma visão geral e informações sobre o uso de dados em seus aplicativos, por exemplo, analisar requisitos de dados e projetar os componentes do aplicativo para atender a esses requisitos.
**Importing and Exporting Data**
Explica como as informações são copiadas entre o Visual FoxPro e outros aplicativos importando para e exportando do Visual FoxPro.
**Developing Visual FoxPro Applications**
Explica conceitos sobre como desenvolver aplicativos Visual FoxPro, instruções para criar bancos de dados e a interface do usuário e outras tarefas necessárias para criar aplicativos Visual FoxPro.
