# Função ADIR( )

Coloca informações sobre arquivos em uma matriz e retorna o número de arquivos.

```foxpro
ADIR(ArrayName [, cFileSkeleton [, cAttribute [, nFlag]]])
```

#### Parâmetros
 **ArrayName**
Especifica o nome da matriz. Se a matriz que você incluir não existir, o Visual FoxPro cria a matriz automaticamente. Se a matriz existir e não for grande o suficiente para conter todas as informações, o Visual FoxPro aumenta automaticamente o tamanho da matriz para acomodar as informações. Se a matriz for maior do que o necessário, o Visual FoxPro trunca a matriz. Se a matriz existir e ADIR( ) retornar 0 porque nenhum arquivo correspondente foi encontrado, a matriz permanece inalterada. Se a matriz não existir e ADIR( ) retornar 0, a matriz não é criada. A tabela a seguir descreve o conteúdo e o tipo de dados de cada coluna na matriz: Coluna Conteúdo da matriz Tipo de dados 1 Nomes de arquivos Character 2 Tamanhos de arquivos Numeric 3 Datas da última modificação Date 4 Horas da última modificação Character 5 Atributos de arquivo Character A última coluna da matriz contém os atributos de arquivo dos arquivos correspondentes. Cada atributo de arquivo é expresso por uma letra; um arquivo pode ter mais de um atributo. A tabela a seguir indica o atributo de arquivo representado por cada letra: Letra Atributo A Archive – Read/Write H Hidden R Read-only S System D Directory
**cFileSkeleton**
Especifica um esqueleto de arquivo para que você possa armazenar informações sobre arquivos com nomes ou extensões que correspondam a um critério de pesquisa. Por exemplo, o critério pode ser todas as tabelas, todos os arquivos de texto, todos os arquivos com nomes que tenham A como primeira letra, e assim por diante. Essas pesquisas gerais são feitas incluindo os curingas * e ? em cFileSkeleton . Um ponto de interrogação representa um único caractere; um asterisco representa qualquer número de caracteres. Você pode usar qualquer número de curingas em qualquer posição dentro do esqueleto de arquivo. Você pode especificar uma unidade e/ou diretório para pesquisar nomes de arquivos correspondentes. Se você não especificar uma unidade e um diretório, o Visual FoxPro coloca informações sobre arquivos no diretório atual na matriz.
**cAttribute**
Especifica a inclusão de subdiretórios e arquivos ocultos ou de sistema. cAttribute pode conter qualquer combinação de D, H e S. Incluir D retorna nomes de subdiretórios do diretório atual, além de nomes de arquivos que correspondam ao esqueleto de arquivo especificado em cFileSkeleton . Incluir H retorna informações sobre arquivos ocultos que correspondam ao esqueleto de arquivo especificado em cFileSkeleton . Incluir S retorna informações sobre arquivos de sistema que correspondam ao esqueleto de arquivo especificado em cFileSkeleton . Inclua uma cadeia de caracteres vazia em cFileSkeleton para retornar apenas nomes de subdiretórios, arquivos ocultos ou arquivos de sistema. Você pode incluir V em cAttribute para retornar o nome do volume da unidade atual. Somente o nome do volume é retornado à matriz se V for incluído com D, H ou S. O nome do volume é armazenado no primeiro elemento da matriz e o restante da matriz é truncado.
**nFlag**
Especifica se a exibição fornece nomenclatura DOS ou sensibilidade real a maiúsculas e minúsculas. nFlag Descrição 0 (Padrão) A exibição representa o nome completo do arquivo em maiúsculas 1 A exibição representa a capitalização original nos nomes 2 A exibição segue a convenção de nomenclatura DOS 8+3

# Valor de retorno

Numeric

# Observações

Para cada arquivo, ADIR( ) coloca na matriz o nome do arquivo, tamanho, data da última modificação, hora da última modificação e atributos.

# Exemplo

O exemplo a seguir usa ADIR( ) para criar uma matriz contendo informações de banco de dados. Os nomes dos bancos de dados são então exibidos.

```foxpro
CLOSE DATABASES
SET DEFAULT TO (HOME(2) + 'Data')
gnDbcnumber = ADIR(gaDatabase, '*.DBC')  && Create array
CLEAR
FOR nCount = 1 TO gnDbcnumber  && Loop for number of databases
   ? gaDatabase(nCount,1)  && Display database names
ENDFOR
SET PATH TO HOME()  && Set path to Visual FoxPro directory
```
