# Vinculação de eventos para objetos

Você pode usar vinculação de eventos para anexar um evento, método ou propriedade de um objeto Visual FoxPro ou um evento de um objeto Component Object Model (COM), ambos podendo atuar como origens de eventos, a um objeto Visual FoxPro. No entanto, a abordagem para vincular eventos de objetos nativos e COM difere.

# Nesta seção
 **Vinculação de eventos para objetos Visual FoxPro**
Discute a vinculação de eventos, métodos e propriedades de outros objetos nativos Visual FoxPro a objetos Visual FoxPro.
**Vinculação de eventos para objetos COM**
Discute a vinculação de eventos de objetos COM a objetos Visual FoxPro.
