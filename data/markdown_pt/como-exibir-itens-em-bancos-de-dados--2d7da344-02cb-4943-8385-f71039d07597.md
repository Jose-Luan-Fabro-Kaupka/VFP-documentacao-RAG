# Como: exibir itens em bancos de dados

Você pode escolher quais itens do banco de dados exibir ou como exibi-los no Database Designer. Por exemplo, você pode expandir tabelas para ver os campos e índices que contêm ou recolher tabelas para mostrar apenas os nomes das tabelas.

### Para exibir itens em um banco de dados
- Abra o banco de dados no Database Designer .
- No menu Database, clique em Properties para abrir a caixa de diálogo Database Properties.
- Na área Display, selecione os itens que deseja exibir.

### Para expandir ou recolher uma tabela em um banco de dados
- No Database Designer , clique com o botão direito em uma tabela e clique em Expand ou Collapse .

### Para expandir ou recolher todas as tabelas
- Clique com o botão direito no Database Designer e clique em Expand All ou Collapse All .
