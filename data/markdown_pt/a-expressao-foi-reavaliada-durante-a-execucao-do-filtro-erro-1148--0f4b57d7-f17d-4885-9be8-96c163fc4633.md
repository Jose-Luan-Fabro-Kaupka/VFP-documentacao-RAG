# A expressão foi reavaliada durante a execução do filtro (Erro 1148)

A expressão do comando SET FILTER foi reavaliada durante a execução do filtro. Isso pode ocorrer em configurações complexas que envolvam SET RELATION ou SET FILTER, ou durante o uso de funções do Visual FoxPro ou definidas pelo usuário que façam referência a outras áreas de trabalho, como LOOKUP( ) ou SEEK( ).
