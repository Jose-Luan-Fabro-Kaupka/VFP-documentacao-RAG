# Função SET( )

Retorna o status de vários comandos SET.

```foxpro
SET(cSETCommand [, 1 | cExpression | 2 | 3 | 4])
```

#### Parâmetros
 **cSETCommand**
Especifica uma expressão de caracteres do comando SET para o qual você deseja retornar informações. A configuração atual do comando especificado é retornada como uma cadeia de caracteres ou numérica.
**1 | cExpression | 2 | 3 | 4**
Especifica informações adicionais a retornar sobre um comando SET. Os valores 1 e cExpression são idênticos. cExpression pode ser qualquer expressão que avalie para um valor do tipo character. Observação Incluir um argumento não retorna informações adicionais para todos os comandos SET. # Valor de retorno

Character ou Numeric data type. SET( ) retorna o valor de um comando SET.

# Observações

SET( ) reconhece a abreviação de 4 caracteres para todas as palavras-chave SET do Visual FoxPro, com a exceção de HELPFILTER, que pode ser abreviada para 5 caracteres. Por exemplo, você pode usar STAT e PRIN para SET STATUS e SET PRINTER, respectivamente.

A função SET( ) é idêntica a SYS(2001).
