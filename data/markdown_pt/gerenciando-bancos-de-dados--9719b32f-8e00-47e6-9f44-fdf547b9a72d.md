# Gerenciando bancos de dados

Você pode executar diferentes tarefas para gerenciar bancos de dados.

# Nesta seção
 **How to: Add Databases to Projects**
Descreve como adicionar bancos de dados a um projeto de aplicativo.
**How to: Open Databases**
Descreve como abrir bancos de dados existentes e trabalhar com uma representação visual deles.
**How to: Set the Current Database**
Descreve como definir um banco de dados como o atual.
**How to: Validate a Database**
Descreve como validar a integridade do arquivo de banco de dados (.dbc).
**Handling Database Errors**
Descreve como fornecer mensagens de erro personalizadas em vez de erros genéricos de banco de dados usando triggers.
**How to: Close Databases**
Descreve como fechar bancos de dados.
**How to: Remove Databases from Projects**
Descreve como remover bancos de dados de um projeto de aplicativo.
**How to: View Database Structure**
Descreve como visualizar a estrutura do arquivo de banco de dados (.dbc), que contém informações sobre o banco de dados.
**How to: Extend Database Files**
Descreve como adicionar campos definidos pelo usuário a um arquivo de banco de dados (.dbc).

# Referência
 **Database Designer (Visual FoxPro)**
Permite criar bancos de dados começando com um contêiner de banco de dados vazio ou modificar bancos de dados existentes.
**Project Manager Window**
Permite organizar arquivos em um projeto de aplicativo.
**Databases**
Lista a linguagem de programação que você pode usar para trabalhar com bancos de dados.

# Seções relacionadas
 **Working with Items in Databases**
Apresenta e descreve como executar tarefas com itens em bancos de dados, como exibi-los, organizá-los, adicionar itens, definir relacionamentos, atualizar links entre um banco de dados e suas tabelas, criar regras que regem adição, atualização e exclusão de registros, e assim por diante.
**Designing Databases**
Descreve considerações de design para criar bancos de dados bem planejados.
**Developing Databases**
Apresenta e descreve o uso de bancos de dados para armazenar, organizar e trabalhar com tabelas e views como uma coleção.
