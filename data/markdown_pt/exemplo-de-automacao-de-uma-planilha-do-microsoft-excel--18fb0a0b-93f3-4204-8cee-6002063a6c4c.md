# Exemplo de automação de uma planilha do Microsoft Excel

Arquivo: ...\Samples\Solution\OLE\Olexl.scx

Este formulário mostra dois exemplos do Visual FoxPro chamando uma planilha do Excel por meio de automação.

O botão Tendência executa uma consulta seguida de uma tabulação cruzada para criar um conjunto de dados a ser passado ao Excel por meio de automação usando o objeto Excel.Sheet. No Excel, o Visual FoxPro pode chamar uma função Trend para executar uma análise de regressão simples.

O botão Gráfico automatiza o objeto Excel.Chart para criar um gráfico. O Excel oferece suporte à passagem de dados por automação, mas o MS Graph não. No entanto, você pode distribuir o MS Graph com seus aplicativos.
