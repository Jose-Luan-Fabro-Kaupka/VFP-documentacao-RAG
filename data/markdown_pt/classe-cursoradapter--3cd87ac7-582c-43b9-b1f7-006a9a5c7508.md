# Classe CursorAdapter

Suporta o tratamento de uma ampla variedade de fontes de dados como cursores nativos do Visual FoxPro. Esses tipos de fonte de dados incluem os seguintes:
 - Native
- Open Database Connectivity (ODBC)
- ActiveX Data Object (ADO)
- Extensible Markup Language (XML)

```foxpro
CursorAdapter
```

# Observações

O cursor aberto por um objeto CursorAdapter é sempre um cursor com buffer e tem como padrão Optimistic Row Buffering.

Para obter informações mais detalhadas sobre a classe CursorAdapter, consulte Data Access Management Using CursorAdapters.
