# Função AFIELDS( )

Recupera e armazena informações sobre a estrutura da tabela em uma área de trabalho especificada, especificada por um alias de tabela, ou na área de trabalho selecionada atualmente em uma matriz e retorna o número de campos na tabela.

```foxpro
AFIELDS( ArrayName [, nWorkArea | cTableAlias ] )
```

#### Parâmetros
 **ArrayName**
Especifica uma matriz para armazenar informações sobre a estrutura da tabela. Se a matriz que você especificar não existir, o Visual FoxPro a cria automaticamente. Se a matriz existir e não for grande o suficiente para conter todas as informações retornadas por AFIELDS( ), o tamanho da matriz é aumentado automaticamente para acomodar as informações.
**nWorkArea**
Especifica a área de trabalho da tabela.
**cTableAlias**
Especifica um alias de tabela. Se você omitir nWorkArea e cTableAlias , AFIELDS( ) recupera informações da tabela na área de trabalho selecionada atualmente.

# Valor de retorno

Tipo de dados numérico. AFIELDS( ) retorna o número de campos na tabela. A matriz contém 18 colunas e tem o mesmo número de linhas que campos na tabela.

A tabela a seguir descreve o conteúdo de cada coluna na primeira linha da matriz e o tipo de dados das informações armazenadas em cada coluna. Valores para propriedades específicas da tabela nas colunas 10 a 16 aparecem somente na primeira linha da matriz. Uma linha é criada para cada campo na tabela.

| Número da coluna | Informação do campo | Tipo de dados |
| --- | --- | --- |
| 1 | Nome do campo | Character |
| 2 | Tipo do campo: C = Character Y = Currency D = Date T = DateTime B = Double F = Float G = General I = Integer L = Logical M = Memo N = Numeric Q = Varbinary V = Varchar e Varchar (Binary) W = Blob | Character |
| 3 | Largura do campo | Numeric |
| 4 | Casas decimais | Numeric |
| 5 | Valores nulos permitidos | Logical |
| 6 | Tradução de página de código não permitida | Logical |
| 7 | Expressão de validação do campo | Character |
| 8 | Texto de validação do campo | Character |
| 9 | Valor padrão do campo | Character |
| 10 | Expressão de validação da tabela | Character |
| 11 | Texto de validação da tabela | Character |
| 12 | Nome longo da tabela | Character |
| 13 | Expressão de gatilho de inserção | Character |
| 14 | Expressão de gatilho de atualização | Character |
| 15 | Expressão de gatilho de exclusão | Character |
| 16 | Comentário da tabela | Character |
| 17 | NextValue para autoincremento | Numeric |
| 18 | Step para autoincremento | Numeric |

# Observações

Se os campos na tabela usam autoincremento, o valor Step é maior que 0.

Você pode usar o Comando COPY STRUCTURE EXTENDED para colocar informações semelhantes em uma tabela em vez de uma matriz.

# Exemplo

O exemplo a seguir cria uma matriz chamada `gaMyArray`, que contém informações sobre os campos na tabela `Customer`. Os nomes dos campos são exibidos.

```foxpro
CLOSE DATABASES
OPEN DATABASE (HOME(2) + 'Data\testdata')
USE Customer     && Open Customer table.
gnFieldcount = AFIELDS(gaMyArray)  && Create array.
CLEAR
FOR nCount = 1 TO gnFieldcount
   ? gaMyArray(nCount,1)  && Display field names.
ENDFOR
```
