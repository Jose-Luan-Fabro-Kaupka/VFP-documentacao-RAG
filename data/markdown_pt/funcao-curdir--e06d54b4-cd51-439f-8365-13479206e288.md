# Função CURDIR( )

Retorna o diretório atual.

```foxpro
CURDIR([cExpression])
```

#### Parâmetros
 **cExpression**
Especifica a unidade ou volume para o qual CURDIR( ) retorna o diretório ou pasta atual. Se você omitir cExpression , a unidade ou volume padrão atual é assumido. A cadeia de caracteres vazia é retornada se a unidade ou volume que você especificar em cExpression não existir. Observe que este argumento está incluído apenas para versões anteriores do Visual FoxPro e do FoxPro em execução no Windows 3.1 ou MS-DOS.

# Valor de retorno

Character

# Observações

CURDIR( ) retorna, como uma cadeia de caracteres, o diretório MS-DOS atual em uma unidade especificada.

# Exemplo

O exemplo a seguir armazena o diretório atual em uma variável, define o padrão para o diretório em que o Visual FoxPro foi iniciado, exibe o novo diretório, retorna o padrão ao diretório original e exibe o diretório original.

```foxpro
CLEAR
? 'Current directory: ', CURDIR()
gcOldDir = SET('DEFAULT') + SYS(2003)
SET DEFAULT TO (HOME())
? 'Visual FoxPro directory: ', CURDIR()
SET DEFAULT TO (gcOldDir)
? 'Current directory: ', CURDIR()
```
