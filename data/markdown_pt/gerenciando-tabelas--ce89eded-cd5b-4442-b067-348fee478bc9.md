# Gerenciando tabelas

Você pode executar diferentes tarefas para gerenciar tabelas.

# Nesta seção
 **Como: abrir tabelas (Visual FoxPro)**
Descreve como abrir tabelas livres, tabelas de banco de dados e tabelas em projetos.
**Como: copiar tabelas**
Descreve como copiar a estrutura e o conteúdo de uma tabela para uma nova tabela.
**Como: salvar uma tabela como HTML**
Descreve como salvar o conteúdo de uma tabela como HTML.
**Como: fechar tabelas**
Descreve como fechar tabelas.
**Como: excluir tabelas**
Descreve como excluir tabelas.
**Gerenciando tabelas em sessões de dados**
Descreve como gerenciar tabelas em sessões de dados, que são ambientes de trabalho separados para um formulário, conjunto de formulários ou relatório.

# Seções relacionadas

**Criando bancos de dados**
Descreve a criação de bancos de dados e o trabalho com tabelas associadas a bancos de dados.
**Trabalhando com tabelas (Visual FoxPro)**
Discute como estruturar suas tabelas para atender aos requisitos da aplicação. Escolhas de tipo de dados e índice são essenciais para o sucesso da aplicação.
