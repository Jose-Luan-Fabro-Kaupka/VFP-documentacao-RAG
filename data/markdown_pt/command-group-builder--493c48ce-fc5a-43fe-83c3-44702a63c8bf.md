# Command Group Builder

O Command Group builder facilita a definição de propriedades para um controle command group. Você define propriedades selecionando opções na caixa de diálogo Command Group Builder.

 Para usar o Command Group builder
 - Usando a barra de ferramentas Form Controls, coloque um controle command group em um formulário.
- Selecione e clique com o botão direito no controle command group e escolha Builder no menu de atalho do Form Designer. Uma caixa de diálogo apropriada ao controle selecionado aparece.
- Escolha as opções desejadas na caixa de diálogo e escolha OK . Quando você escolhe OK , o builder fecha, aplicando as configurações de propriedade de cada guia.

# Guias do Builder
 **Buttons**
Especifica o número de botões e as propriedades Caption e Picture de cada um.
**Layout**
Especifica o layout dos botões (vertical ou horizontal), o espaçamento e o estilo da borda controlando as propriedades Height e Width do command group. Observação Os botões de comando podem ter legendas, ou gráficos, ou ambos. Você também pode especificar gráficos a serem exibidos quando o botão estiver desabilitado e quando estiver pressionado, mas deve fazer isso programaticamente ou na janela Properties. Para mais detalhes, consulte as propriedades DisabledPicture e DownPicture.
