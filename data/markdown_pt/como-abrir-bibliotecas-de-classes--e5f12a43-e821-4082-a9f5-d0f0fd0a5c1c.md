# Como: abrir bibliotecas de classes

Você pode abrir bibliotecas de classes para visualizar ou adicionar classes.

Você pode abrir classes usando o Class Browser, o Project Manager quando a biblioteca de classes faz parte de um projeto ou programaticamente.

### Para abrir uma biblioteca de classes
- No menu Tools, escolha Class Browser .
- No Class Browser , clique em Open .
- Na caixa de diálogo Open, selecione a biblioteca de classes desejada e clique em OK . A biblioteca de classes selecionada aparece na lista de classes no Class Browser junto com quaisquer classes que ela contém.

### Para abrir uma biblioteca de classes em um projeto
- Abra o projeto que contém a biblioteca de classes.
- No Project Manager , selecione a guia Classes.
- Selecione a biblioteca de classes que deseja abrir e clique em Modify . A biblioteca de classes selecionada abre no Class Browser .

### Para abrir e fechar bibliotecas de classes programaticamente
- Para abrir bibliotecas de classes programaticamente, use o comando SET CLASSLIB. -OU-
- Para fechar bibliotecas de classes programaticamente, use o comando RELEASE CLASSLIB.

Para obter mais informações, consulte SET CLASSLIB Command e RELEASE CLASSLIB Command.
