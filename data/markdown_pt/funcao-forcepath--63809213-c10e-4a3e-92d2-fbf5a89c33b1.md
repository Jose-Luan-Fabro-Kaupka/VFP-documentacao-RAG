# Função FORCEPATH( )

Retorna um nome de arquivo com um novo nome de caminho substituído pelo antigo.

```foxpro
FORCEPATH(cFileName, cPath)
```

#### Parâmetros
 **cFileName**
Especifica o nome do arquivo (com ou sem caminho ou extensão), que receberá um novo caminho.
**cPath**
Especifica o novo caminho para cFileName .

# Valor de retorno

Character
