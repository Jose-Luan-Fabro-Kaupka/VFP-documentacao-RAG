# Função ROUND( )

Retorna uma expressão numérica arredondada para o número especificado de casas decimais.

```foxpro
ROUND(nExpression, nDecimalPlaces)
```

#### Parâmetros
 **nExpression**
Especifica a expressão numérica cujo valor deve ser arredondado.
**nDecimalPlaces**
Especifica o número de casas decimais para o qual nExpression é arredondada. Se nDecimalPlaces for negativo, ROUND( ) retornará um número inteiro contendo à esquerda da vírgula uma quantidade de zeros igual a nDecimalPlaces. Por exemplo, se nDecimalPlaces for –2, o primeiro e o segundo dígitos à esquerda da vírgula no valor serão 0.

# Valor de retorno

Tipo de dados Numeric. ROUND( ) retorna um valor arredondado para a posição decimal mais próxima, conforme especificado por nDecimalPlaces.

# Observações

ROUND( ) ignora o número de casas decimais especificado pelo comando SET DECIMALS. Para exibir mais casas decimais que o especificado por nDecimalPlaces em ROUND( ), use SET FIXED ON com SET DECIMALS.

# Exemplo

O exemplo a seguir especifica que os valores resultantes sejam exibidos com quatro casas decimais usando os comandos SET DECIMALS e SET FIXED. Ele limpa a janela principal do Visual FoxPro usando CLEAR, executa operações de arredondamento com ROUND( ) e exibe os resultados usando o comando ?. Por fim, restaura os valores padrão de inicialização usando SET FIXED e SET DECIMALS.

```foxpro
SET DECIMALS TO 4
SET FIXED ON
CLEAR
? ROUND(1234.1962, 3) && Displays 1234.1960
? ROUND(1234.1962, 2) && Displays 1234.2000
? ROUND(1234.1962, 0) && Displays 1234.0000
? ROUND(1234.1962, -1)  && Displays 1230.0000
? ROUND(1234.1962, -2)  && Displays 1200.0000
? ROUND(1234.1962, -3)  && Displays 1000.0000
SET FIXED OFF
SET DECIMALS TO 2
```
