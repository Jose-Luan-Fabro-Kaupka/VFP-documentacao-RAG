# Comando MOVE POPUP

Move um menu definido pelo usuário, criado com DEFINE POPUP, para um novo local.

```foxpro
MOVE POPUP MenuName TO nRow1, nColumn1 | BY nRow2, nColumn2
```

#### Parâmetros
 **MenuName**
Especifica o menu a mover. No Visual FoxPro, não é possível mover o menu do sistema.
**TO nRow1 , nColumn1**
Move o menu para um local, especificado por nRow1 e nColumn1, em uma janela definida pelo usuário ou na janela principal do Visual FoxPro.
**BY nRow2 , nColumn2**
Move o menu para um local relativo à sua posição atual. nRow2 especifica o número de linhas do deslocamento (para baixo se positivo, para cima se negativo). nColumn2 especifica o número de colunas (para a direita se positivo, para a esquerda se negativo).

# Observações

Um menu pode ser movido para uma posição específica ou em relação à posição atual. Se tiver sido definido, poderá ser movido; ele não precisa estar ativo nem visível.

# Exemplo

O exemplo a seguir define e ativa um menu e, em seguida, o move e altera seu tamanho.

```foxpro
CLOSE DATABASE
CLEAR
DEFINE POPUP popMovIn FROM 2,2 TO 7, 14 PROMPT FILES LIKE *.PRG ;
   TITLE 'Programs'
ACTIVATE POPUP popMovIn NOWAIT
=CHRSAW(2)
MOVE POPUP popMovIn BY 5,5     && Move menu down
=CHRSAW(2)
SIZE POPUP popMovIn BY 5,5     && Enlarge the menu
=CHRSAW(2)
SIZE POPUP popMovIn BY -5,-5     && Shrink the menu
=CHRSAW(2)
MOVE POPUP popMovIn BY -5,-5     && Move menu up
=CHRSAW(2)
DEACTIVATE POPUP popMovIn
RELEASE POPUP popMovIn
```
