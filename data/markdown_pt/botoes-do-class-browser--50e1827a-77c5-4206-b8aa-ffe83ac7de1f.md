# Botões do Class Browser

Os seguintes botões estão disponíveis no Class Browser. Para obter mais informações, consulte Class Browser Window e Operating the Class Browser.
 **Component Gallery**
Alterna entre o Class Browser e o Component Gallery para gerenciar itens de foundation class.
**Open**
Abre um arquivo de biblioteca de classes (.vcx) existente, cria novos arquivos de biblioteca de classes e de biblioteca de tipos, ou abre um arquivo de formulário/form set (.scx) existente.
**View Additional File**
Adiciona um arquivo de biblioteca de classes (.vcx) existente ou um arquivo de formulário ou form set (.scx) à lista de classes, ou cria um novo arquivo de biblioteca de classes. Para listar os arquivos abertos mais recentemente no Class Browser, clique com o botão direito no botão View Additional File.
**View Class Code**
Exibe o código de definição da classe em um arquivo de programa (.prg) para a classe selecionada. A classe abre como somente leitura, e você não pode salvar alterações feitas na classe. No entanto, você pode salvar o código em outro arquivo.
**Find**
Pesquisa texto especificado em nomes de classes, descrições de classes, nomes de membros e descrições de membros.
**New Class**
Cria uma subclasse da classe selecionada ou de qualquer classe existente.
**Rename**
Altera o nome da classe, propriedade ou método selecionado. Cuidado Renomear uma classe pode invalidar formulários ou classes que não estão atualmente exibidos em janelas do Class Browser e que dependem da classe. Alterar o nome de uma propriedade ou método pode fazer com que o código que referencia a propriedade ou o método falhe.
**Redefine**
Altera a classe pai da classe selecionada.
**Clean Up Class Library**
Executa o comando PACK para remover registros no arquivo .vcx marcados para exclusão. Para obter mais informações, consulte PACK Command .
