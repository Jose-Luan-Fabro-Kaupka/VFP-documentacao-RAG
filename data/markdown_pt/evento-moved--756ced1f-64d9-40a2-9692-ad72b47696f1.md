# Evento Moved

Ocorre quando um objeto é movido para uma nova posição ou quando as configurações das propriedades Top ou Left de um objeto contêiner foram alteradas programaticamente.

```foxpro
PROCEDURE Object.Moved
```

# Observações

Aplica-se a: Column Object | Container Object | Control Object (Visual FoxPro) | Form Object | Grid Control | OLE Bound Control | OLE Container Control | PageFrame Control | ToolBar Object

Ocorre quando um objeto é movido para uma nova posição ou quando as configurações das propriedades Top ou Left foram alteradas no código.
