# Referential Integrity Builder

O Referential Integrity (RI) Builder ajuda você a criar um conjunto de regras que controlam como os registros são inseridos, atualizados ou excluídos em tabelas relacionadas. O RI Builder gera código para essas regras como triggers que referenciam stored procedures. Para obter mais informações, consulte How to: Build Referential Integrity Between Tables.

# Guias do Builder
 **Rules for Updating**
Especifica regras a aplicar quando o valor da chave na tabela pai é modificado.
**Rules for Deleting**
Especifica regras a aplicar quando um registro na tabela pai é excluído.
**Rules for Inserting**
Especifica regras a aplicar quando um novo registro é inserido ou um registro existente é atualizado na tabela filha.

Para obter mais informações, consulte Developing Databases e Trigger Usage.
