# Membros de objetos da Component Gallery

A Component Gallery é composta por uma interface, cujas classes estão em Vfpglry.vcx, e por itens que fazem referência às seguintes classes base do Visual FoxPro.

| Objeto | Descrição | Biblioteca de classes |
| --- | --- | --- |
| About Dialog Box | Fornece uma caixa de diálogo About simples para aplicativos personalizados. | _dialogs.vcx |
| ActiveX Calendar | Controle de calendário que pode ser vinculado a um campo de data. | _datetime.vcx |
| Application Registry | Fornece funções de registro que retornam informações específicas do aplicativo. | Registry.vcx |
| Array Handler | Fornece métodos para operações com matrizes não realizadas pelas funções nativas. | _utility.vcx |
| Cancel Button | Libera um formulário e descarta dados armazenados em buffer ainda pendentes. | _miscbtns.vcx |
| Clock | Controle de relógio simples para formulário ou contêiner. | _datetime.vcx |
| Conflict Catcher | Caixa de diálogo para resolver conflitos de linhas durante edição com buffering otimista. | _dataquery.vcx |
| Cookies | Classe Web simples para tratar cookies entre páginas Web. | _internet.vcx |
| Cross Tab | Gera uma tabela de referência cruzada. | _utility.vcx |
| Data Edit Buttons | Conjunto completo de botões de edição, como os usados pelos Form Wizards. | Wizbtns.vcx |
| Data Navigation Buttons | Grupo de botões Top, Next, Prev e Bottom e classe DataChecker para verificar conflitos ao mover registros. | _datanav.vcx |
| Data Navigation Object | Objeto de navegação não visual que pode ser usado por outras classes. | _table.vcx |
| Data Session Manager | Gerencia sessões de dados e atualizações de dados. | _app.vcx |
| Data Validation | Detecta conflitos em dados armazenados em buffer. | _datanav.vcx |
| DBF -> HTML | Converte um cursor (.dbf) do Visual FoxPro em HTML. | _internet.vcx |
| Distinct Values Combo | Pesquisa valores exclusivos no campo ControlSource para preencher uma caixa de combinação. | _dataquery.vcx |
| Error Object | Manipulador genérico de erros para código orientado a objetos e procedural. | _app.vcx |
| Field Mover | Caixa de listagem supermover que carrega automaticamente campos da fonte de dados atual. | _movers.vcx |
| File Version | Recupera informações do recurso de versão de um arquivo. | _utility.vcx |
| Filter Button | Exibe uma caixa de diálogo para especificar um filtro de dados em determinado campo. | _table2.vcx |
| Filter Dialog | Permite especificar condições de filtro nos dados. | _table.vcx |
| Filter Expression Dialog | Cria uma caixa de diálogo avançada de expressão de filtro. | _table.vcx |
| Find (Findnext) Buttons | Conjunto genérico de botões find/findnext. | _table.vcx |
| Find Button | Localiza um registro com base em critérios específicos. | _table.vcx |
| Find Dialog | Caixa de diálogo de pesquisa com opções simples, como escolha de campo. | _table.vcx |
| Find Files/Text | Usa o objeto COM Filer.DLL para procurar arquivos. | _utility.vcx |
| Find Object | Cria um objeto genérico que localiza um registro conforme os critérios especificados. | _table.vcx |
| Font Combobox | Caixa de combinação que lista as fontes disponíveis; também usada pelas classes tbrEditing e rtfControls. | _format.vcx |
| Fontsize Combobox | Caixa de combinação que lista tamanhos de fonte; também usada pelas classes tbrEditing e rtfControls. | _format.vcx |
| Format Toolbar | Barra de ferramentas para aplicar formatação de fonte ao texto do controle ativo. | _format.vcx |
| FRX -> HTML | Converte uma saída de relatório (.frx) do Visual FoxPro em HTML. | _internet.vcx |
| GetFile and Directory | Recupera o nome de um arquivo e de uma pasta. | _controls.vcx |
| Goto Dialog Box Button | Cria um botão que exibe a caixa de diálogo Goto. | _table2.vcx |
| Goto Dialog Box | Cria uma caixa de diálogo para ir a um registro. | _table.vcx |
| Graph By Record Object | Grupo de botões de navegação que permite atualizar dinamicamente um novo gráfico por registro. | _utility.vcx |
| Graph Object | Gera um gráfico usando o mecanismo principal do Graph Wizard. | Autgraph.vcx |
| Help Button | Exibe o arquivo de Ajuda ao iniciar a pesquisa do HelpContextID especificado. | _miscbtns.vcx |
| Hyperlink Button | Inicia um navegador Web a partir de um botão. | _hyperlink.vcx |
| Hyperlink Image | Inicia um navegador Web a partir de uma imagem. | _hyperlink.vcx |
| Hyperlink Label | Inicia um navegador Web a partir de um rótulo. | _hyperlink.vcx |
| INI Access | Funções de registro que acessam configurações antigas de arquivos INI. | Registry.vcx |
| Item Locator | Botão que abre uma caixa de diálogo para localizar um registro. | _dialogs.vcx |
| Keywords Dialog | Cria uma caixa de diálogo como a de palavras-chave da Component Gallery. | _dialogs.vcx |
| Launch Button | Inicia um aplicativo com um documento opcional. | _miscbtns.vcx |
| Locate Button | Exibe uma caixa de diálogo para localizar um registro. | _table2.vcx |
| Lookup Combobox | Pesquisa valores em um campo para preencher uma caixa de combinação. | _dataquery.vcx |
| Mail Merge Object | Gera uma mala direta do Word usando o mecanismo principal do Mail Merge Wizard. | Mailmerge.vcx |
| Messagebox Handler | Wrapper simples para a função MessageBox. | _dialogs.vcx |
| MouseOver Effects | Realça um controle quando o mouse passa sobre ele. | _ui.vcx |
| Mover | Fornece uma classe simples de caixa de listagem com botões para mover/remover. | _movers.vcx |
| Navigation Shortcut Menu | Menu de atalho que pode ser inserido em um formulário. | _table2.vcx |
| Navigation Toolbar | Conjunto de botões de navegação em uma barra de ferramentas. | _table2.vcx |
| Object State | Determina o estado de um objeto e salva/restaura as configurações de suas propriedades. | _app.vcx |
| ODBC Registry | Funções de registro que retornam informações específicas de ODBC. | Registry.vcx |
| Offline Switch | Fornece uma exibição de dados online para uso offline. | _dataquery.vcx |
| OK Button | Executa uma liberação simples de formulário. | _miscbtns.vcx |
| Output Control | Exibe uma caixa de diálogo complexa que solicita uma opção de saída de relatório. | _reports.vcx |
| Output Dialog | Exibe uma caixa de diálogo que solicita uma opção de saída de relatório. | _reports.vcx |
| Output Object | Fornece várias opções de saída de relatório. | _reports.vcx |
| Password Dialog | Caixa de diálogo Password simples para aplicativos personalizados. | _dialogs.vcx |
| Pivot Table | Gera uma tabela dinâmica do Microsoft Excel usando o mecanismo principal do PivotTable Wizard. | Pivtable.vcx |
| Preview Report | Botão genérico para executar um relatório. | _miscbtns.vcx |
| QBF | Fornece um conjunto de botões para consultas Query-By-Form. | _dataquery.vcx |
| Registry Access | Fornece acesso a informações no Registro do Windows. | registry.vcx |
| Resize Object | Faz os objetos do formulário mudarem de tamanho ou posição com o evento Resize do formulário. | _controls.vcx |
| RTF Controls | Fornece botões para aplicar formatação de fonte ao texto do controle ativo. | _format.vcx |
| Run Form Button | Botão que executa um formulário. | _miscbtns.vcx |
| SCX -> HTML | Converte um formulário .scx em HTML. | _internet.vcx |
| SendMail Buttons | Usa o controle ActiveX MAPI para enviar uma mensagem de email de um formulário. | _miscbtns.vcx |
| Shell Execute | Fornece o comportamento de clique duplo do Windows Explorer. | _environ.vcx |
| Shortcut Menu Class | Classe wrapper que cria dinamicamente menus pop-up de atalho. | _menu.vcx |
| Simple Edit Buttons | Botões simples Add, Edit, Delete, Duplicate, Save e Cancel, como os usados pelos Form Wizards. | Wizbtns.vcx |
| Simple Navigation Buttons | Fornece botões de navegação Next e Previous. | _table.vcx |
| Simple Picture Navigation Buttons | Conjunto de botões simples de navegação com imagens. | _table2.vcx |
| Sort Button | Exibe uma caixa de diálogo para ordenar dados de um campo em ordem crescente ou decrescente. | _table2.vcx |
| Sort Dialog | Permite ordenar dados de um campo em ordem crescente ou decrescente. | _table2.vcx |
| Sort Mover | Subclasse da caixa de listagem supermover que trata automaticamente a ordenação de dados. | _movers.vcx |
| Sort Object | Ordena uma fonte de dados. | _table.vcx |
| Sort Selector | Executa ordenação crescente ou decrescente com base no controle atual. | _table2.vcx |
| Sound Player | Carrega e reproduz um arquivo de som. | _multimedia.vcx |
| Splash Screen | Fornece uma tela de abertura simples para aplicativos personalizados. | _dialogs.vcx |
| SQL Pass Through | Fornece SQL Pass-Through e permite executar procedimentos armazenados no banco de dados host. | _dataquery.vcx |
| Stop Watch | Fornece um controle de cronômetro para formulário ou contêiner. | _datetime.vcx |
| String Library | Executa várias conversões de cadeias de caracteres. | _utility.vcx |
| Super Mover | Fornece botões Move, Remove, Moveall e Removeall. | _movers.vcx |
| System Toolbars | Classe gerenciadora que controla e acompanha Systoolbars. | _app.vcx |
| Table Mover | Subclasse de supermover que carrega automaticamente tabelas e campos da fonte de dados atual. | _movers.vcx |
| Text Preview | Fornece um visualizador de texto de saída. | _reports.vcx |
| Thermometer | Fornece uma classe padrão de termômetro. | _controls.vcx |
| Trace Aware Timer | Utilitário que determina se a janela Trace está aberta. | _app.vcx |
| Type Library | A rotina principal ExportTypeLib cria um arquivo de texto com a saída Typelib. | _utility.vcx |
| URL Combo | Cria uma caixa de combinação para digitar uma URL, inicia o Microsoft Internet Explorer e navega até o site. | _internet.vcx |
| URL Open Dialog | Fornece uma caixa de diálogo com lista suspensa que armazena o histórico de URLs. | _internet.vcx |
| VCR Buttons | Grupo de botões de navegação Top, Next, Prev e Bottom. | _table.vcx |
| VCR Picture Navigation Buttons | Conjunto de botões de navegação VCR com imagens. | _table2.vcx |
| Video Player | Carrega e reproduz um arquivo de vídeo usando comandos MCI. | _multimedia.vcx |
| Web Browser control | Subclasse do controle Browser do Internet Explorer 4.0 que fornece ganchos para código do Visual FoxPro. | _webview.vcx |
| Window Handler | Executa várias operações comuns de janela típicas de aplicativos. | _ui.vcx |
