# Atualizando dados

Para atualizar dados, você pode usar buffers, transações ou views.

# Nesta seção
 **How to: Perform Updates Using Buffers**
Explica como habilitar buffer de registro ou de tabela, após escolher o tipo de método de buffer e o tipo de bloqueio.
**Managing Updates Using Transactions**
Descreve transações e como usá-las para proteger operações de atualização e usar transações para recuperar de uma seção inteira de código como uma unidade.
**Managing Updates by Using Views**
Discute o uso de views para gerenciar conflitos de dados em ambientes multiusuário.

# Referência
 **TABLEUPDATE( ) Function**
Confirma alterações feitas em uma linha em buffer, uma tabela em buffer, cursor ou cursor adapter.
**TABLEREVERT( ) Function**
Descarta alterações feitas em uma linha em buffer ou em uma tabela ou cursor em buffer e restaura os dados OLDVAL( ) para cursors remotos e os valores atuais em disco para tabelas e cursors locais.
