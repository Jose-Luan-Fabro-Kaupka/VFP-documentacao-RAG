# Construtor DataEnvironment

O Construtor DataEnvironment permite que você crie objetos DataEnvironment que usam os recursos dos objetos CursorAdapter. Você pode abrir o Construtor DataEnvironment no Form Designer ou Class Designer.

 Para abrir o Construtor DataEnvironment
 - Crie um novo formulário ou abra um formulário existente.
- No Form Designer , clique com o botão direito no formulário e clique em DataEnvironment . Para um formulário com um objeto DataEnvironment vazio, a caixa de diálogo Abrir aparece.
- Na caixa de diálogo Abrir, clique em Cancelar .
- Clique com o botão direito na superfície Data Environment e clique em Builder .

Agora você pode usar o construtor para criar objetos DataEnvironment.

Você também pode abrir o Construtor DataEnvironment clicando com o botão direito em uma classe DataEnvironment nova ou existente no Class Designer e selecionando Builder.

# Guias do construtor

Guia Data Source, Construtor DataEnvironment

Especifica o tipo de fonte de dados e a fonte de dados para o objeto DataEnvironment.

Guia Cursors, Construtor DataEnvironment

Adiciona, cria ou remove objetos CursorAdapter do objeto DataEnvironment. Você também pode abrir o Construtor CursorAdapter para editar objetos CursorAdapter existentes.
