# Exemplos de servidor (Visual FoxPro)

O Visual FoxPro inclui vários exemplos, que se concentram em servidores de automação. Um servidor de automação é um aplicativo de componente COM que expõe funcionalidade que pode ser usada e reutilizada por outros aplicativos por meio de automação. Além disso, você pode criar uma ou mais classes para tratar regras de negócios em toda a empresa. Um aplicativo cliente que usa o objeto de regra de negócios passaria parâmetros de entrada em uma chamada de método, e o servidor de automação poderia então realizar muito trabalho, recuperando ou armazenando dados de várias fontes e executando cálculos complexos, antes de retornar a resposta.

# Nesta seção
 **FoxISAPI Automation Server Samples**
Descreve a extensão ISAPI do Visual FoxPro que permite acessar servidores de automação personalizados do Visual FoxPro de qualquer servidor Web compatível com ISAPI, como o Microsoft Internet Information Services (IIS) versão 5.0 ou posterior e o Microsoft Personal Web Server.
**COM+ Samples**
Descreve exemplos para usar Queued Components, COM+ Events e Compensation Resource Managers.
