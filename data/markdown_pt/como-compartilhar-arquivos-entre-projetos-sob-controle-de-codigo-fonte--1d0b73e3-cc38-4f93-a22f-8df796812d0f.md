# Como: compartilhar arquivos entre projetos sob controle de código-fonte

Você pode configurar um arquivo para pertencer simultaneamente a dois ou mais projetos sob controle de código-fonte. Isso é útil para arquivos comuns, como programas, bibliotecas ou caixas de diálogo padrão. Alterações submetidas ao arquivo são refletidas em todos os projetos que o compartilham.

O método específico depende do software de controle de código-fonte. Se o provedor não oferecer opções de compartilhamento, os comandos correspondentes não estarão disponíveis no menu.

A primeira etapa a seguir se aplica a todos os sistemas compatíveis; as demais podem variar.

### Para compartilhar arquivos entre projetos controlados
- No menu Project, escolha Source Control e Share Files.
- Na caixa exibida, indique os arquivos a compartilhar com o projeto atual e o projeto ao qual pertencem. As opções dependem do sistema. Para detalhes, escolha Help na caixa Share ou consulte a documentação. Dica: no Microsoft Visual SourceSafe, use Project Properties e a guia Links para ver a quais projetos um arquivo pertence. Para mapear corretamente um projeto adicionado ao Visual SourceSafe, todos os seus arquivos devem estar no diretório ou caminho do projeto.
