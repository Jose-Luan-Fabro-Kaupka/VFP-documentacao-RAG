# Operadores de data e hora

Os operadores a seguir atuam em datas e horas.
 Operadores de data e hora
| Operador | Ação | Código |
| --- | --- | --- |
| + | Adição | tNewTime = tTime1 + nSeconds dNewDate = dDate1 + nDays |
| - | Subtração | nSeconds = tTime1 - tTime2 tNewTime = tTime1 - nSeconds dNewDate = dDate1 - nDays |
