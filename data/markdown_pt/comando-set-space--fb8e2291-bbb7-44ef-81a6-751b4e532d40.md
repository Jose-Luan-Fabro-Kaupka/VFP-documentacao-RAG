# Comando SET SPACE

Determina se um espaço é exibido entre campos ou expressões quando você usa o comando ? ou ??.

```foxpro
SET SPACE ON | OFF
```

#### Parâmetros
 **ON**
(Padrão) Insere um espaço entre campos e expressões.
**OFF**
Remove todos os espaços entre campos ou expressões e os concatena.
