# Função ISLOWER( )

Determina se o caractere mais à esquerda da expressão de caracteres especificada é um caractere alfabético minúsculo.

```foxpro
ISLOWER(cExpression)
```

#### Parâmetros
 **cExpression**
Especifica a expressão de caracteres testada por ISLOWER( ). ISLOWER( ) ignora todos os caracteres posteriores ao primeiro caractere de cExpression.

# Valor de retorno

Logical

# Observações

ISLOWER( ) retorna verdadeiro (.T.) se o caractere mais à esquerda da expressão de caracteres especificada for um caractere alfabético minúsculo; caso contrário, ISLOWER( ) retorna falso (.F.).

# Exemplo

```foxpro
CLEAR
? ISLOWER('redmond')  && Displays .T.
? ISLOWER('Redmond')  && Displays .F.
```
