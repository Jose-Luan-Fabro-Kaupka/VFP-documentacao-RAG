# Caixa de Diálogo Avançado

Esta caixa de diálogo faz parte do assistente Publicação na Web e permite especificar características adicionais para sua página Web. Ela é exibida a partir do botão Avançado da Etapa 3. Você pode especificar formatação e objetos de folhas de estilo em cascata (.css) e adicionar itens HTML adicionais que podem incluir cabeçalhos, texto ou outros itens e características de página Web.

 Para acessar a caixa de diálogo Avançado
 - No menu Ferramentas, escolha Assistentes , e depois clique em Publicação na Web .
- Navegue pelo assistente até chegar à Etapa 3.
- Clique em Avançado .
 **Folha de estilo em cascata**
Este controle permite especificar ou localizar um arquivo de folha de estilo em cascata (.css) para usar em sua página Web.
**Corpo**
Cor Esta caixa de listagem suspensa permite especificar uma cor da lista para usar como fundo do corpo. Esta opção substitui qualquer cor especificada no layout de dados ou estilo visual selecionado. Imagem Esta caixa de texto permite especificar ou localizar um arquivo de imagem para exibir em sua página Web.
**Copiar gráficos para o local de saída HTML**
Esta caixa de seleção permite especificar que quaisquer arquivos gráficos usados em seu layout de dados ou estilo visual sejam copiados para o mesmo local que seu arquivo de página Web.
**Salvar Configurações**
Este botão permite manter suas alterações de estilo visual em um arquivo para usar posteriormente.
**Carregar Configurações**
Este botão permite acessar um layout salvo ou remover um layout salvo que você não deseja mais.
**Itens HTML Adicionais**
Esta seção permite adicionar tags HTML para formatação, texto e referências à sua página Web.
**Adicionar**
Este botão abre a caixa de diálogo Item HTML, para que você possa especificar itens HTML adicionais e formatação para sua página Web. Para obter mais informações, consulte Caixa de Diálogo Item HTML .
**Editar**
Este botão abre a caixa de diálogo Item HTML, para que você possa editar o item HTML selecionado para sua página Web. Para obter mais informações, consulte Caixa de Diálogo Item HTML .
**Remover**
Este botão permite excluir o item HTML selecionado de sua página Web.
