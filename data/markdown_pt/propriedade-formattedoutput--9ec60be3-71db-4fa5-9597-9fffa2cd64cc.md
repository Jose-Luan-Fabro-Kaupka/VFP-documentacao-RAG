# Propriedade FormattedOutput

Gera XML como saída formatada ou como uma única cadeia de caracteres contínua.

FormattedOutput se aplica ao executar o método ToXML do XMLAdapter, que cria XML consistente com sua configuração.

```foxpro
XMLAdapter.FormattedOutput [= lValue]
```

# Valor de retorno
 **lValue**
Tipo de dados lógico. A tabela a seguir lista os valores para lValue . lValue Descrição True (.T.) Exibe o XML como saída formatada. (Padrão) False (.F.) Exibe a saída XML como uma única cadeia de caracteres contínua.
