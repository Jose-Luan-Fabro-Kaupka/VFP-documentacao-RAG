# Ambiente (Visual FoxPro)

Estes comandos e funções permitem gerenciar uma ampla variedade de parâmetros do sistema e do ambiente do Microsoft Visual FoxPro.

| Use | Para |
| --- | --- |
| Função ADIR( ) | Colocar informações sobre arquivos em uma matriz e retornar o número de arquivos. |
| Função ADLLS( ) | Retornar uma matriz contendo os nomes das funções carregadas por DECLARE DLLs. |
| Função ALANGUAGE( ) | Retornar uma matriz contendo os nomes de todos os comandos, funções ou classes base válidos do Visual FoxPro. |
| Função APROCINFO( ) | Criar uma matriz contendo elementos da linguagem Visual FoxPro presentes em um arquivo de programa. |
| Função ASESSIONS( ) | Criar uma matriz de IDs de sessões de dados existentes. |
| Função ASTACKINFO( ) | Criar uma matriz e preenchê-la com informações sobre o estado atual da pilha de chamadas. |
| Variável de sistema _BROWSER | Especificar o nome do aplicativo Class Browser. |
| Variável de sistema _BUILDER | Especificar o nome do aplicativo Builder do Visual FoxPro. |
| Função CAPSLOCK( ) | Retornar o modo atual da tecla CAPS LOCK ou ativar ou desativar esse modo. |
| Comando CREATE COLOR SET | Criar um conjunto de cores a partir das configurações de cor atuais. |
| Comando CREATE VIEW | Criar um arquivo de exibição a partir do ambiente do Visual FoxPro. |
| Propriedades CurrentX e CurrentY | Especificar as coordenadas horizontal (X) e vertical (Y) do próximo método de desenho. Indisponíveis em tempo de design; leitura/gravação em tempo de execução. |
| Comando DECLARE - DLL | Registrar uma função em uma biblioteca compartilhada externa. |
| Comando DIR ou DIRECTORY | Exibir informações sobre os arquivos de um diretório. |
| Função DISKSPACE( ) | Retornar o número de bytes disponíveis na unidade de disco ou no volume padrão ou especificado. |
| Comando DISPLAY DLLS | Exibir informações sobre funções de bibliotecas compartilhadas registradas no Visual FoxPro com DECLARE – DLL. |
| Comando DISPLAY STATUS | Exibir o estado do ambiente do Visual FoxPro. |
| Função FKLABEL( ) | Retornar o nome da tecla de função (F1, F2, F3...) a partir de seu número correspondente. |
| Função FKMAX( ) | Retornar o número de teclas de função programáveis ou combinações dessas teclas disponíveis no teclado. |
| Função FONTMETRIC( ) | Retornar atributos de fonte para as fontes atualmente instaladas no sistema operacional. |
| Variável de sistema _GALLERY | Especificar o programa executado quando você escolhe Component Gallery no menu Tools. |
| Variável de sistema _GENHTML | Especificar um programa de geração de HTML (Hypertext Markup Language). |
| Função GETCOLOR( ) | Exibir a caixa de diálogo Color do Windows e retornar o número da cor escolhida. |
| Função GETCP( ) | Solicitar uma página de código exibindo a caixa de diálogo Code Page e retornar o número da página escolhida. |
| Função GETENV( ) | Retornar o conteúdo da variável de ambiente MS-DOS especificada. |
| Variável de sistema _GETEXPR | Especificar o programa executado quando você emite o comando GETEXPR ou abre a caixa de diálogo Expression Builder no Visual FoxPro. |
| Função GETFILE( ) | Exibir a caixa de diálogo Open e retornar o nome do arquivo escolhido. |
| Função GETFONT( ) | Exibir a caixa de diálogo Font e retornar informações sobre a fonte escolhida. |
| Função GETPEM( ) | Retornar, em tempo de design, o valor atual de uma propriedade ou o código de programa de um evento ou método. |
| Função HOME( ) | Retornar os nomes dos diretórios do Visual FoxPro e do Visual Studio. |
| Comando HELP | Abrir a janela Help. |
| Função IMESTATUS( ) | Ativar ou desativar a janela IME (Input Method Editor) ou retornar o estado atual do IME. |
| Variável de sistema _INCLUDE | Especificar um arquivo de cabeçalho padrão incluído com classes, formulários ou conjuntos de formulários definidos pelo usuário. |
| Função INKEY( ) | Retornar um número correspondente ao primeiro clique do mouse ou pressionamento de tecla no buffer de digitação antecipada. |
| Função INSMODE( ) | Retornar o modo de inserção atual ou ativá-lo ou desativá-lo. |
| Função ISCOLOR( ) | Determinar se um computador pode exibir cores. |
| Função ISMOUSE( ) | Retornar true (.T.) se houver hardware de mouse presente. |
| Comando LIST DLLS | Exibir continuamente informações sobre funções de bibliotecas compartilhadas registradas no Visual FoxPro com DECLARE - DLL. |
| Comandos LIST | Exibir informações da tabela ou do ambiente sem pausar a janela principal do Visual FoxPro ou uma janela definida pelo usuário. Há várias versões da sintaxe. |
| Função LOCFILE( ) | Localizar um arquivo no disco e retornar seu nome com o caminho. |
| Função MEMORY( ) | Retornar a quantidade de memória disponível para executar um programa externo. |
| Função MESSAGE( ) | Retornar a mensagem de erro atual como uma cadeia de caracteres ou o conteúdo da linha do programa que causou o erro. |
| Função NUMLOCK( ) | Retornar o modo atual da tecla NUM LOCK ou ativá-lo ou desativá-lo. |
| Variável de sistema _ObjectBrowser | Conter o nome do aplicativo Object Browser. |
| Função OBJTOCLIENT( ) | Retornar uma posição ou dimensão de um controle ou objeto em relação ao seu formulário. |
| Função OS( ) | Retornar o nome e o número da versão do sistema operacional no qual o Visual FoxPro está sendo executado. |
| Função PCOL( ) | Retornar a posição atual da coluna da cabeça de impressão. |
| Função PEMSTATUS( ) | Obter um atributo de uma propriedade, evento, método ou objeto. |
| Função PROW( ) | Retornar o número atual da linha da cabeça de impressão. |
| Função PUTFILE( ) | Abrir a caixa de diálogo Save As e retornar o nome de arquivo especificado. |
| Comando QUIT | Encerrar a sessão atual do Visual FoxPro e devolver o controle ao sistema operacional. |
| Função RGB( ) | Retornar um único valor de cor a partir de componentes vermelho, verde e azul. |
| Função SCHEME( ) | Retornar uma lista de pares de cores ou um único par de um esquema de cores especificado. |
| Variável de sistema _SCREEN | Especificar propriedades e métodos da janela principal do Visual FoxPro. |
| Função SET( ) | Retornar o estado de vários comandos SET. |
| Comandos SET | Abrir a janela Data Session. Essa janela oferece uma maneira fácil de abrir tabelas, estabelecer relações ou definir e alterar várias opções do Visual FoxPro. |
| SYS(3) - Legal File Name | Retornar um nome de arquivo válido que possa ser usado para criar arquivos temporários. |
| SYS(5) - Default Drive | Retornar a unidade padrão atual do Visual FoxPro. |
| SYS(6) - Current Printer Device | Retornar a unidade padrão atual do Visual FoxPro. |
| SYS(7) - Current Format File | Retornar o nome do arquivo de formato atual. |
| SYS(9) - Visual FoxPro Serial Number | Retornar o número de série do Visual FoxPro. |
| SYS(12) - Available Memory in Bytes | Retornar a quantidade de memória abaixo de 640K disponível para executar um programa externo. |
| SYS(16) - Executing Program File Name | Retornar o nome do arquivo do programa em execução. Você pode usar SYS(16) para se recuperar de erros. |
| SYS(17) - Processor in Use | Retornar a unidade central de processamento (CPU) em uso. |
| SYS(1001) - Visual FoxPro Memory | Retornar a quantidade total de memória disponível para o gerenciador de memória do Visual FoxPro. |
| SYS(1016) - User Object Memory Use | Retornar a quantidade de memória usada pelos objetos definidos por você. |
| SYS(1023) - Enable Help Diagnostic Mode | Ativar o modo de diagnóstico da Ajuda, permitindo interceptar o HelpContextID passado ao sistema de Ajuda do Visual FoxPro. |
| SYS(1024) - Disable Help Diagnostic Mode | Desativar o modo de diagnóstico da Ajuda ativado por SYS(1023). |
| SYS(1269) - Property Information | Retornar um valor que indica se uma configuração de propriedade foi alterada em relação ao padrão ou se a propriedade é somente leitura. |
| SYS(1270) - Object Location | Retornar uma referência para um objeto no ponto especificado. |
| SYS(1271) - Object's .SCX File | Retornar o nome do arquivo .SCX em que o objeto instanciado especificado está armazenado. |
| SYS(1272) - Object Hierarchy | Retornar a hierarquia de objetos de um objeto especificado. Indisponível em tempo de design. |
| SYS(2001) - SET ... Command Status | Retornar o estado dos comandos SET especificados. |
| SYS(2003) - Current Directory | Retornar o nome do diretório atual na unidade padrão. |
| SYS(2004) - Visual FoxPro Start Directory | Retornar o nome do diretório a partir do qual o Visual FoxPro foi iniciado. |
| SYS(2005) - Current Resource File | Retornar o nome do arquivo de recursos atual do Visual FoxPro. |
| SYS(2006) - Current Graphics Card | Retornar o tipo de placa gráfica e monitor em uso. |
| SYS(2010) - CONFIG.SYS File Settings | Retornar a configuração de arquivos em CONFIG.SYS. |
| SYS(2013) - System Menu Name String | Retornar uma cadeia de caracteres delimitada por espaços contendo os nomes internos do sistema de menus do Visual FoxPro. |
| SYS(2019) - Configuration File Name and Location | Retornar o nome e o local do arquivo de configuração do Visual FoxPro. |
| SYS(2020) - Default Disk Free Space | Retornar o espaço livre, em bytes, no disco padrão. |
| SYS(2022) - Disk Cluster Size | Retornar o tamanho do cluster, em bytes, de um disco especificado. |
| SYS(2023) - Temporary Path | Retornar o caminho em que o Visual FoxPro armazena seus arquivos temporários. |
| SYS(2334) - Automation Server Invocation Mode | Retornar um valor que indica como um método de servidor de Automation do Visual FoxPro foi chamado. |
| SYS(2800) - Accessibility Support | Desativar ou ativar o suporte ao Microsoft Active Accessibility e definir opções para acompanhar o foco do teclado no controle atualmente selecionado em um formulário do Visual FoxPro. |
| SYS(3004) - Return Locale ID | Retornar o ID de localidade usado por controles de Automation e ActiveX. |
| SYS(3005) - Set Locale ID | Definir o ID de localidade usado por controles de Automation e ActiveX. |
| SYS(3006) - Set Language and Locale IDs | Definir o ID de idioma e o ID de localidade. |
| SYS(3050) - Set Buffer Memory Size | Definir o tamanho da memória de buffer em primeiro ou segundo plano. |
| SYS(3053) - ODBC Environment Handle | Retornar o identificador do ambiente ODBC. |
| SYS(3056) - Read Registry Settings | Ler as configurações do Registro do Visual FoxPro e atualizá-las com as configurações atuais do Registro. |
| SYS(3095) - IDispatch Pointer | Retornar um ponteiro IDispatch de saída para um objeto COM. |
| Função SYSMETRIC( ) | Retornar o tamanho dos elementos da tela do sistema operacional. |
| Variável de sistema _TASKLIST | Conter o nome do programa gerenciador da lista de tarefas. |
| Função TXTWIDTH( ) | Retornar o comprimento de uma expressão de caracteres em relação à largura média dos caracteres de uma fonte. |
| Função VERSION( ) | Retornar informações sobre a versão do Visual FoxPro em uso. |
| Função WFONT( ) | Retornar o nome, tamanho ou estilo da fonte atual de uma janela no Visual FoxPro para Windows. |
| Variável de sistema _WIZARD | Conter o nome do aplicativo Wizard do Visual FoxPro. |
