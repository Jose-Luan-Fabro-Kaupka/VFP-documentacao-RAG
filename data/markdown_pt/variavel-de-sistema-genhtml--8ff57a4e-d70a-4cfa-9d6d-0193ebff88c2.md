# Variável de sistema _GENHTML

Especifica um programa de geração de HTML (Hypertext Markup Language).

```foxpro
_GENHTML = ProgramName
```

#### Parâmetros
 **ProgramName**
Especifica um programa que gera HTML. Se o seu programa de geração de HTML estiver em um diretório diferente do diretório padrão atual, inclua um caminho com o nome do programa.

# Observações

_GENHTML contém Genhtml.prg por padrão. Genhtml.prg é executado quando você escolhe Salvar como HTML no menu Arquivo. Um arquivo de texto que contém uma versão em hypertext markup language do formulário, menu, relatório ou tabela é criado. A opção Salvar como HTML está disponível somente quando os designers Form, Menu ou Report estão ativos e o formulário, menu ou relatório foi salvo, ou quando uma janela Browse está aberta.
