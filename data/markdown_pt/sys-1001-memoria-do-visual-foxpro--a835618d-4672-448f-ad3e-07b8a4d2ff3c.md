# SYS(1001) - Memória do Visual FoxPro

Retorna a quantidade total de memória disponível para o gerenciador de memória do Visual FoxPro.

```foxpro
SYS(1001)
```

# Valor de retorno

Caractere

# Observações

No Visual FoxPro, SYS(1001) retorna o tamanho do pool de memória virtual, que é aproximadamente quatro vezes a quantidade de memória física.
