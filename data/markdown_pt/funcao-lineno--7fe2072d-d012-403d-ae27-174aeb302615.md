# Função LINENO( )

Retorna o número da linha de uma linha sendo executada em um programa em relação à primeira linha do programa principal.

```foxpro
LINENO([1])
```

#### Parâmetros
 **1**
Retorna o número da linha em relação à primeira linha do programa ou procedimento atual. Se você omitir o argumento 1, o número da linha é retornado em relação à primeira linha do programa principal.

# Valor de retorno

Numeric

# Observações

As linhas do programa são contadas a partir do topo do programa. Linhas de comentário, linhas de continuação e linhas em branco são incluídas na contagem de número de linha. Se um programa é suspenso durante a execução, LINENO( ) retorna o número da linha do programa na qual a execução do programa foi suspensa. LINENO( ) retorna 0 se um programa é cancelado.

Por padrão, os números de linha são retornados em relação ao início do programa principal. Se um procedimento é chamado, a numeração de linhas continua a partir do topo do programa chamador.

LINENO( ) é útil para depurar programas. Você pode definir um ponto de interrupção para interromper a execução do programa em um número de linha específico abrindo a janela Breakpoints, definindo o Type como 'Break when expression is true' e adicionando `LINENO( ) = nExpression` na caixa de texto Expression.

# Exemplo

O exemplo a seguir é parte de uma rotina simples de tratamento de erros.

```foxpro
ON ERROR DO bug_proc WITH LINENO()
BRWS  && Causes an error
ON ERROR
*** Bug_Proc error handler ***
PROCEDURE bug_proc
PARAMETERS gnBadLine
WAIT WINDOW 'Error occurred at line: ' + ALLTRIM(STR(gnBadLine))
RETURN
```
