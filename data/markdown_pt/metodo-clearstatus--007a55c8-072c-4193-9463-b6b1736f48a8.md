# Método ClearStatus

Remove os elementos da interface fornecidos pelo método DoStatus.

```foxpro
oReportListener.ClearStatus()
```

#### Parâmetros

Nenhum.

# Valor de retorno

Nenhum.

# Observações

Aplica-se a: objeto ReportListener.

O método DoStatus fornece retorno não modal para objetos ReportListener. Como o programa continua em execução depois que os elementos da interface do usuário de DoStatus aparecem, é necessário removê-los explicitamente. O método ClearStatus fornece esse recurso.

Escreva o código apropriado neste método para remover os elementos da interface fornecidos pela classe em seu método DoStatus. Por exemplo, a classe base ReportListener usa uma janela WAIT NOWAIT para fornecer retorno durante a execução de um relatório; portanto, o método ClearStatus da classe base ReportListener executa o equivalente a WAIT CLEAR. Em contraste, a classe de fundação ReportListener User Feedback fornece uma barra de progresso em um formulário como retorno da execução do relatório; portanto, seu método ClearStatus remove o formulário.

> **Importante:** O código da interface do usuário deve levar em conta a configuração da propriedade QuietMode, imitando o comportamento da classe base ReportListener. Para obter mais informações, consulte Método DoStatus.

# Exemplo

Você pode invocar DoStatus e ClearStatus a qualquer momento, mesmo quando não houver uma execução de relatório em andamento. No exemplo a seguir, um objeto ReportListener adiciona um comportamento personalizado quando ocorre uma chamada a DoStatus entre execuções de relatórios. Quando uma execução começa, ele limpa qualquer retorno anterior que possa estar na tela devido a uma chamada anterior a DoStatus.

```foxpro
LOCAL oListener
oListener = CREATEOBJECT("messagingReportListener")
oListener.DoStatus()
REPORT FORM ? OBJECT oListener
oListener.DoStatus()
REPORT FORM ? OBJECT oListener
oListener.DoStatus()
DEFINE CLASS messagingReportListener AS ReportListener
   iReportRuns = 0
   ListenerType = 1
   PROCEDURE BeforeReport()
     THIS.iReportRuns = This.iReportRuns + 1
     THIS.ClearStatus()
     DODEFAULT()
   ENDPROC
   PROCEDURE DoStatus(cMessage)
      IF EMPTY(cMessage)
         NODEFAULT
         DODEFAULT("You have run " + ;
                   TRANSFORM(THIS.iReportRuns) + " report(s) so far!")
      ENDIF
   ENDPROC
ENDDEFINE
```
