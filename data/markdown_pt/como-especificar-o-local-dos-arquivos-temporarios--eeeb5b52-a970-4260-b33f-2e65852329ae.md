# Como: especificar o local dos arquivos temporários

Você pode especificar um local diferente para arquivos temporários usando a interface do Visual FoxPro ou as configurações TMPFILES, EDITWORK, PROGWORK e SORTWORK em um arquivo de configuração do Visual FoxPro.

### Para especificar o local dos arquivos temporários
- No menu Tools, clique em Options.
- Na caixa de diálogo Options, clique na guia File Locations.
- Na lista File Type, clique em Temporary Files e depois em Modify.
- Na caixa de diálogo Change File Location, digite um novo local ou clique no botão de reticências (...) para procurar e selecionar um local para arquivos temporários.

Para obter mais informações, consulte Options Dialog Box (Visual FoxPro) e File Locations Tab, Options Dialog Box.
