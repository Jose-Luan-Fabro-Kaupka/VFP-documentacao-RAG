# Função FSEEK( )

Move o ponteiro de arquivo em um arquivo aberto com uma função de arquivo de baixo nível.

```foxpro
FSEEK(nFileHandle, nBytesMoved [, nRelativePosition])
```

#### Parâmetros
 **nFileHandle**
Especifica o identificador de arquivo do arquivo em que FSEEK( ) move o ponteiro de arquivo. Um número de identificador de arquivo é retornado por FCREATE( ) ou FOPEN( ) quando o arquivo é criado ou aberto.
**nBytesMoved**
Especifica o número de bytes para mover o ponteiro de arquivo. O ponteiro de arquivo é movido em direção ao final do arquivo se nBytesMoved for positivo. O ponteiro de arquivo é movido em direção ao início do arquivo se nBytesMoved for negativo.
**nRelativePosition**
Move o ponteiro de arquivo para uma posição relativa no arquivo. Por padrão, o ponteiro de arquivo é movido em relação ao início do arquivo. Você também pode mover o ponteiro de arquivo em relação à posição atual do ponteiro de arquivo ou ao final do arquivo incluindo nRelativePosition . A tabela a seguir lista os valores para nRelativePosition e de onde o ponteiro de arquivo é movido. nRelativePosition Move o ponteiro de arquivo em relação a 0 (Padrão) O início do arquivo. 1 A posição atual do ponteiro de arquivo. 2 O final do arquivo.

# Valor de retorno

Numérico

# Observações

Após mover o ponteiro de arquivo, FSEEK( ) retorna o número de bytes em que o ponteiro de arquivo está posicionado a partir do início do arquivo. O ponteiro de arquivo também pode ser movido com FREAD( ) e FWRITE( ).

# Exemplo

A função definida pelo usuário a seguir usa FSEEK( ) para retornar o tamanho de um arquivo. Se você não passar parâmetros para a função definida pelo usuário, ela retorna –2. Se o arquivo não puder ser encontrado, a função definida pelo usuário retorna –1.

```foxpro
FUNCTION fsize2
PARAMETERS gcFileName  && File to be checked
PRIVATE pnHandle,pnSize
IF PARAMETERS() = 0
   RETURN -2  && Return -2 if no parameter passed
ELSE
   IF !FILE(gcFileName)
      RETURN -1  && Return -1 if file does not exist
   ENDIF
ENDIF
pnHandle = FOPEN(gcFileName)   && Open file
pnSize = FSEEK(pnHandle,0,2)   && Determine file size, assign to pnSize
=FCLOSE(pnHandle)  && Close file
RETURN pnSize  && Return value
```
