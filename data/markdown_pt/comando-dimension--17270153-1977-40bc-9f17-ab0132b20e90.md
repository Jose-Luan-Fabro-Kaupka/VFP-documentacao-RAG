# Comando DIMENSION

Cria um array unidimensional ou bidimensional de variáveis.

> **Observação:** DIMENSION é idêntico em operação e similar em sintaxe ao comando DECLARE. Para obter mais informações, consulte Comando DECLARE.

```foxpro
DIMENSION ArrayName1(nRows1 [, nColumns1]) [AS cType]
   [, ArrayName2(nRows2 [, nColumns2])] ...
```

#### Parâmetros
 **ArrayName1**
Especifica o nome do array. Dica Você pode criar múltiplos arrays com um único comando DIMENSION incluindo nomes de array adicionais, por exemplo, ArrayName2, ArrayName3, e assim por diante.
**nRows1 [, nColumns1 ]**
Especifica o tamanho do array a criar. Observação Você deve especificar um tamanho para cada array que criar com DIMENSION. Os tamanhos de array podem ser limitados pela memória disponível, o que afeta o desempenho, especialmente para arrays muito grandes. Certifique-se de que seu computador tem memória suficiente para acomodar os limites superiores de seus arrays. Para criar um array unidimensional, inclua apenas nRows1. Neste cenário, DIMENSION usa nRows1 para criar o número de linhas em um array unidimensional com uma única coluna. Por exemplo, o comando a seguir cria um array unidimensional chamado gaArrayOne que contém dez linhas e uma coluna: DIMENSION gaArrayOne(10) Para criar um array bidimensional, inclua tanto nRows1 quanto nColumns1. Neste cenário, nRows1 especifica o número de linhas no array, e nColumns1 especifica o número de colunas. O exemplo a seguir cria um array bidimensional chamado gaArrayTwo contendo duas linhas e quatro colunas: DIMENSION gaArrayTwo(2,4)
**AS cType**
Especifica um tipo de dados para o array. Usando a cláusula AS cType, você pode definir e especificar um tipo de dados diferente de Variant para arrays. A sintaxe AS cType não aparece no IntelliSense durante o tempo de design; é destinada apenas para uso em tempo de execução. Para um exemplo, consulte Exemplo 4 na seção Exemplo. A cláusula AS cType aplica-se somente ao passar um array para um componente COM. Caso contrário, o Visual FoxPro desconsidera a cláusula AS cType. Se você especificar um tipo de dados que não é um tipo de dados COM válido, o Visual FoxPro automaticamente usa o tipo VARIANT por padrão. # Observações

Você pode usar colchetes ou parênteses para delimitar expressões em DIMENSION. Por exemplo, as duas linhas de código a seguir criam arrays idênticos:

```foxpro
DIMENSION gaArrayOne(10), gaArrayTwo[2,4], gaArrayThree(3,3)
DIMENSION gaArrayOne[10], gaArrayTwo(2,4), gaArrayThree[3,3]
```

Elementos do Array O tamanho de um array determina quantos elementos o array contém. Cada elemento do array pode armazenar uma única peça de informação. Para determinar o número total de elementos que um array contém, multiplique o número de linhas (nRows1) no array pelo número de colunas (nColumns1) no array.

Os elementos do array podem conter qualquer tipo de dados e são inicializados como False (.F.) quando o array é criado pela primeira vez. Você pode inicializar todos os elementos em um array com o mesmo valor usando o comando STORE se o comando SET COMPATIBLE estiver definido como FOXPLUS ou OFF (padrão). O exemplo a seguir armazena a cadeia de caracteres "initial" em todos os elementos do array gaArray:

```foxpro
DIMENSION gaArray(10,3)
STORE 'initial' TO gaArray
```

Para obter mais informações sobre limites no número de elementos em arrays, consulte Capacidades do sistema Visual FoxPro.

> **Observação:** Arrays do Visual FoxPro são baseados em um — o primeiro elemento, linha ou coluna de um array é especificado com o número 1. (Arrays em outras linguagens de programação podem ser baseados em zero; o primeiro elemento, linha ou coluna de um array é especificado com o número 0.)

Subscritos do Array Você pode acessar e manipular elementos específicos em um array usando o nome do array e subscritos do array, ou índices. Um subscrito do array é um número único que identifica a posição do elemento no array. O subscrito ou subscritos para o primeiro elemento em um array é sempre 1.

Se o array é unidimensional, o array usa um subscrito para identificar o número da linha do array. Por exemplo, o subscrito para o elemento na terceira linha de um array unidimensional é 3.

Se o array é bidimensional, o array usa dois subscritos para identificar elementos no array. O primeiro subscrito indica a posição da linha do elemento, e o segundo subscrito indica a posição da coluna. Por exemplo, os subscritos para o elemento na terceira linha e quarta coluna de um array bidimensional são (3,4). Você também pode referenciar arrays bidimensionais usando um único subscrito.

Para retornar o subscrito único de um par de subscritos de linha e coluna do array, use AELEMENT( ). Para retornar os subscritos de linha e coluna de um subscrito único, use a função ASUBSCRIPT( ).

Para obter mais informações sobre subscritos, consulte Função ASUBSCRIPT( ).

Redimensionamento de Arrays Você pode alterar o tamanho e as dimensões de um array chamando DIMENSION novamente. O tamanho de um array pode ser aumentado ou diminuído; arrays unidimensionais podem ser convertidos para duas dimensões, e arrays bidimensionais podem ser reduzidos para uma dimensão.

> **Observação:** Se um array bidimensional é redimensionado com menos linhas ou colunas, o número de elementos é diminuído por número de elemento, não por número de linha ou coluna. Por exemplo, um array 10 por 10 redimensionado para 10 por 7 perde todos os dados de elemento para elementos 71 e superiores. Para obter mais informações, consulte Função AELEMENT( ).

Se o número de elementos em um array é aumentado, o conteúdo de todos os elementos no array original é copiado para o array redimensionado. Os elementos adicionais do array são inicializados como False (.F.).

Quando o tamanho de um array é aumentado ou diminuído quando SET COMPATIBLE está definido como ON ou DB4, o valor de cada elemento no array é reinicializado para .F.

Arrays Tipados Você pode passar um array tipado por referência ou por valor. Você não deve especificar explicitamente objetos do Visual FoxPro, como CommandButton. Em vez disso, use Object:

```foxpro
DIMENSION aObjects[] AS CommandButton   && Not supported
DIMENSION aObjects[] AS Object   && Recommended
```

> **Observação:** Se o servidor COM é um servidor Visual FoxPro, você pode especificar um objeto Visual FoxPro válido. No entanto, servidores que não são Visual FoxPro não reconhecerão este tipo.

Você deve usar COMARRAY( ) para controlar outras configurações de como arrays são passados para servidores COM, por exemplo, baseado em zero, byref, e assim por diante.

> **Observação:** Ao passar arrays para servidores executando o Microsoft .NET Framework, você deve chamar explicitamente COMARRAY(<object>, 10) para passar um array baseado em zero por referência. O código de marshaling de interoperabilidade fornecido pelo .NET Framework espera um array byref mas recebe um array byval e falha.

Arrays tipados de Single (escalar) não são suportados para servidores COM que não são servidores COM do Visual FoxPro. Você não pode passar tipos Currency para servidores executando o Microsoft .NET Framework.

Quando servidores executando o Microsoft .NET Framework retornam tipos System.Decimal e System.UInt16, eles são convertidos para wchart_t, que mapeia para o tipo de dados Decimal do Visual FoxPro.

# Exemplo

### Exemplo 1

O exemplo a seguir demonstra o resultado de aumentar o tamanho de um array unidimensional.

> **Observação:** Se você digitar esses comandos na Janela de Comando, o array será PUBLIC. No entanto, o array será PRIVATE se você copiá-los em um programa e executá-lo.

Se o número de elementos em um array é diminuído, os elementos e quaisquer dados que contêm são excluídos. Quando um array unidimensional é redimensionado para duas dimensões, o conteúdo do array unidimensional original é copiado para o novo array em ordem elemento-para-linha.

```foxpro
DIMENSION marray(2)
STORE 'A' TO marray(1)
STORE 'B' TO marray(2)
CLEAR
DISPLAY MEMORY LIKE marray
DIMENSION marray(4)
DISPLAY MEMORY LIKE marray
WAIT WINDOW
```

### Exemplo 2

No exemplo a seguir, um array unidimensional é convertido para um array bidimensional. O conteúdo dos elementos do array unidimensional é copiado para a primeira linha do novo array, seguido pela segunda linha e assim por diante. Os elementos adicionais são inicializados como False (.F.).

Quando um array bidimensional é convertido para uma dimensão, o conteúdo do array bidimensional original é copiado para o novo array em ordem linha-para-elemento. O primeiro elemento na primeira linha torna-se o primeiro elemento no array unidimensional, o segundo elemento na primeira linha torna-se o segundo elemento, e assim por diante.

Use ADEL( ) ou AINS( ) para excluir ou inserir elementos, linhas e colunas de array. Use APPEND FROM ARRAY, COPY TO ARRAY, SCATTER e GATHER para transferir dados entre registros de tabela e arrays.

```foxpro
DIMENSION marrayone(4)
STORE 'E' TO marrayone(1)
STORE 'F' TO marrayone(2)
STORE 'G' TO marrayone(3)
STORE 'H' TO marrayone(4)
CLEAR
DISPLAY MEMORY LIKE marrayone
DIMENSION marrayone(2,3)
DISPLAY MEMORY LIKE marrayone
WAIT WINDOW
```

### Exemplo 3

No exemplo a seguir, um array bidimensional é criado e carregado com dados. Os elementos do array e os dados que contêm são exibidos.

```foxpro
DIMENSION sample(2,3)
STORE 'Goodbye' TO sample(1,2)
STORE 'Hello' TO sample(2,2)
STORE 99 TO sample(6)
STORE .T. TO sample(1)
CLEAR
DISPLAY MEMORY LIKE sample
```

### Exemplo 4

No exemplo a seguir, um array é criado no Visual FoxPro e é então passado por referência para um servidor COM do Visual Basic, que espera um tipo forte de Long. Anteriormente, chamar FillIntArray falharia porque `aMyArray` tem tipo Variant. No entanto, após incluir uma definição na classe Visual Basic que define o array como tipo Variant, chamar FillIntArray funciona conforme mostrado:

```foxpro
* Visual FoxPro code
DIMENSION aMyArray [10] AS Long
lo.FillIntArray(@aMyArray, 100)   && Passing to Visual Basic COM Server
' Add following Visual Basic code to .CLS file and compile
' to COM component
Public Sub FillIntArray(ByRef aInts() As Long, iCount As Long)
   ReDim aInts(1 to 100)
   Dim ii As Interger
   For ii = 1 to 100
      AInts(ii) = ii
   Next
End Sub
```
