# Variável de sistema _INCLUDE

Especifica um arquivo de cabeçalho padrão incluído em classes, formulários ou conjuntos de formulários definidos pelo usuário.

```foxpro
_INCLUDE = HeaderFileName
```

#### Parâmetros
 **HeaderFileName**
Especifica um arquivo de cabeçalho padrão de constantes predefinidas em tempo de compilação, incluído automaticamente em classes, formulários ou conjuntos de formulários definidos pelo usuário. Se estiver em outro diretório, inclua o caminho no nome do arquivo. Por padrão, contém a cadeia de caracteres vazia.

# Observações

Você também pode especificar o arquivo de cabeçalho padrão pelo item Default Include File da guia File Locations da caixa de diálogo Options.
