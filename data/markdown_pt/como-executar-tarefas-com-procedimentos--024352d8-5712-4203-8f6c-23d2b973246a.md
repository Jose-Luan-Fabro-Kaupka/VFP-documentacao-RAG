# Como: executar tarefas com procedimentos

Você pode atribuir um procedimento a um menu ou item de menu. A forma de atribuição depende de haver submenus.

### Para atribuir um procedimento a um menu ou item sem submenus
- Na coluna Prompt, selecione o título ou item apropriado.
- Na caixa Result, selecione Procedure. Um botão Create será exibido; se já houver um procedimento, será exibido Edit.
- Selecione Create ou Edit.
- Digite o código apropriado na janela. Você não precisa digitar o comando PROCEDURE, pois o Visual FoxPro gera essa instrução. PROCEDURE só é necessário no código de limpeza.

### Para atribuir um procedimento a um menu ou item com submenus
- Na caixa Menu level, selecione o nível que inclui o menu ou item apropriado. Por exemplo, para atribuir um procedimento ao menu Customer, selecione o nível "Menu Bar"; para um item desse menu, selecione "Customer".
- No menu View, escolha Menu Options.
- Atribua o procedimento de uma destas formas: escreva ou chame um procedimento na caixa Procedure; ou escolha Edit e OK para abrir outra janela de edição e escrever ou chamar um procedimento.
