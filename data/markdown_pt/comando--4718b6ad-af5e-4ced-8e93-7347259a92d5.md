# Comando ? | ??

Avalia expressões e envia os resultados para a janela principal do Visual FoxPro, uma janela definida pelo usuário ativa ou a impressora.

```foxpro
? | ?? Expression1 [PICTURE cFormatCodes] | [FUNCTION cFormatCodes] |
   [VnWidth] [AT nColumn]
   [FONT cFontName [, nFontSize [, nFontCharSet]] [STYLE cFontStyle | Expression2]]
   [, Expression3] ...
```

#### Parâmetros
 **? Expression1**
Avalia a expressão especificada por Expression1 e envia um retorno de carro e avanço de linha precedendo os resultados da expressão. Os resultados são exibidos na próxima linha da janela principal do Visual FoxPro ou da janela definida pelo usuário ativa e são impressos na margem esquerda de uma página, a menos que um código de função especificado por cFormatCodes ou a variável de sistema _ALIGNMENT especifique o contrário. Se você omitir as expressões, uma linha em branco é exibida ou impressa. Um espaço é colocado entre os resultados das expressões quando várias expressões são incluídas. Se Expression1 é um objeto, o comando ? retorna a cadeia de caracteres "(Object)".
**?? Expression1**
Avalia a expressão especificada por Expression1 e exibe os resultados da expressão na linha atual na posição atual da janela principal do Visual FoxPro, de uma janela definida pelo usuário ativa ou da impressora. Um retorno de carro e avanço de linha não são enviados antes dos resultados.
**PICTURE cFormatCodes**
Especifica um formato picture no qual o resultado de Expression1 é exibido. cFormatCodes pode consistir em códigos de função, códigos picture ou uma combinação de ambos. Você pode usar os mesmos códigos disponíveis na Format Property e InputMask Property . Os códigos de função afetam o formato geral do resultado; os códigos picture atuam em caracteres individuais no resultado. Se códigos de função são usados em cFormatCodes , eles devem aparecer antes dos códigos picture e devem ser precedidos por um sinal de arroba (@). Vários códigos de função sem espaços incorporados podem seguir imediatamente o sinal @. O último código de função deve ser seguido por um ou mais espaços. O espaço ou espaços sinalizam o fim dos códigos de função e o início dos códigos picture.
**FUNCTION cFormatCodes**
Especifica um código de função a incluir na saída dos comandos ? e ??. Se a cláusula function for incluída, não preceda os códigos de função com um sinal @. Os códigos de função devem ser precedidos por um sinal @ quando incluídos em PICTURE.
**VnWidth**
Especifica um código de função especial que permite que os resultados de uma expressão de caracteres se estendam verticalmente dentro de um número limitado de colunas. nWidth especifica o número de colunas na saída. ? 'This is an example of how the V function code works.' ; FUNCTION 'V10'
**AT nColumn**
Especifica o número da coluna onde a saída é exibida. Esta opção permite alinhar a saída em colunas para criar uma tabela. A expressão numérica nColumn pode ser uma função definida pelo usuário que retorna um valor numérico.
**FONT cFontName [, nFontSize [, nFontCharSet ]]**
Especifica uma fonte para saída pelo comando ? ou ??. cFontName especifica o nome da fonte, e nFontSize especifica o tamanho em pontos. Você pode especificar um script de idioma com nFontCharSet . Consulte a GETFONT( ) Function para uma lista de valores de script de idioma disponíveis. Por exemplo, o comando a seguir exibe a data do sistema em fonte Courier de 16 pontos: ? DATE( ) FONT 'Courier',16 Se você incluir a cláusula FONT mas omitir o tamanho em pontos nFontSize , uma fonte de 10 pontos é usada. Se você omitir a cláusula FONT, e a saída do comando ? ou ?? for colocada na janela principal do Visual FoxPro, a fonte da janela principal do Visual FoxPro é usada para a saída. Se você omitir a cláusula FONT, e a saída do comando ? ou ?? for colocada em uma janela definida pelo usuário, a fonte da janela definida pelo usuário é usada para a saída. Observação Se a fonte que você especificar não estiver disponível, uma fonte com características semelhantes é substituída.
**STYLE cFontStyle**
Especifica um estilo de fonte para saída pelos comandos ? e ??. Se você omitir a cláusula STYLE, o estilo de fonte Normal é usado. Se o estilo de fonte que você especificar não estiver disponível, um estilo de fonte com características semelhantes é substituído. Observação Você deve incluir a cláusula FONT quando especificar um estilo de fonte com a cláusula STYLE. A tabela a seguir lista os estilos de fonte que você pode especificar para cFontStyle . cFontStyle Estilo de fonte B Bold I Italic N Normal Q Opaque - Strikeout T Transparent U Underline Você pode incluir mais de um caractere para especificar uma combinação de estilos de fonte. Por exemplo, o comando a seguir exibe a data do sistema em Courier Bold Italic: ? DATE( ) FONT 'COURIER' STYLE 'BI'


# Observações

Para enviar os resultados apenas para a impressora, use os seguintes comandos:

```foxpro
SET PRINTER ON
SET CONSOLE OFF
```

Para enviar os resultados para a impressora e a janela principal do Visual FoxPro ou uma janela definida pelo usuário ativa, use o seguinte comando:

```foxpro
SET PRINTER ON
```

A configuração de SET ALTERNATE afeta o destino dos comandos ? e ??. Para obter mais informações, consulte SET ALTERNATE Command.

O comando ? exibe dados binários para tipos de dados Varbinary em formato hexadecimal sem limitação de tamanho. Para obter mais informações, consulte Varbinary Data Type.

# Exemplo

O exemplo a seguir avalia e exibe as expressões especificadas:

```foxpro
? 15 * (10+10)
? 'Welcome to ' PICTURE '@!'
?? 'Visual FoxPro'
```
