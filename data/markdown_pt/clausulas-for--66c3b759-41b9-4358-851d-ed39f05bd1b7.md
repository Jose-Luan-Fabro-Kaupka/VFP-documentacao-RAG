# Cláusulas FOR

Uma cláusula FOR faz um comando atuar em cada registro que atende à condição lógica especificada. As cláusulas FOR têm a seguinte sintaxe:

O exemplo a seguir armazena `low balance` no campo `alert` de todos os registros que contêm menos de 500 no campo `total`.

```foxpro
FOR lExpr
REPLACE ALL alert WITH "low balance" FOR total < 500
```

# Observações

A tabela a seguir lista comandos nos quais você pode usar uma cláusula FOR.
 Comandos que usam cláusulas FOR
| APPEND FROM ARRAY | COUNT | LOCATE |
| --- | --- | --- |
| APPEND FROM | DEFINE PAD | RECALL |
| AVERAGE | DELETE | REPLACE FROM ARRAY |
| BLANK | DISPLAY | REPLACE |
| BROWSE | EXPORT | REPORT |
| CALCULATE | FOR( ) | SCAN...ENDSCAN |
| CHANGE | INDEX | SORT |
| COPY TO ARRAY | LABEL | SUM |
| COPY TO | LIST | |

Usar a cláusula FOR pode acelerar a operação de comandos de tabela única. Para obter mais informações sobre aprimoramento de desempenho, consulte Optimizing Applications.
