# Linguagem de manipulação de registros

Esses comandos e funções permitem selecionar registros em uma tabela ou posicionar o ponteiro de registro.

| Use | Para |
| --- | --- |
| APPEND FROM Command | Adicionar registros a uma tabela. |
| APPEND MEMO Command | Copiar o conteúdo de um arquivo de texto para um campo memo. |
| BLANK Command | Limpar dados dos campos. |
| CONTINUE Command | Continuar o LOCATE anterior. |
| DELETE - SQL Command | Marcar registros para exclusão. |
| FILTER( ) Function | Retornar uma expressão de filtro de tabela especificada em SET FILTER. |
| GO | GOTO Command | Mover o ponteiro de registro. |
| INDEXSEEK( ) Function | Pesquisar uma tabela indexada sem mover o ponteiro de registro. |
| INSERT - SQL Command | Anexar novos registros a uma tabela. |
| ISBLANK( ) Function | Determinar se uma expressão está em branco. |
| KEYMATCH( ) Function | Pesquisar uma tag de índice ou um arquivo de índice por uma chave de índice. |
| LOCATE Command | Pesquisar sequencialmente uma tabela por uma expressão lógica especificada. |
| LOOKUP( ) Function | Pesquisar uma tabela pelo primeiro registro com um campo correspondente a uma expressão especificada |
| REPLACE FROM ARRAY Command | Atualizar dados em campos com valores de um array de variáveis. |
| SEEK Command | Pesquisar uma tabela por um registro cuja chave de índice corresponda a uma expressão geral. |
| SEEK( ) Function | Pesquisar uma tabela indexada por um registro cuja chave de índice corresponda a uma expressão especificada. |
| SET COLLATE Command | Especificar uma sequência de ordenação para campos de caracteres em operações subsequentes de indexação e classificação. |
| SET FILTER Command | Especificar uma condição que os registros devem satisfazer para serem acessíveis. |
| SET KEY Command | Especificar acesso a um intervalo de registros baseado em suas chaves de índice. |
| SET NEAR Command | Determinar onde o ponteiro de registro é posicionado após uma pesquisa de registro sem sucesso. |
| SET RELATION Command | Estabelecer uma relação entre duas tabelas abertas. |
| SKIP Command | Mover o ponteiro de registro para frente ou para trás em uma tabela. |
| UPDATE - SQL Command | Atualizar registros em uma tabela com novos valores. |
