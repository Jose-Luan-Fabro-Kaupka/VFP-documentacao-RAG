# Comando SKIP

Move o ponteiro de registro para frente ou para trás em uma tabela.

```foxpro
SKIP   [nRecords]   [IN nWorkArea | cTableAlias]
```

#### Parâmetros
 **nRecords**
Especifica o número de registros para mover o ponteiro. SKIP sem nRecords avança para o próximo registro. Um valor positivo move em direção ao fim do arquivo; um valor negativo, ao início. Se o ponteiro estiver no último registro e SKIP sem argumentos for executado, RECNO( ) retornará um valor 1 maior que o número de registros e EOF( ) retornará verdadeiro (.T.). Se estiver no primeiro registro e SKIP –1 for executado, RECNO( ) retornará 1 e BOF( ) retornará verdadeiro (.T.).
**IN nWorkArea | cTableAlias**
Move o ponteiro em uma tabela de uma área de trabalho específica. nWorkArea especifica o número da área e cTableAlias, o alias da tabela ou área.

# Observações

Se a tabela tiver uma tag de índice mestre controladora ou um arquivo de índice, SKIP moverá o ponteiro para o registro determinado pela sequência do índice.

# Exemplo

```foxpro
CLOSE DATABASES
OPEN DATABASE (HOME(2) + 'data\testdata')
USE customer  && Opens Customer table
CLEAR
SKIP 4 IN 'customer'
? RECNO('customer')  && Displays 5
GO BOTTOM
SKIP -5
? RECNO()
```
