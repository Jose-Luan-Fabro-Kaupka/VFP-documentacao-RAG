# Interoperabilidade e a Internet

O Visual FoxPro suporta OLE drag-and-drop, o que torna possível mover dados entre o Visual FoxPro e outros aplicativos, bem como dentro de aplicativos Visual FoxPro.

O Visual FoxPro também facilita a criação de aplicativos para uso com a Internet e outros aplicativos baseados em Microsoft Windows, como Excel e Visual Basic.

Além disso, o Visual FoxPro facilita a criação de servidores Automation que funcionam melhor com a Internet, o Microsoft Transaction Server e o Active Desktop.

# Nesta seção
