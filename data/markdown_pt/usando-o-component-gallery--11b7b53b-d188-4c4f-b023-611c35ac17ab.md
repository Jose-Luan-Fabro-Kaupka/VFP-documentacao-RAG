# Usando o Component Gallery

O Component Gallery é um contêiner para catálogos de objetos de software, como bibliotecas de classes, formulários, botões e outros. O Component Gallery também contém classes do Visual FoxPro. Você pode usá-lo para organizar componentes em agrupamentos de objetos, projetos, aplicativos ou outros. Esses agrupamentos visuais podem ser personalizados dinamicamente, permitindo usar, duplicar ou reorganizar componentes entre várias classificações no Component Gallery. Você pode acessar um componente específico de qualquer local do Component Gallery em que coloque uma referência a ele. É possível ter várias referências, em diferentes catálogos ou pastas, para um único objeto. Por exemplo, um botão pode aparecer em uma ou mais categorias de projeto do Component Gallery (representadas como pastas), mas também pode estar visível em uma categoria "Tools" que contenha referências a todos os botões usados.

Você pode usar o Component Gallery para todas as funções fornecidas separadamente pela janela Project Manager, pela janela Class Browser e pela barra de ferramentas Form Controls. Cada um dos outros componentes do Visual FoxPro oferece foco muito específico aos projetos ou classes dentro do ambiente especial de um arquivo de projeto ou biblioteca de classes. O Component Gallery permite gerenciar as relações entre componentes e muitos de seus comportamentos tanto em um nível abstrato de projeto quanto em uma perspectiva mais próxima do desenvolvimento.

Você pode arrastar e soltar componentes dentro do Component Gallery e dele para projetos ou formulários. Também pode alterar propriedades de objetos ou classes no Component Gallery.

O Component Gallery pode conter qualquer elemento do Visual FoxPro, incluindo documentos, arquivos ou pastas locais e remotos, servidores de Automação como Microsoft Excel e Word, além de locais e arquivos HTML. Também é possível incluir arquivos .prg que contenham trechos de código, classes, assistentes, construtores ou arte.
