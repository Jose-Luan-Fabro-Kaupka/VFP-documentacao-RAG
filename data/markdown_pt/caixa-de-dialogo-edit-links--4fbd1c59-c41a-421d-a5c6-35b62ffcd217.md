# Caixa de diálogo Edit Links

Esta caixa de diálogo permite alterar ou romper um vínculo de objeto. Esta opção de menu é habilitada quando você abre um campo general que contém um objeto OLE vinculado que você gerou em um aplicativo separado.
 **Links**
Exibe o nome e o caminho do arquivo vinculado, o tipo de aplicativo e o tipo de atualização selecionado para o vínculo.
**Source**
Exibe o nome completo e a localização do arquivo de objeto selecionado na caixa Link.
**Type**
Exibe o aplicativo de objeto ou o tipo de aplicativo ao qual o arquivo selecionado na caixa Link está vinculado.
**Update**
Especifica como você deseja atualizar as informações. Selecione Automatic para que o Visual FoxPro atualize as informações sempre que novas informações estiverem disponíveis. Selecione Manual para atualizar as informações somente quando você selecionar um vínculo e clicar em Update Now .
**Update Now**
Atualiza o vínculo selecionado na caixa Link. Se as informações foram alteradas no documento de objeto, as novas informações aparecem no seu formulário ou relatório.
**Open Source**
Abre o arquivo selecionado no aplicativo de objeto para edição.
**Change Source**
Exibe a caixa de diálogo Change Source, onde você pode especificar um arquivo de objeto diferente para o vínculo selecionado ou alterar informações do item.
**Break Link**
Rompe o vínculo selecionado na caixa Link. Isso altera o objeto para uma imagem, que não pode mais ser editada pelo aplicativo OLE que o criou.
