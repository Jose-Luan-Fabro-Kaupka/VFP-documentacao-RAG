# Variável de Sistema _GALLERY

Especifica o programa que é executado quando você escolhe Galeria de Componentes no menu Ferramentas.

```foxpro
_GALLERY = ProgramName
```

#### Parâmetros
 **ProgramName**
Especifica um programa. Se seu programa estiver em um diretório diferente do diretório padrão atual, inclua um caminho com o nome do programa.

# Observações

_GALLERY contém GALLERY.APP por padrão.
