# Guia Format, Edit Box Builder

Esta guia no Edit Box builder especifica opções diversas de formato para a caixa de edição, como adicionar barras de rolagem verticais e tornar a caixa somente leitura.
 **Allow User to Insert Tabs**
Permite a inserção de tabulações na caixa de edição. Isso impede que o foco se mova para o próximo controle quando a tecla TAB é pressionada. Pressione CTRL+TAB para mover para o próximo controle. Esta opção corresponde à propriedade AllowTabs.
**Add Vertical Scrollbars**
Adiciona barras de rolagem verticais à caixa de edição. Esta opção corresponde à propriedade ScrollBars.
**Select on Entry**
Especifica que o texto na caixa de edição seja selecionado quando a caixa de edição receber o foco. Isso adiciona a configuração "K" à propriedade Format.
**Use Current SET DATE**
Adiciona a configuração "D" à propriedade Format para que as entradas de data sigam o SET DATE atual ou o Date Format da guia International da caixa de diálogo Options.
**HideSelection**
Especifica se o texto selecionado na caixa de edição permanece visivelmente selecionado quando a caixa de edição não tem o foco. Esta opção corresponde à propriedade HideSelection.
**Enable at Run time**
Especifica se a caixa de edição está habilitada quando o formulário é executado. Esta opção corresponde à propriedade Enabled.
**Make Read-Only**
Impede que o usuário altere o texto na caixa de edição. Esta opção corresponde à propriedade ReadOnly.
**British Date**
Adiciona a configuração "E" à propriedade Format para que as entradas de data sigam a formatação britânica de SET DATE ou do Date Format da guia International da caixa de diálogo Options.
