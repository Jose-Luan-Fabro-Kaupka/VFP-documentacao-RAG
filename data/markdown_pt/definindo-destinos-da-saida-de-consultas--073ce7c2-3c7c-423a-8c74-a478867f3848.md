# Definindo destinos da saída de consultas

A tabela a seguir descreve os destinos da saída de consultas.

| Opção de saída | Destino |
| --- | --- |
| Browse | Exibe os resultados da consulta em uma janela de navegação. |
| Cursor | Salva os resultados da consulta em uma tabela temporária somente leitura com um nome especificado por você. |
| Table | Salva os resultados da consulta como uma tabela com um nome especificado por você. |
| Screen | Exibe os resultados da consulta na janela principal do Visual FoxPro ou na janela de saída ativa no momento. |

# Referência
 **Janela Browse**
Exibe registros em uma janela ativa.
**Comando SELECT - SQL**
Recupera dados de uma ou mais tabelas.
**Caixa de diálogo Query Destination**
Permite enviar os resultados da consulta para sete saídas diferentes. Esse comando está disponível somente para consultas.
