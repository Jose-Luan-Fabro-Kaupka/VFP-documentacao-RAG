# Variável de sistema _TOOLBOX

Contém o caminho e o nome do arquivo do Visual FoxPro Toolbox. _TOOLBOX especifica o caminho e o nome do arquivo do Visual FoxPro Toolbox. Este caminho geralmente é o diretório raiz do Visual FoxPro, e o nome do arquivo geralmente é Toolbox.app.

```foxpro
_TOOLBOX = cPath
```

#### Parâmetros
 **cPath**
Especifica o caminho completo e o nome do arquivo do Visual FoxPro Toolbox.

# Observações

Você pode especificar um caminho e nome de arquivo para _TOOLBOX na guia File Locations na caixa de diálogo Options. Para obter mais informações, consulte File Locations Tab, Options Dialog Box.
