# Operação inválida para visualização offline enquanto offline (Erro 2007)

Algumas operações não são válidas quando uma visualização offline está sendo usada offline.
 - Você tentou criar uma visualização offline a partir de uma visualização que já está offline. Use a visualização original diretamente, ou use uma visualização diferente como base para sua nova visualização offline.

Para obter mais informações, consulte Função CREATEOFFLINE( ).
