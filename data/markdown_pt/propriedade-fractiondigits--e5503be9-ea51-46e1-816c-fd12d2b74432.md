# Propriedade FractionDigits

Para tipos de dados Numeric, FractionDigits especifica o número de dígitos à direita do ponto decimal.

```foxpro
XMLField.FractionDigits
```

# Valor de retorno

Tipo de dados numérico. FractionDigits especifica o número de dígitos à direita do ponto decimal. Se nenhum existir ou se FractionDigits não for aplicável, o valor de FractionDigits é -1.

Aplica-se a: XMLField Class
