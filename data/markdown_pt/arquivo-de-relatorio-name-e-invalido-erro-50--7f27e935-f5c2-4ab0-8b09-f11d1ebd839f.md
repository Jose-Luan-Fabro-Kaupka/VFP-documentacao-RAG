# Arquivo de relatório "name" é inválido (Erro 50)

A definição do relatório contém um erro, como:
 - O número de grupos de dados ou bandas Detail em um relatório excede os limites especificados.
- O arquivo de relatório (frx) não contém as colunas necessárias para uma tabela FRX.
- O arquivo de relatório (frx) não inclui um registro para uma banda necessária, como uma banda Page Header.
