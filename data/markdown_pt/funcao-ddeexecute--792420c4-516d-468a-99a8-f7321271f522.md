# Função DDEExecute( )

Envia um comando para outro aplicativo, usando dynamic data exchange (DDE).

```foxpro
DDEExecute(nChannelNumber, cCommand [, cUDFName])
```

#### Parâmetros
 **nChannelNumber**
Especifica o número do canal.
**cCommand**
Especifica o comando que você deseja enviar ao outro aplicativo. O formato do comando é determinado pelo aplicativo para o qual você está enviando. Consulte a documentação do aplicativo para a sintaxe correta.
**cUDFName**
Permite solicitações de execução de comando assíncronas. Se você omitir cUDFName , um aplicativo cliente aguarda o período especificado com DDESetOption( ) . Se você especificar uma função definida pelo usuário com cUDFName , a execução do programa cliente continua imediatamente após a solicitação de execução do comando ser feita. Quando o aplicativo servidor termina de executar o comando, a função definida pelo usuário que você especifica com cUDFName é executada. A função definida pelo usuário recebe seis parâmetros na ordem mostrada na tabela a seguir. Parameter Contents Channel Number O número do canal do aplicativo servidor. Action XACTCOMPLETE (successful execution).XACTFAIL (failed command execution). Item O nome do item; por exemplo, R1C1 para uma célula de planilha do Microsoft Excel. Data Os novos dados (REQUEST) ou dados passados (POKE or EXECUTED). Format O formato dos dados; por exemplo, CF_TEXT. Transaction Number O número da transação retornado por DDEExecute( ). Use DDEAbortTrans( ) para cancelar uma transação não concluída. Se a transação falhar, você pode usar DDELastError( ) para determinar por que falhou. Quando você inclui cUDFName , DDEExecute( ) não retorna um valor lógico. Em vez disso, um número de transação é retornado; se ocorrer um erro, –1 é retornado.

# Valor de retorno

Logical

# Observações

O comando enviado com DDEExecute( ) deve ser compreendido pelo aplicativo. Antes de executar o comando, você deve estabelecer um canal para o aplicativo servidor com DDEInitiate( ).

Por exemplo, o Microsoft Excel tem um conjunto extenso de comandos de macro, incluindo comandos DDE que permitem solicitar dados do Visual FoxPro a partir do Microsoft Excel. Se você estabelecer um canal para o Microsoft Excel, pode usar DDEExecute( ) para enviar comandos de macro ao Excel a partir do Visual FoxPro.

Se o aplicativo receptor executar o comando com sucesso, DDEExecute( ) retorna true (.T.). Se o aplicativo receptor não conseguir executar o comando com sucesso ou se o número do canal incluído não for válido, DDEExecute( ) retorna false (.F.). Se a função definida pelo usuário assíncrona opcional cUDFName for incluída, um número de transação é retornado. Se ocorrer um erro, DDEExecute( ) retorna –1.

# Exemplo

O exemplo a seguir usa DDEInitiate( ) para estabelecer um canal DDE entre o Visual FoxPro e a planilha do Microsoft Excel Sheet1. DDEExecute( ) é usado para executar um comando do Microsoft Excel que maximiza a janela do Microsoft Excel.

```foxpro
gnChanNum = DDEInitiate('Excel', 'Sheet1')
IF gnChanNum != -1
   glExecute = DDEExecute(gnChanNum, '[App.Maximize]')
   IF glExecute != .F.
      WAIT WINDOW 'EXCEL window has been zoomed out.'
   ENDIF
   = DDETerminate(gnChanNum)   && Close the channel
ENDIF
```
