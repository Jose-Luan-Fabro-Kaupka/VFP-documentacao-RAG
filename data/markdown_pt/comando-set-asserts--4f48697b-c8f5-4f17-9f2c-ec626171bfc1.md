# Comando SET ASSERTS

Especifica se os comandos ASSERT são avaliados ou ignorados.

```foxpro
SET ASSERTS ON | OFF
```

#### Parâmetros
 **ON**
Especifica que o Visual FoxPro executa comandos ASSERT.
**OFF**
Especifica que o Visual FoxPro ignora comandos ASSERT. (Padrão)

# Observações

Se você escolher o botão Ignore All na caixa de mensagem após uma assert, SET ASSERTS é definido como OFF.
