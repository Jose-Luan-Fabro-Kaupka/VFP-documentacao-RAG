# Arrays

Um array é uma série ordenada de valores de dados, chamados elementos do array. Os elementos do array são referenciados pela sua posição no array, que são números chamados subscritos ou índices do array. Como os arrays existem na memória, você pode especificar, acessar e manipular rapidamente e com facilidade elementos de dados em um array. Um array Visual FoxPro pode conter qualquer ou todos os tipos de dados como elementos. Os arrays têm as mesmas opções de escopo que as variáveis.

Você pode criar um array usando o comando DIMENSION ou DECLARE e atribuir um valor a cada elemento especificando o elemento usando o nome do array e a posição, ou subscrito, do elemento. Você pode usar os comandos SCATTER, GATHER, COPY TO ARRAY e APPEND FROM ARRAY para mover valores de campos de e para elementos do array.

Por exemplo, a linha de código a seguir cria um array bidimensional de cinco linhas e duas colunas e, em seguida, atribui um valor à segunda coluna da primeira linha:

```foxpro
DIMENSION ArrayName[5,2]
ArrayName[1,2] = 966789
```

> **Observação:** Os arrays Visual FoxPro são baseados em um — o primeiro elemento, linha ou coluna de um array é especificado com o número 1. (Arrays em outras linguagens de programação podem ser baseados em zero; o primeiro elemento, linha ou coluna de um array é especificado com o número 0.)

Para obter mais informações, consulte DIMENSION Command, DECLARE Command, SCATTER Command, GATHER Command, COPY TO ARRAY Command e APPEND FROM ARRAY Command. Para obter mais informações sobre o uso de arrays em seu aplicativo, consulte Data Transfer and Arrays.
