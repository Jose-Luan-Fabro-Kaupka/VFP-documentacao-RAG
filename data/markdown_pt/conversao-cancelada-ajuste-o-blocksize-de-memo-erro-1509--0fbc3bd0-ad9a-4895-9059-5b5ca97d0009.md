# Conversão cancelada. Ajuste o BLOCKSIZE de memo (Erro 1509)

Você está tentando converter uma tabela dBASE com um tamanho de bloco de memo inferior a 512K.

Para converter o arquivo com êxito para o Visual FoxPro, volte ao dBASE e ajuste o tamanho de bloco de memo para um valor maior ou igual a 512K.
