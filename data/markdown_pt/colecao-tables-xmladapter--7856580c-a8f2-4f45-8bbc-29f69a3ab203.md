# Coleção Tables (XMLAdapter)

A coleção Tables em um objeto XMLAdapter contém um ou mais objetos XMLTable e descreve XML como cursores do Visual FoxPro junto com qualquer informação relacional. Para criar um novo objeto XMLTable e adicioná-lo à coleção Tables, ou preencher a coleção Tables com uma ou mais tabelas, use os métodos LoadXML, AddTableSchema ou Attach do XMLAdapter.

```foxpro
XMLAdapter.Tables
```
