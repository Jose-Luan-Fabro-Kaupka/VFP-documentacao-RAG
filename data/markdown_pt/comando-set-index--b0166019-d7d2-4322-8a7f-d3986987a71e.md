# Comando SET INDEX

Abre um ou mais arquivos de índice para uso com a tabela atual.

```foxpro
SET INDEX TO [IndexFileList | ? ] [ORDER nIndexNumber
 | IDXIndexFileName | [TAG] TagName [OF CDXFileName] [ASCENDING
 | DESCENDING]] [ADDITIVE]
```

#### Parâmetros
 **IndexFileList**
Especifica um ou mais arquivos de índice a serem abertos. Use vírgulas para separar vários arquivos de índice na lista. A lista de arquivos de índice pode conter qualquer combinação de nomes de arquivos de índice .idx e .cdx; você não precisa incluir as extensões de nome de arquivo, a menos que exista outro arquivo .idx ou .cdx com o mesmo nome. O primeiro arquivo de índice na lista de arquivos de índice torna-se o arquivo de índice controlador, que controla como os registros são acessados e exibidos. Os registros são exibidos e acessados na ordem física dos registros se o primeiro arquivo de índice for um arquivo .cdx e SET ORDER TO TAG não tiver sido emitido.
**?**
Exibe a caixa de diálogo Open, na qual você pode abrir um único arquivo .idx.
**ORDER nIndexNumber**
Especifica um arquivo de índice ou tag controlador. A expressão numérica nIndexNumber especifica os arquivos de índice conforme aparecem na lista de arquivos de índice. Arquivos .Idx são numerados primeiro na ordem em que aparecem na lista de arquivos de índice. As tags no arquivo .cdx estrutural (se existir) são numeradas na ordem em que as tags foram criadas. Por fim, as tags em quaisquer arquivos .cdx independentes são numeradas na ordem em que foram criadas. Consulte SET ORDER para uma discussão adicional sobre a numeração de arquivos de índice e tags. Se nIndexNumber for 0, os registros na tabela são exibidos e acessados na ordem física dos registros, mas os arquivos de índice permanecem abertos. ORDER 0 permite atualizar arquivos de índice abertos enquanto acessa registros na ordem física. ORDER sem argumentos adicionais é idêntico a ORDER 0. O Visual FoxPro gera uma mensagem de erro se nIndexNumber for maior que o número de arquivos .idx e tags de arquivo .cdx.
**ORDER IDXIndexFileName**
Especifica um arquivo .idx como o arquivo de índice controlador.
**ORDER [TAG] TagName [OF CDXFileName ]**
Especifica uma tag (TagName) de um arquivo .cdx para ser a tag controladora. O nome da tag pode ser do arquivo .cdx estrutural ou de qualquer arquivo .cdx independente aberto. Se tags com o mesmo nome existirem em arquivos .cdx independentes abertos, use OF CDXFileName para especificar o arquivo .cdx em que a tag está.
**ASCENDING | DESCENDING**
Especifica se os registros da tabela são exibidos e acessados em ordem ascendente ou descendente. Os arquivos de índice ou tags não são alterados de forma alguma; apenas a ordem em que os registros são exibidos e acessados é alterada. Inclua a cláusula ASCENDING ou DESCENDING imediatamente após a cláusula ORDER.
**ADDITIVE**
Especifica que arquivos de índice abertos anteriormente, exceto um índice composto estrutural, permanecem abertos quando você emite SET INDEX para abrir um arquivo de índice adicional ou arquivos para uma tabela. Sem ADDITIVE, os arquivos abertos anteriormente seriam fechados.

# Observações

Os registros em uma tabela que tem um arquivo de índice ou arquivos abertos podem ser exibidos e acessados em uma ordem determinada por um dos arquivos de índice. Tanto arquivos de índice simples (.idx) quanto compostos (.cdx) podem ser abertos com SET INDEX. Se uma tabela tem um arquivo .cdx estrutural, o arquivo é aberto automaticamente quando a tabela é aberta.

Somente um arquivo .idx (o arquivo de índice controlador) ou tag de um arquivo .cdx (a tag controladora) controla a ordem em que os registros na tabela são exibidos ou acessados. Certos comandos (SEEK, por exemplo) usam o arquivo de índice ou tag controlador para pesquisar registros.

Emitir SET INDEX TO sem argumentos adicionais fecha todos os arquivos de índice abertos (exceto um arquivo .cdx estrutural) na área de trabalho atual.
