# Compilando um aplicativo

Ao criar um aplicativo um componente de cada vez, você pode verificar a funcionalidade de cada componente conforme o cria. Depois de criar todos os componentes funcionais no projeto do aplicativo, você pode compilar um aplicativo e reunir os componentes executáveis no projeto do aplicativo, como formulários, relatórios, menus e programas, em um único arquivo que você pode distribuir com os arquivos de dados do aplicativo para seus usuários.
