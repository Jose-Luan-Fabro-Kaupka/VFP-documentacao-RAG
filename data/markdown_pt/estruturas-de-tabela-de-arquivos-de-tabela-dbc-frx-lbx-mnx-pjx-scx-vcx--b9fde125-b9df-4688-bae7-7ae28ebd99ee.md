# Estruturas de tabela de arquivos de tabela (.dbc, .frx, .lbx, .mnx, .pjx, .scx, .vcx)

As descrições das estruturas de tabela são armazenadas em arquivos localizados no diretório FILESPEC. O diretório FILESPEC contém dois arquivos de projeto: 60SPEC.pjx e 26SPEC.pjx. O arquivo 60SPEC.pjx contém tabelas e relatórios que documentam o Visual FoxPro versões 5.0 e posteriores. O arquivo 26SPEC.pjx contém tabelas e relatórios que documentam arquivos de tabela do FoxPro versão 2.6.

Para ver as descrições de qualquer estrutura de tabela, imprima o relatório apropriado. As tabelas a seguir listam os tipos de arquivo e seus relatórios associados. Alguns tipos de arquivo requerem mais de um relatório porque há muitas colunas para caber em uma única página.

> **Observação:** Todos os relatórios estão formatados para impressão em paisagem.
 Tipos de arquivo para Visual FoxPro 5.0 e posteriores
| Para ver a estrutura de tabela de um... | Imprima este relatório | Que usa |
| --- | --- | --- |
| Banco de dados1 | 60DBC.frx | 60DBC.dbf |
| Formulário e biblioteca de classes visual | 60SCX1.frx 60SCX2.frx | 60SCX.dbf |
| Menu2 | 60MNX.frx | 60MNX.dbf |
| Projeto | 60PJX1.frx 60PJX2.frx | 60PJX.dbf |
| Relatório e etiqueta | 90FRX.frx ou 60FRX1.frx e 60FRX2.frx | 60FRX.dbf |

1 As propriedades do banco de dados podem ser impressas de 60DBCPRO.frx. 2 O campo location na estrutura do Visual FoxPro 6.0 difere da estrutura do Visual FoxPro 5.0. Campos adicionais para suportar imagens no Visual FoxPro 7.0 estão incluídos no relatório.
