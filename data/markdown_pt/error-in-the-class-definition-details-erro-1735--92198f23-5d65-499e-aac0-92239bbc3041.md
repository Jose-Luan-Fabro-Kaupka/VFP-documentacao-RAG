# Error in the class definition. "Details" (Erro 1735)

Ocorreu um erro na definição da classe por um dos seguintes motivos:
 - A matriz não existe.
- Páginas não podem ser removidas na definição da classe.
- Colunas não podem ser removidas na definição da classe.
- Não foi possível encontrar o nome da classe no formulário.
- CREATEOBJECT( ) foi usado em uma definição de classe.
- Colunas de grade foram excluídas em uma definição de classe definindo ColumnCount na classe pai com um valor e depois definindo ColumnCount com um valor menor na classe filha.
- Páginas do tipo page frame foram excluídas em uma definição de classe definindo PageCount na classe pai com um valor e depois definindo PageCount com um valor menor na classe filha.
- A cláusula ADD OBJECT a[1] do comando DEFINE CLASS foi usada onde a não é uma matriz.
