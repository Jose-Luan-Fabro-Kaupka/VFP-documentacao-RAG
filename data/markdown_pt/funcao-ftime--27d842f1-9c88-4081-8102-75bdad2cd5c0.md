# Função FTIME( )

Retorna a hora da última modificação de um arquivo.

```foxpro
FTIME(cFileName)
```

#### Parâmetros
 **cFileName**
Especifica o nome do arquivo cuja hora de última modificação FTIME( ) retorna. cFileName pode incluir um caminho. Se não houver caminho, o Visual FoxPro procurará no diretório padrão e nos diretórios ou pastas especificados com SET PATH.

# Valor de retorno

Character

# Observações

A hora retornada por FTIME( ) é atribuída ao arquivo pelo sistema operacional.

# Exemplo

O exemplo a seguir usa FTIME( ) para exibir a hora da última modificação de FoxUser.dbf, o arquivo de recursos do Visual FoxPro.

```foxpro
? FTIME('FOXUSER.DBF')  && Displays the last modification time
```
