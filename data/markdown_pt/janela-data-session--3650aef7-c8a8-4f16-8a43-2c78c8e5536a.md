# Janela Data Session

Você pode usar a janela Data Session para abrir e exibir tabelas ou views, estabelecer relacionamentos temporários e definir propriedades de área de trabalho.
 **Current Session**
Exibe o nome da sessão de dados atual.
**Aliases**
Exibe o nome da view ou o nome da tabela sem a extensão do arquivo.
**Relations**
Indica o relacionamento temporário estabelecido entre as tabelas ou views na caixa Aliases.
**Properties**
Exibe a caixa de diálogo Work Area Properties, na qual você pode modificar a estrutura de uma tabela, selecionar arquivos de índice e campos e definir filtros de dados. Se nenhuma tabela ou view estiver listada na caixa Aliases, aparece uma caixa de diálogo Open para permitir que você abra uma tabela ou view.
**Browse**
Exibe a tabela ou view selecionada na caixa Aliases em uma janela Browse, onde você pode examinar, editar ou anexar dados.
**Open**
Exibe uma caixa de diálogo Open, semelhante à caixa de diálogo Add Table or View, para que você possa selecionar uma tabela ou view a ser aberta.
**Close**
Remove a tabela ou view selecionada e quaisquer arquivos associados da caixa Aliases.
**Relations**
Define os relacionamentos entre tabelas ou views, usando a caixa de diálogo Expression Builder. A caixa de diálogo Set Index Order aparece antes da caixa de diálogo Expression Builder quando nenhuma ordem de índice foi definida entre as duas tabelas.
**1-To-Many**
Exibe a caixa de diálogo Create One-To-Many Relationships, que permite estabelecer um relacionamento temporário um-para-muitos entre tabelas filhas e tabelas pai. Este botão fica habilitado quando você estabelece relacionamentos entre duas ou mais tabelas selecionando-as na caixa de diálogo View e, em seguida, clicando em Relations .
