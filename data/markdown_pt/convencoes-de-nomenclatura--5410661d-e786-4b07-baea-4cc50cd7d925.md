# Convenções de nomenclatura

Ao nomear objetos, propriedades e métodos expostos, escolha nomes que os usuários possam entender facilmente. O Visual FoxPro não exige as seguintes convenções de nomenclatura, mas as recomenda como parte de bons hábitos de programação e para ajudar a lembrar o tipo de dados com o qual você está trabalhando. Usar as convenções de nomenclatura recomendadas não determina o tipo ou o conteúdo dos dados com os quais você está trabalhando.
