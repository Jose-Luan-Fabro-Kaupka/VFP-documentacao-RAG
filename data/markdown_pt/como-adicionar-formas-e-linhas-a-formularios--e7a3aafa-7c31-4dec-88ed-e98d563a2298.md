# Como: adicionar formas e linhas a formulários

Você pode adicionar formas e linhas a formulários para personalizá-los. Por exemplo, você pode querer separar grupos de controles com uma linha divisória ou incluir controles relacionados em uma caixa para destacá-los.

### Para adicionar uma linha a um formulário
- Na barra de ferramentas Form Controls, escolha o botão Line.
- Arraste no formulário para criar uma linha.

Você pode dimensionar e mover a linha como outros controles ou alterar a inclinação da linha com a propriedade LineSlant na janela Properties.

### Para adicionar uma forma a um formulário
- Na barra de ferramentas Form Controls, escolha o botão Shape.
- Arraste no formulário para criar uma forma.

Você pode alterar o tipo de forma desenhada com a propriedade Curvature na janela Properties.
