# Como: ajustar manualmente a exibição de uma grade em tempo de design

Depois de adicionar colunas à grade, você pode alterar a largura das colunas e a altura das linhas. É possível definir manualmente as propriedades de altura e largura dos objetos de coluna e linha na janela Properties ou defini-las visualmente no modo de design da grade.

### Para alternar para o modo de design da grade
- Escolha Edit no menu de atalho da grade. -ou-
- Na caixa Object da janela Properties (Visual FoxPro), selecione uma coluna da grade.

Quando você está no modo de design da grade, uma borda espessa é exibida ao redor dela. Para sair desse modo, selecione o formulário ou outro controle.

### Para ajustar a largura das colunas de uma grade
- No modo de design da grade, posicione o ponteiro do mouse entre os cabeçalhos das colunas até que ele mude para uma barra com setas apontando para a esquerda e para a direita.
- Selecione a coluna e arraste até obter a largura desejada -ou- Defina a propriedade Width da coluna na janela Properties.

### Para ajustar a altura das linhas de uma grade
- No modo de design da grade, posicione o ponteiro do mouse entre o primeiro e o segundo botão no lado esquerdo do controle Grid até que ele mude para uma barra com setas apontando para cima e para baixo.
- Selecione a linha e arraste até obter a altura desejada. -ou- Defina a propriedade Height da coluna na janela Properties. Dica: você pode impedir que o usuário altere a altura das linhas da grade em tempo de execução definindo a propriedade AllowRowSizing como false (.F.).
