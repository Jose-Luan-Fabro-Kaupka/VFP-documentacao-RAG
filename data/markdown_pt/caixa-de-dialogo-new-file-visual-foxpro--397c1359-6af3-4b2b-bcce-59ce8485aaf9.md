# Caixa de diálogo New File (Visual FoxPro)

Permite criar um novo formulário, relatório, etiqueta ou consulta, dependendo do tipo de arquivo selecionado no momento no Project Manager.

Se você marcar Prompt for Wizard na guia Projects da caixa de diálogo Options, o Visual FoxPro solicita a opção de executar um assistente se houver um assistente associado ao tipo de arquivo selecionado.

> **Observação:** Nomes de arquivo precedidos por um círculo riscado são excluídos quando o projeto é compilado. Se não houver círculo riscado ao lado do nome do arquivo, esse arquivo será incluído na compilação. O nome do arquivo de programa principal aparece em negrito.

Esta caixa de diálogo aparece quando você seleciona New File no menu Project.
 **File Type Wizard**
Abre um assistente que cria o tipo de arquivo selecionado. Se houver um grupo de assistentes para escolher, o Visual FoxPro solicitará que você selecione o assistente desejado. Exibido somente se você marcar Prompt for Wizard na guia Projects da caixa de diálogo Options.
**New File Type**
Exibe uma caixa de diálogo, designer ou janela de edição para que você possa criar o tipo de arquivo selecionado.
