# Guia Style, Form Builder

Esta guia do Form Builder oferece várias opções de estilo para os controles e a opção de ampliar o formulário para acomodar os dados. O tamanho do formulário só será ampliado até o tamanho da Maximum Design Area definido na guia Forms da caixa de diálogo Options.
 **Style**
Especifica o estilo dos controles do formulário, que é determinado pela classe do controle. Selecione um estilo de formulário para visualizar sua aparência.
**Enlarge Form as Needed check box**
Especifica que o construtor amplie o formulário para acomodar os campos selecionados, até o tamanho máximo determinado pela área de design do formulário, se necessário.
