# Função LENC( )

Retorna o número de caracteres em uma expressão de caractere ou campo memo.

```foxpro
LENC(cExpression)
```

#### Parâmetros
 **cExpression**
Especifica a expressão de caractere para a qual LENC( ) retorna o número de caracteres.

# Valor de retorno

Numérico

# Observações

LENC( ) foi projetada para expressões que contêm caracteres de byte duplo. Se a expressão contém apenas caracteres de byte único, LENC( ) é equivalente a LEN( ).

LENC( ) retorna o número de caracteres em uma expressão de caractere ou campo memo contendo qualquer combinação de caracteres de byte único e duplo.

Esta função é útil para manipular conjuntos de caracteres de byte duplo para idiomas como Hiragana e Katakana.
