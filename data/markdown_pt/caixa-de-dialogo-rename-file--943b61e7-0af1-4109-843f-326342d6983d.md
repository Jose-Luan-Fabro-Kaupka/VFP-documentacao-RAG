# Caixa de Diálogo Rename File

Permite renomear o arquivo selecionado.

Esta caixa de diálogo aparece quando você seleciona Rename File no menu Project.
 **Rename**
Exibe o nome de arquivo atual do arquivo selecionado.
**To**
Exibe o nome de arquivo atual, que pode ser substituído digitando um novo nome na caixa. Observação Tenha cuidado ao renomear arquivos. Se você renomear uma tabela que é referenciada na propriedade DataEnvironment de um formulário, esse formulário não conseguirá encontrar a tabela. Se você renomear uma classe que foi adicionada a um formulário, o formulário não conseguirá localizar a classe.
