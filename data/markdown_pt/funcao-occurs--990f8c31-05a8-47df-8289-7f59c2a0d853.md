# Função OCCURS( )

Retorna o número de vezes que uma expressão de caracteres ocorre dentro de outra expressão de caracteres.

```foxpro
OCCURS(cSearchExpression, cExpressionSearched)
```

#### Parâmetros
 **cSearchExpression**
Especifica uma expressão de caracteres que OCCURS( ) pesquisa dentro de cExpressionSearched.
**cExpressionSearched**
Especifica a expressão de caracteres em que OCCURS( ) pesquisa cSearchExpression.

# Valor de retorno

Numeric

# Observações

OCCURS( ) retorna 0 (zero) se cSearchExpression não for encontrada dentro de cExpressionSearched.

# Exemplo

```foxpro
STORE 'abracadabra' TO gcstring
CLEAR
? OCCURS('a', gcstring)  && Displays 5
? OCCURS('b', gcstring)  && Displays 2
? OCCURS('c', gcstring)  && Displays 1
? OCCURS('e', gcstring)  && Displays 0
```
