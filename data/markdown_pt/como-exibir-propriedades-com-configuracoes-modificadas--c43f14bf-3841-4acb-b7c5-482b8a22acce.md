# Como: exibir propriedades com configurações modificadas

Na janela Properties, você pode optar por listar somente as propriedades cujas configurações padrão foram alteradas.

### Para visualizar propriedades com configurações modificadas
- Clique com o botão direito do mouse na janela Properties fora da lista de propriedades.
- No menu de atalho, selecione Non-Default Properties Only .

A lista de propriedades mostra somente as propriedades, eventos e métodos cujas configurações foram alteradas.
