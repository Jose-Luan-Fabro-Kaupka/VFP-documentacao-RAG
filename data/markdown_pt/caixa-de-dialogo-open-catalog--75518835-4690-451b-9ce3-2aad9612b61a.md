# Caixa de diálogo Open Catalog

Permite selecionar uma descrição de catálogo ou nome de arquivo existente para abrir no Component Gallery.
 **Open**
Abre o catálogo ou descrição de catálogo selecionado.
**Browse**
Abre a caixa de diálogo Open do sistema Windows para que você possa localizar um catálogo para abrir.
