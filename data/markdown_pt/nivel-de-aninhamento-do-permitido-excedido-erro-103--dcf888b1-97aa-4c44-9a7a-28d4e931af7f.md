# Nível de aninhamento DO permitido excedido (Erro 103)

O número de níveis de aninhamento foi excedido. Para obter mais informações, consulte Visual FoxPro System Capacities.

Para exceder o limite atual de níveis de aninhamento, altere o número de níveis de aninhamento incluindo a configuração STACKSIZE e o novo limite de níveis de aninhamento em um arquivo de configuração a ser usado quando o Visual FoxPro for iniciado. Para obter mais informações, consulte Special Terms for Configuration Files.
