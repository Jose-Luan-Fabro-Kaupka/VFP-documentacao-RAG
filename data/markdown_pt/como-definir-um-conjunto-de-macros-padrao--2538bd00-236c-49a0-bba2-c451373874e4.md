# Como: definir um conjunto de macros padrão

Um conjunto de macros padrão existe quando o Visual FoxPro é iniciado. Você pode criar e definir seu próprio conjunto de macros padrão por meio da caixa de diálogo Macros.

### Para definir um conjunto de macros padrão
- Na caixa de diálogo Macros, crie ou restaure um conjunto de macros.
- Escolha Set Default .
