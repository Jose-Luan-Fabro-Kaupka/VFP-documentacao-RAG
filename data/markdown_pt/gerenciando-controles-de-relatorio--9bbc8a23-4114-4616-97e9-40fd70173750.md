# Gerenciando controles de relatório

Você pode gerenciar controles de relatório existentes agrupando-os, movendo-os e alinhando-os. Você pode gerenciar cada controle individualmente, ou agrupar controles para gerenciar como uma única unidade. Quando você seleciona um controle de relatório no Report Designer ou Label Designer, o Visual FoxPro exibe muitas opções de gerenciamento de controle de relatório que você pode escolher no menu Format.
