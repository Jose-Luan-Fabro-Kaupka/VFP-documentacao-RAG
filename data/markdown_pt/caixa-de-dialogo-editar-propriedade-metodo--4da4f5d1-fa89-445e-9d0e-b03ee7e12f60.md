# Caixa de diálogo Editar propriedade/método

Permite editar propriedades e métodos existentes ou adicionar novas propriedades e métodos.

Esta caixa de diálogo aparece quando você escolhe Editar propriedade/método no menu Form que aparece quando o Form Designer está aberto ou no menu Class que aparece quando o Class Designer está aberto.

> **Observação:** Para formulários e form sets, a propriedade ou método tem escopo no formulário autônomo ou form set, conforme aplicável.
 **Informações de propriedade/método**
Exibe informações sobre propriedades e métodos adicionados a um formulário, form set ou classe. Você pode ordenar colunas em ordem alfabética ascendente ou descendente clicando no cabeçalho da coluna. Você pode redimensionar as colunas clicando e arrastando entre os cabeçalhos das colunas. Coluna Descrição Nome O nome de cada propriedade e método. Tipo Propriedade (P) ou método (M). Access Indica se uma propriedade tem um método Access correspondente. Yes indica que a propriedade tem um método Access, No indica que a propriedade não tem um método Access. Assign Indica se uma propriedade tem um método Assign correspondente. Yes indica que a propriedade tem um método Assign, No indica que a propriedade não tem um método Assign. Visibilidade Indica a visibilidade de uma propriedade ou método. Para um formulário ou form set, a visibilidade de propriedades e métodos é sempre Public. Para uma classe, a visibilidade pode ser Public, Protected ou Hidden. Para obter mais informações, consulte Protegendo e ocultando membros de classe . Dica No Class Designer, você pode definir o mesmo nível de visibilidade para todas as propriedades e métodos selecionados selecionando várias propriedades e métodos. Observação Todas as propriedades e métodos públicos aparecem em bibliotecas de tipos criadas para arquivos .dll em processo e executáveis (.exe) fora de processo. Ao selecionar várias propriedades e métodos e definir seu nível de visibilidade como Protected ou Hidden, você pode impedir que as propriedades e métodos selecionados apareçam nas bibliotecas de tipos.
**Nova propriedade**
Exibe a caixa de diálogo Nova propriedade, permitindo criar uma nova propriedade. Para obter mais informações, consulte Caixa de diálogo Nova propriedade .
**Novo método**
Exibe a caixa de diálogo Novo método, permitindo criar um novo método. Para obter mais informações, consulte Caixa de diálogo Novo método .
**Remover**
Remove a propriedade ou método selecionado.
**Nome da propriedade/método**
Exibe o nome da propriedade ou método atualmente selecionado.
**Método Access**
Especifica se uma propriedade tem um método Access cujo código é executado sempre que a propriedade é consultada. Selecione esta caixa de seleção para criar um método Access para uma propriedade. Limpe a caixa de seleção para remover um método Access.
**Método Assign**
Especifica se uma propriedade tem um método Assign cujo código é executado sempre que você tenta alterar o valor da propriedade. Selecione esta caixa de seleção para criar um método Assign para uma propriedade. Limpe a caixa de seleção para remover um método Assign.
**Descrição**
Contém a descrição da propriedade ou método que é exibida na parte inferior da janela Propriedades no Class Designer e, se a propriedade não é protegida, no Form Designer.
**Visibilidade (somente classes)**
Especifica se a classe é Public, Protected ou Hidden.
**Aplicar**
Aplica as alterações feitas a uma propriedade ou método.
**Fechar**
Fecha a caixa de diálogo.
