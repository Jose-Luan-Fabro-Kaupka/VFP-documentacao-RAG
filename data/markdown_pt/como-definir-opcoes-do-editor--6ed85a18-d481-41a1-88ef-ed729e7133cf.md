# Como: definir opções do editor

Você pode configurar a janela do editor do Visual FoxPro para exibir o texto da maneira que desejar, como definir a fonte, o alinhamento do texto ou a coloração de sintaxe. Você também pode tornar o editor mais fácil de usar definindo preferências para recuo, quebra automática de linha, cópias de backup automáticas e outros recursos.

Para configurar a janela de edição, defina suas preferências na caixa de diálogo Propriedades de Edição que aparece depois que você abre um programa ou arquivo de texto e seleciona Propriedades no menu Editar. Para obter detalhes sobre as configurações que você pode definir, consulte Caixa de diálogo Propriedades de Edição.

### Para exibir a caixa de diálogo Propriedades de Edição
- Abra a janela de edição de um programa, arquivo de texto ou controle.
- No menu Editar que se torna ativo, selecione Propriedades. Dica Você pode exibir a caixa de diálogo Fonte diretamente clicando com o botão direito na janela de edição e escolhendo Fonte no menu de atalho.

Para obter mais informações sobre como abrir um programa ou arquivo de texto, consulte Como: criar programas.

Por padrão, as configurações que você faz na caixa de diálogo Propriedades de Edição persistem para esse arquivo. Por exemplo, se você alterar a fonte, a fonte de todo o texto na janela atual é alterada. Se você abrir outra janela de edição, as configurações padrão se aplicam.

Você pode optar por salvar suas configurações para que se apliquem a todos os arquivos do mesmo tipo, ou não salvar as novas configurações. Se você aplicar suas configurações a tipos de arquivo semelhantes, o Visual FoxPro usa as configurações que você faz ao editar arquivos com a mesma extensão, por exemplo, todos os arquivos .prg, ou todo o código de método no Form Designer.

### Para evitar persistir alterações nas configurações do editor
- Na janela Propriedades de Edição, desmarque a opção Salvar preferências e clique em OK.

### Para aplicar opções do editor a arquivos semelhantes
- Na caixa de diálogo Propriedades de Edição, selecione Usar estas preferências como padrão e clique em OK.

Você também pode definir a cor e a fonte que o editor usa para identificar palavras-chave, comentários e outros elementos de programas. Para obter detalhes, consulte Guia Editor, caixa de diálogo Opções.
