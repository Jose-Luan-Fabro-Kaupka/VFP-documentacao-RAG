# Como: adicionar índices a campos

Ao adicionar um campo a uma tabela, você pode especificar rapidamente um índice normal para o campo.

### Para adicionar um índice a um campo
- Abra a tabela no Table Designer (Visual FoxPro).
- Na guia Fields, selecione o campo desejado.
- Na lista Index do campo, selecione a ordem de classificação desejada para o índice. O índice criado aparece automaticamente na guia Indexes do Table Designer e usa o campo como expressão de índice.
- Para continuar editando o índice, clique na guia Indexes.

Para obter mais informações, consulte Como: criar índices (Visual FoxPro).
