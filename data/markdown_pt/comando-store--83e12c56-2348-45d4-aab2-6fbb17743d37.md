# Comando STORE

Armazena dados em uma variável, em uma matriz ou em um elemento de matriz.

```foxpro
STORE eExpression TO VarNameList | ArrayNameList-or-
VarName | ArrayName = eExpression
```

#### Parâmetros
 **eExpression**
Especifica uma expressão cujo valor é armazenado na variável, matriz ou elemento de matriz. Se a variável não existir, ela é criada e inicializada com eExpression. Uma matriz deve ser previamente definida com DIMENSION. STORE substitui o valor em uma variável, matriz ou elemento de matriz existente pelo novo valor.
**VarNameList**
Especifica uma lista de variáveis ou elementos de matriz nos quais eExpression é armazenado. Separe os nomes ou elementos de matriz com vírgulas.
**ArrayNameList**
Especifica uma lista de nomes de matrizes existentes nas quais eExpression é armazenado. Separe os nomes das matrizes com vírgulas. STORE inicializa todos os elementos nas matrizes com o valor especificado se SET COMPATIBLE estiver OFF. STORE armazena o valor especificado em variáveis de memória com os nomes especificados se SET COMPATIBLE estiver ON, substituindo quaisquer matrizes existentes com esses nomes.

# Observações

Uma alternativa ao STORE é o operador de atribuição de igual (=). A variável, matriz ou elemento de matriz deve estar à esquerda do sinal de igual e seu valor à direita.

Datas podem ser armazenadas diretamente em variáveis, matrizes ou elementos de matriz usando chaves:

```foxpro
STORE {^1998-12-25} TO gdXMas
```

O número máximo de variáveis ou matrizes que você pode criar está listado no tópico Visual FoxPro System Capacities. O limite pode ser aumentado ou diminuído no arquivo de configuração do Visual FoxPro. Para obter mais informações sobre como configurar o Visual FoxPro, consulte Customizing the Visual FoxPro Environment.

# Exemplo

```foxpro
STORE DATE() TO gdDate
STORE 50 TO gnNumeric
STORE 'Hello' TO gcCharacter
STORE .T. TO glLogical
STORE $19.99 TO gyCurrency
DIMENSION gaMyArray(2,2)
SET COMPATIBLE OFF
STORE 2 TO gaMyArray
CLEAR
DISPLAY MEMORY LIKE g*
```
