# Manipulação de Classes e Objetos

O Visual FoxPro fornece dois operadores especiais para programação orientada a objetos: o operador ponto (.) e o operador de resolução de escopo (::). O Visual FoxPro também adiciona comandos que permitem criar uma classe e criar e adicionar objetos a uma classe.

| Operador, Comando, Função | Descrição |
| --- | --- |
| . (Operador ponto) | Define o escopo de objetos em relação aos seus pais e de propriedades, eventos e métodos em relação aos objetos. |
| :: (Operador de resolução de escopo) | Chama um método da classe pai a partir da subclasse. |
| CREATEOBJECT( ) | Cria um objeto a partir de uma classe, subclasse ou objeto OLE. |
| DEFINE CLASS com cláusula ADD OBJECT | Cria uma definição de classe. A cláusula ADD OBJECT adiciona um objeto baseado em uma classe ou subclasse existente em tempo de design. |
| GETOBJECT( ) | Retorna uma referência a um objeto OLE. |

Para obter mais informações sobre o uso de classes e objetos, consulte Programação Orientada a Objetos.
