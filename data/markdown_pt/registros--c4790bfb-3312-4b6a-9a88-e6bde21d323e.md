# Registros

Um registro é um conjunto de campos em uma tabela. Os registros podem ter até 255 campos. Todos os registros em uma tabela contêm os mesmos campos. Embora o conteúdo dos campos difira de registro para registro, o tamanho de um campo é o mesmo para todos os registros em uma tabela. O tipo de dados de cada campo é o mesmo para todos os registros em uma tabela.

Para criar registros, use o comando INSERT - SQL ou o comando APPEND.

Para obter mais informações sobre como criar registros e usar tabelas, consulte Trabalhando com tabelas (Visual FoxPro).
