# Database Designer (Visual FoxPro)

O Database Designer exibe todas as tabelas, views e relacionamentos contidos em um banco de dados. Quando a janela do Database Designer está ativa, o Visual FoxPro exibe o menu Database e a barra de ferramentas do Database Designer.

Cada tabela é representada por uma janela redimensionável que lista os campos e índices da tabela, se existirem. O Database Designer mostra relacionamentos persistentes exibindo linhas entre tabelas que conectam os índices.

Você pode posicionar as tabelas e views arrastando-as para o lugar desejado ou usando o comando Arrange no menu Database. Se quiser mostrar ou ocultar objetos na janela, use o comando Properties no menu Database.
