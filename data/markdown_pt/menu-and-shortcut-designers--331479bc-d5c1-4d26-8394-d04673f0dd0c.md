# Menu and Shortcut Designers

Você pode criar menus, itens de menu, submenus, linhas que separam grupos de itens de menu relacionados, menus de atalho e assim por diante usando o Menu Designer e o Shortcut Designer. Ao criar seus próprios menus e menus de atalho, você pode personalizar sua cópia do Visual FoxPro ou projetar menus para aplicativos que pretende distribuir.

O Menu and Shortcut Designers contém os seguintes elementos e opções:
 **Prompt**
Especifica títulos de menu e itens de menu em menus ou menus de atalho.
**Mover Control**
Aparece como um botão de seta dupla à esquerda da coluna Prompt quando você insere pelo menos um item. Você pode usar o mover control para organizar a ordem dos itens de menu em tempo de design.
**Result**
Especifica a ação que ocorre quando você escolhe um título de menu ou item de menu. Por exemplo, você pode executar um comando, abrir um submenu ou executar um procedimento.
**Create**
Aparece quando você seleciona Submenu ou Procedure na coluna Result. Você pode usar o botão Create para especificar um submenu ou procedimento para um título de menu ou item de menu.
**Edit**
Aparece somente depois que você criou um submenu ou procedimento na coluna Result para um item de menu. Clicar no botão Edit alterna o Menu Designer para o submenu ou procedimento associado a um título de menu ou item de menu.
**Options**
Abre a caixa de diálogo Prompt Options, que você pode usar para definir atalhos de teclado e outras opções de menu.
**Menu level**
Especifica o menu, submenu ou atalho que você está editando.
**Preview**
Exibe o menu que você está criando.

# Grupo de itens
 **Insert**
Insere um novo item na janela Menu Designer.
**Insert Bar**
Disponível somente quando um item está selecionado no Shortcut Designer e abre a caixa de diálogo Insert System Menu Bar, que permite selecionar e inserir itens de menu padrão do Visual FoxPro.
**Delete**
Disponível somente quando um item está selecionado e exclui a linha selecionada do Menu Designer.
**Move Item**
Disponível somente quando um item está selecionado e abre a caixa de diálogo Move Item, que você pode usar para alterar o local do item de menu.
