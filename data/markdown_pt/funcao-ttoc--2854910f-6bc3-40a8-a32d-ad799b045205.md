# Função TTOC( )

Converte uma expressão DateTime em um valor Character com o formato especificado.

```foxpro
TTOC(tExpression [, 1 | 2 | 3])
```

#### Parâmetros
 **tExpression**
Especifica uma expressão DateTime a converter em uma cadeia de caracteres. Se tExpression contiver apenas uma hora, o Visual FoxPro adiciona a data padrão de 12/30/1899 a tExpression . Se tExpression contiver apenas uma data, o Visual FoxPro adiciona uma hora padrão de 12:00:00 AM (se SET HOURS for 12) ou 00:00:00 (se SET HOURS for 24) a tExpression para produzir um valor DateTime válido.
**1**
Retorna tExpression como uma cadeia de caracteres em um formato adequado para indexação. A cadeia de caracteres retornada tem um formato de 14 caracteres, yyyymmddhhmmss, que não é afetado pelos comandos SET CENTURY , SET HOURS ou SET SECONDS . Para obter mais informações, consulte SET CENTURY , SET HOURS e SET SECONDS .
**2**
Retorna tExpression como uma cadeia de caracteres contendo apenas a parte de hora de tExpression . Para controlar se os segundos da parte de hora são incluídos na cadeia de caracteres, defina os comandos SET SECONDS e SET DATE . O comando SET HOURS determina se AM ou PM é anexado à parte de hora retornada. Para obter mais informações, consulte SET DATE e SET HOURS . Observação Se SET DATE estiver definido como LONG ou SHORT , o formato da configuração de hora no Painel de Controle do Windows determina o formato da cadeia de caracteres.
**3**
Retorna tExpression como uma cadeia de caracteres com o formato DateTime XML. A cadeia de caracteres retornada tem um formato de 19 caracteres yyyy-mm-ddThh:mm:ss que não é afetado pelas configurações dos comandos SET CENTURY , SET HOURS ou SET SECONDS .

# Valor de retorno

Character. TTOC( ) retorna uma expressão DateTime como uma cadeia de caracteres.

> **Observação:** Ao passar o valor 1 ou 3 como segundo parâmetro, a cadeia de caracteres retornada não inclui as designações AM ou PM para indicar horários antes ou depois do meio-dia, respectivamente. Em vez disso, a cadeia usa um relógio de 24 horas, também conhecido como horário militar. Por exemplo, a hora 18:30:00 é equivalente a 06:30:00 PM.

# Observações

Se um valor inválido for passado como segundo parâmetro, TTOC( ) trata o valor inválido como se fosse um valor de 1.

# Exemplo

O exemplo a seguir converte um valor DateTime em um valor Character. O comando STORE armazena os resultados da função DATETIME( ), que retorna a data e a hora atuais como um valor DateTime, em uma variável chamada gtDateTime. O comando ? exibe texto e os resultados da função TYPE( ), que retorna a letra T como o tipo da variável gtDateTime. A função TTOC( ) converte gtDateTime em uma cadeia de caracteres, e a função TYPE( ) retorna a letra T como o tipo atual de gtDateTime.

```foxpro
STORE DATETIME() TO gtDateTime
? "gtDateTime has type: "+TYPE('gtDateTime')
gtDateTime = TTOC(gtDateTime)
? "gtDateTime is now type: "+TYPE('gtDateTime')
```
