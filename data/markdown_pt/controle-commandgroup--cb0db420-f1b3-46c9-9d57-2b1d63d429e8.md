# Controle CommandGroup

Cria um grupo de botões de comando.

```foxpro
CommandGroup
```

# Observações

Use o controle CommandGroup para criar um conjunto de botões de comando que você pode manipular individualmente ou como um grupo. Use o controle CommandButton para criar um botão de comando individual.

Use a propriedade ButtonCount para especificar o número de botões de comando no grupo e a propriedade Caption para especificar um rótulo para o grupo de botões de comando.

Para informações adicionais sobre grupos de botões de comando, consulte o tópico Form Designer e Using Controls.
