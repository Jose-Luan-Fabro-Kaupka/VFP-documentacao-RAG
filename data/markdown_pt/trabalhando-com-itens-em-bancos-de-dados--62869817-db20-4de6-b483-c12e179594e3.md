# Trabalhando com itens em bancos de dados

Depois de criar um banco de dados, você pode executar várias tarefas, por exemplo:
 - Configurar como exibir itens no banco de dados.
- Adicionar tabelas ou criar novas tabelas e views no banco de dados.
- Localizar tabelas no banco de dados.
- Atualizar links entre bancos de dados e as tabelas que contêm quando arquivos de banco de dados ou de tabela são movidos.
- Definir relacionamentos entre tabelas de banco de dados.
- Criar regras que governam a adição, atualização e exclusão de registros em tabelas de banco de dados.
