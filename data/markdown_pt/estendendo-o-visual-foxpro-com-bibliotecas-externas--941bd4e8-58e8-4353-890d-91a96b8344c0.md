# Estendendo o Visual FoxPro com Bibliotecas Externas

Você pode estender os recursos nativos do Microsoft® Visual FoxPro® aproveitando as facilidades de controles Microsoft® ActiveX® (.ocx files), objetos ActiveX e bibliotecas de vínculo dinâmico (DLLs). Bibliotecas externas tornam possível acessar não apenas os recursos de outros programas, mas também os do Microsoft® Windows®. Por exemplo, você pode usar um controle ActiveX para ler e atualizar o registro do Windows diretamente, ou pode chamar funções em nível de sistema vinculando-se a uma das DLLs no Windows.

# Nesta Seção
 **Accessing External Libraries**
Na maioria dos casos, o Visual FoxPro fornece todas as ferramentas que você deve ter para completar seu aplicativo. No entanto, ocasionalmente você pode descobrir que um aplicativo requer funcionalidade adicional não disponível no Visual FoxPro.
**How to: Access ActiveX Controls and Objects**
Você pode usar qualquer controle Microsoft® ActiveX® disponível em seu computador. Para usar um controle ActiveX, você o adiciona a um formulário e então define suas propriedades, escreve manipuladores para seus eventos ou chama seus métodos.
**How to: Access Dynamic-Link Libraries**
Se a funcionalidade que você requer estiver disponível em uma DLL, você pode vincular-se à biblioteca e chamar suas funções.
**How to: Access a Visual FoxPro Library**
Como uma DLL, uma biblioteca do Visual FoxPro (.fll file) contém funções que você pode chamar como qualquer outra função.

# Seções Relacionadas
 **Accessing APIs**
Se seu aplicativo tiver requisitos que não podem ser atendidos pelos recursos já integrados ao Visual FoxPro, você pode estender o programa aproveitando bibliotecas externas — controles Microsoft® ActiveX® ou bibliotecas de vínculo dinâmico (DLLs).
**Accessing the Visual FoxPro API**
Se uma biblioteca externa não estiver disponível para atender às suas necessidades, você pode escrever seu próprio controle Microsoft® ActiveX® ou biblioteca de vínculo dinâmico específica do Visual FoxPro (.fll file). Ao chamar as funções disponíveis na API disponível no Visual FoxPro, você pode criar controles ou bibliotecas que estão fortemente integrados e otimizados para uso no Visual FoxPro.
