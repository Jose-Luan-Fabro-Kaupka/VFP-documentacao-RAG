# Table Designer (Visual FoxPro)

Use o Table Designer para criar e modificar tabelas de banco de dados, tabelas livres, campos e índices. O Table Designer ajuda você a implementar recursos avançados, como regras de validação, valores padrão e classes de controle padrão.

# Nesta seção
 **Fields Tab, Table Designer**
Exibe os campos da tabela em uma grade rolável.
**Indexes Tab, Table Designer**
Contém uma grade rolável para definir índices.
**Table Tab, Table Designer**
Exibe informações sobre a tabela e permite especificar triggers e regras em nível de registro.
