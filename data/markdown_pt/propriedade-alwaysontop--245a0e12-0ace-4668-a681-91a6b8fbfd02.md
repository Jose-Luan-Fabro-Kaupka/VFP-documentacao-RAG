# Propriedade AlwaysOnTop

Impede que outras janelas cubram a janela do formulário. Disponível em tempo de design; leitura/gravação em tempo de execução.

```foxpro
Object.AlwaysOnTop[ = lExpr]
```

# Valor de retorno
 **lExpr**
As configurações da propriedade AlwaysOnTop são: Configuração Descrição True (.T.) O formulário está sempre no topo (somente outra janela com a propriedade AlwaysOnTop definida como True (.T.) pode ficar acima do formulário). False (.F.) (Padrão) O formulário pode ser coberto por outra janela.

# Observações

Aplica-se a: Form Object | _SCREEN System Variable
