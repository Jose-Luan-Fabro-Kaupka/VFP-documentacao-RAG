# Trabalhando com objetos no Visual FoxPro

O Visual FoxPro oferece muitas maneiras de trabalhar com objetos. Ao usar objetos, você pode criar objetos a partir de classes para código mais reutilizável, usar objetos para armazenar dados e criar código mais fácil de ler e referenciar.

# Nesta seção
 **Objects in Visual FoxPro**
Apresenta objetos no Visual FoxPro e como criá-los e usá-los.
**Creating Objects from Classes**
Descreve como criar um objeto com base em uma classe visual salva.
**How to: Add Classes to Forms**
Descreve como adicionar uma classe a um formulário usando o Project Manager.
**Adding Objects to a Container Class**
Detalha como adicionar objetos a um contêiner por meio do uso da cláusula ADD OBJECT no comando DEFINE CLASS ou do método AddObject.
**How to: Add Objects to a Control or Container Class**
Descreve como adicionar objetos a uma classe usando o Class Designer.
**Creating Table Navigation Buttons**
Fornece uma explicação de como projetar e construir botões de navegação de tabela por meio de código.
**Defining a Grid Control**
Descreve como definir um controle de grade programaticamente.
**How to: Set Properties**
Descreve como definir as propriedades de um objeto em tempo de execução ou em tempo de design.
**Container Hierarchy Object Referencing**
Descreve como objetos são referenciados na hierarquia de contêineres e explica a importância de identificar objetos em relação à hierarquia de contêineres.
**Object Reference Creation**
Explica como fazer uma referência a um objeto e descreve os benefícios de criar referências em vez de fazer cópias de objetos.
**Object and Member Arrays**
Descreve como criar arrays contendo objetos e definir membros de classe como arrays.
**Data Storage with Objects**
Descreve quando e como armazenar dados em objetos.
**How to: Call Methods**
Descreve como chamar os métodos de um objeto de qualquer lugar em um aplicativo depois que ele foi criado.
**Object and Data Integration**
Contém informações sobre por que integrar objetos e dados é importante.
**How to: Create Instances of Classes with the Class Browser**
Descreve como criar uma nova instância de uma classe usando o Class Browser.
**How to: Add Controls to Forms with the Class Browser**
Descreve como adicionar objetos a um formulário com o Class Browser.
