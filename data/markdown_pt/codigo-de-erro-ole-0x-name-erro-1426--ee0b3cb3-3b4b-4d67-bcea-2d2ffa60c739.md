# Código de erro OLE 0x"name" (Erro 1426)

Você recebeu um código de erro hexadecimal do OLE e uma breve descrição do erro. A solução depende do erro retornado pelo OLE. Embora o erro seja externo ao Visual FoxPro, você pode usar a função AERROR( ) para determinar se uma mensagem de erro mais específica foi enviada pelo provedor OLE.
