# Nenhuma coluna de chave especificada para a tabela de atualização "name". Use a propriedade KeyFieldList do cursor (Erro 1492)

Nenhuma coluna de chave foi especificada na propriedade KeyFieldList para uma tabela base que está sendo atualizada.

Modifique a propriedade KeyFieldList para incluir colunas de chave para cada tabela que está sendo atualizada. Os campos de chave também precisam ser incluídos na propriedade UpdateNameList. Para a maioria das exibições, você pode usar os Designers de consulta e exibição para definir as propriedades de atualização da exibição e depois salvar a exibição de volta no banco de dados. Para obter mais informações, consulte Função CURSORGETPROP( ).
