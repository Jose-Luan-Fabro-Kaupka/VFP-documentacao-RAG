# Class Designer

Use o Class Designer para criar e modificar classes visualmente. Quando a janela Class Designer está ativa, o Microsoft Visual FoxPro exibe o menu Class. O menu View permite abrir ferramentas complementares de design de classes, como a janela Properties, a Form Controls Toolbar e a Layout Toolbar.

As classes são armazenadas em arquivos de biblioteca de classes (.vcx). Para modificar mais de uma classe, você pode abrir vários class designers ao mesmo tempo.

Você pode salvar classes pressionando CTRL+E enquanto estiver no editor de código. Quando você reabre a classe, o editor de código reabre no mesmo local do código.

Para obter informações detalhadas sobre o design de classes, consulte Object-Oriented Programming e os tópicos Como: criar classes e subclasses e Como: salvar formulários.

A janela Class Designer consiste na janela Class, que exibe uma única classe. A janela Class está ancorada no canto superior esquerdo do Class Designer e não pode ser movida, a menos que a janela contenha tipos de barra de ferramentas.
