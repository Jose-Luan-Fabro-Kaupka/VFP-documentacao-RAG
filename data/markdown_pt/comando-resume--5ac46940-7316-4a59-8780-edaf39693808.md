# Comando RESUME

Continua a execução de um programa suspenso.

```foxpro
RESUME
```

# Observações

Use SUSPEND para suspender a execução do programa. O programa suspenso reinicia na linha onde a execução foi suspensa.

SUSPEND e RESUME são ferramentas valiosas de depuração. Você pode suspender um programa para examinar o status atual do ambiente do Visual FoxPro, incluindo variáveis de memória, janela, barra de menu ou definições de menu.

> **Cuidado:** Para evitar que comandos executados quando um programa está suspenso interfiram na saída subsequente do programa, emita CLEAR para limpar a janela principal do Visual FoxPro ou a janela definida pelo usuário ativa antes de retomar a execução do programa.
