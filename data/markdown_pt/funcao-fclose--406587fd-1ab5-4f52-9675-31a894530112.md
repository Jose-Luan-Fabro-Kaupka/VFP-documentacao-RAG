# Função FCLOSE( )

Libera e fecha um arquivo ou porta de comunicação aberto com uma função de arquivo de baixo nível.

```foxpro
FCLOSE(nFileHandle)
```

#### Parâmetros
 **nFileHandle**
Especifica o identificador de arquivo do arquivo de baixo nível a ser fechado. O identificador de arquivo numérico é retornado quando você cria o arquivo com FCREATE( ) ou abre o arquivo com FOPEN( ) .

# Valor de retorno

Lógico

# Observações

Se o arquivo for fechado com sucesso, FCLOSE( ) retorna true (.T.) e libera o identificador de arquivo. Se o arquivo não puder ser fechado, FCLOSE( ) retorna false (.F.).

CLOSE ALL também fecha arquivos de baixo nível.
