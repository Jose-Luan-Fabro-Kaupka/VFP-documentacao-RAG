# Como: exibir informações de arquivo e projeto

Você pode exibir informações sobre arquivos individuais e sobre o projeto como um todo. Por exemplo, você pode exibir o histórico de check-out de um arquivo individual ou da lista de projeto. As informações normalmente disponíveis incluem:
 - O número da versão, que indica quantas vezes uma nova versão do arquivo ou da lista de projeto foi incluída no check-in.
- Quem incluiu o arquivo ou arquivo de projeto no check-in cada vez.
- A data e hora em que foi incluído no check-in.
- Quais comentários o desenvolvedor adicionou ao incluir o arquivo ou lista de projeto no check-in.

### Para visualizar o histórico de check-out de um arquivo ou da lista de projeto
- Se você estiver visualizando o histórico de um único arquivo, no Project Manager , selecione o arquivo para o qual deseja ver o histórico.
- Para um arquivo individual, no menu Project, escolha Source Control , depois escolha Show History . Para a lista de projeto, no menu Project, escolha Source Control e depois escolha Show Project List History . As opções específicas disponíveis neste comando de menu dependem do seu sistema de controle de origem. Para detalhes, escolha Help na caixa de diálogo exibida ou consulte a documentação do seu sistema de controle de origem.

Você também pode visualizar as informações sobre um indivíduo ou sobre o projeto que está sendo mantido pelo sistema de controle de origem. Isso geralmente inclui informações como o status de check-out do arquivo ou lista de projeto, se o arquivo é um arquivo de texto ou binário (o que determina se você pode mesclar suas alterações com o arquivo armazenado centralmente) e assim por diante.

### Para visualizar informações de controle de origem de um arquivo ou da lista de projeto
- Se você estiver visualizando o histórico de um único arquivo, no Project Manager , selecione o arquivo para o qual deseja ver o histórico.
- Para um arquivo individual, no menu Project, escolha Source Control e depois escolha Source Control Properties . Para a lista de projeto, no menu Project, escolha Source Control e depois escolha Project Properties . As opções específicas disponíveis neste comando de menu dependem do seu sistema de controle de origem. Para detalhes, escolha Help na caixa de diálogo exibida ou consulte a documentação do seu sistema de controle de origem.
