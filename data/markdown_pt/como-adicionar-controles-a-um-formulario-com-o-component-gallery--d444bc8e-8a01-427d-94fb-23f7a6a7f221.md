# Como: adicionar controles a um formulário com o Component Gallery

Você pode usar o Component Gallery para adicionar rapidamente controles e objetos personalizados a um formulário. O Component Gallery contém dezenas de controles e objetos personalizados que reduzem significativamente a quantidade de codificação necessária para criar formulários especializados.

### Para abrir o Component Gallery
- No menu Tools, escolha Component Gallery.

Quando o Component Gallery está aberto, você pode arrastar controles e objetos personalizados do Component Gallery e soltá-los em um formulário.
