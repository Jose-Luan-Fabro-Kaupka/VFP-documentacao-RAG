# Web Publishing Wizard

Este wizard usa dados de uma tabela ou view para criar um documento HTML. Você pode usar ou compartilhar o arquivo que o Web Publishing wizard cria em seu navegador ou editá-lo em um editor de texto.

 Para acessar o Web Publishing wizard
 - No menu Tools, escolha Wizards e clique em Web Publishing.

No Web Publishing wizard, você pode especificar o layout dos dados, bem como o layout e o estilo do cabeçalho e do corpo da página HTML. Você pode usar os layouts e estilos visuais padrão que vêm com o wizard ou personalizar esses layouts e estilos. Além disso, você pode carregar um arquivo de folha de estilo em cascata (.css) existente.

# Etapa 1 – Select Fields

Nesta etapa, você pode escolher uma tabela livre ou uma tabela dentro de um banco de dados como fonte para sua página Web. Você pode selecionar campos de apenas uma única tabela ou view.

 Para selecionar os campos para sua página Web
 - Use os controles Databases and Tables para localizar e selecionar a tabela que deseja usar.
- Na caixa de listagem Available fields, selecione um ou mais campos que deseja usar da tabela selecionada e use os botões de seta para movê-los para a caixa Selected fields.

# Etapa 2 – Sort Records

Esta etapa permite especificar um ou mais campos pelos quais classificar os registros em sua página Web.

Escolha até três campos ou uma tag de índice que já existe no banco de dados para determinar a ordem em que os resultados da view serão classificados. Selecione Ascending ou Descending para determinar a ordem da classificação.

Use Remove para eliminar um campo da lista de classificação.

# Etapa 3 – Choose Style

Esta etapa permite selecionar um layout de dados e um estilo visual para sua página Web.

Você pode modificar o layout selecionado usando o botão Options. Você pode substituir as configurações de estilo visual padrão e adicionar suas próprias tags HTML usando o botão Advanced.
 **Options**
Abre a caixa de diálogo Layout Options para que você possa modificar propriedades específicas do layout de dados que escolheu.
**Advanced**
Abre a caixa de diálogo Advanced para que você possa modificar a aparência de sua página Web adicionando uma folha de estilo em cascata (.css), cores, texto e tags HTML.
**Preview**
Exibe uma amostra de sua página Web no layout de dados e estilo visual selecionados. A visualização é limitada a 10 registros por página.

# Etapa 4 - Finish

Nesta etapa, você especifica como salvar e usar sua página Web.
 **Save Web page for later use**
Salva a página Web no disco para uso posterior.
**Save Web page and modify it in a text editor**
Salva a página Web no disco e a abre em seu editor de texto padrão para que você possa modificá-la.
**Save Web page and open it in a browser**
Salva a página Web no disco e a abre em seu navegador Web padrão.
**Create script for generating Web page**
Cria um arquivo de programa que criará dinamicamente sua página Web.

Save style

Use para especificar e salvar o nome do estilo que você aplica a uma página Web.
