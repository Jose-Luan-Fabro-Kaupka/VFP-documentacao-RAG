# Builders

Builders são ferramentas que auxiliam na definição de propriedades de controles em um formulário. Diferentemente dos assistentes, os builders são reentrantes, de modo que você pode reabrir um builder em um controle específico repetidamente.

O Visual FoxPro inclui diversos builders genéricos para muitos dos controles de formulário comuns, incluindo grades, caixas de listagem, caixas de combinação, caixas de seleção, grupos de comando e grupos de opção.

O Visual FoxPro oferece uma ampla seleção de builders. Para detalhes, consulte a lista abaixo.

# Nesta seção
 **Como: usar builders**
Fornece instruções para criar controles e usar os builders.
**Application Builder**
Exibe uma caixa de diálogo com guias para simplificar a criação e modificação de formulários, controles complexos e outros elementos opcionais de aplicações eficazes e satisfatórias.
**AutoFormat Builder**
Permite aplicar um conjunto de estilos a controles selecionados do mesmo tipo.
**Combo Box Builder**
Facilita a definição de propriedades para um controle Combo Box.
**Command Group Builder**
Facilita a definição de propriedades para um controle Command Group.
**CursorAdapter Builder**
Facilita a construção de objetos CursorAdapter com mais rapidez.
**DataEnvironment Builder**
Facilita a construção de objetos DataEnvironment que usam os recursos de objetos CursorAdapter.
**Edit Box Builder**
Facilita a definição de propriedades para um controle Edit Box.
**Form Builder**
Facilita a adição de campos como novos controles a um formulário.
**Grid Builder**
Permite definir propriedades para um controle Grid.
**List Box Builder**
Facilita a definição de propriedades para um controle List Box.
**Option Group Builder**
Facilita a definição de propriedades para um controle Option Group.
**Referential Integrity Builder**
Ajuda a garantir a integridade referencial configurando gatilhos para controlar como registros são inseridos, atualizados ou excluídos em tabelas relacionadas.
**Text Box Builder**
Facilita a definição de propriedades para um controle Text Box.
**XML Web Service Builder**
Permite associar um serviço Web XML a um controle em um formulário do Visual FoxPro ou a um objeto, como um cursor adapter no ambiente de dados do formulário, sem escrever código.
