# Propriedade MainFile

Contém o nome e o caminho do arquivo definido como o programa principal de um projeto. Somente leitura.

```foxpro
Object.MainFile
```

# Observações

Aplica-se a: Project Object (Visual FoxPro)

MainFile contém a cadeia vazia se um programa principal não foi definido para um projeto. Um programa ou formulário pode ser definido como programa principal em um projeto clicando com o botão direito do mouse no programa ou formulário e escolhendo Set Main no menu de atalho. Você também pode usar o método SetMain para especificar programaticamente um programa principal para um projeto.
