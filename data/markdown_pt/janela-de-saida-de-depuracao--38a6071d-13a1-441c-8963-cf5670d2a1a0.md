# Janela de Saída de Depuração

Permite exibir a saída de programas, procedimentos ou código de métodos ativos.

Esta janela é ativada quando você escolhe Output no menu Window, Debugger Window.
 **Painel Output**
Exibe cadeias de caracteres especificadas pelo comando DEBUGOUT e, se o rastreamento de eventos estiver habilitado, os nomes dos eventos do sistema conforme ocorrem.

 Para salvar o texto na janela
 - Escolha Save Output As no menu File na janela Debugger.
