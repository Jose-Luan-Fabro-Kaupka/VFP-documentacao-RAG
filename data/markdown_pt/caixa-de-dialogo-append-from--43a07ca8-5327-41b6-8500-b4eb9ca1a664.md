# Caixa de diálogo Append From

Permite adicionar registros à tabela ou visualização atual a partir de outra tabela, planilha ou arquivo de texto. Esta caixa de diálogo é exibida quando você seleciona Append Records no menu Table.
 **Type**
Especifica o tipo de arquivo do qual anexar registros.
**From**
Fornece espaço para você digitar o nome do arquivo do qual anexar registros. Se você não conhece o nome, escolha o botão de diálogo para exibir a Open Dialog Box e selecionar o arquivo desejado.
**To**
Exibe o caminho e o nome do arquivo da tabela ou visualização à qual os registros serão anexados.
**Options**
Exibe a Append From Options Dialog Box, na qual você especifica campos a anexar e constrói uma expressão que os registros a serem anexados devem satisfazer.

Para obter mais informações, consulte Appending Data in Importing and Exporting Data.
