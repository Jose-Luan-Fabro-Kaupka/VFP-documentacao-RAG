# Método MoveItem

Move um item para uma nova posição em um list box.

```foxpro
ListBox.MoveItem(nItemIndex, nMoveBy)
```

#### Parâmetros
 **nItemIndex**
Especifica o índice atual do item que você deseja mover.
**nMoveBy**
Indica quantas posições o item deve ser movido. Um valor positivo indica movimento para baixo. Um número negativo indica movimento para cima.

# Observações

Aplica-se a: ListBox Control

Chamar o método MoveItem dispara o evento OnMoveItem.

O evento OnMoveItem sempre dispara uma vez quando o método MoveItem é chamado; no entanto, a movimentação de um item no list box ocorre somente se a propriedade RowSourceType do list box estiver definida como 0 (None) ou 1 (Value).
