# Como: adicionar imagens a relatórios

Você pode adicionar imagens ao layout de página de relatório ou etiqueta. Por exemplo, você pode adicionar o logotipo da empresa ao cabeçalho de página de uma fatura. Você pode adicionar imagens de arquivos de imagem ou conteúdos de campos General a relatórios usando o controle Picture/OLE Bound.

> **Dica:** Quando você deseja adicionar uma imagem que pode variar dependendo do registro ou de um grupo de registros, armazene a imagem em um campo General em vez de um arquivo. Quando você adiciona a imagem ao layout, adicione a imagem especificando o campo General em vez de um arquivo. Para obter mais informações, consulte General Field Type e Como: adicionar campos General a relatórios.

### Para adicionar uma imagem ao layout de página
- Abra o relatório ou etiqueta no designer apropriado.
- No menu Report, aponte para Insert Control e clique em Picture/OLE Bound. A caixa de diálogo Picture/OLE Bound Properties é aberta. Observação Se a variável de sistema _REPORTBUILDER não estiver definida para o Report Builder padrão ou estiver definida para um builder de terceiros, a caixa de diálogo Report Picture é exibida ou uma caixa de diálogo diferente pode ser exibida. Para obter mais informações, consulte a variável de sistema _REPORTBUILDER e Report Picture Dialog Box.
- Na caixa de diálogo Picture/OLE Bound Properties, clique na guia General se ela não estiver selecionada.
- Na área Control source, execute uma das seguintes ações: Para usar um arquivo de imagem no disco (ou em seu projeto) em um layout de relatório, clique em Image file name. Na caixa Control source, digite o nome do arquivo e inclua o caminho, se necessário. Dica Para procurar e selecionar um arquivo, clique no botão de reticências ( … ) para exibir a caixa de diálogo Open Picture. Para usar uma imagem armazenada em um campo General de uma tabela, clique em General field name. Na caixa Control source, digite o nome do campo General que contém a imagem. Dica Para procurar e selecionar um campo, clique no botão de reticências ( … ) para abrir a caixa de diálogo Expression Builder. A caixa de diálogo Expression Builder exibe campos disponíveis quando o data environment do relatório contém uma tabela ou view. Para usar uma expressão (como uma variável de cadeia de caracteres, um campo de caractere não-General ou um literal de cadeia de caracteres) que resolve para o nome de um arquivo de imagem, clique em Expression or variable name. Dica Para construir uma expressão ou selecionar uma variável, clique no botão de reticências ( … ) para abrir o Expression Builder para que você possa construir uma expressão ou selecionar uma variável. Para obter mais informações, consulte Expression Builder Dialog Box. Para usar uma instância de uma classe Image do Visual FoxPro como fonte de uma imagem em um layout de relatório, clique em Expression or variable name e insira um nome de variável contendo uma referência de objeto para o controle Image de um formulário que tenha sua propriedade PictureVal definida adequadamente. Dica O uso da propriedade PictureVal de um objeto Image como fonte de imagem em um relatório é suportado apenas no modo de saída assistida por objetos. Funcionará no modo compatível com versões anteriores, em alguns casos, mas os resultados não são garantidos. Por exemplo, no modo compatível com versões anteriores, controles Picture/OLE Bound com esta fonte podem não respeitar a opção de dimensionamento Clip. Para obter mais informações, consulte o comando SET REPORTBEHAVIOR.
- Quando terminar na caixa de diálogo Picture/OLE Bound Properties, clique em OK. O controle de relatório Picture/OLE Bound aparece na banda Page Header por padrão. Depois de adicionar o controle, você pode movê-lo arrastando-o para a posição desejada. Dica Você pode adicionar controles Picture/OLE Bound na posição desejada selecionando-os na Report Controls toolbar e desenhando-os. Se você especificou um arquivo de imagem, o controle de relatório Picture/OLE Bound exibe uma imagem. Se você especificou um campo General, o controle de relatório Picture/OLE Bound exibe um frame genérico. Quando você especifica imagens, elas mantêm seu tamanho original por padrão. Para obter mais informações, consulte Como: redimensionar controles de relatório.

Para obter mais informações, consulte General Tab, Report Control Properties Dialog Box (Report Builder).

Para um exemplo de relatório contendo imagens, consulte o relatório de exemplo Wrapping.frx no diretório do Visual FoxPro, ...\Samples\Solution\Reports.
