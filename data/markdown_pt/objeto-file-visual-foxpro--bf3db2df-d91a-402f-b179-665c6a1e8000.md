# Objeto File (Visual FoxPro)

Instanciado quando um arquivo é adicionado a um projeto.

```foxpro
File
```

# Observações

Um objeto file é criado e instanciado para cada arquivo adicionado a um projeto. Um objeto file fornece uma referência de objeto ao arquivo no projeto e permite determinar informações sobre o arquivo e manipulá-lo por meio das propriedades e métodos do objeto File.

A coleção files de um projeto é composta por todos os objetos file no projeto.

Observe que um objeto file é um objeto COM; portanto, atribuir uma referência de objeto file a uma variável de memória cria uma variável de memória da classe "Unknown Type".
