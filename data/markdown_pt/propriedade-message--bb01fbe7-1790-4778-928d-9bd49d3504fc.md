# Propriedade Message

Especifica a mensagem de erro real para um objeto de exceção. Leitura/gravação em tempo de execução.

```foxpro
Exception.MessageProperty
```

# Valor de retorno

Tipo de dados Caractere

# Observações

Aplica-se a: classe Exception (Visual FoxPro)

Idêntico ao valor retornado pela função MESSAGE() e ao segundo elemento no array produzido pela função AERROR().
