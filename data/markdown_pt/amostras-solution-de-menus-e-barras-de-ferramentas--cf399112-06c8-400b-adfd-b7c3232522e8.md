# Amostras Solution de menus e barras de ferramentas

# Nesta seção
 **Amostra Adicionar itens de menu em tempo de execução**
Ilustra como adicionar itens de menu a um menu em tempo de execução.
**Amostra Adicionar menus personalizados**
Ilustra como adicionar menus personalizados semelhantes aos do Microsoft Office 2000.
**Amostra Alterar atributos de fonte**
Ilustra como usar uma barra de ferramentas para definir propriedades de fonte e cor para controles em um formulário.
**Amostra Coordenar itens de menu e botões de barra de ferramentas**
Ilustra como coordenar itens de menu e botões de barra de ferramentas que fornecem a mesma funcionalidade.
**Amostra Criar menus de atalho dinâmicos**
Ilustra como criar menus de atalho alternativamente.
**Amostra Desabilitar ou exibir uma marca de seleção ao lado de um item de menu**
Ilustra como tornar itens de menu indisponíveis dinamicamente e exibir marcas de seleção ao lado de itens de menu específicos.
**Amostra Exibir menus de atalho**
Ilustra como exibir menus de atalho quando o usuário clica com o botão direito em um objeto.
**Amostra Usar barras de ferramentas de estilo**
Ilustra como exibir uma barra de ferramentas personalizada com uma lista suspensa de botões de imagem semelhante às barras de ferramentas do Microsoft Office.
