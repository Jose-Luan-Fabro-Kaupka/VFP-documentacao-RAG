# Propriedade Controls (Visual FoxPro)

Uma matriz para acessar os controles de um objeto contêiner. Disponível em tempo de execução.

```foxpro
ContainerObject.Controls(Index).Property[ = Expr]
```

# Valor de retorno
 **Expr**
Especifica um valor de propriedade para um controle contido em ContainerObject.

# Observações

Aplica-se a: Objeto Column | Objeto Container | Objeto Control (Visual FoxPro) | Objeto Form | Objeto Page | Variável de sistema _SCREEN | Objeto ToolBar

Use a propriedade Controls para acessar as propriedades dos objetos contidos.
