# Comando * 

Indica o início de uma linha de comentário não executável em um arquivo de programa.

```foxpro
* [Comments]
```

#### Parâmetros
 **Comments**
Especifica o comentário na linha de comentário. Por exemplo: * This is a comment

# Observações

Coloque um ponto e vírgula (;) no final de cada linha de comentário que continua na linha seguinte.

Qualquer texto adicionado a um método ou evento em uma Biblioteca de Classes Visuais (VCX) ou formulário (SCX) na janela Code fará com que essa classe tenha comportamento Override para o método ou evento. Portanto, o código do método ou evento em uma classe pai não será executado por padrão (deve ser executado explicitamente). Isso inclui linhas de comentário não executáveis que começam com "*".

# Exemplo

```foxpro
* Initialize the page number;
   variable.
STORE 1 to gnPageNum
* Set up the loop
DO WHILE gnPageNum <= 25  && loop 25 times
   gnPageNum = gnPageNum + 1
ENDDO  && DO WHILE gnPageNum <= 25
```
