# Caixa de Diálogo Create

Aparece quando você seleciona Project, Database ou Table na caixa de diálogo New e escolhe New File. Permite especificar o diretório, o nome e o tipo do novo arquivo.
 **Code Page**
Exibe a caixa de diálogo Code Page para que você possa especificar a página de código necessária para visualizar o arquivo corretamente. Este comando se aplica apenas a arquivos de texto, como arquivos de programa (.prg), consulta (.qpr) e texto (.txt).
