# Propriedade IsBinary

Especifica se o campo é Binary no XML Schema.

```foxpro
XMLField.IsBinary [= lValue]
```

# Valor de retorno
 **lValue**
Tipo de dados Logical. A tabela a seguir lista os valores para lValue . lValue Descrição False (.F.) (Padrão) O campo não é Binary, mas String no XML Schema. True (.T.) O campo é especificado como Binary no XML Schema.

# Observações

Aplica-se a: Classe XMLField

Para a propriedade IsBase64 se aplicar, IsBinary deve ser True (.T.).
