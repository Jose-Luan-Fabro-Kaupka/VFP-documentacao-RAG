# Erro interno de consistência .DBC (Erro 1550)

Ocorreu um erro interno de banco de dados.
 - O banco de dados está corrompido. Tente VALIDATE DATABASE para diagnosticar ou reparar o problema.
- O índice do contêiner de banco de dados (.dcx) está corrompido ou não está sincronizado com o arquivo de contêiner de banco de dados (.dbc), geralmente como resultado de um desligamento anormal do sistema. Reconstrua o índice fechando o banco de dados, excluindo o arquivo de índice dbc_name.DCX e reabrindo o banco de dados. Se o problema não for corrigido, registre suas ações recentes ao usar o Visual FoxPro e então entre em contato com o Suporte da Microsoft.
