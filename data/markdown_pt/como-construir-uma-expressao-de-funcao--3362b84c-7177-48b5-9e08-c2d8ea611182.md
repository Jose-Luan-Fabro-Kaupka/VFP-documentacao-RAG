# Como: construir uma expressão de função

No Expression Builder, você pode construir uma expressão que contém uma função.

### Para construir uma expressão de função
- Quando disponível, clique no botão de reticências (...) para abrir o Expression Builder.
- Na área Functions do builder, selecione uma função de uma das listas de funções.
- Clique em OK.

Para obter mais informações, consulte Caixa de diálogo Expression Builder.
