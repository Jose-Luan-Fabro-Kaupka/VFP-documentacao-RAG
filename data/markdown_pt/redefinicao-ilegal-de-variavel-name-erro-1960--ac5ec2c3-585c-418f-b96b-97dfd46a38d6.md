# Redefinição ilegal de variável "name" (Erro 1960)

O comando PUBLIC ou o comando LOCAL tentou alterar o estado de uma variável que já existe. Por exemplo, se você tem uma variável x que não é pública e emite PUBLIC x, recebe este erro.

Variáveis criadas na janela Command (Visual FoxPro) são públicas por definição. Para criar uma variável que não seja pública, use um arquivo de programa (.PRG).
