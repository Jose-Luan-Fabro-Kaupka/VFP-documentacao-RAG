# Comando SET STATUS

Exibe ou remove a barra de status baseada em caracteres.

```foxpro
SET STATUS ON | OFF
```

#### Parâmetros
 **ON**
Se SET STATUS estiver ON, a barra de status baseada em caracteres é exibida mostrando o nome do programa em execução no momento (se houver), o alias da tabela ativa, a posição atual do ponteiro de registro, o número de registros na tabela e o estado das teclas Insert, NumLock e CapsLock. O status de bloqueio de registro ou arquivo também é mostrado na barra de status quando a tabela é aberta para uso compartilhado. A barra de status é atualizada cada vez que você executa um comando que altera informações de status.
**OFF**
(Padrão) Emita SET STATUS OFF para remover a barra de status.
