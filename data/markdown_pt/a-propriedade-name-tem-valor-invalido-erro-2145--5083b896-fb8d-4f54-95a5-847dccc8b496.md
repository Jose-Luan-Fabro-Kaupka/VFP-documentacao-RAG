# A propriedade "name" tem valor inválido. (Erro 2145)

Ocorre quando as propriedades UpdateableFieldList e UpdateNameList dos objetos CursorAdapter são definidas com valores inválidos.
 - Certifique-se de que os valores atribuídos às propriedades acima são válidos. Para obter mais informações, consulte Data Access Management Using CursorAdapters .
