# Comando &&

Indica o início de um comentário inline não executável em um arquivo de programa.

```foxpro
&& [Comments]
```

#### Parâmetros
 **&& [ Comments ]**
Especifica comentários inline que seguem.

# Observações

Inserir comentários inline para denotar o fim dos comandos de programação estruturada IF ... ENDIF, DO e FOR ... ENDFOR melhora muito a legibilidade dos programas ao incluir muitas dessas estruturas.

> **Cuidado:** Incluir e comerciais duplos (&&) em um literal de cadeia de caracteres, por exemplo, "AAA&&BBB", gera um erro. Em vez disso, para incluir e comerciais duplos, use concatenação conforme mostrado: "AAA&" + "&" + "BBB".

> **Observação:** Ao usar concatenação, tenha cuidado com a colocação de um e comercial simples (&), que é usado para executar substituição de macro e, portanto, pode produzir resultados indesejáveis. Por exemplo, suponha que você atribua a cadeia de caracteres "YYY" a uma variável, BBB. Executar concatenação usando "AAA&" e "&BBB" substitui "BBB" por "YYY", então, em vez de obter o resultado "AAA&&BBB", o resultado é "AAA&YYY". Para obter mais informações, consulte Comando &.

Para continuar um comentário na linha seguinte, coloque um ponto e vírgula (;) no final da linha de comentário a ser continuada.

> **Observação:** Em versões anteriores do Visual FoxPro, você não pode colocar && e um comentário após o ponto e vírgula usado para continuar uma linha de comando em uma linha adicional.

# Exemplo

O exemplo a seguir inclui os comentários inline "20 years of monthly payments" indicados pelo comando &&:

```foxpro
STORE (20*12) TO gnPayments  && 20 years of monthly payments
NOTE  Initialize the page number;
   variable.
STORE 1 to gnPageNum
* Set up the loop
DO WHILE gnPageNum <= 25  && loop 25 times
   gnPageNum = gnPageNum + 1
ENDDO  && DO WHILE gnPageNum <= 25
```
