# Evento RangeLow

Para um spinner ou text box, ocorre quando o controle perde o foco. Para um combo box ou list box, ocorre quando o controle recebe o foco.

```foxpro
PROCEDURE Object.RangeLow
```

# Observações

Aplica-se a: ComboBox Control | ListBox Control | Spinner Control | TextBox Control (Visual FoxPro)

Um evento RangeLow pode retornar um valor numérico ao Visual FoxPro por meio de uma instrução RETURN. Para um spinner ou text box com valor numérico, se o valor retornado ao Visual FoxPro for maior que o valor inserido no controle, o controle mantém o foco. Para um combo box ou list box, o valor retornado ao Visual FoxPro especifica qual item no controle é selecionado inicialmente. Por exemplo, se 2 for retornado ao Visual FoxPro, o segundo item no controle é selecionado inicialmente.
