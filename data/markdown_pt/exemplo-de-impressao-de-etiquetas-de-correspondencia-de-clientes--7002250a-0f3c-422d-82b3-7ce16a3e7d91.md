# Exemplo de impressão de etiquetas de correspondência de clientes

Arquivo: ...\Samples\Solution\Reports\Cust.lbx

Este exemplo ilustra a impressão de etiquetas de correspondência, uma para cada cliente na tabela de clientes.

As etiquetas incluem os seguintes quatro itens:
 - Company
- Contact + ", " + Title
- Address
- City + ", " + Region+ " " + Country

O logotipo é exibido em cada etiqueta usando o controle de contêiner OLE.
