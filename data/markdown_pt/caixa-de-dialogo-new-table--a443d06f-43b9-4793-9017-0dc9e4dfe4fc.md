# Caixa de diálogo New Table

Permite criar uma nova tabela usando o Table Designer ou o Table Wizard.

> **Observação:** Para projetos, a caixa de diálogo New Table exibe o botão Table Wizard somente quando a caixa de seleção Prompt for Wizards na guia Projects da caixa de diálogo Options está selecionada.
 **Table Wizard**
Abre o Table Wizard, que usa suas respostas a uma série de perguntas para criar uma tabela. Para obter mais informações, consulte Table Wizard .
**New Table**
Abre o Table Designer para que você possa criar uma tabela vazia. Para obter mais informações, consulte Table Designer .
