# Criando menus, menus de atalho, itens de menu e submenus

Depois de planejar seu sistema de menus, você pode criá-lo com o Menu Designer. Você pode criar menus, menus de atalho, itens de menu, submenus de itens de menu, linhas que separam grupos de itens de menu relacionados e assim por diante. As seções a seguir fornecem os detalhes.

# Nesta seção
 **How to: Create Menus and Submenus**
Descreve como criar menus e submenus para navegar em sua aplicação.
**How to: Create Menu Items**
Descreve como criar menus nos quais você pode colocar itens de menu. Itens de menu podem representar comandos ou procedimentos do Visual FoxPro ou submenus que oferecem opções adicionais.
**How to: Create Shortcut Menus**
Descreve como criar menus de atalho que aparecem quando você clica com o botão direito do mouse em um controle ou objeto.
