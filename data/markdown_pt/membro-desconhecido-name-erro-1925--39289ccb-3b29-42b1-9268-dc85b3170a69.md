# Membro desconhecido "name" (Erro 1925)

O Visual FoxPro tentou avaliar a sintaxe a seguir:

```foxpro
      objvar.memberobj.property
```

Nenhum membro chamado memberobj foi encontrado.
 - Você estava tentando acessar os membros de uma classe de controle de fora da classe. Certifique-se de que referências a controles, como com .ActiveControl, estejam no escopo.
