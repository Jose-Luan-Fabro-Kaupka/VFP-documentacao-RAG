# Função DTOC( )

Retorna uma data do tipo Character a partir de uma expressão Date ou DateTime.

```foxpro
DTOC(dExpression | tExpression [, 1])
```

#### Parâmetros
 **dExpression**
Especifica uma variável, elemento de array ou campo do tipo Date para o qual DTOC( ) retorna uma data do tipo Character.
**tExpression**
Especifica uma variável, elemento de array ou campo do tipo DateTime para o qual DTOC( ) retorna uma data do tipo Character.
**1**
Retorna a data em um formato adequado para indexação. Isso é particularmente útil para manter os registros da tabela em sequência cronológica. Por exemplo, para ordenar os registros da tabela em sequência de entrada, você poderia emitir este comando: INDEX ON DTOC(gdInvDate, 1) + gnInvTime TAG Timeindx gdInvDate e gnInvTime são campos contendo a data e a hora em que os dados foram inseridos no registro.

# Valor de retorno

Character

# Observações

DTOC( ) retorna uma cadeia de caracteres correspondente a uma expressão Date ou DateTime. O formato da data é determinado por SET CENTURY e SET DATE.

# Exemplo

```foxpro
SET STRICTDATE TO 1
STORE CTOD('10/31/98') TO gdThisDate
CLEAR
? DTOC(gdThisDate)
STORE DTOC({^1998-10-31}+90) TO gcExpireDate
? 'Your 90-day warranty expires ', gcExpireDate
? DTOC({^1998-10-31},1)
```
