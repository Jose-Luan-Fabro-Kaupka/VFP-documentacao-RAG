# Importação e exportação de dados

Você pode copiar dados entre o Visual FoxPro e outros aplicativos importando para e exportando do Visual FoxPro. Os dados podem estar em qualquer um de uma variedade de formatos de arquivo de texto, planilha e tabela. Você pode criar uma nova tabela do Visual FoxPro, adicionar a uma tabela existente do Visual FoxPro ou copiar dados para um tipo de arquivo diferente.

# Nesta seção
 **Importing and Exporting Concepts**
Quando você importa ou anexa dados, traz os dados de outro aplicativo para o Visual FoxPro. Quando você exporta dados, envia dados de uma tabela do Visual FoxPro para um tipo de arquivo usado por outro aplicativo.
**Importing Data**
Se você deseja importar do seu arquivo de origem, pode deixar o Visual FoxPro definir a estrutura da nova tabela ou usar o Import Wizard para especificar sua estrutura.
**Appending Data**
Você pode adicionar seus dados de texto, planilha ou tabela a uma tabela existente do Visual FoxPro. Por padrão, o Visual FoxPro usa o tipo de arquivo para mapear os campos de origem para a tabela de destino.
**Exporting Data**
Você pode exportar dados de suas tabelas do Visual FoxPro para arquivos de texto, planilhas ou tabelas usadas em outros aplicativos.
**Data Access Management Using CursorAdapters**
Descreve o suporte para trabalhar com diferentes tipos de fonte de dados como cursores nativos do Visual FoxPro usando objetos CursorAdapter.
**Converting Between XML and Visual FoxPro Data**
Apresenta a troca de dados com mais facilidade com outros aplicativos convertendo dados do Visual FoxPro para o formato XML.
**XML Functionality Using XMLAdapters**
Discute a extensão dos recursos XML do Visual FoxPro e a compatibilidade com os formatos XML DiffGram e .NET Framework ADO.NET DataSet e com suporte a XML formatado hierarquicamente.
