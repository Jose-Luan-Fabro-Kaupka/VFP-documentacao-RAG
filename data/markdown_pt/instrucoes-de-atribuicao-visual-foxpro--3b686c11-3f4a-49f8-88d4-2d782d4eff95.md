# Instruções de atribuição (Visual FoxPro)

Você pode comparar como as instruções de atribuição diferem entre o Visual FoxPro e outras linguagens de programação.

> **Observação:** No Visual FoxPro, você também pode atribuir valores a campos em uma tabela com o comando REPLACE.

| Visual FoxPro | BASIC |
| --- | --- |
| nVal = 7 -OR- STORE 7 to nVal | nVal = 7 |

| Pascal | C/C++ |
| --- | --- |
| nVal := 7 | nVal = 7 |
