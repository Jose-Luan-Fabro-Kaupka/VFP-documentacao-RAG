# Função MONTH( )

Retorna o número do mês para uma expressão Date ou DateTime fornecida.

```foxpro
MONTH(dExpression | tExpression)
```

#### Parâmetros
 **dExpression**
Especifica a expressão Date para a qual você deseja que MONTH( ) retorne o número do mês.
**tExpression**
Especifica a expressão DateTime para a qual você deseja que MONTH( ) retorne o número do mês.

# Valor de retorno

Numérico

# Observações

MONTH( ) retorna um número de 1 a 12. Janeiro é o mês 1 e dezembro é o mês 12.

# Exemplo

```foxpro
CLEAR
? DATE()  && Displays today's date
? MONTH(DATE())  && Displays the month number
STORE {^1998-05-03} TO gdBuy
STORE MONTH(gdBuy + 31) TO gdMonth
? gdMonth  && Displays 6
```
