# Guia Symbols, Code Analyzer

Esta guia exibe os símbolos disponíveis em seu código documentado e fornece uma forma de navegar pelo código e entre símbolos. A guia contém os seguintes controles.

# Opções da guia
 **Goto**
Abre uma janela de texto ou move o cursor para a primeira ocorrência do símbolo selecionado na grade Files.
**Next**
Move o cursor da janela de texto para a próxima ocorrência do símbolo selecionado na grade Files.
**Symbols**
Exibe todos os símbolos disponíveis no arquivo documentado.
**Files**
Exibe os procedimentos e arquivos nos quais o símbolo selecionado ocorre.
