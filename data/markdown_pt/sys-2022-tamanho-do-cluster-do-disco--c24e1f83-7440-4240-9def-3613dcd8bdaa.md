# SYS(2022) - Tamanho do cluster do disco

Retorna o tamanho do cluster em bytes de um disco especificado.

```foxpro
SYS(2022 [, cDiskName])
```

#### Parâmetros
 **cDiskName**
Especifica uma letra de unidade (A, B, C, ...) para um disco diferente do disco padrão atual.

# Valor de retorno

Character
