# O Microsoft Visual FoxPro não suporta e não pode abrir este formato de recordset (Erro 2038)

O Visual FoxPro tentou abrir um recordset ADO Shaped (Hierarchical) que não é diretamente suportado pelo produto. Você pode usar um recordset ADO Shaped em sua aplicação, desde que seja manipulado por um controle Activex que suporte esses tipos de recordsets, como o Microsoft Hierarchical FlexGrid Control.
