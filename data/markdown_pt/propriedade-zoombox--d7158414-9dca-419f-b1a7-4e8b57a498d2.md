# Propriedade ZoomBox

Incluída para compatibilidade com versões anteriores com o Macintosh. Especifica se um formulário tem uma caixa de zoom. Disponível em tempo de design; leitura/gravação em tempo de execução.

```foxpro
Object.ZoomBox = lExpr
```

# Valores da propriedade
 **lExpr**
As configurações da propriedade ZoomBox são as seguintes: Configuração Descrição True (.T.) Uma caixa de zoom aparece no canto superior direito do formulário. False (.F.) (Padrão) Nenhuma caixa de zoom aparece no formulário.

# Observações

Aplica-se a: Form Object
