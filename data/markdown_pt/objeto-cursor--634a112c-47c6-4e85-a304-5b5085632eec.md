# Objeto Cursor

Criado quando uma tabela ou view é adicionada ao ambiente de dados de um formulário, conjunto de formulários ou relatório.

```foxpro
Cursor
```

# Observações

O objeto cursor permite especificar ou determinar propriedades para a tabela ou view quando o formulário, FormSet ou relatório é executado.

Observe que definir uma propriedade de objeto cursor em tempo de execução gera um erro (com exceção das propriedades Filter e Order, que podem ser definidas em tempo de execução). Para que uma nova configuração de propriedade tenha efeito, você deve chamar os métodos CloseTables e OpenTables para o ambiente de dados. Além disso, se você alterar a propriedade Order em tempo de execução de um cursor que está envolvido em um relacionamento um-para-muitos, o relacionamento um-para-muitos é interrompido.
