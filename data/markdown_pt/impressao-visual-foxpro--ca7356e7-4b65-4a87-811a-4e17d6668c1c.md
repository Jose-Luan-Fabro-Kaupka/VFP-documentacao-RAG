# Impressão (Visual FoxPro)

Esses comandos e funções tornam possível imprimir ou exibir dados de registros ou variáveis de memória na tela, em uma impressora ou em um arquivo de saída.

| Use | Para |
| --- | --- |
| Variável de sistema _ASCIICOLS | Especificar o número de colunas em um arquivo de texto ASCII criado com a palavra-chave ASCII no comando REPORT FORM. |
| Variável de sistema _ASCIIROWS | Especificar o número de linhas em um arquivo de texto ASCII criado com a palavra-chave ASCII no comando REPORT FORM. |
| Comando \ | \\ | Imprimir ou exibir linhas de texto. |
| Comando ? | ?? | Avaliar expressões e enviar os resultados para a janela principal do Visual FoxPro, uma janela definida pelo usuário ativa ou a impressora. |
| Comando ??? | Enviar saída diretamente para a impressora. |
| Função APRINTERS( ) | Armazenar informações sobre impressoras instaladas atualmente em uma matriz. |
| Comandos CLOSE | Fechar vários tipos de arquivo. |
| Comando DISPLAY | Exibir conteúdo de registros e resultados de expressões para a tabela atual na janela principal do Visual FoxPro ou em uma janela definida pelo usuário. |
| Comando EJECT | Enviar um avanço de formulário para a impressora. |
| Comando EJECT PAGE | Enviar um avanço de página condicional para a impressora. |
| Função GETPRINTER( ) | Exibir a caixa de diálogo Printer e retornar o nome da impressora selecionada. |
| Comandos LIST | Exibir informações de tabela ou ambiente sem pausar a janela principal do Visual FoxPro ou definida pelo usuário. |
| Comando ON PAGE | Especificar um comando que é executado quando a saída impressa atinge um número de linha especificado em um relatório ou quando você emite EJECT PAGE. |
| Função PCOL( ) | Retornar a posição de coluna atual do cabeçote de impressão da impressora. |
| Comando PRINTJOB ... ENDPRINTJOB | Ativar as configurações para variáveis de sistema de trabalho de impressão. |
| Função PROW( ) | Retornar o número de linha atual do cabeçote de impressão da impressora. |
| Função PRTINFO( ) | Retornar a configuração de impressora especificada atual. |
| Comando REPORT FORM | Exibir ou imprimir um relatório especificado por um arquivo de definição de relatório (.frx), por exemplo, criado com o comando CREATE REPORT ou MODIFY REPORT. |
| Comando SET MARGIN | Definir a margem esquerda da impressora. |
| Comando SET PDSETUP | Carregar uma configuração de driver de impressora ou limpar a configuração atual do driver de impressora. |
| Comando SET PRINTER | Habilitar ou desabilitar saída para a impressora ou direcionar saída para um arquivo, porta ou impressora de rede. |
| SYS(6) - Current Printer Device | Retornar o dispositivo de impressão atual. |
| SYS(1037) - Page Setup Dialog Box | Exibir a caixa de diálogo Page Setup padrão do Visual FoxPro ou de relatório, ou definir configurações de impressora para a impressora padrão no Visual FoxPro ou para o ambiente de impressora do relatório. |
| Comando TYPE | Exibir o conteúdo de um arquivo. |
