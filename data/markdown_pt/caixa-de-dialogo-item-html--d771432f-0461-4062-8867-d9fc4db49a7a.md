# Caixa de diálogo Item HTML

A caixa de diálogo Item HTML faz parte do assistente Publicação na Web. Esta caixa de diálogo permite especificar itens adicionais e seus atributos para a página Web que você cria.

 Para acessar a caixa de diálogo Item HTML
 - No menu Ferramentas, escolha Assistentes e clique em Publicação na Web .
- Navegue pelo assistente até a Etapa 3.
- Clique em Avançado .
- Na caixa de diálogo Avançado, clique em Adicionar .
 **Tipo**
Esta lista suspensa fornece uma lista de itens de tag HTML que você pode adicionar à sua página.
**Localização**
Esta lista suspensa permite especificar onde na página Web você deseja que o item HTML selecionado apareça — no cabeçalho, antes dos dados ou após os dados.
**Formatação de texto**
Texto Especifique o texto exato que deseja exibir no local selecionado na lista suspensa Localização. Cabeçalho Especifique, na lista suspensa, a tag de cabeçalho HTML que deseja aplicar ao texto especificado. Negrito (Strong) Especifique se deseja que o texto especificado seja formatado em negrito. Itálico Especifique se deseja que o texto especificado seja formatado em itálico. Nome da fonte Especifique a fonte que deseja usar para o texto especificado. Se você escolheu um Cabeçalho, esta opção é desabilitada e sua página Web usará o valor de cabeçalho definido no navegador de visualização. Tamanho Especifique o tamanho da fonte que deseja usar para o texto especificado. Se você escolheu um Cabeçalho, esta opção é desabilitada e sua página Web usará o valor de cabeçalho definido no navegador de visualização. Alinhamento Especifica o alinhamento da página da esquerda para a direita do item HTML especificado. Cor de primeiro plano Especifica a cor de primeiro plano (texto padrão) do item HTML especificado. Cor de fundo Especifica a cor do item HTML especificado.
**Atributos**
Arquivo/HREF Especifique ou localize o arquivo (ou URL) que deseja usar se escolheu o item Hiperlink ou Imagem na lista suspensa Tipo. Classe de estilo Especifica uma referência de caminho para uma classe contida em uma folha de estilo em cascata (.css).

Quando você clica em OK, retorna à caixa de diálogo Avançado, onde pode especificar outro item HTML, salvar as informações atuais de layout e estilo de dados ou prosseguir para a Etapa 4 do assistente Publicação na Web.
