
# Observações

Incluída para compatibilidade com versões anteriores — use o Report Writer em vez disso.

_INDENT contém um valor numérico que instrui o comando ? a recuar (ou desrecuar) a primeira linha de cada parágrafo um número especificado de caracteres a partir da margem esquerda.

_INDENT está ativo apenas quando _WRAP está definido como .T.
