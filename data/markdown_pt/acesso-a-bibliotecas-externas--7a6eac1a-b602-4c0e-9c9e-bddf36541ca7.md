# Acesso a bibliotecas externas

Na maioria dos casos, o Visual FoxPro fornece todas as ferramentas necessárias para concluir seu aplicativo. No entanto, ocasionalmente você pode descobrir que um aplicativo requer funcionalidade adicional não disponível no Visual FoxPro. Nesses casos, você pode ir além do Visual FoxPro e aproveitar as capacidades de bibliotecas externas.

O Visual FoxPro permite acessar os seguintes tipos de bibliotecas externas:
 - ActiveX controls (.ocx files) and Objects . ActiveX controls e objects são programas que incluem objetos projetados para realizar tarefas específicas. A maioria dos ActiveX controls e objects adiciona novos objetos ao Visual FoxPro — desde um novo tipo de text box até um calendário, calculadora ou outro objeto complexo. Alguns ActiveX controls e objects também incorporam recursos adicionais, como acesso ao seu sistema de e-mail ou às portas de comunicação do computador. Em geral, após incorporar um ActiveX control ou object ao Visual FoxPro, você pode usar os objetos neles como faria com qualquer base class do Visual FoxPro.
- Dynamic-link libraries (.dll files) . Um arquivo .dll é uma biblioteca de funções que você pode chamar de programas Visual FoxPro como faria com qualquer função definida pelo usuário no Visual FoxPro. Muitos programas Windows — e o próprio Windows — disponibilizam sua funcionalidade usando arquivos .dll. Por exemplo, você pode acessar as configurações de cores do sistema para Windows vinculando-se a um arquivo .dll do sistema e chamando funções nele.
- Visual FoxPro external libraries (.fll files) . Um arquivo .fll é semelhante a um arquivo .dll, mas usa protocolo especial para compartilhar dados com o Visual FoxPro e frequentemente contém chamadas a funções internas do Visual FoxPro. Como consequência, arquivos .fll são específicos do Visual FoxPro, ao contrário de arquivos .dll, que podem ser chamados de qualquer programa Windows. Você pode chamar as funções em um .fll como faria com qualquer função definida pelo usuário no Visual FoxPro.

Antes de usar qualquer biblioteca, você deve estar familiarizado com as convenções usadas para acessar seus controles ou funções. Por exemplo, se você deseja incluir um ActiveX control em um formulário, deve saber quais propriedades, eventos e métodos pode usar para gerenciar o controle. Para um ActiveX control, você pode usar um Visual FoxPro Class Browser para determinar as propriedades, eventos e métodos que pode usar. Da mesma forma, se deseja chamar uma função em um arquivo .dll, deve saber o nome da função, o número e os tipos de dados dos parâmetros que ela requer e o tipo de dados de seu valor de retorno. Em geral, você pode obter esse tipo de informação na documentação que acompanha uma biblioteca, seja em um livro ou em um sistema de Help. Para informações sobre arquivos .dll do sistema para Windows, consulte o Software Development Kit (SDK) adequado à sua versão do Windows.
