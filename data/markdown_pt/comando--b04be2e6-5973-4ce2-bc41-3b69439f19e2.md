# Comando \ | \\

Imprime ou exibe linhas de texto.

```foxpro
\TextLine
```

```foxpro
\\TextLine
```

#### Parâmetros
 **\ TextLine**
Quando você usa \, a linha de texto é precedida por um retorno de carro e um avanço de linha.
**\\ TextLine**
Quando você usa \\, a linha de texto não é precedida por um retorno de carro e um avanço de linha. Quaisquer espaços que precedem \ e \\ não são incluídos na linha de saída, mas os espaços que seguem \ e \\ são incluídos. Você pode incorporar uma expressão na linha de texto. Se a expressão estiver entre os delimitadores de mesclagem de texto (<< >> por padrão) e SET TEXTMERGE estiver ON, a expressão é avaliada e seu valor é exibido como texto.

# Observações

Os comandos \ e \\ facilitam a mesclagem de texto no Visual FoxPro. A mesclagem de texto permite enviar texto para um arquivo para criar cartas-formulário ou programas.

Use \ e \\ para enviar uma linha de texto para o arquivo de saída de mesclagem de texto atual e para a tela. SET TEXTMERGE é usado para especificar o arquivo de saída de mesclagem de texto. Se a mesclagem de texto não for direcionada para um arquivo, a linha de texto é enviada somente para a janela principal do Visual FoxPro ou para a janela de saída definida pelo usuário ativa. SET TEXTMERGE NOSHOW suprime a saída para a janela principal do Visual FoxPro ou para a janela definida pelo usuário ativa.

# Exemplo

```foxpro
CLOSE DATABASES
OPEN DATABASE (HOME(2) + 'Data\testdata')
USE Customer && Open customer table
SET TEXTMERGE ON
SET TEXTMERGE TO letter.txt
\<<CDOW(DATE())>>, <<CMONTH(DATE())>>
\\ <<DAY(DATE())>>, <<YEAR(DATE())>>
\
\
\Dear <<contact>>
\Additional text
\
\Thank you,
\
\XYZ Corporation
CLOSE ALL
MODIFY FILE letter.txt NOEDIT
```
