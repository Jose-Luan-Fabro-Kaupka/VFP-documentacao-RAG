# Integração de relatórios com aplicativos

Depois de concluir o desenvolvimento dos relatórios do aplicativo, você poderá integrá-los a ele. A ilustração a seguir mostra algumas maneiras de adicionar relatórios ao aplicativo.
 Maneiras de integrar relatórios a aplicativos

# Opções para integrar relatórios

Você tem várias opções para integrar relatórios ao aplicativo:
 - Adicione código capaz de executar e exibir relatórios aos seguintes objetos: controles de formulário. Para obter mais informações sobre formulários e botões, consulte Criação de formulários. Botões de barra de ferramentas ou comandos de menu. Para obter mais informações, consulte Criação de menus e barras de ferramentas. Por exemplo, para permitir que o usuário execute o relatório e produza somente uma impressão, você pode adicionar o comando REPORT FORM a um controle de formulário, comando de menu ou botão de barra de ferramentas. Para obter mais informações, consulte Como: gerar saída para relatórios.
- Para permitir que o usuário insira algumas variáveis usadas no relatório, você pode coletar esses valores do usuário da mesma forma que faz para consultas. Por exemplo, o usuário pode inserir um intervalo de datas específico para o relatório, que você usa para executá-lo. Para obter mais informações, consulte Trabalho com variáveis de relatório.
- Para permitir que o usuário crie relatórios personalizados, você pode oferecer a capacidade de criar novos relatórios ou modificar relatórios existentes com o Designer de Relatórios. Para obter mais informações, consulte Como: abrir relatórios e etiquetas.
