# Função OS( )

Retorna o nome e o número da versão do sistema operacional sob o qual o Microsoft Visual FoxPro está em execução.

```foxpro
OS([nValue])
```

#### Parâmetros
 **nValue**
Especifica o item a retornar, conforme a tabela a seguir. nValues Value Description 1 Specifies that the name and version number of the operating system is returned. 2 DBCS Support. If DBCS (double-byte character sets) are supported, "DBCS" is returned. Otherwise, an empty string is returned 3 Identifies the major version number of the operating system. For example, for Windows 2000, the major version number is 5. 4 Identifies the minor version number of the operating system. For example, for Windows 2000, the minor version number is 0. 5 Identifies the build number of the operating system. 6 Identifies the operating system platform. 7 Contains a string, such as "Service Pack 3", that indicates the latest Service Pack installed on the system. If no Service Pack has been installed, the string is empty. 8 Identifies the major version number of the latest Service Pack installed on the system. For example, for Service Pack 3, the major version number is 3. If no Service Pack has been installed, the value is zero. 9 Identifies the minor version number of the latest Service Pack installed on the system. For example, for Service Pack 3, the minor version number is 0. 10 A set of bit flags that identify the product suites available on the system. See Product Suite bit flag table below for values. 11 Indicates additional information about the system. See Product Type settings table below for values.
 Sinalizadores de bits Product Suite:
| Valor | Significado |
| --- | --- |
| 1 | Microsoft Small Business Server está instalado. |
| 2 | Windows 2000 Advanced Server ou Windows Server 2003, Enterprise Edition, está instalado. |
| 4 | Componentes Microsoft BackOffice estão instalados. |
| 16 | Terminal Services estão instalados. |
| 32 | Microsoft Small Business Server está instalado com a licença de cliente restritiva em vigor. |
| 64 | Windows Embedded NT está instalado |
| 128 | Windows 2000 ou Windows Server 2003, Datacenter Edition, está instalado. |
| 256 | Terminal Services está instalado, mas apenas uma sessão interativa é suportada. |
| 512 | Windows XP Home Edition está instalado. |
| 1024 | Windows Server 2003, Web Edition, está instalado. |
 Configurações Product Type:
| Valor | Significado |
| --- | --- |
| 1 | O sistema está executando Windows NT 4.0 Workstation, Windows 2000 Professional, Windows XP Home Edition ou Windows XP Professional. |
| 2 | O sistema é um controlador de domínio. |
| 3 | O sistema é um servidor. |

# Valor de retorno

Character

# Observações

Se você omitir o argumento opcional, esta função retorna o nome do sistema operacional subjacente e seu número de versão.

Alguns nValues não se aplicam a alguns sistemas operacionais. Em tais casos, a função OS( ) retorna "0" ou "", uma cadeia de caracteres vazia.

# Exemplo

```foxpro
? OS()
? OS(1)
? OS(2)
```
