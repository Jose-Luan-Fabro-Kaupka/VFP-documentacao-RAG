# Como: criar programas

Você pode criar um programa autônomo, um programa como parte de um projeto ou programaticamente.

> **Observação:** Após criar um programa, certifique-se de salvá-lo. Se você tentar fechar um programa não salvo ou modificado, o Visual FoxPro solicita que você salve o programa ou descarte as alterações.

### Para criar um programa autônomo
- No menu Arquivo, clique em New .
- Na caixa de diálogo New, clique em Program e então New File .
- Na janela de edição, digite o código do programa.

### Para criar um programa em um projeto
- Abra o projeto do seu aplicativo no Project Manager .
- No Project Manager , expanda o nó Code.
- Clique em Programs e então New .
- Na janela de edição, digite o código do programa.

### Para criar um programa programaticamente
- Na Janela de comando, use MODIFY COMMAND para abrir uma janela de edição.
