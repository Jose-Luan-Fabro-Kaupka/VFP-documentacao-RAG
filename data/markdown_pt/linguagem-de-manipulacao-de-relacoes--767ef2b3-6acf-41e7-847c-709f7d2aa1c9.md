# Linguagem de manipulação de relações

Estes comandos e funções permitem estabelecer ou quebrar relações entre arquivos de tabela.

| Use | Para |
| --- | --- |
| RELATION( ) Function | Retornar uma expressão relacional especificada para uma tabela aberta em uma área de trabalho específica. |
| SELECT - SQL Command | Recuperar dados de uma ou mais tabelas. |
| SET RELATION Command | Estabelecer uma relação entre duas tabelas abertas. |
| SET RELATION OFF Command | Quebrar uma relação estabelecida entre a tabela pai e a tabela filha relacionada. |
| SET SKIP Command | Criar uma relação um-para-muitos entre tabelas. |
| TARGET( ) Function | Retornar o alias de uma tabela que é o destino de uma relação conforme especificado na cláusula INTO de SET RELATION. |
