# Como: gerar resultados para views

Depois de concluir a seleção de campos e a personalização de uma view, você pode executá-la para recuperar e visualizar os registros selecionados pela view. Quando estiver satisfeito com os resultados da view, pode salvar a view de resultados especificando um nome para a view.

### Para recuperar e visualizar os resultados de uma view
- No menu Query, clique em Run Query . O Visual FoxPro exibe os resultados em uma janela browse.

### Para salvar a view
- No menu File, clique em Save As .
- Na caixa de diálogo Save, digite um nome para a view.

O Visual FoxPro adiciona uma definição de view contendo os nomes das tabelas, os campos selecionados e as configurações de propriedade da view ao banco de dados atual.
