# Exemplo Handle Data Conflicts

Arquivo: ...\Samples\Solution\Ffc\Conflicts.scx

Este exemplo contém as seguintes classes.

| Classe | Biblioteca | Descrição |
| --- | --- | --- |
| _conflicts | _dataquery.vcx | Exibe uma caixa de diálogo que permite resolver linhas conflitantes encontradas durante sessões de edição com buffer otimista. |
| _nav4picbutton | _table.vcx | Exibe dois botões adicionais que fornecem as funções GO TOP e GO BOTTOM à classe _Nav2PicButton. |
| _resizable | _controls.vcx | Faz com que objetos soltos em um formulário sejam redimensionados e movidos com o evento resize do Form. |
| _datachecker | _datanav.vcx | Detecta conflitos de dados. |

Para detalhes sobre todas as classes disponíveis nas classes foundation, consulte Visual FoxPro Foundation Classes A-Z.
