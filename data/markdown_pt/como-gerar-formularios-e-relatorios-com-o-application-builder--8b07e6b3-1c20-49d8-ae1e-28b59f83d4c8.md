# Como: gerar formulários e relatórios com o Application Builder

Você pode usar o Application Builder para gerar formulários e relatórios sem precisar escrever código.

### Para gerar formulários ou relatórios
- Use o botão Database Wizard, o botão Table Wizard ou o botão Select para localizar e escolher uma fonte de dados. Se você selecionar os botões Database Wizard ou Table Wizard, o Visual FoxPro abrirá o assistente selecionado para você. Depois de usar o assistente, você retornará à guia Data do Application Wizard. Quando você especificar a fonte de dados, a grade exibe o nome da tabela e os controles Form e Report selecionados. O assistente seleciona automaticamente formulários padrão e estilo de apresentação para todos os formulários e relatórios. Se você aceitar as escolhas padrão de estilo de formulário e relatório, vá para a Etapa 4; caso contrário, vá para a Etapa 2.
- Se você quiser alterar apenas o estilo do formulário, desmarque a caixa de seleção Report. Se você quiser alterar apenas o estilo do relatório, desmarque a caixa de seleção Form. Se você quiser alterar ambos, deixe os dois selecionados.
- Escolha os estilos desejados nos controles Style.
- Clique no botão Generate para criar os formulários e/ou relatórios que você especificou. Observação Como a grade de dados é limpa depois que você gera formulários ou relatórios, você deve escolher relatórios e formulários com estilos diferentes em sessões de 'generate' separadas.
