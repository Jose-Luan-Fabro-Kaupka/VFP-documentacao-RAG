# Considerações para criar relatórios

Há algumas diretrizes que você pode usar ao projetar e criar relatórios:
 - Use controles de rótulo para identificar informações e áreas específicas do relatório, atrair a atenção para elas e destacá-las.
- Use espaçamento e posicionamento adequados das informações para melhorar a organização e a clareza, reduzir a poluição visual no relatório e conduzir o olhar do leitor às partes do relatório. Em geral, o olhar do leitor percorre as partes superior, central, direita e, em seguida, esquerda da tela ou página.
- Considere o tipo de saída que pretende criar ao planejar o design básico. Por exemplo, se pretende fornecer exibição na tela, não obrigue os leitores a rolar pelas informações. Se não puder exibir as informações do relatório no espaço de uma única tela, considere reorganizá-las de outra maneira. Se os usuários forem imprimir o relatório, considere se todos possuem impressoras coloridas antes de usar cores para exibir distinções importantes entre registros ou campos, como usar vermelho para distinguir números negativos.
- Teste seus relatórios com registros de exemplo bastante variados, assim como testaria formulários e outras partes do aplicativo. Verifique se elementos de dados ausentes têm valores padrão ou espaços reservados apropriados e se valores excepcionalmente longos em campos de dados não são cortados.
