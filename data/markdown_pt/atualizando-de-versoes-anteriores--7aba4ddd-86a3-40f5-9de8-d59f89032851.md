# Atualizando de versões anteriores

O Microsoft Visual FoxPro protege seu investimento em aplicativos construídos com versões anteriores do FoxPro. No Visual FoxPro, você pode executar muitos aplicativos escritos em versões anteriores com pouca ou nenhuma conversão. Você pode modificar e aprimorar aplicativos usando a linguagem Visual FoxPro, sabendo que a maioria das extensões à linguagem não afeta a compatibilidade com versões anteriores. Além disso, você pode converter telas, projetos e relatórios do FoxPro para o formato Visual FoxPro.

No entanto, é possível que algumas alterações de comportamento ou recursos na versão atual do Visual FoxPro possam afetar o código-fonte Visual FoxPro existente. Portanto, você deve revisar os novos recursos, aprimoramentos e as alterações de comportamento mais recentes desta versão. Para obter mais informações, consulte What's New in Visual FoxPro e Changes in Functionality for the Current Release.

# Conversão para o formato Visual FoxPro

Se você optar por converter seus arquivos dBASE ou FoxPro para o formato Visual FoxPro, pode aproveitar os recursos exclusivos do Visual FoxPro. Você pode executar muitos arquivos de algumas versões anteriores do FoxPro diretamente; outros requerem níveis variados de conversão.

Você pode converter a maioria dos projetos ou componentes criados usando versões anteriores do Visual FoxPro simplesmente abrindo ou recompilando-os nesta versão do Visual FoxPro. Ao recompilar componentes, como formulários, telas ou relatórios, algumas modificações podem ser necessárias. Você pode fazer modificações nesses componentes da mesma forma que modifica os componentes desta versão do Visual FoxPro.

Você pode encontrar informações adicionais sobre atualização de versões anteriores do Visual FoxPro no site Microsoft Developer Network (MSDN) em http://msdn.microsoft.com. Você pode pesquisar o MSDN Archive para documentação de versões anteriores do Visual FoxPro.
