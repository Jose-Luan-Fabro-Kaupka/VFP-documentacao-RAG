# O Visual FoxPro não pode ser iniciado

O Visual FoxPro não pode ser inicializado ou configurado por um dos seguintes motivos:
 - Memória insuficiente. O Visual FoxPro não pôde alocar memória suficiente para estruturas internas. Libere memória e reinicie o Visual FoxPro.
- Espaço em disco insuficiente. O Visual FoxPro não pôde alocar arquivos temporários. Libere espaço em disco e reinicie o Visual FoxPro.
- O arquivo VFP<versionNumber>ENU.dll não pôde ser carregado. O Visual FoxPro não encontra o arquivo porque ele está ausente ou foi renomeado. Reinstale o Visual FoxPro.
- O arquivo de recursos especificado com a opção de inicialização -L não pôde ser carregado. O Visual FoxPro não encontra o arquivo especificado. Verifique se o arquivo especificado com a opção -L está disponível.
- O Visual FoxPro requer um sistema operacional Windows suportado. Instale um dos sistemas operacionais Windows suportados. Para mais informações, consulte Installing Visual FoxPro.
- Produto em uso por outro. Certifique-se de que você tem os direitos de acesso de rede corretos. Consulte a documentação do Windows.
- Arquivo .EXE inválido ou ausente. Reinstale o Visual FoxPro.
