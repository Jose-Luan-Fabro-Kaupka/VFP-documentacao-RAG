# Criando aplicativos com o Application Framework

O Application Framework foi projetado para incluir todos os elementos obrigatórios e muitos opcionais que tornam um aplicativo eficaz e agradável de usar. Embora o framework em si forneça muita flexibilidade e poder para criar aplicativos da forma que funciona melhor para você, esta seção discute as formas de usar o Application Wizard e o Application builder para facilitar o desenvolvimento do seu aplicativo.

# Nesta seção
 **How to: Create a Framework**
Saiba como criar um Application Framework usando o Application Wizard ou o item New Application no Component Gallery.
**Application Framework Files**
Fornece uma lista e descrição de arquivos incluídos no Application Framework.
**Data Selection with Application Builder**
Descreve como selecionar as fontes de dados que você deseja no desenvolvimento do seu aplicativo depois de planejar seu aplicativo.
**How to: Manage Documents with Application Builder**
Discute como planejar e escolher os documentos que você deseja adicionar ao seu aplicativo depois de selecionar fontes de dados.
**How to: Generate Forms and Reports with Application Builder**
Explica como gerar formulários ou relatórios sem escrever nenhum código.
**How to: Specify a Builder Application with Builder.dbf**
Fornece a tabela Builder.dbf, que você pode usar para especificar um aplicativo builder. A tabela contém campos que representam o nome de um builder, uma descrição do builder e um campo chamado Type que identifica a propriedade Class or Base Class que invoca o builder personalizado.
