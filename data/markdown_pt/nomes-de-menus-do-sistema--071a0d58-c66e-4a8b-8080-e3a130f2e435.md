# Nomes de menus do sistema

As tabelas a seguir listam os nomes internos e os nomes da interface do usuário da barra de menus do sistema, títulos de menus, menus e itens de menu do Visual FoxPro. Com esses nomes, você pode usar a barra de menus do sistema do Visual FoxPro para criar um sistema de menus para seu próprio aplicativo.

A função SYS(2013) - System Menu Name String retorna uma cadeia de caracteres delimitada por espaços que contém esses nomes. Você também pode criar um menu rápido usando os designers Menu e Shortcut para ver os nomes internos dos menus do sistema.

Para obter mais informações sobre a barra de menus do sistema, consulte Criando menus e barras de ferramentas.
