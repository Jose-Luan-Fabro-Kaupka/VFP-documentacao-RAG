# Operadores lógicos

Operadores lógicos funcionam com todos os tipos de dados e retornam um valor lógico. A tabela a seguir lista os operadores lógicos em ordem de precedência.
 Operadores lógicos
| Operador | Ação | Código |
| --- | --- | --- |
| ( ) | Agrupamento de expressões | cVar AND (cVar2 AND cVAR3) |
| NOT, ! | Negação lógica | IF NOT cVarA = cVarB IF ! nVar1 = nVar2 |
| AND | E lógico | lVar0 AND lVar9 |
| OR | OU lógico inclusivo | lVarX OR lVarY |

> **Observação:** O operador Not Equal ( # ) pode ser usado para realizar comparação XOR (como lVarX # lVarY).
