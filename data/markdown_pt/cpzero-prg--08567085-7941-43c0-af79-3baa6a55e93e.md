# Cpzero.prg

Localizado na pasta Tools\Cpzero do Visual FoxPro, Cpzero.prg remove a marca de página de código de qualquer arquivo que tenha uma estrutura de arquivo de tabela (.dbc, .dbf, .frx, .lbx, .mnx, .pjx, .scx, .vcx). Após remover a marca, Cpzero aplica outra marca especificada por você.

Normalmente, você usa Cpzero com arquivos de outras plataformas ou de versões anteriores do FoxPro. Se esses arquivos não tiverem marcas de página de código quando forem abertos, o Visual FoxPro solicitará uma página de código. Contudo, se você especificar a página de código incorreta, os dados dos arquivos não serão exibidos corretamente. Para corrigir a página de código, use Cpzero.

```foxpro
DO Cpzero [WITH "filename"[, codepage_number]]
```

#### Parâmetros
 **filename**
Especifica o nome do arquivo, que deve ser delimitado por aspas simples ou duplas. Se filename não for incluído, será exibida uma caixa de diálogo Localizar Arquivo.
**codepage_number**
Especifica o número da página de código desejada. Se não for incluído, será exibida a caixa de diálogo Página de Código. Observação Antes de executar Cpzero em uma tabela, verifique se ela está fechada.

# Exemplo

```foxpro
* Remove the code page from MYFILE.DBF and specify 437
* as the new code page.
*
DO Cpzero WITH 'MYFILE.DBF',437
```
