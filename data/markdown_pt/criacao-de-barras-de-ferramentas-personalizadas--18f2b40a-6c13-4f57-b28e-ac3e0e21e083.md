# Criação de barras de ferramentas personalizadas

Se o seu aplicativo incluir tarefas repetitivas executadas com frequência pelos usuários, você poderá adicionar barras de ferramentas personalizadas para simplificar ou agilizar as tarefas. Por exemplo, se os usuários normalmente imprimirem um relatório escolhendo um comando de menu, você poderá simplificar a tarefa fornecendo uma barra de ferramentas com um botão de impressão.
