# Objeto Container

Cria um objeto que pode conter outros objetos.

```foxpro
Container
```

# Observações

Os objetos Container podem conter outros objetos e permitem acesso aos objetos contidos neles. Por exemplo, se você criar um objeto Container que contém duas list boxes e dois command buttons e depois adicionar o objeto Container a um formulário, as list boxes e os command buttons podem ser manipulados em tempo de design e em tempo de execução.

Para obter mais informações sobre objetos Container e como eles diferem de outros objetos e controles, consulte Object-Oriented Programming.
