# Requisitos para Instalar o Visual FoxPro

O Visual FoxPro possui os seguintes requisitos mínimos de sistema:
 - Computador : PC com processador da classe Pentium.
- Periféricos : Mouse ou dispositivo apontador
- Memória : 64 MB RAM (128 MB ou mais recomendado)
- Espaço em disco rígido : Pré-requisitos do Visual FoxPro: 20 MB Instalação Típica do Visual FoxPro: 165 MB Instalação Máxima do Visual FoxPro: 165 MB
- Vídeo : Resolução 800 x 600, 256 cores (Alta cor 16 bits recomendado)
- Sistema operacional : O desenvolvimento de aplicativos com o Visual FoxPro é suportado apenas no Microsoft Windows 2000 Service Pack 3 ou posterior, Windows XP e Windows Server 2003. Você pode criar e distribuir aplicativos de tempo de execução para Windows 98, Windows Me, Windows 2000 Service Pack 3 ou posterior, Windows XP e Windows Server 2003. Observação A instalação no Windows NT 4.0 Terminal Server Edition não é suportada.
