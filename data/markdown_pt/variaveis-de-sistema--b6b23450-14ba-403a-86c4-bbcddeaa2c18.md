# Variáveis de sistema

As seguintes variáveis de sistema estão disponíveis no Visual FoxPro.

# A

| Uso | Para |
| --- | --- |
| Variável de sistema _ASCIICOLS | Especifica o número de colunas em um arquivo de texto ASCII criado com a palavra-chave ASCII no comando REPORT FORM. |
| Variável de sistema _ASCIIROWS | Especifica o número de linhas em um arquivo de texto ASCII criado com a palavra-chave ASCII no comando REPORT FORM. |

# B

| Uso | Para |
| --- | --- |
| Variável de sistema _BEAUTIFY | Especifica o aplicativo de embelezamento para programas Visual FoxPro. |
| Variável de sistema _BROWSER | Especifica o nome do aplicativo class browser a usar para navegar em classes. |
| Variável de sistema _BUILDER | Especifica o nome do aplicativo builder do Visual FoxPro. |

# C

| Uso | Para |
| --- | --- |
| Variável de sistema _CALCMEM | Especifica o valor numérico que o Microsoft Visual FoxPro armazena na memória da Calculadora. |
| Variável de sistema _CALCVALUE | Especifica o valor numérico que a Calculadora exibe inicialmente. |
| Variável de sistema _CLIPTEXT | Especifica o conteúdo da Área de transferência. |
| Variável de sistema _CODESENSE | Especifica o nome do aplicativo que fornece funcionalidade para o IntelliSense Manager. |
| Variável de sistema _CONVERTER | Especifica o nome do aplicativo conversor do Microsoft Visual FoxPro. |
| Variável de sistema _COVERAGE | Especifica o nome do aplicativo Visual FoxPro que cria a saída de cobertura e profiler do Debugger. |

# D

| Uso | Para |
| --- | --- |
| Variável de sistema _DBLCLICK | Especifica o intervalo de tempo entre cliques duplos e triplos do mouse. |
| Variável de sistema _DIARYDATE | Especifica a data atual no Calendar/Diary. |
| Variável de sistema _DOS | Incluída para compatibilidade com versões anteriores. |

# E

# F

| Uso | Para |
| --- | --- |
| Variável de sistema _FOXCODE | Especifica o nome do arquivo de tabela usado para IntelliSense do Visual FoxPro. |
| Variável de sistema _FOXREF | Especifica o nome do aplicativo que fornece a ferramenta Code References. |
| Variável de sistema _FoxTask | Especifica o nome da tabela FOXTASK que suporta o Visual FoxPro Task Manager. |

# G

| Uso | Para |
| --- | --- |
| Variável de sistema _GALLERY | Especifica o programa executado quando você escolhe Component Gallery no menu Tools. |
| Variável de sistema _GENHTML | Especifica um programa de geração de HTML (Hypertext Markup Language). |
| Variável de sistema _GENMENU | Especifica um programa de geração de menu. |
| Variável de sistema _GETEXPR | Especifica o programa executado quando você emite o comando GETEXPR ou invoca a caixa de diálogo Expression Builder no Visual FoxPro. |

# H

# I

| Uso | Para |
| --- | --- |

| Variável de sistema _INCLUDE | Especifica um arquivo de cabeçalho padrão incluído com classes, formulários ou conjuntos de formulários definidos pelo usuário. |

# R

| Uso | Para |
| --- | --- |
| Variável de sistema _REPORTBUILDER | Define o aplicativo manipulador Visual FoxPro para eventos do Report Designer e Label Designer. |
| Variável de sistema _REPORTOUTPUT | Define o aplicativo manipulador Visual FoxPro para a cláusula OBJECT TYPE <n> do comando REPORT FORM e mantém um registro de classes ReportListener para diferentes resultados de saída. |
| Variável de sistema _REPORTPREVIEW | Define o aplicativo manipulador Visual FoxPro que fornece uma referência PreviewContainer a objetos ReportListener. |

# S

| Uso | Para |
| --- | --- |
| Variável de sistema _SAMPLES | Especifica o caminho do diretório no qual as amostras do Microsoft Visual FoxPro estão instaladas. |
| Variável de sistema _SCCTEXT | Especifica um programa de conversão Visual FoxPro que trata da tradução de arquivos binários Visual FoxPro em equivalentes de texto e vice-versa. |
| Variável de sistema _SCREEN | Especifica propriedades e métodos para a janela principal do Visual FoxPro. Você pode usar _SCREEN para manipular a janela principal do Visual FoxPro como um objeto. Há duas versões da sintaxe. |
| Variável de sistema _SHELL | Especifica um shell de programa. |
| Variável de sistema _SPELLCHK | Especifica um programa de verificação ortográfica para o editor de texto do Visual FoxPro. |
| Variável de sistema _STARTUP | Especifica o nome do aplicativo executado ao iniciar o Visual FoxPro. |

# T

| Uso | Para |
| --- | --- |
| Variável de sistema _TASKLIST | Especifica o nome do programa gerenciador de lista de tarefas. |
| Variável de sistema _TASKPANE | Especifica o caminho e o nome do arquivo do Visual FoxPro Task Pane Manager. |
| Variável de sistema _TALLY | Especifica o número de registros processados pelo comando de tabela executado mais recentemente. |
| Variável de sistema _TEXT | Direciona a saída dos comandos de mesclagem de texto \ | \\ e TEXT ... ENDTEXT para um arquivo de baixo nível. |
| Variável de sistema _THROTTLE | Especifica a velocidade de execução de programas quando a janela Trace está aberta. |
| Variável de sistema _TOOLBOX | Especifica o caminho e o nome do arquivo do Visual FoxPro Toolbox |
| Variável de sistema _TRIGGERLEVEL | Lê o valor que indica o nível atual de aninhamento do procedimento de trigger. |
