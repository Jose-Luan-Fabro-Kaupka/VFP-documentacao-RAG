# Variável de sistema _CODESENSE

Contém o nome do aplicativo que fornece funcionalidade para o IntelliSense Manager.

```foxpro
_CODESENSE = [cFilename]
```

#### Parâmetros
 **cFilename**
Especifica o nome do aplicativo Visual FoxPro que fornece funcionalidade para o IntelliSense Manager. Por padrão, _CODESENSE especifica FoxCode.app, localizado na pasta de aplicativos do usuário do Windows ou no diretório HOME( ).
