# Campo "name" é somente leitura. (Erro 2088)

Ocorre ao tentar inserir, atualizar ou substituir um valor em um campo que usa autoincremento, e a propriedade AutoIncError está definida como True (.T.) ou ON via o comando SET AUTOINCERROR.

Tente definir a propriedade AutoIncError como False (.F.) ou OFF usando o comando SET AUTOINCERROR.
