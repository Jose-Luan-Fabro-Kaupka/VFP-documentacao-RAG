# Conflito de atualização (Erro 1585)

Um conflito de bloqueio otimista foi detectado ao tentar atualizar uma view.

Certifique-se de que sua chave de atualização é válida.

Se desejar confirmar suas alterações na(s) tabela(s) base, chame TABLEUPDATE( ) Function com lForce. Isso substituirá as alterações feitas na tabela base desde a última busca da view.

Para descartar as alterações locais feitas na view, chame TABLEREVERT( ) Function.
