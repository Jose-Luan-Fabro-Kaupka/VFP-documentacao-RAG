# Acessando APIs

Se seu aplicativo tem requisitos que não podem ser atendidos pelos recursos já incorporados ao Visual FoxPro, você pode estender o programa aproveitando bibliotecas externas, como controles Microsoft ActiveX ou bibliotecas de vínculo dinâmico (DLLs). Usando bibliotecas externas, você pode adicionar todos os tipos de objetos ao seu aplicativo, desde caixas de texto aprimoradas até calendários e outros aplicativos completos, e pode aproveitar a funcionalidade oferecida por outros programas (incluindo o Microsoft Windows) por meio de suas interfaces de programação de aplicativos (APIs).

# Nesta seção
 **Extendendo o Visual FoxPro com bibliotecas externas**
Explica que você pode adicionar controles Microsoft ActiveX (.ocx) ao seu aplicativo facilmente, o que fornece novos objetos para usar em formulários, para criar subclasses e para gerenciar a forma como você trabalha com controles nativos do Visual FoxPro. Além disso, você pode vincular a uma biblioteca externa, como uma DLL, e chamar as funções da biblioteca para usar em seus próprios programas.
**Acessando a API do Visual FoxPro**
Se uma biblioteca externa não estiver disponível para atender às suas necessidades, você pode escrever seu próprio controle Microsoft ActiveX ou biblioteca de vínculo dinâmico específica do Visual FoxPro (arquivo .fll). Ao chamar as funções disponíveis na API do Visual FoxPro, você pode criar controles ou bibliotecas que estão fortemente integrados e otimizados para uso no Visual FoxPro.
