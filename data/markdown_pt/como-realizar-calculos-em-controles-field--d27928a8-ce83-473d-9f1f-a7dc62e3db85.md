# Como: realizar cálculos em controles Field

Você pode alterar o valor renderizado de um controle Field especificando que um cálculo cumulativo seja realizado e os resultados exibidos no lugar do valor da expressão do campo.

### Para especificar que um cálculo cumulativo seja aplicado a um controle Field
- Abra o relatório ou etiqueta no designer apropriado.
- No designer, clique com o botão direito no controle Field e selecione Properties… no menu de contexto.
- Na caixa de diálogo Field Properties, selecione a guia Calculate.
- Selecione um tipo de Calculation.
- Selecione uma opção Reset based on.

Para obter informações detalhadas sobre o comportamento de cada tipo de cálculo, consulte Calculate Field Dialog Box.

> **Observação:** Se a variável de sistema _REPORTBUILDER não estiver definida para o Report Builder padrão ou estiver definida para um builder de terceiros, a caixa de diálogo de controle de relatório é exibida ou uma caixa de diálogo diferente pode ser exibida. Para obter mais informações, consulte _REPORTBUILDER System Variable e Report Expression Dialog Box.
