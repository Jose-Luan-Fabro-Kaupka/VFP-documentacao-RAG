# Controle Image (Visual FoxPro)

Cria um controle Image que exibe uma imagem compatível com GDI+.

```foxpro
Image
```

# Observações

Um controle Image é um controle gráfico que exibe bitmaps que não podem ser alterados diretamente. No entanto, como um controle Image tem um conjunto completo de propriedades, eventos e métodos que outros controles possuem, um controle Image pode responder a eventos e pode ser alterado dinamicamente em tempo de execução.

Para obter informações adicionais sobre como criar Images, consulte Using Controls.
