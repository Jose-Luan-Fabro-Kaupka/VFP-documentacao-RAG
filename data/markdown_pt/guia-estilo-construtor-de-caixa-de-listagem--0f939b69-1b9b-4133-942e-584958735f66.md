# Guia Estilo, Construtor de Caixa de Listagem

Este guia do Construtor de Caixa de Listagem especifica o estilo, o número de linhas a exibir e a pesquisa incremental.
 **Tridimensional**
Especifica uma aparência tridimensional para a caixa de listagem. Esta opção corresponde à propriedade SpecialEffect.
**Simples**
Especifica uma aparência simples para a caixa de listagem. Esta opção corresponde à propriedade SpecialEffect.
**Linhas a exibir**
Define a propriedade Height da caixa de listagem para que ela exiba somente o número especificado de linhas por vez.
**Sim, habilitar pesquisa incremental**
Especifica se o controle tenta encontrar um item na lista à medida que o usuário digita cada letra. Esta opção corresponde à definição da propriedade IncrementalSearch como .T.
**Não, não habilitar pesquisa incremental**
Desabilita a pesquisa incremental. Esta opção corresponde à definição da propriedade IncrementalSearch como .F.
