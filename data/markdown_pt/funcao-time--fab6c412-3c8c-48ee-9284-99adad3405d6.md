# Função TIME( )

Retorna a hora atual do sistema em formato de cadeia de oito caracteres de 24 horas (hh:mm:ss).

```foxpro
TIME([nExpression])
```

#### Parâmetros
 **nExpression**
A hora retornada inclui centésimos de segundo se nExpression for incluído. A expressão numérica nExpression pode ser qualquer valor. No entanto, a resolução máxima real é de aproximadamente 1/18 de segundo. Use SECONDS( ) para maior resolução.

# Valor de retorno

Character
