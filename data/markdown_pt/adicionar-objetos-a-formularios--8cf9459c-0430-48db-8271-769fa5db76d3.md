# Adicionar objetos a formulários

Para projetar a funcionalidade desejada em um formulário, você adiciona os controles apropriados, define propriedades de formulário e controle e escreve código de evento.

# Nesta seção
 **Understanding Container and Control Objects**
Introduz contêineres e controles no Visual FoxPro.
**How to: Add Visual FoxPro Containers**
Explica como adicionar as várias classes de contêiner base a um formulário.
**How to: Add Visual FoxPro Controls to a Form**
Descreve vários métodos para adicionar controles a um formulário Visual FoxPro.
**How to: Add Controls to a Form with the Component Gallery**
Explica como adicionar rapidamente controles e objetos personalizados a um formulário usando o Component Gallery.
**How to: Add Controls to a Wizard-Generated Form**
Explica como adicionar controles da galeria de controles do assistente a um formulário para que correspondam ao estilo dos controles em um formulário criado por um dos assistentes de formulário.
**How to: Select, Move, and Resize Form Controls**
Descreve como selecionar um controle para ajustar sua posição ou tamanho.
**How to: Copy and Delete Form Controls**
Descreve como fazer uma cópia de um controle já no formulário e como excluir controles existentes.
**Aligning Controls in Forms**
Discute maneiras de alinhar controles em um formulário.
**How to: Set Tab Order for Controls**
Descreve como definir a ordem de tabulação para controles em um formulário de forma interativa ou por lista.
**How to: Add User-Defined Objects to a Form**
Explica como adicionar classes personalizadas definidas pelo usuário a um formulário.
