# Função AINS( )

Insere um elemento em uma matriz unidimensional ou uma linha ou coluna em uma matriz bidimensional.

```foxpro
AINS(ArrayName, nElementNumber [, 2])
```

#### Parâmetros
 **ArrayName**
Especifica o nome da matriz na qual o elemento é inserido.
**nElementNumber**
Especifica onde o novo elemento, linha ou coluna é inserido na matriz. Para inserir um elemento em uma matriz unidimensional, inclua ArrayName e o elemento nElementNumber onde a inserção ocorre. O novo elemento é inserido imediatamente antes do elemento nElementNumber . Para inserir uma linha em uma matriz bidimensional, inclua ArrayName e o número da linha nElementNumber onde a inserção ocorre. A nova linha é inserida imediatamente antes da linha nElementNumber . Para obter mais informações sobre como referenciar um elemento de matriz por seus subscritos, consulte o comando DIMENSION .
**2**
Insere uma coluna em uma matriz bidimensional. A nova coluna é inserida imediatamente antes da coluna especificada com nElementNumber .

# Valor de retorno

Numérico

# Observações

Inserir um elemento, linha ou coluna em uma matriz não altera o tamanho da matriz. Os elementos, linhas ou colunas finais são deslocados em direção ao final da matriz e o último elemento, linha ou coluna da matriz é removido dela. O elemento, linha ou coluna recém-inserido é inicializado como false (.F.).

AINS( ) retorna 1 se o elemento, linha ou coluna for inserido com sucesso.

# Exemplo

O exemplo a seguir cria e preenche uma matriz com nomes de empresas e examina a matriz em busca de um nome de empresa específico. Se o nome da empresa não for encontrado, ele insere o nome da empresa ausente na matriz.

```foxpro
CLOSE DATABASES
OPEN DATABASE (HOME(2) + 'Data\testdata')
USE customer     && Open customer table
SELECT company FROM customer ;
   WHERE country = 'Germany' ;
   INTO ARRAY gaCompanies
gnCount = _TALLY
gcName = 'Seven Seas Imports'
CLEAR
DISPLAY MEMORY LIKE gaCompanies
IF ASCAN(gaCompanies, gcName) = 0  && Search for company
*** Company not found-add it ***
   DIMENSION gaCompanies[gnCount+1,1]
   = AINS(gaCompanies, gnCount-1)
   gaCompanies[gnCount-1] = gcName
ENDIF
DISPLAY MEMORY LIKE gaCompanies
```
