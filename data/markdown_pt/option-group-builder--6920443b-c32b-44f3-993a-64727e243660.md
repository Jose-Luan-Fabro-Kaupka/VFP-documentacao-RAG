# Option Group Builder

O Option Group builder facilita a definição de propriedades para um controle option group. Option buttons permitem que os usuários escolham uma de várias opções mutuamente exclusivas. Você define propriedades selecionando opções exibidas na caixa de diálogo Option Group Builder.

 Para usar o Option Group builder
 - Usando a barra de ferramentas Form Controls, coloque um controle option group em um formulário.
- Selecione e clique com o botão direito no controle option group e escolha Builder no menu de atalho do Form Designer.
- Escolha as opções desejadas na caixa de diálogo e escolha OK. Quando você escolhe OK, o builder fecha, aplicando as configurações de propriedade de cada guia.

# Guias do Builder
 **Buttons**
Especifica número de botões, legendas e gráficos.
**Layout**
Especifica layout dos option buttons (vertical ou horizontal), espaçamento e estilo de borda.
**Value**
Especifica um campo de tabela ou view no qual armazenar o valor do option group.
