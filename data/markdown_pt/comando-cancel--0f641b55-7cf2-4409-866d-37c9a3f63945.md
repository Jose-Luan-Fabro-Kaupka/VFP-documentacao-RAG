# Comando CANCEL

Encerra a execução do arquivo de programa atual do Visual FoxPro.

```foxpro
CANCEL
```

# Observações

O controle retorna à janela Comando quando o Visual FoxPro está sendo usado interativamente. Se um aplicativo distribuído em tempo de execução estiver em execução, CANCEL encerrará o aplicativo e o controle retornará ao Windows. Se um programa estiver sendo executado no Visual FoxPro durante o tempo de design, CANCEL encerrará o programa e o controle retornará à janela Comando.

A execução de CANCEL libera todas as variáveis privadas.

# Exemplo

O exemplo a seguir simula um loop de execução de programa. A cada passagem pelo loop, você é perguntado se deseja continuar. Se pressionar o botão Cancelar, CANCEL interromperá a execução do programa.

```foxpro
DO WHILE .T.
   IF MESSAGEBOX("Do you want to continue?",36) <> 6
      CANCEL
   ENDIF
ENDDO
```
