# Exemplo Adicionar hiperlinks da Web a um formulário

Arquivo: ...\Samples\Solution\Ffc\HyperLnk.scx

Este exemplo contém as seguintes classes.

| Classe | Biblioteca | Descrição |
| --- | --- | --- |
| _urlcombobox | Internet.vcx | Cria uma caixa de combinação para especificar e navegar para sites da Web. |
| _hyperlinklabel | Internet.vcx | Fornece funcionalidade de Hyperlink e inicia um navegador da Web a partir de um label. |
| _hyperlinkimage | Internet.vcx | Fornece funcionalidade de Hyperlink e inicia um navegador da Web a partir de uma imagem. |
| _hyperlinkcommandbutton | Internet.vcx | Fornece funcionalidade de Hyperlink e inicia um navegador da Web a partir de um botão. |

Para detalhes sobre todas as classes disponíveis nas classes de fundação, consulte Classes de fundação do Visual FoxPro A-Z.
