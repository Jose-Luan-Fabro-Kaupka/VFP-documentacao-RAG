# Como: modificar atributos de classe e de membros de classe

Depois de criar classes, você pode adicionar ou editar suas descrições usando o Class Designer ou o Class Browser. Ao usar o Class Browser, você não precisa abrir cada classe. Você também pode modificar atributos de propriedades e métodos personalizados.

### Para modificar a descrição de uma classe
- Abra a classe no Class Designer . Para obter mais informações sobre como abrir classes, consulte Como: modificar classes . Quando a classe é aberta no Class Designer , o menu Class aparece.
- No menu Class, escolha Class Info .
- Na caixa de diálogo Class Info, escolha a guia Class.
- Faça alterações na descrição na caixa Description.
- Quando terminar de fazer alterações, clique em OK .

### Para modificar a descrição de uma classe sem abrir cada classe
- Abra a biblioteca de classes no Class Browser . Para obter mais informações sobre como abrir bibliotecas de classes, consulte Como: abrir bibliotecas de classes .
- Na lista de classes do Class Browser , selecione a classe cuja descrição você deseja alterar.
- No canto inferior esquerdo do Class Browser , digite o texto da descrição da classe.

Se nenhum membro estiver selecionado na lista de membros do Class Browser, o canto inferior direito do Class Browser exibe as informações de classe e de carimbo de data/hora da classe selecionada.

# Modificando atributos de propriedades e métodos personalizados

Você pode editar os atributos, como o nível de visibilidade e a descrição, de propriedades e métodos personalizados usando a IDE do Visual FoxPro, o Project Manager quando a classe faz parte de um projeto ou no Class Browser.

> **Cuidado:** Tenha cuidado ao editar atributos, como o nível de visibilidade, de propriedades e métodos personalizados. As alterações que você fizer podem afetar o código que referencia essas propriedades e métodos.

### Para modificar atributos de uma propriedade ou método personalizado
- Abra a classe no Class Designer . Para obter mais informações sobre como abrir classes, consulte Como: modificar classes . Quando a classe é aberta no Class Designer , o menu Class aparece.
- No menu Class, escolha Edit Property/Method .
- Quando terminar de fazer alterações, clique em Apply .

Você também pode clicar com o botão direito do mouse na propriedade ou no método na lista de propriedades da janela Properties e escolher Edit Property/Method.

### Para modificar atributos de uma propriedade e método personalizados sem abrir cada classe
- Abra a biblioteca de classes no Class Browser . Para obter mais informações sobre como abrir bibliotecas de classes,, consulte Como: abrir bibliotecas de classes .
- Na lista de membros do Class Browser , selecione um método ou propriedade.
- No canto inferior direito do Class Browser , digite o texto da descrição da propriedade ou do método.

> **Observação:** Para propriedades e métodos de membro, o canto inferior direito exibe uma descrição que você pode editar. No entanto, para membros de objeto e instâncias de classes, o canto inferior direito exibe informações somente leitura da classe e da classe base do membro de objeto, incluindo o nível de visibilidade, nomes de membros e valores de propriedade.
