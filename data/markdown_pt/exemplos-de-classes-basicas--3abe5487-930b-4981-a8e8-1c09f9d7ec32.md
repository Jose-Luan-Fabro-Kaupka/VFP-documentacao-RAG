# Exemplos de classes básicas

As classes básicas do Visual FoxPro fornecem desenvolvimento rápido de aplicações com o mínimo de codificação possível e são fornecidas com a Component Gallery. As classes funcionam imediatamente atendendo às seguintes necessidades:
 - Fornecer ferramentas e estruturas comuns de desenvolvimento de banco de dados.
- Fornecer componentes genéricos rápidos e extensíveis.
- Fornecer componentes que aprimoram e facilitam o desenvolvimento de páginas Web.
- Fornecer wrappers eficazes para funções de API do sistema.
- Fornecer um conjunto extenso de funções para uma ampla gama de usuários do Visual FoxPro.

# Nesta seção
 **Guidelines for Using Visual FoxPro Foundation Classes**
Fornece uma visão geral das situações e soluções em que usar classes básicas.
**Add a Data-Bound Calendar Sample**
Demonstra o uso de um controle ActiveX de calendário associado a dados para aprimorar a entrada de dados em campos de data em formulários.
**Add Data Lookup Combo Boxes Sample**
Realiza uma pesquisa de valores em um campo para preencher uma caixa de combinação.
**Add Data Querying to Forms Sample**
Demonstra opções que permitem navegar em uma tabela e localizar dados.
**Add Data Sorting and Filtering to Forms Sample**
Demonstra o uso de opções avançadas de consulta em um formulário, bem como opções para realizar uma ordenação ascendente ou descendente dos dados.
**Add Encryption to Applications Sample**
Demonstra como você pode adicionar criptografia às suas aplicações.
**Add Miscellaneous Form Buttons Sample**
Mostra o uso de botões de comando em aplicações para executar tarefas como iniciar e parar uma aplicação, exibir um formulário ou visualizar um relatório.
**Add Navigation to Forms Sample**
Demonstra várias opções para fornecer navegação de dados em formulários.
**Add Shortcut Menus to Objects Sample**
Demonstra o uso de menus de atalho em um formulário, incluindo separadores, texto em negrito, comandos marcados e menus em cascata.
**Add Web Hyperlinks to a Form Sample**
Demonstra a adição de funcionalidade de hiperlink e a inicialização de um navegador Web a partir de vários controles.
**Application Error Handling Sample**
Demonstra o tratamento de erros de aplicação e o registro de detalhes do estado da aplicação.
**Create a Visual FoxPro Web Browser Sample**
Demonstra o fornecimento de um controle de navegador Web em um formulário Visual FoxPro para exibir dados em HTML.
**Create Record Bound Graphs Sample**
Mostra o uso de dados de campos para gerar gráficos registro por registro.
**Create Toolbar Control Effects Sample**
Demonstra vários efeitos que você pode obter em controles de barra de ferramentas quando o mouse é movido sobre eles.
**Display Data Reporting Output Options Sample**
Demonstra um editor de texto simples e fornece uma variedade de opções de saída de relatório.
**Expanding the SetAll Method Sample**
Usa a classe básica SetAllx para permitir a definição programática de propriedades de objetos com base em critérios estendidos não disponíveis com o método nativo SetAll( ).
**Generate HTML Sample**
Mostra como você pode usar classes HTML para criar páginas Web a partir de seus dados, formulários e relatórios.
**Handle Application Environment Tasks Sample**
Demonstra utilitários para salvar e restaurar configurações de estado críticas e lidar com operações comuns de aplicação.
**Handle Common Windowing Tasks Sample**
Demonstra o arranjo e o cascateamento de vários formulários na área de trabalho.
**Handle Data Conflicts Sample**
Demonstra a resolução de conflitos de dados, permitindo que o usuário atualize dados no formulário.
**Pool Manager Sample**
Demonstra como usar a classe Pool Manager, que gerencia um pool ou coleção de objetos de uma classe e é útil quando você precisa usar objetos repetidamente por um curto período de tempo.
**Retrieve Project Location and Name Sample**
Demonstra o fornecimento de um local para o usuário inserir um arquivo e local de diretório, principalmente para criar novos projetos.
**Run Word, Excel, and Graph Automation Sample**
Demonstra a adição de rotinas de automação a uma aplicação para criar tabelas dinâmicas do Microsoft Excel, documentos de mala direta do Microsoft Word, tabelas cruzadas do Visual FoxPro e gráficos do Graph.
**Search Text Using Regular Expressions Sample**
Demonstra o uso de pesquisa por expressão regular em aplicações.
**Set VFP Shell Open Commands Sample**
Ilustra como alterar as configurações Shell Open para vários tipos de arquivo.
**Tips for the Windows 2000 Logo Program Sample**
Mostra várias classes básicas que fornecem informações que podem ser úteis para tornar aplicações compatíveis com o Windows 2000 Logo.
**Use an Enhanced Openfile Dialog Box Sample**
Ilustra como usar a classe básica Common File Dialog para criar a aparência das caixas de diálogo de arquivo do Windows.
**Use Array Handling Sample**
Demonstra métodos úteis para expandir a funcionalidade de manipulação de matrizes. Este exemplo usa ACOLSCAN( ) para pesquisar uma coluna específica em uma matriz.
**Use an Enhanced Openfile Dialog Box Sample**
Mostra o uso da classe básica Common File Dialog.
**Use Common Application Dialog Boxes Sample**
Mostra como você pode usar caixas de diálogo em aplicações para operações comuns, como logons de usuário, telas de abertura, caixas Sobre e assim por diante.
**Use Edit Buttons for a Complex Form Sample**
Demonstra o uso de botões para editar formulários que envolvem relações um-para-muitos.
**Use Edit Buttons for a Simple Form Sample**
Demonstra o uso de botões simples de edição de dados para editar formulários simples com uma única tabela.
**Use Mover List Boxes for Selecting Data Sample**
Demonstra o uso de caixas de lista mover para carregar tabelas e campos de uma fonte de dados e lidar com a ordenação de dados.
**Use Progress Thermometer Sample**
Demonstra o uso de uma exibição padrão para mostrar o progresso em aplicações.
**Working with Microsoft Agent Sample**
Demonstra a adição de personagens animados a aplicações usando a tecnologia Microsoft Agent.
