# Função DEFAULTEXT( )

Retorna um nome de arquivo com uma nova extensão se uma ainda não existir.

```foxpro
DEFAULTEXT(cFileName, cDefault)
```

#### Parâmetros
 **cFileName**
Especifica o nome do arquivo (com ou sem caminho ou extensão) a ser retornado.
**cDefault**
Especifica a extensão padrão sem ponto.

# Valor de retorno

Caractere
