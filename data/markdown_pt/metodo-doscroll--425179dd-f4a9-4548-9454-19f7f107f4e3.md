# Método DoScroll

Rola o controle Grid para simular um usuário clicando nas barras de rolagem.

```foxpro
Grid.DoScroll(nDirection)
```

#### Parâmetros
 **nDirection**
As configurações para nDirection são: Comando de rolagem Ação de rolagem 0 Rolar para cima 1 Rolar para baixo 2 Rolar uma página para cima 3 Rolar uma página para baixo 4 Rolar para a esquerda 5 Rolar para a direita 6 Rolar uma página para a esquerda 7 Rolar uma página para a direita

# Observações

Aplica-se a: Grid Control

O evento Scrolled é disparado após o método DoScroll.
