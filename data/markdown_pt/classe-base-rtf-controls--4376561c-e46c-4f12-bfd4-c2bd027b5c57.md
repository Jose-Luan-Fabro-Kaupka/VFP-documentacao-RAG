# Classe base RTF Controls

Esta classe, quando colocada em um formulário, fornece controles para aplicar formatação de fonte ao texto no controle ativo.

| Categoria | Text Format |
| --- | --- |
| Catálogo padrão | Visual FoxPro Catalog\Foundation Classes\Text Formatting |
| Classe | _rtfcontrols |
| Classe base | Container |
| Biblioteca de classes | _format.vcx |
| Classe pai | _container |
| Exemplo | ...\Samples\Solution\Toolbars\format.scx |

# Observações

Para usar, solte a classe em um projeto ou, no menu de atalho do Component Gallery Item, selecione Add to Project ou Add to Form. Quando você adiciona a classe a um projeto, pode escolher entre adicionar a classe ou criar uma subclasse. Quando você adiciona a classe a um formulário, o Visual FoxPro coloca os comboboxes e controles de botão no formulário no Form Designer.
