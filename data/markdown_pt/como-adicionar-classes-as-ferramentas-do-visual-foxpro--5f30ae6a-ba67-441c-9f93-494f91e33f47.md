# Como: adicionar classes às ferramentas do Visual FoxPro

Normalmente, você pode adicionar objetos a formulários arrastando classes da Toolbox ou adicionando-as na barra de ferramentas Form Controls. No entanto, o Visual FoxPro não adiciona classes personalizadas à Toolbox ou à barra de ferramentas Form Controls automaticamente.

### Para adicionar uma classe à Toolbox
- No menu Ferramentas, escolha Toolbox .
- Clique com o botão direito na Toolbox e escolha Add Class Library .
- Na caixa Categoria na caixa de diálogo Add Class Library, digite ou escolha a categoria à qual deseja adicionar a classe.
- Na caixa Class Library, digite o nome da biblioteca de classes. -OU- Clique no botão de reticências (...) para selecionar uma biblioteca de classes.

O Visual FoxPro adiciona a classe ao final da categoria escolhida na Toolbox.

Para obter mais informações, consulte Toolbox (Visual FoxPro) e Como: personalizar a Toolbox.

### Para adicionar uma classe à barra de ferramentas Form Controls
- Abra um formulário.
- No menu Exibir, escolha Form Controls Toolbar .
- Na barra de ferramentas Form Controls, clique em View Classes e escolha Add .
- Na caixa de diálogo Abrir, selecione uma biblioteca de classes e clique em Abrir . A classe aparece na barra de ferramentas Form Controls.

Quando você adiciona bibliotecas de classes à barra de ferramentas Form Controls, elas aparecem registradas na guia Controls da caixa de diálogo Opções. Se você deseja que a classe apareça na barra de ferramentas Forms Control em sessões futuras do Visual FoxPro, clique em Set As Default na guia Controls da caixa de diálogo Opções.

> **Dica:** Você pode registrar a biblioteca de classes para que, ao escolher View Classes na barra de ferramentas Form Controls, a biblioteca de classes apareça na lista de bibliotecas de classes que você pode escolher.

### Para registrar uma biblioteca de classes
- No menu Ferramentas, escolha Opções .
- Na caixa de diálogo Opções, escolha a guia Controls.
- Na guia Controls, escolha Visual class libraries e clique em Add .
- Na caixa de diálogo Abrir, selecione uma biblioteca de classes e clique em Abrir .
- Para disponibilizar a biblioteca de classes na barra de ferramentas Form Controls em sessões futuras do Visual FoxPro, clique em Set As Default .
- Clique em OK .
