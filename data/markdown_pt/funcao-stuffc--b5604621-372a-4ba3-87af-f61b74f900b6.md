# Função STUFFC( )

Retorna uma cadeia de caracteres criada substituindo um número especificado de caracteres em uma expressão de caracteres por outra expressão de caracteres.

```foxpro
STUFFC(cExpression, nStartReplacement, nCharactersReplaced, cReplacement)
```

#### Parâmetros
 **cExpression**
Especifica a expressão de caracteres na qual a substituição ocorre.
**nStartReplacement**
Especifica a posição do caractere em cExpression onde a substituição começa.
**nCharactersReplaced**
Especifica o número de caracteres a serem substituídos. Se nCharactersReplaced for 0, toda a cadeia de substituição cReplacement é inserida em cExpression .
**cReplacement**
Especifica a expressão de caracteres de substituição. Se cReplacement for a cadeia de caracteres vazia, o número de caracteres especificado por nCharactersReplaced é removido de cExpression .

# Valor de retorno

Character

# Observações

STUFFC( ) foi projetada para expressões que contêm caracteres de byte duplo. Se a expressão contém apenas caracteres de byte simples, STUFFC( ) é equivalente a STUFF( ).

STUFFC( ) retorna uma cadeia de caracteres criada substituindo um número especificado de caracteres em uma expressão de caracteres por outra expressão de caracteres. As expressões de caracteres podem consistir em qualquer combinação de caracteres de byte simples e duplo.

Esta função é útil para manipular conjuntos de caracteres de byte duplo para idiomas como Hiragana e Katakana.
