# Propriedade VersionCompany

As informações do nome da empresa para um projeto.

```foxpro
Object.VersionCompany[ = cCompanyName]
```

# Valor de retorno
 **cCompanyName**
Especifica as informações do nome da empresa para um projeto. O valor padrão é a cadeia de caracteres vazia.

# Observações

Aplica-se a: Project Object (Visual FoxPro)

A propriedade VersionCompany corresponde ao valor do item Company Name na caixa de diálogo EXE Version Dialog Box.
