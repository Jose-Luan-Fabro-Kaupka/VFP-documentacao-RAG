# Método UndoCheckOut

Descarta quaisquer alterações feitas em um arquivo e faz check-in do arquivo de volta no controle de código-fonte.

```foxpro
Object.UndoCheckOut()
```

# Observações

Aplica-se a: Objeto File (Visual FoxPro)

True (.T.) é retornado se as alterações no arquivo forem descartadas com sucesso e o arquivo for devolvido ao controle de código-fonte; caso contrário, false (.F.) é retornado.
