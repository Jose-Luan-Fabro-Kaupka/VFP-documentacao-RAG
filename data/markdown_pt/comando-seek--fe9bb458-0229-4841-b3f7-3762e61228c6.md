# Comando SEEK

Procura em uma tabela a primeira ocorrência de um registro cuja chave de índice corresponda a uma expressão geral e move o ponteiro de registro para o registro correspondente.

> **Observação:** O Visual FoxPro não suporta operações seek para índices binários.

```foxpro
SEEK eExpression   [ORDER nIndexNumber | IDXIndexFileName
    | [TAG] TagName [OF CDXFileName]    [ASCENDING | DESCENDING]]
   [IN nWorkArea | cTableAlias]
```

#### Parâmetros
 **eExpression**
Especifica a chave de índice para a qual SEEK procura. eExpression pode ser null.
**ORDER nIndexNumber**
Especifica o número do arquivo de índice ou tag usado para procurar a chave de índice. nIndexNumber refere-se aos arquivos de índice conforme listados em USE ou SET INDEX. Arquivos .idx abertos são numerados primeiro na ordem em que aparecem em USE ou SET INDEX. Tags no arquivo .cdx estrutural (se existir) são então numeradas na ordem em que foram criadas. Finalmente, tags em quaisquer arquivos .cdx independentes abertos são numeradas na ordem em que foram criadas. Consulte Comando SET ORDER para obter mais informações sobre a numeração de índices.
**ORDER IDXIndexFileName**
Especifica um arquivo .idx usado para procurar a chave de índice.
**ORDER [TAG] TagName [OF CDXFileName ]**
Especifica uma tag de um arquivo .cdx usada para procurar a chave de índice. O nome da tag pode ser de um arquivo .cdx estrutural ou de qualquer arquivo .cdx independente aberto. Se existirem nomes de tag idênticos em arquivos .cdx independentes abertos, use OF CDXFileName para especificar o arquivo .cdx que contém a tag. Observação O arquivo .idx tem precedência se existirem nomes de arquivo .idx e tag duplicados.
**ASCENDING**
Especifica que a tabela é pesquisada em ordem ascendente.
**DESCENDING**
Especifica que a tabela é pesquisada em ordem descendente.
**IN nWorkArea**
Especifica o número da área de trabalho da tabela pesquisada.
**IN cTableAlias**
Especifica o alias da tabela pesquisada. Se você omitir IN nWorkArea e IN cTableAlias, a tabela na área de trabalho atualmente selecionada é pesquisada.

# Observações

Você pode usar SEEK apenas com tabelas indexadas e pode pesquisar apenas na chave de índice. A correspondência deve ser exata, a menos que SET EXACT esteja definido como OFF.

Se SEEK encontrar um registro com uma chave de índice correspondente, RECNO( ) retorna o número do registro correspondente, FOUND( ) retorna true (.T.) e EOF( ) retorna false (.F.).

Se uma chave correspondente não for encontrada, RECNO( ) retorna o número de registros na tabela mais 1, FOUND( ) retorna false (.F.) e EOF( ) retorna true (.T.).

Se SET NEAR estiver ativado, o ponteiro de registro é posicionado imediatamente após o registro com a chave de índice mais próxima. Se SET NEAR estiver desativado, o ponteiro de registro é posicionado no final do arquivo. Em ambos os casos, RECNO() retorna o número do registro mais próximo.

# Exemplo

No exemplo a seguir, a tabela Customer é aberta e indexada no campo Company. SEEK é usado para encontrar a expressão de chave de índice que corresponde ao valor contido na variável `gcSeekVal`.

```foxpro
CLOSE DATABASES
OPEN DATABASE (HOME(2) + 'Data\testdata')
USE customer ORDER company  && Opens Customer table
SET EXACT OFF
STORE 'B' TO gcSeekVal
SEEK gcSeekVal
IF FOUND()
   DISPLAY FIELDS company, contact
ENDIF
```
