# Rotinas de entrada e saída de campos Memo

Essas rotinas de API permitem manipular campos memo em uma tabela Visual FoxPro.
 **_AllocMemo( ) API Library Routine**
Aloca size bytes de espaço no arquivo memo para um campo e insere o novo número de bloco no registro associado na tabela.
**_FindMemo( ) API Library Routine**
Retorna a localização no arquivo memo para iniciar a leitura e acessar um campo memo diretamente.
**_MemoChan( ) API Library Routine**
Retorna o canal Visual FoxPro do arquivo memo associado à área de trabalho especificada.
**_MemoSize( ) API Library Routine**
Retorna o comprimento do campo memo no arquivo memo.
