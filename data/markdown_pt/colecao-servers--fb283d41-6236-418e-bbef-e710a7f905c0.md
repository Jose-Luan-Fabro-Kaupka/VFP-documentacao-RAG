# Coleção Servers

Uma coleção de objetos server.

```foxpro
Servers
```

# Observações

Uma coleção Servers fornece acesso a objetos server, possibilitando manipular servidores dentro do projeto.

Para obter mais informações sobre a coleção servers e projetos, consulte Project Manager Hooks.

Para obter informações sobre criação de servidores Automation personalizados, consulte Como: criar servidores Automation.
