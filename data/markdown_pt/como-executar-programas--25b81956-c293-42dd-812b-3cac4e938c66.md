# Como: executar programas

Depois de salvar um programa, você pode executá-lo.

### Para executar um programa independente
- No menu Program, clique em Do.
- Na caixa de diálogo Do, procure e selecione o programa desejado.
- Clique em Do.

### Para executar um programa de um projeto
- Abra o projeto no Project Manager.
- Expanda o nó Code e depois Programs.
- Selecione o programa e clique em Run.

### Para executar um programa programaticamente
- Na janela Command, use o comando DO com o nome do arquivo de programa (.prg), por exemplo: DO MyProgram. Use DO com um ponto de interrogação (?) para abrir a caixa de diálogo Do, por exemplo: DO ?
