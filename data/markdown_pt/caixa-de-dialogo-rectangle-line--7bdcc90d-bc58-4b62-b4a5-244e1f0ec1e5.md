# Caixa de diálogo Rectangle/Line

Especifica opções de posição e saída para controles de relatório Rectangle e Line.

Esta caixa de diálogo aparece quando você desenha um retângulo ou linha em um relatório ou etiqueta e clica duas vezes nele enquanto ele está selecionado.

> **Observação:** Dependendo da configuração da variável de sistema _REPORTBUILDER, esta caixa de diálogo pode ser substituída por uma interface de usuário alternativa. Para obter mais informações, consulte Variável de sistema _REPORTBUILDER.

# Print When

Exibe a caixa de diálogo Print When para que você possa controlar exatamente quando a linha ou o retângulo é impresso no seu relatório ou etiqueta.

# Object Position
 **Float**
Especifica que o controle se move para baixo na página quando um controle acima dele se estende para baixo.
**Fix Relative to Top of Band**
Especifica que o controle permanece na posição em relação ao topo da faixa que o contém.
**Fix Relative to Bottom of Band**
Especifica que o controle permanece na posição em relação à parte inferior da faixa que o contém.

# Stretch Downwards
 **No Stretch**
Especifica que a parte inferior do controle não se expande verticalmente quando a faixa se estica para exibir dados de campo.
**Stretch Relative to Tallest Object In Group**
Especifica que o retângulo se estica para acomodar o objeto mais alto no grupo.
**Stretch Relative to Height of Band**
Especifica que a parte inferior do controle se estica verticalmente para baixo quando a faixa se estica para acomodar dados em controles Field.

# Comment

Permite adicionar comentários ao arquivo .frx ou .lbx. Os comentários são apenas para referência e não aparecem em nenhum lugar no relatório ou etiqueta impressa.
