# "name" não é um arquivo de recurso válido (Erro 1294)

Um arquivo de recurso está corrompido. Por padrão, o arquivo de recurso é FoxUser (FoxUser.dbf e FoxUser.fpt).
 - FoxUser.dbf, FoxUser.fpt ou um dos arquivos de recurso padrão está corrompido. Restaure os arquivos a partir de um backup ou saia do Visual FoxPro, exclua-os e reinicie o Visual FoxPro. Para verificar o arquivo de recurso padrão, consulte a guia Locais dos Arquivos da caixa de diálogo Opções ou use o comando SET RESOURCE.
