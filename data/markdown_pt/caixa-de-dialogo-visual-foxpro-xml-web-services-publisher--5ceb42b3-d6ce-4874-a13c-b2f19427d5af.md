# Caixa de diálogo Visual FoxPro XML Web Services Publisher

Especifica informações para publicar servidores COM Visual FoxPro (.dll) como XML Web services que podem ser acessados na Web. A caixa de diálogo Visual FoxPro XML Web Services Publisher aparece quando você clica em Publish an XML Web Service no painel XML Web Services no Task Pane Manager ou quando você clica em Web Services no menu Wizards do menu Tools.

> **Observação:** A caixa de diálogo Visual FoxPro XML Web Services Publisher usa o mecanismo de geração Web Services Description Language (WSDL) do SOAP Toolkit versão 3.0. Portanto, certos tipos complexos podem não ser suportados. Para obter mais detalhes sobre os arquivos WSDL ou WSML gerados pelo Visual FoxPro XML Web Services Publisher, consulte a documentação do SOAP Toolkit 3.0.

A caixa de diálogo Visual FoxPro XML Web Services Publisher usa o local de URL padrão (diretório virtual) para suas configurações. Você pode exibir e modificar essas configurações padrão clicando em Advanced na caixa de diálogo Publisher. As configurações são preservadas para que você possa republicar seu XML Web service posteriormente com arquivos de suporte recém-gerados.
 **COM Server**
Especifica o nome do arquivo do servidor COM a ser publicado. Clique no botão Ellipsis (...) para selecionar um servidor COM (arquivo .dll ou .exe). Por padrão, um COM Server associado a um projeto ativo é exibido. A caixa COM Server lista todos os COM Servers associados a projetos abertos e quaisquer COM Servers publicados anteriormente.
**Select Class**
Especifica uma classe individual (OLEPUBLIC) do COM Server a ser publicada. A caixa Select Class lista todas as classes no COM Server.
**Advanced**
Exibe a caixa de diálogo Advanced para que você possa modificar as configurações padrão para o XML Web service que deseja publicar e para os arquivos de suporte gerados para o XML Web service. Essas configurações são usadas quando você clica em Generate . Elas são preservadas para que você possa republicar o XML Web service posteriormente com arquivos de suporte recém-gerados. As seguintes configurações estão disponíveis: Guia Options Service Name Especifica o nome do XML Web service a ser criado. Ao gerar os arquivos WSDL (e ASP), use este nome de arquivo. Listener URI Especifica a URL para o arquivo WSDL e ASP. Esta caixa lista locais sugeridos baseados no conjunto de diretórios virtuais em seu servidor Web padrão. Clicar no botão Ellipsis (...) exibe a caixa de diálogo Visual FoxPro XML Web Service Location para que você possa escolher um diretório virtual existente ou novo. Para obter mais informações, consulte Visual FoxPro XML Web Service Location Dialog Box . File(s) Location Exibe o local físico dos arquivos WSDL gerados. Este local é determinado pelo local especificado ao clicar no botão Ellipsis (...) no lado direito da caixa Listener URI. Listener Type Especifica se o XML Web service usa um listener ISAPI ou ASP. O listener ISAPI é a opção padrão e oferece o melhor desempenho. Se um listener ASP for especificado, um arquivo ASP é criado junto com os arquivos WSDL quando o botão Generate é clicado. ASP listener Application Exibe o nome do aplicativo usado no script ASP do arquivo listener. VBScript Especifica que o arquivo listener ASP usa VBScript como linguagem de script. JScript Especifica que o arquivo listener ASP usa JScript como linguagem de script. Automatically generate Cria um project hook com o projeto COM Server para que os arquivos de suporte a XML Web service sejam gerados automaticamente quando o COM Server é recompilado. Generate with UTF-16 Usa codificação Unicode UTF-16 ao gerar arquivos WSDL. Com codificação UTF-16, cada caractere usa dois bytes. Com codificação UTF-8, a maioria dos caracteres, por exemplo, caracteres em inglês, usa um byte cada. Outros caracteres, como asiáticos ou árabes, usam até três bytes cada. Portanto, é melhor salvar arquivos no formato UTF-16. Guia Methods Methods Especifica uma lista de métodos disponíveis na classe COM Server selecionada. Apenas métodos selecionados são incluídos como operações no arquivo XML Web service WSDL gerado. Guia Namespaces Especifica namespaces diferentes para URIs em seus arquivos WSDL gerados. Cada XML Web service precisa de um namespace exclusivo para que aplicativos cliente possam distingui-lo de outros serviços na Web. É recomendável usar um domínio diferente de tempuri.org. WSDL Namespace URI Especifica o namespace usado para definições no documento WSDL. Schema Type Definition Namespace URI Especifica o namespace usado para referências de esquema no documento WSDL. Message Namespace URI Especifica o namespace usado para mensagens de entrada ou saída, ou chamadas de método, no documento WSDL. Base SOAP Action URI Especifica a URI usada para operações no documento WSDL.
**STK3 Wizard**
Abre o SOAP Toolkit 3.0 WSDL Generator para que você possa criar um arquivo WSDL a partir de um objeto COM. Você pode usar este assistente como um método alternativo para publicar seu COM Server como um XML Web service e contém muitas das mesmas opções do Visual FoxPro XML Web Services Publisher.
**Generate**
Gera todos os arquivos de suporte a XML Web service necessários para publicar seu servidor COM como um XML Web service, incluindo um listener ASP e arquivos WSDL.
