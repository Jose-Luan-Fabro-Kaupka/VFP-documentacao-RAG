# Considerações para vincular ou incorporar dados

Use as diretrizes a seguir ao escolher se deve vincular ou incorporar dados:

Vincule a dados quando:
 - Os dados ou gráficos provavelmente mudarão.
- Sua aplicação deve incluir a versão mais recente desses dados disponível.
- Os arquivos de origem estão disponíveis para atualização no seu computador ou em uma rede.
- Os arquivos de origem devem ser compartilhados com outras aplicações.

Incorpore dados ou gráficos quando:
 - Você não precisa das versões mais atuais em sua aplicação.
- Você não precisa incluir os dados em mais de uma aplicação.
- Os arquivos de origem não estariam disponíveis para atualização se fossem vinculados.
- Você deseja incluir um arquivo muito grande, como um arquivo de vídeo ou som.
- Você deseja incluir dados que são mantidos separadamente por sua aplicação de origem.
