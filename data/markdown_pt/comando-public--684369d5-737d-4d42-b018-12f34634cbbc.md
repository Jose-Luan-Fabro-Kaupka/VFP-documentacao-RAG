# Comando PUBLIC

Define variáveis ou matrizes globais. Há duas versões da sintaxe.

```foxpro
PUBLIC MemVarList
```

```foxpro
PUBLIC [ ARRAY ] ArrayName1( nRows1 [ , nColumns1 ] ) [, ArrayName2( nRows2 [, nColumns2 ] ) ] ...
   [AS type [OF ClassLib]]
```

#### Parâmetros
 **PUBLIC MemVarList**
Especifica uma ou mais variáveis de memória a inicializar e designar como globais. Use vírgulas para separar vários itens em MemVarList. As letras simples A a J e M são reservadas e não podem ser usadas como nomes de variáveis.
**PUBLIC [ ARRAY ] ArrayName1 ( nRows1 [, nColumns1 ] ) [, ArrayName2 ( nRows2 [, nColumns2 ] )] ...**
Especifica uma ou mais matrizes a inicializar e designar como globais. Para obter mais informações sobre matrizes, consulte Comando DIMENSION.
**[ AS type [OF ClassLib ] ]**
Especifica o tipo de dados da variável ou matriz e a biblioteca de classes que contém a descrição de tipo de type na qual esta variável ou matriz é baseada. Você pode usar a cláusula AS para implementar tipagem forte. A funcionalidade IntelliSense está disponível para referências de objetos e variáveis somente quando elas são fortemente tipadas. Para obter mais informações, consulte Como: implementar tipagem forte para código de classe, objeto e variável.

# Observações

Você pode usar e modificar variáveis e matrizes globais de qualquer programa executado durante a sessão atual do Visual FoxPro.

Variáveis e matrizes criadas com PUBLIC são inicializadas como False (.F.), exceto as variáveis públicas FOX e FOXPRO, que são inicializadas como True (.T.). Dependendo da versão do Visual FoxPro que você está executando, você pode usar as variáveis públicas FOX e FOXPRO para executar código condicionalmente.

> **Observação:** As variáveis públicas FOX e FOXPRO eram usadas em versões anteriores para detectar versões anteriores do FoxBASE e FoxPro, respectivamente.

Você deve declarar quaisquer variáveis ou matrizes que deseja tornar públicas antes de atribuir valores a elas. Se você atribuir um valor a uma variável ou matriz em um programa e depois declará-la como pública usando PUBLIC, o Visual FoxPro gera um erro de sintaxe.

Variáveis ou matrizes que você cria na janela Command são automaticamente públicas.

# Exemplo

```foxpro
SET TALK OFF
PUBLIC val1,val2
val1 = 10
val2 = 15
DO down
? val1
? val2
RELEASE ALL     && Releases private variables only
DISPLAY MEMORY LIKE val?
RELEASE val1,val2  && Public variables must be released explicitly
DISPLAY MEMORY LIKE val?
PROCEDURE down
PRIVATE val1
val1 = 50
val2 = 100
? val1
? val2
RETURN
```
