# Propriedade FirstElement

Especifica o primeiro elemento de uma matriz a ser exibido em um controle ComboBox ou ListBox. Disponível em tempo de projeto e em tempo de execução.

```foxpro
Control.FirstElement[ = nElement]
```

# Valor de retorno
 **nElement**
Especifica qual elemento da matriz é exibido como o primeiro elemento da lista.

# Observações

Aplica-se a: controle ComboBox | controle ListBox

Esta propriedade está disponível somente quando RowSource é uma matriz (RowSourceType = 5). Observe que a propriedade FirstElement se aplica apenas a ComboBoxes e ListBoxes com uma coluna.
