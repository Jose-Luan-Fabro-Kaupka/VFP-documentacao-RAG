# Caixa de diálogo Coverage

Permite especificar opções para registrar a execução de programas. Use esta caixa de diálogo para obter informações sobre quantas vezes cada linha de código foi executada, quais linhas de código não foram executadas nos seus testes e quanto tempo cada linha levou para executar.

Esta caixa de diálogo aparece quando você escolhe Coverage Logging no menu Tools da janela Debugger.
 **File**
Especifica o arquivo no qual gravar o log de cobertura. O botão da caixa de diálogo exibe a caixa de diálogo Open, que permite selecionar um arquivo no qual gravar o log de cobertura.
**Append**
Especifica que o log de cobertura é gravado após o conteúdo atual de um arquivo existente, preservando o conteúdo original.
**Overwrite**
Especifica que o log de cobertura substitui o conteúdo do arquivo especificado.
