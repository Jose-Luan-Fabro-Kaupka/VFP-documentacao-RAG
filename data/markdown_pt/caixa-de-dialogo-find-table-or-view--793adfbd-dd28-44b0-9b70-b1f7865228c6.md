# Caixa de diálogo Find Table or View

Permite localizar uma tabela ou view que você não consegue encontrar facilmente no Database Designer. Esta caixa de diálogo aparece quando você clica em Find Object no menu Database. Para obter mais informações, consulte How to: Find Tables or Views in Databases.
 **Tables or Views**
Mostra uma lista de objetos no layout do banco de dados que você pode localizar. Se a tabela ou view desejada não aparecer nesta lista, ela não foi adicionada ao banco de dados.
**Find button**
Seleciona e exibe o objeto no esquema do banco de dados.
