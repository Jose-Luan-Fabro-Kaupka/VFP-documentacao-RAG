# Como: construir uma expressão de variável

No Expression Builder, você pode construir uma expressão que contém o nome de uma variável.

### Para construir uma expressão de variável
- Quando disponível, clique no botão de reticências (...) para abrir o Expression Builder.
- Execute uma das seguintes ações: Na caixa de expressão principal, digite um nome de variável. Na lista Variables do builder, selecione um nome de variável de sistema.
- Clique em OK.

Para obter mais informações, consulte Expression Builder Dialog Box.
