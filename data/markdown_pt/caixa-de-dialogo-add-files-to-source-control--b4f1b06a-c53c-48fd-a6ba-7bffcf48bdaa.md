# Caixa de diálogo Add Files to Source Control

Adiciona um arquivo ou arquivos selecionados no seu projeto ao controle de código-fonte.
 **Files to add**
Lista todos os arquivos que você pode adicionar ao controle de código-fonte.
**Keep Checked out**
Atualiza o banco de dados de controle de código-fonte com suas alterações, mas mantém o arquivo reservado para você.
**Comment**
Exibe o comentário associado a um arquivo ou permite adicionar ou alterar um.
