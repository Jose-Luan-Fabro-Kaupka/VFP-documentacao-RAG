# Como: operar a janela Command

Em geral, você pode fazer na janela Command qualquer coisa que pode fazer em um programa. Por exemplo, você pode executar uma linha de código, como um comando do Visual FoxPro, digitando-a na janela Command. No entanto, quando você executa código na janela Command, esse código é executado imediatamente. Você também pode executar várias linhas de código na janela Command como se estivessem em um programa autônomo.

Além disso, as escolhas que você faz em menus e caixas de diálogo são ecoadas na janela Command. Você pode copiar e colar esses comandos em um programa do Visual FoxPro e executar o programa repetidamente, facilitando a execução de vários comandos repetidamente.

A janela Command é uma janela de edição; portanto, você pode editar código usando as ferramentas de edição disponíveis no Visual FoxPro. Por exemplo, você pode editar, inserir, excluir, cortar, copiar ou colar texto na janela Command.

### Para executar uma linha de código na janela Command
- Na janela Command, digite uma linha de código e pressione a tecla ENTER.

### Para executar a mesma linha de código na janela Command
- Na janela Command, mova o cursor para qualquer posição na linha de código que deseja executar.
- Pressione a tecla ENTER.

### Para executar várias linhas de código na janela Command
- Na janela Command, selecione as linhas de código que deseja executar.
- Pressione a tecla ENTER.

Embora você possa executar código na janela Command que normalmente executaria em um arquivo de programa, certas vantagens existem ao executar código de um programa. Para obter mais informações, consulte Trabalhando com programas.
