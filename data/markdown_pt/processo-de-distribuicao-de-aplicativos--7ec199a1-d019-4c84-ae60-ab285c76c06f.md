# Processo de distribuição de aplicativos

A lista a seguir identifica as etapas gerais que você precisa seguir para distribuir um aplicativo do Visual FoxPro:
 - Criar e depurar o aplicativo usando o ambiente de desenvolvimento do Visual FoxPro.
- Preparar e personalizar seu aplicativo para o ambiente de tempo de execução. Para obter detalhes, consulte Preparation for Distributing Applications .
- Certificar-se de que seu projeto inclui todos os arquivos necessários para seu aplicativo, incluindo quaisquer arquivos de recursos, arquivos gráficos ou modelos. Para obter mais informações sobre os tipos de arquivos que você pode incluir em seu aplicativo e como incluir arquivos, consulte Resource Files in Applications e How to: Include Files with Applications for Distribution . Observação Arquivos de tempo de execução necessários: O Visual FoxPro requer a inclusão de certos arquivos para que seus aplicativos de tempo de execução funcionem corretamente. A maneira mais fácil de incluir esses arquivos é usando uma ferramenta baseada em Windows Installer para criar configurações personalizadas (como InstallShield Express). Ao selecionar o módulo de mesclagem Microsoft Visual FoxPro 9.0 Runtime Libraries, sua configuração contém os arquivos adequados necessários para executar seu aplicativo personalizado do Visual FoxPro 9.0. O módulo de mesclagem principal do Visual FoxPro 9.0 trata corretamente a instalação e o registro dos seguintes arquivos: vfp9r.dll vfp9t.dll vfp9renu.dll msvcr71.dll gdiplus.dll Os arquivos Msvcr71.dll e gdiplus.dll fazem parte de módulos de mesclagem separados, mas são incluídos automaticamente devido à sua dependência com as bibliotecas de tempo de execução do Visual FoxPro 9.0. Gdiplus.dll é instalado apenas em plataformas anteriores ao Windows 2000 (por exemplo, Windows 98). Se você precisar de suporte de tempo de execução para um idioma adicional, selecione o módulo de mesclagem de idioma apropriado. Esses módulos de mesclagem contêm uma biblioteca de recursos de idioma específica (por exemplo, vfp9rdeu.dll).
- Remover quaisquer recursos ou arquivos restritos do Visual FoxPro do seu aplicativo. Certos recursos do ambiente de desenvolvimento não estão disponíveis no ambiente de tempo de execução e precisam ser removidos do seu aplicativo. Certifique-se de que quaisquer arquivos que você planeja distribuir atendam às diretrizes para redistribuição de arquivos. Para obter mais informações sobre recursos e arquivos restritos e distribuíveis, consulte Distributable and Restricted Visual FoxPro Features and Files .
- Compilar um aplicativo (.app), um arquivo executável (.exe) ou um componente COM (servidor de automação) com extensão .dll ou .exe. Para obter mais informações sobre como compilar um aplicativo, consulte Compiling an Application .
- Criar um pacote de instalação usando um programa de implantação do Windows Installer. Para obter mais informações sobre como criar pacotes de instalação, consulte Walkthrough: Creating a Visual FoxPro Application Setup Program Using InstallShield . Observação O programa de criação de configuração que você usar deve usar a tecnologia Windows Installer para criar um programa de configuração (.msi) ou módulos de mesclagem (.msm) compatíveis com o Microsoft Windows Installer. As diretrizes do Windows 2000 Logo exigem que os programas de configuração sejam baseados na tecnologia Windows Installer.
- Empacotar e distribuir os discos do seu aplicativo e qualquer documentação impressa. Dependendo do programa de criação de configuração que você usar, o programa pode criar as imagens de disco para você, ou você pode precisar copiar os arquivos para o local de distribuição manualmente. Consulte a documentação do programa de criação de configuração para obter mais informações.
