# Caixa de diálogo Opções do Report Builder (Report Builder)

Permite especificar como o Report Builder responde a eventos no Report Designer.
 - Como: configurar o tratamento de eventos do Report Builder
- Como: especificar uma tabela alternativa de manipuladores de eventos de relatório
- Como: adicionar seu próprio manipulador ao registro do Report Builder
 **Tratamento de eventos do Report Designer**
Especifica como o Report Builder responderá a eventos no Report Designer.
**Tabela de registro de manipuladores**
Especifica se o Report Builder usa sua tabela de consulta interna ou uma tabela externa alternativa personalizável. A caixa de texto conterá o nome de arquivo totalmente qualificado da tabela de registro de manipuladores de eventos do report builder atual. Clique nas reticências ( … ) para exibir uma caixa de diálogo de seleção de arquivo para selecionar uma tabela de registro de manipuladores de eventos alternativa. Esta configuração não persiste entre sessões do Visual FoxPro.
**Criar cópia**
Solicita um nome de arquivo e local nos quais será colocada uma cópia da tabela de registro de manipuladores de eventos interna padrão, pronta para personalização.
**Explorador de registro**
Exibe a Caixa de diálogo Registro de manipuladores de eventos (Report Builder) .
**Fechar**
Fecha a caixa de diálogo Opções do Report Builder.
