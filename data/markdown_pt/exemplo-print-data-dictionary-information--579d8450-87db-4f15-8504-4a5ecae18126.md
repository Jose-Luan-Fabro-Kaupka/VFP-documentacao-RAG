# Exemplo Print Data Dictionary Information

Arquivo: ...\Samples\Solution\Reports\Dbctofrx.scx

Este exemplo ilustra uma maneira simples de gerar um relatório com o conteúdo de um banco de dados do Visual FoxPro (.dbc). Basta escolher um arquivo .dbc quando solicitado e um relatório será gerado para você visualizar. Você pode clicar no botão Print para gerar uma cópia impressa.

O exemplo cria um cursor temporário e insere novos registros conforme o .dbc é examinado. Registros de tabelas e views são adicionados junto com suas informações de campos e índices associados.
