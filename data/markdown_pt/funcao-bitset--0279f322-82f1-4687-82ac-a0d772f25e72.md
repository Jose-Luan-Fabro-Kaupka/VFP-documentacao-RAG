# Função BITSET( )

Define como 1 um bit de um valor Numeric, Varbinary ou Blob e retorna o valor resultante. Há uma versão numérica e outra binária da sintaxe.

> **Observação:** Se a expressão especificada não for inteira, ela será convertida em inteiro antes da definição do bit.

```foxpro
BITSET(nNumericExpression1, nNumericExpression2)
BITSET(BinaryExpression [, nStartBit [, nBitCount]])
```

#### Parâmetros
 **nNumericExpression1**
Especifica um valor Numeric no qual o bit será definido.
**nNumericExpression2**
Especifica a posição do bit de nExpression1 a definir como 1. Pode variar de 0 a 31, sendo 0 o bit mais à direita.
**BinaryExpression**
Especifica uma expressão Varbinary ou Blob.
**[ nStartBit [, nBitCount ]]**
Especifica em nStartBit o primeiro bit, com numeração iniciada em zero, e em nBitCount o número de bits da operação. Se ambos forem omitidos, a operação se aplicará a todos os bits. Se apenas nStartBit for informado, ela se aplicará somente a esse bit.

# Valor de retorno

Numeric, Varbinary ou Blob. BITSET( ) retorna a expressão especificada com o bit definido como 1.

# Exemplo

```foxpro
x = 5  && 0101 binary
y = 1  && 2nd bit position (0 = 1st bit position)
? BITSET(x,y) && Returns 7, 0111 binary
```
