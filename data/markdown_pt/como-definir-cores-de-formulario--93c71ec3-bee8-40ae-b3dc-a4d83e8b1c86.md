# Como: definir cores de formulário

Você pode controlar as cores de um formulário usando a propriedade ColorSource para basear as cores em um esquema de cores existente, ou pode usar a barra de ferramentas Color Palette para alterar a cor de primeiro plano ou de fundo dos seus formulários e dos controles dentro deles.

### Para definir cores de formulário usando a propriedade ColorSource
- Na guia Layout na janela Properties, escolha ColorSource e selecione um valor.

### Para definir a cor de primeiro plano ou de fundo de um formulário ou controle
- No menu View, selecione Color Palette toolbar.
- Escolha Foreground Color ou Background Color.
- Selecione o controle ou formulário que deseja alterar.
- Na barra de ferramentas Color Palette, selecione a cor que deseja usar.
- Para ver mais opções de cores, escolha Other Colors na barra de ferramentas.

### Para criar uma cor personalizada
- Na barra de ferramentas Color Palette, escolha Other Colors.
- Na caixa de diálogo Color, escolha Define Custom Colors para exibir o Custom Color Selector.
- Selecione uma das caixas Custom Colors e, em seguida, clique no Custom Color Selector para selecionar a cor personalizada desejada.
- Escolha Add to Custom Colors para adicionar a nova cor à sua paleta.
- Escolha OK. O Visual FoxPro aplica a cor personalizada à seleção atual.
