# Amostras de solução diversas

Essas amostras de solução ilustram outras tarefas que você pode realizar com o Visual FoxPro.

# Nesta seção
 **Control MSN Messenger Sample**
Demonstra como realizar operações com o MSN Messenger usando a API do Messenger e o Windows Scripting Host.
**Track Activities in a Project Sample**
Demonstra como project hooks podem ser usados para rastrear a atividade do projeto, incluindo adição, exclusão e modificação de arquivos.

# Seções relacionadas
 **Solution Samples**
Contém amostras que demonstram recursos específicos do Visual FoxPro e podem ser executadas de forma independente.
**Sample Class Libraries**
Contém bibliotecas de classes de amostra que fornecem funcionalidade encapsulada que você pode adicionar às suas aplicações.
**Foundation Class Samples**
Contém amostras que ilustram o uso das classes Foundation do Visual FoxPro.
**Walkthroughs**
Contém instruções passo a passo para cenários comuns.
