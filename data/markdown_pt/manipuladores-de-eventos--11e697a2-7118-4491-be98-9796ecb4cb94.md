# Manipuladores de eventos

Estes comandos e funções permitem especificar a ação que um programa executa quando determinado evento ocorre.

| Usar | Para |
| --- | --- |
| Função EVENTHANDLER( ) | Associar um evento de servidor COM a métodos de interface implementados em um objeto do Visual FoxPro. |
| Comando ON ERROR | Especificar uma expressão válida ou um comando do Visual FoxPro a ser executado quando ocorrer um erro no código em tempo de execução. |
| Comando ON ESCAPE | Especificar um comando executado quando você pressiona a tecla ESC durante a execução de um programa ou comando. |
| Comando ON KEY LABEL | Especificar um comando executado quando você pressiona uma tecla ou combinação de teclas específica ou clica no botão do mouse. |
| Comando ON PAD | Especificar o menu ou a barra de menus ativada quando você escolhe um título de menu específico. |
| Comando ON SELECTION PAD | Especificar o menu ou a barra de menus ativada quando você escolhe um título de menu específico. |
| Comando ON SELECTION POPUP | Especificar um comando executado quando você escolhe qualquer item de menu em um menu especificado ou em todos os menus. |
| Comando ON SHUTDOWN | Especificar um comando executado quando você tenta sair do Visual FoxPro ou do Microsoft Windows. |
| Função ON( ) | Retornar o comando atribuído a cada um destes comandos de tratamento de eventos: ON ERROR, ON ESCAPE, ON KEY LABEL ou ON PAGE. |
