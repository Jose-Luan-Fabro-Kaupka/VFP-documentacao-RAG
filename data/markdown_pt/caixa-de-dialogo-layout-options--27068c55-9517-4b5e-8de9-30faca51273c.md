# Caixa de diálogo Layout Options

Parte do Web Publishing Wizard, esta caixa permite alterar os valores padrão do layout de dados selecionado e salvar as alterações como novo layout e estilo.

 Para acessar a caixa de diálogo Layout Options
 - No menu Tools, escolha Wizards e Web Publishing.
- Avance até a etapa 3.
- Clique em Options.
 **Border**
Permite escolher cores de fundo e borda, largura da borda e uma imagem .gif ou .jpg de fundo.
**Font**
Permite especificar uma ou mais fontes HTML, tamanho e cor do texto, melhorando a compatibilidade entre plataformas.
**Other**
Permite indicar uma classe HTML e configurações específicas do layout, como arquivo .css, cores de linhas e número de linhas por bloco alternado.
**Reset Defaults**
Restaura os valores padrão originais do assistente.

Ao clicar em OK, a caixa fecha e retorna à etapa 3.
