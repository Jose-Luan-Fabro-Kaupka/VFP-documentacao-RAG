# Função WCOLS( )

Retorna o número de colunas dentro da janela ativa ou especificada.

```foxpro
WCOLS([WindowName])
```

#### Parâmetros
 **WindowName**
Especifica a janela para a qual WCOLS( ) retorna o número de colunas. No Visual FoxPro, você também pode especificar o nome de uma barra de ferramentas. Se você não especificar uma janela, o número de colunas na janela de saída ativa é retornado. Se nenhuma janela estiver ativa, WCOLS( ) retorna o número de colunas na janela principal do Visual FoxPro. Você pode especificar o nome de uma janela do sistema (a janela Command, a janela Data Session, uma janela Browse e assim por diante) em WCOLS( ) se a janela do sistema foi ativada e está visível ou oculta. No Visual FoxPro, você pode especificar o nome de uma barra de ferramentas (a barra de ferramentas Standard, a barra de ferramentas Color Palette e assim por diante) em WCOLS( ) se a barra de ferramentas foi ativada e está visível ou oculta. Se você especificar o nome de uma janela do sistema ou barra de ferramentas que não foi ativada, o Visual FoxPro gera uma mensagem de erro. A janela Debug é uma exceção. Uma vez que a janela Debug foi aberta, seu nome pode ser incluído em WCOLS( ) se estiver visível, oculta ou fechada. Você também pode incluir a cadeia de caracteres vazia como nome da janela para retornar o número de colunas na janela principal do Visual FoxPro. A cadeia de caracteres vazia pode ser usada para especificar a janela principal do Visual FoxPro em funções como WLCOL( ), WLROW( ) e WROWS( ), que retornam localizações ou tamanhos de janela.

# Valor de retorno

Numérico

# Observações

No Visual FoxPro, o valor retornado por WCOLS( ) depende da fonte especificada para a janela. Muitas fontes podem ser exibidas em uma ampla variedade de tamanhos, e algumas são proporcionalmente espaçadas. Uma coluna corresponde à largura média de uma letra na fonte atual. Para mais informações, consulte o tópico Fonts Overview.

# Exemplo

O exemplo a seguir centraliza uma mensagem de saída curta na última linha de uma janela de tamanho desconhecido.

```foxpro
CLEAR
DO SendMesg WITH 'Message', WCOLS(), WROWS() –1
*** SendMesg ***
PROCEDURE SendMesg
PARAMETERS gcMsg, gnCol, gnRow
STORE (gnCol – LEN(gcMsg))/2 TO gnCol
@ gnRow, gnCol SAY gcMsg
RETURN
```
