# Classe base de imagem GDI Plus

A classe gpImage encapsula uma imagem GDI+ e serve como classe base para tipos de imagem específicos (por exemplo, a classe gpBitmap).

| Categoria | Relatórios |
| --- | --- |
| Catálogo padrão | Visual FoxPro Catalog\Foundation Classes\Output\GDIplus |
| Classe | gpImage |
| Classe base | Custom |
| Biblioteca de classes | _GDIPLUS.vcx |
| Classe pai | gpObject ( Classe base de objeto GDI Plus ) |

# Observações

A tabela a seguir lista propriedades e métodos públicos adicionados por esta classe à sua classe pai, gpObject. Esta classe também implementa os métodos Init e Clone.

| Propriedades e métodos | Descrição |
| --- | --- |
| Método Clone | Clona um objeto de imagem. Sintaxe: THIS.Clone(toGpImage) Valores de retorno: Lógico, representando sucesso ou falha. Parâmetros: toGpImage , obrigatório, o objeto baseado em gpImage a clonar. |
| Método CreateFromFile | Cria um objeto de imagem a partir de um arquivo. Sintaxe: THIS.CreateFromFile(tcFileName [, tlUseEmbeddedColorMgmt]) Valores de retorno: Lógico, representando sucesso ou falha. Parâmetros: tcFileName , obrigatório, o arquivo de imagem do qual criar o objeto de imagem. tlUseEmbeddedColorMgmt , opcional, se o gerenciamento de cores incorporado deve ser usado. |
| Propriedade Flags | Especifica sinalizadores de atributo para esta imagem como um inteiro calculado como uma combinação de valores de bit, usando as constantes definidas GDIPLUS_ImageFlags_*. Padrão: Vazio. |
| Método GetBounds | Obtém um retângulo delimitador nas unidades especificadas. Sintaxe: THIS.GetBounds(tnUnits) Valores de retorno: um objeto do tipo gpRectangle , ou null ( .NULL. ) em caso de erro. Parâmetros: tnUnits , obrigatório, especificado conforme o conjunto de constantes GDIPLUS_Unit_*. |
| Método GetDecoderCLSID | Obtém o CLSID do Decoder para um formato de imagem específico (por exemplo, " image/jpeg "). Sintaxe: qCLSID = THIS.GetDecoderCSLID(tvSearchValue) Valores de retorno: Varbinary, CLSID do Decoder. Retorna null ( .NULL. ) em caso de erro. Parâmetros: tvSearchValue , obrigatório. Uma cadeia de caracteres contendo o tipo MIME da imagem (ex.: "image/jpeg" ), ou um GUID varbinary do formato de imagem, conforme especificado nas constantes GDIPLUS_IMAGEFORMAT_*. Observações: Se nenhum decoder for encontrado para o tipo de imagem especificado, ou se o tipo MIME ou GUID do formato de imagem fornecido em tvSearchValue for inválido, esta função retorna .NULL. e o método GetStatus() retorna 0 ("no error"). |
| Método GetEncoderCLSID | Obtém o CLSID do encoder para um formato de imagem específico (por exemplo, " image/jpeg "). Sintaxe: qCLSID = THIS.GetEncoderCSLID(tvSearchValue) Valores de retorno: Varbinary, CLSID do encoder adequado para passar ao método SaveToFile(). Retorna null ( .NULL. ) em caso de erro. Parâmetros: tvSearchValue , obrigatório. Uma cadeia de caracteres contendo o tipo MIME da imagem (ex.: "image/jpeg" ), ou um GUID varbinary do formato de imagem, conforme especificado nas constantes GDIPLUS_IMAGEFORMAT_*. Observações: Se nenhum encoder for encontrado para o tipo de imagem especificado, ou se o tipo MIME ou GUID do formato de imagem fornecido em tvSearchValue for inválido, esta função retorna .NULL. e o método GetStatus() retorna 0 ("no error"). |
| Método GetPropertyCount | Obtém o número de propriedades armazenadas nos metadados deste objeto de imagem. Sintaxe: nCount = THIS.GetPropertyCount() Valores de retorno : Inteiro, número de propriedades de metadados (que pode ser zero). Retorna null ( .NULL. ) em caso de erro. Parâmetros: nenhum . |
| Método GetPropertyIdList | Obtém uma lista de todas as propriedades armazenadas nos metadados da imagem, como uma matriz do Visual FoxPro. Sintaxe: nCount = THIS.GetPropertyIdList(@raPropIDList) Valores de retorno : Inteiro, número de propriedades de metadados (que pode ser zero). Retorna null ( .NULL. ) em caso de erro. Os valores de ID de propriedade são retornados na matriz de parâmetro raPropIDList. Parâmetros: raPropIDList , obrigatório, matriz passada por referência. No retorno, esta matriz é dimensionada como uma matriz unidimensional, e cada elemento da matriz contém um valor inteiro de ID de propriedade. |
| Método GetPropertyItem | Recupera a propriedade especificada dos metadados da imagem. Sintaxe: vPropertyValue = THIS.GetPropertyItem(tnPropID) Retorna: Valor da propriedade, ou null ( .NULL. ) se a propriedade não for encontrada ou ocorrer um erro. O tipo de dados depende do tipo de tag da propriedade, conforme segue: Tipos de propriedade: Retornados no Visual FoxPro como: byte, short, long, signed long Numérico String Cadeia de caracteres ANSI rational, signed rational Cadeia de caracteres contendo dois números separados por um caractere de barra. Por exemplo, um terço seria "1/3" . Tipos de propriedade não mostrados aqui não são suportados. Parâmetros: tnPropID , obrigatório, inteiro, um ID de item de propriedade conforme retornado por GetPropertyIDList . Observações: Se a propriedade solicitada não estiver definida, este método retorna null ( .NULL. ) e o método GetStatus() retorna 19 (GDIPLUS_STATUS_PropertyNotFound). |
| Método GetThumbnailImage | Obtém uma imagem em miniatura do objeto de imagem, retornada como um novo objeto gpImage. Sintaxe: oImage= THIS.GetThumbnailImage(tnWidth, tnHeight) Valores de retorno: Objeto gpImage contendo uma miniatura. Retorna null ( .NULL. ) se ocorrer um erro. Parâmetros: tnWidth , inteiro, obrigatório, largura desejada da miniatura em pixels. tnHeight , inteiro, obrigatório, largura desejada da miniatura em pixels. Observações: Alguns arquivos de imagem possuem uma imagem em miniatura incorporada no arquivo. Nesses casos, este método recupera a miniatura incorporada e os valores dos parâmetros tnWidth e tnHeight são ignorados. Se não houver miniatura incorporada, este método cria uma miniatura redimensionando a imagem principal para o tamanho especificado nos parâmetros tnWidth e tnHeight. Se ambos os parâmetros forem 0 , um tamanho definido pelo sistema é usado. |
| Propriedade HorizontalResolution | Numérico, resolução horizontal em pixels por polegada. Somente leitura. Padrão: nenhum. |
| Propriedade ImageHeight | Altura deste objeto Image. Somente leitura. Padrão: nenhum. |
| Propriedade ImageWidth | Largura deste objeto Image. Somente leitura. Padrão: nenhum. |
| Método Init | Constrói um objeto Image durante a inicialização se argumentos apropriados forem passados. Sintaxe: CREATEOBJECT("gpImage" [,tnHandle|tcFileName[, tlParam]]) Valores de retorno: Lógico, representando sucesso ou falha. Se o método falhar, o objeto não é instanciado. Parâmetros: tnHandle | tcFilename, obrigatório se a criação imediata do objeto for solicitada, um identificador gráfico ou nome de arquivo do qual a imagem será criada. tlParam , opcional, indica se a classe possui o identificador gráfico (se o primeiro parâmetro for tnHandle ) ou se o gerenciamento de cores deve ser usado (se o primeiro parâmetro for tcFileName ). |
| Propriedade PhysicalDimension | Fornece a largura e a altura deste objeto de imagem, como um objeto do tipo gpSize . Somente leitura. Padrão: nenhum. Observações: Se a imagem for um bitmap, a largura e a altura são retornadas em pixels. Se a imagem for um metafile, a largura e a altura são retornadas em unidades de 0,01 milímetro. |
| Propriedade PixelFormat | Formato de pixel, conforme os valores especificados nas constantes GP_PIXELFORMAT_*. Somente leitura. Padrão: nenhum. Observações: Pode não se aplicar a alguns objetos de imagem, como imagens em formato vetorial. |
| Propriedade RawFormat | Obtém o formato desta imagem como um GUID do tipo varbinary. Somente leitura. Padrão: nenhum. |
| Método RotateFlip | Rotaciona e/ou inverte (espelha) o objeto de imagem. Sintaxe: THIS.RotateFlip(tnRotateFlipType) Valores de retorno: Lógico, representando sucesso ou falha. Parâmetros: tnRotateFlipType , obrigatório, inteiro. Especifica o ângulo de rotação e/ou o tipo de inversão, conforme os valores especificados nas constantes definidas GDIPLUS_ROTATEFLIPTYPE_*. |
| Método SaveToFile | Salva o objeto de imagem em um arquivo em disco, usando o encoder ou formato de imagem especificado e parâmetros opcionais. Sintaxe: THIS.SaveToFile(tcFilename, tvCLSIDEncoder[, rvEncoderParams]) Valores de retorno: Lógico, representando sucesso ou falha. Parâmetros: tcFilename , obrigatório, cadeia de caracteres, o nome do arquivo no qual a imagem deve ser salva. tvCLSIDEncoder , obrigatório, cadeia de caracteres ou varbinary. O CLSID do encoder a usar, ou um tipo MIME (ex.: " image/jpeg "). Se um tipo MIME for especificado, o método pesquisa dinamicamente o CLSID do Encoder apropriado. rvEncoderParams , opcional, parâmetros para o encoder. Uma cadeia de caracteres separada por vírgulas na forma " param1=value1,param2=value2 ", ou uma matriz de duas colunas (passada por referência) de parâmetros e valores do encoder. Observações: Os parâmetros do encoder são definidos internamente por IDs globalmente exclusivos (GUIDS). Esta função entende um conjunto limitado de parâmetros por nome: Tipo de imagem Parâmetros disponíveis JPEG quality, transformation TIFF compression, colordepth, saveflag Para passar outros parâmetros, use a forma de matriz de rvEncoderParams com o GUID do parâmetro na primeira coluna. O exemplo a seguir salva uma imagem em um arquivo JPEG, usando qualidade de 80%. lSuccess = oImage.SaveToFile( "example.jpg", ; "image/jpeg", "quality=80" ) |
| Propriedade VerticalResolution | Numérico, resolução vertical em pixels por polegada. Somente leitura. Padrão: nenhum. |
