# SYS(2002) - Ativar ou desativar o ponto de inserção

Ativa ou desativa o ponto de inserção.

```foxpro
SYS(2002 [, 1])
```

# Valor de retorno

Nenhum

# Observações

SYS(2002) desativa o ponto de inserção. SYS(2002, 1) ativa o ponto de inserção. Para obter mais informações sobre ativar e desativar o ponto de inserção, consulte Comando SET CURSOR.
