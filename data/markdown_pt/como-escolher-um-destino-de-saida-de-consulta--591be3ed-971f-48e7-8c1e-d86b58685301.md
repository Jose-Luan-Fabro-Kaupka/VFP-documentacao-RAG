# Como: escolher um destino de saída de consulta

Você pode enviar os resultados da sua consulta para um destino diferente para saída, como um cursor, tabela ou tela. Por padrão, o Visual FoxPro exibe os resultados da sua consulta em uma janela de navegação.

Quando você escolhe Query Destination no menu Query ou escolhe o botão Query Destination na barra de ferramentas Query, a caixa de diálogo Destination é exibida, para que você possa escolher onde enviar os resultados da sua consulta.

### Para escolher um destino de consulta
- No menu Query, escolha Query Destination .
- Na caixa de diálogo Query Destination, escolha um destino de saída e preencha quaisquer campos adicionais conforme necessário.
