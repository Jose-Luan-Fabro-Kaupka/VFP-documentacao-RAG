# Método Box

Desenha um retângulo em um objeto Form. Há duas versões da sintaxe.

```foxpro
Object.Box(nXCoord1, nYCoord1, nXCoord2, nYCoord2)
```

```foxpro
Object.Box(nXCoord2, nYCoord2)
```

#### Parâmetros
 **nXCoord1 , nYCoord1**
Especifica as coordenadas do ponto inicial do retângulo. O método ScaleMode do formulário determina a unidade de medida usada. Se você omitir esses argumentos, os valores de CurrentX e CurrentY são usados.
**nXCoord2 , nYCoord2**
Especifica o ponto final do retângulo.

# Observações

Aplica-se a: Form Object | _SCREEN System Variable

A largura das linhas desenhadas depende da configuração da propriedade DrawWidth. A forma como um retângulo é desenhado no plano de fundo depende das configurações das propriedades DrawMode e DrawStyle. Quando o método Box é chamado, as propriedades CurrentX e CurrentY são definidas para o ponto final especificado pelos dois últimos argumentos.
