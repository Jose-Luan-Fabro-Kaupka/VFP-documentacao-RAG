# Como: adicionar dados do usuário a bandas de relatório

Você pode adicionar dados definidos pelo usuário a uma banda de relatório. Dados definidos pelo usuário aparecem no campo User da tabela de estrutura do relatório e não aparecem no relatório ou etiqueta.

### Para adicionar dados definidos pelo usuário a uma banda de relatório
- Abra o relatório ou etiqueta no designer apropriado.
- No menu Report, clique em Edit Bands. A caixa de diálogo Edit Bands é aberta.
- Na caixa de diálogo Edit Bands, selecione a banda desejada e clique em OK. A caixa de diálogo de propriedades da banda de relatório é aberta. Dica Você também pode clicar duas vezes no separador de banda no Report Designer ou Label Designer para abrir a caixa de diálogo de propriedades da banda de relatório. Observação Se a variável de sistema _REPORTBUILDER não estiver definida para o Report Builder padrão ou estiver definida para um builder de terceiros, a caixa de diálogo da banda de relatório é exibida ou uma caixa de diálogo diferente pode ser exibida. Para obter mais informações, consulte Variável de sistema _REPORTBUILDER e Caixa de diálogo Report Band Properties.
- Na caixa de diálogo de propriedades da banda de relatório, clique na guia Other se ela não estiver selecionada.
- Na guia Other, clique em Edit user data. A caixa de diálogo de dados do usuário da banda de relatório é aberta.
- Na caixa de diálogo de dados do usuário, digite os dados definidos pelo usuário desejados e clique em OK.
- Para obter mais informações, consulte Guia Other, Caixa de diálogo Report Band Properties (Report Builder).
