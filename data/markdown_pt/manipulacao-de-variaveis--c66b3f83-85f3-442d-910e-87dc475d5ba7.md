# Manipulação de variáveis

Estes comandos e funções permitem atribuir valores a variáveis ou texto.

| Use | Para |
| --- | --- |
| Comando & | Realizar substituição de macro. |
| Comando = | Avaliar uma ou mais expressões. |
| Função ACOPY( ) | Copiar elementos de uma matriz para outra matriz. |
| Função ADEL( ) | Excluir um elemento de uma matriz unidimensional, ou uma linha ou coluna de uma matriz bidimensional. |
| Função ADIR( ) | Colocar informações sobre arquivos em uma matriz e depois retornar o número de arquivos. |
| Função AELEMENT( ) | Retornar o número de um elemento de matriz a partir dos subscritos do elemento. |
| Função AFIELDS( ) | Recuperar e armazenar informações sobre a estrutura da tabela em uma área de trabalho especificada, especificada por um alias de tabela, ou na área de trabalho selecionada atualmente em uma matriz e retornar o número de campos na tabela. |
| Função AINS( ) | Inserir um elemento em uma matriz unidimensional, ou uma linha ou coluna em uma matriz bidimensional. |
| Função ASCAN( ) | Pesquisar uma matriz por um elemento contendo os mesmos dados e tipo de dados que uma expressão. |
| Função ASORT( ) | Ordenar elementos em uma matriz em ordem ascendente ou descendente. |
| Função ASUBSCRIPT( ) | Retornar o subscrito de linha ou coluna de um elemento a partir do número do elemento. |
| Comando AVERAGE | Calcular a média aritmética de expressões numéricas ou campos. |
| Comandos CLEAR | Liberar o item ou itens especificados da memória. |
| Comandos CLEAR | Liberar o item ou itens especificados da memória. |
| Comando COUNT | Contar registros da tabela. |
| Comando DISPLAY MEMORY | Exibir o conteúdo atual de variáveis e matrizes. |
| Comando GETEXPR | Exibir a Caixa de diálogo Construtor de expressões para que você possa criar uma expressão e armazená-la em uma variável ou elemento de matriz. |
| Variável de sistema _GETEXPR | Especificar o programa que é executado quando você emite o comando GETEXPR ou invoca a caixa de diálogo Construtor de expressões no Visual FoxPro. |
| Função LEN( ) | Determinar o número de caracteres em uma expressão de caracteres, indicando o comprimento da expressão. |
| Comandos LIST | Exibir informações de tabela ou ambiente sem pausar a janela principal do Visual FoxPro ou a janela definida pelo usuário. |
| Comando LOCAL | Criar variáveis locais e matrizes de variáveis. |
| Comando PARAMETERS | Atribuir dados de um programa chamador a variáveis ou matrizes PRIVATE. |
| Comando PRIVATE | Ocultar variáveis ou matrizes especificadas que foram definidas em um programa chamador do programa atual. |
| Comando PUBLIC | Definir variáveis ou matrizes globais. |
| Comando RELEASE | Remover variáveis e matrizes da memória. |
| Comando RESTORE FROM | Recuperar variáveis e matrizes de variáveis salvas em um arquivo de variáveis ou um campo memo e colocá-las na memória. |
| Comando SAVE TO | Armazenar variáveis e matrizes atuais em um arquivo de variáveis ou campo memo. |
| Comando STORE | Armazenar dados em uma variável, em uma matriz ou em um elemento de matriz. |
| Comando SUM | Totalizar todos ou campos numéricos especificados na tabela selecionada atualmente. |
| Função TEXTMERGE( ) | Fornecer avaliação de uma expressão de caracteres. |
| Comando WAIT | Exibir uma mensagem e pausar a execução do Visual FoxPro até que o usuário pressione uma tecla ou clique no mouse. |
