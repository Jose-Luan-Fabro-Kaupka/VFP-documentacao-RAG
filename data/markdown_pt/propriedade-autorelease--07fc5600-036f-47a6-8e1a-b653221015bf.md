# Propriedade AutoRelease

Determina se um conjunto de formulários é liberado quando o último formulário do conjunto é liberado. Disponível em tempo de design; leitura/gravação em tempo de execução.

```foxpro
FormSet.AutoRelease[ = lExpr]
```

# Valor de retorno
 **lExpr**
As configurações da propriedade AutoRelease são: Configuração Descrição True (.T.) O padrão no Designer de Formulários. O conjunto de formulários é liberado quando o último formulário do conjunto é liberado. False (.F.) O padrão no código do programa. O conjunto de formulários não é liberado quando o último formulário do conjunto é liberado.

# Observações

Aplica-se a: Objeto FormSet
