# Subclasses no Visual FoxPro

Você pode criar uma nova classe ou uma subclass a partir da maioria das classes base do Visual FoxPro ou de outras classes existentes. Uma subclass pode incluir algumas ou todas as funcionalidades da classe original, ou pai, além de quaisquer características adicionais, como propriedades padrão personalizadas ou funcionalidade que você deseja incluir para personalizar a nova classe.

Criar e usar subclasses oferece os benefícios da reutilização, ajudando a diminuir a quantidade de código que você precisa escrever, e da herança, que economiza tempo e esforço ao atualizar classes quando você faz alterações em uma classe pai. Quando você modifica uma classe pai, as alterações que faz se propagam para todas as subclasses que herdam da classe pai.

Por exemplo, suponha que você tenha uma classe command button. Você pode criar uma subclass a partir da classe command button que contém todas as propriedades, métodos e eventos padrão de um command button, além de propriedades ou funcionalidade adicionais que deseja incluir, como exibir o command button com uma determinada cor ou tamanho ou executar ações como exibir uma mensagem específica quando clicado.

Subclasses não se limitam a uma única classe. Por exemplo, você pode adicionar vários controles a uma definição de classe container, como uma classe form. Muitas das classes na biblioteca de classes de amostra do Visual FoxPro se enquadram nesta categoria. Para obter mais informações, consulte Sample Class Libraries.
