# Gerenciando arquivos em um projeto sob controle de origem

Depois de colocar um projeto do Visual FoxPro sob controle de origem, você pode trabalhar com arquivos individuais ou gerenciar o projeto como um todo.

# Nesta seção
 **Working with Multi-File Components**
Aborda como alguns arquivos de projeto consistem em vários componentes e como o Visual FoxPro gerenciará o arquivo ou arquivos implícitos automaticamente.
**How to: Check Out Files**
Descreve como fazer check-out de um arquivo em um projeto sob controle de origem.
**How to: Check In Files**
Descreve como fazer check-in de um arquivo em um projeto sob controle de origem.
**How to: Discard Changes**
Descreve como desfazer um check-out para que quaisquer alterações no arquivo sejam descartadas.
**How to: Get the Latest Versions of Files**
Descreve como obter a versão mais recente de um arquivo que já está em check-out.
**How to: Compare Files or Projects**
Explica como comparar arquivos ou projetos em um ambiente com controle de origem para determinar se outro usuário os alterou ou para identificar onde as alterações foram feitas desde o último check-out.
**How to: Check for Differences in Forms, Reports, and Other Table Files**
Descreve como comparar arquivos que representam formulários, relatórios e tabelas para determinar onde as alterações foram feitas.
**How to: Display File and Project Information**
Discute como visualizar o histórico de check-out ou as informações de controle de origem de um arquivo ou lista de projetos.

# Seções relacionadas

Discute como o uso de software de controle de origem, como o Microsoft Visual SourceSafe, para gerenciar os arquivos em um projeto torna possível criar aplicações complexas rapidamente, combinando as habilidades de uma equipe de desenvolvedores.
