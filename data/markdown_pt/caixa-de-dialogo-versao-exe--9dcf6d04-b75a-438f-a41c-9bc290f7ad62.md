# Caixa de diálogo Versão EXE

Exibe o número de compilação de um programa e outras informações sobre o programa que você pode fornecer.

Esta caixa de diálogo aparece quando você clica no botão Version na caixa de diálogo Opções de compilação.

# Número da versão
 **Principal**
Exibe um número de quatro dígitos que pode ser editado. Este número corresponde a uma versão principal.
**Secundário**
Exibe um número de quatro dígitos que pode ser editado. Este número corresponde a uma versão secundária.
**Revisão**
Exibe um número editável de quatro dígitos. Este número corresponde a atualizações incrementais.
**Incremento automático**
Quando marcada, esta opção permite atualizações automáticas do número de Revisão em cada compilação do programa.

# Informações da versão
 **Tipo**
Lista sete categorias de informações de versão, que você pode definir. Essas categorias são Comments, Company Name, File Description, Legal Copyright, Legal Trademarks, Product Name e Language ID.
**Valor**
Exibe as informações inseridas sobre uma única categoria. Clique em uma categoria na lista Tipo para exibir, inserir ou editar as informações.
