# Variável de sistema _ObjectBrowser

Contém o nome do aplicativo de navegador de objetos.

```foxpro
_ObjectBrowser = cObjectBrowserApplication
```

#### Parâmetros
 **cObjectBrowserApplication**
Especifica o nome do programa Visual FoxPro que permite visualizar bibliotecas de tipos COM.

# Observações

Por padrão, _ObjectBrowser contém objectbrowser.app, instalado na pasta de aplicativos do usuário do Windows ou no local HOME( ). Você pode especificar um nome diferente para o aplicativo de navegador de objetos.
