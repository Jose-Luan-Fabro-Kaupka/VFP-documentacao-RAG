# Programação no Visual FoxPro

Você pode criar aplicações e programas aprendendo e usando a linguagem de programação e os recursos do Visual FoxPro.

# Nesta seção
 **Basic Programming Concepts**
Fornece uma visão geral dos fundamentos de programação necessários para trabalhar no Visual FoxPro, incluindo armazenamento de dados, tipos de dados, contêineres, operadores, comandos e controle do fluxo do programa.
**Working with Programs**
Apresenta como criar e trabalhar com programas Visual FoxPro, que são arquivos de texto contendo instruções usando a linguagem Visual FoxPro.
**Working with Procedures and Functions**
Apresenta como chamar funções nativas, bem como funções e procedimentos definidos pelo usuário, fornece uma visão geral e aspectos de funções e procedimentos definidos pelo usuário, e como criar funções e procedimentos.
**Passing Data to Parameters**
Discute formas e como passar dados para parâmetros.
**Object-Oriented Programming**
Discute como você pode criar componentes de aplicação autocontidos que respondem a ações do usuário e do sistema e que podem ser facilmente mantidos e reutilizados.
**Accessing APIs**
Discute como você pode estender uma aplicação aproveitando bibliotecas externas, como controles Microsoft ActiveX ou bibliotecas de vínculo dinâmico (DLLs).
**How to: Create Quit Routines**
Descreve como criar rotinas de saída personalizadas quando os usuários saem da sua aplicação, do Visual FoxPro ou do Microsoft Windows.

# Seções relacionadas
 **Using Visual FoxPro**
Fornece uma visão geral dos recursos do Visual FoxPro, descreve conceitos e ferramentas de produtividade para desenvolver, programar e gerenciar aplicações e componentes de banco de dados de alto desempenho.
**Developing Visual FoxPro Applications**
Explica conceitos sobre como desenvolver aplicações Visual FoxPro, instruções para criar bancos de dados e a interface do usuário, e outras tarefas necessárias para criar aplicações Visual FoxPro.
**Development Productivity Tools**
Discute as ferramentas de desenvolvedor para desenvolvimento de aplicações dentro da aplicação Visual FoxPro e a linguagem Visual FoxPro.
**Walkthroughs**
Fornece cenários comuns e guias passo a passo sobre como criar diferentes tipos de aplicações e componentes.
