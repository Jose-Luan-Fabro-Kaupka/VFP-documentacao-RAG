# Objeto Relation

Criado quando você estabelece relacionamentos no Data Environment Designer para um formulário, conjunto de formulários ou relatório.

```foxpro
Relation
```

# Observações

O objeto Relation permite determinar ou especificar como duas tabelas estão relacionadas.

Definir uma propriedade do objeto Relation em tempo de execução gera um erro. Para que uma nova configuração de propriedade tenha efeito, você deve chamar os métodos CloseTables e OpenTables do ambiente de dados.

Para obter mais informações sobre o ambiente de dados para Forms e FormSets, consulte Como: definir o ambiente de dados.
