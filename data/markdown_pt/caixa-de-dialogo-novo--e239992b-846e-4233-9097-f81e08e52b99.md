# Caixa de diálogo Novo

Permite criar um novo arquivo. A caixa de diálogo Novo aparece quando você seleciona Novo no menu Arquivo.

# Atalho

CTRL+N
 **Tipo de arquivo**
A tabela a seguir lista os tipos de arquivo e os recursos disponíveis para criá-los, dependendo de você clicar em Novo arquivo ou Assistentes. Tipo de arquivo Criado com Projeto Gerenciador de projetos Banco de dados Database Designer Tabela Table Designer , Table Wizard Consulta Query Designer , Cross-Tab Wizard , Query Wizard , Local View Wizard , Remote View Wizard , PivotTable Wizard Conexão* Connection Designer View* View Designer , Local View Wizard Remote View* Remote View Wizard Formulário Form Designer , Form Wizard , One-to-Many Form Wizard Relatório Report Designer , Report Wizard , One-to-Many Report Wizard Etiqueta Label Designer , Label Wizard Programa Janela de edição Classe Class Designer Arquivo de texto Janela de edição Menu Menu Designer

* Você deve ter um banco de dados aberto para habilitar esta opção.
 **Novo arquivo**
Exibe uma caixa de diálogo, designer ou janela de edição para que você possa criar o tipo de arquivo selecionado.
**Assistente**
Abre um assistente que cria o tipo de arquivo selecionado. Se houver um grupo de assistentes para escolher, o Visual FoxPro solicitará que você selecione o assistente desejado.
