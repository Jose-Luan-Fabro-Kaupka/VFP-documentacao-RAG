# Método RemoveListItem

Remove um item de uma caixa de combinação ou caixa de lista.

```foxpro
Control.RemoveListItem(nItemId)
```

#### Parâmetros
 **nItemId**
Especifica um inteiro que representa o ID exclusivo do item no controle.

# Observações

Aplica-se a: controle ComboBox | controle ListBox
