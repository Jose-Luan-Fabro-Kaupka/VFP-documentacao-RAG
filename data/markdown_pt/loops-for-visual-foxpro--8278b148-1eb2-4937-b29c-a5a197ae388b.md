# Loops FOR (Visual FoxPro)

Você pode comparar como os loops FOR diferem entre o Visual FoxPro e outras linguagens de programação.

| Visual FoxPro | BASIC |
| --- | --- |
| FOR n = 1 TO 10 ? n ENDFOR | For n = 1 to 10 Print n Next n |

| Pascal | C/C++ |
| --- | --- |
| for n := 1 to 10 do writeln(n); | for(n=1; n<11; n++) printf("%d\n",n); |
