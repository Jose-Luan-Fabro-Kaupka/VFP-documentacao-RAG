# Botões da ferramenta Coverage Profiler

Contém os seguintes botões da ferramenta Coverage Profiler.

| Botão | Descrição |
| --- | --- |
| Caixa de diálogo Open Catalog | Exibe a caixa de diálogo Open para que você possa abrir um log de cobertura. |
| Caixa de diálogo Save As | Exibe a caixa de diálogo Save As para que você possa salvar as informações do aplicativo Coverage Profiler como uma tabela (.dbf). |
| Caixa de diálogo Coverage Profiler Statistics | Exibe a caixa de diálogo Coverage Profiler Statistics para que você possa visualizar resumos dos detalhes do Coverage Profiler e revisar estatísticas do Coverage Profiler em relação a um projeto específico do Visual FoxPro. |
| Caixa de diálogo Coverage Profiler Add-Ins | Exibe a caixa de diálogo Coverage Profiler Add-Ins para que você possa especificar Add-Ins a serem usados com o Coverage Profiler. |
| Janela Coverage Profiler | Exibe resultados de cobertura no painel inferior da janela Coverage Profiler ou na janela Zoom. |
| Janela Coverage Profiler | Exibe resultados do profiler no painel inferior da janela Coverage Profiler ou na janela Zoom. |
| Janela Coverage Profiler | Exibe a janela Coverage Profiler como uma única caixa de diálogo de dois painéis. |
| Janela Coverage Profiler | Exibe o Coverage Profiler como duas caixas de diálogo separadas que você pode organizar e redimensionar. |
| Caixa de diálogo Coverage Profiler Find | Exibe a caixa de diálogo Coverage Profiler Find para que você possa pesquisar um item específico no log de cobertura. |
