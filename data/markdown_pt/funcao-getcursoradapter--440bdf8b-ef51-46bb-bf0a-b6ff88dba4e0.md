# Função GETCURSORADAPTER( )

Retorna uma referência de objeto a um objeto CursorAdapter em tempo de execução, referenciando o nome do cursor.

```foxpro
GETCURSORADAPTER( [ cAlias ] )
```

#### Parâmetros
 **cAlias**
Especifica o alias do cursor. Se você não fornecer um alias, o Visual FoxPro usa o alias do cursor na área de trabalho atual.

# Valor de retorno

Uma referência de objeto a um objeto CursorAdapter.

# Observações

Aplica-se a: CursorAdapter Class
