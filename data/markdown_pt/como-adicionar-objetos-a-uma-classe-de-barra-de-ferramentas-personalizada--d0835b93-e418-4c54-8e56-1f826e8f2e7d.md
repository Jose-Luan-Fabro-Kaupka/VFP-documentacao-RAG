# Como: adicionar objetos a uma classe de barra de ferramentas personalizada

Depois de criar uma classe de barra de ferramentas personalizada, você pode adicionar objetos a ela, incluindo quaisquer objetos suportados pelo Visual FoxPro, exceto grids. Por exemplo, você pode adicionar objetos da barra de ferramentas Controls.

### Para adicionar objetos à sua classe de barra de ferramentas personalizada
- Abra a biblioteca de classes que contém a classe de barra de ferramentas personalizada e, em seguida, abra a classe.
- Na barra de ferramentas Form Controls, escolha um objeto que deseja adicionar.
- Coloque o objeto na barra de ferramentas personalizada selecionando a barra de ferramentas personalizada.
- Repita as etapas 2 e 3 até que a barra de ferramentas personalizada esteja completa.
- Reorganize os objetos na barra de ferramentas personalizada, se apropriado. Por exemplo, você pode dimensionar objetos, movê-los arrastando-os, excluí-los pressionando a tecla DELETE ou adicionar espaço extra entre eles inserindo objetos Separator da barra de ferramentas Form Controls. Observação Você pode mover apenas um objeto por vez.
- Defina as propriedades da barra de ferramentas na janela Properties.
- Salve a classe de barra de ferramentas personalizada. Dica Você pode adicionar um bitmap ou ícone a um botão da barra de ferramentas definindo sua Picture Property (Visual FoxPro) .
