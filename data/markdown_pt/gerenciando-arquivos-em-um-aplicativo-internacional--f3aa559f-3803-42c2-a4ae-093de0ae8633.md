# Gerenciando arquivos em um aplicativo internacional

A janela Project Manager pode ajudá-lo a organizar um aplicativo internacional. Em um projeto, você pode integrar as partes de um aplicativo, como formulários, menus, programas e relatórios. O projeto garante que as partes estejam atualizadas quando você compila o aplicativo para o mercado-alvo.

Diferentemente dos arquivos .dbf, arquivos de texto como consultas e programas não possuem marcas de página de código. Isso significa que você deve acompanhar as páginas de código usadas por arquivos de texto para poder usá-los corretamente. Com o Project Manager, você pode acompanhar as páginas de código usadas por arquivos de texto.

# Distribuindo arquivos de tempo de execução específicos de localidade

Se você estiver distribuindo seu aplicativo junto com a versão de tempo de execução do Visual FoxPro, talvez precise incluir um arquivo de recursos específico de localidade. Esse arquivo contém as caixas de diálogo e outros elementos da interface do usuário que o Visual FoxPro usa para interagir com o usuário. Há um arquivo de recursos de tempo de execução diferente para cada idioma em que o Visual FoxPro está disponível.

Normalmente, você só precisa se preocupar com um recurso de tempo de execução específico de localidade se todas as condições a seguir forem verdadeiras:
 - Você está incluindo a versão de tempo de execução do Visual FoxPro com seu aplicativo.
- Você está distribuindo seu aplicativo para usuários que usam um idioma diferente daquele em que você desenvolveu. Por exemplo, se você desenvolve em inglês para uma base de usuários de língua inglesa, não precisa se preocupar em incluir um arquivo de recursos específico de localidade. No entanto, se você usa a versão em inglês do Visual FoxPro para desenvolver, mas está distribuindo seu aplicativo de tempo de execução em um país de língua francesa, deve considerar incluir o arquivo de recursos de tempo de execução.
- Seu aplicativo exibe caixas de diálogo, menus ou mensagens de erro do Visual FoxPro. Normalmente, se você projetou e localizou suas próprias versões desses elementos de interface, não precisa incluir o arquivo de recursos específico de localidade.

Os arquivos de recursos de tempo de execução são nomeados usando o formato VFPVersionNumber***.dll, em que VersionNumber é o número da versão do Visual FoxPro e "***" é um código de três letras que representa o idioma. Por exemplo, o código ENU representa inglês dos Estados Unidos, o código DEU representa alemão e o código FRA representa francês.

Você deve sempre incluir pelo menos um arquivo de recursos de tempo de execução, mesmo se não pretender usar nenhum dos elementos da interface do usuário do Visual FoxPro como parte do seu aplicativo. Por padrão, o Visual FoxPro inclui o arquivo de recursos fornecido com sua cópia do programa. Por exemplo, se você está desenvolvendo um aplicativo usando a versão dos Estados Unidos do Visual FoxPro, o Visual FoxPro inclui automaticamente VFPVersionNumberRENU.dll se você incluir arquivos de tempo de execução com seu aplicativo. Se não houver motivo para usar um arquivo de recursos específico de localidade, você pode simplesmente distribuir o arquivo de recursos padrão como parte do seu aplicativo.

Quando o aplicativo é instalado, os usuários podem especificar o arquivo de recursos de tempo de execução a ser usado fazendo uma entrada no registro do sistema Windows ou usando uma opção de linha de comando.

Para especificar um arquivo de recursos de tempo de execução:
 - Na linha de comando que inicia seu aplicativo, inclua a opção L e o nome do arquivo de recursos que deseja usar (incluindo um caminho, se necessário). Não coloque um espaço entre a opção e o nome do arquivo. Por exemplo, o seguinte comando especifica o arquivo VFP VersionNumber RDEU.dll como o arquivo de recursos: C:\Program Files\Microsoft Visual ; FoxPro\MYAPP.EXE -LC:\MyApp\VFP VersionNumber RDEU.dll -ou-
- Configure o registro do Windows na máquina do usuário (usando código ou um aplicativo como Regedit.exe) para apontar para o arquivo de recursos a ser usado. A entrada do registro que contém o nome do arquivo de recursos de tempo de execução é: HKEY_CLASSES_ROOT\VisualFoxProRuntime. VersionNumber \Resources Por exemplo, a seguinte entrada do registro aponta para o arquivo de recursos de tempo de execução VFPRDEU.dll: HKEY_CLASSES_ROOT\VisualFoxproRuntime. VersionNumber \Resources C:\Program Files\Common Files\Microsoft Shared\VFP\VFPRDEU.dll Se você deseja controlar o arquivo de recursos usado pela versão completa de desenvolvimento do Visual FoxPro, use uma chave de registro semelhante sem a referência de tempo de execução: HKEY_CLASSES_ROOT\VisualFoxpro. VersionNumber \Resources Por exemplo, a seguinte entrada do registro aponta para o arquivo de recursos em um computador com a versão completa do Visual FoxPro instalada: HKEY_CLASSES_ROOT\VisualFoxpro. VersionNumber \Resources C:\Program Files\Visual FoxPro VersionNumber \VFPDEU.dll

Quando o aplicativo de tempo de execução é iniciado, o Visual FoxPro procura um arquivo de recursos, primeiro de acordo com a opção L e depois de acordo com a configuração do Registro. Se nenhuma dessas configurações especificar um arquivo de recursos específico de localidade, o Visual FoxPro usa a localidade do sistema (Windows) atual para construir dinamicamente um nome de arquivo DLL. Portanto, se o arquivo de recursos específico de localidade do seu aplicativo corresponder à localidade do sistema na versão do Windows do usuário, você não precisa especificar explicitamente o nome do arquivo de recursos. No entanto, é sempre mais seguro não depender do padrão do sistema se você deseja ter certeza de que o arquivo correto será carregado.
