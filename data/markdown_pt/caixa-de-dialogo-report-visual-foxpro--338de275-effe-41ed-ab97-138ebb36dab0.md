# Caixa de diálogo Report (Visual FoxPro)

Exibe os resultados de sua consulta como um layout de relatório. Esta caixa de diálogo aparece na guia Miscellaneous do Query Designer e está disponível apenas para consultas. Para obter mais informações, consulte Guia Miscellaneous, Query and View Designers.

> **Observação:** Você deve ter configurado previamente um arquivo de relatório (.frx) que acomode os campos de saída na consulta. Para obter mais informações, consulte Trabalhando com relatórios.
 **Open Report**
Exibe a caixa de diálogo Open para você selecionar um arquivo de relatório a ser usado em sua consulta. Você pode clicar no botão ou digitar o nome do arquivo na caixa de texto.
**Wizard Icon**
Exibe a caixa de diálogo Wizard Selection, na qual você pode escolher um report wizard para executar.
**Page Preview**
Exibe a saída na janela Page Preview.
**Console On**
Exibe a saída na janela de saída ativa.
**Eject Page Before Report**
Imprime uma página em branco no início do relatório para separar documentos na impressora.

# Saída secundária
 **None**
Especifica que a saída não será enviada à impressora nem salva como arquivo de texto.
**To Printer**
Envia os resultados da consulta à impressora.
**To Text File**
Salva os resultados da consulta como um arquivo de texto. Clique no botão para selecionar um arquivo existente que deseja sobrescrever ou digite o nome de um novo arquivo na caixa de texto.

# Opções
 **Suppress Column Headings**
Impede que os cabeçalhos de coluna apareçam no topo da saída.
**Summary Information Only**
Suprime a impressão de linhas de detalhe. O relatório produzido inclui cabeçalhos, rodapés, totais e assim por diante, mas exclui as linhas de detalhe.
