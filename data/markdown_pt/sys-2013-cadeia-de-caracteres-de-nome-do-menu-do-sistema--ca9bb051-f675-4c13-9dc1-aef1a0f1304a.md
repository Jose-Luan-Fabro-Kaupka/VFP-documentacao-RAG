# SYS(2013) - Cadeia de caracteres de nome do menu do sistema

Retorna uma cadeia de caracteres delimitada por espaços contendo os nomes internos do sistema de menu do Visual FoxPro.

```foxpro
SYS(2013)
```

# Valor de retorno

Caractere

# Observações

SYS(2013) facilita a utilização da barra de menu do sistema e dos menus do sistema do Visual FoxPro. A cadeia de caracteres retornada contém o nome da barra de menu do sistema, seus títulos de menu e o nome de cada item nos menus.

SYS(2013) retorna os nomes dos títulos de menu e itens de menu para todas as plataformas FoxPro. Consulte System Menu Names para uma listagem dos títulos de menu e itens de menu do Visual FoxPro.
