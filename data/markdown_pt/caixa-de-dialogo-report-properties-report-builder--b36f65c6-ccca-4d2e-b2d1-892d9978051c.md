# Caixa de diálogo Report Properties (Report Builder)

Permite definir opções para relatórios e etiquetas.

Esta caixa de diálogo aparece quando você escolhe Properties no menu de contexto de uma janela de layout de relatório ou quando clica em Properties no menu Report.

> **Observação:** Esta caixa de diálogo é exibida apenas se a variável de sistema _REPORTBUILDER estiver definida para o aplicativo Report Builder padrão. Se estiver vazia ou foi definida para um report builder de terceiros, a caixa de diálogo nativa do Visual FoxPro (ou uma caixa de diálogo de terceiros) pode aparecer. Para obter mais informações, consulte a variável de sistema _REPORTBUILDER.

A tabela a seguir lista as guias que existem na caixa de diálogo Report Properties.

> **Observação:** Ao modificar o relatório ou a etiqueta no modo protegido, algumas ou todas as guias podem não estar disponíveis conforme especificado pelas configurações do modo de proteção.

| Guia | Descrição |
| --- | --- |
| Page Layout Tab, Report Properties Dialog Box (Report Builder) | Permite especificar configurações de layout de página e configuração de impressora para o layout do relatório ou da etiqueta. |
| Optional Bands Tab, Report Properties Dialog Box (Report Builder) | Permite especificar a estrutura de bandas do layout, como se inclui bandas Title, Summary ou Detail adicionais, e como elas são processadas quando o layout é processado em tempo de execução. |
| Data Grouping Tab, Report Properties Dialog Box (Report Builder) | Permite criar e especificar como os dados são agrupados no layout do relatório ou da etiqueta. |
| Variables Tab, Report Properties Dialog Box (Report Builder) | Permite criar variáveis que são inicializadas e recebem valores conforme o layout é processado em tempo de execução. |
| Protection Tab, Report Properties Dialog Box (Report Builder) | Permite ocultar ou mostrar guias na caixa de diálogo Report Properties ou impedir que os usuários executem certas ações ao modificar o relatório ou a etiqueta no modo protegido. |
| Ruler/Grid Tab, Report Properties Dialog Box (Report Builder) | Permite especificar configurações específicas do layout para a régua e a grade de layout de página no Report Designer e no Label Designer. |
| Data Environment Tab, Report Properties Dialog Box (Report Builder) | Permite carregar um ambiente de dados no layout atual e especificar configurações de sessão de dados. |
| Document Properties Tab, Report Properties Dialog Box (Report Builder) | Permite adicionar, editar ou excluir propriedades de documento para o relatório. As propriedades de documento são incluídas apenas em relatórios HTML ou XML e são renderizadas como meta tags na saída de um relatório. |
| Other Tab, Report Properties Dialog Box (Report Builder) | Permite adicionar comentários, dados do usuário e elementos de código que você pode usar em tempo de execução do relatório para relatórios no Report Designer ou Label Designer. |
