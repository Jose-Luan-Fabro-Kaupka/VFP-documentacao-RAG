# Caixa de diálogo Configuração de página do relatório

Permite especificar configurações para a página do relatório que são salvas com o relatório, por exemplo, para ajustar a largura da coluna e a área de impressão.

> **Observação:** Dependendo da configuração da variável de sistema _REPORTBUILDER, esta caixa de diálogo pode ser substituída por uma interface de usuário alternativa. Para obter mais informações, consulte Variável de sistema _REPORTBUILDER .

# Seção Layout da página

Fornece uma representação gráfica da página, que reflete seu layout no Report Designer e Label Designer e as configurações que você escolhe na caixa de diálogo Configuração de página do relatório.

# Colunas

Especifica opções para colunas na página.
 **Number**
Especifica o número de colunas a imprimir na página.
**Width**
Especifica a largura do layout dentro de uma coluna.
**Spacing**
Especifica o espaço entre colunas, quando várias colunas foram especificadas.
**Page Setup**
Exibe a caixa de diálogo Configuração de página, na qual você pode selecionar configurações de papel e impressora. Para obter mais informações, consulte Caixa de diálogo Configuração de página .
**Print order**
Determina se os registros são impressos de cima para baixo ou da esquerda para a direita quando o layout contém várias colunas.

# Área de impressão

Especifica opções para a área de impressão na página.
 **Printable page**
Especifica que o layout usa as dimensões de página imprimível da impressora atual. A impressão começa imediatamente após a área de margem não imprimível. A impressão começa imediatamente após a área de margem não imprimível.
**Whole page**
Especifica que os atributos de tamanho físico do papel da impressora atual determinam as dimensões do layout. Observação Para impressoras que têm uma área de impressão menor que o tamanho físico do papel, você precisará verificar seus layouts de relatório para garantir que a saída renderizada não seja truncada pela impressora.
**Left margin**
Especifica a largura da margem esquerda. Aumentar este valor reduzirá proporcionalmente a largura do layout.
**Dimensions**
Exibe as unidades de medida para especificar largura da coluna, espaçamento e margem esquerda.
