# Amostra Run Word, Excel, and Graph Automation

Arquivo: ...\Samples\Solution\Ffc\Automate.scx

Esta amostra contém as seguintes classes.

| Class | Library | Description |
| --- | --- | --- |
| Cross Tab | _utility.vcx | Generates a cross-tab report. |
| Mail Merge | Mailmerge.vcx | Generates a Word mail merge using the core Mail Merge Wizard engine. |
| Pivot Table | Pivtable.vcx | Generates an Excel pivot table using the core PivotTable Wizard engine. |
| Graph Object | _utility.vcx | Generates a graph using the core Graph Wizard engine. |

Esta amostra demonstra como adicionar rotinas de automação ao seu aplicativo. Escolha os botões na caixa de diálogo para gerar um resumo de tabela cruzada, uma tabela dinâmica do Excel, um documento de mesclagem de correspondência do Word e um gráfico de dados.

Para obter detalhes sobre todas as classes disponíveis nas classes de fundação, consulte Visual FoxPro Foundation Classes A-Z.
