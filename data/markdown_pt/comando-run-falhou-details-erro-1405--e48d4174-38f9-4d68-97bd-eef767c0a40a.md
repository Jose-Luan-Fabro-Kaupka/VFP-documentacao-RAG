# Comando RUN|! falhou. "Details" (Erro 1405)

A mensagem do sistema operacional que acompanha esta mensagem do Visual FoxPro indica por que não é possível criar um processo para executar um comando RUN.

Na maioria das vezes, este erro ocorre devido à incapacidade de encontrar o programa shell a ser executado ou por não haver memória livre suficiente para carregar o programa shell na memória.
