# Estrutura de arquivo de índice composto (.cdx)

Todos os índices compostos são índices compactos.

Existe uma estrutura de arquivo para rastrear todas as tags no arquivo .cdx. Essa estrutura é idêntica à Estrutura de arquivo de índice compacto (.idx), com uma exceção — os nós folha no nível mais baixo dessa estrutura apontam para uma das tags no índice composto.

Todas as tags no índice possuem sua própria estrutura completa, idêntica à estrutura de índice compacto de um arquivo .idx.
