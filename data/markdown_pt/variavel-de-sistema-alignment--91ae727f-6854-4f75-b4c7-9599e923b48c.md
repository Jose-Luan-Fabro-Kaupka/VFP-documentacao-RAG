# Variável de sistema _ALIGNMENT

Incluída para compatibilidade com versões anteriores. Use o Report Designer em vez disso.

Alinha texto entre as margens.

```foxpro
_ALIGNMENT = expC
```

#### Parâmetros
 expC deve ser avaliado como um dos seguintes:

 LEFT Produz saída alinhada à esquerda (padrão).

 CENTER Produz saída centralizada.

 RIGHT Produz saída alinhada à direita.

_ALIGNMENT está ativo somente quando _WRAP está definido como verdadeiro (.T.).

# Observações

_ALIGNMENT está incluída para compatibilidade com versões anteriores. Use o Report Writer em vez disso.

_ALIGNMENT contém um valor de caracteres que determina como a saída é alinhada entre as margens atuais.
