# Caixa de diálogo Obter versão mais recente de arquivos

Obtém os arquivos selecionados do provedor de controle de código-fonte e coloca uma cópia local no Project Manager.
 **Arquivo(s) para obter versão mais recente**
Lista os arquivos disponíveis no projeto de controle de código-fonte.
**Selecionar tudo**
Seleciona todos os arquivos disponíveis.
**Avançado**
Exibe a caixa de diálogo Advanced Get Options do provedor de controle de código-fonte.
