# Usando controles

Os usuários interagem com aplicações principalmente usando controles em formulários. Por exemplo, ao clicar, digitar e navegar em controles em formulários em sua aplicação, os usuários podem manipular dados e realizar as tarefas que precisam executar. O Visual FoxPro fornece uma variedade de controles que você pode incluir em formulários para ajudar os usuários a realizar tarefas. A lista a seguir descreve as principais categorias de tarefas de aplicação que você pode executar usando controles:
 - Fornecer aos usuários um conjunto de escolhas predeterminadas.
- Aceitar entrada do usuário que não pode ser predeterminada.
- Aceitar entrada do usuário em um intervalo determinado.
- Permitir que os usuários executem ações específicas.
- Executar ações específicas em intervalos determinados.
- Exibir informações.

Por exemplo, você pode garantir que apenas dados válidos sejam armazenados em um banco de dados fornecendo aos usuários um conjunto especificado de opções ou valores. Para fornecer essas escolhas predeterminadas, você pode usar os seguintes controles:
 - Option buttons ou option button groups.
- List boxes e drop-down list boxes.
- Check boxes.

Embora você possa usar uma variedade de controles para executar qualquer tarefa específica, deve selecionar e usar controles de forma consistente para que os usuários possam facilmente entender ou saber o que esperar quando interagem com a interface da sua aplicação. Por exemplo, um label pode conter o mesmo evento Click que um command button; no entanto, usuários familiarizados com interfaces gráficas esperam clicar em command buttons, não em labels, para executar ações.
