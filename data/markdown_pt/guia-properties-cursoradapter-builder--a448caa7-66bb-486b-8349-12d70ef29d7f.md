# Guia Properties, CursorAdapter Builder

Exibe o nome e as propriedades da classe CursorAdapter e especifica se deve usar a fonte de dados do Data Environment e usar configurações de conexão somente no builder.
 **Class**
Exibe o nome da classe na qual o objeto CursorAdapter se baseia. A classe pode ser a classe base, o objeto CursorAdapter ou uma classe em uma biblioteca de classes ou arquivo de programa, caso em que o nome e o caminho do arquivo também são exibidos.
**Name**
Especifica o nome atribuído ao objeto CursorAdapter pelo builder. Você pode alterar este nome.
**Alias**
Especifica o alias atribuído ao objeto CursorAdapter pelo builder. O nome padrão é o mesmo que aparece na caixa Name. Você pode alterar este nome. Observação Certifique-se de que o alias seja exclusivo em tempo de execução. O método CursorFill do CursorAdapter falha se uma tabela ou cursor usando o mesmo nome de alias já estiver aberto. Para obter mais informações, consulte CursorFill Method .
**Use DataEnvironment data source**
Especifica se você deseja usar a fonte de dados do objeto DataEnvironment. Quando a propriedade CursorAdapterDataSourceType é "ADO", você não deve selecionar esta caixa de seleção, a menos que o objeto DataEnvironment contenha somente um CursorAdapter que use esta fonte de dados.
**Use connection settings in builder only**
Especifica se você deseja usar configurações de conexão somente no builder. Se você selecionar esta opção, precisará adicionar código para configurar um ambiente de conexão personalizado em tempo de execução. Selecionar esta opção torna possível ter uma conexão aberta em tempo de design para que você possa selecionar tabelas, criar consultas e assim por diante.
**Data source type**
Especifica um tipo de fonte de dados. Dependendo do tipo de fonte de dados selecionado, você pode selecionar ou criar uma das seguintes fontes de dados: ADO Especifica uma das seguintes maneiras de estabelecer uma conexão ActiveX Data Objects (ADO). Use existing ADO Recordset Especifica uma referência a um objeto ADO RecordSet válido. Esta referência deve ser válida em tempo de design se o CursorAdapter Builder for usar este RecordSet. Use DSN Especifica um nome de fonte de dados (DSN) na lista Data source e valores nas caixas User ID e Password, se aplicável. Na maioria dos casos, selecionar um DSN para uma conexão ADO resulta no uso do driver Open Database Connectivity (ODBC) especificado pelo DSN por meio do MSDASQL OLE DB Provider for ODBC. Certos provedores OLE DB podem mapear as configurações ODBC DSN para as configurações correspondentes no provedor OLE DB correspondente. Observação Você não deve usar um nome DSN se o provedor OLE DB não puder mapear configurações ODBC DSN. Você pode usar um driver ODBC para uma fonte de dados que não tenha um provedor OLE DB. Use connection string Especifica uma cadeia de conexão válida. Este é o mesmo tipo de cadeia de conexão que você insere para a propriedade ADO ConnectionString. Como alternativa, você pode exibir a caixa de diálogo Data Link Properties clicando em Build. Você pode então selecionar o OLE DB Provider apropriado e outros parâmetros necessários da cadeia de conexão. Native Especifica um nome e caminho de banco de dados válidos na caixa Database. Você pode selecionar um banco de dados a ser usado clicando no botão de reticências (...) para exibir a caixa de diálogo Select Database. ODBC Especifica uma das seguintes maneiras de estabelecer uma conexão de banco de dados. Use existing connection handle Especifica uma propriedade, variável de memória, valor ou expressão que avalia para um identificador de conexão válido em tempo de execução. Use DSN Especifica um nome de fonte de dados (DSN) na lista Data source e valores nas caixas User ID e Password, se aplicável. Use connection string Especifica uma cadeia de conexão válida. Este é o mesmo tipo de cadeia de conexão que você insere para a função SQLSTRINGCONNECT( ). Para obter mais informações, consulte SQLSTRINGCONNECT( ) Function . XML Especifica XML como a fonte de dados.
