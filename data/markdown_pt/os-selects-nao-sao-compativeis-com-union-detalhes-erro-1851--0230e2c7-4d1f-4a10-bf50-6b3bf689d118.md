# Os SELECTs não são compatíveis com UNION. "Detalhes" (Erro 1851)

Isso ocorreu por um destes motivos:
 - O número de campos não corresponde. Verifique se os números são iguais.
- Os campos especificados não são compatíveis. Verifique sua compatibilidade.
- Os tipos de dados ou tamanhos dos campos projetados em cada instrução SELECT não são idênticos.
