# Guia Protection, caixa de diálogo Report Properties (Report Builder)

Permite restringir atividades selecionadas no Report ou Label Designer ao modificar o layout no modo protegido. Para obter mais informações, consulte Setting Protection for Reports.
 - Como: proteger layouts de relatório

# No modo PROTECTED

Especifica as configurações de proteção que você pode configurar para o relatório ou etiqueta.
 **Report can not be run or printed**
Especifica que o usuário não pode imprimir o layout de relatório ou etiqueta ao modificar o layout de relatório ou etiqueta no modo protegido. Desabilita a opção Print… no menu File e as opções Run Report nos menus Report e no menu de contexto do designer.
**Report can not be previewed**
Especifica que o usuário não pode visualizar a impressão do layout de relatório ou etiqueta ao modificar o layout de relatório ou etiqueta no modo protegido. Desabilita a opção Print Preview nos menus File, Report e no menu de contexto do designer, e a opção Preview no menu View.
**Data Environment can not be modified**
Especifica que o usuário não pode modificar o data environment do layout de relatório ao modificar o relatório ou etiqueta no modo protegido. Desabilita a opção Data Environment… nos menus View e no menu de contexto do designer; oculta a guia Data Environment na caixa de diálogo Report Properties do Report Builder; e desabilita a opção Load Data Environment… no menu Report.
**Page Layout is not available**
Especifica que o usuário não pode alterar a configuração da impressora ou o tamanho da página, margens, etc., do layout ao modificar o layout de relatório ou etiqueta no modo protegido. Desabilita a opção Page Setup no menu File e oculta a guia Page Layout na caixa de diálogo Report Properties do Report Builder.
**Optional Bands can not be changed**
Especifica que o usuário não pode alterar o número de bandas de detalhe, banda de título ou resumo e outras configurações de layout ao modificar o layout de relatório ou etiqueta no modo protegido. Desabilita a opção Optional Bands no menu Report e oculta a guia Optional Bands da caixa de diálogo Report Properties do Report Builder.
**Data Grouping can not be modified**
Especifica que o usuário não pode alterar as configurações de agrupamento de dados do layout ao modificar o layout de relatório ou etiqueta no modo protegido. Desabilita a opção Data Grouping no menu Report e oculta a guia Data Grouping da caixa de diálogo Report Properties do Report Builder.
**Report Variables can not be edited**
Especifica que o usuário não pode visualizar ou modificar variáveis de relatório ao modificar o layout de relatório ou etiqueta no modo protegido. Desabilita a opção Variables no menu Report e oculta a guia Variables da caixa de diálogo Report Properties do Report Builder.
