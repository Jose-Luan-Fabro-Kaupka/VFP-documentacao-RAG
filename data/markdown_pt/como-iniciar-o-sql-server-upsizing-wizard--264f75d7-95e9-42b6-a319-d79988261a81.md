# Como: iniciar o SQL Server Upsizing Wizard

Depois de criar uma fonte de dados ODBC e concluir a preparação necessária no cliente e no servidor, você estará pronto para iniciar o upsizing.

### Para iniciar o SQL Server Upsizing Wizard
- No menu Tools, escolha Wizards e Upsizing.
- Na caixa Wizard Selection, escolha SQL Server Upsizing Wizard.
- Siga as instruções das telas. Você pode escolher Cancel a qualquer momento; nenhuma ação será executada no servidor até escolher Finish.
- Quando estiver pronto, escolha Finish.

O assistente começará a exportar o banco de dados para o servidor. O botão Finish fica disponível após o fornecimento das informações básicas; se usado antes de todas as telas serem concluídas, serão adotados valores padrão para as restantes.
