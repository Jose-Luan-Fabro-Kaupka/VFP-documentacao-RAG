# Evento Deleted

Ocorre quando o usuário marca um registro para exclusão ou desmarca um registro marcado para exclusão.

```foxpro
PROCEDURE Grid.Deleted
LPARAMETERS nRecNo
```

#### Parâmetros
 **nRecNo**
Retorna o número do registro da linha sendo excluída.

# Observações

Aplica-se a: Controle Grid
