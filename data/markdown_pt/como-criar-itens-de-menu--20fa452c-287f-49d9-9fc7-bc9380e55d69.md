# Como: Criar itens de menu

Depois de criar menus, você pode colocar itens de menu nos menus. Os itens de menu podem representar comandos ou procedimentos do Visual FoxPro que você deseja que o usuário execute, ou os itens de menu podem conter submenus que oferecem itens de menu adicionais.

### Para adicionar itens de menu a um menu
- Na coluna Prompt, selecione o título do menu ao qual deseja adicionar itens de menu.
- Na caixa Resultado, selecione Submenu. A O botão Criar aparece à direita da lista.
- Escolha o botão Criar. Uma janela de design vazia é exibida. Nesta janela, você insere os itens do menu.
- Na coluna Prompt, digite os nomes dos novos itens de menu.
