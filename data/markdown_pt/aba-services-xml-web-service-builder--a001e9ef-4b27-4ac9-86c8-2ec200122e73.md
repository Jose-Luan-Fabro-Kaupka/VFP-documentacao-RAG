# Aba Services, XML Web Service Builder

Especifica o XML Web service a usar em seu aplicativo. Você também pode visualizar as operações, ou chamadas de método, disponíveis para o XML Web service.
 **Select an XML Web service**
Especifica o XML Web service que você deseja vincular a controles ou objetos no formulário e exibe outros XML Web services disponíveis na Toolbox.
**Refresh**
Atualiza o XML Web service selecionado para que possa ser registrado corretamente em seu computador. Esta opção está disponível apenas quando todos os XML Web services registrados estão listados.
**Add a new XML Web service**
Permite que você registre e adicione um novo XML Web service. Esta opção está disponível apenas quando todos os XML Web services registrados estão listados.
**Change XML Web service**
Lista todos os XML Web services registrados. Esta opção aparece se um XML Web service estiver selecionado ao abrir o builder. Observação Alterar o XML Web service remove todas as configurações da aba Operations para esse XML Web service.
**View operations**
Exibe as operações, ou chamadas de método, disponíveis para o XML Web service selecionado. Observação A operação selecionada aparece na caixa View operations apenas para fins informativos. Você pode definir vinculações para a operação na aba Operations. Para obter mais informações, consulte Aba Operations, XML Web Service Builder .
**View service description (WSDL)**
Exibe a descrição WSDL para o XML Web service.
