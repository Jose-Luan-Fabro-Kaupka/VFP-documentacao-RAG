# Planejando aplicativos cliente/servidor

O Microsoft® Visual FoxPro® fornece as ferramentas para criar aplicativos cliente/servidor poderosos. Um aplicativo cliente/servidor do Visual FoxPro combina o poder, a velocidade, a interface gráfica do usuário e a consulta, relatório e processamento sofisticados do Visual FoxPro com o acesso multiusuário contínuo, o armazenamento massivo de dados, a segurança integrada, o processamento robusto de transações, o registro em log e a sintaxe nativa do servidor de uma fonte de dados ODBC ou servidor. A sinergia das forças do Visual FoxPro e do servidor fornece uma solução cliente/servidor poderosa para seus usuários.

A etapa mais importante na construção de um aplicativo cliente/servidor bem-sucedido é criar um bom design. Ao projetar um aplicativo cliente/servidor, você equilibra vários conjuntos de requisitos. Você deseja construir o aplicativo mais rápido e produtivo para seus usuários. Você também deseja garantir a integridade dos dados do aplicativo, aproveitar ao máximo os investimentos em hardware existentes e incorporar escalabilidade para o futuro. Além disso, como desenvolvedor Visual FoxPro, você deseja tornar o processo de desenvolvimento o mais simplificado e econômico possível.
