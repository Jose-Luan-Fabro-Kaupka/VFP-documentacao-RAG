# Tabela relacionada não foi encontrada no banco de dados atual (Erro 1880)

Um objeto de relação de banco de dados está sendo criado ou referenciado para o qual a tabela relacionada não pôde ser encontrada.
 - Você usou a cláusula REFERENCES do comando CREATE TABLE ou ALTER TABLE. Certifique-se de que ambas as tabelas envolvidas na relação estão no banco de dados.
