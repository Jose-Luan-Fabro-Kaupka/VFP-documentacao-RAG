# Classe de fundação Get File and Directory

Esta caixa de diálogo recupera um nome de arquivo e de pasta. É usada para criar novos projetos em diretórios com o mesmo nome.

| Categoria | Interface do usuário |
| --- | --- |
| Catálogo padrão | Visual FoxPro Catalog\Foundation Classes\User Controls |
| Classe | _folder |
| Classe base | Container |
| Biblioteca de classes | _controls.vcx |
| Classe pai | _container |
| Exemplo | ...\Samples\Solution\Ffc\getproject.scx |

# Observações

Para usar, solte a classe em um projeto ou formulário. Quando você solta a classe em um projeto, pode escolher entre adicionar a classe ou criar uma subclasse. Quando você solta a classe em um formulário, o Visual FoxPro posiciona os controles da classe, incluindo um botão Browse, no seu formulário.

| Propriedades, eventos, métodos | Descrição |
| --- | --- |
| Propriedade cLastProjectFile | Interna à classe. |
| Propriedade cExt | Interna à classe. |
| Propriedade TrimFile | Interna à classe. |
