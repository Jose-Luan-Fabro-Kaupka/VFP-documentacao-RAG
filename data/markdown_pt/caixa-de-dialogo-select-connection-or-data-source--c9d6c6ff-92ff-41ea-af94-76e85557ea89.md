# Caixa de diálogo Select Connection or Data Source

Permite selecionar uma fonte de dados ou uma conexão existente a uma fonte de dados para criar uma nova view remota. Você também pode acessar o Connection Designer para criar uma nova conexão.

Aparece quando você seleciona Remote View na caixa de diálogo New e, em seguida, escolhe New File.
 **Connections in Database/Available Data Sources**
Lista fontes de dados ODBC disponíveis ou conexões existentes, dependendo da opção selecionada no grupo de opções Select. Selecione a fonte de dados ou conexão desejada e escolha OK.

# Select
 **Connections**
Exibe conexões existentes para você escolher no banco de dados ativo.
**Available Data Sources**
Exibe as fontes de dados ODBC disponíveis para criar uma view remota.
**New**
Exibe o Connection Designer, no qual você pode criar e salvar uma conexão a uma fonte de dados.
