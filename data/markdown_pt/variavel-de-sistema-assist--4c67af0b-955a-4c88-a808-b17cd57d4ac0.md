# Variável de sistema _ASSIST

Incluída para compatibilidade com versões anteriores. Use o comando DO em vez disso.

Especifica o programa que é executado quando o comando ASSIST é emitido.

```foxpro
_ASSIST = expC
```

#### Parâmetros
 expC

Especifica o programa a executar.

# Observações

Use _ASSIST para especificar um programa a executar quando o comando ASSIST é emitido. _ASSIST contém CATALOG.APP, o aplicativo Catalog Manager, por padrão.
