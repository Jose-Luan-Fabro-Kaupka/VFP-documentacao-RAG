# Não foi possível criar arquivos de trabalho temporários (Erro 1410)

Um comando SORT Command ou INDEX Command que requer arquivos de trabalho temporários não recebeu permissão do sistema operacional para criá-los.
 - Seu diretório está cheio. Remova alguns arquivos.
- O Visual FoxPro não tem permissão para acessar o diretório de arquivos temporários. Verifique suas permissões.
