# Método DelayedMemoFetch

Executa uma busca atrasada de campo Memo para um registro de destino em um cursor em um objeto CursorAdapter.

```foxpro
CursorAdapter.DelayedMemoFetch(cMemoName)
```

#### Parâmetros
 **cMemoName**
Especifica o nome do campo Memo a ser buscado no registro atual do cursor associado ao objeto CursorAdapter.

# Observações

Aplica-se a: CursorAdapter Class

Quando a propriedade FetchMemo Property é definida como False (.F.), a capacidade de executar uma busca atrasada de Memo é habilitada. Uma busca atrasada de Memo impede que o conteúdo de campos Memo seja atualizado durante chamadas aos métodos CursorFill Method e CursorRefresh Method. Uma tentativa de buscar conteúdo para um campo Memo é feita quando o aplicativo tenta acessar o valor desse campo. Os quatro membros CursorAdapter a seguir permitem usar busca atrasada de Memo.
 - DelayedMemoFetch Method
- FetchMemoDataSourceType Property
- FetchMemoDataSource Property
- FetchMemoCmdList Property

O método DelayedMemoFetch executa uma busca atrasada de memo para o campo Memo cMemoName no registro atual. Este método retornará o conteúdo do campo Memo especificado. Um erro é gerado se os dados não puderem ser recuperados.

> **Observação:** Para que a busca atrasada de Memo funcione com um CursorAdapter, o cursor associado deve ser aberto em modo exclusivo.

> **Observação:** O método DelayedMemoFetch nunca deve ser chamado para outra finalidade que não seja executar uma busca atrasada de Memo. Em nenhuma circunstância este método deve alterar o registro atual.

Para permitir acesso aos dados no registro de destino, o Visual FoxPro abre um cursor somente leitura com o registro de destino como registro atual. Este cursor somente leitura é aberto exclusivamente, e seu alias está contido na propriedade RefreshAlias Property. Se a propriedade RefreshAlias estiver vazia, o método DelayedMemoFetch não foi invocado pelo mecanismo de dados do Visual FoxPro.

Você pode retornar o conteúdo de um campo General usando DelayedMemoFetch. Para fazer isso, você precisa converter o conteúdo do campo em um Blob usando a função CAST( ) Function.

O exemplo a seguir mostra o uso de DelayedMemoFetch para recuperar dados de campos Memo e General da tabela Northwind Categories via Visual FoxPro OLE DB Provider.

```foxpro
CLOSE DATABASES all
CLEAR
LOCAL oCA as CursorAdapter
LOCAL oConn AS ADODB.Connection
LOCAL oRS AS ADODB.Recordset
LOCAL cConnStr,lcNorthwindFile
lcNorthwindFile = HOME()+"Samples\Northwind\northwind.dbc"
cConnStr = [Provider=VFPOLEDB.1;Data Source=&lcNorthwindFile.;Password="";Collating Sequence=MACHINE]
oConn  = createobject('ADODB.Connection')
oConn.Open(cConnStr)
oRS = CREATEOBJECT("ADODB.Recordset")
oRS.ActiveConnection = oConn
oRS.CursorLocation = 3  && adUseClient
oRS.CursorType = 3&& adOpenStatic
oRS.LockType = 3&& adLockOptimistic
oCA=CREATEOBJECT("CADelayedFetch")
oCA.DataSource=oRS
IF !oCA.CursorFill()
AERROR(aerrs)
DISPLAY MEMORY LIKE aerrs
RETURN
ENDIF
GO TOP
BROWSE
DEFINE CLASS CADelayedFetch AS CursorAdapter
FetchMemo=.F.
DataSourceType="ADO"
SelectCmd="SELECT * from categories"
CursorSchema="categoryid i, categoryname c(15), description m, picture g"
UseCursorSchema=.T.
FUNCTION DelayedMemoFetch(cFieldName)
NODEFAULT
IF UPPER(cFieldName)==UPPER("picture")
RETURN CAST(DODEFAULT(cFieldName) as W)
ENDIF
RETURN [Modified value:] + DODEFAULT(cFieldName)
ENDFUNC
ENDDEFINE
```
