# Caixa de diálogo Define Window Layout

Permite nomear e salvar configurações de janela e barra de ferramentas para reutilização.
 **View Name**
Especifica o nome do layout de janela atual.
**View**
Lista os layouts de janela disponíveis.
**Apply**
Configura as janelas atuais para o layout de janela selecionado.
**Add**
Adiciona o layout atualmente nomeado à lista de layouts de janela disponíveis.
**Delete**
Exclui o layout atualmente selecionado da lista de layouts de janela disponíveis.
**Rename**
Permite alterar o nome do layout de janela atual.
