# Comando RECALL

Desmarca registros marcados para exclusão na tabela selecionada.

```foxpro
RECALL [Scope] [FOR lExpression1] [WHILE lExpression2] [NOOPTIMIZE]
   [IN nWorkArea | cTableAlias]
```

#### Parâmetros
 **Scope**
Especifica um intervalo de registros a serem recuperados. O escopo padrão para RECALL é o registro atual (NEXT 1). Somente os registros que estão dentro do intervalo especificado são recuperados. As cláusulas de escopo são: ALL, NEXT nRecords, RECORD nRecordNumber e REST. Para obter mais informações sobre cláusulas de escopo, consulte Scope Clauses.
**FOR lExpression1**
Especifica que somente os registros para os quais lExpression1 é avaliada como verdadeira (.T.) são recuperados. Esta opção permite filtrar registros indesejados. Rushmore Query Optimization otimiza um RECALL FOR se lExpression1 for uma expressão otimizável. Para melhor desempenho, use uma expressão otimizável na cláusula FOR. Para obter mais informações, consulte SET OPTIMIZE Command e Using Rushmore Query Optimization to Speed Data Access.
**WHILE lExpression2**
Especifica uma condição pela qual os registros são recuperados enquanto lExpression2 for avaliada como verdadeira (.T.).
**NOOPTIMIZE**
Impede a otimização Rushmore de RECALL. Para obter mais informações, consulte SET OPTIMIZE Command e Using Rushmore Query Optimization to Speed Data Access.
**IN nWorkArea | cTableAlias**
Especifica a área de trabalho ou o alias da tabela afetado pelo comando RECALL. Use esta cláusula para especificar uma área de trabalho ou uma tabela fora da área de trabalho atual.

# Observações

Você pode usar RECALL para recuperar registros, desde que não tenha emitido PACK ou ZAP.

> **Cuidado:** Depois que um arquivo foi compactado, todos os registros marcados para exclusão desaparecem para sempre.

Você pode marcar registros para exclusão emitindo DELETE ou DELETE – SQL, ou escolhendo Delete Records no menu Table quando uma janela Browse ou Edit está ativa. Você pode recuperar registros emitindo RECALL, ou escolhendo Recall Records no menu Record quando uma janela Browse ou Edit está ativa.

Se você omitir a cláusula IN, o comando RECALL opera na área de trabalho atual.

# Exemplo

O exemplo a seguir abre a tabela `customer` no banco de dados `testdata`. DELETE – SQL é usado para marcar todos os registros para exclusão onde o campo `country` contém USA. Todos os registros marcados para exclusão são exibidos. RECALL ALL é usado para desmarcar todos os registros marcados para exclusão.

```foxpro
CLOSE DATABASES
OPEN DATABASE (HOME(2) + 'data\testdata')
USE customer  && Opens Customer table
DELETE FROM customer WHERE country = 'USA'  && Mark for deletion
CLEAR
LIST FIELDS company, country FOR DELETED() && List marked records
RECALL ALL  && Unmark all records marked for deletion
```
