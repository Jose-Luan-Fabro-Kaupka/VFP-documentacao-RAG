# Função JUSTFNAME( )

Retorna a parte do nome do arquivo de um caminho completo e nome de arquivo.

```foxpro
JUSTFNAME(cFileName)
```

#### Parâmetros
 **cFileName**
Especifica o nome, que pode incluir o caminho completo, do arquivo para o qual você deseja apenas o nome do arquivo. O comprimento máximo da cadeia de caracteres passada para cFileName é de 259 bytes.

# Valor de retorno

Caractere
