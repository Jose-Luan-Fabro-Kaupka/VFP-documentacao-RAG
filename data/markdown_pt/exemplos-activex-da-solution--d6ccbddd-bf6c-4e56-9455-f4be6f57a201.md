# Exemplos ActiveX da Solution

Estes exemplos da Solution ilustram como você pode usar controles ActiveX no Visual FoxPro.

# Nesta seção
 **Exemplo Add and Remove Items in a Treeview Control**
Ilustra como adicionar, excluir e selecionar nós para um controle treeview, que exibe uma coleção de objetos Node. Este exemplo também ilustra como gravar e ler uma hierarquia treeview em e de uma tabela.
**Exemplo Customize the Open Dialog Box**
Ilustra como personalizar a aparência e o comportamento da caixa de diálogo Open.
**Exemplo Display System Information**
Ilustra como usar o SysInfoControl para exibir informações do sistema e notificar quando uma configuração do sistema é alterada.
**Exemplo Play an AVI File in an ActiveX Control**
Ilustra como usar o controle Multimedia para reproduzir um arquivo AVI em um controle que tem a propriedade hWnd.
**Exemplo Provide a Hierarchical Display of Items**
Ilustra como usar dois tipos diferentes de controles ActiveX para exibir uma hierarquia de itens, por exemplo, como um outline.
**Exemplo Send Mail (Visual FoxPro)**
Ilustra como criar um formulário de mensagens simples que pode enviar dados do Visual FoxPro para um endereço de e-mail.
**Exemplo Use Slider and Status Bar Controls**
Ilustra como usar o controle Slider e o controle StatusBar.
**Exemplo Use the RichText Control**
Ilustra como usar um controle RichText para exibir e editar texto RTF no campo memo de uma tabela.
