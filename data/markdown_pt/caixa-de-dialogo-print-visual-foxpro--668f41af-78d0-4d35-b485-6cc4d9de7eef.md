# Caixa de diálogo Print (Visual FoxPro)

Permite que você selecione opções de impressora ao imprimir um arquivo. Esta caixa de diálogo aparece quando você seleciona Print no menu Arquivo.

> **Observação:** As configurações disponíveis dependem do sistema operacional Windows em que você está executando o Visual FoxPro. Para versões do Windows anteriores ao Windows 2000, os nomes de configuração para esta caixa de diálogo são indicados entre parênteses. Configurações disponíveis somente ao executar Windows 2000 e posteriores são indicadas.

# Atalho

CTRL+P

# Guia General (Impressora)

Especifica configurações específicas da impressora.
 **Select Printer (Name)**
Exibe impressoras conectadas ao seu computador.
**Status**
Exibe o status da impressora.
**Location (Where)**
Exibe o caminho da impressora de rede.
**Comment**
Exibe informações adicionais da impressora, por exemplo, localização da impressora.
**Preferences (Properties)**
Abre a caixa de diálogo Printing Preferences ( Document Properties ) do sistema para que você possa definir preferências de página.
**Find Printer**
Abre a caixa de diálogo Find Printers para que você possa localizar uma impressora. Disponível no Windows 2000 ou posterior.

# Page Range (Intervalo de impressão)

Especifica configurações de seleção de página.
 **All**
Imprime todas as páginas do arquivo.
**Selection**
Imprime o texto selecionado no arquivo. Esta opção está disponível somente quando o texto está selecionado. Observação Se uma linha parcial de texto estiver selecionada, a linha inteira é impressa.
**Pages**
Especifica um intervalo de páginas no arquivo a imprimir.
**Number of copies**
Especifica o número de cópias do arquivo a imprimir.
**Collate**
Especifica agrupar as cópias impressas ao imprimir várias cópias do arquivo.
**Options**
Exibe a caixa de diálogo Print Options. Para obter mais informações, consulte Print Options Dialog Box .
**Print (OK)**
Imprime o arquivo.
