# Personalizando o Gerenciador de Lista de Tarefas

Você pode personalizar a visão de seu Gerenciador de Lista de Tarefas de várias maneiras:
- Ordenar tarefas Você pode ordenar a lista de tarefas clicando no cabeçalho da coluna do campo pelo qual deseja ordenar. Clicar numa coluna comuta repetidamente esse campo entre ordem ascendente/ descendente.
- Tipos de tarefas de filtragem Você pode filtrar os tipos de tarefas que deseja exibir na Lista de Tarefas selecionando tipos específicos de tarefas no submenu Mostrar Tarefas do menu de contexto Lista de Tarefas. O submenu contém opções para exibir atalhos, definidos pelo usuário e outras Tarefas.
- Escolha campos para visualização Você pode escolher quais campos você deseja ver na Lista de Tarefas selecionando o item do menu Seletor de Colunas no menu de contexto Lista de Tarefas. Aparece uma caixa de diálogo do seletor de colunas para que você possa adicionar novos campos usando o arrastar- e- soltar diretamente na Lista de Tarefas. Para remover um campo, clique com o botão direito do mouse no cabeçalho da coluna e selecione o item de menu Remover esta coluna.
- Adding custom fields You can add custom fields to your Task List. Custom fields are stored in a separate table from your main _FOXTASK (Foxtask.dbf) table. This custom fields table must have a UniqueID field, so it can be linked to the field in the Foxtask table. You can edit Custom fields from the Fields tab of the Task Properties dialog box. You can add a new or existing custom fields table in the Options dialog box. Access the Options dialog box from the Options menu item of the Task List context menu item. All custom fields appear in the Columns Chooser dialog box, so you can add them to or remove them from the Task List.
