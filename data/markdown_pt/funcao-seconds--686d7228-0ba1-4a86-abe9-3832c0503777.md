# Função SECONDS( )

Retorna o número de segundos que se passaram desde a meia-noite.

```foxpro
SECONDS()
```

# Valor de retorno

Numeric. SECONDS( ) retorna um valor numérico em formato decimal com resolução de 1 milissegundo. Para versões do Visual FoxPro executadas no Windows NT 4.0 ou posterior, SECONDS( ) retorna uma resolução de 10 milissegundos.

# Exemplo

```foxpro
CLEAR
? SECONDS()
? SECONDS()/(60 * 60)
```
