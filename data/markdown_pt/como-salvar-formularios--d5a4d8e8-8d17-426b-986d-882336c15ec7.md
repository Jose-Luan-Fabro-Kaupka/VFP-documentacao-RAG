# Como: salvar formulários

Você precisa salvar seu formulário antes de executá-lo. Se tentar fechar o Form Designer quando o formulário não foi salvo, o Visual FoxPro solicita que você salve ou descarte as alterações feitas.

### Para salvar um formulário
- No Form Designer, escolha Save no menu File. Os formulários são salvos como arquivos com extensão .scx.

# Salvando formulários e controles como classes

Você também pode salvar um formulário, ou um subconjunto dos controles em um formulário, como uma definição de classe. Se pretende criar subclasses baseadas no formulário ou reutilizar os controles em outros formulários, salve o formulário como uma definição de classe.

### Para salvar um formulário ou controles selecionados como definição de classe
- No menu File, escolha Save As Class.
- Na caixa de diálogo Save As Class, escolha Current form ou Selected controls.
- Na caixa Name, digite um nome para a classe.
- Na caixa File, digite um nome de arquivo para o qual a classe será armazenada.
- Escolha OK.

Se você não fornecer uma extensão ao nome do arquivo, a extensão padrão .vcx é adicionada quando o arquivo é salvo. Depois que um formulário foi salvo como definição de classe, você pode modificá-lo com o comando MODIFY CLASS. Para obter mais informações sobre criação de classes, consulte Object-Oriented Programming.
