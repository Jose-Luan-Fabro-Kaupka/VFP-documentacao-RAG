# Função QUARTER( )

Retorna o trimestre do ano em que uma expressão de data ou datetime ocorre.

```foxpro
QUARTER(dExpression | tExpression [, nMonth])
```

#### Parâmetros
 **dExpression**
Especifica a expressão Date para a qual você deseja que QUARTER( ) retorne um valor.
**tExpression**
Especifica a expressão DateTime para a qual você deseja que QUARTER( ) retorne um valor.
**nMonth**
Especifica um mês inicial opcional para o trimestre examinado. Você pode usar isso para especificar trimestres baseados em um ano fiscal em vez de um ano calendário.

# Valor de retorno

Tipo de dados numérico. QUARTER( ) retorna o trimestre do ano em que uma data ocorre, e os valores podem ser 0, 1, 2, 3 ou 4.

> **Observação:** QUARTER( ) retorna 0 se receber um valor Date ou DateTime vazio, por exemplo, QUARTER({//}) .
