# Evento BeforeOpenTables

Ocorre imediatamente antes de as tabelas e views associadas ao data environment de um form set, formulário ou relatório serem abertas.

```foxpro
PROCEDURE DataEnvironment.BeforeOpenTables
```

# Observações

Aplica-se a: DataEnvironment Object

O evento BeforeOpenTables ocorre antes do evento Load de um form set ou formulário.
