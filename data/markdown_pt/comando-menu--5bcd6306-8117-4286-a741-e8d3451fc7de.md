# Comando @ ... MENU

Incluído para compatibilidade com versões anteriores. Use os Designers de Menu e Atalho e o comando CREATE MENU em vez disso.

Cria um menu popup.

```foxpro
@ row, column MENU array,
expN1 [, expN2]
	[TITLE expC]
	[SHADOW]
```

#### Parâmetros
 row, column
 row, column são expressões numéricas que especificam onde o canto superior esquerdo do menu popup é colocado na janela principal do FoxPro ou em uma janela definida pelo usuário.

 array
 array é uma matriz unidimensional contendo as opções que aparecem no menu popup. As opções de menu devem ser do tipo caractere.

 expN1

 A expressão numérica expN1 é o número total de opções de menu disponíveis no menu popup. Se a matriz tem 10 elementos e o valor de expN1 é 5, os primeiros cinco elementos da matriz estão disponíveis no menu popup.

 expN2

 A expressão numérica expN2 é o número de opções de menu exibidas no menu popup. Se expN1 é maior que expN2, expN2 determina quantas opções são exibidas no popup. Se houver opções demais para caber no menu popup, você pode percorrer-las usando o teclado ou o mouse.

TITLE expC

 A expressão de caractere expC é o título exibido na borda superior do menu popup.

SHADOW

 Atrás de um menu popup definido com SHADOW há uma área escurecida que se assemelha a uma sombra. Texto ou objetos cobertos pela sombra ainda estão visíveis. Por padrão, menus popup não têm sombras.

# Observações

@ ... MENU está incluído para compatibilidade com versões anteriores. Use o Menu Builder para criar menus e menus popup.

Este comando cria um menu popup. Um menu popup é uma caixa com borda que contém uma lista de opções das quais você pode escolher. Menus popup são ativados quando READ MENU é emitido. Apenas um menu popup pode estar ativo por vez.

DEFINE POPUP e ACTIVATE POPUP são outro par de comandos que criam e ativam menus popup. DEFINE POPUP e ACTIVATE POPUP operam independentemente de @ ... MENU e READ MENU.

# Exemplo

```foxpro
SET TALK OFF
CLEAR
DIMENSION choices(3)
STORE 'Chicken' TO choices(1)
STORE 'Beef' TO choices(2)
STORE 'Fish' TO choices(3)
STORE 0 TO mchoice
@ 5,0 MENU choices,3 TITLE 'Dinner Choices'
READ MENU TO mchoice
DO CASE
	CASE mchoice = 1
		@ 10,0 SAY 'You will be having chicken for dinner.'
	CASE mchoice = 2
		@ 10,0 SAY 'You will be having beef for dinner.'
	CASE mchoice = 3
		@ 10,0 SAY 'You will be having fish for dinner.'
ENDCASE
```
