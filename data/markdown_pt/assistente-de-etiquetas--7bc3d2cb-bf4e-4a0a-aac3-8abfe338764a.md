# Assistente de etiquetas

Você pode criar etiquetas para colar em envelopes e pacotes ou para uso personalizado usando o Assistente de etiquetas. No assistente, as etiquetas são geradas a partir das entradas em uma tabela. Para obter informações sobre como iniciar o Assistente de etiquetas, consulte Como: criar etiquetas.

# Etapa 1 – Selecionar tabelas

Nesta etapa, você seleciona uma tabela ou exibição como origem das suas etiquetas. Se você usar uma tabela, obterá todos os campos da tabela para usar na etiqueta. Escolher uma exibição pode permitir que você pré-selecione determinados registros ou determinados campos em cada registro de uma tabela.

# Etapa 2 - Escolher tipo de etiqueta

Nesta etapa, você pode escolher uma etiqueta padrão ou personalizada por nome, tamanho e colunas disponíveis.

O assistente lista os tipos de etiqueta padrão instalados com o Visual FoxPro. O assistente também lista todos os tipos de etiqueta que você criar usando o aplicativo AddLabel na pasta \Tools.

Você também pode iniciar o assistente Add Label clicando no botão New Label. Para obter informações, consulte Como: adicionar uma definição de etiqueta usando Addlabel.app.

# Etapa 3 – Definir layout

Nesta etapa, você seleciona os campos que deseja usar na etiqueta e especifica o layout, a fonte e qualquer texto de comentário que deseja que apareça na etiqueta.

Adicione os campos na ordem em que deseja que apareçam na etiqueta. Você pode usar os botões de pontuação (vírgula, ponto, dois-pontos e hífen), nova linha e Space para formatar a etiqueta. Use a caixa de texto Text para adicionar texto. Você também pode usar o botão Font para alterar a fonte usada nas etiquetas.

À medida que você adiciona itens à etiqueta, a imagem na janela do assistente é atualizada para mostrar aproximadamente como sua etiqueta ficará. Verifique essa imagem para ver se os campos escolhidos caberão na etiqueta. As linhas de texto se estenderão além da borda inferior da etiqueta se houver linhas em excesso.

# Etapa 4 – Classificar registros

Nesta etapa, você pode especificar a ordem de classificação das suas etiquetas. Por exemplo, se são etiquetas de correspondência, você pode classificar por cidade, estado ou CEP. No entanto, se são etiquetas de pasta ou de evento, você pode querer classificar alfabeticamente por nomes.

Selecione os campos ou a tag de índice na ordem em que deseja classificar os registros.

# Etapa 5 - Concluir

Nesta etapa, você escolhe como salvar suas etiquetas. Você pode salvar para uso posterior; pode salvar para modificação no Label designer, o que permite usar uma das etiquetas padrão como base para uma etiqueta personalizada de seu próprio design; ou pode imprimir as etiquetas imediatamente no Visual FoxPro.

Você pode escolher Preview para verificar suas escolhas antes de concluir.
