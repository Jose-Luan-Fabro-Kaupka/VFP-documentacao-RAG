# Caixa de diálogo New Local View

Esta caixa de diálogo permite criar uma view de tabelas locais ou outras views no banco de dados usando o Local View wizard ou o View designer. Views locais podem incluir tabelas no formato nativo Visual FoxPro .dbf, views locais ou remotas existentes, quaisquer tabelas em formato .dbf e outras tabelas armazenadas em servidores locais.

A caixa de diálogo New Local View exibe a opção Local View Wizard somente quando você selecionou Prompt for Wizards na guia Projects da caixa de diálogo Options.
 **View Wizard**
Abre o Local View wizard, que cria uma view local.
**New View**
Abre o View designer para que você possa criar uma view local.
