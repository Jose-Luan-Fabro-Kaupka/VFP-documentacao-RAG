# Construção de expressões

Expressões do Visual FoxPro combinam dados e operadores para criar um valor com um tipo de dados específico. Quando você precisa fornecer um valor com um tipo de dados específico, também pode fornecer uma expressão.

# Nesta seção
 **Creating Character Expressions**
Apresenta expressões de caracteres para fornecer valores de caracteres.
**Creating Visual FoxPro Names**
Apresenta nomes usados por contêineres de dados, comandos e funções no Visual FoxPro.
**Name Expression Creation**
Apresenta expressões de nome como substitutos para valores de variáveis e elementos de matriz Character necessários para comandos e funções.
**Macro Substitution (Visual FoxPro)**
Apresenta o uso de substituição de macro para substituir nomes por variáveis.
**Creating Numeric Expressions**
Apresenta expressões numéricas para fornecer valores numéricos.
**Creating Logical Expressions**
Apresenta expressões lógicas para fornecer valores lógicos.
**Creating Date Expressions**
Apresenta expressões de data para fornecer valores de data.
**Using Commands and Functions**
Apresenta o uso de expressões com comandos e funções do Visual FoxPro.
**Trimming and Concatenating Expressions**
Explica como cortar valores em campos e concatenar expressões em uma única expressão.
**Operating the Expression Builder**
Descreve como criar expressões no Expression Builder quando ele está disponível.
