# See Amostra de opções de design de botão de comando

Arquivo: ...\Samples\Solution\Controls\Buttons\Cmdbtn.scx

Este exemplo ilustra uma variedade de propriedades que podem ser definidas para exibição do botão de comando customize.

| Propriedade | Descrição |
| --- | --- |
| Cancel | O código de evento Click do botão de comando the com Cancelar definido como verdadeiro (.T.) é executado quando um usuário pressiona ESC. |
| Default | O código de evento Click do botão de comando the com Padrão definido como verdadeiro (.T.) é executado quando um usuário pressiona ENTER. |
| Picture | Bitmap exibido se o Estilo for Gráfico. |
