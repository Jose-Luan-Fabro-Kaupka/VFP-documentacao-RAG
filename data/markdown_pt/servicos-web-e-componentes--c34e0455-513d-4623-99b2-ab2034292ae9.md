# Serviços Web e componentes

Para estender um aplicativo básico do Microsoft Visual FoxPro, você pode habilitá-lo para trabalhar com vários usuários, acessar e distribuir serviços Web XML, usar controles Microsoft ActiveX e aplicativos habilitados para automação e adicionar recursos internacionais.

# Nesta seção
 **XML Web Services in Visual FoxPro**
Descreve como acessar e distribuir serviços Web XML com seus aplicativos Visual FoxPro. Serviços Web XML são classes ou objetos disponíveis na Web que você pode usar em seus aplicativos programaticamente como chamadas orientadas a objetos normais.
**Automation and COM Servers**
Descreve como você pode estender a funcionalidade de seus aplicativos Visual FoxPro sem muito tempo extra de codificação usando Automation e COM Servers.
**Interoperability and the Internet**
Explica como usar OLE drag-and-drop para desenvolver aplicativos que possibilitam mover dados entre aplicativos baseados no Microsoft Windows e dentro de um aplicativo Visual FoxPro. Crie documentos para uso na Internet ou use um dos dois run times diferentes do Visual FoxPro para criar componentes COM (servidores Automation) como aplicativos normais ou multithread.
