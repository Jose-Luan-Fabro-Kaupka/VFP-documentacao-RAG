# Chamada inválida emitida durante a execução de uma sequência SQLMORERESULTS( ) (Erro 1475)

Uma chamada de função SQL pass-through (SPT) inválida foi feita enquanto era esperada uma chamada da função SQLMORERESULTS( ) para continuar a sequência de chamadas SPT em andamento.

Chame a função SQLCANCEL( ) para cancelar a sequência SPT ou faça chamadas SPT válidas para concluir a sequência de chamadas.
