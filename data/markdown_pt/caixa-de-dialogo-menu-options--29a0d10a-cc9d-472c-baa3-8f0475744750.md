# Caixa de diálogo Menu Options

Permite especificar código para um menu. Acesse-a escolhendo Menu Options no menu View dos designers de menus e menus de atalho.
 **Name**
Contém o nome do menu. Por padrão, é igual ao texto da coluna Prompt de MenuDesigner.
**Procedure**
Fornece espaço para o código do procedimento do menu ou exibe o código existente. A barra de rolagem é ativada se necessário.
**Edit**
Abre uma janela de edição para criar código. Para ativá-la, clique em OK em MenuOptions.

Para obter mais informações, consulte Projetando menus e barras de ferramentas.
