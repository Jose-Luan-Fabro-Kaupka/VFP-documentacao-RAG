# Guia Members, caixa de diálogo Class Info

Exibe informações sobre membros individuais da classe. A caixa de diálogo que contém esta guia aparece quando você escolhe Class Info no menu Class.

A guia Members consiste em uma caixa de listagem com as seguintes colunas:
 **Class**
Exibe o nome da classe.
**Name**
Exibe o nome da propriedade ou método da classe. Métodos Access e Assign criados para propriedades também aparecem na coluna Name.
**Visibility**
Especifica se o membro da classe é protected, public ou hidden. Se você selecionar Protected na lista suspensa Visibility na caixa de diálogo Edit Property/Method, o acesso e as alterações a propriedades da classe são impedidos de fora da definição da classe ou subclasse.
**No Init**
Especifica se o método Init é executado quando um objeto é adicionado. Quando true (.T.), o método Init não é executado. Esta opção se aplica apenas a subclasses da classe.
**Modify**
Abre a caixa de diálogo Edit Property/Method, onde você pode editar uma propriedade ou método existente.
