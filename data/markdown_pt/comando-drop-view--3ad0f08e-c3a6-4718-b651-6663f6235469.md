# Comando DROP VIEW

Exclui uma exibição SQL do banco de dados atual.

```foxpro
DROP VIEW ViewName
```

# Valor de retorno
 **ViewName**
Especifica o nome da exibição excluída do banco de dados atual.

# Observações

DROP VIEW é idêntico a DELETE VIEW; DROP VIEW é a sintaxe padrão ANSI SQL para excluir uma exibição SQL.

Use CREATE SQL VIEW para criar uma exibição SQL e adicioná-la ao banco de dados atual. Se uma exibição SQL estiver aberta e for excluída, os cursores que contêm os resultados da exibição SQL não são fechados.
