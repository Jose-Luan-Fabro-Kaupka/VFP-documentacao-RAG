# Função MOD( )

Divide uma expressão numérica por outra expressão numérica e retorna o resto.

```foxpro
MOD(nDividend, nDivisor)
```

#### Parâmetros
 **nDividend**
Especifica o dividendo. O número de casas decimais em nDividend determina o número de casas decimais no valor de retorno.
**nDivisor**
Especifica o divisor. Um número positivo é retornado se nDivisor for positivo, e um número negativo é retornado se nDivisor for negativo.

# Valor de retorno

Numérico

# Observações

A função de módulo MOD( ) e o operador % retornam resultados idênticos.

# Exemplo

```foxpro
CLEAR
? MOD(36,10)  && Displays 6
? MOD((4*9), (90/9))  && Displays 6
? MOD(25.250,5.0)  && Displays 0.250
? IIF(MOD(YEAR(DATE()), 4) = 0, 'Summer Olympics this year';
   , 'No Summer Olympics this year')
```
