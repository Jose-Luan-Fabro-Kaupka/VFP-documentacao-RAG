# Criando expressões de data

Componha expressões de data combinando operadores de data com os seguintes elementos do Visual FoxPro:
 - Campos Date ou DateTime.
- Funções que retornam datas ou datas e horas.
- Variáveis e elementos de matriz que contêm datas ou horas.
- Constantes Date e DateTime.

O Visual FoxPro trata uma data inválida como uma data vazia.
