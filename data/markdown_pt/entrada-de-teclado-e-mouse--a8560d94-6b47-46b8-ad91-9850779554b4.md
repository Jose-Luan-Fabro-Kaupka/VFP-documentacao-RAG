# Entrada de teclado e mouse

Estes comandos e funções permitem que você controle a entrada com o teclado ou o mouse.

| Use | Para |
| --- | --- |
| Função AMOUSEOBJ( ) | Criar uma matriz contendo informações sobre a posição do ponteiro do mouse e o objeto sobre o qual o ponteiro do mouse está posicionado. |
| Função CAPSLOCK( ) | Retornar o modo atual da tecla CAPS LOCK ou definir o modo da tecla CAPS LOCK como ligado ou desligado. |
| Função CHRSAW( ) | Determinar se um caractere está presente ou não no buffer do teclado. |
| Comandos CLEAR | Liberar o item ou itens especificados da memória. |
| Comandos CLEAR | Liberar o item ou itens especificados da memória. |
| Função INSMODE( ) | Retornar o modo de inserção atual ou definir o modo de inserção como ligado ou desligado. |
| Comando KEYBOARD | Colocar a expressão de caracteres especificada no buffer do teclado. |
| Função LASTKEY( ) | Retornar um inteiro correspondente à última tecla pressionada. |
| Função MCOL( ) | Retornar a posição de coluna do ponteiro do mouse na janela principal do Visual FoxPro ou em uma janela definida pelo usuário. |
| Comando MOUSE | Executar o equivalente de clicar, clicar duas vezes ou mover o mouse, ou executar uma operação de arrastar. |
| Função MROW( ) | Retornar a posição de linha do ponteiro do mouse na janela principal do Visual FoxPro ou em uma janela definida pelo usuário. |
| Função NUMLOCK( ) | Retornar o modo atual da tecla NUM LOCK ou definir o modo da tecla NUM LOCK como ligado ou desligado. |
| Comando ON KEY LABEL | Especificar um comando que executa quando você pressiona uma tecla ou combinação de teclas específica ou clica no botão do mouse. |
| Comando PLAY MACRO | Executar uma macro de teclado. |
| Comando POP KEY | Restaurar atribuições ON KEY LABEL que foram colocadas na pilha com PUSH KEY. |
| Comando PUSH KEY | Colocar todas as configurações atuais de comando ON KEY LABEL em uma pilha na memória. |
| Comando RESTORE MACROS | Restaurar na memória macros de teclado salvas em um arquivo de macro de teclado ou campo memo. |
| Comando SAVE MACROS | Salvar um conjunto de macros de teclado em um arquivo de macro de teclado ou em um campo memo. |
| Comando SET FUNCTION | Atribuir uma expressão (macro de teclado) a uma tecla de função ou combinação de teclas. |
| Comando SET KEYCOMP | Controlar a navegação por teclas do Visual FoxPro. |
| Comando SET MACKEY | Especificar uma tecla ou combinação de teclas que exibe a caixa de diálogo Macro Key Definition. |
| Comando SET TYPEAHEAD | Especificar o número máximo de caracteres que podem ser armazenados no buffer type-ahead. |
