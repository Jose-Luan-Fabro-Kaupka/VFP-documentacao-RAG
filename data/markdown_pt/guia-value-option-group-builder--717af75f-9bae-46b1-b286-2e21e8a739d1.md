# Guia Value, Option Group Builder

Esta guia no Option Group builder especifica um campo de tabela ou view no qual colocar o valor do option group.
 **Field Name**
Especifica um campo de tabela ou view no qual armazenar o valor do option group. Por padrão, a lista inclui campos de uma tabela. Escolha o botão de diálogo para exibir a caixa de diálogo Open para que você possa selecionar outro arquivo. Esta opção corresponde à propriedade ControlSource.
