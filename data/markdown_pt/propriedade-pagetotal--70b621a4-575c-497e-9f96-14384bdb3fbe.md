# Propriedade PageTotal

Fornece um PageTotal para saída de relatório.

```foxpro
ReportListener.PageTotal
```

# Valor de retorno

Tipo de dados Integer.

Valor padrão: 0. Esta propriedade é somente leitura.

# Observações

Aplica-se a: Objeto ReportListener.

ReportListener.PageTotal não está disponível até depois da prepassagem em cada comando LABEL ou REPORT FORM de múltiplas passagens, mas de outra forma funciona de maneira semelhante a ReportListener.PageNo. Consulte a propriedade PageNo e a propriedade CurrentPass para obter mais informações.
