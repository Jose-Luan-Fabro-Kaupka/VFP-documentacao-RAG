# Função AGETCLASS( )

Exibe bibliotecas de classes na caixa de diálogo Open e cria uma matriz contendo o nome da biblioteca de classes e da classe escolhida.

```foxpro
AGETCLASS(ArrayName [, cLibraryName [, cClassName [, cTitleText
[, cFileNameCaption [, cButtonCaption]]]]])
```

#### Parâmetros
 **ArrayName**
Especifica o nome da matriz na qual os nomes da biblioteca de classes e da classe são colocados. A tabela a seguir lista o conteúdo de cada elemento da matriz criada quando você escolhe uma classe. Elemento Conteúdo 1 Nome do arquivo da biblioteca de classes escolhida. 2 Nome da classe escolhida.
**cLibraryName**
Especifica o nome da biblioteca de classes inicialmente selecionada quando a caixa de diálogo Open é exibida. cLibraryName pode ser uma biblioteca de classes visual (.vcx) ou baseada em programa (.prg). O nome da biblioteca de classes que você especifica é exibido na caixa de texto File name. Um erro é gerado se a biblioteca de classes que você especifica não existir ou cLibraryName for a cadeia de caracteres vazia ou o valor nulo.
**cClassName**
Especifica o nome da classe inicialmente selecionada na lista Class name quando a caixa de diálogo Open é exibida. Se a classe que você especifica não existir, a primeira classe na lista Class name é selecionada. Um erro é gerado se você omitir cLibraryName ou cClassName for o valor nulo.
**cTitleText**
Especifica o texto exibido na barra de título da caixa de diálogo Open. Por padrão, "Open" é o texto exibido.
**cFileNameCaption**
Especifica o texto exibido ao lado da caixa de texto File name. Por padrão, "File name:" é o texto exibido.
**cButtonCaption**
Especifica a legenda do botão OK.

# Valor de retorno

Tipo de dados lógico. AGETCLASS( ) retorna True (.T.), se você escolheu uma classe, e cria uma matriz unidimensional contendo dois elementos. O primeiro elemento contém o nome do arquivo da biblioteca de classes escolhida; o segundo elemento contém o nome da classe escolhida. AGETCLASS retorna False (.F.) se você sair da caixa de diálogo Class Library pressionando ESC, escolhendo Cancel ou clicando no botão Close.

# Observações

Se a matriz que você especifica não existir, o Visual FoxPro cria automaticamente a matriz.

Se a matriz existir e não for grande o suficiente para conter os nomes da biblioteca de classes e da classe, o Visual FoxPro aumenta automaticamente o tamanho da matriz.

Se a matriz for maior do que o necessário, o Visual FoxPro trunca a matriz. Se a matriz existir, e AGETCLASS( ) retornar False (.F.) porque a caixa de diálogo Class Library foi fechada pressionando ESC, escolhendo Cancel ou clicando no botão Close, a matriz permanece inalterada.

Se a matriz não existir, e AGETCLASS( ) retornar false (.F.), a matriz não é criada.

O Visual FoxPro 8.0 não suporta AGETCLASS( ) em suas bibliotecas de tempo de execução. AGETCLASS( ) é suportado nas bibliotecas de tempo de execução do Visual FoxPro 9.0, mas a opção Program (*.prg) não está disponível na caixa de listagem suspensa Files of type.

# Exemplo

O exemplo a seguir cria uma matriz chamada `aClassLib`. O diretório é alterado para o subdiretório \Samples que contém as bibliotecas de classes de exemplo. AGETCLASS( ) é usado para exibir uma caixa de diálogo com a biblioteca de classes Buttons e a classe VCR selecionada. Se você escolher o botão Modify, o nome da biblioteca de classes e da classe que você seleciona é armazenado na matriz. A classe é então aberta no Class designer.

```foxpro
LOCAL aClassLib(2)  && Create an array, initialized to .F.
cCurrentDir = CURDIR()  && Save the current directory.
CD HOME(2) + 'CLASSES'  && Switch directories.
AGETCLASS(aClassLib, 'BUTTONS.VCX', 'VCR', 'Modify Class', ;
   'Class File:', 'Modify')  && Display the dialog.
CD (cCurrentDir)  && Switch to the previous directory.
IF TYPE('aClassLib(2)') = 'C'  && Class chosen?
   MODIFY CLASS (aClassLib(2)) OF (aClassLib(1))  && Open to modify.
ENDIF
```
