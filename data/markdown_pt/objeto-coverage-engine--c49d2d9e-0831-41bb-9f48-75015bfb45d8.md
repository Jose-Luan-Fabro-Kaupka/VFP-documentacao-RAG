# Objeto Coverage Engine

A classe Coverage engine é uma subclasse da classe FormSet do Visual FoxPro. Embora não forneça componentes visíveis, fornece a sessão de dados de uma classe FormSet e inclui provisões para feedback sobre o processamento do log de cobertura por meio do Comando WAIT, da Função MESSAGEBOX( ) e de subclasses de MSComDlg.CommonDialog.

> **Observação:** Este formset não é uma subclasse de _formset; portanto, o Coverage Profiler é executado no Visual FoxPro 5.0 e versões posteriores.

Para obter mais informações, consulte Aplicativo Coverage Profiler.

# Observações

Este formset tem um membro, uma barra de ferramentas, que permanece oculta enquanto fornece um contêiner para objetos personalizados, como subclasses de CusRegistry ou Dialog. Cov_standard, uma subclasse de cov_engine, fornece uma interface de usuário de exemplo, o Aplicativo Coverage Profiler. Você pode criar subclasses de cov_engine ou cov_standard para atender aos seus requisitos.

| MarkTargetCoverage( ) Method | Marks up a copy of the source and REPLACEs a memo field in the target file. Sintaxe: MarkTargetCoverage(tcSource, tcTarget) Valores de retorno: NOT (EMPTY( cMemo ) OR THIS. lError ) Parâmetros: tcSource S pecifies the name of the table containing the source records. tcTarget Especifica o nome da tabela sendo modificada. Observações: MarkTargetCoverage( ) creates a marked-up version of tcSource and REPLACEs a memo field in the target file, tcTarget , (whether the code is for a class or a full procedure file). To perform this action, the method starts with the sourcecode memo. The memo field REPLACEd depends on whether Coverage Profiler is marking Profiler or Coverage information, because the Target record retains both sets of marked-up code. This method parses the source code and evaluates its statistics line by line. By default, this method calls the MarkCodeLine( ) method to mark each line when it has the appropriate statistics. However, the way this method marks the code line is #DEFINEd as COV_MARK_CODE_LINE in COV_TUNE.H, not directly implemented as a call to the MarkCodeLine( ) method. This makes it possible for you to replace the call to the MarkCodeLine( ) method with a different marking system. A second #DEFINE, COV_TOPSPEED, in COV_TUNE.H also makes it possible for you to switch the MarkCodeLine( ) call to a simpler, in-line marking system for fastest response time. MarkTargetCoverage( ) evaluates each line to find out whether it was executed, how many times it was executed, and its execution timings (first and average) when in Profile mode. However, many lines are considered uncoverable in Coverage Profiler. These lines, such as comments, DEFINE CLASS and ELSE/Otherwise statements, and lines within TEXT ... ENDTEXT, do not appear in coverage logs, because they are not executable. Observação Other uncoverable code lines include #DEFINE statements, empty lines, continuations of executing lines, and parameter lines. This method sets the number of times these lines run to .NULL. These lines are not considered when Coverage Profiler compiles statistics. In addition, lines broken by continuation symbols (semicolons) are considered as a single line of code and marked only on the last line. |
