# Guia Default Data, Pane Customization Dialog Box

A guia Default Data especifica os dados padrão a exibir se os dados reais não puderem ser recuperados da Internet quando um painel é exibido pela primeira vez. Essas informações são opcionais e são usadas apenas se os dados não estiverem armazenados localmente. Se um painel recuperar dados com sucesso da Internet, mas falhar em tentativas subsequentes, o painel usa os dados armazenados no diretório PaneCache, não os dados XML padrão.
 **Modify**
Abre uma janela para editar os dados XML padrão.
**Edit Box**
Exibe os dados XML padrão.
