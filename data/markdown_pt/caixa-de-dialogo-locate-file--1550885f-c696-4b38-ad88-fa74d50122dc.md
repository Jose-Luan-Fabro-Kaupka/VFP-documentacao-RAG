# Caixa de diálogo Locate File

Permite localizar ou ignorar um arquivo ou grupo de arquivos ausente. Esta caixa de diálogo aparece quando você executa um programa e o Visual FoxPro não consegue localizar um arquivo necessário para executá-lo com êxito.
 **Locate**
Exibe a caixa de diálogo Open para que você localize o arquivo.
**Ignore**
O Visual FoxPro continuará executando o programa sem o arquivo necessário.
**Ignore all**
O Visual FoxPro continuará executando o programa sem o grupo de arquivos necessário.
**Cancel**
O Visual FoxPro interromperá a execução do programa.
