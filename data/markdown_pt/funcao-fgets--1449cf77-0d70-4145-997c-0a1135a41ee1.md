# Função FGETS( )

Retorna uma série de bytes de um arquivo ou porta de comunicação aberta com uma função de arquivo de baixo nível até encontrar um retorno de carro.

```foxpro
FGETS(nFileHandle [, nBytes])
```

#### Parâmetros
 **nFileHandle**
Especifica o identificador numérico do arquivo ou da porta de comunicação de onde FGETS( ) retorna dados.
**nBytes**
Especifica o número de bytes retornados por FGETS( ). FGETS( ) retorna nBytes bytes, a menos que encontre primeiro um retorno de carro. Se encontrar um retorno de carro dentro de nBytes bytes, FGETS( ) retorna os dados entre a posição inicial do ponteiro do arquivo e o retorno de carro. FGETS( ) retorna no máximo 8192 bytes. Se nBytes for omitido, FGETS( ) retornará 254 bytes por padrão.

# Valor de retorno

Character

# Observações

Você pode ler um arquivo linha por linha emitindo uma série de FGETS( ).

FGETS( ) retorna uma série de bytes como uma cadeia de caracteres. Os dados são retornados a partir da posição atual do ponteiro do arquivo até que seja encontrado um retorno de carro. Em seguida, o ponteiro é posicionado no byte imediatamente posterior ao retorno de carro. O retorno de carro não faz parte da cadeia retornada, e os avanços de linha são descartados.

# Exemplo

```foxpro
*** TEST.TXT must exist ***
STORE FOPEN('test.txt') TO gnFileHandle    && Open the file
STORE FSEEK(gnFileHandle, 0, 2) TO gnEnd    && Move pointer to EOF
STORE FSEEK(gnFileHandle, 0) TO gnTop     && Move pointer to BOF
IF gnEnd <= 0  && Is file empty?
   WAIT WINDOW 'This file is empty!' NOWAIT
ELSE  && If not
   gcString = FGETS(gnFileHandle, gnEnd)  && Store contents
   ? gcString
ENDIF
= FCLOSE(gnFileHandle)  && Close the file
```
