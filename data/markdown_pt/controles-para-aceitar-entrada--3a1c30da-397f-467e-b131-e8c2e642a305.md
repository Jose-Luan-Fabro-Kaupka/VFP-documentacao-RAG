# Controles para aceitar entrada

É difícil antecipar todos os valores que um usuário pode precisar inserir em um controle. Os controles a seguir permitem aceitar entrada do usuário que não pode ser predeterminada:
 - Caixas de texto
- Caixas de edição
- Caixas de combinação
