# Função AEVENTS( )

Você pode usar a função AEVENTS( ) para recuperar o número de associações de eventos existentes.

```foxpro
AEVENTS( ArrayName [, 0 | 1 | oEventObject ] )
```

#### Parâmetros
 **ArrayName**
Especifica o nome da matriz que contém os resultados de AEVENTS( ) .
**0**
Especifica que AEVENTS( ) retorna uma matriz de três elementos contendo uma referência de objeto à origem do evento atual, o nome do evento disparado e como o evento foi disparado. Coluna Descrição Tipo 1 Origem do evento Referência de objeto 2 Evento Cadeia de caracteres 3 Tipo de evento, ou como o evento foi gerado. 0 - Sistema 1 - Função RAISEEVENT( ) 2 - Chamada de método O terceiro elemento da matriz indica como um evento foi disparado. Se o evento é uma propriedade, este valor pode ser 1 ou 2. O valor é 2 se a propriedade é definida ou atribuída.
**1**
Especifica que AEVENTS( ) retorna uma matriz de quatro colunas contendo informações sobre eventos de mensagem do Windows (Win Msg). A matriz contém uma linha para cada associação. As associações são criadas com a Função BINDEVENT( ) . A tabela a seguir descreve o conteúdo de cada coluna na matriz. Coluna Descrição Tipo 1 hWnd Inteiro 2 Mensagem de janela Inteiro 3 Referência do manipulador Referência de objeto 4 Delegado do manipulador Cadeia de caracteres
**oEventObject**
Especifica uma referência de objeto. Se você especificar uma referência de objeto, AEVENTS( ) retorna uma matriz de cinco colunas que contém os eventos gerados e os métodos delegados para oEventObject . Cada linha em ArrayName representa uma associação. A tabela a seguir descreve as informações em cada uma das cinco colunas. Coluna Descrição Tipo 1 .T. se o segundo elemento é a origem do evento .F. se o segundo elemento é o manipulador de eventos Valor lógico 2 Origem do evento se você passar o manipulador de eventos para oEventObject ; caso contrário, manipulador de eventos se você passar a origem do evento para oEventObject . Referência de objeto 3 Evento Cadeia de caracteres 4 Método delegado Cadeia de caracteres 5 Sinalizadores BINDEVENT( ) Inteiro Quando você passa oEventObject , o número de associações retornado por AEVENTS( ) deve ser igual ao número de eventos desassociados retornado pela função UNBINDEVENTS( ) ao passar apenas o parâmetro oEventObject.

# Valor de retorno

Numérico. AEVENTS( ) retorna o número de linhas na matriz especificada. Normalmente, o número representa o número de associações de eventos. No entanto, se você passar zero (0), AEVENTS( ) retorna 3.

# Observações

Se AEVENTS( ) retornar 0 e a matriz não existir, o Visual FoxPro não cria a matriz. O Visual FoxPro altera ou modifica uma matriz existente somente se resultados válidos são retornados. A matriz permanece inalterada nas seguintes condições:
 - Não existem eventos.
- Você especifica um valor de 0 como segundo parâmetro, e AEVENTS( ) não aparece dentro de um evento ou oEventObject não tem associações.

# Exemplo

O exemplo a seguir mostra como usar AEVENTS( ) para recuperar o número de associações de eventos existentes. BINDEVENTS( ) mantém o Navegador de classes posicionado no lado direito da área de trabalho do Visual FoxPro, independentemente de como a área de trabalho é redimensionada. Para obter mais informações, consulte Função BINDEVENT( ).

UNBINDEVENTS( ) desassocia o evento Resize da variável de sistema _SCREEN do objeto `oHandler`. AEVENTS( ) retorna o número de associações de eventos antes de BINDEVENT( ) e após UNBINDEVENTS( ) em uma matriz chamada `myArray`:

```foxpro
PUBLIC oHandler
oHandler=NEWOBJECT("myhandler")
DO (_browser)
BINDEVENT(_SCREEN,"Resize",oHandler,"myresize")
AEVENTS(myArray,oHandler)
numRows=ALEN(myArray,1)
numCols=ALEN(myArray,2)
WAIT "Rows in array after binding: " + TRANSFORM(numRows) WINDOW AT 20,20
WAIT "Cols in array after binding: " + TRANSFORM(numCols) WINDOW AT 20,20
FOR count1 = 1 TO numRows
   FOR count2 = 1 TO numCols
      WAIT myArray[count1,count2] WINDOW AT 20,20
   ENDFOR
ENDFOR
* Comment the following line to see event binding persist.
UNBINDEVENTS(_SCREEN,"Resize",oHandler,"myresize")
AEVENTS(myArray,oHandler)
* Check if AEVENTS() created and populated new array.
IF VARTYPE(myArray) <> U
   * The following code does not execute if event is unbound because
   * AEVENT() does not create a new array if it returns 0. To execute
   * the following code and see the contents of the new array, uncomment
   * the UNBINDEVENTS() statement.
   numRows=ALEN(myArray,1)
   numCols=ALEN(myArray,2)
   WAIT "Rows in array after unbinding: " + TRANSFORM(numRows) ;
      WINDOW AT 20,20
   WAIT "Cols in array after unbinding: " + TRANSFORM(numCols) ;
      WINDOW AT 20,20
   FOR count1 = 1 TO numRows
      FOR count2 = 1 TO numCols
         WAIT myArray[count1,count2] WINDOW AT 20,20
      ENDFOR
   ENDFOR
ENDIF
DEFINE CLASS myhandler AS Session
   PROCEDURE myresize
   _obrowser.left = _SCREEN.Width - _obrowser.width
   RETURN
ENDDEFINE
```
