# Janela Locals (Visual FoxPro)

Permite exibir todas as variáveis, arrays, objetos e membros de objetos visíveis em determinado programa, procedimento ou método.

É ativada ao escolher Locals no menu Window da janela Debugger.

No Visual FoxPro 9.0, os itens Find e Find Again permitem pesquisar itens na coluna Name.
 **Locals for**
Indica o procedimento cujas variáveis, arrays e objetos são exibidos.
**Name**
Exibe os nomes dos locais visíveis.
**Value**
Exibe os valores atuais.
**Type**
Exibe caracteres que representam os tipos de dados.

Use o menu de atalho para controlar a categoria de variável exibida.

| Categoria | Descrição |
| --- | --- |
| Public | Variáveis declaradas com a palavra-chave PUBLIC. |
| Local | Variáveis declaradas com a palavra-chave LOCAL. |
| Standard | Todas as variáveis no escopo do procedimento exibido em Locals for. |
| Objects | Variáveis de objeto. |

Para ver valores de elementos de array ou propriedades de objeto, clique na caixa à esquerda do nome. A janela permite ver propriedades de todos os objetos na hierarquia do contêiner.
