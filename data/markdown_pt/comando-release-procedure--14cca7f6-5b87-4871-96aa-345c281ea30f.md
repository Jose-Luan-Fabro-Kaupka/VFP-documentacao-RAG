# Comando RELEASE PROCEDURE

Fecha arquivos de procedimento abertos com SET PROCEDURE.

```foxpro
RELEASE PROCEDURE FileName1 [, FileName2 ...]
```

#### Parâmetros
 **FileName1 [, FileName2 ... ]**
Especifica o nome do arquivo de procedimento ou de um conjunto de arquivos de procedimento a fechar.

# Observações

Arquivos de procedimento são abertos com SET PROCEDURE. Depois de aberto o arquivo, seus procedimentos ficam disponíveis para programas e na janela Command.

Para fechar todos os arquivos de procedimento abertos, emita SET PROCEDURE TO sem argumentos adicionais.
