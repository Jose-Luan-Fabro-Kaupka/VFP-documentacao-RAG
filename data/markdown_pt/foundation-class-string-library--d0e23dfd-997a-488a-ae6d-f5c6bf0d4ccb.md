# Foundation Class String Library

Esta classe remove caracteres de retorno de carro e quebra de linha de uma cadeia de caracteres.

| Categoria | Data Utilities |
| --- | --- |
| Catálogo padrão | Visual FoxPro Catalog\Foundation Classes\Utilities |
| Classe | _stringlib |
| Classe base | Custom |
| Biblioteca de classes | _utility.vcx |
| Classe pai | _custom |

# Observações

| Properties, Events, Methods | Descrição |
| --- | --- |
| Método TrimCRLF | Remove caracteres de retorno de carro e quebra de linha de uma cadeia de caracteres. Sintaxe: TrimCRLF (tcString, tlTrimLeft, tlTrimRight) Retorno: none Argumentos: tcString especifica a cadeia de caracteres a aparar. tlTrimLeft especifica se deve aparar o lado esquerdo. tlTrimRight especifica se deve aparar o lado direito. |
