# Designers

Os designers permitem que você projete visualmente as janelas, caixas de diálogo e componentes do seu aplicativo.

# Nesta Seção
 **Class Designer**
Permite criar e modificar classes visualmente.
**Connection Designer**
Permite criar e modificar conexões nomeadas. Como as conexões são armazenadas como parte de um banco de dados, você só pode usar o Connection designer se tiver um banco de dados aberto.
**Data Environment Designer**
Permite criar e modificar visualmente o ambiente de dados de formulários, conjuntos de formulários e relatórios.
**Database Designer (Visual FoxPro)**
Exibe e permite criar e modificar tabelas, views e relacionamentos contidos em um banco de dados.
**Form Designer**
Permite criar e modificar formulários e conjuntos de formulários visualmente. Um conjunto de formulários consiste em um ou mais formulários que podem ser manipulados como uma unidade.
**Label Designer**
Permite criar e modificar etiquetas. Quando a janela do Label designer está ativa, o Microsoft Visual FoxPro exibe o menu Report e a barra de ferramentas Report Controls.
**Menu and Shortcut Designers**
Permite criar menus, itens de menu, submenus de itens de menu, linhas que separam grupos de itens de menu relacionados e assim por diante.
**Query and View Designers**
Permite criar e modificar consultas e views. Quando o Query ou View designer está ativo, o Microsoft Visual FoxPro exibe o menu Query e a barra de ferramentas Query ou a barra de ferramentas do View designer.
**Report Designer**
Permite criar e modificar relatórios. Quando a janela do Report designer está ativa, o Microsoft Visual FoxPro exibe o menu Report e a barra de ferramentas Report Controls.
**Table Designer (Visual FoxPro)**
Permite criar e modificar tabelas de banco de dados, tabelas livres, campos e índices.
