# Como: personalizar o Visual FoxPro para acessibilidade

Você pode usar as etapas a seguir para melhorar a acessibilidade no Visual FoxPro:

# Ampliar botões da barra de ferramentas

### Para exibir botões ampliados da barra de ferramentas
- No menu View, clique em Toolbars.
- Marque a caixa de seleção Large buttons.

# Ampliar texto na janela de código

### Para exibir texto ampliado na janela de código
- No menu Format, clique em Font e escolha o tamanho de fonte desejado.

# Ampliar texto no Debugger

### Para exibir texto ampliado no Debugger
- No menu Tools, clique em Options.
- Na caixa de diálogo Options, clique na guia Debug e depois em Font.
- Selecione a fonte e o tamanho de fonte desejados.
