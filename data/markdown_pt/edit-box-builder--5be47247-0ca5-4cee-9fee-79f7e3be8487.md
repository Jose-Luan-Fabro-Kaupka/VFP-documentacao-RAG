# Edit Box Builder

O Edit Box Builder facilita a definição de propriedades para um controle edit box. Edit boxes são comumente usados para exibir campos Character longos ou campos Memo e permitem que o usuário edite texto. Um edit box também pode exibir texto de um arquivo de texto ou da área de transferência. Você define propriedades para o controle edit box selecionando opções na caixa de diálogo Edit Box Builder.

 Para usar o Edit Box Builder
 - Usando a barra de ferramentas Form Controls, posicione um controle edit box em um formulário.
- Selecione e clique com o botão direito no controle edit box e escolha Builder no menu de atalho do Form Designer. Uma caixa de diálogo apropriada ao controle selecionado é exibida.
- Escolha as opções desejadas na caixa de diálogo e escolha OK . Quando você escolhe OK , o builder é fechado, aplicando as configurações de propriedade de todas as guias.

# Guias do Builder
 **Format**
Especifica opções diversas de formatação para o edit box.
**Style**
Especifica o efeito visual, a borda e o alinhamento do edit box.
**Value**
Especifica um campo no qual armazenar o valor do edit box.
