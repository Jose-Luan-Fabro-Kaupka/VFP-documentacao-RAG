# Controle OptionButton

Cria um único botão de opção.

Você pode usar um grupo de botões de opção para fornecer uma seleção de escolhas predeterminadas. Para obter mais informações sobre como criar um grupo de botões de opção, consulte o controle OptionGroup e Usando controles.

```foxpro
OptionButton
```

# Observações

Embora você possa adicionar um botão de opção a qualquer contêiner, quando adicionado a um contêiner OptionGroup, o botão é sincronizado com outros botões de opção nesse OptionGroup para que apenas um botão possa ser selecionado por vez.

Quando você define a propriedade Style de um controle OptionButton como Graphical, o controle OptionButton aparece como um controle CommandButton e pode conter gráficos e texto. Para obter mais informações, consulte a propriedade Style.
