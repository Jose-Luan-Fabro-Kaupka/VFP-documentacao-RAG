# Como: descartar alterações

Se você fez check-out de um arquivo, mas decide descartar as alterações feitas, pode desfazer o check-out. Isso tem o efeito de devolver o arquivo (ou seja, outros usuários podem fazer check-out do arquivo), mas não o atualiza com as alterações. Por exemplo, se você fez check-out de um arquivo por engano em vez de simplesmente obter a versão mais recente, desfaça o check-out em vez de devolver o arquivo. Isso evita que o sistema de controle de código-fonte precise criar outra versão do arquivo, economizando tempo e espaço.

> **Dica:** Se você deseja visualizar um arquivo, mas não precisa fazer check-out dele, pode obter a versão mais recente.

### Para desfazer um check-out
- Na janela Project Manager, selecione o arquivo com o qual deseja trabalhar.
- No menu Project, escolha Source Control e depois Undo Check Out.
- Na caixa de diálogo Undo Check Out of Files, verifique se o arquivo desejado está selecionado e clique em OK.
