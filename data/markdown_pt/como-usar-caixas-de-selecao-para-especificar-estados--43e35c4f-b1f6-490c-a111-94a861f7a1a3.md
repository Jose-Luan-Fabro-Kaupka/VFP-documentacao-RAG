# Como: usar caixas de seleção para especificar estados

Você pode usar caixas de seleção para permitir que um usuário especifique um estado booleano: True ou False, On ou Off, Open ou Closed. No entanto, há momentos em que não é preciso avaliar algo como True ou False, como perguntas sem resposta em um questionário de Verdadeiro/Falso.

### Para ver exemplos de uso de caixas de seleção
- Execute Solution.app no diretório Visual FoxPro ...\Samples\Solution.
- Na visualização em árvore, clique em Controls e depois em Check boxes.
