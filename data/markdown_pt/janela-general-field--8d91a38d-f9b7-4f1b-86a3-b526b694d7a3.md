# Janela General Field

Esta janela é exibida quando você clica duas vezes no designador de tipo de um campo General em uma tabela em modo de navegação, ou pressiona CTRL+PAGE UP ou CTRL+PAGE DOWN para abrir a janela General Field pelo teclado.

Com esta janela exibida, você pode criar ou inserir objetos OLE usando o comando Insert Object no menu Edit. Você pode editar o objeto existente clicando duas vezes nele ou selecionando Bitmap Image object Edit ou object Open no menu Edit.
