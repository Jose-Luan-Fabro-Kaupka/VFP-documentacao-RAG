# Propriedade StatusBar

Especifica o texto exibido na barra de status de uma instância do Visual FoxPro. Leitura/gravação em tempo de execução.

```foxpro
ApplicationObject.StatusBar[ = cMessageText]
```

# Valor de retorno
 **cMessageText**
Especifica o texto exibido na barra de status.

# Observações

Aplica-se a: Application Object | _VFP System Variable
