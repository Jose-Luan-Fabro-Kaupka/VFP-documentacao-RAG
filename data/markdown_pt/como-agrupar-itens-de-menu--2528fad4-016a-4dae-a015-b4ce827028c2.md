# Como: agrupar itens de menu

Para facilitar a leitura, separe grupos de itens de menu semelhantes com linhas divisórias. Por exemplo, no Visual FoxPro, o menu Edit tem uma linha separando os comandos Undo e Redo dos comandos Cut, Copy, Paste, Paste Special e Clear.

### Para agrupar itens de menu
- Na coluna Prompt, digite \- . Isso cria uma linha divisória.
- Arraste o botão à esquerda do prompt \- para mover a linha divisória até que ela apareça onde você deseja.
