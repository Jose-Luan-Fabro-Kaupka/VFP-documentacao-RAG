# Visão geral dos recursos do Visual FoxPro

O Microsoft Visual FoxPro oferece mais de tudo o que você espera de um sistema de gerenciamento de banco de dados (DBMS) — velocidade, poder e flexibilidade. Além disso, o Visual FoxPro conduz você à próxima geração fornecendo modelos de objetos e eventos que ajudam você a criar e modificar aplicativos mais rapidamente do que nunca.

Os tópicos a seguir orientam você por alguns dos principais recursos do Visual FoxPro. Para obter informações sobre os aprimoramentos mais recentes nesta versão do Visual FoxPro, consulte Novidades no Visual FoxPro.

# Nesta Seção
 **Criação rápida de aplicativos**
Discute como você pode desenvolver aplicativos rapidamente com ajuda dos assistentes, construtores, barras de ferramentas e designers do Visual FoxPro, e implementá-los rapidamente usando os modelos de objetos e eventos do Visual FoxPro.
**Vantagens de mais poder**
Descreve como você pode aproveitar as capacidades de programação orientada a objetos do Visual FoxPro, bem como recursos como a tecnologia Rushmore Query Optimization para melhorar o desempenho e acelerar o desenvolvimento de aplicativos.
**Criação de interface do usuário sem programação**
Discute os controles poderosos fornecidos pelo Visual FoxPro que oferecem interfaces que requerem pouco ou nenhum código.
**Desenvolvimento de aplicativos com vários desenvolvedores**
Discute o uso do Visual FoxPro para permitir acesso simultâneo a componentes de banco de dados e o uso de programas de controle de origem com o Project Manager para rastrear e proteger alterações em seu código-fonte.
**Interação com outros aplicativos**
Fornece informações sobre compartilhamento de dados com outros aplicativos, como Microsoft Excel e Microsoft Word, usando objetos de outros aplicativos e controlando outros aplicativos usando automação.
**Desenvolvimento de soluções cliente/servidor**
Discute como você pode usar o Visual FoxPro como front-end para desenvolver aplicativos cliente/servidor robustos. Ele combina o suporte de nível superior de views atualizáveis de dados do servidor com acesso direto à sintaxe nativa do servidor usando SQL pass-through.
