# Caixa de diálogo Optional Bands

Permite incluir faixas Title, Summary ou Detail adicionais em um relatório ou etiqueta.

> **Observação:** Dependendo da configuração da variável de sistema _REPORTBUILDER, esta caixa de diálogo pode ser substituída por uma interface de usuário alternativa. Para obter mais informações, consulte Variável de sistema _REPORTBUILDER.
 - Como: adicionar faixas a relatórios
- Como: configurar a saída de faixas de relatório
- Como: excluir faixas de relatórios

# Título do relatório

Permite incluir uma faixa Title e especificar opções de quebra de página para ela.
 **Title band**
Especifica se o layout inclui uma faixa Title para exibir informações uma vez no início do relatório.
**New page**
Especifica que uma quebra de página será enviada à impressora após a renderização das informações da faixa Title. Disponível somente quando a caixa de seleção Title band estiver marcada.

# Resumo do relatório

Permite incluir uma faixa Summary e especificar suas opções.
 **Summary band**
Especifica se o layout inclui uma faixa Summary para exibir informações uma vez no final do relatório.
**New page**
Especifica que uma quebra de página será enviada à impressora antes da renderização das informações da faixa Summary. Disponível somente quando a caixa Summary band estiver marcada.
**Page header**
Especifica que as informações da faixa Page Header serão renderizadas na página separada junto com as informações de Summary.
**Page footer**
Especifica que as informações da faixa Page Footer serão renderizadas na página separada junto com as informações de Summary.

# Detalhes

Permite adicionar faixas Detail.
 **Details**
Especifica o número de faixas Detail a incluir no relatório. O padrão é 1. Um layout de relatório deve conter pelo menos uma faixa Detail. Observação: é possível incluir no máximo 20 faixas Detail.
