# Classe de fundação Sort Mover

Esta subclasse da classe de caixa de lista mover, quando colocada em um formulário, controla automaticamente a classificação de dados.

| Categoria | Movers |
| --- | --- |
| Catálogo padrão | Visual FoxPro Catalog\Foundation Classes\User Controls |
| Classe | _sortmover |
| Classe base | Container |
| Biblioteca de classes | _mover.vcx |
| Classe pai | _mover |
| Exemplo | ...\Samples\Solution\Ffc\movers.scx |

# Observações

| Propriedades, eventos, métodos | Descrição |
| --- | --- |
| CurrentAlias property | O alias atual para opções de campo. Padrão: "" |
| CurrentDBC property | O banco de dados atual para opções de campo. Padrão: "" |
| MaxFields property | Número máximo de campos permitidos. Padrão: 3 |
| ShowTags property | Especifica se as tags de índice existentes devem ser exibidas além dos campos. Padrão: .F. |
| aTags[1,1] property | Uso interno da classe. |
| TagName property | Uso interno da classe. |
| UpdateMover | Uso interno da classe. |
