# Exemplo Generate HTML

Arquivo: ...\Samples\Solution\Ffc\DoHTML.scx

Este exemplo contém as seguintes classes.

| Classe | Biblioteca | Descrição |
| --- | --- | --- |
| _webform | Webview.vcx | Fornece um formulário Visual FoxPro contendo um controle Web browser para exibir texto HTML. |
| _resizable | Controls.vcx | Faz com que objetos soltos em um formulário redimensionem e se movam com o evento resize do Form. |
| _dbf2html | Internet.vcx | Converte uma tabela Visual FoxPro (.dbf) em HTML. |
| _frx2html | Internet.vcx | Converte um relatório Visual FoxPro (.frx) em HTML. |

Para detalhes sobre todas as classes disponíveis nas classes base, consulte Classes base do Visual FoxPro A-Z.
