# Função ALEN( )

Retorna o número de elementos, linhas ou colunas em uma matriz.

```foxpro
ALEN(ArrayName [, nArrayAttribute])
```

#### Parâmetros
 **ArrayName**
Especifica o nome da matriz. Se você incluir apenas o nome da matriz, ALEN( ) retorna o número de elementos na matriz.
**nArrayAttribute**
Determina se ALEN( ) retorna o número de elementos, linhas ou colunas na matriz de acordo com os seguintes valores para nArrayAttribute: 0 Retorna o número de elementos na matriz. Omitir nArrayAttribute é idêntico a especificar 0. 1 Retorna o número de linhas na matriz. 2 Retorna o número de colunas na matriz. Se a matriz é unidimensional, ALEN( ) retorna 0 (sem colunas).

# Valor de retorno

Numeric

# Exemplo

O exemplo a seguir usa AFONT( ) para criar uma matriz contendo os nomes de todas as fontes disponíveis. ALEN( ) é usado para determinar o número de linhas na matriz. O nome de cada fonte é exibido, junto com um exemplo da fonte. Se mais de 10 fontes estiverem instaladas, apenas as primeiras 10 são exibidas.

```foxpro
CLEAR
=AFONT(gaFontArray)  && Array containing font names
gnNumFonts= ALEN(gaFontArray)  && Number of fonts
IF gnNumFonts > 10
   gnNumFonts = 10  && Display first 10 fonts
ENDIF
FOR nCount = 1 TO gnNumFonts
   ? ALLTRIM(gaFontArray(nCount))  && Display font name
   ?? '  This is an example of ' ;
      + ALLTRIM(gaFontArray(nCount)) FONT gaFontArray(nCount), 8
ENDFOR
```
