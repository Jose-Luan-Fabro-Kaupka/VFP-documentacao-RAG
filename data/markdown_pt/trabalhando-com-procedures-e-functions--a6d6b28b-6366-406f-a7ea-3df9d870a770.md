# Trabalhando com procedures e functions

O Visual FoxPro inclui uma ampla gama de funções nativas que você pode usar para realizar manipulação de dados ou outras operações. Funções no Visual FoxPro executam operações em dados e retornam resultados com um tipo específico. Você também pode criar procedures e functions para armazenar código que executa rotinas usadas com frequência ou comumente em seus programas.
