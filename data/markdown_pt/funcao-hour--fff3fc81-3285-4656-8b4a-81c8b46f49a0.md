# Função HOUR( )

Retorna a parte da hora de uma expressão DateTime.

```foxpro
HOUR(tExpression)
```

#### Parâmetros
 **tExpression**
Especifica uma expressão DateTime da qual HOUR( ) retorna a hora.

# Valor de retorno

Numeric

# Observações

HOUR( ) retorna um valor numérico baseado em um formato de 24 horas e não é afetado pela configuração atual de SET HOURS. Por exemplo, se SET HOURS for 12 ou 24, o comando a seguir retorna 13:

```foxpro
? HOUR({^1998-02-16 1:00p})
```

# Exemplo

O exemplo a seguir exibe a parte da hora da hora atual e a parte da hora de uma hora específica.

```foxpro
CLEAR
? HOUR(DATETIME())
? HOUR({^1998-02-16 10:42a})  && Displays 10
```
