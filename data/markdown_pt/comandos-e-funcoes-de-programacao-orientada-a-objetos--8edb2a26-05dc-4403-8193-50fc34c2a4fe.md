# Comandos e funções de programação orientada a objetos

Esses comandos e funções permitem criar e manipular classes e objetos.

| Use | To |
| --- | --- |
| :: Scope Resolution Operator | Executar um método de classe pai a partir de um método de subclasse. |
| @ ... CLASS Command | Criar um controle ou objeto que pode ser ativado com READ. |
| _WIZARD System Variable | Contém o nome da aplicação de assistente do Visual FoxPro. |
| ACLASS( ) Function | Coloca o nome da classe de um objeto e os nomes de suas classes ancestrais em uma matriz de variáveis. |
| ADATABASES( ) Function | Coloca os nomes de todos os bancos de dados abertos e seus caminhos em uma matriz de variáveis. |
| ADBOBJECTS( ) Function | Coloca os nomes de conexões nomeadas, relações, tabelas ou views SQL no banco de dados atual em uma matriz de variáveis. |
| ADD CLASS Command | Adicionar uma definição de classe a uma biblioteca de classes visuais .vcx. |
| AGETCLASS( ) Function | Exibir bibliotecas de classes na caixa de diálogo Open e criar uma matriz contendo o nome da biblioteca de classes e da classe escolhida. |
| AINSTANCE( ) Function | Colocar instâncias de uma classe em uma matriz de variáveis e retorna o número de instâncias colocadas na matriz. |
| AMEMBERS( ) Function | Colocar os nomes de propriedades, procedimentos e objetos membro de um objeto em uma matriz de variáveis. |
| AMOUSEOBJ( ) Function | Criar uma matriz contendo informações sobre a posição do ponteiro do mouse e o objeto sobre o qual o ponteiro do mouse está posicionado. |
| ASELOBJ( ) Function | Colocar uma referência de objeto para o controle ou contêiner atualmente selecionado que existe no Form Designer, Class Designer ou janela de edição de código em uma matriz de variáveis especificada. |
| AVCXCLASSES( ) Function | Colocar as informações sobre classes em uma biblioteca de classes em uma matriz. |
| _BUILDER System Variable | Contém o nome da aplicação builder do Visual FoxPro. |
| COMCLASSINFO( ) Function | Retornar informações de registro sobre um objeto COM, como um servidor automation do Visual FoxPro. |
| COMPOBJ( ) Function | Comparar as propriedades de dois objetos e retorna True (.T.) se suas propriedades e valores de propriedade são idênticos. |
| CREATE CLASS Command | Abrir o Class Designer, permitindo criar uma nova definição de classe. |
| CREATE CLASSLIB Command | Criar um novo arquivo de biblioteca de classes visuais (.vcx) vazio. |
| CREATEOBJECT( ) Function | Criar um objeto a partir de uma definição de classe ou de uma aplicação habilitada para Automation. |
| DEFINE CLASS Command | Criar uma classe ou subclasse definida pelo usuário e especificar as propriedades, eventos e métodos da classe ou subclasse. |
| DISPLAY OBJECTS Command | Exibir informações sobre um objeto ou um grupo de objetos. |
| GETINTERFACE( ) Function | Fornecer acesso a propriedades, métodos e eventos de objetos COM por meio de early binding. |
| GETOBJECT( ) Function | Ativar um objeto Automation e criar uma referência ao objeto. |
| LIST OBJECTS Command | Exibir continuamente informações sobre um objeto ou um grupo de objetos |
| LOADPICTURE( ) Function | Criar uma referência de objeto para um bitmap, ícone ou arquivo meta do Windows. |
| MODIFY CLASS Command | Abrir o Class Designer, permitindo modificar uma definição de classe existente ou criar uma nova definição de classe. |
| NEWOBJECT( ) Function | Criar uma nova classe ou objeto diretamente a partir de um arquivo de biblioteca de classes visuais (.vcx) ou arquivo de programa (.prg) sem abrir o arquivo. |
| RELEASE CLASSLIB Command | Fechar bibliotecas de classes visuais .vcx contendo definições de classe. |
| REMOVE CLASS Command | Remover uma definição de classe de uma biblioteca de classes visuais .vcx. |
| RENAME CLASS Command | Renomear uma definição de classe contida em uma biblioteca de classes visuais .VCX. |
| SAVEPICTURE( ) Function | Criar um arquivo bitmap (.bmp) a partir de uma referência de objeto de imagem. |
| _SCREEN System Variable | Especificar propriedades e métodos para a janela principal do Visual FoxPro. |
| SET CLASSLIB Command | Abrir uma biblioteca de classes visuais .vcx contendo definições de classe. |
| SET OLEOBJECT Command | Especificar se o Visual FoxPro pesquisa o registro quando um objeto não pode ser localizado. |
| WITH ... ENDWITH Command | Especificar várias propriedades para um objeto. |
