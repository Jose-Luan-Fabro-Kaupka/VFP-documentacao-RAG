# Desenvolvendo aplicativos Visual FoxPro

O Visual FoxPro fornece um conjunto extenso de ferramentas e tecnologias para que você possa construir rapidamente soluções flexíveis com poderosas capacidades de manipulação de dados. O ambiente de desenvolvimento de aplicativos do Visual FoxPro ajuda você em todos os aspectos do desenvolvimento de aplicativos.
