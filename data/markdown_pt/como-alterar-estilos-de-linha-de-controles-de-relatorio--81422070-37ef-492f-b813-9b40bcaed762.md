# Como: alterar estilos de linha de controles de relatório

Você pode alterar o estilo de linha nos controles Line, Rectangle e Rounded Rectangle. Por exemplo, é possível alterar a espessura ou a aparência da linha para esses controles. Você pode alterar o padrão de preenchimento nos controles Rectangle e Rounded Rectangle. Também é possível alterar a forma dos controles Rectangle e Rounded Rectangle para exibir cantos arredondados ou como círculos.

> **Observação:** Os estilos de preenchimento podem não ser exibidos se o controle estiver definido como transparente. Para mais informações, consulte Como: alterar a opacidade de controles de relatório.

### Para alterar o estilo de linha de controles de relatório
- Abra o relatório ou a etiqueta no designer apropriado.
- No designer, selecione o controle de relatório que deseja alterar.
- No menu Format, aponte para Pen e clique na espessura ou no estilo de linha desejado. Dica Você também pode clicar duas vezes no controle de relatório para abrir a caixa de diálogo de propriedades do controle de relatório. Na caixa de diálogo de propriedades do controle de relatório, clique na guia Style, se ela não estiver selecionada. Na lista Style, selecione o estilo de linha desejado. Na lista Weight, selecione a espessura de linha desejada. Para mais informações, consulte Style Tab, Report Control Properties Dialog Box (Report Builder). Observação Se a variável de sistema _REPORTBUILDER não estiver definida para o Report Builder padrão ou estiver definida para um builder de terceiros, a caixa de diálogo do controle de relatório é exibida ou uma caixa de diálogo diferente pode ser exibida. Para mais informações, consulte _REPORTBUILDER System Variable.

### Para alterar o padrão de preenchimento de controles de relatório
- Abra o relatório ou a etiqueta no designer apropriado.
- No designer, selecione o controle de relatório que deseja alterar.
- No menu Format, aponte para Fill e clique no padrão de preenchimento desejado.

> **Observação:** Uma forma que usa o estilo de preenchimento 0 ("vazio" ou "sem preenchimento") sempre será renderizada e aparecerá no designer como transparente, independentemente do modo Backstyle. Por outro lado, uma forma que usa o estilo de preenchimento 1 ("sólido") sempre será renderizada e aparecerá no designer como opaca, independentemente do modo Backstyle. Para mais informações, consulte Como: alterar a opacidade de controles de relatório.

### Para alterar a forma de controles de relatório
- Abra o relatório ou a etiqueta no designer apropriado.
- No designer, clique duas vezes no controle de relatório que deseja alterar. A caixa de diálogo de propriedades do controle de relatório é aberta. Observação Se a variável de sistema _REPORTBUILDER não estiver definida para o Report Builder padrão ou estiver definida para um builder de terceiros, a caixa de diálogo do controle de relatório é exibida ou uma caixa de diálogo diferente pode ser exibida. Para mais informações, consulte _REPORTBUILDER System Variable.
- Na caixa de diálogo de propriedades do controle de relatório, clique na guia Style, se ela não estiver selecionada.
- Na lista Curvature, digite ou selecione o valor de curvatura para o controle de relatório.
- Quando terminar, clique em OK.

Para mais informações, consulte Style Tab, Report Control Properties Dialog Box (Report Builder).
