# Páginas de código suportadas pelo Visual FoxPro

Uma página de código é um conjunto de caracteres específico de um idioma ou plataforma de hardware. Caracteres acentuados não são representados pelos mesmos valores em todas as plataformas e páginas de código. Além disso, alguns caracteres disponíveis em uma página de código não estão disponíveis em outra.
