# Criando aplicativos

Quando você cria um aplicativo Microsoft Visual FoxPro, ele normalmente inclui um ou mais bancos de dados, um programa principal que configura o ambiente do sistema do aplicativo e uma interface do usuário composta por formulários, barras de ferramentas, relatórios e menus.

Para criar um aplicativo, siga estas etapas:
 - Crie um projeto.
- Configure seu aplicativo definindo um ponto de partida, inicializando o ambiente e iniciando o loop de eventos.
- Crie uma interface do usuário para seu aplicativo.
- Crie relatórios e etiquetas para seu aplicativo.

O Application Framework pode criar aplicativos automaticamente que incluem todos os elementos obrigatórios e muitos opcionais que tornam um aplicativo eficaz e fácil de usar. Para obter mais informações, consulte Creating Applications with the Application Framework.
