# Propriedade Docked

Indica se uma barra de ferramentas ou formulário definido pelo usuário está encaixado. Somente leitura em tempo de design e em tempo de execução.

```foxpro
Object.Docked [= lValue]
```

# Valor de retorno
 **lValue**
Especifica um valor lógico que indica se uma barra de ferramentas ou formulário está encaixado. A tabela a seguir lista os valores de lValue . lValue Descrição False (.F.) A barra de ferramentas ou formulário não está encaixado. (Padrão) True (.T.) A barra de ferramentas ou formulário está encaixado.

# Observações

Aplica-se a: objeto Form | objeto ToolBar

Para encaixar um formulário ou barra de ferramentas, use o método Dock. Para obter mais informações, consulte o método Dock.
