# Designer de Relatórios

Você pode criar e modificar relatórios usando o Designer de Relatórios. Quando a janela do Designer de Relatórios está ativa, o Visual FoxPro exibe o menu Relatório e a barra de ferramentas Controles de Relatório. Para obter mais informações, consulte Trabalho com relatórios.

O Designer de Relatórios usa faixas e controles de relatório para gerenciar o layout das informações e dos dados na página do relatório.

# Faixas

As faixas permitem especificar onde e quando os dados são exibidos na página do relatório. Por padrão, o Designer de Relatórios contém três faixas:
 - Cabeçalho da página: exibe informações ou dados uma vez por página, no início da página.
- Detalhes: exibe informações ou dados uma vez para cada registro da tabela subjacente.
- Rodapé da página: exibe informações ou dados uma vez por página, no final da página.

Cada faixa é seguida por um separador que contém seu nome e uma seta apontando para cima, indicando o espaço ocupado pela faixa. Faixas de detalhes são indicadas por setas preenchidas; todas as outras são indicadas por setas vazias.

Você pode adicionar outras faixas ao layout. Para obter mais informações, consulte Trabalho com faixas de relatório.

# Régua

O Designer de Relatórios exibe réguas vertical e horizontal que podem ser usadas para posicionar objetos com mais precisão nas faixas. A escala da régua é determinada pelas configurações de medida do sistema.
