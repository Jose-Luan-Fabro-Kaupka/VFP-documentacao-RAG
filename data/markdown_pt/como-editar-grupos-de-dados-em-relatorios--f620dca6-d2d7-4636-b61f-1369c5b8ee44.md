# Como: editar grupos de dados em relatórios

Você pode editar a expressão de um grupo de dados e suas opções de saída. Você também pode alterar a ordem em que os grupos de dados aparecem.

> **Observação:** Quando você altera a ordem de um grupo de dados, todos os controles em uma banda de grupo movem-se para o novo local. Alterar a ordem dos grupos de dados não altera quaisquer controles previamente definidos. Por exemplo, se os controles estão posicionados relativamente ao topo ou à base de uma banda de grupo, eles permanecem ancorados nessa posição na banda.

### Para editar uma expressão de grupo de dados
- Abra o relatório ou etiqueta no designer apropriado.
- No menu Report, clique em Data Grouping .
- A caixa de diálogo Report Properties é aberta. Observação Se a variável de sistema _REPORTBUILDER não estiver definida para o Report Builder padrão ou estiver definida para um builder de terceiros, a caixa de diálogo Data Grouping é exibida ou uma caixa de diálogo diferente pode ser exibida. Para obter mais informações, consulte Variável de sistema _REPORTBUILDER e Caixa de diálogo Data Grouping .
- Na caixa de diálogo Report Properties, clique na guia Data Grouping se ela não estiver selecionada.
- Na lista Grouping nesting order, selecione a expressão que deseja.
- Na caixa Group on, digite a nova expressão ou altere a expressão no Expression Builder clicando no botão de reticências ( … ).
- Quando terminar, clique em OK .

Para obter mais informações, consulte Guia Data Grouping, caixa de diálogo Report Properties (Report Builder) e Caixa de diálogo Expression Builder.

### Para alterar configurações de saída de um grupo de dados
- Abra o relatório ou etiqueta no designer apropriado.
- No menu Report, clique em Data Grouping . A caixa de diálogo Report Properties é aberta. Observação Se a variável de sistema _REPORTBUILDER não estiver definida para o Report Builder padrão ou estiver definida para um builder de terceiros, a caixa de diálogo Data Grouping é exibida ou uma caixa de diálogo diferente pode ser exibida. Para obter mais informações, consulte Variável de sistema _REPORTBUILDER e Caixa de diálogo Data Grouping .
- Na caixa de diálogo Report Properties, clique na guia Data Grouping se ela não estiver selecionada.
- Na guia Data Grouping, altere as configurações de saída que deseja.
- Quando terminar, clique em OK .

Para obter mais informações, consulte Guia Data Grouping, caixa de diálogo Report Properties (Report Builder).

### Para alterar a ordem da expressão de grupo de dados
- Abra o relatório ou etiqueta no designer apropriado.
- No menu Report, clique em Data Grouping . A caixa de diálogo Report Properties é aberta. Observação Se a variável de sistema _REPORTBUILDER não estiver definida para o Report Builder padrão ou estiver definida para um builder de terceiros, a caixa de diálogo Data Grouping é exibida ou uma caixa de diálogo diferente pode ser exibida. Para obter mais informações, consulte Variável de sistema _REPORTBUILDER e Caixa de diálogo Data Grouping .
- Na caixa de diálogo Report Properties, clique na guia Data Grouping se ela não estiver selecionada.
- Na lista Group nesting order, arraste o botão de movimentação à esquerda da expressão de grupo que deseja para sua nova posição.
- Quando terminar, clique em OK .

Para obter mais informações, consulte Guia Data Grouping, caixa de diálogo Report Properties (Report Builder).
