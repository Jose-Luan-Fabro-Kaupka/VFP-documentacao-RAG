# Janela Go To Definition

Exibe várias definições de elementos de código das quais você pode escolher ao pesquisar uma definição de código.

A janela Go To Definition aparece depois que a seleção do comando View Definition resulta em várias definições de elementos de código. Você pode selecionar o comando View Definition no menu de atalho que aparece quando você clica com o botão direito dentro da janela Editing de um programa.
 **File**
Lista o nome e o local do arquivo da definição de código.
**Class.Method (Line)**
Lista a classe, o método e o número da linha, se disponível, da definição de código.
**Code**
Lista o código que contém a definição de código.
**Go To**
Move para o local da definição de código selecionada.
