# Construção de biblioteca de API

Esta seção inclui tópicos sobre rotinas de biblioteca de API, eventos do sistema e códigos de tecla.

# Nesta seção
 **API Library Routines A-Z**
Contém uma listagem alfabética das rotinas de biblioteca de API.
**API Library Routines by Category**
Contém uma lista categorizada das rotinas de biblioteca de API.
**Visual FoxPro System Events (API Library Construction)**
Lista cada evento do Microsoft Visual FoxPro junto com o layout de seus campos de registro de evento e uma descrição de quando o evento ocorre.
**Visual FoxPro Key Codes (API Library Construction)**
Fornece informações sobre teclas do teclado e como o Visual FoxPro as interpreta dependendo do modificador com o qual são combinadas.

# Seções relacionadas
 **Accessing the Visual FoxPro API**
Descreve como você pode escrever seu próprio controle Microsoft ActiveX ou biblioteca de link dinâmico específica do Visual FoxPro (arquivo .fll). Ao chamar as funções disponíveis na API disponível no Visual FoxPro, você pode criar controles ou bibliotecas que estão fortemente integrados e otimizados para uso no Visual FoxPro
**Extending Visual FoxPro with External Libraries**
Discute como você pode adicionar controles Microsoft ActiveX (arquivos .ocx) à sua aplicação facilmente, fornecendo novos objetos para usar em formulários, para subclassificar e para gerenciar a forma como você trabalha com controles nativos do Visual FoxPro.
**Language Reference (Visual FoxPro)**
Inclui tópicos sobre controles, objetos, propriedades, métodos, eventos, instruções, funções e constantes.
**Developing Visual FoxPro Applications**
Inclui informações conceituais sobre como desenvolver aplicações Visual FoxPro, instruções para criar bancos de dados e a interface do usuário e outras tarefas necessárias para criar aplicações Visual FoxPro.
**Programming in Visual FoxPro**
Descreve como você pode acessar todo o poder do Visual FoxPro criando aplicações. Compreender técnicas de programação orientada a objetos e o modelo orientado a eventos pode maximizar sua produtividade de programação.
