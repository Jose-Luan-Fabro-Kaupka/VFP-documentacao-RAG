# Como: executar exemplos Solution do Visual FoxPro

Você pode executar exemplos Solution do Visual FoxPro a partir do Gerenciador de Painéis de Tarefas do Visual FoxPro, que inclui funcionalidade para pesquisar e instalar exemplos adicionais.

### Para executar exemplos Solution
- Para abrir o Gerenciador de Painéis de Tarefas , selecione Painel de Tarefas no menu Ferramentas.
- Na barra de ferramentas do Gerenciador de Painéis de Tarefas, selecione Exemplos Solution .
- Em uma das categorias de exemplos, escolha um exemplo que você deseja executar.
- Para executar o exemplo, clique no hiperlink do exemplo. Para ver o código do exemplo, clique no ícone Clique aqui para ver o código localizado à direita da descrição do exemplo.

Para obter mais informações sobre o Gerenciador de Painéis de Tarefas, consulte Gerenciador de Painéis de Tarefas.

Você também pode executar os exemplos Solution a partir do aplicativo de exemplo Solution localizado em ...\Samples\Solution\Solution.app.
