# Como: criar arquivos em projetos

Depois de criar um projeto para seu aplicativo, você pode criar arquivos para novos componentes do aplicativo, como tabelas, consultas, programas ou arquivos de texto, em seu projeto.

### Para criar um arquivo para um novo componente do projeto
- Abra o projeto do seu aplicativo.
- No Project Manager , expanda o nó na hierarquia do projeto que contém o tipo de componente para o qual você deseja criar um arquivo.
- Clique no tipo de componente para o qual deseja criar um arquivo.
- No menu Projeto, clique em Novo arquivo . Dica Você também pode clicar em Novo no Project Manager .
- Execute uma das seguintes ações: Para iniciar um assistente para o componente, clique no botão do assistente. Para criar um arquivo em branco para o componente, clique no botão do novo componente.

Para obter mais informações, consulte Janela Project Manager.
