# Método CheckOut

Faz check-out de um arquivo em um projeto sob controle de código-fonte, permitindo que você faça alterações no arquivo.

```foxpro
Object.CheckOut()
```

# Observações

Aplica-se a: File Object (Visual FoxPro)

Verdadeiro (.T.) é retornado se o arquivo foi feito check-out com sucesso do controle de código-fonte. Falso (.F.) é retornado se o arquivo não pôde ser feito check-out ou o projeto não está sob controle de código-fonte.
