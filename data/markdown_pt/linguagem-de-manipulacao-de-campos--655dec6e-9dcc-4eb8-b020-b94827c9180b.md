# Linguagem de manipulação de campos

Esses comandos e funções permitem que você manipule campos em uma tabela.

| Use | Para |
| --- | --- |
| AFIELDS( ) Function | Armazenar informações sobre a estrutura da tabela atual em um array e retornar o número de campos. |
| BLANK Command | Limpar dados dos campos especificados. |
| DELETED( ) Function | Indicar se um registro está marcado para exclusão. |
| FCOUNT( ) Function | Retornar o número de campos em uma tabela. |
| FIELD( ) Function | Retornar o nome de um campo, referenciado por número. |
| FLDLIST( ) Function | Incluída para compatibilidade com dBASE. |
| FSIZE( ) Function | Retornar o tamanho em bytes de um campo ou arquivo especificado. |
| GATHER Command | Substituir os dados em um registro por dados de uma fonte especificada. |
| ISBLANK( ) Function | Determinar se uma expressão está em branco. |
| LUPDATE( ) Function | Retornar a data em que uma tabela foi atualizada pela última vez. |
| NDX( ) Function | Retornar o nome de um arquivo de índice (.IDX) aberto para a tabela atual ou especificada. |
| SCATTER Command | Copiar dados de um registro para um destino especificado. |
| SET BLOCKSIZE Command | Especificar como alocar espaço em disco para armazenamento de campos memo. |
| SET EXACT Command | Especificar as regras para comparar duas cadeias de caracteres de comprimentos diferentes. |
| SET NOCPTRANS Command | Impedir a tradução para uma página de código diferente para campos selecionados em uma tabela aberta. |
| SET TEXTMERGE Command | Habilitar ou desabilitar a avaliação de campos, variáveis, elementos de array, funções ou expressões que estão entre delimitadores de mesclagem de texto e especificar a saída de mesclagem de texto. |
| SET TEXTMERGE DELIMITERS Command | Especificar os delimitadores de mesclagem de texto. |
| SYS(14) - Index Expression | Retornar a expressão de índice de um arquivo de índice .idx de entrada única aberto ou expressões de índice para tags em arquivos de índice compostos .cdx. |
