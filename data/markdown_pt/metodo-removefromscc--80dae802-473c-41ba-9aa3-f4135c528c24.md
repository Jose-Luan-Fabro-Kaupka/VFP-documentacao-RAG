# Método RemoveFromSCC

Remove um arquivo em um projeto do controle de código-fonte.

```foxpro
Object.RemoveFromSCC()
```

# Observações

Aplica-se a: File Object (Visual FoxPro)

O método RemoveFromSCC retorna true (.T.) se o arquivo for removido com sucesso do controle de código-fonte; caso contrário, retorna false (.F.).
