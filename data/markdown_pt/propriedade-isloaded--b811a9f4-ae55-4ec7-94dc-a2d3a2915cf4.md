# Propriedade IsLoaded

Indica se o objeto XMLAdapter está associado a um documento XML. Somente leitura.

```foxpro
XMLAdapter.IsLoaded [= lValue]
```

# Valor de retorno
 **lValue**
Tipo de dados lógico. A tabela a seguir lista os valores de lValue . lValue Descrição False (.F.) XMLAdapter não está associado a um documento XML. (Padrão) True (.T.) XMLAdapter está associado a um documento XML.
