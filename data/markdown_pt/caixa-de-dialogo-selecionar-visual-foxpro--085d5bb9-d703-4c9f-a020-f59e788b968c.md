# Caixa de diálogo Selecionar (Visual FoxPro)

Permite selecionar um serviço Web XML e inserir o código correspondente em um programa ou em uma janela de edição de código.

Essa caixa de diálogo aparece quando você digita os caracteres ws e, em seguida, pressiona a BARRA DE ESPAÇOS na janela de edição de um programa.
 **Select an XML Web service**
Especifica o serviço Web XML para o qual será gerado o código proxy.
**Use Custom class**
Especifica se deve ser incluído código que usa a classe básica WSHandler para encapsular chamadas de cliente SOAP (Simple Object Access Protocol). Caso contrário, é gerado código para chamar diretamente o cliente COM do SOAP Toolkit 3.0.
**Include error handling**
Especifica se deve ser incluído tratamento estruturado de erros usando código TRY...CATCH...FINALLY ao redor das chamadas de cliente SOAP. Para obter mais informações, consulte o comando TRY...CATCH...FINALLY.
**New**
Abre a caixa de diálogo Registro de Serviços Web XML do Visual FoxPro para que você possa registrar um novo serviço Web XML. Para obter mais informações, consulte a caixa de diálogo Registro de Serviços Web XML do Visual FoxPro.
