# Assistente Mail Merge

O assistente Mail Merge cria uma fonte de dados, como nomes ou endereços, para um documento mesclado do Microsoft Word, como uma carta modelo, etiquetas de correspondência, envelopes ou catálogos, ou um arquivo de texto que pode ser usado por qualquer processador de texto.

O Visual FoxPro Setup pode instalar a funcionalidade ODBC por meio do Visual FoxPro OLE DB Provider. Para obter informações sobre documentos mesclados, consulte a Ajuda do Microsoft Word. Para obter mais informações, consulte OLE DB Provider for Visual FoxPro.

 Para acessar o assistente Mail Merge
 - No menu Ferramentas, escolha Assistentes e clique em Mail Merge .

# Etapa 1 – Selecionar campos

Esta etapa permite especificar os campos que contêm as informações que você deseja usar com o documento mesclado, que pode ser um documento do Word ou um arquivo de outro processador de texto. Você pode selecionar campos de uma única tabela ou exibição apenas.

# Etapa 2 - Escolher processador de texto

Nesta etapa, você especifica se criará um arquivo para uso com o Word ou um arquivo genérico delimitado por vírgulas para uso com outro processador de texto.

Você deve ter uma versão atual do Word instalada em seu computador se selecionar Microsoft Word. Se você selecionar Arquivo de texto delimitado por vírgulas, o assistente ignorará as Etapas 3 e 4 e irá diretamente para a tela Concluir.

# Etapa 3 - Selecionar tipo de documento

Esta etapa permite criar um novo documento, como uma lista de correspondência, ou adicionar a um documento existente, como uma lista de nomes.

# Etapa 4 - Escolher estilo de documento

Nesta etapa, você escolhe um tipo de documento a criar.
 **Carta modelo**
Permite criar ou usar um modelo de carta no qual os dados do arquivo do Visual FoxPro especificado serão mesclados.
**Etiqueta**
Permite criar ou usar um modelo de etiqueta no qual os dados do arquivo do Visual FoxPro especificado serão mesclados.
**Envelope**
Permite criar ou usar um modelo de envelope no qual os dados do arquivo do Visual FoxPro especificado serão mesclados.
**Catálogo**
Permite criar ou usar um arquivo que contém etiquetas, como Item ou Color ou Catalog number , no qual os dados do arquivo do Visual FoxPro especificado serão mesclados.

# Etapa 5 - Concluir

Esta etapa permite salvar os dados como um arquivo de texto ou continuar no Word para especificar como os dados do Visual FoxPro são mesclados no documento mesclado existente ou novo.

Se você escolheu criar um documento do Word, o assistente abrirá o documento no Word. Se você escolheu criar um arquivo de texto, o assistente solicitará que você salve seu arquivo delimitado por vírgulas.
