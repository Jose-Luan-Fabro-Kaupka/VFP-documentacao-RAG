# Suporte a arrastar e soltar OLE em tempo de design

O suporte em tempo de design para arrastar e soltar OLE no Visual FoxPro torna o desenvolvimento de aplicações ainda mais rápido do que em versões anteriores. Arrastar e soltar OLE facilita soltar arquivos no Project Manager e nos designers do Visual FoxPro a partir do Windows Explorer. O texto pode ser facilmente movido ou copiado de outras aplicações para a Command Window, os editores de texto do Visual FoxPro e a Properties Window.

A tabela a seguir lista os recursos de tempo de design do Visual FoxPro que oferecem suporte a arrastar e soltar OLE com uma descrição do suporte.

| Interface item | Description |
| --- | --- |
| Command Window | Destino de soltar para arquivos, origem de arrastar e destino de soltar para texto. Se um arquivo criado no Visual FoxPro é solto na Command window, o arquivo é aberto com o comando Visual FoxPro adequado. Por exemplo, se um banco de dados é solto na Command window, o Visual FoxPro emite os comandos OPEN DATABASE e MODIFY DATABASE para abrir o arquivo para modificação. Se uma tabela é solta na Command window, a tabela é aberta com os comandos USE ... AGAIN e BROWSE. Se SET EXCLUSIVE estiver ON, a tabela é aberta para uso exclusivo. Se SET EXCLUSIVE estiver OFF, a tabela é aberta para uso compartilhado. Outros arquivos do Visual FoxPro são abertos com o comando MODIFY adequado — formulários são abertos com MODIFY FORM, consultas são abertas com MODIFY QUERY, arquivos de texto e de cabeçalho (.H) são abertos com MODIFY FILE, e assim por diante. Se um arquivo criado em outra aplicação é solto na Command window, o arquivo é aberto na aplicação com a qual está associado. Por exemplo, soltar uma planilha do Microsoft Excel na Command window inicia o Excel e abre a planilha. |
| Project Manager | Destino de soltar para arquivos. Os arquivos são adicionados às categorias adequadas do Project Manager, com base em suas extensões de arquivo. Se um arquivo com uma extensão que o Visual FoxPro não reconhece é solto no Project Manager, o arquivo é adicionado à categoria Other. Se uma tabela contida em um banco de dados é solta no Project Manager, o banco de dados é adicionado à categoria Databases do item Data e é marcado como Excluded. Se uma tabela livre é solta no Project Manager, a tabela é adicionada à categoria Free Tables do item Data e é marcada como Excluded. Se um banco de dados é solto no Project Manager, o banco de dados é adicionado à categoria Databases do item Data e é marcado como Excluded. Embora arrastar e soltar OLE facilite adicionar arquivos ao Project Manager, lembre-se de que o Project Manager adiciona automaticamente quaisquer arquivos referenciados ao projeto quando você compila o projeto. Por exemplo, se um programa que você adiciona ao projeto executa um segundo programa, o segundo programa é adicionado automaticamente ao projeto quando o projeto é compilado. Não é necessário adicionar manualmente o segundo programa ao projeto. |
| Text Editors | Origem de arrastar e destino de soltar para texto. Editores de texto incluem janelas de edição abertas com MODIFY COMMAND, MODIFY FILE e MODIFY MEMO, a Command window, janelas de edição de código nos designers Form, Class, Menu e Data Environment e o editor Stored Procedure no Database Designer. |
| Debugger | Origem de arrastar e destino de soltar para texto. A caixa de texto da Watch window e a lista Name são origens de arrastar e destinos de soltar para texto. A Trace window e a Debug Output window são origens de arrastar para texto. |
| Database Designer | Destino de soltar para arquivos. Soltar uma tabela no Database Designer adiciona a tabela ao banco de dados atual. |
| Class Designer | Destino de soltar para texto e arquivos. Por padrão, soltar texto em um objeto contêiner no Class Designer cria um label com o texto como valor de sua propriedade Caption. Você pode alterar o controle padrão criado quando o texto é solto no Form Designer na guia Field Mapping da caixa de diálogo Options. Se você soltar texto em um controle que não é contêiner (um controle CheckBox, CommandButton, Header, Label ou OptionButton), a propriedade Caption é definida como o texto. Soltar um arquivo gráfico (.ani, .bmp, .cur, .gif, .ico ou .jpg) no Class Designer cria um controle Image com a propriedade Picture definida como o nome do arquivo gráfico. |
| Data Environment Designer | Destino de soltar para arquivos. Soltar uma tabela no Data Environment Designer adiciona a tabela ao ambiente de dados. Soltar um banco de dados no Data Environment Designer exibe a caixa de diálogo Add Table or View, permitindo adicionar uma tabela ou exibição ao ambiente de dados. |
| Query Designer | Destino de soltar para arquivos. Soltar uma tabela no Query Designer adiciona a tabela à consulta. Soltar um banco de dados no Query Designer exibe a caixa de diálogo Add Table or View, permitindo adicionar uma tabela ou exibição à consulta. |
| View Designer | Destino de soltar para arquivos. Soltar uma tabela no View Designer adiciona a tabela à exibição. Soltar um banco de dados no View Designer exibe a caixa de diálogo Add Table or View, permitindo adicionar uma tabela ou exibição à exibição. |
| Properties window | Destino de soltar para texto. Você pode soltar texto na caixa de texto que aparece na parte superior da Properties window quando uma propriedade de tempo de design é selecionada. |
| Component Gallery | Origem de arrastar e destino de soltar para arquivos. Você pode arrastar objetos da Component Gallery e soltá-los no Form Designer. Você também pode arrastar arquivos da Component Gallery e soltá-los no Project Manager. Arquivos podem ser soltos na Component Gallery. |
