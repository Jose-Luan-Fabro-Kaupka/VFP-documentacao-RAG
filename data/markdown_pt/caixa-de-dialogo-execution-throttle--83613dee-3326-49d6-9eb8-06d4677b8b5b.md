# Caixa de diálogo Execution Throttle

Permite especificar o atraso em segundos entre a execução de cada linha de código localizada na Trace Window. Esta caixa de diálogo aparece quando você seleciona Throttle no menu Debug, Debugger Window.
 **Delay (seconds)**
Permite definir o atraso de execução de 0,0 segundos a 5,0 segundos entre cada linha de código.
