# Como: visualizar tabelas abertas em sessões de dados

Você pode ver as tabelas que estão atualmente abertas em uma sessão de dados. Para obter mais informações sobre sessões de dados, consulte Como: usar sessões de dados.

### Para ver tabelas abertas em uma sessão de dados
- No menu Window, escolha Data Session. -OU-
- Use o comando SET sem nenhum argumento.

A janela Data Session é aberta e exibe o nome da sessão de dados atual, os aliases de tabela de todas as tabelas abertas e outras opções.

Para obter mais informações, consulte Visão geral do comando SET e Janela Data Session.
