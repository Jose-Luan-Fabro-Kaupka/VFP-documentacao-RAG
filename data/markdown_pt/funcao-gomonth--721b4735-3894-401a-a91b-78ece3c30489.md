# Função GOMONTH( )

Retorna a data que está um número especificado de meses antes ou depois de uma expressão Date ou Date/Time fornecida.

```foxpro
GOMONTH(dExpression | tExpression, nNumberOfMonths)
```

#### Parâmetros
 **dExpression**
Especifica uma expressão de data para a qual GOMONTH( ) retorna a data.
**tExpression**
Especifica uma expressão de data/hora para a qual GOMONTH( ) retorna a data.
**nNumberOfMonths**
Especifica o número de meses a partir da data ou data/hora. Se nNumberOfMonths for positivo, GOMONTH( ) retorna uma data que está nNumberOfMonths meses depois da data ou data/hora. Se nNumberOfMonths for negativo, GOMONTH( ) retorna uma data que está nNumberOfMonths meses antes da data ou data/hora. Por exemplo, -1 significa -31 dias.

# Valor de retorno

Date

# Observações

GOMONTH( ) não suporta datas anteriores a 1753.

# Exemplo

```foxpro
SET CENTURY ON
STORE GOMONTH({^1998-02-16}, 5) TO gdDeadLine
CLEAR
? gdDeadLine  && Displays 07/16/1998
? GOMONTH({^1998-12-31}, 2)  && Displays 02/28/1999
? GOMONTH({^1998-12-31}, -2)  && Displays 10/31/1998
```
