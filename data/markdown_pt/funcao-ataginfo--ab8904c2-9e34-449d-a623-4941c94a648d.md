# Função ATAGINFO( )

Cria uma matriz que contém informações sobre arquivos de índice da tabela selecionada.

```foxpro
ATAGINFO(ArrayName [,cCDXName [, nWorkArea | cTableAlias]])
```

#### Parâmetros
 **ArrayName**
Especifica o nome da matriz a criar. O Visual FoxPro cria a matriz se ela ainda não existir.
**cCDXName**
Especifica o nome do arquivo de índice composto (.cdx) para o qual retornar informações. Observação Especificar uma cadeia de caracteres vazia ("") retorna o número de tags em todos os arquivos .cdx abertos e em todos os arquivos de índice independentes (.idx) abertos da tabela selecionada.
**nWorkArea**
Especifica a área de trabalho que contém a tabela para a qual retornar informações.
**cTableAlias**
Especifica o alias da tabela para a qual retornar informações. Observação Omitir cTableAlias e nWorkArea usa a tabela na área de trabalho atual.

# Valor de retorno

Numérico. ATAGINFO( ) retorna o número de tags de índice em arquivos de índice composto (.cdx) ou em arquivos de índice independentes de chave única (.idx) abertos da tabela atual.

# Observações

A tabela a seguir descreve as informações armazenadas na matriz que ATAGINFO( ) cria.

| Coluna | Descrição | Tipo de dados |
| --- | --- | --- |
| 1 | Nome da tag de índice em um arquivo .cdx ou nome do arquivo de índice para arquivos .idx | Character |
| 2 | Tipo da tag de índice | Character |
| 3 | Expressão de chave de índice | Character |
| 4 | Expressão de filtro | Character |
| 5 | Ordem do índice conforme criado (Ascending ou Descending) | Character |
| 6 | Sequência de collate | Character |
