# Função AT_C( )

Retorna a posição numérica inicial da primeira ocorrência de uma expressão de caracteres ou campo memo dentro de outra expressão de caracteres ou campo memo, contando a partir do caractere mais à esquerda.

```foxpro
AT_C(cSearchExpression, cExpressionSearched [, nOccurrence])
```

#### Parâmetros
 **cSearchExpression**
Especifica a expressão de caracteres que AT_C( ) busca em cExpressionSearched.
 **cExpressionSearched**
Especifica a expressão de caracteres em que cSearchExpression é buscada. Tanto cSearchExpression quanto cExpressionSearched podem ser campos memo de qualquer tamanho.
 **nOccurrence**
Especifica qual ocorrência (primeira, segunda, terceira e assim por diante) de cSearchExpression é buscada em cExpressionSearched. Por padrão, AT_C( ) busca a primeira ocorrência de cSearchExpression (nOccurrence = 1). Incluir nOccurrence permite buscar ocorrências adicionais de cSearchExpression em cExpressionSearched. AT_C( ) retorna 0 se nOccurrence for maior que o número de vezes que cSearchExpression ocorre em cExpressionSearched.

# Valor de retorno

Numeric

# Observações

AT_C( ) busca na segunda expressão de caracteres a primeira ocorrência da primeira expressão de caracteres. Em seguida, retorna um inteiro indicando a posição do primeiro caractere na expressão de caracteres encontrada. Se a expressão de caracteres não for encontrada, AT_C( ) retorna 0.

AT_C( ) foi projetada para expressões contendo caracteres de dois bytes. Se a expressão contém apenas caracteres de um byte, AT_C( ) é equivalente a AT( ).

A busca realizada por AT_C( ) diferencia maiúsculas de minúsculas. Para realizar uma busca que não diferencia maiúsculas de minúsculas, use ATCC( ).

Esta função é útil para manipular conjuntos de caracteres de dois bytes para idiomas como Hiragana e Katakana.
