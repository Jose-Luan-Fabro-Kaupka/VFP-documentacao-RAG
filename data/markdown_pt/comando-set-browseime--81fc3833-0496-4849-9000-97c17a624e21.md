# Comando SET BROWSEIME

Especifica se o Input Method Editor é aberto quando você navega para uma caixa de texto em uma janela Browse.

```foxpro
SET BROWSEIME ON | OFF
```

#### Parâmetros
 **ON**
(Padrão para o Windows em chinês tradicional) Abre o Input Method Editor quando você navega para uma caixa de texto em uma janela Browse.
**OFF**
(Padrão para o Windows em coreano) O Input Method Editor não é aberto quando você navega para uma caixa de texto em uma janela Browse.

# Observações

SET BROWSEIME corresponde à caixa de seleção Browse IME control na guia General da caixa de diálogo Options Dialog Box (Visual FoxPro).

Este comando não tem efeito se você não estiver trabalhando em um ambiente de conjunto de caracteres de byte duplo (DBCS).
