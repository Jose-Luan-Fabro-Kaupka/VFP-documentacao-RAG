# Guia List Items, Combo Box Builder

Esta guia no Combo Box Builder especifica os itens que entram na caixa de combinação.
 **Fill the List With**
Especifica o tipo de dados com os quais preencher a lista da caixa de combinação. A seleção feita aqui determina quais opções aparecem nesta guia. Escolha Fields From a Table or View, Data Entered by Hand ou Values From an Array.
**Fields From a Table or View**
Permite selecionar tabelas livres ou tabelas e views de um banco de dados para usar na caixa de combinação.
**Databases and Tables**
Lista os bancos de dados disponíveis e oferece a opção de selecionar Free Tables. Para localizar um banco de dados ou tabela, clique no botão de diálogo, que exibe a caixa de diálogo Open. Esta opção aparece quando você seleciona Fields From a Table or View na lista suspensa Fill the List With.
**List of Tables**
Exibe tabelas e views no banco de dados selecionado ou tabelas livres. Esta opção aparece quando você seleciona Fields From a Table or View na lista suspensa Fill the List With.
**Available Fields**
Mostra todos os campos na tabela ou view selecionada. Selecione os campos cujos dados você deseja na caixa de combinação. Esta opção aparece quando você seleciona Fields From a Table or View na lista suspensa Fill the List With.
**Arrow Buttons**
Adiciona campos a e remove campos da caixa Selected Fields. Esta opção aparece quando você seleciona Fields From a Table or View na lista suspensa Fill the List With. Você também pode clicar duas vezes em um item para movê-lo entre as listas.
**Selected Fields**
Exibe os campos que serão usados para preencher a lista da caixa de combinação. A ordem dos campos selecionados corresponderá à ordem das colunas na caixa de combinação. Esta opção aparece quando você seleciona Fields From a Table or View na lista suspensa Fill the List With.
**Data Entered By Hand**
Permite selecionar o número de colunas a serem exibidas na caixa de combinação e inserir as informações a serem exibidas.
**Columns**
Especifica o número de colunas na lista da caixa de combinação. Esta opção aparece quando você seleciona Data Entered By Hand na lista suspensa Fill the List With.
**Column Grid**
Exibe as colunas nas quais inserir dados. Digite os dados nas células da coluna. Você pode dimensionar as colunas arrastando as linhas entre elas com o mouse. Esta opção aparece quando você seleciona Data Entered By Hand na lista suspensa Fill the List With.
**Values From An Array**
Permite usar dados de um array na caixa de combinação.
**Array Name**
Especifica o nome de um array. Esta opção aparece quando você seleciona Values From An Array na lista suspensa Fill the List With.
**Entire Array**
Especifica que o array inteiro preencherá a lista da caixa de combinação. Esta opção aparece quando você seleciona Values From An Array na lista suspensa Fill the List With.
**Range Of The Array**
Especifica que uma parte do array preencherá a lista da caixa de combinação com base nas configurações de coluna e linha. Esta opção aparece quando você seleciona Values From An Array na lista suspensa Fill the List With.
**Column and Row Range**
Especifica a coluna e a linha inicial e final como intervalo do array. Essas opções estão disponíveis apenas quando você seleciona Range of the Array. Esta opção aparece quando você seleciona Values From An Array na lista suspensa Fill the List With.
