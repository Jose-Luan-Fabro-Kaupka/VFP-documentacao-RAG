# Como: acrescentar dados com o Import Wizard

O Import Wizard faz uma série de perguntas e acrescenta os dados do arquivo de origem com base nas suas respostas. Usando o assistente, você pode optar por mapear os campos de origem para os campos de destino alterando os números das colunas.

### Para acrescentar de um arquivo com o Import Wizard
- No menu File, escolha Import .
- Na caixa de diálogo Import, escolha Import Wizard .
- Siga as instruções nas telas do assistente.
