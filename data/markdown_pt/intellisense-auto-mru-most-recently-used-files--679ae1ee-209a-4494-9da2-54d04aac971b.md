# IntelliSense Auto MRU (Most Recently Used) Files

Quando você digita certos comandos do Visual FoxPro, pode usar o IntelliSense para visualizar uma lista de arquivos disponíveis e usados recentemente do tipo apropriado para cada comando.

A tabela a seguir lista os comandos e os tipos de arquivo padrão que o IntelliSense pesquisa e exibe.

| Comando | IntelliSense exibe arquivos com os seguintes tipos |
| --- | --- |
| CD | Arquivos no caminho atual ou especificado. |
| DO | .prg, .mpr, .qpr, .fxp, .app, .exe |
| DO FORM | .scx |
| LABEL FORM | .frx, .lbx |
| MODIFY CLASS | .vcx |
| MODIFY COMMAND | .prg, .mpr, .qpr |
| MODIFY DATABASE | .dbc |
| MODIFY FILE | Qualquer tipo e extensão de arquivo. |
| MODIFY FORM | .scx |
| MODIFY LABEL | .lbx |
| MODIFY MENU | .mnx |
| MODIFY PROJECT | .pjx |
| MODIFY QUERY | .qpr |
| MODIFY REPORT | .frx |
| MODIFY VIEW | Views locais e remotas. |
| OPEN DATABASE | .dbc |
| REPORT FORM | .frx, .lbx |
| SET DATABASE | .dbc |
| USE | .dbf, view |
