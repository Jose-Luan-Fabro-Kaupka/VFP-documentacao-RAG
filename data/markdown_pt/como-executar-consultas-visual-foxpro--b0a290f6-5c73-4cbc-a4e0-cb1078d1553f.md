# Como: executar consultas (Visual FoxPro)

Depois de terminar de construir sua consulta, você pode executá-la para obter os resultados. O Visual FoxPro executa a instrução SQL SELECT gerada pelo Query Designer e envia os resultados para uma janela browse. Para obter mais informações sobre como construir consultas, consulte Como: criar consultas (Visual FoxPro).

### Para executar uma consulta no Query Designer
- Abra a consulta no Query Designer antes de executá-la.
- No menu Query, selecione Run Query.

O Visual FoxPro exibe os resultados da consulta em uma janela browse.

Você também pode executar uma consulta no Project Manager sem abrir a consulta, selecionando o nome da consulta no nó Queries na visualização em árvore de arquivos e escolhendo Run.
