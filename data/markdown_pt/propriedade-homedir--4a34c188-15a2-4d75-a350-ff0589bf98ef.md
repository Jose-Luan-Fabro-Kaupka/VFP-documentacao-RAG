# Propriedade HomeDir

Especifica o diretório base de um projeto.

```foxpro
Object.HomeDir[ = cDirectory]
```

# Valor de retorno
 **cDirectory**
Especifica o diretório base do projeto. O valor padrão é o diretório em que o arquivo de projeto (.pjx) está localizado.

# Observações

Aplica-se a: Project Object (Visual FoxPro)

O diretório base de um projeto é o caminho relativo para todos os arquivos no projeto. A propriedade HomeDir corresponde ao diretório na caixa de texto Home na guia Project da caixa de diálogo Project Information Dialog Box.
