# Caixa de diálogo Quick Report

Permite selecionar campos e um layout de campos para um relatório.
 **Field layout**
Especifica se os campos serão exibidos da esquerda para a direita na página como colunas ou de cima para baixo como linhas.
**Titles**
Determina se os nomes dos campos serão exibidos como títulos em controles de etiqueta que aparecem acima ou ao lado do campo correspondente.
**Add alias**
Adiciona o alias a todos os nomes de campos automaticamente no Report Designer.
**Add table to data environment**
Adiciona a tabela ao ambiente de dados automaticamente.
**Fields**
Exibe a caixa de diálogo Field Picker para que você possa selecionar os campos a incluir no relatório. Para mais informações, consulte a caixa de diálogo Field Picker .
