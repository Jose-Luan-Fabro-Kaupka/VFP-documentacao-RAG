# Comando SET COLOR TO

Incluído para compatibilidade com versões anteriores. Use o comando SET COLOR OF SCHEME em vez disso.

Especifica as cores de menus e janelas definidos pelo usuário.

```foxpro
SET COLOR TO [[standard]
	[, [enhanced] [, [border]]]]
```

# Observações

SET COLOR TO está incluído para compatibilidade com versões anteriores. Use SET COLOR OF SCHEME em vez disso.

SET COLOR TO afeta vários pares de cores do esquema de cores número 1 e esquema de cores número 2. Use SET COLOR OF SCHEME para controle máximo sobre o ambiente de cores.
