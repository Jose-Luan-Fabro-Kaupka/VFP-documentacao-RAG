# Exemplos de solução de dados

Estes exemplos de Solution ilustram como realizar tarefas de desenvolvimento de aplicativos usando dados.

# Nesta seção
 **Create a Cursor from an XML DataSet Sample**
Demonstra como criar um cursor a partir de um XML DataSet usando as classes CursorAdapter e XMLAdapter e como vincular os dados a controles em um formulário.
**Load and Generate XML Using the XMLAdapter Class Sample**
Demonstra alguns dos muitos usos da classe XMLAdapter, como selecionar um arquivo XML para criar cursors ou gerar XML de múltiplas tabelas.
**Manage Data Access Using CursorAdapters Sample**
Demonstra como objetos CursorAdapter recuperam dados de três tipos diferentes de fontes de dados.
