# Como: fechar tabelas

Quando você terminar de trabalhar com tabelas, feche-as.

### Para fechar uma tabela
- No menu Window, clique em Data Session .
- Na janela Data Session, clique no alias da tabela que deseja fechar e depois em Close . A tabela é fechada.

### Para fechar uma tabela programaticamente
- Use o comando CLOSE com a palavra-chave TABLES. Observação CLOSE TABLES fecha todas as tabelas no banco de dados selecionado atualmente ou todas as tabelas livres em todas as work areas se nenhum banco de dados estiver aberto.

Para obter mais informações, consulte CLOSE Commands.
