# Caixa de diálogo Database Properties

Esta caixa de diálogo permite escolher o tipo de objeto de banco de dados exibido no Database Designer. Você pode escolher entre tabelas, relações, exibições locais e exibições remotas. Também pode adicionar um comentário. Use esta caixa de diálogo para mostrar ou ocultar objetos do banco de dados no esquema do banco de dados.

Esta caixa de diálogo aparece quando você seleciona Properties no menu Database.
 **Event**
Lista os eventos disponíveis.
**Set Events On**
Especifica se DBC Events estão habilitados em tempo de design e em tempo de execução na sessão atual do Visual FoxPro.
**Events File**
Permite especificar um arquivo externo que contenha código de DBC Event.
**Botão Edit Code**
Abre o editor do Visual FoxPro para que você possa adicionar código ao DBC Event atualmente selecionado no arquivo de procedimentos armazenados ou no arquivo externo especificado.
**Tables**
Mostra ou oculta as tabelas no esquema do banco de dados.
**Relations**
Mostra ou oculta as linhas de relação entre tabelas no esquema do banco de dados.
**Local Views**
Mostra ou oculta as exibições criadas sobre dados armazenados em tabelas locais.
**Remote Views**
Mostra ou oculta as exibições criadas sobre dados armazenados em uma fonte de dados remota.
**Comment**
Fornece espaço para digitar um comentário sobre o esquema do banco de dados.
