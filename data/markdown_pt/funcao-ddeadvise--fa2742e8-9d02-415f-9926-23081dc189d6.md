# Função DDEAdvise( )

Cria um link de notificação ou um link automático usado em uma troca dinâmica de dados (DDE).

```foxpro
DDEAdvise(nChannelNumber, cItemName, cUDFName, nLinkType)
```

#### Parâmetros
 **nChannelNumber**
Especifica o número do canal.
**cItemName**
Especifica o nome do item. Por exemplo, o Microsoft Excel usa notação de linha e coluna para referenciar células em uma planilha. O nome do item R1C1 designa a célula na primeira linha e primeira coluna da planilha.
**cUDFName**
Especifica a função definida pelo usuário que é executada quando um link de notificação ou um link automático é estabelecido e o item cItemName é modificado. Quando a função definida pelo usuário é executada, os seguintes seis parâmetros são passados na ordem indicada abaixo: Parâmetro Conteúdo Número do canal O número do canal do aplicativo servidor. Ação ADVISE ou TERMINATE. Item O nome do item; por exemplo, R1C1 para uma célula de planilha do Microsoft Excel. Data Os novos dados (link automático) ou a cadeia de caracteres vazia (link de notificação). Format O formato dos dados; por exemplo, CF_TEXT. Status Advise O tipo de link (0 = manual, 1 = notificação, 2 = automático). A função definida pelo usuário deve ter seis parâmetros em sua instrução LPARAMETER ou PARAMETER para aceitar os valores passados do aplicativo servidor. Se um link de notificação for estabelecido, a função definida pelo usuário é executada e a cadeia de caracteres vazia é passada no parâmetro Data. Você pode emitir DDERequest( ) posteriormente para recuperar os dados. Se um link automático for estabelecido, a função definida pelo usuário é executada e os dados são passados no parâmetro Data. O parâmetro Action contém ADVISE quando o link está sendo atualizado pelo servidor. A função definida pelo usuário é chamada e o parâmetro Action contém TERMINATE quando o link é fechado pelo cliente ou servidor. Qualquer valor retornado pela função definida pelo usuário é ignorado.
**nLinkType**
Especifica o tipo de link da seguinte forma: nLinkType Tipo de link 0 Manual 1 Notificação 2 Automático Você pode desativar a notificação do aplicativo servidor especificando 0 para nLinkType. Se o item mudar, a função definida pelo usuário não é executada.

# Valor de retorno

Logical

# Observações

DDEAdvise( ) é usada para criar um link de notificação ou um link automático a um nome de item em um aplicativo servidor. Quando um link de notificação é criado com DDEAdvise( ), o aplicativo servidor notifica o Visual FoxPro de que o nome do item foi modificado. Se um link automático for criado, o aplicativo servidor notifica o Visual FoxPro de que o nome do item foi modificado e passa os novos dados ao Visual FoxPro.

Antes de poder criar um link, você deve estabelecer um canal para o aplicativo servidor com DDEInitiate( ).

Você também pode usar DDEAdvise( ) para desativar a notificação do servidor.

DDEAdvise( ) retorna um valor verdadeiro (.T.) se for executada com sucesso; caso contrário, retorna falso (.F.).

# Exemplo

O exemplo a seguir demonstra como você pode estabelecer um canal DDE para uma planilha do Microsoft Excel chamada Sheet1. DDEAdvise( ) é usada para estabelecer dois links a dados em duas células da planilha (R1C1 e R1C2). A função definida pelo usuário NEWDATA é executada quando os dados em qualquer uma das células mudam. A função definida pelo usuário testa os parâmetros `item` e `advise` para determinar qual item mudou e que tipo de link foi estabelecido.

```foxpro
PUBLIC mchannum
mchannum = DDEInitiate('Excel', 'Sheet1')
IF mchannum != -1
   = DDEAdvise(mchannum, 'R1C1', 'newdata', 1)     && Notify link
   = DDEAdvise(mchannum, 'R1C2', 'newdata', 2)     && Automatic link
   WAIT WINDOW 'Enter data in first two cells in Excel.'
ENDIF
PROCEDURE newdata
PARAMETERS channel, action, item, data, format, advise
IF action = 'ADVISE'
   DO CASE
      CASE item = 'R1C1'   && Notify link
         newvalue = DDERequest(channel, item)
         ? 'R1C1 notify link: ' + newvalue
      CASE item = 'R1C2'   && Automatic link
         newvalue = data
         ? 'R1C2 automatic link: ' + newvalue
   ENDCASE
ELSE
   IF action != "TERMINATE"
      = DDETerminate(mchannum)
 ENDIF
ENDIF
```
