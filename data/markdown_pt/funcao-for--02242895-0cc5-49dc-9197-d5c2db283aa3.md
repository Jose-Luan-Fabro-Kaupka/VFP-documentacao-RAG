# Função FOR( )

Retorna, em letras maiúsculas, a expressão de filtro de índice de um arquivo de índice de entrada única (.idx) aberto ou de uma tag de índice.

```foxpro
FOR([nIndexNumber [, nWorkArea | cTableAlias]])
```

#### Parâmetros

Se nenhum argumento opcional for incluído, FOR( ) retorna a expressão de filtro do arquivo ou tag de índice mestre. Se não houver um índice mestre em vigor, FOR( ) retorna a cadeia vazia.
 **nIndexNumber**
Especifica o arquivo ou a tag de índice cuja expressão de filtro será retornada. À medida que nIndexNumber aumenta de 1 até o número total de índices abertos, FOR( ) retorna:
 - Primeiro, expressões de arquivos de índice de entrada única, na ordem em que foram incluídos em USE ou SET INDEX.
- Depois, expressões de cada tag do índice composto estrutural, na ordem de criação.
- Por último, expressões de tags de índices compostos independentes abertos, na ordem de criação. A cadeia vazia é retornada se um índice ou tag tiver sido criado sem cláusula FOR ou se nIndexNumber exceder o total de índices abertos.
 **nWorkArea**
Especifica a área de trabalho da tabela. FOR( ) retorna a cadeia vazia se não houver uma tabela aberta na área especificada.
**cTableAlias**
Especifica o alias da tabela. O Visual FoxPro gera um erro se o alias não existir.

# Valor de retorno

Caractere

# Observações

Você pode criar índices filtrados no Visual FoxPro. Se incluir a cláusula opcional FOR lExpression em INDEX, o arquivo de índice atuará como filtro da tabela. Somente os registros que correspondem a lExpression ficam disponíveis para exibição e acesso; chaves são criadas apenas para esses registros.

USE e SET INDEX aceitam uma lista de nomes que permite abrir vários arquivos de índice para uma tabela, em qualquer combinação de índices de entrada única, compostos estruturais ou compostos independentes. FOR( ) é semelhante a SYS(2021) - Filtered Index Expression e é fornecida para compatibilidade com dBASE IV.
