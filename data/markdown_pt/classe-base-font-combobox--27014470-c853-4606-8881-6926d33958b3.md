# Classe base Font Combobox

Esta classe é uma combobox que lista as fontes disponíveis quando colocada em um formulário. Também é usada pelas classes tbrEditing e rtfControls de _format.scx.

| Categoria | Formatação de texto |
| --- | --- |
| Catálogo padrão | Visual FoxPro Catalog\Foundation Classes\Text Formatting |
| Classe | _cbofontname |
| Classe base | ComboBox |
| Biblioteca de classes | _format.vcx |
| Classe pai | _combobox |
| Exemplo | ...\Samples\Solution\Toolbars\format.scx |

# Observações

Adicione a classe a um projeto ou formulário. Em um formulário, ela coloca uma combobox para especificar fontes dos objetos do formulário ativo. Em um projeto, você pode adicionar a classe ou criar uma subclasse.
