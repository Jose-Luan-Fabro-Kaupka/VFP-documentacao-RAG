# Import Wizard

Você pode usar o Import wizard para mover dados para arquivos de tabela do Visual FoxPro (.dbf) a partir de outros formatos de arquivo, como texto simples, Microsoft Excel ou Word, e outros arquivos. Por exemplo, você pode ter uma lista de nomes e endereços em um arquivo Word que seria mais fácil de usar e mais eficaz se estivesse em uma tabela do Visual FoxPro.

 Para acessar o Import wizard
 - No menu Tools, escolha Wizards e clique em Import.

# Etapa 1 – Identificar dados

Nesta etapa, você identifica o tipo e a localização dos dados que deseja importar.
 **File Type drop-down list**
Fornece uma lista de tipos de arquivo conhecidos dos quais você pode escolher.
**Source File edit box**
Permite escolher ou especificar um nome e localização de arquivo. Se você não souber nenhum dos dois, pode usar o botão Locate para encontrar o arquivo.
**New table radio button**
Quando você especifica um nome e localização de arquivo de destino, o assistente solicita um novo nome de tabela no mesmo diretório. A caixa de edição permite especificar um nome ou localização diferente para o arquivo de destino. Você pode usar o botão Locate para especificar outro arquivo e localização novos.
**Existing table radio button**
Se você escolher este botão, a caixa de edição permite especificar o nome e a localização de um arquivo existente. Se você não souber nenhum dos dois, pode usar o botão Locate para encontrar o arquivo.

### Etapa 1a – Selecionar um banco de dados

Nesta etapa você pode especificar um banco de dados ao qual sua tabela será adicionada. Você também pode decidir importar seus dados em uma tabela autônoma. Se escolher um banco de dados, pode ter aprimoramentos como opções de formatação automática e personalizada. Para obter informações sobre aprimoramentos de banco de dados, consulte Criando bancos de dados

# Etapa 2 – Determinar formato de dados

Nesta etapa, você pode especificar como os dados importados foram formatados — com ou sem caracteres delimitadores entre campos ou colunas e linhas ou como uma única coluna de largura fixa. Você também pode especificar onde no arquivo deseja começar a importar dados.
 **Delimited**
Especifica que os campos no arquivo são separados por um caractere, como uma vírgula (,) ou um ponto e vírgula (;).
**Fixed Width**
Especifica que os campos no arquivo estão alinhados em colunas.
**Field names in row**
Permite especificar a linha dos dados importados que contém os nomes de campo. Por exemplo, se a primeira linha dos dados importados contiver os nomes de campo desejados, defina Field names in row como 1. Se, no entanto, os nomes de campo não fizerem parte dos dados importados, na Etapa 3 você pode especificar nomes de campo para a nova tabela. O Import wizard automaticamente substitui espaços por sublinhados e reduz o tamanho do nome de campo para caber no máximo de 10 caracteres.
**Begin import at row**
Permite especificar a linha inicial de dados no arquivo importado. Esta opção permite evitar importar dados de cabeçalho.

Se você estiver importando uma planilha, esta etapa oferece uma lista suspensa de planilhas disponíveis na planilha selecionada.

### Etapa 2a – Descrever dados ou definir colunas

A Etapa 2a do Import wizard só aparece se você escolheu importar um arquivo de texto (.txt). Dependendo do que você escolheu como formato de dados na etapa 2, você terá uma de duas opções para a etapa 2a: Describe Data ou Set Columns.

### Describe Data

Esta etapa aparece como Describe Data, se você selecionar Delimited como formato de dados na etapa 2. Selecione qual delimitador separa as cadeias de texto no arquivo selecionado. Visualize o efeito do delimitador selecionado na grade Field na parte inferior desta caixa de diálogo do assistente.

### Set Columns

Esta etapa aparece como Set Columns, se você selecionar Fixed Width como formato de dados na etapa 2. Você pode usar a grade Field na parte inferior desta caixa de diálogo do assistente para especificar mais colunas clicando abaixo dos dados exibidos, para que as informações importadas sejam divididas em campos discretos.

# Etapa 3 - Definir campos importados

Nesta etapa, você especifica o nome das colunas na tabela, o tipo de dados das colunas e a largura das colunas. Clique abaixo do cabeçalho existente da coluna na grade Field e edite as informações listadas nas listas suspensas Name, Type, Width e Decimal.

Se não quiser importar uma coluna específica, clique abaixo do cabeçalho existente e, em seguida, pressione DELETE. O espaço para a coluna ainda estará visível (sem um nome de cabeçalho de coluna), mas quando você concluir o assistente e importar os dados, essa coluna será ignorada.
 **Worksheet**
Especifica o nome da planilha se você estiver importando uma planilha do Excel.
**Field Grid**
Para um arquivo de texto, esta grade exibe, na parte inferior da caixa de diálogo do assistente, o número do registro e os dados conforme encontrados no arquivo. Para outros tipos de arquivo, exibe os dados do arquivo conforme aparecerão quando você tiver concluído o Import wizard.

### Etapa 3a – Especificar opções internacionais

Nesta etapa, você pode especificar configurações alternativas para internacionalização dos dados a serem importados na tabela. Você pode optar por alterar a página de código, símbolo de moeda, separador de milhar, separador decimal e formato de data.
 **Code Page button**
Alterar a página de código pode afetar a forma como seus gráficos aparecem, porque os caracteres que formam linhas e cantos diferem entre páginas de código. Esta opção permite selecionar entre páginas de código suportadas pelo Visual FoxPro.
**Currency Symbol edit box**
Esta configuração permite substituir a configuração de moeda padrão para o arquivo criado por este assistente.
**1000 Separator edit box**
Esta configuração permite substituir o separador de milhar padrão para o arquivo criado pelo Import wizard.
**Decimal Separator**
Esta configuração permite substituir o separador decimal padrão para o arquivo criado pelo Import wizard.
**DateFormat**
Esta opção permite selecionar um dos formatos de data suportados pelo Visual FoxPro. Para obter mais informações, consulte Propriedade DateFormat.
