# Comando DELETE

Marca registros para exclusão.

```foxpro
DELETE [Scope] [FOR lExpression1] [WHILE lExpression2]
   [IN nWorkArea | cTableAlias] [NOOPTIMIZE]
```

#### Parâmetros
 **Scope**
Especifica um intervalo de registros a marcar para exclusão. O escopo padrão para DELETE é o registro atual (NEXT 1). As cláusulas scope são: ALL, NEXT nRecords , RECORD nRecordNumber e REST. Para obter mais informações sobre cláusulas scope, consulte Cláusulas Scope .
**FOR lExpression1**
Especifica uma condição pela qual somente os registros que satisfazem a condição lógica lExpression1 são marcados para exclusão. A Rushmore Query Optimization otimiza uma consulta criada com DELETE ... FOR se lExpression1 é uma expressão otimizável e a tabela está indexada em DELETED( ). Para melhor desempenho, use uma expressão otimizável na cláusula FOR. Para informações sobre expressões otimizáveis pelo Rushmore, consulte Comando SET OPTIMIZE , e Usando Rushmore Query Optimization para acelerar o acesso a dados em Otimizando aplicativos .
**WHILE lExpression2**
Especifica uma condição pela qual os registros são marcados para exclusão enquanto lExpression2 avalia como true (.T.).
**IN nWorkArea**
Especifica a área de trabalho da tabela na qual os registros são marcados para exclusão.
**IN cTableAlias**
Especifica o alias da tabela na qual os registros são marcados para exclusão. Se você omitir nWorkArea e cTableAlias , os registros são marcados para exclusão na tabela na área de trabalho atualmente selecionada.
**NOOPTIMIZE**
Desabilita a otimização Rushmore de DELETE.

# Observações

Registros marcados para exclusão não são fisicamente removidos da tabela até que PACK seja emitido. Registros marcados para exclusão podem ser recuperados (desmarcados) com RECALL.

# Exemplo

O exemplo a seguir abre a tabela `customer` no banco de dados `testdata`. DELETE é usado para marcar todos os registros para exclusão onde o campo `country` contém USA. Todos os registros marcados para exclusão são exibidos. RECALL ALL é usado para desmarcar todos os registros marcados para exclusão.

```foxpro
CLOSE DATABASES
OPEN DATABASE (HOME(2) + 'Data\testdata')
USE customer  && Opens Customer table
DELETE FOR country = 'USA'  && Mark for deletion
CLEAR
LIST FIELDS company, country FOR DELETED() && List marked records
RECALL ALL  && Unmark all records marked for deletion
```
