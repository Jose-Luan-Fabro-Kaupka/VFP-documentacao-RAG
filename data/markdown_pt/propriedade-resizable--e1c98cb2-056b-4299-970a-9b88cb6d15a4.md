# Propriedade Resizable

Especifica se um objeto Column pode ser dimensionado em tempo de execução pelo usuário. Disponível em tempo de design; leitura/gravação em tempo de execução.

```foxpro
Column.Resizable[ = lExpr]
```

# Valor de retorno
 **lExpr**
As configurações da propriedade Resizable são: Configuração Descrição True (.T.) O objeto Column pode ser dimensionado. False (.F.) (Padrão) O objeto Column não pode ser dimensionado pelo usuário.

# Observações

Aplica-se a: Column Object
