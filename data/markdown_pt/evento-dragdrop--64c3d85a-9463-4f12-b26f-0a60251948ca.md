# Evento DragDrop

Ocorre quando uma operação de arrastar e soltar é concluída.

```foxpro
PROCEDURE Object.DragDrop
LPARAMETERS oSource, nXCoord, nYCoord
```

#### Parâmetros

Você deve incluir uma instrução LPARAMETERS ou PARAMETERS no procedimento do evento e especificar um nome para cada parâmetro. O Visual FoxPro passa os parâmetros do evento DragDrop na seguinte ordem:
 **oSource**
Faz referência ao controle que está sendo arrastado. Você pode fazer referência a propriedades e métodos do controle com este parâmetro.
**nXCoord , nYCoord**
Contém a posição horizontal ( nXCoord ) e vertical ( nYCoord ) do ponteiro do mouse no Form quando os dados são soltos em um destino de soltar. Essas coordenadas são expressas em termos do sistema de coordenadas do Form na unidade de medida especificada pela propriedade ScaleMode do Form.

# Observações

Aplica-se a: CheckBox Control | ComboBox Control | CommandButton Control | CommandGroup Control | Container Object | Control Object (Visual FoxPro) | EditBox Control | Form Object | Grid Control | Image Control (Visual FoxPro) | Label Control (Visual FoxPro) | Line Control | ListBox Control | OLE Bound Control | OLE Container Control | OptionButton Control | OptionGroup Control | Page Object | PageFrame Control | Shape Control | Spinner Control | TextBox Control (Visual FoxPro) | ToolBar Object

Uma operação de arrastar e soltar é concluída quando um controle é arrastado sobre outro controle ou formulário e o botão do mouse é liberado, ou quando o método Drag com seu argumento nAction definido como 2 (Drop) é chamado para o controle.

Use um evento DragDrop para controlar o que acontece após a conclusão de uma operação de arrastar. Por exemplo, você pode mover o controle de origem para um novo local ou copiar um arquivo de um local para outro.

> **Observação:** O evento DragDrop envolve dois objetos, um controle que está sendo arrastado e um objeto de destino. O evento DragDrop é disparado para o objeto de destino, não para o controle que está sendo arrastado. Use a propriedade DragMode e o método Drag para especificar como o arrastar deve ser iniciado. Depois que o arrastar é iniciado, você pode tratar eventos que precedem um evento DragDrop com um evento DragOver.
