# Usando o depurador

Depois de identificar problemas no processo de teste, você pode usar o ambiente de depuração do Visual FoxPro para isolar esses problemas:
 - Iniciando uma sessão de depuração
- Rastreando o código
- Suspendendo a execução do programa
- Visualizando valores armazenados
- Exibição de saída

# Nesta seção
 **How to: Use the Debugger**
Descreve como usar o depurador para rastrear o código durante a execução.
**How to: Suspend Program Execution**
Explica como usar pontos de interrupção para suspender a execução do programa. Pontos de interrupção podem ser usados para suspender um aplicativo para que você possa verificar os valores de variáveis e propriedades, ver configurações de ambiente e examinar seções de código.
**How to: See Stored Values**
Descreve como ver valores armazenados em variáveis de tempo de execução, elementos de matriz, propriedades e expressões usando as janelas Locals, Watch ou Trace.
