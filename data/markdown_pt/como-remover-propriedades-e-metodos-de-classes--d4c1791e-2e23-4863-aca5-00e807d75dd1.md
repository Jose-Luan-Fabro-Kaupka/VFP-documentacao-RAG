# Como: remover propriedades e métodos de classes

Você pode remover propriedades e métodos personalizados de classes.

> **Cuidado:** Use cautela ao remover propriedades e métodos de classes. As alterações que você faz afetam o código que referencia essas propriedades e métodos.

### Para remover uma propriedade ou método personalizado
- Abra a classe no Class Designer. Para obter mais informações sobre como abrir classes, consulte How to: Modify Classes. Quando a classe é aberta no Class Designer, o menu Class aparece.
- No menu Class, escolha Edit Property/Method.
- Na lista Property/Method Information, selecione a propriedade ou método que você deseja remover e clique em Remove.
