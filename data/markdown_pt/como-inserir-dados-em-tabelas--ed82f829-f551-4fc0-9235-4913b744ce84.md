# Como: inserir dados em tabelas

Você pode incluir dados de outros aplicativos em uma tabela do Visual FoxPro inserindo os dados em campos General. Por exemplo, se você tem imagens de produtos, pode incluí-las em uma tabela contendo outras informações de produto inserindo-as em um campo General. Se a quantidade de dados for pequena o suficiente, você pode copiar e colar no campo General.

### Para inserir dados em um campo General
- Abra e navegue na tabela apropriada.
- Clique duas vezes no campo General no qual deseja inserir os dados.
- No menu Edit, escolha Insert Object . A caixa de diálogo Insert Object aparece listando os tipos de dados que você pode inserir no campo. Dica Você pode economizar espaço em disco ao vincular ou incorporar dados clicando em Display As Icon na caixa de diálogo Paste Special. Quando isso está selecionado, o Visual FoxPro exibe o ícone em vez dos dados.
- Escolha uma das seguintes opções: Para criar seus próprios dados, selecione Create New e então escolha o tipo de dados apropriado. -OU- Para usar dados existentes, selecione Create from File . Então, digite o nome do arquivo que contém os dados ou escolha Browse e selecione o arquivo apropriado. Se desejar vincular ao arquivo, selecione Link .

### Para colar dados de outro aplicativo em um campo General
- No outro aplicativo, selecione e copie os dados para a Área de transferência.
- Abra a tabela contendo o campo General em uma janela browse.
- Clique duas vezes no campo General.
- Escolha uma das seguintes opções: Para colar os dados, no menu Edit, clique em Paste . -OU- Para vincular aos dados, no menu Edit, clique em Paste Special para abrir a caixa de diálogo Paste Special, depois clique em Paste Link . Dica Você pode economizar espaço em disco ao vincular ou incorporar dados clicando em Display As Icon na caixa de diálogo Paste Special. Quando isso está selecionado, o Visual FoxPro exibe o ícone em vez dos dados.
