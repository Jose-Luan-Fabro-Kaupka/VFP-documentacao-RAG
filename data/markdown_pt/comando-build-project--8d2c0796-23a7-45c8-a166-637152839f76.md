# Comando BUILD PROJECT

Cria um arquivo de tabela de projeto do Visual FoxPro (.pjx) abrindo, processando e incluindo um ou mais arquivos de programa, menu, relatório, etiqueta, formulário ou biblioteca especificados no projeto. Um projeto do Visual FoxPro consiste em um arquivo .pjx e um arquivo de memo de projeto (.pjt). Você também pode usar BUILD PROJECT para reconstruir um projeto.

```foxpro
BUILD PROJECT ProjectFileName [RECOMPILE]
   [FROM ProgramName1 | MenuName1 | ReportName1 | LabelName1 |
            FormName1 | LibraryName1 [, ProgramName2 | MenuName2 |
            ReportName2 | LabelName2 | FormName2 | LibraryName2 ...]]
```

#### Parâmetros
 **ProjectFileName**
Especifica o nome do arquivo de projeto a ser criado.
**[RECOMPILE]**
Compila todos os arquivos do projeto. Se RECOMPILE for omitido, apenas os arquivos que foram modificados são compilados quando o projeto é construído.
**[FROM ProgramName1 | MenuName1 | ReportName1 | LabelName1 | FormName1 | LibraryName1 ]**
Especifica os arquivos a incluir no projeto. Você pode especificar um ou mais arquivos de programa, menu, relatório, etiqueta, formulário ou biblioteca. Por padrão, o primeiro programa executável ou arquivo de menu na cláusula FROM é o arquivo de programa mestre. Dica Para reconstruir um projeto, omita a cláusula FROM. O Visual FoxPro atualiza os arquivos no projeto especificado.

# Observações

Um projeto do Visual FoxPro mantém o controle dos arquivos no projeto, bem como das dependências, referências e relações entre eles. Depois de especificar os arquivos a incluir em um projeto, o Visual FoxPro garante que o projeto da aplicação seja baseado nos arquivos de origem mais recentes. Cada arquivo incluído no projeto contém um carimbo de data e hora para que você possa atualizar o projeto quando fizer alterações nos arquivos do projeto ou quando as dependências mudarem. Essa prática ajuda a garantir que quaisquer aplicações criadas a partir de um projeto sempre usem os arquivos de origem mais recentes. Quando o Visual FoxPro encontra um arquivo de programa, menu ou formulário ao criar um projeto usando BUILD PROJECT, ele localiza o arquivo compilado correspondente e compara o carimbo de data e hora dos dois arquivos. Se o carimbo de data e hora do arquivo de origem for posterior ao do arquivo compilado, o Visual FoxPro recompila o arquivo de origem.

Quando você usa BUILD PROJECT, o Visual FoxPro relata referências não resolvidas e outros erros, que não impedem a criação do projeto. Isso torna possível construir um projeto mesmo quando todas as peças necessárias ainda não foram criadas ou não estão disponíveis. Você pode corrigir referências não resolvidas ou outros erros posteriormente atualizando o arquivo de projeto ou modificando manualmente as informações armazenadas no arquivo de projeto usando MODIFY PROJECT.

Você pode criar os seguintes arquivos de aplicação redistribuíveis a partir de projetos: arquivos de aplicação (.app), arquivos executáveis (.exe) ou arquivos de biblioteca de vínculo dinâmico (.dll). No entanto, antes de criar arquivos de aplicação redistribuíveis, você deve testar seu projeto. Para obter mais informações, consulte How to: Test a Project. Para obter mais informações sobre como construir arquivos de aplicação redistribuíveis, consulte Compiling an Application.
