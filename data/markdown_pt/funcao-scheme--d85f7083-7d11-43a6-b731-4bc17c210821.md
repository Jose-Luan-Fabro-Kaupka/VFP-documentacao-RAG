# Função SCHEME( )

Retorna uma lista de pares de cores ou um único par de cores de um esquema de cores especificado.

```foxpro
SCHEME(nSchemeNumber [, nColorPairNumber])
```

#### Parâmetros
 **nSchemeNumber**
Especifica o número do esquema de cores para o qual você deseja uma lista completa de pares de cores. SCHEME( ) retorna dez pares de cores.
**nColorPairNumber**
Especifica a posição de um par de cores no esquema de cores, e SCHEME( ) retorna apenas este par de cores. Por exemplo, se nColorPairNumber é 4, SCHEME( ) retorna o quarto par de cores do esquema de cores.

# Valor de retorno

Character

# Exemplo

O exemplo a seguir retorna o terceiro par de cores do esquema de cores número 4:

```foxpro
? SCHEME(4,3)
```
