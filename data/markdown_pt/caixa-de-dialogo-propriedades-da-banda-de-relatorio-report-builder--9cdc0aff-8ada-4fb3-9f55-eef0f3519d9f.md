# Caixa de diálogo Propriedades da banda de relatório (Report Builder)

Permite definir propriedades e opções para uma banda em um layout de página de relatório ou etiqueta no Report Designer ou Label Designer.

Esta caixa de diálogo aparece quando você escolhe Properties no menu de contexto de um separador de banda de relatório, quando você clica duas vezes em um separador de banda de relatório ou quando você clica duas vezes no nome da banda na Caixa de diálogo Edit Bands.

> **Observação:** Esta caixa de diálogo é exibida somente se a variável de sistema _REPORTBUILDER estiver definida para o aplicativo Report Builder padrão. Se estiver vazia ou foi definida para um report builder de terceiros, a caixa de diálogo nativa do Visual FoxPro (ou uma caixa de diálogo de terceiros) pode aparecer. Para obter mais informações, consulte Variável de sistema _REPORTBUILDER .

A tabela a seguir lista cada uma das guias que existem na caixa de diálogo Propriedades da banda de relatório. Algumas guias podem estar presentes somente para tipos específicos de bandas.

> **Observação:** Ao modificar o relatório ou etiqueta no modo protegido, algumas ou todas as guias podem não estar disponíveis conforme especificado pelas configurações do modo protegido.

| Guia | Descrição |
| --- | --- |
| Guia General, Caixa de diálogo Propriedades da banda de relatório (Report Builder) | Permite alterar a altura da banda de relatório, controlar se a banda de relatório expande ou contrai para ajustar-se aos dados ou ajustar linhas em branco suprimidas, e expressões a avaliar antes ou depois de processar a banda. |
| Guia Band, Caixa de diálogo Propriedades da banda de relatório (Report Builder) | (Somente bandas Detail.) Permite especificar como uma banda Detail é processada em tempo de execução. |
| Guia Data Grouping, Caixa de diálogo Propriedades do relatório (Report Builder) | (Somente bandas Group Header e Group Footer.) Permite criar e especificar como os dados são agrupados no layout de relatório ou etiqueta. |
| Guia Protection, Caixa de diálogo Propriedades da banda de relatório (Report Builder) | Permite definir opções de proteção para uma banda de relatório no Report Designer ou Label Designer que restringem o usuário de fazer alterações ao modificar o layout no modo protegido. |
| Guia Other, Caixa de diálogo Propriedades da banda de relatório (Report Builder) | Permite adicionar comentários e dados de usuário a uma banda de relatório no Report Designer ou Label Designer. |
