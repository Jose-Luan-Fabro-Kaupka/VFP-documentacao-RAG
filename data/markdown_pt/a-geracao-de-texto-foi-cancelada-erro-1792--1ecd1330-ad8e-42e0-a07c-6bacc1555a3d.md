# A geração de texto foi cancelada (Erro 1792)

O programa de geração de texto, SCCTEXT.PRG (ou o programa cujo valor está armazenado na variável de sistema _SCCTEXT), foi interrompido.
 - Você pressionou a tecla ESC. O programa estava criando versões em texto dos arquivos de projeto para fazer check-in no controle de origem. Evite pressionar ESC durante o check-in dos arquivos.
