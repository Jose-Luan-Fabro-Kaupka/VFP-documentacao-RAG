# Propriedade FullName

Contém o nome do arquivo de uma instância do Visual FoxPro e o nome do diretório a partir do qual ela foi iniciada. Somente leitura em tempo de execução.

```foxpro
ApplicationObject.FullName
```

# Observações

Aplica-se a: objeto Application | variável de sistema _VFP

Use a propriedade FullName para determinar o diretório a partir do qual uma instância do Visual FoxPro foi iniciada.
