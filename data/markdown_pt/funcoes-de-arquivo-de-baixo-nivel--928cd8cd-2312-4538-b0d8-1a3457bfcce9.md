# Funções de Arquivo de Baixo Nível

Essas funções tornam possível manipular arquivos e portas de comunicação em baixo nível. As funções de arquivo de baixo nível devem ser usadas com cuidado, especialmente ao manipular arquivos de tabela. Antes de usar essas funções, teste-as em arquivos de exemplo antes de usá-las em arquivos que contêm dados importantes.

| Use | Para |
| --- | --- |
| FCHSIZE( ) Function | Alterar o tamanho de um arquivo aberto com uma função de arquivo de baixo nível. |
| FCLOSE( ) Function | Liberar e fechar um arquivo ou porta de comunicação aberto com uma função de arquivo de baixo nível. |
| FCREATE( ) Function | Criar e abrir um arquivo de baixo nível. |
| FEOF( ) Function | Determinar se o ponteiro de arquivo está posicionado no final de um arquivo. |
| FERROR( ) Function | Retornar um número correspondente ao erro mais recente de função de arquivo de baixo nível. |
| FFLUSH( ) Function | Liberar para o disco um arquivo aberto com uma função de baixo nível. |
| FGETS( ) Function | Retornar uma série de bytes de um arquivo ou porta de comunicação aberto com uma função de arquivo de baixo nível até encontrar um retorno de carro. |
| FOPEN( ) Function | Abrir um arquivo para uso com funções de arquivo de baixo nível. |
| FPUTS( ) Function | Gravar uma cadeia de caracteres, retorno de carro e avanço de linha em um arquivo aberto com uma função de arquivo de baixo nível. |
| FREAD( ) Function | Retornar um número especificado de bytes de um arquivo aberto com uma função de baixo nível. |
| FSEEK( ) Function | Mover o ponteiro de arquivo em um arquivo aberto com uma função de arquivo de baixo nível. |
| FWRITE( ) Function | Gravar uma cadeia de caracteres em um arquivo aberto com uma função de arquivo de baixo nível. |
| HEADER( ) Function | Retornar o número de bytes no cabeçalho do arquivo de tabela atual ou especificado. |
