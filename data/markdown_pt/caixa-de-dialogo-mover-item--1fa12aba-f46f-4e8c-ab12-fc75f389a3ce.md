# Caixa de diálogo Mover item

Permite alterar a localização de um menu ou item de menu.

A caixa de diálogo Mover item aparece quando você seleciona uma linha no Designer de Menus ou no Designer de Atalhos e clica em Mover item.

# Grupo Mover
 **Nome**
Exibe o nome do menu ou item de menu.
**Tipo**
Exibe o tipo do menu ou item de menu.

# Grupo Para local
 **Caixa Para local**
Exibe uma lista de locais válidos para os quais um item de menu pode ser movido.
