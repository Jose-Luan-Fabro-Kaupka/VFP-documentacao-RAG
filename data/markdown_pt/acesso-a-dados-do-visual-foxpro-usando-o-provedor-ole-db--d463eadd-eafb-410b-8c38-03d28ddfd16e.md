# Acesso a dados do Visual FoxPro usando o Provedor OLE DB

Você pode acessar dados do Visual FoxPro de outras linguagens de programação e aplicações. Usando o Microsoft OLE DB Provider for Visual FoxPro, você pode se conectar a bancos de dados e tabelas do Visual FoxPro e recuperar dados de bancos de dados e tabelas do Visual FoxPro para usar em aplicações e arquivos do Visual Studio e do Microsoft Office.
