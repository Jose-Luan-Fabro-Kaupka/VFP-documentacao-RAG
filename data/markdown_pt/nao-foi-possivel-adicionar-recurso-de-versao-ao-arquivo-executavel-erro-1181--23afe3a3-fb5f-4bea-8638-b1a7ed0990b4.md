# Não foi possível adicionar recurso de versão ao arquivo executável (Erro 1181)

O recurso não pôde ser adicionado ao arquivo executável na hora de compilação.
- O recurso pode ser corrupto. Recriar o recurso.
- Você pode ter usado uma letra na opção VersionNumber cBuildNumber. Utilizar apenas números para a configuração cBuildNumber.
