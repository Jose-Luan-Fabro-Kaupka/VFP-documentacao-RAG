# Manipulação de objetos

Você pode manipular e trabalhar com objetos de um formulário em tempo de design.

A lista a seguir descreve algumas tarefas que podem ser executadas:
 - Definir o tamanho e a posição dos objetos no Form Designer expandindo, reduzindo ou arrastando-os.
- Alinhar controles escolhendo opções no menu Format ou usando as ferramentas de alinhamento da barra Layout. Para obter mais informações, consulte Alinhamento de controles em formulários.
- Definir cores com a barra Palette. Para obter mais informações, consulte Personalização de formulários.
- Exibir configurações de propriedades, código herdado de objetos, eventos e métodos, definir valores de propriedades e limitar a exibição apenas às propriedades modificadas usando a janela Properties.

A janela Properties é o principal local para controlar todos os objetos de um formulário. Ela exibe propriedades, eventos, métodos e suas configurações para o formulário, ambiente de dados, cursor, relação ou controle selecionado. Para obter mais informações, consulte Janela Properties (Visual FoxPro).
