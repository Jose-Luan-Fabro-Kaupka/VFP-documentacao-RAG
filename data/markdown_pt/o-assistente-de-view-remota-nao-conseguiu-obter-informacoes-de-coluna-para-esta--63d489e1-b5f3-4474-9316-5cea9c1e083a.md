# O Assistente de View Remota não conseguiu obter informações de coluna para esta tabela remota. Isso pode ser o resultado de um erro ODBC ou a tabela remota pode não pertencer ao usuário atual.

Se a consulta que você está usando não contém o nome do proprietário da tabela que você especificou, as informações da tabela remota estarão indisponíveis.

Para corrigir este problema, use os Designers de Consulta e View para adicionar o usuário atual como proprietário da tabela à cadeia de caracteres SQL.

Se você ainda receber um erro, deve corrigir o problema no ODBC.
