# XML Web Service Builder

Torna possível vincular um serviço Web XML a um controle em um formulário do Visual FoxPro ou a um objeto, como um cursor adapter no ambiente de dados do formulário, sem escrever código.

Você pode abrir o XML Web Service Builder no Form Designer ou Class Designer.

 Para abrir o XML Web Service Builder
 - Crie um formulário novo ou abra um existente.
- No menu Tools, clique em Toolbox.
- Em My XML Web Services na Toolbox, arraste e solte o controle Generic Handler ou um serviço Web XML registrado em um formulário.

Você também pode abrir o XML Web Service Builder para um serviço Web XML existente registrando o serviço Web XML na Toolbox, arrastando o serviço Web XML da Toolbox e soltando-o em um formulário, clicando com o botão direito no serviço Web XML e, no menu de atalho, clicando em Builder.

> **Observação:** Como com outros builders do Visual FoxPro, você pode usar o XML Web Service Builder para modificar o serviço Web XML novamente. O builder não apenas define propriedades para um controle, mas também grava informações no método personalizado SetupOperations.

# Guias do Builder
 **Guia Services, XML Web Service Builder**
Especifica um serviço Web XML a ser usado para um formulário ou classe.
**Guia Operations, XML Web Service Builder**
Especifica as operações do serviço Web XML a serem usadas e suas vinculações entre os controles ou objetos em um formulário ou classe.
