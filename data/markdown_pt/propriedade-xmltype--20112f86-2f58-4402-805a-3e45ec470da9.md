# Propriedade XMLType

Contém uma referência de objeto para o objeto lSchemaType do Microsoft XML Core Services (MSXML) 4.0, que contém restrições, padrões e outras informações do campo.

Para obter mais informações sobre objetos lSchemaType, consulte o SDK do MSXML 4.0 no site da Biblioteca MSDN em http://msdn.microsoft.com/library/.

```foxpro
XMLField.XMLType
```

# Valor de retorno

Referência de objeto. XMLType contém uma referência ao objeto lSchemaType do MSXML 4.0.
