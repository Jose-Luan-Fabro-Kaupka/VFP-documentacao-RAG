# Caixa de diálogo Run-time Extensions (Report Builder)

Permite atribuir elementos de código e expressões a um controle de relatório para uso durante a execução do relatório.
 - Como: atribuir metadados estruturados a controles de relatório
 **Run-time extensions**
Especifica código arbitrário que objetos ReportListener podem executar.
**Execute when**
Especifica uma expressão que objetos ReportListener podem avaliar para determinar se as extensões devem ser executadas. Clicar no botão de reticências (…) abre o Expression Builder para que você possa criar uma expressão. Para obter mais informações, consulte Caixa de diálogo Expression Builder.
