# Não é possível inserir uma linha vazia de uma exibição em sua(s) tabela(s) base (Erro 1547)

Enquanto uma exibição está sendo atualizada, um novo registro vazio (sem campos modificados) está sendo inserido em uma das tabelas base da exibição.

Certifique-se de que cada registro inserido de uma exibição em uma tabela base tenha pelo menos um campo que foi modificado na exibição antes da atualização da exibição.
