# Guia Layout, Combo Box Builder

Esta guia no Combo Box builder controla a largura das colunas e a exibição.
 **Adjust the Width of the Combo Box to Display All Columns**
Especifica que todas as colunas selecionadas serão exibidas, mesmo que o combo box aberto precise se estender além do limite do formulário. Isso controla a propriedade Width do combo box.
**Column Grid**
Controla os valores na propriedade ColumnWidths. Você pode ajustar a largura da coluna arrastando a borda direita de um cabeçalho de coluna com o mouse. Clique duas vezes em um cabeçalho de coluna para ocultar a coluna. A grade mostra dados reais, se disponíveis. Se não houver dados disponíveis, a grade exibe uma mensagem a esse respeito. Para alterar a ordem das colunas, retorne à guia List Items, remova os campos e adicione-os novamente na ordem desejada.
