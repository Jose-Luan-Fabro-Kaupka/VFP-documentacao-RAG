# Guia Avançado, Application Builder

Nesta guia do Application builder, você pode especificar o nome do arquivo de Ajuda e o diretório padrão para sua aplicação. Você também pode especificar a inclusão de uma barra de ferramentas padrão e um menu Favorites em sua aplicação.
 **Arquivo de Ajuda**
Permite especificar o nome e o caminho do arquivo de Ajuda para sua aplicação.
**Diretório de dados padrão**
Permite especificar o diretório padrão para os arquivos de dados de sua aplicação. Se você especificar este diretório antes de selecionar sua fonte de dados, pode facilitar a especificação de várias tabelas.

# Menus
 **Barra de ferramentas padrão**
Especifica se a barra de ferramentas padrão aparece em sua aplicação.
**Menu Favorites**
Especifica se o menu Favorites está disponível em sua aplicação.
**Cleanup**
Executa uma rotina para reconciliar quaisquer alterações feitas no Application Builder com o projeto ativo.

Se você escolher OK, o builder fecha, aplicando as configurações de propriedade de todas as guias.
