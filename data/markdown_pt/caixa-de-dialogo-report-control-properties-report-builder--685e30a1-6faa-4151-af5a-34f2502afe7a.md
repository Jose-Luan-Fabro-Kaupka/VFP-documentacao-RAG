# Caixa de diálogo Report Control Properties (Report Builder)

Permite definir opções para controles de relatório no layout do relatório.

Esta caixa de diálogo aparece quando você escolhe Properties no menu de contexto de um controle de relatório ou quando clica duas vezes em um controle de relatório.

> **Observação:** Esta caixa de diálogo é exibida somente se a variável de sistema _REPORTBUILDER estiver definida para o aplicativo Report Builder padrão. Se estiver vazia ou tiver sido definida para um report builder de terceiros, a caixa de diálogo nativa do Visual FoxPro (ou uma caixa de diálogo de terceiros) pode aparecer. Para obter mais informações, consulte Variável de sistema _REPORTBUILDER.

A tabela a seguir lista as guias que existem na caixa de diálogo Report Control Properties e estão disponíveis conforme apropriado.

> **Observação:** Ao modificar o relatório ou a etiqueta no modo protegido, algumas ou todas as guias podem não estar disponíveis conforme especificado pelas configurações do modo de proteção.

| Guia | Descrição |
| --- | --- |
| Guia General, Caixa de diálogo Report Control Properties (Report Builder) | Permite definir opções gerais para controles de relatório no Report Designer ou Label Designer. |
| Guia Style, Caixa de diálogo Report Control Properties (Report Builder) | (Somente controles Label, Field, Line e Shape.) Permite definir opções de estilo para controles de relatório no Report Designer ou Label Designer. |
| Guia Format, Caixa de diálogo Report Control Properties (Report Builder) | (Somente controles Label e Field.) Permite especificar expressões de formato para saída gerada a partir de controles de relatório Field no Report Designer ou Label Designer. |
| Guia Print When, Caixa de diálogo Report Control Properties (Report Builder) | Permite especificar se deve repetir a exibição de controles de relatório ou valores na saída para relatórios e etiquetas. |
| Guia Calculate, Caixa de diálogo Report Control Properties (Report Builder) | (Somente controles Field.) Permite especificar um cálculo a executar em expressões de controle Field e exibir os resultados do cálculo em vez da expressão. Você também pode especificar o ponto em que redefinir o cálculo no relatório. |
| Guia Protection, Caixa de diálogo Report Control Properties (Report Builder) | Permite definir opções de proteção para um controle de relatório que impedem o usuário de alterar o controle no Report Designer ou Label Designer ao modificar o relatório ou a etiqueta no modo protegido. |
| Guia Other, Caixa de diálogo Report Control Properties (Report Builder) | Permite adicionar comentários, dados do usuário e elementos de código que você pode executar usando objetos ReportListener para controles de relatório no Report Designer ou Label Designer. |
| Guia Dynamics, Caixa de diálogo Report Control Properties (Report Builder) | Permite especificar uma ou mais expressões que alteram as propriedades de exibição em tempo de execução dos controles de relatório. |
| Guia Advanced, Caixa de diálogo Report Control Properties (Report Builder) | Permite definir, adicionar ou excluir propriedades personalizadas para um controle de relatório e alterar a rotação do controle. |
