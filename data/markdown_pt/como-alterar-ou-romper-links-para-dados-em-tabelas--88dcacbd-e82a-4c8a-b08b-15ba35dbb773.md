# Como: alterar ou romper links para dados em tabelas

Depois de vincular a alguns dados, você pode querer usar uma fonte de dados diferente ou pode querer incorporar em vez de vincular. Para alterar a fonte de dados, você deve alterar o link; e para incorporar, você deve romper o link.

### Para alterar o link para dados em um campo General
- Abra e navegue na tabela apropriada.
- Clique duas vezes no campo General contendo os dados cujo link você deseja alterar.
- No menu Edit, escolha Links . A caixa de diálogo Links aparece. Observação Escolha Automatic para atualizar automaticamente os dados sempre que eles mudarem no aplicativo de origem, ou Manual se desejar atualizar os dados manualmente.
- Na caixa de diálogo Links, escolha Change Source . A caixa de diálogo Change Source aparece.
- Especifique a nova fonte de dados e escolha OK .
- Na caixa de diálogo Links, escolha Close para concluir a alteração.

### Para romper um link para dados em um campo General
- Abra e navegue na tabela apropriada.
- Clique duas vezes no campo General contendo os dados cujo link você deseja romper.
- No menu Edit, escolha Links .
- Na caixa de diálogo Links, escolha Break Link .
- Escolha Close .

Quando o link é rompido, os dados tornam-se estáticos.
