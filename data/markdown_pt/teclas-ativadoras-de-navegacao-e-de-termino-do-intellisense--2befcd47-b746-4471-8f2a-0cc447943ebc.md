# Teclas ativadoras, de navegação e de término do IntelliSense

O IntelliSense responde a teclas ativadoras como a BARRA DE ESPAÇO, teclas de navegação como teclas alfanuméricas e teclas de término como a tecla ESC. O contexto do código e o elemento de linguagem determinam quais teclas ativadoras você pode usar.

As tabelas a seguir descrevem as teclas ativadoras, de navegação e de término às quais o IntelliSense responde.
 Teclas ativadoras
| Tecla | Descrição |
| --- | --- |
| BARRA DE ESPAÇO | Espaço (" "). Tecla ativadora para comandos do Visual FoxPro e elementos de linguagem definidos pelo usuário. Exibe listas de membros ou janelas de dica. |
| ( | Parêntese de abertura. Tecla ativadora para funções do Visual FoxPro e métodos de objetos. Exibe listas de valores ou janelas de dica. |
| PERIOD | Ponto (.). Tecla ativadora para variáveis de sistema ou objetos. Exibe listas de membros de propriedades, métodos ou eventos de objetos ou janelas de dica. |
| = | Sinal de igual. Tecla ativadora para propriedades. Verifica espaço em branco entre a propriedade e o caractere "=". Exibe listas de valores, editores de valores, por exemplo, seletores de fonte ou cor, ou janelas de dica. |
 Teclas de navegação
| Tecla | Descrição |
| --- | --- |
| a–z, A-Z, 0-9 | Alfanumérico. Navega pelos itens correspondentes nas listas do IntelliSense até que não existam mais correspondências. |
| < | SETA PARA A ESQUERDA. Posiciona o cursor um caractere à esquerda. Fecha a lista do IntelliSense se o cursor sair do contexto, por exemplo, antes de um ponto. |
| > | SETA PARA A DIREITA. Posiciona o cursor um caractere à direita. Fecha a lista do IntelliSense se o cursor sair do contexto, por exemplo, após o que foi digitado. |
| PAGE UP | Move o cursor uma página para cima na lista do IntelliSense. |
| PAGE DOWN | Move o cursor uma página para baixo na lista do IntelliSense. |
| TAB | Insere um item selecionado em uma lista do IntelliSense no código e posiciona o cursor imediatamente após o item adicionado. |
 Teclas de término
| Tecla | Descrição |
| --- | --- |
| ESC | Fecha a caixa de lista do IntelliSense. |
| HOME | Fecha a caixa de lista do IntelliSense e posiciona o cursor no início da linha atual. |
| END, ENTER, BARRA DE ESPAÇO e outros caracteres não alfanuméricos | Fecha a caixa de lista do IntelliSense e posiciona o cursor no final da linha atual. |
