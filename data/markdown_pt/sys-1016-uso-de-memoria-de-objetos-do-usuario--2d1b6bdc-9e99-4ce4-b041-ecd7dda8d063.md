# SYS(1016) - Uso de memória de objetos do usuário

Retorna a quantidade de memória sendo usada por objetos que você define.

```foxpro
SYS(1016)
```

# Valor de retorno

Caractere

# Observações

Objetos definidos pelo usuário incluem: janelas definidas pelo usuário, barras de menu, menus, variáveis, matrizes, tabelas abertas, arquivos abertos com funções de arquivo de baixo nível e assim por diante.
