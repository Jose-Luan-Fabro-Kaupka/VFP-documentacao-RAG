# Como: formatar código em programas

Você pode formatar blocos específicos de código ou o arquivo de programa inteiro definindo as opções desejadas na caixa de diálogo Opções de embelezamento e, em seguida, aplicar as opções de formatação escolhidas. Depois de formatar o código usando a ferramenta Beautify, você pode fazer alterações adicionais na formatação do código.

### Para definir opções de formatação de código
- Abra o arquivo de programa.
- Para formatar um bloco específico de código, selecione o código que deseja formatar. Observação Para formatar o programa inteiro, não selecione nenhum código.
- No menu Ferramentas, clique em Beautify .
- Na caixa de diálogo Opções de embelezamento, selecione as opções de formatação desejadas. O processo de formatação usa a linha superior do bloco selecionado para determinar o nível base de indentação.

### Para aplicar opções de formatação ao código
- Na caixa de diálogo Opções de embelezamento, clique em Executar .
