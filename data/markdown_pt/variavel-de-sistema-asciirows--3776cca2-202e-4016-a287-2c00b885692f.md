# Variável de sistema _ASCIIROWS

Especifica o número de linhas em um arquivo de texto ASCII criado com a palavra-chave ASCII no comando REPORT FORM.

```foxpro
_ASCIIROWS = nExpression
```

#### Parâmetros
 **nExpression**
Especifica o número de linhas no arquivo de texto a ser criado. O valor padrão é 63.
