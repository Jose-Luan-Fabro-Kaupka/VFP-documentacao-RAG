# Propriedade SCCProvider

O nome do provedor de controle de código-fonte para um projeto. Somente leitura.

```foxpro
Object.SCCProvider
```

# Observações

Aplica-se a: objeto Project (Visual FoxPro)

Você pode especificar um provedor de controle de código-fonte para novos projetos na guia Projects da caixa de diálogo Options. A propriedade SCCProvider contém a cadeia de caracteres vazia se um projeto não está sob controle de código-fonte.
