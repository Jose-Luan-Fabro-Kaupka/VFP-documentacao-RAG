# Guia Controls, Options Dialog Box

Contém opções para registrar bibliotecas de classes visuais para especificar classes de modelo na guia Forms, Options Dialog Box. Essas opções também especificam o que pode ser selecionado no botão View Classes na Form Controls Toolbar para facilitar a adição de controles personalizados a formulários.

Quando você escolhe Set As Default — que aparece em cada guia da caixa de diálogo — o Visual FoxPro salva as configurações de opção no registro (banco de dados de registro do sistema Windows).
 **Visual class libraries**
Especifica que bibliotecas de classes (.vcx files) são exibidas na lista Selected.
**ActiveX controls**
Especifica que controles ActiveX são exibidos na lista Selected.
**Selected**
Lista arquivos que você pode adicionar ou remover do seu ambiente do Visual FoxPro. Se você escolheu Visual class libraries, a lista exibe os arquivos .vcx que você já adicionou e especifica quais bibliotecas aparecem no menu de atalho quando você clica no botão View Classes na Form Controls Toolbar. Se você escolheu ActiveX controls , a lista exibe as classes de objetos e controles disponíveis em seu sistema. Objetos e controles ActiveX que você já adicionou estão marcados e aparecem no menu de atalho quando você clica no botão View Classes na barra de ferramentas Form Controls.
**Label**
Aparece quando a opção Visual class libraries está selecionada. Especifica o nome da biblioteca de classes. Por padrão, o Visual FoxPro usa o nome do arquivo sem a extensão .vcx.
**Library**
Aparece quando a opção Visual class libraries está selecionada. Exibe o caminho e o nome do arquivo dos arquivos .vcx para a biblioteca de classes atualmente selecionada.
**Show**
Aparece quando ActiveX está selecionado. Permite especificar quais tipos de objetos ActiveX aparecem na lista Selected. Insertable Objects Especifica que a lista Selected exibe classes de objetos que você pode inserir como objetos ActiveX em aplicativos do Visual FoxPro. Controls Especifica que a lista Selected exibe controles ActiveX.
**Add**
Escolha este botão para exibir a Open Dialog Box para que você possa adicionar bibliotecas (.vcx files) ou controles ActiveX à lista Selected. Adicionar um controle ActiveX também o registra para que estará disponível na lista de controles na Insert Object Dialog Box e em outros aplicativos.
**Remove**
Aparece quando a opção Visual class libraries está selecionada. Escolha este botão para remover a biblioteca selecionada da caixa Selected.
