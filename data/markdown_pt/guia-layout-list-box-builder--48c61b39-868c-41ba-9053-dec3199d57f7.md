# Guia Layout, List Box Builder

Esta guia no List Box builder controla a largura das colunas e a exibição.
 **Adjust the Width of the List Box to Display All Columns**
Especifica que todas as colunas serão exibidas e que a caixa de listagem será dimensionada automaticamente conforme necessário. Esta opção corresponde à propriedade Width.
**Column Grid**
Mostra as colunas definidas na guia List Items. Você pode ajustar a largura da coluna arrastando a borda direita de um cabeçalho de coluna com o mouse. Você pode ocultar uma coluna clicando duas vezes em um cabeçalho de coluna se você escolheu "Fill the list with fields from a table or view" na guia List Items. Esta opção corresponde à propriedade ColumnWidths.
