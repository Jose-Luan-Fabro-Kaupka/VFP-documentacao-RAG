# Comando LPARAMETERS

Atribui dados passados de um programa chamador a variáveis ou matrizes locais.

```foxpro
LPARAMETERS Parameter1 [AS type [OF ClassLib]]
   [, Parameter2 [AS type [OF ClassLib]]]
```

#### Parâmetros
 **LPARAMETERS ParameterList**
Especifica um ou mais nomes de variáveis ou matrizes locais para atribuir dados do programa chamador. Use vírgulas para separar vários parâmetros em ParameterList. Você pode passar no máximo 26 parâmetros. Observação A instrução LPARAMETERS deve especificar pelo menos tantos parâmetros quanto os usados pela chamada ao programa, procedimento ou função que contém a instrução LPARAMETERS. Se mais variáveis ou matrizes estiverem listadas na instrução LPARAMETERS do que são passadas pelo programa chamador, as variáveis ou matrizes restantes na instrução LPARAMETERS são inicializadas como False (.F.).
**[ AS type [OF ClassLib ] ]**
Especifica o tipo de dados da variável ou matriz local e a biblioteca de classes que contém a descrição de tipo de type na qual esta variável ou matriz se baseia. Você pode usar a cláusula AS para implementar tipagem forte. A funcionalidade IntelliSense está disponível para referências de objetos e variáveis somente quando elas são fortemente tipadas. Para obter mais informações, consulte Como: implementar tipagem forte para código de classe, objeto e variável.

# Observações

Quando LPARAMETERS é usado com um programa, procedimento ou função definida pelo usuário chamada com o comando DO, deve ser a primeira instrução executável no programa, procedimento ou função definida pelo usuário chamada.

Por padrão, a cláusula WITH no comando DO passa variáveis e matrizes por referência a procedimentos. Por padrão, o Visual FoxPro passa argumentos por valor a funções definidas pelo usuário.

> **Observação:** Para passar matrizes inteiras a funções, você deve passá-las por referência. Se não passar matrizes a funções por referência, apenas o primeiro elemento é passado à função. Para obter mais informações, consulte Como: passar dados a parâmetros por referência.

Para obter mais informações, consulte Passing Data to Parameters e Parameters in Procedures and Functions.
