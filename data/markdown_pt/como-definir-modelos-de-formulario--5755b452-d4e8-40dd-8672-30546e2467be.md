# Como: definir modelos de formulário

Você pode criar sua própria classe de formulário para usar como modelo para todos os seus novos formulários ou pode usar uma das classes de exemplo fornecidas com o Visual FoxPro. Para obter mais informações, consulte Using Form Templates.

Quando você cria um novo formulário, ele é baseado no formulário modelo definido na caixa de diálogo Options. Se nenhum modelo for especificado, o novo formulário é baseado na classe base Form do Visual FoxPro. Para obter mais informações sobre classes do Visual FoxPro, consulte Object-Oriented Programming.

Você pode especificar uma classe de formulário de uma biblioteca de classes registrada para o seu modelo de formulário.

### Para especificar um modelo de formulário padrão
- No menu Tools, escolha Options .
- Na caixa de diálogo Options, escolha a guia Forms.
- Na área Template classes, selecione a caixa de seleção Form. Se nenhum modelo de formulário foi selecionado, a caixa de diálogo Open é aberta para que você possa escolher uma classe de formulário. Se um modelo de formulário foi selecionado, você pode alterá-lo escolhendo o botão de diálogo e selecionando outra classe.
- Escolha Set as Default se desejar que o modelo seja usado em sessões subsequentes do Visual FoxPro.
- Escolha OK .
