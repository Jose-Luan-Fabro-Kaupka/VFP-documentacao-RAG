# Propriedade NestedInto

Especifica o objeto XMLTable pai para um XMLTable dentro de uma hierarquia. Somente leitura em tempo de design e em tempo de execução.

```foxpro
XMLTable.NestedInto = oXMLTable
```

# Valor de retorno
 **oXMLTable**
Referência de objeto ao objeto XMLTable pai.
**null (.NULL.)**
Propriedade não preenchida. Indica que não há XMLTable pai.

# Observações

Aplica-se a: Classe XMLTable
