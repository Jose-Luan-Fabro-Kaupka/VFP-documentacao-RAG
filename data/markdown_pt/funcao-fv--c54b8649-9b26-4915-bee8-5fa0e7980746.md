# Função FV( )

Retorna o valor futuro de um investimento financeiro.

```foxpro
FV(nPayment, nInterestRate, nPeriods)
```

#### Parâmetros
 **nPayment**
Especifica o pagamento periódico constante (que pode ser negativo ou positivo).
**nInterestRate**
Especifica a taxa de juros periódica. Se a taxa de juros é anual, mas os pagamentos são feitos mensalmente, divida a taxa de juros anual por 12.
**nPeriods**
Especifica o número de períodos durante os quais os pagamentos são feitos. FV( ) assume que os pagamentos periódicos são feitos no final de cada período.

# Valor de retorno

Numérico

# Observações

FV( ) calcula o valor futuro de uma série de pagamentos periódicos constantes que rendem juros compostos fixos. O valor futuro é a soma de todos os pagamentos e dos juros.

# Exemplo

```foxpro
STORE 500 TO gnPayment  && Monthly payment
STORE .075/12 TO gnInterest     && 7.5% annual interest rate
STORE 48 TO gnPeriods  && Four years (48 months)
CLEAR
? FV(gnPayment, gnInterest, gnPeriods)    && Displays 27887.93
```
