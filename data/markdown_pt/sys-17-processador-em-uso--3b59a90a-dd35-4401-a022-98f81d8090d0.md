# SYS(17) - Processador em uso

Retorna a unidade de processamento central (CPU) em uso.

```foxpro
SYS(17)
```

# Valor de retorno

Character

# Observações

Esta função retorna o tipo de unidade de processamento central que você está usando.

# Exemplo

```foxpro
? 'Processor in use: ', SYS(17)
```
