# Solução de problemas de instalação

Você pode encontrar os seguintes problemas ao instalar o Visual FoxPro:
 - Se você não conseguir executar o Visual FoxPro e não ver mensagens de erro informando o que está errado, o problema pode estar na ROM BIOS do seu computador ou no driver de vídeo que você está usando.
- Se você estiver usando um teclado estendido, certifique-se de que ele é compatível com a ROM BIOS. Além disso, certifique-se de que você está usando um driver de vídeo Windows VGA ou Super VGA padrão.
- Se você receber uma mensagem de erro "stack overflow", seu driver de vídeo está desatualizado ou não foi projetado para sua placa de vídeo. Para corrigir este problema, atualize o driver de vídeo.
- Para informações adicionais, consulte o Visual FoxPro Readme na raiz do CD de instalação do Visual FoxPro.
