# Amostras Solution de controles

Estas amostras Solution, organizadas por tipo de controle, ilustram muitas tarefas que você pode realizar com controles.

# Nesta seção

Ilustra como adicionar e remover itens de uma caixa de lista.
**Amostra Add New Items to a Combo Box**

**Amostra Allow Users to Choose List Values**
Ilustra como fornecer um conjunto de valores de uma tabela em uma caixa de lista e caixa de combinação.
**Amostra Allow Users to Drag and Drop Controls**
Ilustra como implementar operações de arrastar e soltar para controles.
**Amostra Change Pages When a User Chooses a Button**
Ilustra como exibir diferentes combinações de botões de comando em uma caixa de mensagem usando botões de opção.
**Amostra Change the Number of Tabs at Run Time**
Ilustra como usar um page frame com guias.
**Amostra Display a Stop Watch**

**Amostra Display a System Clock**
Ilustra como exibir um relógio do sistema.
**Amostra Display Calculated Values in a Column**
Ilustra como exibir um valor calculado em uma coluna de grade.
**Amostra Display Child Records from a Relationship**
Ilustra como coordenar um formulário com uma relação um-para-muitos e duas grades e exibir os tipos de relações.
**Amostra Display Controls in a Grid**
Ilustra como exibir controles em colunas de grade.
**Amostra Display Different Pages without Tabs**
Ilustra como manipular páginas sem guias em um page frame.
**Amostra Display Multiple Columns in a List Box**
Ilustra como exibir várias colunas em uma caixa de lista.
**Amostra Display Pictures in a List**
Ilustra como exibir imagens ao lado de itens em caixas de lista.
**Amostra Dynamically Format Grid Columns**
Ilustra como definir as cores dinâmicas de primeiro plano e plano de fundo em colunas de grade.
**Amostra Edit a Memo Field or Text File**
Ilustra como visualizar e editar texto de um campo Memo ou arquivo de texto em uma caixa de edição.
**Amostra Execute Commands at Specified Intervals**
Ilustra como definir intervalos entre a exibição de texto usando uma caixa de texto e um spinner.
**Amostra Fill a List with Values from Different Sources**
Ilustra como definir a propriedade RowSourceType de uma caixa de lista para exibir valores de diferentes fontes.
**Amostra Format Input and Validate Data in a Text Box**
Ilustra como facilitar para o usuário a entrada de dados com um formato específico em uma caixa de texto.
**Amostra Grid Highlighting, Column Resizing, and Header Images**
Demonstra como selecionar estilo e cores para destaque de grade, redimensionar colunas automaticamente à largura dos dados na coluna, bloquear a primeira coluna da grade para que não role e especificar imagens nos cabeçalhos de coluna.
**Amostra Hot Tracking and Hover Effects**
Ilustra como adicionar efeitos especiais a controles em formulários.
**Amostra Manipulate Text Programmatically**
Ilustra como usar propriedades de uma caixa de edição para manipular texto em tempo de execução.
**Amostra Move Items Between List Boxes**
Ilustra como mover itens de uma caixa de lista para outra.
**Amostra Multiselect Items in a List Box**
Ilustra como gerenciar vários itens selecionados em uma caixa de lista.
**Amostra Present a User with Multiple Choices**
Ilustra como usar um grupo de botões de opção para apresentar várias escolhas.
**Amostra Open Multiple Files Interactively**
Ilustra como exibir arquivos em uma lista.
**Amostra Resize and Reposition Controls at Run Time**
Ilustra como redimensionar um formulário conforme desejado e fazer com que os controles no formulário se redimensionem ou reposicionem em relação às novas dimensões do formulário.
**Amostra See Check Box Design Options**
Ilustra uma variedade de propriedades usadas para personalizar a exibição de caixas de seleção.
**Amostra See Command Button Design Options**
Ilustra uma variedade de propriedades usadas para personalizar a exibição de botões de comando.
**Amostra Sort List Box Items**
Ilustra como permitir que o usuário reorganize ou classifique itens em uma caixa de lista.
**Amostra Treeview/Listbox Drag and Drop**
Ilustra como definir as propriedades de arrastar e soltar para controles tree view e caixa de lista.
