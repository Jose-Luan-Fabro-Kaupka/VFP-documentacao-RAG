# Não é possível atualizar o projeto a partir do metafile do projeto (Erro 1909)

Há um conflito no metafile do projeto (arquivo .PJM).
 - Você editou o arquivo .PJM diretamente. Restaure o arquivo para uma versão anterior e use a interface para fazer alterações: desfaça o checkout do arquivo .PJM e atualize a lista do projeto.
- Há um conflito na seção de informações do projeto do arquivo .PJM. Resolva o conflito removendo apenas linhas completas, se possível.
- A formatação no metafile do projeto está incorreta. Por exemplo, algumas informações têm um tipo de dados inesperado ou vírgulas estão mal posicionadas.
