# Janela Editing

Fornece edição de arquivos de texto e programa. Se você selecionou Modify Selected File na guia Projects da caixa de diálogo Options, a janela Editing abre quando você clica duas vezes em um arquivo de texto ou programa no Project Manager.

Na janela Editing, você pode:
 - Mover texto dentro da janela Command e para outras janelas de edição. Selecione o texto desejado e arraste-o para o local desejado.
- Copiar texto dentro da janela Command e colá-lo em outras janelas de edição sem usar comandos do menu Edit. Selecione o texto desejado, mantenha CTRL pressionado e arraste o texto para o local desejado.

Altere fonte, espaçamento entre linhas e indentação selecionando o comando apropriado no menu Format.
