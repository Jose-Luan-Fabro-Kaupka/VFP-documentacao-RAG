# NULL como valor

Um valor nulo é diferente de uma cadeia de caracteres vazia, um campo em branco ou zero. Por exemplo, tanto EMPTY( ) quanto ISBLANK( ) retornam true (.T.) quando uma variável contém em branco ou uma cadeia de caracteres vazia. EMPTY( ) também retorna true (.T.) para zero. ISNULL( ) retorna false (.F.) para esses valores e tanto EMPTY( ) quanto ISBLANK( ) retornam false (.F.) para valores nulos.

Você pode usar valores nulos com comandos de matriz e campo como STORE, GATHER e SCATTER. O exemplo a seguir atribui .`NULL`. a cada membro da matriz `aX`:

```foxpro
DIMENSION aX[4]
STORE .NULL. TO aX
```

O valor nulo não é um tipo de dados. Quando você atribui .NULL. a um campo ou variável, o valor muda para .NULL., mas o tipo de dados do campo ou variável não muda. Por exemplo:

```foxpro
STORE 5 TO nX
nX = .NULL.
? TYPE ("nX")  && Data type reported as numeric
```
