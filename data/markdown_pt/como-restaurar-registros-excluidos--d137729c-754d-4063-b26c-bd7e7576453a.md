# Como: restaurar registros excluídos

Você pode restaurar registros que estão marcados para exclusão, mas ainda não foram removidos.

### Para restaurar um registro marcado para exclusão
- Abra a tabela em uma janela browse.
- Na janela browse, insira o cursor no registro marcado para exclusão.
- No menu Table, clique em Toggle Deletion Mark . Dica Você também pode clicar na coluna de exclusão ao lado do registro marcado para exclusão para remover o marcador de exclusão. O marcador de exclusão é removido da coluna de exclusão.

### Para restaurar vários registros marcados para exclusão
- Abra a tabela em uma janela browse.
- No menu Table, clique em Recall Records A caixa de diálogo Recall abre.
- Na caixa Scope da caixa de diálogo Recall, selecione o intervalo de registros que deseja restaurar.
- Na caixa For, digite uma expressão que os registros devem atender para serem incluídos na restauração. Para construir uma expressão, clique no botão reticências (...).
- Na caixa While, digite uma expressão que avalia como true para continuar avaliando registros a incluir na restauração.
- Quando terminar, clique em Recall .

Para obter mais informações, consulte Caixa de diálogo Recall (Records).

### Para restaurar registros excluídos programaticamente
- Use o comando RECALL.

Para obter mais informações, consulte Comando RECALL.
