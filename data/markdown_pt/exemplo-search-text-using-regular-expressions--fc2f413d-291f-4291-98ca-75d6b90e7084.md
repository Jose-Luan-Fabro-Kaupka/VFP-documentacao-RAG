# Exemplo Search Text Using Regular Expressions

Arquivo: ...\Samples\Solution\FFC\Regexp.scx

Este exemplo ilustra como você pode usar pesquisa por expressões regulares nas suas aplicações e usa a Classe Foundation Regular Expressions, que fornece acesso a rotinas para usar expressões regulares. Expressões regulares fornecem um conjunto mais complexo de critérios de pesquisa/filtro em uma seleção de texto do que a pesquisa por padrão curinga disponível na caixa de diálogo Find.
 Este exemplo contém as seguintes classes
| Classe | Biblioteca | Descrição |
| --- | --- | --- |
| _regexp | _ regexp.vcx | Fornece métodos para realizar capacidades de pesquisa por expressão regular em um bloco de texto. |
