# Guia Value, Text Box Builder

Esta guia no Text Box builder especifica um campo no qual armazenar o valor da caixa de texto.
 **Field Name**
Especifica um campo de tabela ou view no qual armazenar o valor da caixa de texto. Escolha o botão de diálogo para exibir a caixa de diálogo Open para que você possa selecionar um arquivo. Esta opção corresponde à propriedade ControlSource.
