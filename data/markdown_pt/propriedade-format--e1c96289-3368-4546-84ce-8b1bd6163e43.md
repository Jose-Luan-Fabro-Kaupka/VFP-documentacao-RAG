# Propriedade Format

Especifica a formatação de entrada e saída da propriedade Value de um controle. Disponível em tempo de design e em tempo de execução.

```foxpro
Control.Format[ = cFunction]
```

# Valor de retorno
 **cFunction**
Especifica as restrições de caracteres para entrada de dados e formatação para exibição. F Impede que valores Varchar sejam preenchidos com espaços à direita em caixas de texto ou que valores Varbinary sejam preenchidos com zeros (0s) à direita. Observação Para caixas de texto vinculadas a dados com tipo Varchar, a propriedade MaxLength deve ser definida com um valor diferente de zero para permitir entrada do número desejado de caracteres. Quando você arrasta um controle Grid para um formulário e cria controles TextBox para colunas com tipo Varchar, a propriedade Format é definida como "F" e a propriedade MaxLength é definida com a largura máxima do campo Varchar. Os delimitadores de data / / não são exibidos, a menos que o controle tenha foco.

# Observações

Aplica-se a: Column Object | ComboBox Control | EditBox Control | Spinner Control | TextBox Control (Visual FoxPro)

A propriedade Format especifica um comportamento para todo o campo de entrada. Você pode misturar vários códigos Format, mas eles sempre afetam tudo no campo de entrada. Esta propriedade contrasta com a propriedade InputMask na qual cada entrada na máscara de entrada corresponde a uma entrada no campo de entrada.

A propriedade Format imita o comportamento da cláusula FUNCTION nos comandos @ ... GET e @ ... EDIT.
