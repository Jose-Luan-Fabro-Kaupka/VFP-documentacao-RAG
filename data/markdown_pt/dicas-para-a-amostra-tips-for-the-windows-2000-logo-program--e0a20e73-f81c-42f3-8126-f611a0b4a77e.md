# Dicas para a amostra Tips for the Windows 2000 Logo Program

Arquivo: ...\Samples\Solution\FFC\Logo.scx

Aplicativos personalizados podem ser enviados para receber o Windows 2000 Logo. Há vários requisitos que seu aplicativo deve atender para obter o Logo (consulte http://www.microsoft.com/winlogo). Esta amostra mostra várias Foundation Classes que fornecem informações que podem ser úteis para tornar seu aplicativo compatível com o Logo.
 Esta amostra contém as seguintes classes
| Classe | Biblioteca | Descrição |
| --- | --- | --- |
| _sysmetrics | _ system.vcx | Retorna informações do sistema, como número de botões do mouse, número de monitores e se um mousewheel está presente. |
| _userpriv | _ system.vcx | Retorna os direitos de acesso do usuário conectado (convidado, usuário avançado, administrador). |
| _commonfolder | _ system.vcx | Retorna o caminho para pastas comuns do sistema, como Meus Documentos. |

Para detalhes sobre todas as classes disponíveis nas foundation classes, consulte Foundation Classes do Visual FoxPro A-Z.
