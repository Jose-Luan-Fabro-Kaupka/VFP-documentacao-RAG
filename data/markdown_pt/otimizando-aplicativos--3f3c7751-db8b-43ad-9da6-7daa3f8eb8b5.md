# Otimizando aplicativos

Quando você usa o Visual FoxPro para projetar e executar aplicativos, deseja obter o melhor desempenho do seu sistema operacional, do Visual FoxPro e do seu aplicativo.

# Nesta seção
 **Optimizing Tables and Indexes**
Descreve como você pode acelerar o acesso a dados em tabelas usando índices e usando o buffer de forma eficiente. Além disso, você pode usar a tecnologia Rushmore Query Optimization para otimizar suas consultas.
**Using Rushmore Query Optimization to Speed Data Access**
Explica que o Visual FoxPro inclui a tecnologia de acesso a dados Rushmore para ajudar a otimizar o desempenho dos seus aplicativos.
**Optimizing Forms and Controls**
Descreve como você pode fazer melhorias significativas nos formulários e controles do seu aplicativo.
**Optimizing Programs**
Discute como você pode escrever os programas mais rápidos possíveis escrevendo seu código com cuidado.
**Optimizing ActiveX Controls**
Explica que, se você usa Automation ou controles Microsoft ActiveX no seu aplicativo, pode ajustar o aplicativo para obter o melhor desempenho dos controles ActiveX e da automação.
**Optimizing Access to Remote Data**
Descreve o custo da recuperação de dados de qualquer banco de dados remoto.
**Optimizing International Applications**
Explica que, se você está desenvolvendo aplicativos internacionais, pode querer gerenciar a sequência de classificação dos seus dados para desempenho ideal.

# Seções relacionadas
 **Programming in Visual FoxPro**
Descreve como você pode acessar todo o poder do Visual FoxPro usando técnicas de programação orientada a objetos e o modelo orientado a eventos ao criar aplicativos.
**Working with Programs**
Descreve como escrever e trabalhar com arquivos de programa Visual FoxPro (.prg), que são arquivos de texto contendo instruções usando a linguagem Visual FoxPro.
**Object-Oriented Programming**
Descreve como você pode usar programação orientada a objetos para criar componentes de aplicativo autocontidos que respondem a ações do usuário e ao sistema e que podem ser facilmente mantidos e reutilizados.
**Accessing APIs**
Descreve como estender o Visual FoxPro se o seu aplicativo tiver requisitos que não podem ser atendidos pelos recursos integrados do Visual FoxPro, aproveitando bibliotecas externas como controles Microsoft® ActiveX® ou bibliotecas de vínculo dinâmico (DLLs).
