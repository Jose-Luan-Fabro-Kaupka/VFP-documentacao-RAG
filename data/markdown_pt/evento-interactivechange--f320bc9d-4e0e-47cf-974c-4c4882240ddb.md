# Evento InteractiveChange

Ocorre quando o usuário altera o valor de um controle usando o teclado ou o mouse.

```foxpro
PROCEDURE Control.InteractiveChange
```

# Observações

Aplica-se a: CheckBox Control | ComboBox Control | CommandGroup Control | EditBox Control | ListBox Control | OptionGroup Control | Spinner Control | TextBox Control (Visual FoxPro)

Este evento ocorre cada vez que o valor do objeto muda interativamente. Por exemplo, conforme um usuário digita em uma caixa de texto, o evento InteractiveChange é acionado após cada tecla pressionada.
