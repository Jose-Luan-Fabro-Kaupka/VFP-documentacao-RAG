# Evento MouseMove

Ocorre quando o usuário move o mouse sobre um objeto.

```foxpro
PROCEDURE Object.MouseMove
LPARAMETERS nButton, nShift, nXCoord, nYCoord
```

#### Parâmetros

Você deve incluir uma instrução LPARAMETERS ou PARAMETERS no procedimento do evento e especificar um nome para cada parâmetro. O Visual FoxPro passa os parâmetros do evento MouseMove na seguinte ordem:
 **nButton**
Contém um número que especifica qual botão do mouse estava sendo pressionado enquanto o mouse era movido, conforme listado na tabela a seguir: Valores de botão do mouse para nButton Windows Valor nButton Botão esquerdo do mouse 1 Botão direito do mouse 2 Botão do meio do mouse 4 Se mais de um botão do mouse estiver pressionado enquanto o mouse é movido, nButton contém a soma dos valores dos botões do mouse. Por exemplo, se os botões esquerdo e direito do mouse estiverem pressionados, o valor de nButton é 3.
**nShift**
Contém um número que especifica o estado das teclas modificadoras quando o mouse é movido. No Visual FoxPro para Windows, as teclas modificadoras válidas são as teclas SHIFT, CTRL e ALT. Os valores retornados em nShift para teclas modificadoras individuais estão listados na tabela a seguir. Valores de teclas modificadoras para nShift Tecla Windows Valor SHIFT 1 CTRL 2 ALT 4 Se mais de uma tecla modificadora estiver pressionada quando o mouse é pressionado, o argumento nShift contém a soma dos valores das teclas modificadoras. Por exemplo, no Visual FoxPro para Windows, se o usuário mantém CTRL pressionado ao pressionar o botão do mouse, o argumento nShift contém 2. Mas se o usuário mantém CTRL+ALT pressionado ao pressionar o botão do mouse, o argumento nShift contém 6.
**nXCoord , nYCoord**
Contém a posição horizontal (nXCoord) e vertical (nYCoord) atual do ponteiro do mouse no formulário. Essas coordenadas são sempre expressas em termos do sistema de coordenadas do formulário, na unidade de medida especificada na configuração da propriedade ScaleMode.

O evento MouseMove é disparado continuamente conforme o ponteiro do mouse se move sobre objetos.

> **Observação:** Você pode usar os eventos MouseDown e MouseUp para responder a eventos causados por pressionar e liberar botões do mouse. O parâmetro nButton para MouseMove difere do parâmetro nButton para MouseDown e MouseUp. Para MouseMove, o parâmetro nButton indica o estado atual de todos os botões; um único evento MouseMove pode indicar que alguns, todos ou nenhum botão está pressionado. Para MouseDown ou MouseUp, o parâmetro nButton indica exatamente um botão por evento. Evite mover uma janela dentro de um procedimento de evento MouseMove; isso pode causar eventos em cascata e gerar erros de tempo de execução, como estouro de pilha. Eventos MouseMove são disparados quando a janela se move sob o ponteiro. Um evento MouseMove pode ser disparado mesmo se o mouse estiver parado.
