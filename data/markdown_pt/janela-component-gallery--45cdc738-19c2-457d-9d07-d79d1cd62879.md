# Janela Component Gallery

A janela Component Gallery exibe, como ícones de atalho, componentes disponíveis para seus projetos, aplicações, designers, wizards e builders do Visual FoxPro, permitindo que você gerencie, de várias maneiras, qualquer arquivo disponível em seu sistema.

A janela Component Gallery contém uma Component Gallery Toolbar mais as seguintes opções:
 **Painel Catalog (esquerdo)**
Exibe a hierarquia de catálogos e pastas do Component Gallery. Selecione um catálogo ou pasta aqui para exibir os itens do contêiner no painel Object à direita.
**Painel Object (direito)**
Exibe itens contidos em um catálogo ou pasta. Para obter informações sobre como usar itens no Component Gallery, consulte Using the Component Gallery .
**Caixa Description**
Fornece informações sobre o item selecionado. A barra de status do Visual FoxPro relata o status do processo do Component Gallery.
