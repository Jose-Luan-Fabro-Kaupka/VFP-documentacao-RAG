# Comando SET NOCPTRANS

Impede a tradução para uma página de código diferente para campos selecionados em uma tabela aberta.

```foxpro
SET NOCPTRANS TO [FieldName1 [, FieldName2 ...]]
```

#### Parâmetros
 **TO [ FieldName1 [, FieldName2 ...]]**
Especifica os campos que não devem ser traduzidos para outra página de código. Emita SET NOCPTRANS TO sem um conjunto de campos para retornar à tradução padrão (estabelecida pelo item de configuração CODEPAGE) para todos os campos de caractere e memo em uma tabela. Use SET("NOCPTRANS") para retornar os campos especificados no último comando SET NOCPTRANS que você emitiu. Use a função CHR( ) para garantir que caracteres individuais não sejam traduzidos.

# Observações

Como o Microsoft Visual FoxPro pode ser configurado para traduzir automaticamente campos de caractere e memo para outras páginas de código, o comando SET NOCPTRANS está disponível para impedir a tradução automática de campos que contêm dados binários. Por exemplo, um campo memo pode conter um documento do Microsoft Word. Quando você acessa o documento Word, deseja o documento em sua forma original, não traduzida. Use SET NOCPTRANS para especificar que o campo memo não seja traduzido.

Você não precisa usar SET NOCPTRANS para acessar dados binários se o campo de caractere ou memo contendo os dados binários não foi traduzido. Você pode garantir que campos de caractere e memo não sejam traduzidos omitindo o item de configuração CODEPAGE do seu arquivo de configuração do Visual FoxPro.

Para obter informações adicionais sobre páginas de código e o suporte internacional do Visual FoxPro, consulte Code Pages Supported by Visual FoxPro in Developing International Applications.
