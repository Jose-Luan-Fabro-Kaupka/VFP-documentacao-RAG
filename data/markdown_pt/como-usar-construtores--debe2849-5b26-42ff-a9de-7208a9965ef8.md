# Como: usar construtores

Você pode usar construtores para alguns controles, para formulários, para formatar controles e para criar integridade referencial entre tabelas de banco de dados.

### Para construir um controle
- Na barra de ferramentas Form Controls, escolha o botão Builder Lock. Cada vez que você adiciona um novo controle a um formulário, o Visual FoxPro exibe o construtor apropriado. -ou-
- Selecione um controle no formulário e escolha o botão Builder na janela Properties.

### Para usar o Form Builder
- No menu Form, escolha Quick Form .

Quando você tem vários controles em um formulário, pode formatá-los todos ao mesmo tempo com o AutoFormat Builder.

### Para formatar vários controles
- No Form Designer , selecione os controles.
- Na barra de ferramentas Form Designer, escolha o botão AutoFormat.

Quando um construtor é exibido, selecione as opções de cada guia e, em seguida, escolha OK para registrar as alterações.
