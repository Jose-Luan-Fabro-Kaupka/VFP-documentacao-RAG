# Caixa de diálogo Customize Toolbox

Exibe opções para alterar configurações da Toolbox e editar categorias e itens exibidos na Toolbox.
 **Selection Treeview**
Exibe as áreas que você pode modificar e alterar configurações para a Toolbox.

# Opções

Exibe as opções gerais para definir o comportamento da Toolbox.
 **Run associated builder**
Especifica que os builders são exibidos automaticamente no Forms Designer quando você cria um controle que tem um builder registrado nele.
**Display toolbox help text section**
Especifica se a seção de texto de ajuda na Toolbox é exibida.
**Show tooltips**
Especifica se ToolTips são exibidas para itens de categoria.
**Always on top**
Especifica se a Toolbox deve aparecer na frente de outras janelas.
**Double-click to open an item**
Especifica se um item de hiperlink na Toolbox precisa de um clique duplo ou de um clique simples para ser aberto.
**Set CurrentControl property when a control is dropped on a grid column**
Especifica que o Visual FoxPro deve alterar automaticamente o valor da propriedade CurrentContro l quando um controle é solto em uma coluna de grade a partir da Toolbox.
**Prompt to remove Text1 control when dropping new control on a grid column**
Especifica que o Visual FoxPro deve remover automaticamente o controle Text1 da coluna de grade quando um novo controle é solto em uma coluna de grade a partir da Toolbox.
**Allow toolbox to be minimized**
Especifica se o botão de controle de minimização da Toolbox deve ser exibido para que a Toolbox possa ser minimizada.
**Category scroll speed**
Especifica a velocidade, em milissegundos, com que uma categoria rolará quando o mouse estiver sobre um widget de rolagem para cima ou para baixo na Toolbox.
**Toolbox table**
Especifica a tabela para a Toolbox salvar configurações.
**Font**
Define os atributos de fonte usados para a Toolbox.
**Clean Up Toolbox**
Remove itens excluídos da tabela Toobox.
**Restore to Default**
Restaura a Toolbox ao seu estado padrão.

# Class Items

Exibe opções de como as classes são exibidas e usadas a partir da Toolbox.
 **Default naming convention for classes added to Toolbox**
Especifica a convenção de nomenclatura de como uma classe é exibida na Toolbox.
**Drag and drop text template**
Especifica qual texto será adicionado quando você arrastar e soltar uma classe da Toolbox.
**CTRL+Drag and drop text template**
Especifica o texto a ser adicionado quando você CTRL+Arrastar uma classe da Toolbox.
**Edit**
Abre um editor, que tem IntelliSense e coloração de sintaxe, para alterar o texto de arrastar e soltar ou CTRL+Arrastar.

# Filters

Exibe opções para gerenciar seus filtros para a Toolbox.
 **New Filter**
Cria um novo filtro e seleciona-o para edição.
**Delete Filter**
Solicita a exclusão do filtro atualmente selecionado.
**Apply Filter**
Aplica o filtro atualmente selecionado à Toolbox.
**Clear Filter**
Remove os efeitos de um filtro da Toolbox.
**Filter Name**
Especifica o nome do filtro atualmente selecionado.
**Update**
Salva quaisquer alterações feitas no nome do filtro que foram feitas no campo de nome do filtro.
**Defined Filters**
Exibe uma lista de filtros que podem ser aplicados à Toolbox.
**Select toolbox categories that belong to this filter.**
Exibe uma lista de opções de filtro que podem ser aplicadas com um filtro.

# Categories

Exibe opções para gerenciar as categorias na Toolbox.
 **Add Category**
Exibe uma caixa de diálogo para adicionar uma nova categoria à Toolbox.
**Remove Category**
Solicita a exclusão da categoria atualmente selecionada.
**Category Properties**
Exibe uma caixa de diálogo que contém informações sobre as propriedades da categoria atualmente selecionada.
**Refresh Category**
Atualiza a Toolbox com quaisquer alterações feitas na categoria atualmente selecionada.
**Refresh Toolbox**
Atualiza a Toolbox com quaisquer alterações feitas em todas as categorias exibidas na Toolbox.
**Select an item to view**
Especifica o tipo de itens que são mostrados na lista de itens de uma categoria específica.
**Show checked items only**
Especifica que apenas itens na lista de itens que estão selecionados e aparecem na categoria são visíveis.
**Add Item**
Exibe uma caixa de diálogo usada para adicionar um novo item à categoria atualmente selecionada.
**Remove Item**
Solicita a remoção de um item da categoria atualmente selecionada.
**Item Properties**
Exibe uma caixa de diálogo que contém informações sobre as propriedades do item atualmente selecionado.
**Sort Alphabetically**
Classifica os itens na lista de itens para serem exibidos em ordem alfabética.
