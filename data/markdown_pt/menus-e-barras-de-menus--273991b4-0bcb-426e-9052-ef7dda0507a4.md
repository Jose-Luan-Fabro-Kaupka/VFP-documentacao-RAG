# Menus e barras de menus

Estes comandos e funções permitem desenvolver, exibir e ativar menus e barras de menus definidos pelo usuário.

| Use | Para |
| --- | --- |
| \ | \\ Command | Imprimir ou exibir linhas de texto. |
| ACTIVATE POPUP Command | Exibir e ativar um menu. |
| BAR( ) Function | Retornar o número do item escolhido mais recentemente em um menu definido com DEFINE POPUP ou de um item escolhido em um menu do Visual FoxPro. |
| BARPROMPT( ) Function | Incluída para compatibilidade com dBASE. |
| CLEAR Commands | Liberar da memória o item ou os itens especificados. |
| CLEAR Commands | Liberar da memória o item ou os itens especificados. |
| CNTBAR( ) Function | Retornar o número de itens de menu em um menu definido pelo usuário ou no menu do sistema do Visual FoxPro. |
| CNTPAD( ) Function | Retornar o número de títulos em uma barra de menus definida pelo usuário ou na barra de menus do sistema do Visual FoxPro. |
| CREATE MENU Command | Abrir o Menu Designer no Visual FoxPro. |
| DEACTIVATE MENU Command | Desativar uma barra de menus definida pelo usuário e removê-la da tela. |
| DEACTIVATE POPUP Command | Desativar um menu criado com DEFINE POPUP. |
| DEFINE BAR Command | Criar um item em um menu criado com DEFINE POPUP. |
| DEFINE MENU Command | Criar uma barra de menus. |
| DEFINE PAD Command | Criar um título de menu (pad) em uma barra de menus definida pelo usuário ou na barra de menus do sistema do Visual FoxPro. |
| DEFINE POPUP Command | Criar um menu. |
| GETBAR( ) Function | Retornar o número de um item em um menu definido com DEFINE POPUP ou no menu do sistema do Visual FoxPro. |
| GETPAD( ) Function | Retornar o título de menu de uma determinada posição na barra de menus. |
| HIDE MENU Command | Ocultar uma ou mais barras de menus ativas definidas pelo usuário. |
| HIDE POPUP Command | Ocultar um ou mais menus ativos criados com DEFINE POPUP. |
| MODIFY MENU Command | Abrir o Menu Designer para modificar ou criar um sistema de menus. |
| MOVE POPUP Command | Mover um menu definido pelo usuário, criado com DEFINE POPUP, para um novo local. |
| MRKBAR( ) Function | Determinar se um item de menu definido pelo usuário ou do sistema do Microsoft Visual FoxPro está marcado. |
| MRKPAD( ) Function | Determinar se um título de menu em uma barra definida pelo usuário ou do sistema do Visual FoxPro está marcado. |
| ON BAR Command | Especificar um menu ou barra de menus ativado quando você escolhe um item específico. |
| ON EXIT BAR Command | Incluído para compatibilidade com dBASE. |
| ON EXIT MENU Command | Incluído para compatibilidade com dBASE. |
| ON EXIT PAD Command | Incluído para compatibilidade com dBASE. |
| ON EXIT POPUP Command | Incluído para compatibilidade com dBASE. |
| ON PAD Command | Especificar o menu ou barra de menus ativado quando você escolhe um título específico. |
| ON SELECTION BAR Command | Especificar um comando executado quando você escolhe um item específico. |
| ON SELECTION MENU Command | Especificar um comando executado quando você escolhe qualquer título em uma barra de menus. |
| ON SELECTION PAD Command | Especificar um comando executado quando você escolhe um título específico. |
| ON SELECTION POPUP Command | Especificar um comando executado quando você escolhe qualquer item de um menu especificado ou de todos os menus. |
| PAD( ) Function | Retornar, como cadeia de caracteres em maiúsculas, o título escolhido mais recentemente em uma barra de menus, ou um valor lógico indicando se um título está definido para uma barra ativa. |
| POP MENU Command | Restaurar a definição de barra de menus colocada na pilha com PUSH MENU. |
| POP POPUP Command | Restaurar a definição de menu colocada na pilha com PUSH POPUP. |
| POPUP( ) Function | Retornar como cadeia de caracteres o nome do menu ativo, ou um valor lógico indicando se um menu foi definido. |
| PRMBAR( ) Function | Retornar o texto de um item de menu. |
| PRMPAD( ) Function | Retornar o texto de um título de menu. |
| PROMPT( ) Function | Retornar o texto de um título escolhido em uma barra de menus ou de um item escolhido em um menu. |
| PUSH MENU Command | Colocar uma definição de barra de menus em uma pilha de definições na memória. |
| PUSH POPUP Command | Colocar uma definição de menu em uma pilha de definições na memória. |
| RELEASE BAR Command | Remover da memória um item específico ou todos os itens de um menu. |
| RELEASE MENUS Command | Remover da memória barras de menus definidas pelo usuário. |
| RELEASE PAD Command | Remover da memória um título específico ou todos os títulos de menu. |
| RELEASE POPUPS Command | Remover da memória um menu específico ou todos os menus. |
| SET MARK OF Command | Especificar, exibir ou limpar um caractere de marca para títulos ou itens de menu. |
| SET SKIP OF Command | Habilitar ou desabilitar menu, barra, título ou item em menus definidos pelo usuário ou no menu do sistema. |
| SIZE POPUP Command | Alterar o tamanho de um menu criado com DEFINE POPUP. |
| SKPBAR( ) Function | Determinar se um item de menu está habilitado ou desabilitado com SET SKIP OF. |
| SKPPAD( ) Function | Determinar se um título de menu está habilitado ou desabilitado com SET SKIP OF. |
| SHOW MENU Command | Exibir uma ou mais barras de menus definidas pelo usuário sem ativá-las. |
| SHOW POPUP Command | Exibir um ou mais menus definidos com DEFINE POPUP sem ativá-los. |
| SYS(2013) - System Menu Name String | Retornar uma cadeia de caracteres delimitada por espaços contendo os nomes internos do sistema de menus do Visual FoxPro. |
