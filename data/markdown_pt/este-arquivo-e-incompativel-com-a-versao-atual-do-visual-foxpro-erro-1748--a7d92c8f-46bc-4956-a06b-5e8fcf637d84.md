# Este arquivo é incompatível com a versão atual do Visual FoxPro (Erro 1748)

Um arquivo criado em uma versão pré-lançamento do Visual FoxPro 3.0 não é compatível com a versão atual do Visual FoxPro. Execute 30Update.prg, incluído com a versão pré-lançamento do Visual FoxPro 3.0, para converter o arquivo para um formato atual.
