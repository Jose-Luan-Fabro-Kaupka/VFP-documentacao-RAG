# Classe base Stop Watch

Esta classe, quando colocada em um formulário, fornece um controle de cronômetro.

| Categoria | Data/Hora |
| --- | --- |
| Catálogo padrão | Visual FoxPro Catalog\Foundation Classes\Date/Time |
| Classe | _stopwatch |
| Classe base | Container |
| Biblioteca de classes | _datetime.vcx |
| Classe pai | _container |
| Exemplo | ...\Samples\Solution\Controls\Timer\swatch.scx |

# Observações

Para usar, solte a classe em um projeto ou formulário ou, no menu de atalho do item da Galeria de Componentes, selecione Add to Project ou Add to Form. Quando você adiciona a classe a um formulário, o Visual FoxPro coloca o ícone no formulário onde ele será executado no formulário ativo. Quando você solta a classe em um projeto, pode escolher entre adicionar a classe ou criar uma subclasse.

| Propriedades, eventos, métodos | Descrição |
| --- | --- |
| Método Increment | Incrementa a exibição do cronômetro. Sintaxe: Increment( ) Retorno: nenhum Argumentos: nenhum |
| Método Reset | Reinicia o cronômetro. Sintaxe: Reset( ) Retorno: nenhum Argumentos: nenhum |
| Método Start | Inicia o cronômetro. Sintaxe: Start( ) Retorno: nenhum Argumentos: nenhum |
| Método Stop | Para o cronômetro. Sintaxe: Stop( ) Retorno: nenhum Argumentos: nenhum |
| Método UpdateDisplay | Atualiza a exibição. Sintaxe: UpdateDisplay( ) Retorno: nenhum Argumentos: nenhum |
