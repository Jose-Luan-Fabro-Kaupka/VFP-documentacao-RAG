# Comando RELEASE BAR

Remove da memória um item de menu especificado ou todos os itens de menu de um menu.

```foxpro
RELEASE BAR nMenuItemNumber OF MenuName | ALL OF MenuName
```

#### Parâmetros
 **nMenuItemNumber OF MenuName**
Especifica um item de menu em um menu definido pelo usuário a ser removido da memória. Para remover um item de menu de um menu do sistema Microsoft Visual FoxPro, inclua o nome interno do item de menu do sistema Visual FoxPro em nMenuItemNumber . Para obter mais informações, consulte o tópico online System Menu Names.
**ALL OF MenuName**
Especifica que todos os itens de menu de um menu definido pelo usuário são removidos da memória. ALL não pode ser usado para remover itens de menu de um menu do sistema Visual FoxPro.
