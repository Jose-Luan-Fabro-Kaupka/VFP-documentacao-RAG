# SYS(3099) - Modo de compatibilidade do mecanismo de dados SQL

Habilita a compatibilidade do mecanismo de dados SQL com o Visual FoxPro 7.0, 8.0 ou 9.0.

```foxpro
SYS(3099 [, 70 | 80 | 90])
```

#### Parâmetros
 **70**
Especifica que o Visual FoxPro trate comandos SQL com comportamento como em versões anteriores ao Visual FoxPro 8.0.
**80**
Especifica que o Visual FoxPro trate comandos SQL com comportamento como no Visual FoxPro 8.0.
**90**
Especifica que o Visual FoxPro trate comandos SQL com o padrão do Visual FoxPro 9.0. (Padrão)
