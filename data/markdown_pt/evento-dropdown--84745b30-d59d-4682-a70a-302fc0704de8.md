# Evento DropDown

Ocorre quando a parte de lista de um controle ComboBox está prestes a ser exibida após o clique na seta de drop-down.

```foxpro
PROCEDURE ComboBox.DropDown
```

# Observações

Aplica-se a: ComboBox Control

Use um procedimento de evento DropDown para fazer atualizações finais na parte de lista de um ComboBox antes que o usuário faça uma seleção. Isso permite adicionar ou remover itens da lista usando o método AddItem ou RemoveItem. Essa flexibilidade é útil se você deseja que os controles interajam em tempo de execução. Por exemplo, o que você deseja que apareça na parte de lista de um ComboBox pode ser determinado pelo que o usuário escolhe em um OptionGroup.

No Visual FoxPro 9.0 você pode incluir o comando NODEFAULT dentro do procedimento de evento DropDown para impedir que a parte de lista de um controle ComboBox seja exibida. Incluir NODEFAULT impede que o usuário acessar a parte de lista, com o mouse ou com o teclado.
