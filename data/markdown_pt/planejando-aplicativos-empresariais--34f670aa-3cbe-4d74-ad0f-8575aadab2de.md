# Planejando aplicativos empresariais

Muitos aplicativos que você cria com Visual FoxPro são soluções autocontidas para um requisito de negócio específico. Por exemplo, você pode criar um aplicativo Visual FoxPro para rastrear seus clientes, que pode incluir não apenas informações de banco de dados sobre os clientes, mas ferramentas para receber pedidos, faturar e assim por diante. Você pode criar todos os recursos que seu aplicativo precisa usando as instalações já disponíveis no Visual FoxPro, incluindo seu mecanismo de banco de dados, ferramentas de design visual e recursos de relatório.

Você também pode usar o Visual FoxPro como parte de um aplicativo de maior escala que envolve duas ou mais ferramentas de desenvolvimento. Usar o Visual FoxPro dessa forma — referido como "desenvolvimento empresarial" — permite aproveitar os recursos exclusivos de cada produto. O desenvolvimento empresarial pode ser tão simples quanto manter um banco de dados de clientes no Visual FoxPro e criar uma carta de mala direta no Microsoft Word, ou pode envolver a criação de um aplicativo complexo usando bancos de dados client/server, Automation servers, correio eletrônico e muito mais.

O Visual FoxPro é uma ferramenta ideal para criar soluções de negócios em toda a empresa porque oferece:
 - Ferramentas de desenvolvimento de aplicativos poderosas e fáceis de usar, incluindo um Form Designer e wizards.
- Um mecanismo de banco de dados rápido.
- Excelente conectividade com outros produtos, incluindo outros programas Windows como Microsoft Excel e Word, e sistemas client/server como Microsoft SQL Server.
- Controle de código-fonte integrado e outras ferramentas de desenvolvimento em equipe.

Esses recursos permitem desenvolver com Visual FoxPro em vários papéis em um aplicativo em toda a empresa. Você pode usar o Visual FoxPro:
 - Como front end para outros aplicativos. Neste cenário, você trabalha principalmente com Visual FoxPro; por exemplo, cria a interface do usuário para o aplicativo no Visual FoxPro. Em seguida, acessa outros aplicativos que contêm dados necessários para o aplicativo ou que podem fornecer serviços que aprimoram os já disponíveis no Visual FoxPro. Você também pode fazer upsize de seus dados Visual FoxPro ou movê-los para outra plataforma.
- Como fonte de dados para outros aplicativos. Para fazer isso, você criaria a interface do usuário para o aplicativo usando outro programa e acessaria os dados Visual FoxPro conforme necessário.

A estratégia que você escolhe depende de quais são os objetivos do seu aplicativo e quais programas deseja usar.
