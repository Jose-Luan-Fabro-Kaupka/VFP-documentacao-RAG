# Classe base GDI Plus Graphics

A classe gpGraphics encapsula uma superfície de desenho GDI+. Ela fornece métodos para desenhar em uma janela ou outra tela.

| Categoria | Relatórios |
| --- | --- |
| Catálogo padrão | Visual FoxPro Catalog\Foundation Classes\Output\GDIplus |
| Class | gpGraphics |
| Classe base | Custom |
| Biblioteca de classes | _GDIPLUS.vcx |
| Classe pai | gpObject ( Classe base GDI Plus Object ) |
