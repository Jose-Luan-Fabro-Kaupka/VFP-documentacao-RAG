# Propriedade ThreadID

Retorna o ID Win32 da thread na qual o objeto foi chamado.

```foxpro
_VFP.ThreadID
```

# Observações

Aplica-se a: Application Object | _VFP System Variable

Você pode usar esta propriedade especialmente durante a depuração. Por exemplo, você pode usá-la para comparar o threadID de uma chamada recebida com o threadID do objeto que recebe a chamada.
