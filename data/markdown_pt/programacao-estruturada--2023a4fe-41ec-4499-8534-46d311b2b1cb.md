# Programação estruturada

Estes comandos e funções permitem controlar a execução e os desvios em um programa do Visual FoxPro.

| Use | Para |
| --- | --- |
| Comando DO CASE ... ENDCASE | Executar o primeiro conjunto de comandos cuja expressão condicional seja avaliada como true (.T.). |
| Comando DO WHILE ... ENDDO | Executar um conjunto de comandos dentro de um loop condicional. |
| Comando EXIT | Sair de um loop DO WHILE, FOR ou SCAN. |
| Comando FOR EACH ... ENDFOR | Executar um conjunto de comandos para cada elemento de um array ou coleção do Visual FoxPro. |
| Comando FOR ... ENDFOR | Executar um conjunto de comandos um número especificado de vezes. |
| Diretiva de pré-processador #IF ... #ENDIF | Incluir condicionalmente código-fonte em tempo de compilação. |
| Diretiva de pré-processador #IFDEF | #IFNDEF ... #ENDIF | Incluir condicionalmente um conjunto de comandos em tempo de compilação se uma constante de compilação estiver definida. |
| Função ICASE( ) | Avaliar os resultados de uma lista de condições. |
| Comando IF ... ENDIF | Executar condicionalmente um conjunto de comandos com base no valor de uma expressão lógica. |
| Função IIF( ) | Retornar um de dois valores conforme o valor de uma expressão lógica. |
| Comando LOOP | Retornar o controle do programa diretamente ao início de uma estrutura de repetição. |
| Comando SCAN ... ENDSCAN | Mover o ponteiro de registro pela tabela selecionada e executar um bloco de comandos para cada registro que atenda às condições especificadas. |
