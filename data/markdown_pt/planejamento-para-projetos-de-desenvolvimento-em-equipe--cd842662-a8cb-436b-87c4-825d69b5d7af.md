# Planejamento para projetos de desenvolvimento em equipe

Você pode criar aplicações complexas rapidamente combinando as habilidades de uma equipe de desenvolvedores. No entanto, o desenvolvimento em equipe requer alguma coordenação extra para manter o esforço de desenvolvimento funcionando sem problemas. Uma estratégia é usar software de controle de código-fonte, como o Microsoft Visual SourceSafe, para gerenciar os arquivos em um projeto.

Os tópicos a seguir fornecem estratégias que você pode seguir para tornar o desenvolvimento em equipe bem-sucedido. Eles assumem que você já está familiarizado com a criação de uma aplicação Visual FoxPro, conforme discutido em outras seções.

# Nesta seção
 **Conceitos de desenvolvimento em equipe (Visual FoxPro)**
Descreve como você pode criar aplicações mais rapidamente e desenvolver aplicações mais complexas trabalhando com uma equipe de desenvolvedores.
**Recursos de controle de código-fonte**
Explica que o Visual FoxPro fornece vários recursos que suportam desenvolvimento em equipe, um recurso significativo dos quais é o uso de um sistema de controle de código-fonte para coordenar o acesso a arquivos em um projeto.
**Gerenciando projetos Visual FoxPro sob controle de código-fonte**
Explica o processo para usar software de controle de código-fonte no Visual FoxPro, incluindo que você coloca projetos sob controle de código-fonte, adiciona arquivos aos seus projetos controlados por código-fonte e atualiza a lista de projetos para cada projeto.
**Gerenciando arquivos em um projeto controlado por código-fonte**
Diz que depois de colocar um projeto Visual FoxPro sob controle de código-fonte, você pode trabalhar com arquivos individuais ou gerenciar o projeto como um todo.
**Desenvolvendo e modificando bancos de dados em equipes**
Sugere que, além de trabalhar juntos com projetos e arquivos de projeto, sua equipe deve ser capaz de compartilhar informações em bancos de dados.
**Desenvolvendo bibliotecas de classes em equipes**
Descreve como, porque bibliotecas de classes (.vcx) são uma parte crucial da maioria das aplicações Visual FoxPro, equipes devem ser capazes de coordenar esforços de desenvolvimento ao criá-las.
