# Função NDX( )

Retorna o nome de um arquivo de índice (.IDX) aberto para a tabela atual ou especificada.

```foxpro
NDX(nIndexNumber [, nWorkArea | cTableAlias])
```

#### Parâmetros
 **nIndexNumber**
Especifica qual nome de arquivo .idx retornar. USE e SET INDEX suportam uma lista de arquivos de índice que torna possível abrir arquivos .idx para uma tabela. A ordem dos nomes de arquivo nessa lista de arquivos de índice determina qual nome de arquivo .idx NDX( ) retorna. Por exemplo, se nIndexNumber for 1, NDX( ) retorna o nome do primeiro arquivo .idx na lista de arquivos de índice; se nIndexNumber for 2, NDX( ) retorna o segundo nome de arquivo .idx, e assim por diante. NDX( ) ignora nomes de arquivos de índice composto (.cdx) na lista de arquivos de índice. NDX( ) retorna uma cadeia de caracteres vazia se nIndexNumber for maior que o número de arquivos .idx na lista de arquivos de índice.
**nWorkArea**
Especifica o número da área de trabalho para arquivos .IDX abertos em uma área de trabalho diferente da atual. NDX( ) retorna uma cadeia de caracteres vazia se nenhuma tabela estiver aberta na área de trabalho especificada. Se você omitir nWorkArea, NDX( ) retorna os nomes dos arquivos .idx abertos com a tabela na área de trabalho atual.
**cTableAlias**
Especifica o alias da tabela para arquivos .idx abertos em uma área de trabalho diferente da atual. Se nenhuma tabela tiver o alias incluído, o Visual FoxPro gera uma mensagem de erro. Se você omitir cTableAlias, NDX( ) retorna os nomes dos arquivos .idx abertos com a tabela na área de trabalho atual.

# Valor de retorno

Character

# Observações

As funções CDX( ) e MDX( ) podem ser usadas para retornar os nomes de arquivos de índice composto (.cdx) abertos.

No Visual FoxPro para Windows, quando SET FULLPATH está ON, NDX( ) retorna o caminho para o arquivo .idx com o nome do arquivo .idx. Quando SET FULLPATH está OFF, NDX( ) retorna a unidade em que o arquivo .idx reside com o nome do arquivo .idx.
