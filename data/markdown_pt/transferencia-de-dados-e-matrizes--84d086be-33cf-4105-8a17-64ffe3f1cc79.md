# Transferência de dados e matrizes

Matrizes fornecem uma maneira de ordenar informações rapidamente. Uma vez que as informações estão em uma matriz, você pode facilmente pesquisar, classificar e realizar outras manipulações de dados. Para obter informações de e para matrizes, você transfere dados para uma tabela ou transfere dados de uma tabela para uma matriz.

O Visual FoxPro não impõe restrições de tamanho ou tipo de dados ao conteúdo de matrizes. A única restrição de tamanho é a quantidade de memória disponível.
