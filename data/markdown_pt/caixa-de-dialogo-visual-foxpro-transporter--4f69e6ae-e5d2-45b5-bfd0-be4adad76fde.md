# Caixa de diálogo Visual FoxPro Transporter

Permite transportar formulários, etiquetas e relatórios entre diferentes plataformas e versões do FoxPro. Esta caixa de diálogo aparece somente quando você está tentando converter arquivos Macintosh ou MS-DOS que nunca contiveram registros do Windows.

De acordo com as opções definidas na caixa de diálogo Visual FoxPro Transporter, o Visual FoxPro cria registros da plataforma Windows a partir dos registros Macintosh ou MS-DOS para que o Visual FoxPro Converter possa converter os arquivos para o formato de arquivo atual do Visual FoxPro, o que é necessário para usar esses arquivos com versões posteriores do Visual FoxPro.

Para obter mais informações sobre a conversão de arquivos de outras plataformas, consulte How to: Convert Earlier Visual FoxPro Files.
 **Transport**
Cria uma versão Windows dos registros Macintosh ou MS-DOS para que o Visual FoxPro Converter possa reconhecer o arquivo e convertê-lo para o formato de arquivo correto.
**Don't Transport**
Cancela o processo de transporte e conversão do arquivo. Você ainda pode abrir o arquivo na versão mais antiga do FoxPro.
**Font**
Abre a caixa de diálogo Font para que você possa escolher a fonte padrão para sua tela, relatório ou etiqueta transportada.
**Transport Objects From**
Permite escolher a plataforma apropriada na lista.
