# Propriedade inválida para cursors locais (Erro 1467)

A propriedade não é suportada para cursors baseados em tabelas locais ou views locais; ela se aplica apenas a cursors baseados em views remotas. Use a propriedade somente para cursors de views remotas.

Ao usar a função CURSORGETPROP( ), a propriedade ADORecordset não é válida para cursors que não são baseados em ADO Recordsets.
