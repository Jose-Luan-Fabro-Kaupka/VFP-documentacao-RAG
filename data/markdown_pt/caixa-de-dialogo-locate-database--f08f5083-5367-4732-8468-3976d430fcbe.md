# Caixa de diálogo Locate Database

Permite localizar ou ignorar uma tabela ou exibição ausente.

Esta caixa de diálogo aparece quando você abre ou executa um formulário e o Visual FoxPro não consegue localizar uma tabela ou exibição no ambiente de dados do formulário.
 **Locate**
Exibe a caixa de diálogo Open, para que você possa encontrar a tabela ou exibição.
**Ignore**
O Visual FoxPro continuará a carregar o formulário sem instanciar o objeto cursor no ambiente de dados. Se houver controles vinculados a campos na tabela ou exibição, erros adicionais serão gerados.
**Cancel**
O Visual FoxPro interromperá o carregamento do formulário.
**Help**
Exibe a Ajuda sobre a caixa de diálogo.
