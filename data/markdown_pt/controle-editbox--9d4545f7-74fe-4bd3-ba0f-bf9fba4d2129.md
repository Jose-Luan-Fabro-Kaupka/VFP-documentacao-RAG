# Controle EditBox

Cria uma caixa de edição.

```foxpro
EditBox
```

# Observações

Você pode usar uma caixa de edição para editar os valores em campos do tipo Memo e em variáveis, elementos de matriz e campos com tipo Character. Você pode usar uma caixa de edição para visualizar o conteúdo de um campo do tipo Blob; no entanto, o conteúdo é somente leitura. A caixa de edição exibe dados do tipo Blob como valores hexadecimais sem o prefixo 0h. Para obter mais informações, consulte Tipos de dados e campos do Visual FoxPro.

Todos os recursos de edição padrão do Visual FoxPro, como cortar, copiar e colar, estão disponíveis para uma caixa de edição. O texto na caixa de edição rola verticalmente, e o texto quebra horizontalmente.

Para obter informações adicionais sobre como criar e usar controles, consulte Usando controles.
