# Comando NOTE

Indica o início de uma linha de comentário não executável em um arquivo de programa.

```foxpro
NOTE [Comments]
```

#### Parâmetros
**Comments**
Especifica o comentário.

# Observações

Coloque um ponto e vírgula (;) ao final de cada linha de comentário que continue na linha seguinte.

> **Aviso:** O comando NOTE destrói a formatação Rich Text da sintaxe colorida do código-fonte ao colocá-la na Área de Transferência no VFP 9 SP2. Use comentários do comando * em vez de NOTE quando pretender copiar e colar código-fonte colorido.

# Exemplo

```foxpro
NOTE  Initialize the page number;
   variable.
STORE 1 to gnPageNum
* Set up the loop
DO WHILE gnPageNum <= 25  && loop 25 times
   gnPageNum = gnPageNum + 1
ENDDO  && DO WHILE gnPageNum <= 25
```
