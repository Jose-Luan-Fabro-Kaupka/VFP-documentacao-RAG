# Comando SET RELATION OFF

Desfaz uma relação estabelecida entre a tabela pai na área de trabalho atualmente selecionada e uma tabela filha relacionada.

```foxpro
SET RELATION OFF INTO nWorkArea | cTableAlias
```

#### Parâmetros
 **INTO nWorkArea | cTableAlias**
Especifica o número da área de trabalho ou o alias da tabela filha.
