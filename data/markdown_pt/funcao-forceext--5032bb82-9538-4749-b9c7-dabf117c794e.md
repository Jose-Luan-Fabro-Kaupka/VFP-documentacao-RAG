# Função FORCEEXT( )

Retorna uma cadeia de caracteres com a extensão antiga do nome do arquivo substituída por uma nova extensão.

```foxpro
FORCEEXT(cFileName, cExtension)
```

#### Parâmetros
 **cFileName**
Especifica o nome do arquivo (com ou sem caminho ou extensão), que receberá uma nova extensão.
**cExtension**
Especifica a nova extensão (sem ponto) para cFileName .

# Valor de retorno

Character
