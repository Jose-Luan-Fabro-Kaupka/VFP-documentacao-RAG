# Criação de views

Você pode recuperar dados de fontes de dados locais e remotas criando views locais e remotas, respectivamente. Views locais usam a sintaxe SQL do Visual FoxPro para selecionar informações de tabelas ou views armazenadas localmente no seu computador. Views remotas usam a sintaxe SQL da fonte de dados remota para recuperar informações de tabelas na fonte de dados, que normalmente é uma fonte de dados ODBC. Para views locais, você também pode recuperar dados de fontes de dados ODBC locais e remotas do Visual FoxPro adicionando views remotas a views locais.
