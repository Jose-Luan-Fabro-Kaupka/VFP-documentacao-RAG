# Aviso: conversão(ões) de dados inválida(s) a partir do registro "number" (Erro 1485)

Um erro de conversão de dados foi relatado ao buscar dados no registro number do conjunto de resultados remoto.
 - O driver ODBC não pode converter alguns valores de dados remotos para o tipo de dados local da view. Use uma função de conversão na instrução SQL remota para converter os dados para um tipo de dados diferente antes de buscá-los; use a propriedade DataType do campo da view para alterar o tipo de dados local.
