# Caixa de diálogo Imprimir arquivo

Permite procurar e selecionar um arquivo para impressão.

Esta caixa de diálogo aparece quando você clica no botão de reticências (...) à direita da caixa Arquivo na caixa de diálogo Opções de impressão. Os tipos de arquivo são filtrados pelo tipo de arquivo selecionado na caixa de diálogo Opções de impressão. Para obter mais informações, consulte Caixa de diálogo Opções de impressão.
 **Página de código**
Exibe a caixa de diálogo Página de código para que você possa anexar a página de código correta. Se o arquivo que você deseja imprimir usa o conjunto de caracteres estendido, clique em Página de código e faça as seleções apropriadas.
