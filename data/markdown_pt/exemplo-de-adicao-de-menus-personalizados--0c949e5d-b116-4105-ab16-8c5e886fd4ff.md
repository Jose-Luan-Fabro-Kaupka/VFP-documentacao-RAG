# Exemplo de adição de menus personalizados

Arquivo: ...\Samples\Solution\Sedona\Mrumenu.scx

Você pode adicionar menus personalizados semelhantes aos do Microsoft Office 2000, nos quais apenas os itens de menu mais comuns são exibidos. Este exemplo usa um menu de exemplo (Dvdmenu.mnx), que possui o código de menu especial.

Para obter detalhes sobre todas as classes disponíveis nas classes fundamentais, consulte Classes fundamentais do Visual FoxPro de A a Z.
