# Trabalhando com dados

Você pode criar aplicativos mais eficazes analisando seus requisitos de dados e depois projetando seus bancos de dados, tabelas e índices para atender a essas necessidades.

# Nesta seção
 **Developing Databases**
Descreve como usar bancos de dados no Visual FoxPro para estabelecer relacionamentos entre tabelas, impor integridade referencial e gerenciar dados locais e remotos.
**Working with Tables (Visual FoxPro)**
Apresenta a criação e o trabalho com tabelas.
**Enforcing Business Rules**
Fornece uma visão geral sobre como impor regras de negócio usando regras de validação, impedindo valores duplicados em campos e mantendo relacionamentos entre tabelas.
**Working with Queries**
Descreve como usar consultas para selecionar e exibir dados de tabelas ou views.
**Working with Views (Visual FoxPro)**
Explica como usar views para criar um conjunto de dados atualizável personalizado para seu aplicativo.
**Importing and Exporting Data**
Explica como as informações são copiadas entre o Visual FoxPro e outros aplicativos importando para e exportando do Visual FoxPro.
**Upsizing Visual FoxPro Databases**
Discute a construção e o upsizing de um protótipo local de seu aplicativo usando tabelas, views e bancos de dados do Visual FoxPro para representar dados acessados em um servidor remoto.
**Programming for Shared Access**
Explica como a programação para acesso compartilhado permite que você crie um aplicativo que será executado em várias máquinas em um ambiente de rede.
**Visual FoxPro Data Access Using the OLE DB Provider**
Descreve o Visual FoxPro OLE DB Provider e como acessar dados do Visual FoxPro de outras linguagens e aplicativos.

# Referência
 **Reference (Visual FoxPro)**
Inclui tópicos de referência geral, linguagem de programação, interface do usuário e mensagens de erro do Visual FoxPro.

# Seções relacionadas
 **Developing Visual FoxPro Applications**
Inclui informações conceituais sobre como desenvolver aplicativos Visual FoxPro, instruções para criar bancos de dados e a interface do usuário e outras tarefas necessárias para criar aplicativos Visual FoxPro.
**Application Planning**
Enfatiza que o planejamento cuidadoso economiza tempo, esforço e dinheiro e que muitas das decisões que você toma durante a fase de planejamento impactarão como você cria elementos do aplicativo.
**Enhancing Applications Using SQL Pass-Through Technology**
Descreve como você pode usar a tecnologia SQL pass-through (SPT) para criar objetos no servidor, executar procedimentos armazenados em um servidor remoto e executar comandos usando sintaxe nativa do servidor.
