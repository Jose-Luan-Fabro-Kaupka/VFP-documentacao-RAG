# Personalizando o IntelliSense no Visual FoxPro

Você pode personalizar a funcionalidade IntelliSense para o Visual FoxPro e elementos de linguagem definidos pelo usuário modificando ou adicionando registros na tabela IntelliSense. Por exemplo, você pode adicionar ou modificar itens de conclusão de sintaxe ou criar scripts que são executados quando você usa a funcionalidade IntelliSense.

> **Observação:** Alterações na tabela IntelliSense não afetam a funcionalidade IntelliSense para propriedades, métodos e eventos de objetos.
