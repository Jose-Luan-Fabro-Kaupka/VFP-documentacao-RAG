# Exemplo Use Access/Assign Methods on a Form

Arquivo: ...\Samples\Solution\Tahoe\Aa_fun.scx

Este exemplo demonstra maneiras de usar métodos Access/Assign em um formulário.

Este exemplo contém as seguintes classes.

| Método | Descrição |
| --- | --- |
| caption_assign | Atribui um novo valor à propriedade Caption de um formulário. |
| mybuttons_access | Retorna o índice do botão. |
| oshape_access | Retorna a forma do objeto. |
| cshapecolor_access | Retorna a cor do objeto. |
| this_access | Adiciona uma nova propriedade e retorna seu valor. |

Para obter detalhes sobre todas as classes disponíveis nas foundation classes, consulte Visual FoxPro Foundation Classes A-Z.
