# Guia Cursors, DataEnvironment Builder

Use para criar novos objetos CursorAdapter, adicionar objetos CursorAdapter de uma biblioteca de classes, remover objetos CursorAdapter ou abrir o CursorAdapter Builder para um objeto CursorAdapter existente.
 **Add**
Exibe a caixa de diálogo Open para que você possa selecionar uma classe CursorAdapter existente em uma biblioteca de classes ou arquivo de programa.
**New**
Exibe o CursorAdapter Builder para que você possa criar e configurar um novo objeto CursorAdapter.
**Remove**
Remove o objeto CursorAdapter selecionado no momento. Você também pode selecionar outro objeto CursorAdapter na lista exibida na guia Cursors.
**Builder**
Abre o CursorAdapter Builder para o objeto CursorAdapter selecionado no momento.
**Class**
Somente leitura. Exibe o nome da classe do objeto CursorAdapter selecionado no momento.
**Name**
Leitura/gravação. Exibe o nome do objeto CursorAdapter selecionado no momento. O nome padrão é Cursor <CursorNumber>.
