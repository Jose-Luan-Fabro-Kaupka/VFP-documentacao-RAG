# Guia Field Selection, Form Builder

Esta guia no Form builder especifica os campos a serem adicionados como controles de formulário.
 **Databases and Tables**
Lista os bancos de dados disponíveis ou permite selecionar tabelas livres. Para localizar um banco de dados ou tabela, clique no botão de diálogo, que exibe a caixa de diálogo Open.
**List of Tables**
Exibe tabelas e exibições no banco de dados selecionado ou tabelas livres.
**Available Fields**
Mostra todos os campos na tabela ou exibição selecionada. Selecione os campos cujos dados você deseja no seu formulário.
**Arrow Buttons**
Adiciona campos e remove campos da caixa Selected Fields.
**Selected Fields**
Exibe os campos que aparecerão no seu formulário como controles.
