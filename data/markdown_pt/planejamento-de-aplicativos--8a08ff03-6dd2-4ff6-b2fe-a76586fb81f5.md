# Planejamento de aplicativos

Planejamento cuidadosa economiza tempo, esforço, dinheiro e sanidade. Quanto mais você envolver seus usuários finais no processo de planejamento, melhor. Não importa o quanto você planeje cuidadosamente, provavelmente acabará refinando as especificações conforme avança no projeto e seus usuários finais fornecem feedback.

# Nesta seção
 **Considerações de design**
Discute como a decisão de design que você tomar impactará como você cria seu aplicativo.
**Arquitetura de aplicativos**
Descreve como a arquitetura de aplicativos do Visual FoxPro varia com o tipo de aplicativo que você decide criar.
**Considerações de segurança (Visual FoxPro)**
Mostra como você deve estar ciente dos requisitos de segurança de uma perspectiva de negócios e as implicações que um modelo de segurança escolhido pode ter em desempenho, escalabilidade e implantação.
**Planejamento para projetos de desenvolvimento em equipe**
Discute como usar software de controle de origem, como o Microsoft Visual SourceSafe, para gerenciar os arquivos em um projeto torna possível criar aplicativos complexos rapidamente combinando as habilidades de uma equipe de desenvolvedores.
**Desenvolvendo aplicativos internacionais**
Mostra como projetar aplicativos Visual FoxPro para que sejam tão eficazes internacionalmente quanto domesticamente usando os recursos internacionais do Visual FoxPro.
