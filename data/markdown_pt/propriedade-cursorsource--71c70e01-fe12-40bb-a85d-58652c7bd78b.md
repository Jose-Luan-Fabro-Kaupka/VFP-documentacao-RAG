# Propriedade CursorSource

Especifica o nome da tabela ou view associada a um objeto Cursor. Somente leitura em tempo de design; leitura/gravação em tempo de execução.

```foxpro
DataEnvironment.Cursor.CursorSource[ = cText]
```

# Valor de retorno
 **cText**
Para views, especifica o nome da view em um banco de dados. Para tabelas em um banco de dados, especifica o nome longo da tabela. Para tabelas livres, especifica o caminho completo para a tabela livre.
