# Variável de sistema _TASKPANE

Contém o caminho e o nome do arquivo do Visual FoxPro Task Pane Manager.

```foxpro
_TASKPANE = cPath
```

#### Parâmetros
 **cPath**
Especifica o caminho completo e o nome do arquivo do Visual FoxPro Task Pane Manager.

# Observações

_TASKPANE especifica o caminho e o nome do arquivo do Visual FoxPro Task Pane Manager. Este caminho geralmente é o diretório raiz do Visual FoxPro, e o nome do arquivo geralmente é Taskpane.app.

Você pode especificar um caminho e nome de arquivo para _TASKPANE na guia File Locations na caixa de diálogo Options. Para obter mais informações, consulte a guia File Locations, caixa de diálogo Options e a caixa de diálogo Options (Visual FoxPro).
