# Caixa de diálogo Page Setup (Visual FoxPro)

Especifica configurações de tamanho de papel e orientação de página no Visual FoxPro. As configurações disponíveis nesta caixa de diálogo dependem da impressora instalada.

Esta caixa de diálogo aparece quando você seleciona Page Setup no menu Arquivo ou na caixa de diálogo Report Page Setup Dialog Box. Para obter mais informações, consulte Report Page Setup Dialog Box.

# Papel

Especifica configurações de papel para a página.
 **Size**
Especifica o tamanho do papel.
**Source**
Especifica o local de origem do papel na impressora.

# Orientação

Especifica configurações de orientação de página.
 **Portrait**
Imprime a página em posição vertical com o lado mais curto na parte superior.
**Landscape**
Imprime a página em posição horizontal com o lado mais longo na parte superior.

# Margens

As configurações de margem nesta caixa de diálogo não estão disponíveis no Visual FoxPro.
 **Printer**
Exibe a caixa de diálogo Page Setup da impressora para que você possa especificar configurações da impressora.

# Caixa de diálogo Printer Page Setup

Especifica configurações da impressora no Visual FoxPro. As configurações disponíveis nesta caixa de diálogo dependem da impressora instalada.

Esta caixa de diálogo aparece quando você clica em Printer na caixa de diálogo Page Setup.

### Impressora

Especifica e exibe informações da impressora.
 **Name**
Exibe os nomes das impressoras atualmente instaladas no seu computador.
**Status**
Exibe o status da impressora.
**Type**
Exibe o modelo da impressora selecionada. O modelo da impressora é especificado quando você instala a impressora.
**Where**
Exibe o caminho da impressora de rede.
**Comment**
Exibe informações adicionais da impressora, por exemplo, localização da impressora.
