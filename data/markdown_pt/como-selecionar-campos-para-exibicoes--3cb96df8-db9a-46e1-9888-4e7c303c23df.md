# Como: selecionar campos para exibições

Depois de criar uma exibição e selecionar as tabelas ou exibições que deseja usar, você pode construir a exibição selecionando os campos das tabelas ou exibições.

### Para selecionar campos para uma exibição
- Abra a exibição no View Designer .
- No View Designer , clique na guia Fields.
- Na lista Available fields, clique em cada campo desejado e depois em Add . Dica Para selecionar vários campos, pressione e mantenha pressionada a tecla SHIFT enquanto seleciona os campos. Depois de selecionar todos os campos desejados, clique em Add . Cada campo selecionado aparece na lista Selected fields. Dica Para alterar a ordem em que os campos aparecem na saída, na lista Selected fields, arraste o botão de seta dupla à esquerda do campo que deseja mover para a posição desejada.
- Quando terminar, você pode executar outras tarefas para personalizar a exibição.

Você pode personalizar sua exibição no View Designer executando as seguintes tarefas:
 - Alterar a condição de junção das tabelas selecionadas na guia Join.
- Filtrar resultados por campo na guia Filter.
- Organizar resultados por campo na guia Order By.
- Agrupar resultados por campo na guia Group By.
- Especificar critérios de atualização na guia Update Criteria para controlar como realizar atualizações nas tabelas de origem.
- Selecionar um tipo diferente de saída na guia Miscellaneous.

Para obter mais informações, consulte Query and View Designers.
