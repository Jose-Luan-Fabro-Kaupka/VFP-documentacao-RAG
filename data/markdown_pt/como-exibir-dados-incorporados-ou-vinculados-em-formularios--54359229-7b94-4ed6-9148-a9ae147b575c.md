# Como: exibir dados incorporados ou vinculados em formulários

Você pode aprimorar o design de formulários vinculando ou incorporando dados, como documentos do Microsoft Word ou planilhas do Microsoft Excel. Da mesma forma, você pode aprimorar relatórios exibindo dados vinculados ou incorporados de campos General.

### Para vincular ou incorporar dados em um formulário
- Crie ou abra um formulário.
- Na barra de ferramentas Form Controls, selecione o botão OLE Container Control e arraste para dimensionar no formulário. A caixa de diálogo Insert Object aparece, listando os tipos de arquivos que você pode vincular ou incorporar.
- Escolha uma das seguintes opções: Criar um novo arquivo selecionando Create New . -OU- Usar um arquivo existente selecionando Create from File . Digite o nome do arquivo que contém os dados ou escolha Browse e selecione o arquivo apropriado. Além disso, se você quiser vincular ao arquivo, selecione Link .

# Alterar ou romper vínculos com dados em formulários

Você altera ou rompe um vínculo com dados exibidos em um formulário usando o comando Links no menu Edit.

### Para alterar um vínculo com dados em um formulário
- Abra o formulário apropriado.
- Selecione o objeto cujo vínculo você deseja alterar.
- No menu Edit, escolha Links .
- Na caixa de diálogo Links, escolha Change Source .
- Na caixa de diálogo Change Source, especifique a nova fonte de dados e escolha OK .
- Na caixa de diálogo Links, escolha Close para concluir a alteração.

### Para romper um vínculo com dados em um formulário
- Abra o formulário apropriado.
- Selecione o objeto cujo vínculo você deseja romper.
- No menu Edit, escolha Links .
- Na caixa de diálogo Links, escolha Break Link .
- Escolha Close .

Quando o vínculo é rompido, os dados tornam-se estáticos.
