# Acessibilidade para Pessoas com Deficiência (Visual FoxPro)

A Microsoft está empenhada em tornar os seus produtos e serviços mais fáceis de utilizar por todos. Este arquivo de Ajuda fornece informações sobre como tornar o Microsoft Windows e o Visual FoxPro mais acessíveis, bem como outros recursos, produtos e serviços que podem ajudar a melhorar a acessibilidade para pessoas com deficiências.

> **Observação:** As informações nesta seção sobre o Microsoft Windows aplicam-se somente a usuários que adquiriram o Microsoft Windows nos Estados Unidos. Se você adquiriu o Microsoft Windows fora dos Estados Unidos, o pacote do Windows contém um cartão de informações subsidiárias listando os números de telefone e endereços dos Serviços de Suporte da Microsoft. Você pode entrar em contato com sua subsidiária para saber se os tipos de produtos e serviços descritos neste arquivo de Ajuda estão disponíveis em sua área.

Para obter informações sobre serviços de suporte técnico para pessoas surdas ou com deficiência auditiva, consulte Suporte técnico do Microsoft Visual FoxPro.

Você pode saber mais sobre os recursos de acessibilidade dos produtos e serviços Microsoft visitando o site de Acessibilidade em http://www.microsoft.com/enable/.
