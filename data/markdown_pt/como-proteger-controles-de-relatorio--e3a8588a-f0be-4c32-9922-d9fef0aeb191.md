# Como: proteger controles de relatório

Você pode definir opções de proteção para um controle de relatório para impedir que o usuário altere o controle ou para ocultar o controle do usuário ao modificar o relatório ou a etiqueta no modo protegido. Você também pode definir opções de proteção para vários controles de relatório selecionados.

### Para definir proteção para um controle de relatório
- Abra o relatório ou a etiqueta no designer apropriado.
- No designer, clique duas vezes no controle de relatório desejado. A caixa de diálogo de propriedades do controle de relatório é aberta. Observação Se a variável de sistema _REPORTBUILDER não estiver definida para o Report Builder padrão ou estiver definida para um builder de terceiros, a caixa de diálogo do controle de relatório é exibida ou uma caixa de diálogo diferente pode ser exibida. Não há forma de definir um caption em tempo de design usando a caixa de diálogo nativa do controle de relatório. Para obter mais informações, consulte _REPORTBUILDER System Variable.
- Na caixa de diálogo de propriedades do controle de relatório, clique na guia Protection.
- Na guia Protection, selecione uma combinação das seguintes opções de proteção: O usuário não poderá redimensionar ou mover o controle de relatório. O usuário não poderá acessar a caixa de diálogo Report Control Properties. O usuário não poderá excluir o controle de relatório do layout. O usuário não poderá selecionar o controle de relatório com o mouse ou o teclado. O usuário não poderá ver o controle de relatório.
- Quando terminar, clique em OK.
- Para obter mais informações, consulte Protection Tab, Report Control Properties Dialog Box (Report Builder).

### Para definir proteção para vários controles de relatório selecionados
- No designer, selecione os controles de relatório desejados usando o método de seleção múltipla. Para obter mais informações, consulte How to: Select Multiple Report Controls.
- Clique duas vezes em um dos controles selecionados ou clique com o botão direito e selecione Properties. A caixa de diálogo Multiple Selection é aberta. Observação Se a variável de sistema _REPORTBUILDER não estiver definida para o Report Builder padrão ou estiver definida para um builder de terceiros, uma caixa de diálogo do controle de relatório é exibida ou uma caixa de diálogo diferente pode ser exibida. Para obter mais informações, consulte _REPORTBUILDER System Variable.
- Na caixa de diálogo Multiple Selection, clique na guia Protection se ela não estiver selecionada.
- Na guia Protection, selecione as opções de proteção desejadas.
- Quando terminar, clique em OK.

Para obter mais informações, consulte How to: Select Multiple Report Controls.
