# Comando ADD TABLE

Adiciona uma tabela livre ao banco de dados atual.

```foxpro
ADD TABLE TableName | ?   [NAME LongTableName]
```

#### Parâmetros
 **TableName**
Especifica o nome da tabela adicionada ao banco de dados.
**?**
Exibe a caixa de diálogo Abrir, na qual você pode escolher uma tabela para adicionar ao banco de dados.
**NAME LongTableName**
Especifica um nome longo para a tabela. Nomes longos podem conter até 128 caracteres e podem ser usados no lugar de nomes de arquivo curtos com extensão .DBF.

# Observações

Depois que a tabela é adicionada ao banco de dados, você pode executar nela as mesmas operações disponíveis para qualquer outra tabela.

Depois de adicionada ao banco de dados, a tabela deixa de ser livre. No entanto, qualquer tabela do banco de dados pode se tornar livre por meio de REMOVE TABLE.

A tabela que você está adicionando:
 - Deve ser um arquivo .DBF válido.
- Não pode ter o mesmo nome de uma tabela existente no banco de dados aberto, a menos que você atribua a ela um nome longo exclusivo.
- Não pode existir em outro banco de dados. Use REMOVE TABLE para remover a tabela de outro banco de dados.

O banco de dados ao qual você está adicionando uma tabela não pode estar envolvido em uma transação.

# Exemplo

O exemplo a seguir cria dois bancos de dados chamados `mydbc1` e `mydbc2` e uma tabela chamada `table1`. A tabela é adicionada a `mydbc1` quando é criada. Em seguida, a tabela é fechada e removida de `mydbc1`. Depois, ADD TABLE é usado para adicionar a tabela a `mydbc2`. RENAME TABLE é usado para alterar o nome da tabela de `table1` para `table2`.

```foxpro
CREATE DATABASE mydbc1
CREATE DATABASE mydbc2
SET DATABASE TO mydbc1
CREATE TABLE table1 (cField1 C(10), n N(10))  && Adds table to mydbc1
CLOSE TABLES&& A table must be closed to remove it from a database
REMOVE TABLE table1
SET DATABASE TO mydbc2
ADD TABLE table1
RENAME TABLE table1 TO table2
```
