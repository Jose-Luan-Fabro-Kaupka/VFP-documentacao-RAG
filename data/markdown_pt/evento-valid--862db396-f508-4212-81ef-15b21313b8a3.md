# Evento Valid

Ocorre antes de um controle perder o foco.

```foxpro
PROCEDURE Control.Valid
```

# Observações

Aplica-se a: Controle CheckBox | Controle ComboBox | Controle CommandButton | Controle CommandGroup | Controle EditBox | Controle Grid | Controle ListBox | Controle OptionButton | Controle OptionGroup | Controle Spinner | Controle TextBox (Visual FoxPro)

Se o evento Valid retornar true (.T.), o controle pode perder o foco — o foco pode não passar para outro controle. Se o evento Valid retornar false (.F.), o controle não perde o foco.

O evento Valid também pode retornar um valor numérico. Retornar um valor numérico tem um dos três efeitos:
 - Se 0 é retornado, o controle não perde o foco.
- Se um valor positivo é retornado, o valor especifica o número de controles que o foco avança.
- Se um valor negativo é retornado, o valor especifica o número de controles que o foco retrocede. Por exemplo, se o evento Valid retornar –1, o controle anterior recebe o foco.

Você também pode usar o parâmetro opcional ObjectName no comando RETURN do evento Valid para direcionar onde o foco é atribuído. O objeto especificado deve ser um objeto Visual FoxPro válido. Se o objeto especificado estiver desabilitado ou não puder receber foco, o foco é atribuído ao próximo objeto na ordem de tabulação. Se um objeto inválido for especificado, o Visual FoxPro mantém o foco no objeto atual.

Você pode definir o foco em objetos nos seguintes cenários:
 - Definir foco em um objeto em outro formulário visível.
- Definir foco em um objeto em um controle Page ou Pageframe não visível.

Para obter mais informações, consulte o Comando RETURN.
