# Função PI( )

Retorna a constante numérica pi.

```foxpro
PI()
```

# Valor de retorno

Numeric

# Observações

A constante numérica pi (3.141592) é a razão entre a circunferência de um círculo e seu diâmetro.

O número de casas decimais exibidas no valor retornado por PI( ) é determinado por SET DECIMALS.

# Exemplo

```foxpro
CLEAR
? PI() && Displays 3.14
STORE 2.30 TO gnRadius
STORE PI() * gnRadius^2 TO gnArea
? gnArea  && Displays 16.6190
```
