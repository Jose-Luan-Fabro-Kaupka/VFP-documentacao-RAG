# Evento Resize

Ocorre quando um objeto é redimensionado.

```foxpro
PROCEDURE Object.Resize
```

# Observações

Aplica-se a: Variável do sistema  SCREEN|Objeto da Coluna|Objecto do Contentor|Objeto de controle (Visual FoxPro)|Objeto do Formulário|Controle da Grade|OLE Controlo ligado|OLE Controlo de contentores|Controle do PageFrame|Objeto da Barra de Ferramentas

Você pode ativar o Redimensionar interativamente ou em código definindo as propriedades Altura e Largura.

Para um objeto Coluna, você pode ativar o Redimensionamento em código definindo a propriedade Largura para a coluna.

Você também pode ativar o evento Resize usando a vinculação de eventos. Para mais informações, consulte Event Binding para Visual FoxPro Objetos e BINDEVENT( ) Função.
