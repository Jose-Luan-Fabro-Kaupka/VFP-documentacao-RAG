# Amostras

O Visual FoxPro vem com numerosas amostras de código que você pode usar para experimentar e se familiarizar com os recursos.

Para amostras adicionais, consulte a pasta Visual FoxPro ..\Samples, que contém amostras que ilustram APIs, serviços COM+ e acesso a dados.

# Nesta seção
 **Sample Class Libraries**
Contém bibliotecas de classes de amostra que fornecem funcionalidade encapsulada que você pode adicionar às suas aplicações.
**Server Samples (Visual FoxPro)**
Contém amostras de servidor que ilustram Automation Servers.
**Solution Samples**
Contém amostras que demonstram recursos específicos do Visual FoxPro e podem ser executadas independentemente.
**Foundation Class Samples**
Contém amostras que ilustram o uso das foundation classes do Visual FoxPro.

# Seções relacionadas
 **Getting Started with Visual FoxPro**
Fornece informações sobre instalação, atualização e configuração do Visual FoxPro, bem como personalização do ambiente de desenvolvimento.
**Developing Visual FoxPro Applications**
Inclui informações conceituais sobre como desenvolver aplicações Visual FoxPro, instruções para criar bancos de dados e a interface do usuário, e outras tarefas necessárias para criar aplicações Visual FoxPro.
**Programming in Visual FoxPro**
Discute como você pode acessar todo o poder do Visual FoxPro criando aplicações. Compreender técnicas de programação orientada a objetos e o modelo orientado a eventos pode maximizar sua produtividade de programação.
**Reference (Visual FoxPro)**
Inclui tópicos sobre ferramentas de produtividade, bem como os controles, objetos, propriedades, métodos, eventos, instruções, funções e constantes disponíveis.
**Walkthroughs**
Fornece instruções passo a passo para cenários comuns, tornando-os um bom ponto de partida para aprender sobre os vários recursos do Visual FoxPro.
