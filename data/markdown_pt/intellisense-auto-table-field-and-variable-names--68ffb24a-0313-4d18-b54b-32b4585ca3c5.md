# IntelliSense Auto Table, Field, and Variable Names

Quando você digita certos comandos do Visual FoxPro, o IntelliSense exibe nomes de tabelas, campos e variáveis apropriados.

# Exibindo nomes de tabela e campo automaticamente

Quando você está trabalhando com uma tabela aberta e digita certos comandos na janela Command, o IntelliSense exibe uma lista de nomes de tabela ou campo apropriados. Quando você navega em uma lista de campos, o IntelliSense exibe uma janela Tip que mostra o tipo e a largura do campo selecionado.

A tabela a seguir lista os comandos e as tabelas ou campos correspondentes que o IntelliSense exibe.

| Comando Visual FoxPro | IntelliSense exibe uma lista de |
| --- | --- |
| USE ou USE tableAlias | Tabelas do banco de dados ativo e lista MRU (Most Recently Used). |
| REPLACE | Campos da tabela, cursor ou view na área de trabalho selecionada atualmente. |
| MODIFY MEMO | Campos memo da tabela, cursor ou view na área de trabalho selecionada atualmente. |
| MODIFY GENERAL | Campos general da tabela, cursor ou view na área de trabalho selecionada atualmente. |

# Exibindo nomes de variáveis automaticamente

Quando você digita a letra "m" seguida de um ponto (.) na janela Command, o IntelliSense exibe uma lista de todas as variáveis declaradas e disponíveis. Quando você navega na lista de nomes de variáveis, o IntelliSense exibe uma janela Tip com informações sobre o valor da variável.
