# Toolbox (Visual FoxPro)

A Toolbox exibe itens usados na criação de aplicativos; os itens são exibidos em toolsets (coleções de ferramentas) por categoria. Os toolsets podem ser recursos comuns, como classes nativas do Visual FoxPro que podem ser colocadas em uma área de trabalho. Além disso, a Toolbox suporta itens que são builders ou wizards, controles ou classes ActiveX, controles ou classes COM+ e fragmentos de texto. Além disso, a Toolbox pode conter recursos baseados em arquivo, como tabelas, imagens, relatórios, etiquetas e formulários.

Os toolsets individuais podem ser totalmente personalizados. Além disso, os usuários podem adicionar novos toolsets contendo sua própria seleção de itens.

Você pode abrir a Toolbox clicando em Toolbox no menu Tools ou clicando no botão Toolbox na barra de ferramentas padrão do Visual FoxPro. Você pode então arrastar e soltar itens da Toolbox para sua área de trabalho ou clicar neles para executar outras ações.

No Visual FoxPro 9.0, você pode acoplar a Toolbox clicando duas vezes na barra de título da Toolbox. Clique com o botão direito na barra de título para exibir um menu de atalho que permite ativar ou desativar o acoplamento, ou ocultar a Toolbox.
 **Favorites**
Um toolset para armazenar itens usados frequentemente. Itens de outras categorias podem ser movidos para este para fácil acesso.
**Text Scraps**
Um toolset contendo fragmentos de texto. Novos fragmentos de texto podem ser adicionados selecionando texto e arrastando-o para esta categoria.
**VFP Base Classes**
Um toolset contendo classes nativas do Visual FoxPro.
**VFP Foundation Classes**
Um toolset contendo algumas das foundation classes mais populares do Visual FoxPro.
**My Base Classes**
Um toolset contendo as classes base FoxPro Foundation da biblioteca de classes FFC\_BASE.VCX.
**My XML Web Services**
Um toolset contendo serviços Web XML registrados.
**My ActiveX Controls**
Um toolset contendo controles ActiveX registrados.
