# Janela Code

Use a janela Code para escrever, exibir e editar código de formulário, evento e método. Você pode abrir quantas janelas Code quiser, para visualizar, copiar e colar facilmente o código de formulários diferentes.

A janela Code aparece quando você clica duas vezes em um formulário ou controle de formulário no Form Designer, clica duas vezes na janela Data Environment Designer ou clica duas vezes em um evento ou método na janela Properties (Visual FoxPro). Fazer isso tem o mesmo efeito que escolher o comando Code no menu View.

Qualquer texto adicionado a um método ou evento em uma janela Code fará com que essa classe tenha comportamento Override para o método ou evento. Portanto, o código do método ou evento em uma classe pai não será executado por padrão (deve ser executado explicitamente). Isso inclui linhas de comentário não executáveis que começam com "*".
 **Object**
Lista o formulário atual, form set, data environment, objetos de barra de ferramentas, cursor, relation e todos os controles no formulário atual.
**Procedure**
Lista todos os eventos reconhecidos pelo Microsoft Visual FoxPro para o formulário, form set, data environment, cursor, relation ou controle exibido na caixa Object. Quando você seleciona um evento ou método na caixa Procedure, os parâmetros passados ao evento ou método (se houver) são exibidos na região de edição da janela Code. Nomes de eventos em negrito contêm código. Métodos Access e Assign criados para uma propriedade também são exibidos na caixa Procedure. Dica Se você precisar de ajuda sobre sintaxe de funções, instruções, propriedades, eventos ou métodos enquanto trabalha na janela Code, digite a palavra-chave ou o nome da propriedade, evento ou método, selecione-o e pressione F1 para a Ajuda online. Você também pode selecionar um evento ou método na caixa Procedure e pressionar F1 para obter informações sobre o evento ou método selecionado. Pressione PAGE DOWN para ir ao próximo evento ou método que contém código.
