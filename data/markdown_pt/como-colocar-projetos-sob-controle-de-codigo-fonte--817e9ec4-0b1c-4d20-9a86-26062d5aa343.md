# Como: colocar projetos sob controle de código-fonte

Você deve especificar que um projeto do Visual FoxPro estará sob controle de código-fonte antes de poder aproveitar seu software de controle de código-fonte. Isso é feito adicionando um projeto ao seu sistema de controle de código-fonte.

Se o software de controle de código-fonte estiver habilitado, você pode especificar que qualquer novo projeto criado seja automaticamente colocado sob controle de código-fonte.

### Para criar um novo projeto com controle de código-fonte
- Na caixa de diálogo Options, escolha a guia Projects e selecione um provedor de controle de código-fonte, se ainda não tiver feito isso.
- Certifique-se de que Automatically add new projects to source control esteja selecionado e escolha OK. Para tornar essa configuração a padrão, escolha Set as Default e depois OK.
- No menu File, escolha New e inicie um novo projeto do Visual FoxPro. Depois de nomear o novo projeto, o Visual FoxPro solicitará que você crie o novo projeto com controle de código-fonte. O nome padrão do novo projeto será o mesmo nome do projeto do Visual FoxPro.

Depois de criar o novo projeto com controle de código-fonte, o Visual FoxPro conclui a criação do projeto do Visual FoxPro. Antes que outros desenvolvedores possam usar o arquivo, eles devem se inscrever no projeto.

Se você estiver trabalhando com um projeto existente que ainda não está sob controle de código-fonte, pode criar um novo projeto com controle de código-fonte para ele e colocar seus arquivos sob controle de código-fonte.

### Para colocar um projeto existente sob controle de código-fonte
- Abra seu projeto do Visual FoxPro na Project Manager Window.
- No menu Project, escolha Add Project to Source Control. O Visual FoxPro exibe a caixa de diálogo do seu sistema de controle de código-fonte que permite criar um novo projeto. Por padrão, o nome do projeto com controle de código-fonte é o mesmo do projeto do Visual FoxPro.
- Crie o projeto com controle de código-fonte como normalmente faz com seu software de controle de código-fonte.

Ao adicionar um projeto existente ao controle de código-fonte, o Visual FoxPro solicita que você adicione os arquivos do projeto ao projeto com controle de código-fonte.
