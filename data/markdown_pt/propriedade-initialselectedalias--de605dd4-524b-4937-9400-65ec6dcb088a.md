# Propriedade InitialSelectedAlias

Especifica um alias associado a um objeto Cursor como o alias atual quando o ambiente de dados é carregado. Disponível em tempo de design; somente leitura em tempo de execução.

```foxpro
DataEnvironment.InitialSelectedAlias[ = cText]
```

# Valor de retorno
 **cText**
Especifica um nome de alias associado a um objeto Cursor.

# Observações

Aplica-se a: objeto DataEnvironment

Simula o comportamento de SELECT.
