# Como: localizar tabelas ou exibições em bancos de dados

Quando seu banco de dados está associado a muitas tabelas e exibições no Database Designer, você pode localizar rapidamente uma tabela ou exibição específica. Ao localizar um item, como uma tabela ou exibição, associado a um banco de dados aberto, o Visual FoxPro pesquisa primeiro o banco de dados atual. Se o item não for encontrado, o Visual FoxPro pesquisa no caminho de pesquisa padrão.

### Para localizar uma tabela ou exibição em um banco de dados
- Abra o banco de dados no Database Designer .
- No menu Database, clique em Find Object .
- Na caixa de diálogo Find Table or View, selecione a tabela ou exibição que deseja localizar.
- Clique em Find . A tabela ou exibição que você selecionou aparece ativa no Database Designer.
