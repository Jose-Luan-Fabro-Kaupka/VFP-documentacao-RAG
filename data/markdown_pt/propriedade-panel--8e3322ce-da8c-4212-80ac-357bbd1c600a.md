# Propriedade Panel

Especifica o painel ativo em um controle Grid. Disponível em tempo de design; leitura/gravação em tempo de execução. Disponível somente se a propriedade Partition estiver definida com um valor maior que 0.

```foxpro
Grid.Panel[ = nSide]
```

# Valor de retorno
 **nSide**
As configurações da propriedade Panel são: Configuração Descrição 0 O painel esquerdo está ativo. 1 (Padrão) O painel direito está ativo.

# Observações

Aplica-se a: Grid Control
