# Guia Class, caixa de diálogo Class Info

Fornece informações gerais sobre a classe e seus ícones associados. A caixa de diálogo que contém esta guia aparece quando você escolhe Class Info no menu Class.
 **Toolbar Icon**
Exibe o nome do ícone da barra de ferramentas da classe. Escolha o botão de diálogo para selecionar um ícone para a classe. O ícone da barra de ferramentas da classe é exibido na barra de ferramentas Form Controls no Form Designer e no Class Designer quando você popula a barra de ferramentas Form Controls com as classes na sua biblioteca de classes. O ícone da barra de ferramentas da classe também aparece no contêiner Project quando a classe faz parte de um projeto.
**Container Icon**
Exibe o nome do ícone da barra de ferramentas do contêiner da classe. Escolha o botão de diálogo para selecionar um ícone para o contêiner da classe. O ícone do contêiner é exibido somente na janela Class Browser.
**OLEPublic**
Especifica que, quando um programa contendo a palavra-chave OLEPublic é compilado pelo Project Manager, um servidor Automation personalizado é gerado. Um Identificador Globalmente Único, ou GUID, também é gerado para o programa.
**Description**
Exibe comentários sobre a classe selecionada. Você pode digitar uma nova descrição na caixa ou editar uma existente.
**Class Name**
Exibe o nome da classe selecionada no Class Designer.
**Parent Class**
Exibe o nome da classe pai.
**Class Library**
Exibe o caminho e o nome do arquivo da biblioteca de classes.
