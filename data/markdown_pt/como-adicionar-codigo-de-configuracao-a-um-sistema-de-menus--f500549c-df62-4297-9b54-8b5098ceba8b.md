# Como: adicionar código de configuração a um sistema de menus

Você pode personalizar um sistema de menus adicionando código de configuração a ele. O código de configuração pode incluir código para criar o ambiente, definir variáveis, abrir arquivos necessários e salvar ou restaurar sistemas de menus com os comandos PUSH MENU e POP MENU.

### Para adicionar código de configuração a um sistema de menus
- No menu View, escolha General Options .
- Na área Menu Code, selecione Setup e então escolha OK .
- Na janela de código de configuração, digite o código de configuração apropriado. Suas alterações são salvas quando você fecha o Menu Designer.
