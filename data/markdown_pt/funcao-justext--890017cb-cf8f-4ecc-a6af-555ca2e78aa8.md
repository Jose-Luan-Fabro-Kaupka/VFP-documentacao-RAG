# Função JUSTEXT( )

Retorna os caracteres de uma extensão de arquivo de um caminho completo.

```foxpro
JUSTEXT(cPath)
```

#### Parâmetros
 **cPath**
Especifica o nome, que pode incluir o caminho completo, do arquivo para o qual você deseja apenas a extensão. O comprimento máximo da cadeia passada para cPath é de 259 bytes.

# Valor de retorno

Caractere
