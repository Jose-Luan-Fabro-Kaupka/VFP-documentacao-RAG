# Comando SET COLOR SET

Carrega um conjunto de cores previamente definido.

```foxpro
SET COLOR SET TO [ColorSetName]
```

#### Parâmetros
 **ColorSetName**
Especifica o conjunto de cores a carregar.

# Observações

Você pode criar conjuntos de cores com SET COLOR OF SCHEME e salvá-los com CREATE COLOR SET.

Se você emitir SET COLOR SET sem uma cláusula opcional, o conjunto de cores atual permanece carregado.
