# Como: criar projetos

Você pode criar um projeto para seu aplicativo usando o Application wizard ou como um projeto vazio. Depois de criar um projeto, o Visual FoxPro gera as pastas e arquivos associados para o novo projeto, incluindo o arquivo principal do projeto (.pjx) e o arquivo memo do projeto (.pjt).

Um assistente ajuda a criar e definir opções para o projeto do aplicativo usando suas respostas a uma série de perguntas. O Application Wizard ajuda a criar um projeto, adicionar arquivos usando o Application Builder e criar uma estrutura de aplicativo que inclui elementos obrigatórios e opcionais para aplicativos.

### Para criar um projeto usando um assistente
- No menu File, clique em New .
- Na caixa de diálogo New, clique em Project e depois em Wizard . A caixa de diálogo Application Wizard é aberta.
- Na caixa Project name da caixa de diálogo Application Wizard, digite o nome do seu projeto. Para escolher outro local para o projeto, altere o local na caixa Project file ou clique em Browse para selecionar um local diferente. A caixa Project file exibe o local e o nome do projeto conforme você digita.
- Quando terminar, clique em OK .

O Visual FoxPro exibe a caixa de diálogo Application Builder para que você possa definir opções adicionais e adicionar arquivos ao aplicativo.

Para obter mais informações, consulte Application Wizard, Application Builder e Creating Applications with the Application Framework.

### Para criar um projeto vazio
- No menu File, clique em New .
- Na caixa de diálogo New, clique em Project e depois em New File .
- Na caixa de diálogo Create, escolha um local para salvar o projeto e digite o nome do novo projeto.
- Clique em Save .

O Visual FoxPro abre a janela Project Manager do seu projeto. Para obter mais informações, consulte Project Manager Window.

### Para criar um projeto programaticamente
- Use o comando CREATE PROJECT para abrir o Project Manager .

Para obter mais informações, consulte CREATE PROJECT Command.

Depois de criar o projeto, o Visual FoxPro abre o Project Manager para que você possa adicionar e trabalhar com arquivos no projeto. Os arquivos devem ser adicionados a um projeto para serem incluídos em um aplicativo. Para obter mais informações, consulte How to: Add Files to a Project.

Se você tiver dados, como planilhas, arquivos de texto ou tabelas de outros aplicativos, pode importá-los para o Visual FoxPro e adicioná-los ao projeto. Para obter mais informações, consulte Importing and Exporting Data.
