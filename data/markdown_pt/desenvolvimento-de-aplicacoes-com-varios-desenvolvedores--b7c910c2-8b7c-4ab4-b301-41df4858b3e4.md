# Desenvolvimento de aplicações com vários desenvolvedores

Se você tem vários desenvolvedores trabalhando em suas aplicações, pode usar a capacidade do Visual FoxPro de permitir acesso simultâneo a componentes de banco de dados. Além disso, para rastrear e proteger alterações no seu código-fonte, você pode usar programas de controle de código-fonte com o Project Manager.

Permitir que várias pessoas trabalhem em objetos de banco de dados Agora você pode modificar definições de tabelas e views sem acesso exclusivo ao banco de dados. Use a opção Refresh no menu Database – isso recarrega a definição do objeto de banco de dados para refletir quaisquer alterações feitas por outros usuários.

Usar controle de código-fonte Você pode usar um programa de controle de código-fonte, como o Microsoft Visual SourceSafe, para coordenar e gerenciar alterações em aplicações que desenvolve no Visual FoxPro. O Project Manager fornece acesso ao controle de código-fonte no menu Project.

Para obter mais informações sobre como trabalhar com vários desenvolvedores, consulte Planning for Team Development Projects.
