# Comando EJECT

Envia um avanço de página para a impressora.

```foxpro
EJECT
```

# Observações

EJECT avança a impressora até o início da próxima página. Ele envia um avanço de página se a variável de memória do sistema _PADVANCE estiver definida como FORMFEED. Se estiver definida como LINEFEEDS, EJECT emite avanços de linha até o início da próxima página.

EJECT redefine os valores de PCOL( ) e PROW( ) para a posição atual de coluna e linha do cabeçote de impressão, mas não afeta _PAGENO nem _PLINENO.

# Exemplo

No exemplo a seguir, os campos `company` e `phone` da tabela `customer` são impressos. Certifique-se de que haja uma impressora conectada e ligada. Quando o número de linhas impressas ultrapassa 62, a página é ejetada.

```foxpro
CLOSE DATABASES
OPEN DATABASE (HOME(2) + 'data\testdata')
USE customer  && Opens customer table
SET DEVICE TO PRINTER
SET PRINT ON
DO WHILE NOT EOF()
   @ PROW()+1,10 SAY 'Company: ' + company
   @ PROW()+1,10 SAY 'Phone: ' + phone
   @ PROW()+1,1  SAY ''
   IF PROW() > 62
      EJECT
   ENDIF
   SKIP
ENDDO
SET PRINT OFF
SET DEVICE TO SCREEN
```
