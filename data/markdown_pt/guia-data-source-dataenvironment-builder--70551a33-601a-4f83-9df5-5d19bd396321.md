# Guia Data Source, DataEnvironment Builder

Especifica o tipo de origem de dados e a origem de dados a ser usada, se necessário.

> **Observação:** Ao acessar tabelas no Microsoft Access, particularmente tabelas que têm espaços em nomes de colunas, você deve usar o Microsoft OLE DB Provider for Access em vez do driver ODBC do Microsoft Access e especificar ADO como o tipo de origem de dados. Para escolher o OLE DB Provider for Access, na guia Data Source, selecione ADO na caixa Data source type. Clique em Use connection string e depois no botão Build para continuar construindo a cadeia de conexão para o banco de dados Access.
 **Data source type**
Especifica o tipo de origem de dados. Dependendo do tipo de origem de dados selecionado, você pode selecionar ou construir uma das seguintes origens de dados: ADO Especifica uma das seguintes maneiras de estabelecer uma conexão ActiveX Data Objects (ADO). Use existing ADO Recordset Especifica uma referência a um objeto ADO RecordSet válido. Esta referência deve ser válida em tempo de design se o CursorAdapter Builder for usar este RecordSet. Use DSN Especifica um nome de origem de dados (DSN) na lista Data source e valores nas caixas User ID e Password, se aplicável. Na maioria dos casos, selecionar um DSN para uma conexão ADO resulta no uso do driver Open Database Connectivity (ODBC) especificado pelo DSN por meio do MSDASQL OLE DB Provider for ODBC. Certos provedores OLE DB podem mapear as configurações ODBC DSN para as configurações correspondentes no provedor OLE DB correspondente. Observação Você não deve usar um nome DSN se o provedor OLE DB não puder mapear configurações ODBC DSN. Você pode usar um driver ODBC para uma origem de dados que não tenha um provedor OLE DB. Use connection string Especifica uma cadeia de conexão válida. Este é o mesmo tipo de cadeia de conexão que você insere para a propriedade ADO ConnectionString. Alternativamente, você pode selecionar o botão Build para exibir a caixa de diálogo Data Link Properties. Você pode então selecionar o provedor OLE DB apropriado e outros parâmetros necessários da cadeia de conexão. Native Especifica um nome e caminho de banco de dados válidos na caixa Database. Você pode procurar e selecionar um banco de dados a ser usado clicando no botão de reticências (...) para exibir a caixa de diálogo Select Database. ODBC Especifica uma das seguintes maneiras de estabelecer uma conexão de banco de dados. Use existing connection handle Especifica uma propriedade, variável de memória, valor ou expressão que é avaliada como um identificador de conexão válido em tempo de execução. Use DSN Especifica um nome de origem de dados (DSN) na lista Data source e valores nas caixas User ID e Password, se aplicável. Use connection string Especifica uma cadeia de conexão válida. Este é o mesmo tipo de cadeia de conexão que você insere para a função SQLSTRINGCONNECT( ). Para obter mais informações, consulte a função SQLSTRINGCONNECT( ). XML Especifica XML como a origem de dados.
