# Variável de Sistema _PPITCH

Incluída para compatibilidade com versões anteriores. Use o Report Designer em vez disso.

Define o pitch da impressora.

```foxpro
_PPITCH = expC
```

# Observações

_PPITCH é incluída para compatibilidade com versões anteriores. Use o Report Writer em vez disso.

O aplicativo de driver de impressora GENPD.APP fornecido com o FoxPro para MS-DOS não usa _PPITCH. Qualquer valor armazenado na variável de sistema _PPITCH não tem efeito sobre a saída impressa.

_PPITCH está disponível para seu uso em um aplicativo de driver de impressora que você criar.
