# Como: configurar a grade de layout de página para relatórios

Você pode usar a grade de layout de página para ajudar a posicionar e alinhar objetos de relatório e etiqueta. Você pode definir as seguintes opções para a grade:
 - Exibir linhas de grade, que não aparecem na saída resultante.
- Ativar a funcionalidade snap-to-grid, que permite alinhar objetos às linhas de grade automaticamente.
- Alterar unidades de medida para a régua.
- Definir espaçamento da grade.
- Mostrar a posição dos objetos na grade.

### Para mostrar ou ocultar linhas de grade
- Abra o relatório ou etiqueta no designer apropriado.
- No menu Exibir, clique em Grid Lines para que esteja selecionado. O designer mostra linhas de grade para posicionar e alinhar objetos de relatório e etiqueta.

### Para ativar snap-to-grid
- Abra o relatório ou etiqueta no designer apropriado.
- No menu Formatar, clique em Snap to Grid para que esteja selecionado. Quando você arrasta objetos no designer, eles se posicionam ao longo das linhas de grade. Observação As linhas de grade visíveis fornecem orientação ao alinhar controles no layout. Essas linhas não determinam as coordenadas da grade às quais seus controles se ajustam quando Snap to Grid está ativado. Consulte Guia Ruler/Grid, Caixa de diálogo Propriedades do relatório (Report Builder) para mais informações. Dica Você pode habilitar Snap to Grid para orientação geral mesmo em relatórios que exigem posicionamento mais exato. Para substituir o recurso de alinhamento automático e posicionar controles exatamente, selecione-os no layout e use as teclas de seta para movê-los. Você também pode usar as opções padrão do Report Builder para ajustar Tamanho e posição no layout para controles individuais de relatório. Consulte Guia General, Caixa de diálogo Propriedades do controle de relatório (Report Builder) para mais informações.

### Para alterar a unidade de medida da régua
- Abra o relatório ou etiqueta no designer apropriado.
- No menu Formatar, clique em Set Grid Scale . A caixa de diálogo Propriedades do relatório abre. Observação Se a variável de sistema _REPORTBUILDER não estiver definida para o Report Builder padrão ou estiver definida para um construtor de terceiros, a caixa de diálogo Set Grid Scale é exibida ou uma caixa de diálogo diferente pode ser exibida. Para mais informações, consulte Variável de sistema _REPORTBUILDER e Caixa de diálogo Set Grid Scale .
- Na caixa de diálogo Propriedades do relatório, clique na guia Ruler/Grid.
- Na lista Ruler, selecione a unidade de medida desejada.
- Quando terminar, clique em OK .

Para mais informações, consulte Guia Ruler/Grid, Caixa de diálogo Propriedades do relatório (Report Builder).

### Para definir o espaçamento da grade
- Abra o relatório ou etiqueta no designer apropriado.
- No menu Formatar, clique em Set Grid Scale . A caixa de diálogo Propriedades do relatório abre. Observação Se a variável de sistema _REPORTBUILDER não estiver definida para o Report Builder padrão ou estiver definida para um construtor de terceiros, a caixa de diálogo Set Grid Scale é exibida ou uma caixa de diálogo diferente pode ser exibida. Para mais informações, consulte Variável de sistema _REPORTBUILDER e Caixa de diálogo Set Grid Scale .
- Na caixa de diálogo Propriedades do relatório, clique na guia Ruler/Grid.
- Nas caixas Horizontal spacing e Vertical spacing, digite ou selecione o espaçamento desejado.
- Quando terminar, clique em OK .

Para mais informações, consulte Guia Ruler/Grid, Caixa de diálogo Propriedades do relatório (Report Builder).

### Para mostrar a posição do objeto na grade
- Abra o relatório ou etiqueta no designer apropriado.
- No menu Exibir, clique em Show Position para que esteja selecionado. Quando você move o mouse ou arrasta um objeto pela grade, a posição é exibida na barra de status.
