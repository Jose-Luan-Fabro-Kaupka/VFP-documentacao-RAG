# Desenvolvendo aplicativos internacionais

Esta seção descreve como usar os recursos internacionais do Visual FoxPro para desenvolver e planejar aplicativos compatíveis e eficazes em mercados internacionais.

# Nesta seção
 **Planejando um aplicativo internacional**
Descreve etapas para preparar um aplicativo internacional.
**Projetando para localização**
Descreve as melhores práticas a serem usadas ao projetar componentes de interface do usuário para localização.
**Gerenciando arquivos em um aplicativo internacional**
Explica como o Project Manager pode ajudar você a organizar um aplicativo internacional. Em um projeto, você pode integrar as partes de um aplicativo, como formulários, menus, programas e relatórios.
