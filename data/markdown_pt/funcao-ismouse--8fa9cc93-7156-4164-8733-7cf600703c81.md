# Função ISMOUSE( )

Retorna verdadeiro (.T.) se o hardware do mouse estiver presente.

```foxpro
ISMOUSE()
```

# Observações

ISMOUSE( ) retorna verdadeiro (.T.) se o hardware do mouse estiver presente; caso contrário, retorna falso (.F.).

# Exemplo

O exemplo a seguir exibe um valor verdadeiro (.T.) se o hardware do mouse estiver presente; caso contrário, exibe falso (.F.).

```foxpro
CLEAR
? 'Mouse hardware present? '
?? ISMOUSE()
```
