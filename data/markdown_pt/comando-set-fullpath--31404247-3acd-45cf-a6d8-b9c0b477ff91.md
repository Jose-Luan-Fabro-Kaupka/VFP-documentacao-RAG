# Comando SET FULLPATH

Especifica se CDX( ), DBF( ), MDX( ) e NDX( ) retornam o caminho em um nome de arquivo.

```foxpro
SET FULLPATH ON | OFF
```

#### Parâmetros
 **ON**
(Padrão) Especifica que CDX( ), DBF( ), MDX( ) e NDX( ) retornam o designador de unidade, o caminho e o nome do arquivo.
**OFF**
Especifica que somente o designador de unidade e o nome do arquivo são retornados.
