# Caixa de diálogo Salvar como classe

Permite salvar um formulário ou controles selecionados em um formulário como uma definição de classe. Se você planeja criar subclasses baseadas no formulário ou reutilizar os controles para outros formulários, salve o formulário como uma classe.

Esta caixa de diálogo aparece quando você seleciona Save As Class no menu File.
 **Save**
Especifica a parte do formulário a salvar como definição de classe. Selected Controls Salva apenas os controles selecionados como definição de classe. Current Form Salva o formulário ativo como definição de classe. Entire Form Set Salva uma coleção de formulários relacionados como definição de classe. Este comando é habilitado depois que você usa o comando Create FormSet no menu Form. DataEnvironment Salva o data environment de um formulário e quaisquer cursors ou cursor adapters contidos no arquivo de biblioteca de classes visual (.vcx) especificado.
**As Class**
Especifica a definição de classe na qual salvar os controles selecionados, formulário inteiro ou form set. Name Especifica o nome atribuído à classe. File Especifica o nome do arquivo .vcx no qual armazenar a definição de classe. Description Especifica a descrição opcional para a classe.
