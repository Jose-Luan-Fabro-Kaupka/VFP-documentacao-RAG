# Conversão de tipo exigida pela propriedade DataType para o campo "name" é inválida (Erro 1543)

A conversão de tipo entre o tipo de dados remoto e o tipo de dados do Visual FoxPro, especificado pela propriedade DataType do campo da view, não é suportada para o campo da view que está sendo ativada.

Altere a propriedade DataType do campo da view para um tipo válido.
