# Assistentes (Visual FoxPro)

O Visual FoxPro é fornecido com vários assistentes. Assistentes são programas interativos que ajudam você a realizar rapidamente tarefas comuns, como criar formulários, formatar relatórios, configurar consultas, importar e fazer upsizing de dados, criar gráficos, gerar saída de mala direta, gerar tabelas dinâmicas, criar consultas de tabulação cruzada e publicar em formato HTML para a Web.

Ao responder perguntas ou escolher opções na série de telas do assistente, você informa ao assistente para construir um arquivo ou executar uma tarefa com base em suas respostas.

A maioria dos assistentes tem várias opções de saída na última página. Essas opções de saída geralmente são para arquivos que podem ser vinculados à sua aplicação. Por exemplo, o assistente Web Publishing tem uma opção de script de saída, que cria um arquivo de programa (.prg) que gera dinamicamente uma página HTML a partir de dados do FoxPro. Você pode incluir esse arquivo de script na sua aplicação e executá-lo a partir de um item de menu ou botão em um formulário.

Observe que assistentes adicionais estão disponíveis no site do Visual FoxPro em http://msdn.microsoft.com/vfoxpro/.

# Nesta seção
 **Application Wizard**
Permite criar um projeto e um Visual FoxPro Enhanced Application Framework e, em seguida, abre o Application Builder, para que você possa adicionar um banco de dados, tabelas, formulários ou relatórios que já criou.
**Cross-Tab Wizard**
Permite criar uma consulta de tabulação cruzada para resumir dados de tabelas existentes.
**Database Wizard**
Permite usar modelos predefinidos para ajudar a criar um banco de dados contendo tabelas apropriadas.
**Documenting Wizard**
Permite formatar e produzir arquivos de texto a partir do código em seus projetos e arquivos de programa.
**Form Wizard**
Facilita o uso de uma única tabela para criar um formulário para entrada de dados.
**Graph Wizard**
Permite criar um gráfico a partir de uma tabela do Visual FoxPro usando o Microsoft Graph.
**Import Wizard**
Permite mover dados para arquivos de tabela do Visual FoxPro (.dbf) a partir de outros formatos de arquivo, como texto simples, Microsoft Excel, Microsoft Word e outros arquivos.
**Label Wizard**
Permite criar etiquetas que você pode colar em envelopes e pacotes ou usar em sua própria situação personalizada.
**Local View Wizard**
Permite criar views, que são exibições personalizadas de algumas ou todas as informações, usando dados nativos do Visual FoxPro.
**Mail Merge Wizard**
Permite criar uma fonte de dados, como nomes ou endereços, para um documento mesclado do Microsoft Word, como uma carta padrão, etiquetas de correspondência, envelopes ou catálogos, ou um arquivo de texto que pode ser usado por qualquer processador de texto.
**One-To-Many Form Wizard**
Permite criar um formulário de entrada de dados que atualiza várias tabelas a partir de um único formulário.
**One-To-Many Report Wizard**
Permite criar um relatório que agrupa registros de uma tabela pai com registros de uma tabela filha.
**PivotTable Wizard**
Permite criar tabelas de planilha interativas usadas para resumir e analisar dados de tabelas existentes.
**Query Wizard**
Permite criar uma consulta para selecionar um grupo de registros com base em regras que você especifica.
**Remote View Wizard**
Permite criar views, que são exibições personalizadas de algumas ou todas as informações, usando dados remotos (ODBC).
**Report Wizard**
Permite criar relatórios usando uma tabela livre ou uma tabela ou view em um banco de dados.
**SQL Server Upsizing Wizard**
Permite criar um banco de dados SQL Server que duplica, tanto quanto possível, a funcionalidade de um banco de dados do Visual FoxPro.
**Table Wizard**
Permite criar tabelas com base em estruturas de tabela típicas e permite selecionar uma tabela adequada às suas necessidades a partir de uma lista de tabelas de exemplo.
**Web Publishing Wizard**
Exibe dados de uma tabela ou view em um documento HTML.
