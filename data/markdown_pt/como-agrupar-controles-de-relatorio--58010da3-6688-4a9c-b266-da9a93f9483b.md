# Como: agrupar controles de relatório

Você pode associar vários controles entre si e salvar essa preferência no layout agrupando-os. Depois de formatar e alinhar controles, agrupá-los é útil para preservar suas posições em relação uns aos outros. Depois de agrupar controles, você pode movê-los como uma única unidade.

> **Observação:** Propriedades não estão disponíveis para itens agrupados. Você deve desagrupá-los antes de poder invocar suas caixas de diálogo de propriedades.

### Para agrupar controles
- Abra o relatório ou etiqueta no designer apropriado.
- No designer, selecione os controles que deseja agrupar.
- No menu Format, clique em Group . As alças de seleção se movem de cada controle para envolver o grupo de controles.

### Para remover o agrupamento de controles agrupados
- Abra o relatório ou etiqueta no designer apropriado.
- No designer, clique no grupo de controles.
- No menu Format, clique em Ungroup . As alças de seleção se movem de envolver o grupo de controles para as bordas de cada um dos controles que estavam no grupo.
