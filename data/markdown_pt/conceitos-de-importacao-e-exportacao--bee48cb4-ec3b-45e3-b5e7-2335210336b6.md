# Conceitos de importação e exportação

Você pode escolher entre três maneiras de copiar dados para ou a partir do Visual FoxPro:
 - Importação
- Anexação
- Exportação

Quando você importa ou anexa dados, traz os dados de outro aplicativo para o Visual FoxPro. Quando exporta dados, envia dados de uma tabela do Visual FoxPro para um tipo de arquivo usado por outro aplicativo. Esses métodos permitem copiar e usar os dados, em vez de vinculá-los ou compartilhá-los.

Quando você importa dados, copia dados de um arquivo de origem, cria uma nova tabela e preenche a tabela com os dados do arquivo. Por exemplo, você pode importar os dados de uma tabela dBASE para criar uma tabela do Visual FoxPro. Depois de importar um arquivo, você pode usá-lo como qualquer outra tabela do Visual FoxPro.

Quando você anexa dados, adiciona os dados de origem a uma tabela do Visual FoxPro após o último registro da tabela. Você pode especificar campos para importar e selecionar registros que atendam a uma condição em uma expressão. Depois de anexar a partir do arquivo, você pode visualizar e editar os registros na tabela do Visual FoxPro.

Quando você exporta, copia dados de uma tabela do Visual FoxPro para um novo arquivo formatado para uso em outro aplicativo. Por exemplo, você pode exportar dados do Visual FoxPro para um arquivo de planilha do Microsoft Excel.

Você seleciona os arquivos de origem e destino. Você também pode especificar campos para exportar, definir o escopo dos registros a exportar e selecionar registros que atendam a uma condição.
