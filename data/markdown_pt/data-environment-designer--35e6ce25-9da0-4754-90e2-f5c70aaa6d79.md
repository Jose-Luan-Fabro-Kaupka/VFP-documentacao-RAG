# Data Environment Designer

Use o Data Environment Designer para criar e modificar visualmente o ambiente de dados de formulários, conjuntos de formulários e relatórios. Quando a janela do Data Environment Designer está ativa, o Visual FoxPro exibe o menu Data Environment, que permite manipular objetos do ambiente de dados. Para exibir a janela Properties e a janela Code, clique com o botão direito do mouse para exibir o menu de atalho do Data Environment e, em seguida, clique em Properties e Code.

Um ambiente de dados define a origem dos dados usados em um formulário ou relatório. Isso pode incluir tabelas, views e relacionamentos. O ambiente de dados é salvo com o formulário ou relatório e pode ser modificado sempre que você estiver usando o Report Designer ou o Form Designer.

Quando o ambiente de dados de um formulário ou relatório é definido, o Visual FoxPro abre automaticamente as tabelas ou views quando você abre ou executa o arquivo e as fecha quando o arquivo é fechado ou liberado.
 - Para formulários, o Visual FoxPro preenche a lista da propriedade ControlSource na janela Properties com todos os campos do seu ambiente de dados.
- Para relatórios, o Visual FoxPro preenche o conjunto de dados que seu relatório precisa com base nas tabelas e views associadas.
- Para obter mais informações sobre o uso do Data Environment Designer com formulários, consulte Creating Forms .
