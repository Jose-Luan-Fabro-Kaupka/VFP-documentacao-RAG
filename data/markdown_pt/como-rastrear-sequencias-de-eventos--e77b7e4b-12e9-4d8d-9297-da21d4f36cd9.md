# Como: rastrear sequências de eventos

Você pode visualizar a sequência em que os eventos ocorrem ativando o rastreamento de eventos no Visual FoxPro Debugger. Você pode determinar o local mais eficiente para adicionar código a eventos usando o rastreamento de eventos para ver quando os eventos associados aos seus formulários e controles ocorrem em relação a outros eventos.

### Para ativar o rastreamento de eventos
- No menu Tools, escolha Debugger .
- No menu Tools do Visual FoxPro Debugger , escolha Event Tracking .
- Na caixa de diálogo Event Tracking, selecione Turn event tracking on .

Você também pode definir o rastreamento de eventos usando o comando SET EVENTTRACKING. Para obter mais informações, consulte SET EVENTTRACKING Command.

Por padrão, os eventos que aparecem na lista de rastreamento de eventos aparecem na janela Debug Output conforme ocorrem. Você também pode optar por enviar os resultados de saída para um arquivo.

Para obter mais informações, consulte How to: Use the Debugger, Debugger Window, and Event Tracking Dialog Box.
