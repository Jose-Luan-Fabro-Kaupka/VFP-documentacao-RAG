# Trabalhando com consultas

Quando sua aplicação inclui tabelas, você pode selecionar e exibir dados dessas tabelas usando consultas. Você pode usar consultas para várias tarefas:
 - Responder a uma pergunta rapidamente. Por exemplo, você pode descobrir informações como: Nome e endereço do cliente associado a um determinado número de ID Número de pedidos pendentes Número de clientes com saldos em atraso Região ou vendedor com o melhor registro de vendas
- Exibir um subconjunto relevante dos seus dados
- Organizar e gerar dados para um relatório. Você também pode executar relatórios separadamente sem usar uma consulta.

Você pode criar consultas a partir de tabelas, definir e organizar resultados de consultas, coletar entrada do usuário usando consultas e personalizar consultas. Você também pode direcionar consultas para destinos diferentes para poder usá-las em outras partes da sua aplicação.
