# Como: visualizar e definir propriedades de banco de dados

Bancos de dados e objetos de banco de dados, como conexões e views, possuem propriedades que você pode visualizar e algumas que você pode definir. Você pode visualizar e definir essas propriedades usando as funções DBGETPROP( ) e DBSETPROP( ). Para obter mais informações, consulte DBGETPROP( ) Function e DBSETPROP( ) Function.

No entanto, você pode definir a propriedade Comment para um banco de dados usando a interface do Visual FoxPro.

### Para adicionar comentários ao banco de dados atual
- Abra o banco de dados no Database Designer .
- No menu Database, clique em Properties para abrir a caixa de diálogo Database Properties.
- Na caixa Comment, digite um comentário para o banco de dados.
- Quando terminar, clique em OK .
