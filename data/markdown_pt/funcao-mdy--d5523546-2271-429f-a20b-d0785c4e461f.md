# Função MDY( )

Retorna a data ou expressão datetime especificada no formato mês-dia-ano com o nome do mês por extenso.

```foxpro
MDY(dExpression | tExpression)
```

#### Parâmetros
 **dExpression**
Especifica a expressão de data a retornar no formato mês-dia-ano.
**tExpression**
Especifica a expressão datetime a retornar no formato mês-dia-ano.

# Valor de retorno

Caractere

# Observações

Se SET CENTURY estiver OFF, a expressão de caractere é retornada no formato month dd, yy. Se SET CENTURY estiver ON, o formato é month dd, yyyy.

# Exemplo

O exemplo a seguir cria uma função definida pelo usuário que retorna uma data com o dia da semana correspondente.

```foxpro
SET CENTURY OFF
CLEAR
? Longdate({^1998-02-16})  && Displays Monday, February 16, 98
SET CENTURY ON
? Longdate({^1998-02-16})  && Displays Monday, February 16, 1998
*** LongDate ***
FUNCTION longdate
PARAMETERS gdDate
RETURN CDOW(gdDate) + ', ' + MDY(gdDate)
```
