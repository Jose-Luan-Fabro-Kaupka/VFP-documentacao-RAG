# Propriedade ColumnLines

Mostra ou oculta as linhas entre colunas. Disponível em tempo de design e em tempo de execução.

```foxpro
Control.ColumnLines[ = lExpr]
```

# Valor de retorno
 **lExpr**
Especifica se as linhas que separam colunas são exibidas. As configurações para a propriedade ColumnLines são: Configuração Descrição True (.T.) (Padrão) As linhas entre colunas estão visíveis. False (.F.) As linhas entre colunas estão ocultas.

# Observações

Aplica-se a: ComboBox Control | ListBox Control
