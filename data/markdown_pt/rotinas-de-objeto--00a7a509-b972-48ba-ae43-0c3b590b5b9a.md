# Rotinas de objeto

Estas rotinas de API permitem manipular objetos e controles do Visual FoxPro.
 **Rotina de biblioteca de API _FreeObject( )**
Libera um objeto do pool de dados da API do Visual FoxPro.
**Rotina de biblioteca de API _GetObjectProperty( )**
Retorna o valor de uma propriedade de um objeto.
**Rotina de biblioteca de API _ObjectCmp( )**
Compara as propriedades de dois objetos e retorna 0 se as propriedades e seus valores forem idênticos.
**Rotina de biblioteca de API _ObjectReference( )**
Incrementa a contagem de referências de um objeto.
**Rotina de biblioteca de API _ObjectRelease( )**
Decrementa a contagem de referências de um objeto.
**Rotina de biblioteca de API _SetObjectProperty( )**
Define uma propriedade de um objeto.
**Rotina de biblioteca de API _WGetObjectClientWindow( )**
Retorna o identificador da janela cliente que contém o objeto especificado.
**Rotina de biblioteca de API _WGetObjectWindow( )**
Retorna o identificador da janela de quadro que contém o objeto especificado.
