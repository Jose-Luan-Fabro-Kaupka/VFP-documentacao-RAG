# Configurando arquivos de Ajuda para aplicativos

Você pode adicionar Ajuda ao seu aplicativo configurando-o para acessar um arquivo de Ajuda que você cria.

# Referência
 **Comando SET HELP**
Habilita ou desabilita a Ajuda online do Microsoft Visual FoxPro ou especifica um arquivo de Ajuda.
**Comando SET TOPIC**
Especifica o tópico ou tópicos de Ajuda a abrir quando você invoca o sistema de Ajuda do Visual FoxPro.
**Comando SET TOPIC ID**
Especifica o tópico de Ajuda a exibir quando você invoca o sistema de Ajuda do Visual FoxPro. O tópico de Ajuda é baseado no ID de contexto do tópico.
