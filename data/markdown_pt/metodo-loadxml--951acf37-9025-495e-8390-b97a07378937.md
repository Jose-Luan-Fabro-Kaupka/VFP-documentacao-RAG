# Método LoadXML

Carrega XML de um arquivo ou cadeia de caracteres em um documento Document Object Model (DOM) e o anexa ao objeto XMLAdapter.

```foxpro
XMLAdapter.LoadXML( cXMLDocument [, lFile [, lValidateOnParse ]] )
```

#### Parâmetros
 **cXMLDocument**
Especifica um nome de arquivo XML, cadeia XML ou expressão que avalia para um nome de arquivo XML ou cadeia válidos.
**lFile**
Especifica se cXMLDocument é um nome de arquivo. O valor padrão de lFile é False (.F.).
**lValidateOnParse**
Especifica se o XML deve ser validado durante a análise. O valor padrão de lValidateOnParse é True (.T.). Para obter mais informações sobre como o DOM executa validação, consulte o Microsoft XML Core Services (MSXML) 4.0 SDK no site da MSDN Library em http://msdn.microsoft.com/library/ .

# Observações

Aplica-se a: XMLAdapter Class

LoadXML define a propriedade XMLAdapter IXMLDOMElement. Além disso, se o esquema XML for analisado, o Visual FoxPro preenche a coleção Tables com um novo conjunto de objetos XMLTable e define as propriedades XMLAdapter XMLName, XMLNamespace, XMLPrefix, IsDiffgram e SOM para valores apropriados.

Se a propriedade RespectNesting do objeto XMLAdapter for True (.T.), o método LoadXML preserva a hierarquia XML dentro do documento. No entanto, o método ignora a declaração do elemento de nível superior se esse elemento for referenciado por algum outro elemento complexo. Nesse caso, o método aninha o objeto XMLTable do elemento referenciado no objeto XMLTable do elemento que tem uma referência a ele.

Se o documento XML não estiver formatado como um dataset do Visual Studio, o objeto XMLAdapter deixa as propriedades XMLName e XMLPrefix vazias. A propriedade XMLNamspace é definida como o valor do atributo targetNamespace para o nó xsd:schema. Cada elemento XML declarado como xsd:complexType é mapeado para um objeto XMLTable, e a propriedade XMLNamespace é definida como namespaceURI para o elemento. As propriedades IsDiffgram e SOM são definidas para valores apropriados.

As seguintes configurações de propriedade afetam como o método LoadXML é executado:
 - DisableEncode Property
- MapN19_4ToCurrency Property
- NoCpTrans Property
- PreserveWhiteSpace Property
- WrapCharInCDATA Property
- WrapMemoInCDATA Property
- XMLSchemaLocation Property
- RespectNesting Property
