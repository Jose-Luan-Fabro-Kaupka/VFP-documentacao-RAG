# Comando @ ... PROMPT

Incluído para compatibilidade com versões anteriores. Use os Designers de Menu e Atalho e o comando CREATE MENU em vez disso.

Cria uma barra de menu.

```foxpro
@ row, column PROMPT expC1
	[MESSAGE expC2]
```

#### Parâmetros
 row, column

 As coordenadas row, column especificam onde os pads da barra de menu são colocados. Se row for o mesmo para cada @ ... PROMPT, uma barra de menu horizontal é criada. Se column for o mesmo para cada comando @ ...PROMPT, uma barra de menu vertical é criada.

 expC1

 A expressão de caracteres expC1 é o prompt que aparece no pad da barra de menu.

MESSAGE expC2

 A expressão de caracteres expC2 aparece quando a barra de menu é ativada com MENU TO.

# Observações

@ ... PROMPT está incluído para compatibilidade com versões anteriores. Use o Menu Builder para criar menus e popups de menu.

Usando uma série de @ ... PROMPTs você pode criar os pads da barra de menu e especificar suas posições na janela principal do FoxPro ou em uma janela definida pelo usuário.

Depois que os pads da barra de menu são criados, emita MENU TO para ativar a barra de menu.

Quando você escolhe um pad da barra de menu, um número é retornado a uma variável de memória ou elemento de matriz especificado em MENU TO. O número retornado é determinado pela ordem em que os pads são definidos. Por exemplo, se cinco pads são definidos com cinco @ ... PROMPTs e você escolhe o terceiro pad, 3 é armazenado na variável de memória ou elemento de matriz.

Para escolher um pad da barra de menu, pressione Enter ou a barra de espaço quando o pad desejado estiver selecionado, ou clique no pad.

Um pad de menu é desabilitado colocando uma barra invertida (\) antes do prompt do pad. Um pad de menu desabilitado aparece na barra de menu, mas não pode ser selecionado. Você também pode criar uma tecla de atalho para um pad de menu colocando uma barra invertida e um sinal de menor que (\<) antes do caractere no prompt que você deseja que seja a tecla de atalho.

Se um prompt contém mais de uma ocorrência de um caractere, a primeira ocorrência desse caractere é a tecla de atalho. No exemplo a seguir, o segundo D em ADD é especificado como tecla de atalho, mas o primeiro D é a tecla de atalho.

@ 1,20 PROMPT 'AD\<D' MESSAGE 'Add a record'

Se SET CONFIRM estiver ON, você pode selecionar um pad da barra de menu pressionando a tecla correspondente ao primeiro caractere do prompt. Depois que um pad da barra de menu é selecionado, pressione Enter ou a barra de espaço para escolher o pad. Se teclas de atalho foram atribuídas aos pads, você pode escolher um pad pressionando sua tecla de atalho. As teclas de atalho não são afetadas por SET CONFIRM.

Se SET CONFIRM estiver OFF, pressionar a tecla correspondente ao primeiro caractere do prompt de um pad da barra de menu escolhe o pad. Se pads da barra de menu foram definidos com teclas de atalho diferentes do primeiro caractere dos pads da barra de menu, as teclas de atalho têm precedência.

# Exemplo

```foxpro
SET TALK OFF
CLEAR
SET MESSAGE TO 24 CENTER
@ 1,20 PROMPT '\
```
