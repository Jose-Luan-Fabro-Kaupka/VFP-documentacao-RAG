# Guia Value, List Box Builder

Esta guia especifica de onde obter e onde armazenar os valores de retorno.
 **Return the Value From**
Especifica a coluna ou o campo do qual obter um valor quando o usuário seleciona um item. Corresponde à propriedade BoundColumn.
**Field Name**
Especifica um campo de tabela ou view no qual armazenar o valor. Por padrão, a lista inclui campos selecionados na guia List Items. O botão de diálogo permite selecionar outro arquivo. Corresponde à propriedade ControlSource.
