# Comando SET VIEW

Abre ou fecha a janela Data Session ou restaura o ambiente do Visual FoxPro a partir de um arquivo de exibição.

```foxpro
SET VIEW ON | OFF
-or-
SET VIEW TO FileName | ?
```

#### Parâmetros
 **ON**
Abre a janela Data Session.
**OFF**
(Padrão) Fecha a janela Data Session.
**TO FileName**
Restaura o ambiente do Visual FoxPro ao estado em que estava quando o arquivo de exibição especificado com FileName foi criado. Arquivos de exibição são criados com CREATE VIEW.
**?**
Exibe a caixa de diálogo Open, na qual você pode abrir um arquivo de exibição.

# Observações

Para obter mais informações sobre arquivos de exibição, consulte o comando CREATE VIEW.
