# Execução de programas

Estes comandos e funções permitem controlar como os programas Microsoft Visual FoxPro são executados, suspensos e encerrados.

| Use | Para |
| --- | --- |
| Comando BUILD APP | Criar um arquivo de aplicativo padrão (.app) a partir de um projeto Visual FoxPro. |
| Comando BUILD DLL | Criar uma biblioteca de vínculo dinâmico do Windows (.dll) de thread único, ou servidor Automation, usando definições de classe de um projeto Visual FoxPro. |
| Comando BUILD EXE | Criar um arquivo executável (.exe) a partir de um projeto Visual FoxPro. |
| Comando BUILD PROJECT | Criar um arquivo de tabela de projeto Visual FoxPro (.pjx) abrindo, processando e incluindo um ou mais arquivos de programa, menu, relatório, etiqueta, formulário ou biblioteca especificados no projeto. |
| Comando CANCEL | Encerrar a execução do arquivo de programa Visual FoxPro atual. |
| Comandos CLEAR | Liberar o item ou itens especificados da memória. |
| Comandos CLOSE | Fechar vários tipos de arquivo. |
| Comando COMPILE | Compilar um ou mais arquivos de origem especificados e criar um arquivo de objeto para cada arquivo de origem. |
| Comando CREATE PROJECT | Abrir o Project Manager para que você possa criar um projeto. |
| Diretiva de pré-processador #DEFINE ... #UNDEF | Criar e liberar constantes em tempo de compilação. |
| Comando DO | Executar um programa ou procedimento Visual FoxPro. |
| Comando DO FORM | Executar um formulário ou conjunto de formulários compilado criado com o Form designer. |
| Função EXECSCRIPT( ) | Permite executar várias linhas de código de variáveis, tabelas e outro texto em tempo de execução. |
| Comando FUNCTION | Criar uma função definida pelo usuário em um arquivo de programa. Existem duas versões da sintaxe. |
| Diretiva de pré-processador #IF ... #ENDIF | Incluir condicionalmente código-fonte em tempo de compilação. |
| Diretiva de pré-processador #INCLUDE | Instruir o pré-processador do Visual FoxPro a tratar o conteúdo de um arquivo de cabeçalho especificado como se aparecesse em um programa Visual FoxPro. |
| Variável de sistema _INCLUDE | Especificar um arquivo de cabeçalho padrão incluído com classes, formulários ou conjuntos de formulários definidos pelo usuário. |
| Comando LPARAMETERS | Atribuir dados passados de um programa chamador a variáveis ou matrizes locais. |
| Função MESSAGEBOX( ) | Exibir uma caixa de diálogo definida pelo usuário. |
| Comando MODIFY PROJECT | Abrir o Project Manager para que você possa modificar ou criar um arquivo de projeto. |
| Comando PARAMETERS | Atribuir dados de um programa chamador a variáveis ou matrizes privadas. |
| Função PARAMETERS( ) | Retornar o número de parâmetros passados ao programa, procedimento ou função definida pelo usuário chamado mais recentemente. |
| Comando PROCEDURE | Criar um procedimento definido pelo usuário em um arquivo de programa. Existem duas versões da sintaxe. |
| Comando RELEASE PROCEDURE | Fechar arquivos de procedimento abertos com SET PROCEDURE. |
| Comando RESUME | Continuar a execução de um programa suspenso. |
| Comando RETURN | Retornar o controle do programa a um programa chamador. |
| Comando RUN | ! | Executar comandos ou programas externos do sistema operacional. |
| Comando SET ESCAPE | Determinar se pressionar a tecla ESC interrompe a execução de programa e comando. |
| Comando SET LIBRARY | Abrir um arquivo de biblioteca de API (interface de programação de aplicativos) externa. |
| Comando SET LOGERRORS | Determinar se enviar mensagens de erro de compilação do Visual FoxPro para um arquivo de texto. |
| Comando SET PROCEDURE | Abrir um arquivo de procedimento. |
| Comando SET SYSMENU | Habilitar ou desabilitar a barra de menu do sistema Visual FoxPro durante a execução do programa, e permite reconfigurá-la. |
| Comando SET UDFPARMS | Especificar se o Visual FoxPro passa variáveis por valor ou por referência a parâmetros em procedimentos e funções definidas pelo usuário (UDFs). |
| Comando SUSPEND | Pausar a execução do programa e retornar ao Visual FoxPro interativo. |
| SYS(2015) - Nome de procedimento exclusivo | Retornar um nome de procedimento exclusivo de 10 caracteres que começa com sublinhado seguido de uma combinação de letras e números. |
| Comando WAIT | Exibir uma mensagem e pausar a execução do Visual FoxPro até que o usuário pressione uma tecla ou clique no mouse. |
