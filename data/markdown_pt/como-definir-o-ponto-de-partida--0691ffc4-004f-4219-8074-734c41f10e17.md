# Como: definir o ponto de partida

Todos os aplicativos devem ter um arquivo principal, que é um arquivo que define o ponto de partida do aplicativo, executa as principais tarefas do aplicativo e conecta seus componentes.

> **Observação:** Você pode definir apenas um arquivo de um projeto como arquivo principal.

Quando você usa o Application Wizard para criar o projeto do aplicativo, o assistente cria automaticamente um arquivo de programa principal. Entretanto, você pode modificar o arquivo principal criado pelo assistente ou designar outro arquivo do projeto como arquivo principal.

O Application Wizard também cria um objeto de aplicativo que pode ser usado para manipular o aplicativo. O programa principal criado pelo Application Wizard inclui seções para instanciar e configurar o objeto de aplicativo.

### Para definir um arquivo principal para um aplicativo
- Abra o projeto do aplicativo.
- No Project Manager, expanda os nós que contêm o arquivo desejado.
- Clique no arquivo para selecioná-lo.
- No menu Project, clique em Set Main.

O nome do arquivo principal aparece em negrito no Project Manager.

> **Observação:** O arquivo definido como principal é incluído automaticamente no processo de compilação e é marcado como somente leitura quando o aplicativo é compilado.
