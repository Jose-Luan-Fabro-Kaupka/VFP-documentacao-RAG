# Propriedade VersionComments

Os comentários de um projeto.

```foxpro
Object.VersionComments[ = cComments]
```

# Valor de retorno
 **cComments**
Especifica os comentários de um projeto. O valor padrão é a cadeia de caracteres vazia.

# Observações

Aplica-se a: objeto Project (Visual FoxPro)

A propriedade VersionComments corresponde ao valor do item Comments na caixa de diálogo EXE Version Dialog Box.
