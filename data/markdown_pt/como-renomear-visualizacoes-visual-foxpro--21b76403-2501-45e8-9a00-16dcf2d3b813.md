# Como: renomear visualizações (Visual FoxPro)

Você pode renomear visualizações.

### Para renomear uma visualização
- Abra o projeto da aplicação que contém a visualização no Gerenciador de Projetos.
- No Gerenciador de Projetos, clique na visualização.
- No menu Projeto, clique em Renomear arquivo.
- Na caixa de diálogo Renomear arquivo, digite o novo nome da visualização.
- Quando terminar, clique em OK .

Para obter mais informações, consulte Como editar arquivos em projetos.

### Para renomear uma visualização programaticamente
- Abra o banco de dados que contém a visualização.
- Utilize o comando RENAME VIEW.

Para obter mais informações, consulte Como: Abrir bancos de dados e comando RENAME VIEW.
