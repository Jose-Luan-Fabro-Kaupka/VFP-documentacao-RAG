# Trabalhando com faixas de relatório

Você pode especificar onde, quando e como os dados e as informações são exibidos em relatórios e etiquetas adicionando às faixas itens que controlam sua aparência e executam operações definidas pelo usuário.

# Nesta seção
 **Faixas de relatório**
Descreve e compara diferentes tipos de faixas.
**Como: adicionar faixas a relatórios**
Explica como adicionar faixas ao layout de um relatório.
**Como: alterar a altura da faixa de relatório**
Descreve como alterar a altura de uma faixa no layout.
**Como: alterar a ordem das faixas de detalhes**
Descreve como usar o Construtor de Relatórios para alterar a ordem de várias faixas de detalhes.
**Como: especificar aliases de destino para faixas de detalhes**
Descreve como variar a ordem dos registros processados em uma execução especificando aliases de destino para uma ou mais faixas de detalhes.
**Como: especificar expressões a serem avaliadas durante o processamento de faixas**
Explica como criar expressões disparadas antes e depois de o mecanismo de relatório processar uma faixa.
**Como: adicionar comentários a faixas de relatório**
Descreve como adicionar comentários para indicar seus objetivos de design e outras observações relevantes ao uso de uma faixa específica.
**Como: adicionar dados do usuário a faixas de relatório**
Descreve como adicionar dados definidos pelo usuário aos atributos armazenados no layout e relacionados a uma faixa específica.
**Como: configurar a saída de faixas de relatório**
Explica como ajustar faixas para considerar dados longos ou ausentes e como configurar faixas opcionais.
**Como: excluir faixas de relatórios**
Explica como remover faixas opcionais de um layout.
