# Os campos de visualização foram alterados. As propriedades dos campos Atualização e Chave foram redefinidas para os valores padrão (Erro 1568)

Você tentou modificar uma visualização cuja estrutura da tabela foi alterada. Quando você escolhe OK, os Designers de consulta e exibição exibem as condições de visualização anteriores, mas a guia Critérios de atualização, guia Designer de exibição, é redefinida para as condições padrão. Não houve nenhuma atualização.
