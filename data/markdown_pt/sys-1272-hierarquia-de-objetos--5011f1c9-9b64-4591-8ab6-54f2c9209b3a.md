# SYS(1272) - Hierarquia de objetos

Retorna a hierarquia de objetos para um objeto especificado. Não disponível em tempo de design.

```foxpro
SYS(1272, oObjectName)
```

#### Parâmetros
 **oObjectName**
Especifica o nome do objeto para o qual a hierarquia é retornada.

# Valor de retorno

Character
