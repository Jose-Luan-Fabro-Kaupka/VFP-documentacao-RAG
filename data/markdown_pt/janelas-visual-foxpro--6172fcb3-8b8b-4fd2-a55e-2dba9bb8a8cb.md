# Janelas (Visual FoxPro)

Explica as funções e as opções que aparecem em várias janelas do Visual FoxPro.

# Nesta seção
 **Janela Accessibility Browser**
Permite explorar vários elementos da interface do usuário de um aplicativo por meio de sua interface Iaccessible.
**Janela Automated Test Harness**
Permite gravar e reproduzir eventos de mouse e teclado em seus aplicativos.
**Janela Browse**
Exibe os registros na tabela ativa.
**Janela Call Stack (Visual FoxPro)**
Permite exibir procedimentos, programas e métodos que estão sendo executados. Enquanto um programa está em execução, ele é listado na janela Call Stack.
**Janela Class Browser**
Exibe as classes em uma biblioteca de classes ou um formulário e as informações da biblioteca de tipos em um arquivo .tlb, .olb ou .exe.
**Janela Code References**
Permite selecionar e substituir referências de código ou texto após realizar uma pesquisa usando a caixa de diálogo Look Up Reference.
**Janela Code**
Use a janela Code para escrever, exibir e editar código de formulário, evento e método.
**Janela Command (Visual FoxPro)**
Exibe comandos da linguagem Visual FoxPro quando você escolhe comandos de menu. A janela Command é uma janela do sistema do Microsoft Visual FoxPro.
**Janela Component Gallery**
Exibe, como ícones de atalho, componentes disponíveis para seus projetos, aplicativos, designers, assistentes e construtores do Microsoft Visual FoxPro, o que permite gerenciar, de várias formas, qualquer arquivo disponível para seu sistema.
**Janela Coverage Profiler**
Contém um grupo de botões de ferramenta Coverage Profiler e opções que permitem especificar como exibir as informações retornadas pelo Coverage Engine.
**Janela Data Session**
Permite abrir e exibir tabelas ou exibições, estabelecer relações temporárias e definir propriedades de área de trabalho.
**Janela Debug Output**
Permite exibir saída de programas, procedimentos ou código de método ativos.
**Janela Debugger**
Contém os menus do Debugger, a barra de ferramentas Debugger e várias janelas de depuração.
**Janela Document View**
Permite visualizar e navegar para qualquer procedimento, função ou definição #DEFINE ou diretiva de pré-processador em seu programa.
**Janela Editing**
Fornece edição de arquivos de texto e programa.
**Janela General Field**
Permite criar ou inserir objetos OLE.
**Janela Go To Definition**
Permite escolher entre várias definições de código resultantes do uso de View Definition para visualizar definições de elementos de código em seu programa.
**Janela Locals (Visual FoxPro)**
Permite exibir todas as variáveis, matrizes, objetos e membros de objeto visíveis em um determinado programa, procedimento ou método.
**Janela Object Browser**
Exibe as classes, propriedades, métodos, eventos e constantes disponíveis para bibliotecas de objetos COM.
**Janela Project Manager**
Permite organizar e gerenciar seus arquivos em projetos.
**Janela Properties (Visual FoxPro)**
Contém a lista de propriedades, eventos e métodos de um formulário, ambiente de dados, cursor, relação ou controle selecionado.
**Janela Task List Manager**
Descreve informações importantes sobre tarefas por meio do uso de indicações visuais, como texto de cores diferentes e ícones.
**Janela Trace**
Permite ver suas linhas de código enquanto estão sendo executadas.
**Janela Visual FoxPro IntelliSense Manager**
Permite especificar a aparência e o comportamento das instruções de sintaxe e outras informações de dica de ferramenta exibidas nas janelas de propriedades, editor e código.
**Janelas do sistema Visual FoxPro**
Fornecidas pelo Visual FoxPro como parte da interface do produto.
**Janela Watch (Visual FoxPro)**
Permite exibir expressões e seus valores atuais e definir pontos de interrupção em uma expressão.
