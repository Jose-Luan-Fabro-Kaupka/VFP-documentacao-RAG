# Janela Automated Test Harness

A janela Automated Test Harness do Visual FoxPro permite gravar e reproduzir eventos de Mouse e Keyboard em suas aplicações Visual FoxPro.
 **Guia Scripts**
Esta guia permite visualizar e trabalhar com scripts existentes que foram gravados anteriormente com o Test Harness. Você pode editar qualquer script destacando-o na grade e clicando no botão Editar o script de teste da barra de ferramentas ou selecionando o item de menu Edit Script. Um ou mais scripts podem ser reproduzidos de uma vez. Marque as caixas de seleção ao lado dos scripts que deseja reproduzir e clique no botão Reproduzir o script da barra de ferramentas ou selecione o item de menu Play. As seguintes opções estão disponíveis nesta guia: Grade Scripts Exibe todos os scripts gravados. As informações de um script são exibidas em uma linha, incluindo pré e pós-scripts que são executados antes e depois do script principal. O script principal usa o log de eventos. Os itens marcados na primeira coluna são usados ao excluir ou reproduzir scripts. A função Editar script se aplica apenas à linha atual destacada na grade. Botão Delete Exclui os scripts selecionados (primeira coluna marcada) na grade.
**Guia Options**
Esta guia tem configurações opcionais que você pode selecionar para gravação e reprodução. As seguintes opções estão disponíveis nesta guia: Overwrite the existing script Se marcada, um script existente com o mesmo nome será automaticamente substituído sem solicitar confirmação durante a gravação. Always launch new VFP Window Se marcada, a gravação sempre começará com uma nova instância do Visual FoxPro. Validate startup window before playback Se marcada, a janela de inicialização é validada em relação à janela gravada. Se não corresponder, será exibido um prompt de erro. O teste falhará se uma janela inesperada aparecer ou ocorrer um erro. Check for presence of each object Se marcada, o objeto associado a cada evento será verificado antes da reprodução. Por exemplo, se o evento keypress foi gravado em uma textbox, a presença do mesmo nome de objeto é verificada antes de reproduzir o evento. Um erro será exibido se o objeto não existir. Check for program error Esta opção é usada para relatar um erro na aplicação de teste. Se marcada e houver um erro durante a reprodução, o erro será registrado no log de teste. Os resultados do teste podem ser visualizados na guia Test Log. Run count Especifica o número de vezes que cada script selecionado na guia Scripts é executado durante a reprodução. Delay between events Permite especificar um atraso específico (milissegundos) entre eventos durante a reprodução. On script failure Fornece opções de tratamento de erros se ocorrer um problema durante a reprodução do script. Você pode abortar o script inteiro, ignorar apenas o evento que falhou ou continuar reproduzindo o script após tentar novamente o evento que falhou.
**Test Log**
Esta guia contém detalhes sobre os resultados das execuções de teste (reproduções). As seguintes opções estão disponíveis nesta guia: Grade Test Log Exibe informações úteis sobre scripts reproduzidos recentemente. O uso de memória é a diferença na memória antes e depois da execução do teste. Botão Delete Exclui o log de teste selecionado.
**Coverage Log**
Você pode definir o registro de cobertura usando as configurações na guia Coverage Log. Durante a reprodução, ele ativará o registro de cobertura e salvará o log no arquivo especificado. Turn on coverage logging during playback Se marcada, cria um log de cobertura durante a reprodução de um script. Overwrite the log if file exists Se marcada, substitui automaticamente o log se ele já existir sem confirmação. Botão View Log Exibe um log de cobertura para o teste, se existir. Botão Coverage Profiler Invoca o Coverage Profiler, que carregará o log de cobertura se existir; caso contrário, solicitará um log.
