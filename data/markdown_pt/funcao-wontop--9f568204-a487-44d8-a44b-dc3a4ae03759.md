# Função WONTOP( )

Determina se a janela ativa ou especificada está na frente de todas as outras janelas.

```foxpro
WONTOP([WindowName])
```

#### Parâmetros
 **WindowName**
Especifica o nome da janela que WONTOP( ) avalia. Você pode especificar o nome de uma janela definida pelo usuário criada com DEFINE WINDOW ou uma janela do sistema (a janela Command, a janela Data Session, uma janela Browse e assim por diante). Se você omitir WindowName , WONTOP( ) retorna o nome da janela "da frente" ou ativa. Você também pode incluir a cadeia de caracteres vazia em WindowName para especificar a janela principal do Visual FoxPro. Se a janela Debug, Trace ou Command estiver ativa e você não especificar um nome de janela, WONTOP( ) retorna o nome da janela que estava na frente mais recentemente. Quando você está depurando um programa que usa WONTOP( ), a execução do programa não é afetada ao trazer essas janelas para a frente.

# Valor de retorno

Caractere ou Lógico

# Observações

WONTOP( ) retorna true (.T.) se a janela especificada estiver ativa. Retorna false (.F.) se a janela não estiver ativa ou não existir.

Historicamente, em versões anteriores do Visual FoxPro, a janela Data Session sempre foi referida como a janela View. Além disso, a linguagem usada para controlar essa janela, como HIDE WINDOW, ACTIVATE WINDOW, WONTOP( ), também se refere a essa janela como a janela View. O Visual FoxPro continua a se referir à janela View para a função WONTOP( ).

# Exemplo

O exemplo a seguir usa WONTOP( ) para exibir o nome da janela ativa. Antes de executar este programa, abra algumas janelas (janelas Browse, a janela Data Session e assim por diante) e, em seguida, execute o exemplo.

```foxpro
IF NOT EMPTY(WONTOP())
   WAIT WINDOW 'Frontmost window: ' + WONTOP()
ELSE
   WAIT WINDOW 'No windows are open'
ENDIF
```
