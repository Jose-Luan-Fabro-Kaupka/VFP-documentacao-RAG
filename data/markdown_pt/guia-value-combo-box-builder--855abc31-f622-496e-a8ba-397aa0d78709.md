# Guia Value, Combo Box Builder

Esta guia no Combo Box builder especifica de onde obter valores de retorno e onde armazená-los.
 **Return the Value From**
Especifica a coluna cujo valor é armazenado em um campo de tabela quando o usuário seleciona um item do combo box. Esta opção corresponde à propriedade BoundColumn.
**Field Name**
Especifica um campo de tabela ou exibição no qual armazenar o valor especificado na caixa Return the Value From. Por padrão, a lista inclui campos de tabelas no data environment. Escolha o botão de diálogo para exibir a caixa de diálogo Open para que você possa selecionar outra tabela. Esta opção corresponde à propriedade ControlSource. Por exemplo, se você preencher o combo box com uma lista de 50 estados, quando o usuário escolher um estado, você pode gravá-lo no campo STATE de uma tabela de endereços.
