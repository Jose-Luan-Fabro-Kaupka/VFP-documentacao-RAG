# Classe base Distinct Values Combo

Esta classe realiza uma pesquisa de valores exclusivos no campo ControlSource para preencher um combobox.

| Categoria | Data Query |
| --- | --- |
| Catálogo padrão | Visual FoxPro Catalog\Foundation Classes\Data Query |
| Classe | _cbodistinctvalues |
| Classe base | ComboBox |
| Biblioteca de classes | _dataquery.vcx |
| Classe pai | _combobox |
| Exemplo | ...\Samples\Solution\Ffc\datalook2.scx |

# Observações

Para usar, solte a classe em um projeto ou formulário ou, no menu de atalho do item da Component Gallery, selecione Add to Form. Quando você solta a classe em um formulário, o Visual FoxPro coloca um combobox no formulário. Você precisa especificar um valor apropriado para a propriedade ControlSource. Quando você solta a classe em um projeto, pode escolher entre adicionar a classe ou criar uma subclasse.
