# Botão Table, Caixa de diálogo Destino da consulta

Salva os resultados da sua consulta como um arquivo de tabela (.dbf) com o nome que você atribuir a ele. Este comando está disponível somente para consultas.
 **Nome da tabela**
Especifica o nome da tabela. Você pode digitar o nome na caixa de texto ou usar o botão de diálogo para selecionar uma tabela existente que deseja substituir.
