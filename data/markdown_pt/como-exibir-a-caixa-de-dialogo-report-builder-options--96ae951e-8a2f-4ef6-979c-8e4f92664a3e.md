# Como: exibir a caixa de diálogo Report Builder Options

O aplicativo report builder, reportbuilder.app, apresenta uma caixa de diálogo Options onde várias configurações podem ser ajustadas.

> **Importante:** Diferentemente das configurações na Visual FoxPro Options Dialog Box (Visual FoxPro) , ajustes nas configurações do report builder nesta caixa de diálogo não persistem entre sessões do Visual FoxPro.

> **Dica:** Você pode remover o acesso a esta caixa de diálogo para usuários finais que modificam relatórios, emitindo o comando MODIFY REPORT | LABEL com a palavra-chave PROTECTED em seu aplicativo.

### Para abrir a caixa de diálogo Builder Options a partir do Report or Label Designer
- Clique com o botão direito do mouse no plano de fundo do layout do relatório e selecione Properties… no menu de contexto. - OU - Abra a caixa de diálogo Properties de qualquer controle de relatório ou banda de relatório.
- Clique com o botão direito do mouse na superfície da caixa de diálogo para exibir o menu de contexto da caixa de diálogo.
- Selecione Options… A caixa de diálogo Builder Options aparece.

### Para abrir a caixa de diálogo Builder Options a partir da janela Command
- DO (_REPORTBUILDER)
