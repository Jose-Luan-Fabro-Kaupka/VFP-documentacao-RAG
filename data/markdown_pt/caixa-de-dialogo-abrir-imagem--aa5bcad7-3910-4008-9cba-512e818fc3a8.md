# Caixa de diálogo Abrir imagem

Use para abrir um arquivo gráfico existente.

A função GETPICT( ) corresponde à caixa de diálogo Abrir imagem. Por exemplo, esta caixa de diálogo aparece quando você digita `? GETPICT( )` na Command window.
 **Look in**
Exibe uma lista suspensa de locais onde você pode procurar seu arquivo. Nos sistemas operacionais Windows 2000 e Windows XP, a barra Places no lado esquerdo da caixa de diálogo exibe locais comuns, como My Documents e Desktop. Clique em um desses ícones para fazer o local correspondente aparecer na lista suspensa.
**File name**
Exibe o nome do arquivo atualmente selecionado ou permite especificar o arquivo que você deseja abrir.
**Files of type**
Exibe uma lista de tipos de arquivo. Você pode selecionar um tipo de arquivo na lista suspensa para exibir arquivos de um tipo específico. As seguintes extensões não são mais usadas nesta versão do Visual FoxPro: .lbl, .fpc, .cat e .frm.
**Picture**
Exibe uma visualização do arquivo gráfico selecionado quando a caixa de seleção Preview está selecionada. Observação Picture aparece apenas ao executar o Visual FoxPro em sistemas operacionais anteriores ao Windows 2000. Caso contrário, a caixa de diálogo Abrir imagem mostra uma miniatura (menor) do arquivo gráfico. Clique duas vezes na miniatura para visualizar uma versão maior do arquivo.
**Preview**
Permite visualizar o arquivo gráfico selecionado. Observação A caixa de seleção Preview aparece apenas ao executar o Visual FoxPro em sistemas operacionais anteriores ao Windows 2000. Você pode visualizar imagens no Windows 2000 e posterior clicando no ícone View Menu perto do topo da caixa de diálogo e depois em Thumbnails.
