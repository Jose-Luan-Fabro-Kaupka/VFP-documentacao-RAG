# Método Drag

Inicia, encerra ou cancela uma operação de arrastar.

```foxpro
Control.Drag [(nAction)]
```

#### Parâmetros
 **nAction**
Indica a ação a executar. Se você omitir nAction , nAction é definido como 1. As configurações do método Drag são: Configuração Descrição 0 Cancela a operação de arrastar; restaura a posição original do controle. 1 (Padrão) Inicia o arrastar do controle. 2 Encerra o arrastar — ou seja, solta o controle.

# Observações

Aplica-se a: CheckBox Control | ComboBox Control | CommandButton Control | CommandGroup Control | Container Object | Control Object (Visual FoxPro) | EditBox Control | Grid Control | Image Control (Visual FoxPro) | Label Control (Visual FoxPro) | Line Control | ListBox Control | OLE Bound Control | OLE Container Control | OptionButton Control | OptionGroup Control | Page Object | PageFrame Control | Shape Control | Spinner Control | TextBox Control (Visual FoxPro)

Geralmente, o procedimento do evento MouseDown chama o método Drag para iniciar a operação de arrastar.

É necessário usar o método Drag para controlar o arrastar apenas quando a propriedade DragMode do controle está definida como 0 (Manual). Você pode usar Drag em um controle cuja propriedade DragMode está definida como 1 (Automatic), mas os eventos MouseDown e MouseUp não são disparados.

Se você deseja que o ponteiro do mouse altere enquanto o controle está sendo arrastado, use a propriedade DragIcon ou a propriedade MousePointer para definir o ponteiro. A propriedade MousePointer só tem efeito se a propriedade DragIcon não estiver definida.
