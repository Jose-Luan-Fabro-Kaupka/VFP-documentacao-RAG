# Como: incluir arquivos com aplicações para distribuição

Você pode reproduzir e distribuir livremente alguns arquivos, gráficos e programas do Visual FoxPro com as aplicações que cria; no entanto, deve remover arquivos restritos da sua aplicação. Para obter mais informações, consulte Distributable and Restricted Visual FoxPro Features and Files.

Antes de compilar sua aplicação, certifique-se de que seu projeto inclui os arquivos necessários para sua aplicação, bem como quaisquer arquivos de recursos adicionais, como arquivos gráficos ou modelos.

### Para adicionar arquivos à sua aplicação
- Inclua os arquivos no seu projeto. Se não deseja alterar esses arquivos na aplicação distribuída, coloque os arquivos no seu projeto e marque-os como incluídos. Os arquivos ficam somente leitura e não podem ser modificados. -ou-
- Adicione os arquivos ao diretório da sua aplicação para torná-los facilmente acessíveis ao programa de criação de instalação. Se deseja modificá-los, coloque os arquivos no seu projeto e marque-os como excluídos. Em seguida, distribua-os com sua aplicação como arquivos separados.

Para obter mais informações sobre como criar um projeto e incluir ou excluir arquivos em um projeto, consulte Compiling an Application.
