# Propriedade TitleBar

Especifica se uma barra de título aparece na parte superior de um formulário.

```foxpro
Object.TitleBar[ = nExpression]
```

# Valor de retorno
 **nExpression**
As configurações da propriedade TitleBar são as seguintes: Configuração Descrição 0 A barra de título não é exibida. 1 (Padrão) A barra de título é exibida.

# Observações

Aplica-se a: Objeto Form

Se a propriedade TitleBar estiver definida como 0, uma barra de título não é exibida e o menu pop-up da janela e os botões Minimize, Maximize e Close não estão disponíveis.
