# Caixa de diálogo Inserir objeto

Esta caixa de diálogo lista os objetos OLE que você pode vincular ou incorporar em seu aplicativo para formulários ou campos General em tabelas do Visual FoxPro.

Em uma janela browse, clique duas vezes em um campo General para abrir uma janela de edição e habilitar o comando Insert Object.

Para um formulário, selecione um controle OLE Container enquanto um formulário é exibido. Isso exibe a caixa de diálogo Insert Object e o novo objeto é armazenado no campo ao qual o controle está vinculado.
 **Criar novo**
Exibe a caixa Tipo de objeto para que você possa escolher um aplicativo OLE no qual criar um novo objeto.
**Tipo de objeto**
Aparece quando você seleciona Criar novo e exibe os aplicativos OLE instalados em seu computador. Selecione um aplicativo no qual criar o objeto.
**Criar a partir de arquivo**
Exibe a caixa Arquivo para que você possa especificar um objeto existente a inserir.
**Arquivo**
Aparece quando você seleciona Criar a partir de arquivo . Digite o nome e o caminho do arquivo do objeto ou clique em Procurar para selecionar o arquivo apropriado.
**Procurar**
Abre a caixa de diálogo Procurar que permite selecionar uma tabela ou exibição.
**Vincular**
Vincula o objeto. Se você não selecionar esta opção, o objeto é incorporado.
**Exibir como ícone**
Exibe o objeto inserido como um ícone. O ícone vem do aplicativo no qual o objeto foi criado.
**Resultados**
Dependendo do botão de opção selecionado, pode exibir uma descrição da ação a ser executada no conteúdo do arquivo após clicar em OK , um Identificador exclusivo e um caminho para a seleção de Controle ou Tipo de objeto. Você pode alterar a descrição exibida escolhendo as opções Criar novo , Criar a partir de arquivo ou Exibir como ícone.
**Alterar ícone**
Exibe a caixa de diálogo Alterar ícone, que permite selecionar um ícone diferente para o objeto OLE. Aparece quando você seleciona a opção Exibir como ícone.
**Inserir controle (somente formulários)**
Exibe a caixa Tipo de controle para que você possa inserir um controle ActiveX.
**Tipo de controle (somente formulários)**
Aparece quando Inserir controle é selecionado e lista os controles ActiveX que você pode inserir.
**Adicionar controle (somente formulários)**
Aparece quando Inserir controle é selecionado e exibe a caixa de diálogo Procurar para que você possa localizar e selecionar um controle ActiveX não listado em Tipo de controle.
