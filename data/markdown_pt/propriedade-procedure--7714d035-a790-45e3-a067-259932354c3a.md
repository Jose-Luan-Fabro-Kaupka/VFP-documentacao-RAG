# Propriedade Procedure

Especifica o nome do procedimento ou método onde ocorre uma exceção. Leitura/gravação em tempo de execução.

```foxpro
Exception.Procedure
```

# Valor de retorno

Tipo de dados Character.

# Observações

Aplica-se a: Classe Exception (Visual FoxPro)

Idêntico ao valor retornado pela função PROGRAM( ).
