# Caixa de diálogo Add Dynamic Style Condition (Report Builder)

Permite nomear uma nova condição de estilo dinâmico e abrir a caixa de diálogo Configure Dynamic Properties para configurar a nova condição.

Você pode abrir esta caixa de diálogo clicando em Add na guia Dynamics da caixa de diálogo Report Control Properties.

Como: formatar dinamicamente controles de relatório
 **Enter condition name**
Digite um valor de cadeia de caracteres (sem aspas) para identificar a condição. Você não pode renomear a condição depois de criá-la. Quando você clica em OK, a caixa de diálogo Configure Dynamic Properties (Report Builder) é aberta.
