# Caixa de diálogo Label (Visual FoxPro)

Exibe os resultados da consulta em uma etiqueta existente. Esta caixa de diálogo aparece na guia Miscellaneous do Query Designer e está disponível apenas para consultas.

> **Observação:** Você deve ter configurado previamente o arquivo de etiqueta (.lbx) para acomodar as colunas de saída na consulta. Para obter mais informações, consulte Working with Reports.
 **Open Label**
Exibe a caixa de diálogo Open para você selecionar um arquivo de etiqueta a ser usado em sua consulta. Você pode clicar no botão ou digitar um nome de arquivo na caixa de texto.
**Wizard Icon**
Exibe o Label Wizard.
**Page Preview**
Exibe a saída na janela Page Preview.
**Console On**
Exibe a saída na janela de saída ativa.

# Saída secundária
 **None**
Especifica que a saída não será enviada para a impressora nem salva como arquivo de texto.
**To Printer**
Envia os resultados da consulta para a impressora.
**To Text File**
Salva os resultados da consulta como arquivo de texto. Clique no botão para selecionar um arquivo existente que deseja sobrescrever ou digite o nome de um novo arquivo na caixa de texto.
