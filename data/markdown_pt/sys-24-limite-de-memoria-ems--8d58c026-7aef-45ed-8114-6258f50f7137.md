# SYS(24) - Limite de memória EMS

Incluído para compatibilidade com versões anteriores.

Retorna o limite de EMS definido no arquivo de configuração do FoxPro.

```foxpro
SYS(24)
```

# Valor de retorno

Valor de retorno - Character

# Observações

SYS(24) retorna 0 se um limite de EMS não foi incluído no arquivo de configuração. SYS(23) sempre retorna 0 na versão Extended de 32 bits do FoxPro para MS-DOS, FoxPro para Windows e FoxPro para Macintosh.

Para informações completas sobre esta configuração, consulte "Customizing FoxPro", no manual FoxPro Installation and Configuration.
