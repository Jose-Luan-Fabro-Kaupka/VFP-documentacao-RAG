# Comando SET MARK TO

Especifica um delimitador para a exibição de expressões de data.

```foxpro
SET MARK TO [cDelimiter]
```

#### Parâmetros
 **cDelimiter**
Especifica o caractere que você deseja usar como delimitador de data.

# Observações

SET MARK TO especifica o caractere que separa o mês, o dia e o ano nas datas exibidas.

Use SET MARK TO sem cDelimiter para redefinir o delimitador para a barra ( / ) padrão.

SET MARK TO tem escopo na sessão de dados atual.
