# Associação de eventos para objetos COM

Você pode associar eventos de objetos Component Object Model (COM) a um objeto Visual FoxPro usando a função EVENTHANDLER( ). Por exemplo, ao associar um evento de um ActiveX Data Object (ADO) recordset, você pode executar código Visual FoxPro quando o ponteiro de registro se move no recordset. A função EVENTHANDLER( ) trata especificamente da associação de eventos gerados por objetos COM e pela interface IConnectionPoint, que faz parte do COM. Para obter mais informações, consulte Função EVENTHANDLER( ).

No entanto, o Visual FoxPro não suporta a geração de eventos diretamente pela interface IConnectionPoint. Para associar um evento COM a um objeto Visual FoxPro, o objeto deve implementar a interface de eventos do objeto COM, uma ação referida como tratamento de eventos fortemente acoplado, onde tanto o objeto de origem do evento quanto os objetos de destino do evento estão ativos quando o evento ocorre. Destinos de eventos são clientes que se associam a um objeto conectável porque recebem eventos acionados pelo objeto conectável.

Em vez disso, COM+ Events, parte dos COM+ Services, fornece a estratégia preferida para tratar eventos entre componentes COM. COM+ Events envia e entrega notificações de eventos entre aplicativos. Aplicativos podem enviar e receber notificações de eventos, como a contratação de um novo funcionário, uma alteração no preço de uma ação ou uma queda no nível de inventário que exige reabastecimento.

No modelo COM+ Events, aplicativos que enviam notificações de eventos atuam como fontes de eventos e são chamados publishers. Aplicativos que recebem notificações de eventos são chamados subscribers. COM+ Events são frequentemente chamados eventos fracamente acoplados porque publishers e subscribers não possuem conhecimento sobre um ao outro e permitem que assinantes de eventos permaneçam inativos até que os eventos ocorram. Em vez disso, você define um conjunto de eventos dentro do escopo de uma classe de eventos, e essa classe de eventos é instalada em um aplicativo COM+.

Para usar COM+ Events, você cria uma classe de eventos que implementa uma ou mais interfaces. Cada interface define um grupo de métodos, que representa um conjunto de eventos. Você escreve componentes subscriber que implementam essas interfaces e respondem a eventos quando ocorrem. Finalmente, você escreve um aplicativo publisher para criar objetos da classe de eventos e chamar vários métodos quando o aplicativo está pronto para disparar eventos. O serviço de eventos trata do processamento do método e da entrega dos eventos a cada subscriber.
