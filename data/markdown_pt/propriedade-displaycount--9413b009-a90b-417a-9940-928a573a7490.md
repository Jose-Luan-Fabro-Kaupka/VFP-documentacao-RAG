# Propriedade DisplayCount

Especifica o número máximo de itens exibidos na porção de lista de um controle ComboBox.

```foxpro
Object.DisplayCount[ = nExpression]
```

# Valor de retorno
 **nExpression**
Especifica o número máximo de itens exibidos na porção de lista de um controle ComboBox. O valor padrão é zero; se nExpression for zero, um máximo de 7 itens são exibidos na lista. As setas de rolagem não são exibidas na porção de lista de um controle ComboBox se nExpression for um.

# Observações

Aplica-se a: ComboBox Control
