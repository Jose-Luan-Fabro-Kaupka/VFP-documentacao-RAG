# Como: importar dados com o Import Wizard

O Import Wizard ajuda você a criar uma nova tabela a partir do arquivo de origem. O assistente faz uma série de perguntas, importa o arquivo com base nas suas respostas e permite controlar como a nova tabela é estruturada.

### Para importar um arquivo com o Import Wizard
- No menu File, escolha Import .
- Na caixa de diálogo Import, escolha Import Wizard .
- Siga as instruções nas telas do assistente.
