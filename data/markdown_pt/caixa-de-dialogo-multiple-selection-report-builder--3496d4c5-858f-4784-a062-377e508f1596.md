# Caixa de diálogo Multiple Selection (Report Builder)

Permite definir propriedades em vários controles selecionados ao mesmo tempo no layout de relatório. A caixa de diálogo Multiple Selection aparece quando você seleciona mais de um controle no layout de relatório e clica duas vezes em um dos controles selecionados. (Alternativamente, você pode clicar com o botão direito em um dos controles para exibir o menu de contexto e selecionar Properties.)

Consulte Como: selecionar vários controles de relatório para obter mais informações.

> **Observação:** Esta caixa de diálogo é exibida apenas se a variável de sistema _REPORTBUILDER estiver definida para o aplicativo Report Builder padrão. Se estiver vazia ou foi definida para um report builder de terceiros, a caixa de diálogo de propriedades nativa do Visual FoxPro para o controle em que você clicou duas vezes pode aparecer. Para obter mais informações, consulte Variável de sistema _REPORTBUILDER.

# Guias

A tabela a seguir descreve as guias que aparecem na caixa de diálogo Multiple Selection:

| Guia | Opções disponíveis |
| --- | --- |
| Guia Selection, caixa de diálogo Multiple Selection (Report Builder) | Permite revisar os controles selecionados; classificar por tipo de controle ou localização; e remover controles da lista se decidir que não devem mais ser incluídos na seleção. |
| Guia Properties, caixa de diálogo Multiple Selection (Report Builder) | Permite definir opções de proteção ou uma expressão de impressão condicional para os controles atualmente selecionados. |
