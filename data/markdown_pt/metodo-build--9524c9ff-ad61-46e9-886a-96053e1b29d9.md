# Método Build

Reconstrói um projeto ou cria um arquivo de aplicativo (.app), executável (.exe) ou biblioteca de vínculo dinâmico (.dll) a partir de um projeto Visual FoxPro.

```foxpro
Object.Build([cOutputName] [, nBuildAction] [, lRebuildAll]
[, lShowErrors] [, lBuildNewGUIDs])
```

#### Parâmetros
 **cOutputName**
Especifica o nome do arquivo .app, .exe ou .dll a criar. Se cOutputName incluir uma extensão de arquivo e nBuildAction for omitido, a extensão em cOutputName determina o tipo de arquivo compilado. Por exemplo, se a extensão em cOutputName for ".exe", um arquivo executável é criado.
**nBuildAction**
Especifica que deve reconstruir um projeto ou gerar um arquivo .app, .exe ou .dll. Se nBuildAction for especificado e cOutPutName não incluir uma extensão, a extensão apropriada é adicionada . A tabela a seguir lista os valores de nBuildAction . nBuildAction FoxPro.h constant Descrição 1 BUILDACTION_REBUILD Reconstrói o projeto. (Padrão) 2 BUILDACTION_BUILDAPP Cria um arquivo .app. 3 BUILDACTION_BUILDEXE Cria um arquivo .exe. 4 BUILDACTION_BUILDDLL Cria um arquivo .dll. 5 BUILDACTION_BUILDMTDLL Cria um arquivo .dll multithread.
**lRebuildAll**
Especifica se deve recompilar arquivos no projeto antes de criar um arquivo .app, .exe ou .dll. Se lRebuildAll for True (.T.), os seguintes arquivos são recompilados: Arquivos de programa. Arquivos de formato. Código-fonte em formulários, etiquetas, relatórios e bibliotecas de classes visuais. Stored procedures em bancos de dados. Se lRebuildAll for False (.F.) ou for omitido, os arquivos no projeto não são recompilados antes de criar o arquivo .app, .exe ou .dll.
**lShowErrors**
Especifica se deve exibir erros de compilação em uma janela de edição após a conclusão da compilação. A tabela a seguir descreve os valores de lShowErrors . lShowErrors Descrição True (.T.) Exibe erros em uma janela de edição para um arquivo de erro (.err). False (.F.) ou omitido Não exibe erros.
**lBuildNewGUIDs**
Especifica se deve gerar novos identificadores globalmente exclusivos (GUIDs) de registro ao criar um arquivo .exe ou .dll. Observação Se nBuildAction for menor que 3, o Visual FoxPro ignora lBuildNewGUIDs . A tabela a seguir descreve os valores de lBuildNewGUIDs . lShowErrors Descrição True (.T.) Gera novos GUIDs. False (.F.) ou omitido Não gera novos GUIDs.

# Valor de retorno

Lógico. Build retorna True (.T.) se o projeto for reconstruído com sucesso ou um arquivo .app, .exe ou .dll for criado com sucesso sem erros; caso contrário, Build retorna False (.F.).
