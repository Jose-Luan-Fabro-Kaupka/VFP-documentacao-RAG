# Guia Itens da grade, Construtor de grade

Esta guia no Construtor de grade especifica os campos a serem exibidos na grade.

> **Observação:** No Construtor de grade, você pode selecionar campos de apenas uma tabela. Para definir uma relação entre Grids, você deve usar o Construtor de grade em cada Grid separadamente e, em seguida, usar a guia Relação de um Construtor de grade para estabelecer a relação.

Bancos de dados e tabelas Lista os bancos de dados disponíveis e oferece a opção de selecionar tabelas livres. Para localizar um banco de dados ou tabela, clique no botão de diálogo, que exibe a caixa de diálogo Abrir.
 **Lista de tabelas**
Exibe tabelas e views no banco de dados selecionado ou tabelas livres.
**Campos disponíveis**
Mostra todos os campos na tabela selecionada. Você pode selecionar campos de apenas uma tabela.
**Botões de seta**
Adicionam campos e removem campos da lista Campos selecionados.
**Campos selecionados**
Exibe os campos que aparecerão na grade. Cada campo é exibido em uma coluna na grade.
