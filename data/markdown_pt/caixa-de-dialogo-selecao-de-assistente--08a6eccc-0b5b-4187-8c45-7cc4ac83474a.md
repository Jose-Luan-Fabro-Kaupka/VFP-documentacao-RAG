# Caixa de diálogo Seleção de Assistente

Exibe uma lista de assistentes disponíveis para escolha. Essa caixa de diálogo é exibida quando você escolhe Wizards no menu Tools e, em seguida, Query, Form, Report ou All no submenu.
 **Select the wizard you would like to use**
Exibe todos os assistentes do Visual FoxPro disponíveis para um item específico. Por exemplo, o Visual FoxPro tem três assistentes de relatório diferentes.
**Description**
Fornece uma breve descrição do assistente atualmente selecionado.
