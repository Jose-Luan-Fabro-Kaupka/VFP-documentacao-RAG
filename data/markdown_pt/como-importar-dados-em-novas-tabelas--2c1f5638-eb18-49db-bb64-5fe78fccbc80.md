# Como: importar dados em novas tabelas

Você pode importar dados de uma tabela ou formato de planilha usando a estrutura do arquivo de origem para definir a nova tabela.

### Para importar dados para uma nova tabela
- No menu Arquivo, escolha Importar .
- Na caixa Tipo, insira o formato do arquivo que deseja importar.
- Na caixa De, insira o nome do arquivo de origem.
- Se você selecionou uma planilha na caixa Tipo, insira o número da planilha na caixa Planilha que aparece.
- Escolha OK . O Visual FoxPro cria uma nova tabela usando o arquivo de origem.

Se desejar importar para uma nova tabela a partir de um arquivo de texto sem usar o Assistente de importação, você precisa criar uma nova tabela com campos que correspondam à ordem, ao tipo de dados e à largura dos campos no arquivo de texto e depois anexar o texto à nova tabela.

Após importar o arquivo, você pode adicionar a nova tabela ao banco de dados de sua escolha. Você também pode modificar a nova tabela usando o Designer de tabelas.
