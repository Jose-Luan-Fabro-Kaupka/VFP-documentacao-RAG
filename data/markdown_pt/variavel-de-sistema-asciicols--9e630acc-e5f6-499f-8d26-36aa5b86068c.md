# Variável de sistema _ASCIICOLS

Especifica o número de colunas em um arquivo de texto ASCII criado com a palavra-chave ASCII no comando REPORT FORM.

```foxpro
_ASCIICOLS = nExpression
```

#### Parâmetros
 **nExpression**
Especifica o número de colunas no arquivo de texto a criar. O valor padrão é 80.
