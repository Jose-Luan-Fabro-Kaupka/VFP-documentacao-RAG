# Função DROPOFFLINE( )

Descarta todas as alterações feitas em uma view offline e coloca a view offline novamente online.

```foxpro
DROPOFFLINE(cViewName)
```

#### Parâmetros
 **cViewName**
Especifica o nome da view offline a ser colocada novamente online.

# Valor de retorno

Logical

# Observações

DROPOFFLINE( ) retorna um valor lógico verdadeiro (.T.) se a view offline for colocada novamente online com sucesso; caso contrário, retorna falso (.F.).
