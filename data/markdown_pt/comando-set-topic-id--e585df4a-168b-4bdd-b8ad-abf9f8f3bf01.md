# Comando SET TOPIC ID

Especifica o tópico da Ajuda a ser exibido quando você invoca o sistema de Ajuda do Visual FoxPro. O tópico da Ajuda é baseado no ID de contexto do tópico.

```foxpro
SET TOPIC ID TO nHelpContextID
```

#### Parâmetros
 **nHelpContextID**
Especifica o tópico da Ajuda a ser exibido, com base em um ID de contexto numérico. nHelpContextID é um número de contexto na seção MAP do arquivo de projeto da Ajuda.
