# Como: salvar um formulário como HTML

Você pode usar a opção Save As HTML no menu File ao criar um formulário para salvar o conteúdo de um formulário como um arquivo HTML (Hypertext Markup Language).

### Para salvar um formulário como HTML
- Abra o formulário.
- Escolha Save As HTML no menu File. (Você será solicitado a salvar o formulário se ele foi modificado.)
- Digite o nome do arquivo HTML a ser criado e escolha Save .
