# Caixa de diálogo Check Out Files

Faz check-out de uma cópia dos arquivos selecionados do seu provedor de controle de código-fonte e coloca uma cópia gravável no diretório de trabalho correspondente do ambiente de desenvolvimento.
 **Files to be Checked Out**
Lista os arquivos disponíveis para check-out. Clique nos arquivos que deseja fazer check-out, ou clique em Select All para selecionar todos os arquivos listados.
**Comment**
Digite uma breve descrição do motivo do check-out.
**Select All**
Seleciona todos os arquivos listados.
**Advanced**
Exibe a caixa de diálogo Advanced Check Out Options do provedor de controle de código-fonte.
