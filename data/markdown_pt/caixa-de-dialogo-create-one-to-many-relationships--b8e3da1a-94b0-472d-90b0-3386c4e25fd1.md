# Caixa de diálogo Create One-To-Many Relationships

Estabelece um relacionamento um-para-muitos, no qual a tabela filha pode conter vários registros que correspondem a um registro na tabela pai. Corresponde ao comando SET SKIP Command.

Esta caixa de diálogo aparece quando você escolhe o botão 1-To-Many na janela Data Session Window.

O botão 1-To-Many é habilitado quando há pelo menos um relacionamento originado da tabela selecionada.
 **Child Aliases**
Lista os aliases filhos do alias pai, cujo nome é dado no topo da caixa de diálogo.
**SelectedAliases**
Lista os aliases de todas as tabelas atualmente envolvidas em um relacionamento um-para-muitos com a tabela pai.
**Move**
Copia os aliases filhos selecionados na caixa ChildAliases para a caixa SelectedAliases. Para habilitar este botão, você deve selecionar um alias na caixa ChildAliases.
**All**
Copia todos os aliases filhos na caixa ChildAliases para a caixa SelectedAliases.
**Remove**
Remove os aliases selecionados da caixa SelectedAliases. Para habilitar este botão, você deve selecionar um alias na caixa SelectedAliases.
**Remove All**
Remove todos os aliases da caixa SelectedAliases.
