# Variável de sistema _GENSCRN

Incluída para compatibilidade com versões anteriores. Use o Form Designer em vez disso.

Especifica um programa de geração de telas.

```foxpro
_GENSCRN = program name
```

# Observações

_GENSCRN permite especificar o programa que o FoxPro usa para gerar código de tela a partir de um arquivo .SCX. Por padrão, _GENSCRN usa GENSCRN.PRG.

Você pode incluir um caminho com o nome do programa de geração de telas.
