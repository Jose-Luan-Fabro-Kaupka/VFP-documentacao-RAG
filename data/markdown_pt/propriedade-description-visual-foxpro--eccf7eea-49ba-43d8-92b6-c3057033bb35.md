# Propriedade Description (Visual FoxPro)

Para um objeto File, a descrição do arquivo. Para um objeto Server, a descrição da classe do servidor. Disponível em tempo de design e em tempo de execução.

```foxpro
Object.Description[ = cExpression]
```

# Valor de retorno
 **cExpression**
Especifica a descrição do objeto File ou Server. Para um objeto File, o valor padrão é a cadeia de caracteres vazia. Você também pode especificar uma descrição para um arquivo em um projeto escolhendo Edit Description no menu Project. Para um Server, o valor padrão é o nome da classe do servidor. Você também pode especificar uma descrição para um servidor na guia Servers da caixa de diálogo Project Information. A descrição do objeto Server também aparece para o servidor no Registro.

# Observações

Aplica-se a: Objeto File (Visual FoxPro) | Objeto Server
