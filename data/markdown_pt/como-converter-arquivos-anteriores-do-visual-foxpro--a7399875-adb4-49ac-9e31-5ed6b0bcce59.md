# Como: converter arquivos anteriores do Visual FoxPro

Você pode converter explicitamente arquivos do FoxPro 2.6 e do Visual FoxPro 3.0 para o formato atual do Visual FoxPro, o que é necessário quando você deseja usar esses arquivos com versões posteriores do Visual FoxPro. Arquivos criados a partir de versões posteriores são convertidos automaticamente.

### Para converter arquivos do FoxPro 2.6 e do Visual FoxPro 3.0
- No menu File, clique em Open.
- Na caixa de diálogo Open, procure e selecione o arquivo. A caixa de diálogo Visual FoxPro Converter abre. Para obter mais informações, consulte Visual FoxPro Converter Dialog Box.
- Na caixa de diálogo Visual FoxPro Converter, selecione as opções desejadas.
- Para concluir a conversão do arquivo, clique em Continue. Observação Se você estiver convertendo arquivos Macintosh ou MS-DOS que nunca continham registros Windows, a caixa de diálogo Visual FoxPro Transporter aparece. Para obter mais informações, consulte Visual FoxPro Transporter Dialog Box.

Você também pode converter arquivos do FoxPro 2.6 e do Visual FoxPro 3.0 digitando um dos seguintes comandos com o nome do arquivo na janela Command:
 - Comando MODIFY PROJECT
- Comando MODIFY FORM
- Comando MODIFY REPORT
- Comando MODIFY LABEL
