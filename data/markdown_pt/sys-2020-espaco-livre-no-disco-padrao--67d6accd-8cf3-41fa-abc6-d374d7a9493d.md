# SYS(2020) - Espaço livre no disco padrão

Retorna o espaço livre em bytes no disco padrão.

```foxpro
SYS(2020)
```

# Valor de retorno

Character. SYS(2020) retorna o espaço livre em bytes no disco padrão.

# Observações

Você pode especificar o disco padrão usando o comando SET DEFAULT. Para obter mais informações, consulte Comando SET DEFAULT.
