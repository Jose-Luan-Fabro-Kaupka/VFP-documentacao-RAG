# Objeto XMLTable com XMLName "name" não possui campos associados. (Erro 2130)

O Visual FoxPro exige que o objeto XMLTable contenha um ou mais objetos XMLField associados antes que o método ToXML dos objetos XMLAdapter possa ser chamado.
 - Execute o método AddTableSchema dos objetos XMLAdapter para criar as coleções XMLTable e XMLField, ou crie esses itens de outra forma.
