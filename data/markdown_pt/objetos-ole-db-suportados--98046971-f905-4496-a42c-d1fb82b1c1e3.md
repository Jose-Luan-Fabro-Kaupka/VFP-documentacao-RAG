# Objetos OLE DB suportados

O Provedor OLE DB do Visual FoxPro suporta os seguintes objetos OLE DB baseados na especificação OLE DB 2.1.

| Objeto | Descrição |
| --- | --- |
| Objeto de fonte de dados | Estabelece um vínculo com um armazenamento de dados. |
| Objeto de sessão | Fornece métodos para criar comandos e conjuntos de linhas e para criar e modificar tabelas e índices. |
| Objeto de comando | Fornece coleções, propriedades e métodos para emitir comandos e retornar conjuntos de linhas. |
| Objeto de conjunto de linhas | Expõe dados em forma tabular como conjuntos de linhas, linhas que contêm colunas de dados. |
| Objeto de erro | Fornece a capacidade de retornar vários registros de erro de uma única chamada e a capacidade de retornar informações de erro específicas do provedor. |
| Objeto ConnectionPage | Fornece acesso a uma caixa de diálogo de configuração Microsoft DataLink (UDL). |
