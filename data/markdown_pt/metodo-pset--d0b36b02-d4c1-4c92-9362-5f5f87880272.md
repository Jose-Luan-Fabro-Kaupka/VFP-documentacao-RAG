# Método PSet

Define um ponto em um formulário ou na janela principal do Visual FoxPro para a cor de primeiro plano.

```foxpro
 [FormSet.]Object.PSet([nXCoord, nYCoord])
```

#### Parâmetros
 **nXCoord**
Especifica a coordenada horizontal do ponto a definir, na unidade de medida especificada pela propriedade ScaleMode do formulário.
**nYCoord**
Especifica a coordenada vertical do ponto a definir, na unidade de medida especificada pela propriedade ScaleMode do formulário.

# Observações

Aplica-se a: Form Object | _SCREEN System Variable

O tamanho do ponto desenhado depende da propriedade DrawWidth. Quando DrawWidth é definida como 1, o método PSet define um único pixel para a cor especificada. Quando DrawWidth é definida com um valor maior que 1, o ponto é centralizado nas coordenadas especificadas. A forma como o ponto é desenhado depende da configuração das propriedades DrawMode e DrawStyle.

Quando o método PSet é chamado, as propriedades CurrentX e CurrentY são definidas para o ponto especificado pelos argumentos.
