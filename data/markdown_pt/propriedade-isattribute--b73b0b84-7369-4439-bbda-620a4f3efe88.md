# Propriedade IsAttribute

Especifica se o campo é representado como um Attribute no documento XML associado.

```foxpro
XMLField.IsAttribute [= lValue]
```

# Valor de retorno
 **lValue**
Tipo de dados lógico. A tabela a seguir lista os valores de lValue . lValue Descrição False (.F.) O campo está na forma Element, não Attribute, no documento XML associado. (Padrão) True (.T.) O campo é representado como um Attribute no documento XML associado.

# Observações

Aplica-se a: XMLField Class
