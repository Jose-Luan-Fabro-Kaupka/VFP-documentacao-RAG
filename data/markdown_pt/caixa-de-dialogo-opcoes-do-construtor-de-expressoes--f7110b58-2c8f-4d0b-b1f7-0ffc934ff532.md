# Caixa de diálogo Opções do Construtor de Expressões

Define preferências para os itens exibidos no Construtor de Expressões. Esta caixa de diálogo aparece quando você clica em Opções na Caixa de diálogo Construtor de Expressões.

# Funções

Permite alterar o que aparece nas funções String, Math, Logical e Date no Construtor de Expressões. Você pode optar por exibir todas elas na caixa String do Construtor de Expressões ou selecionar apenas as desejadas. Para selecionar ou desmarcar vários itens, pressione CTRL enquanto faz suas seleções.
 **String**
Exibe todas as funções de cadeia de caracteres na caixa. Todas as funções de cadeia de caracteres selecionadas serão exibidas no Construtor de Expressões.
**Math**
Exibe todas as funções matemáticas na caixa. Todas as funções matemáticas selecionadas serão exibidas no Construtor de Expressões.
**Logical**
Exibe todas as funções lógicas na caixa. Todas as funções lógicas selecionadas serão exibidas no Construtor de Expressões.
**Date**
Exibe todas as funções de data na caixa. Todas as funções de data selecionadas serão exibidas no Construtor de Expressões. Observação Selecione itens individuais pressionando CTRL+botão esquerdo do mouse. Selecione um grupo consecutivo de itens clicando com o botão esquerdo no primeiro item e pressionando SHIFT+botão esquerdo do mouse no último item.
**All**
Seleciona todas as funções na caixa para que apareçam como opções no Construtor de Expressões.
**Clear**
Desmarca todas as funções na caixa para que não apareçam como opções no Construtor de Expressões.

# Aliases de campo

Essas opções especificam se e como aliases de tabela ou view aparecem em suas expressões.
 **Always Add Alias**
Especifica que o nome da tabela ou view é sempre incluído com os campos usados na expressão.
**Add Non-Selected Alias Only**
Especifica que, quando mais de uma tabela ou view estiver aberta, o Visual FoxPro inclui apenas o nome de qualquer tabela ou view que não esteja selecionada na lista Aliases da Janela de Sessão de Dados com qualquer um de seus campos na expressão. Nomes de tabela ou view não são adicionados para tabelas selecionadas na lista Aliases.
**Never Add Alias**
Especifica que nomes de tabela ou view não são incluídos com nenhum campo quando você cria a expressão.
**Show System Memory Variables**
Especifica se variáveis de memória do sistema são exibidas no Construtor de Expressões. Desative esta opção se quiser ver apenas as variáveis de memória do sistema que foram definidas.
