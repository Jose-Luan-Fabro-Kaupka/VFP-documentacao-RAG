# Caixa de diálogo Insert System Menu Bar

Permite adicionar menus e opções de menu à janela Menu Designer. Esta caixa de diálogo aparece quando você escolhe Insert Bar no menu Menu ou seleciona o botão Insert Bar na janela Menu Designer.
 **Menu List Box**
Lista os nomes de menu e nomes de opções de menu disponíveis, dependendo de você ter escolhido Usage ou Prompt na área Order by.

# Order By
 **Usage**
Designa que a Menu List Box exiba os itens de menu disponíveis na ordem em que apareceriam em seus respectivos títulos de menu. Por exemplo, todos os itens do menu File são listados primeiro, na ordem em que aparecem no menu File real. Os itens do menu Edit aparecem em seguida, e assim por diante.
**Prompt**
Designa que a Menu List Box exiba os itens de menu disponíveis em ordem alfabética.
**Insert**
Insere o item de menu selecionado na linha designada na janela Menu Designer.
