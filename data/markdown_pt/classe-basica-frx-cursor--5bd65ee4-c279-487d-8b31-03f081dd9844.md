# Classe básica FRX Cursor

Esta classe fornece métodos para traduzir e manipular vários valores em arquivos Label (lbx) e Report (frx).

| Categoria | Reporting |
| --- | --- |
| Catálogo padrão | Visual FoxPro Catalog\Foundation Classes\Output\Output Helper Classes |
| Classe | frxCursor |
| Classe base | Custom |
| Biblioteca de classes | _FrxCursor.vcx |
| Classe pai | Custom |

# Observações

Esta classe expõe os algoritmos usados por ReportOutput.APP, ReportBuilder.APP e ReportPreview.APP para interpretar vários valores de impressão e valores de tabela Report (frx) e Label (lbx).

É principalmente útil para desenvolvedores que estendem a funcionalidade de relatório do Visual FoxPro. Para obter mais informações, consulte Extending Report Functionality in Visual FoxPro.

FrxCursor ajuda você a lidar com muitos detalhes do formato de arquivo Report e Label que de outra forma são obscuros e, em muitos casos, muito complexos. O tópico Understanding and Extending Report Structure fornecerá detalhes importantes sobre este formato de arquivo.

> **Importante:** Muitos métodos desta classe usam uma unidade de medida conhecida como FRU. FRUs são unidades de relatório FoxPro, especificadas como 1/10000 de polegada. Esta unidade é a unidade interna usada pelo Visual FoxPro Report Designer para armazenar medidas de layout e posição. Os métodos de FrxCursor ajudam você a converter FRUs em unidades que você pode usar mais facilmente em outros ambientes.

# Exemplo

Este exemplo altera a largura de um campo em um registro de tabela Report, para acomodar uma expressão diferente neste campo.

Ele usa o método FrxCursor.getFruTextWidth() para determinar a largura correta para o novo conteúdo do campo. Depois usa o método FrxCursor.getFrxTimeStamp() para atualizar o carimbo de data/hora para este registro.

```foxpro
#DEFINE OBJTYPE_FIELD           8
LOCAL iWidth, oFrxCursor
oFrxCursor = NEWOBJECT("FrxCursor", "_FrxCursor")
USE My.FRX
LOCATE FOR objtype = OBJTYPE_FIELD AND ;
           UPPER(ALLTRIM(Expr)) == "DATE()"
IF FOUND()
   iWidth = FrxCursor.getFruTextWidth(TRANSFORM(DATETIME()), ;
                                       fontface,fontsize)
   REPLACE Expr WITH "DATETIME()", ;
           Width WITH iWidth, ;
           Timestamp WITH FrxCursor.getFrxTimeStamp()
ENDIF
```
