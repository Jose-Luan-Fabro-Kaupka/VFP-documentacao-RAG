# O page frame não pode ser dimensionado tão pequeno (Erro 1413)

Os page frames devem ser altos o suficiente para exibir uma linha de guias, se a propriedade Tabs Property estiver definida; caso contrário, devem ter pelo menos um pixel de altura.
 - Você tentou redimensionar o page frame para menos que a altura de uma linha de guias. Torne o page frame mais alto.
