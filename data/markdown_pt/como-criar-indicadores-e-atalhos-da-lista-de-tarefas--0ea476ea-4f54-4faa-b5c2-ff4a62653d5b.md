# Como: criar indicadores e atalhos da Lista de Tarefas

Você pode definir indicadores e atalhos para o código em uma janela de edição, facilitando a navegação pelo código durante os processos de programação e depuração. Ao definir indicadores, você pode navegar entre eles no código.

Ao criar atalhos, você pode criar tarefas no Gerenciador de Lista de Tarefas associadas a esses atalhos. Quando cria um atalho no código, uma entrada aparece na janela Tarefas do Gerenciador de Lista de Tarefas para que você crie uma tarefa, permitindo ir rapidamente para o código marcado. Para obter mais informações, consulte Como: usar o Gerenciador de Lista de Tarefas e Janela do Gerenciador de Lista de Tarefas.

> **Observação:** Antes de criar indicadores e atalhos, você deve ter salvo o arquivo. É possível criar um indicador ou um atalho, mas não ambos, para uma linha de código. Indicadores e atalhos se relacionam à posição de uma linha de código na janela de edição, não ao código em si. Portanto, certas operações de edição, como inserir texto antes de um indicador, podem fazer com que a linha de código à qual um indicador ou atalho se refere seja movida para outra linha. Se não quiser que o indicador se refira à nova linha, remova o indicador ou atalho e adicione um novo no local desejado.

### Para criar indicadores e atalhos
- Se o arquivo de código não tiver sido salvo, salve-o.
- Na linha de código em que deseja criar um indicador, posicione o cursor do mouse.
- No menu Editar, aponte para Indicadores.
- Para criar um indicador, clique em Alternar Indicador. Um retângulo aparece na margem de seleção, no lado esquerdo da janela de edição. Dica: se a margem de seleção não aparecer, você poderá especificá-la no guia Editor da caixa de diálogo Opções. Para obter mais informações, consulte Guia Editor, caixa de diálogo Opções. -OU- Para criar um atalho, clique em Alternar Atalho da Lista de Tarefas. Uma seta curva aparece na margem de seleção, no lado esquerdo da janela de edição.

Você também pode criar um indicador posicionando o cursor do mouse na margem de seleção ao lado da linha de código e pressionando SHIFT enquanto clica duas vezes. Também pode criar um atalho posicionando o cursor do mouse na margem de seleção ao lado da linha de código e pressionando CTRL enquanto clica duas vezes. Também é possível criar e navegar por indicadores e atalhos usando teclas de atalho. Para obter informações sobre atalhos de teclado, consulte Atalhos de teclado (Visual FoxPro).

> **Observação:** Os indicadores são preservados quando você fecha e reabre a janela de edição, mas deixam de existir depois que você encerra e reinicia o Visual FoxPro. Os atalhos persistem entre sessões de edição.

### Para navegar por indicadores e atalhos
- No menu Editar, clique em Próximo Indicador/Atalho ou Indicador/Atalho Anterior.

### Para remover indicadores e atalhos
- Na linha de código da qual deseja remover um indicador ou atalho, posicione o cursor do mouse.
- No menu Editar, aponte para Indicadores. Para remover um indicador, clique em Alternar Indicador. -OU- Para remover um atalho, clique em Alternar Atalho da Lista de Tarefas.
