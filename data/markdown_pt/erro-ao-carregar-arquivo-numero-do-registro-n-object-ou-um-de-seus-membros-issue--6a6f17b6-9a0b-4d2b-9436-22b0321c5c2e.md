# Erro ao carregar arquivo - número do registro n. "object" <ou um de seus membros>. "Issue": "error" (Erro 1881)

Ocorreu um erro ao tentar ler um arquivo de formulário (.scx) ou de classe (.vcx). Issue se refere a "Properties," "Methods" ou "User Properties."

Para resolver o erro:
 - Para acessar o registro referenciado no erro, abra o formulário ou a classe como uma tabela da seguinte forma: USE myform.scx
- Para mover para esse registro, use o comando GO.

Você frequentemente pode encontrar a causa do erro nos campos Properties, Methods, Class, Classloc, Objname ou Parent.

> **Observação:** Você deve fazer uma cópia de backup do seu formulário e arquivo de classe antes de modificar os registros e campos contidos diretamente.
