# Não é possível adicionar este objeto a uma Column (Erro 1769)

A coluna do grid não suporta objetos como formulários, form sets, toolbars e colunas.
 - Você usou o método AddObject na coluna do grid. Use AddObject apenas para objetos que possam ser representados de forma razoável em uma coluna. Se você deseja a aparência de um formulário na coluna, salve o conteúdo do formulário em uma classe container e adicione-a à coluna.
