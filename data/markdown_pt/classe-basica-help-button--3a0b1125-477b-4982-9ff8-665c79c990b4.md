# Classe básica Help Button

Esta classe fornece um botão que, quando clicado, exibe um tópico de Ajuda pesquisando o HelpContextID especificado no controle.

| Category | Misc Buttons |
| --- | --- |
| Default Catalog | Visual FoxPro Catalog\Foundation Classes\Buttons |
| Class | _cmdHelp |
| Base Class | CommandButton |
| Class Library | _miscbtns.vcx |
| Parent Class | _commandbutton |
| Sample | ...\Samples\Solution\Ffc\buttons.scx |

# Observações

Para usar, solte a classe em um projeto ou formulário ou, no menu de atalho do item da Component Gallery, selecione Add to Form. Quando você adiciona a classe a um formulário, o Visual FoxPro coloca um botão no formulário. Você precisa fornecer o valor adequado para substituir o valor padrão de HelpContextID. Quando você solta a classe em um projeto, pode escolher entre adicionar a classe ou criar uma subclasse.
