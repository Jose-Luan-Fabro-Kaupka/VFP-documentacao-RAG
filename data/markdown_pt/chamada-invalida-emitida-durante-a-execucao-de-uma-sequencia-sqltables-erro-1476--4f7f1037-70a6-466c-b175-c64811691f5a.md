# Chamada inválida emitida durante a execução de uma sequência SQLTABLES( ) (Erro 1476)

Uma chamada inválida de função SQL pass-through (SPT) foi feita enquanto era esperada uma chamada da função SQLTABLES( ) para continuar a sequência de chamadas SPT em andamento.

Chame a função SQLCANCEL( ) para cancelar a sequência SPT ou faça chamadas SPT válidas para concluir a sequência de chamadas.
