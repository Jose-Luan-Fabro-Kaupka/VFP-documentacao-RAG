# Método RemoveItem

Remove um item de uma caixa de combinação ou caixa de listagem.

```foxpro
Control.RemoveItem(nIndex)
```

#### Parâmetros
 **nIndex**
Especifica um inteiro correspondente à ordem em que os itens são exibidos no controle. Para o primeiro item em uma caixa de listagem ou caixa de combinação, nIndex = 1.

# Observações

Aplica-se a: Controle ComboBox | Controle ListBox
