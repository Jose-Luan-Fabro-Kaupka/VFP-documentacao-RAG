# Caixa de diálogo Include File

Permite especificar um arquivo de cabeçalho contendo constantes predefinidas em tempo de compilação para uma classe definida pelo usuário, formulário ou conjunto de formulários.

Esta caixa de diálogo aparece quando você seleciona Include File no menu Class ou Form.
 **Include File**
Especifica um arquivo de cabeçalho contendo constantes predefinidas em tempo de compilação para uma classe definida pelo usuário, formulário ou conjunto de formulários. Digite o nome do arquivo de cabeçalho na caixa ou use o botão de diálogo para selecionar um arquivo de cabeçalho existente.
