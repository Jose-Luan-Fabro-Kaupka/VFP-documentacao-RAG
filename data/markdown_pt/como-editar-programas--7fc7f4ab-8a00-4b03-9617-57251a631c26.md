# Como: editar programas

Depois de criar um programa, você pode fazer alterações nele ou em um programa existente.

> **Observação:** Depois de editar um programa, certifique-se de salvá-lo.

### Para editar um programa autônomo
- No menu File, clique em Open .
- Na caixa de diálogo Open, escolha Program na lista Files of type para mostrar apenas arquivos de programa.
- Clique no programa que deseja modificar e depois em OK .

### Para editar um programa em um projeto
- Abra o projeto do seu aplicativo no Project Manager .
- No Project Manager , expanda o nó Code e depois o nó Programs.
- No nó Programs, selecione o programa desejado e clique em Modify .

### Para editar um programa programaticamente
- Na janela Command, execute uma das seguintes opções: Use MODIFY COMMAND com o nome do arquivo de programa (.prg) para abrir uma janela de edição para o programa. Por exemplo: MODIFY COMMAND MyProgram Use MODIFY COMMAND com um ponto de interrogação (?) para exibir a caixa de diálogo Open para que você possa procurar e selecionar um arquivo de programa. Por exemplo: MODIFY COMMAND ?
