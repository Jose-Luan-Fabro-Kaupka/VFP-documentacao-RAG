# Como: remover arquivos de projetos

Você pode remover arquivos do seu projeto ou excluí-los.

### Para remover um arquivo de um projeto
- Abra o projeto da sua aplicação.
- Na Project Manager, expanda o nó na hierarquia do projeto que contém o tipo de componente que deseja remover.
- Clique no arquivo que deseja remover.
- No menu Project, clique em Add File. Dica Você também pode clicar em Remove na Project Manager.
- Quando o Visual FoxPro solicitar confirmação para remover o arquivo, execute uma das seguintes ações: Para remover o arquivo somente do seu projeto, clique em Remove. Para excluir o arquivo do disco, clique em Delete.

Para mais informações, consulte Project Manager Window.
