# Janela Debugger

A janela Debugger do Visual FoxPro contém os menus do Debugger, a barra de ferramentas do Debugger e várias janelas de depuração.

Esta janela é ativada quando você escolhe Debugger no menu Tools principal do Visual FoxPro, desde que a opção Environment no menu Debug (em Options no menu Tools) esteja definida como Debug Frame. Se FoxPro Frame estiver selecionado, a janela Debugger não estará acessível e as janelas individuais do depurador estarão disponíveis no menu principal do FoxPro.
 **Janela Trace**
Permite ver suas linhas de código enquanto são executadas.
**Janela Locals**
Exibe as variáveis, matrizes, objetos e membros de objetos visíveis do programa, procedimento ou método atual.
**Janela Watch**
Exibe expressões e seus valores atuais e permite definir pontos de interrupção em uma expressão.
**Janela Call Stack**
Exibe procedimentos, programas e métodos que estão sendo executados.
**Janela Debug Output**
Exibe saída específica de depuração de seus programas.

As janelas e a barra de ferramentas de depuração podem ser encaixadas e posicionadas.

| Para | Faça |
| --- | --- |
| Redimensionar janelas encaixadas adjacentes | Arraste a barra separadora entre elas. |
| Flutuar uma janela | Escolha Undock no menu de atalho. |
| Visualizar uma janela aberta e oculta | Clique duas vezes no botão da barra de ferramentas associado à janela: uma vez para fechar a janela e uma segunda vez para reabrir a janela. |
