# A tabela não tem ordem de índice definida (Erro 26)

Os registros na tabela não têm ordem.
 - Um índice para o arquivo de tabela não foi selecionado quando um comando UPDATE usando a cláusula RANDOM foi encontrado. Selecione um índice para o arquivo de tabela.
- Um FIND ou SEEK foi tentado em uma tabela sem ordenação de índice. Use SET ORDER TO para especificar uma ordem de índice.
- SET RELATION foi emitido com uma expressão não numérica. Forneça uma expressão numérica.
