# Caixa de diálogo Coverage Profiler Add-Ins

Permite localizar e executar arquivos .app, .fxp ou .prg para alterar ou aprimorar o Coverage Profiler. Você pode usar esses Add-Ins para adicionar controles, consultas, caixas de diálogo e outros aprimoramentos ao Coverage Profiler.

# Add-Ins

Permite selecionar um programa Add-In para executar.
 **Register this Add-In after running**
Adiciona o Add-In atual a uma lista suspensa para que você possa acessar o Add-In no futuro. Observação Você pode configurar o Coverage Profiler para registrar novos Add-Ins por padrão selecionando a caixa de seleção Register Add-Ins when run na caixa de diálogo Coverage Profiler Options .
**Run**
Inicia o programa Add-In.
