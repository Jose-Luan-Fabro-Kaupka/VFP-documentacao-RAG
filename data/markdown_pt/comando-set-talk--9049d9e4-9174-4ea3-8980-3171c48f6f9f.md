# Comando SET TALK

Determina se o Visual FoxPro exibe os resultados dos comandos.

```foxpro
SET TALK ON | OFF | WINDOW [WindowName] | NOWINDOW
```

#### Parâmetros
 **ON**
(Padrão) Permite que o talk seja enviado para a janela principal do Visual FoxPro, a janela de mensagens do sistema, a barra de status gráfica ou uma janela definida pelo usuário. Se SET TALK estiver definido como OFF e depois alterado para ON, o talk é direcionado para o mesmo local para o qual era enviado antes de você emitir SET TALK OFF.
**OFF**
Impede que o talk seja enviado para a janela principal do Visual FoxPro, a janela de mensagens do sistema, a barra de status gráfica ou uma janela definida pelo usuário. Observe que, para servidores de automação .dll em processo, a configuração padrão de SET TALK é OFF.
**WINDOW [ WindowName ]**
WindowName especifica uma janela definida pelo usuário para a qual o talk é direcionado. Você deve criar a janela definida pelo usuário antes de direcionar o talk para ela. O talk é direcionado para a janela do sistema do Visual FoxPro se a janela especificada não existir.
**NOWINDOW**
Direciona o talk para a janela principal do Visual FoxPro.

# Observações

Alguns comandos de processamento de tabelas retornam informações, ou "talk", sobre seu status enquanto são executados. Esses comandos incluem:
 Comandos
| APPEND FROM | PACK |
| --- | --- |
| AVERAGE | REINDEX |
| CALCULATE | REPLACE |
| COPY TO | SELECT - SQL |
| COUNT | SORT |
| DELETE | SUM |
| INDEX | TOTAL |

O talk pode ser direcionado para a janela principal do Visual FoxPro, a barra de status gráfica ou uma janela definida pelo usuário. O talk também pode ser desativado.

O intervalo de relatório de SET TALK pode ser especificado com SET ODOMETER. O valor padrão de SET ODOMETER é 100. Observe que a velocidade de execução pode ser reduzida quando SET TALK está definido como ON, porque a janela principal do Visual FoxPro ou a janela definida pelo usuário deve ser atualizada com frequência. Se você precisar apenas do número total de registros processados por um comando, pode emitir SET TALK OFF e exibir a variável de sistema _TALLY depois que o comando terminar de ser executado.

SET TALK tem escopo na sessão de dados atual.
