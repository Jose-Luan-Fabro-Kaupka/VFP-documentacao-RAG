# Caixa de diálogo Font

Controla o tipo, o estilo e o tamanho da fonte.

Você pode alterar fontes em um arquivo de texto, campo ou controle de etiqueta em um relatório ou etiqueta, ou na janela Command. Para alterar fontes em relatórios e etiquetas, você deve criar um controle de etiqueta ou de campo e depois selecioná-lo.
 **Font**
Exibe as fontes disponíveis.
**Font Style**
Exibe os estilos (Regular, Bold, Italic ou Bold Italic) que você pode aplicar à fonte ou ao texto selecionado.
**Size**
Exibe uma lista de tamanhos em pontos para a fonte. Effects Strikeout Traça o texto com uma linha horizontal. Esta opção aparece apenas quando você está trabalhando com um relatório ou etiqueta. Underline Sublinha o texto selecionado. Esta opção aparece apenas quando você está trabalhando com um relatório ou etiqueta.
**Color**
Especifica a cor do texto selecionado. Esta opção aparece apenas quando você está trabalhando com um relatório ou etiqueta.
**Sample**
Exibe uma amostra do estilo de letras da fonte selecionada para letras maiúsculas e minúsculas.
**Script**
Lista os scripts de idioma disponíveis para uma fonte específica. Escolha o apropriado para o idioma para o qual seu computador está configurado.
