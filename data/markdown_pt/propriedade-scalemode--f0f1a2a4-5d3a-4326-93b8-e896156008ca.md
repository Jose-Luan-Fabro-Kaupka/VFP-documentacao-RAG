# Propriedade ScaleMode

Especifica a unidade de medida para as coordenadas de um objeto ao usar métodos gráficos ou ao posicionar controles. Disponível em tempo de design e em tempo de execução.

```foxpro
Object.ScaleMode = nMode
```

# Valor de retorno
 **nMode**
As configurações da propriedade ScaleMode são: Setting Description 0 Foxels (A Visual FoxPro term. Equivalent to the maximum height and average width of a character in the current font.) 3 Pixels (default; smallest unit of monitor or printer resolution)

# Observações

Aplica-se a: Form Object | _SCREEN System Variable | ToolBar Object
