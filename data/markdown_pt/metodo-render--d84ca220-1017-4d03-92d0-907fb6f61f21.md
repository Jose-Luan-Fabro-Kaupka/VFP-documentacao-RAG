# Método Render

Ocorre quando ReportListener está pronto para fornecer saída para um elemento de layout em um relatório ou etiqueta.

```foxpro
oReportListener.Render(nFRXRecNo,;
                       nLeft,nTop,nWidth,nHeight,;
                       nObjectContinuationType, ;
                       cContentsToBeRendered, GDIPlusImage)
```

#### Parâmetros
 **nFRXRecno**
Especifica o número do registro no arquivo de definição de relatório ou etiqueta (frx ou lbx) que descreve o elemento de layout sendo renderizado.
**nLeft**
Especifica a coordenada da coluna, em unidades de 1/960 de polegada (960 dpi), do retângulo na página atual em que esta ocorrência do elemento de layout será renderizada.
**nTop**
Especifica a coordenada da linha, em unidades de 1/960 de polegada (960 dpi), do retângulo na página atual em que esta ocorrência do elemento de layout será renderizada.
**nWidth**
Especifica a largura, em unidades de 1/960 de polegada (960 dpi), do retângulo na página atual em que esta ocorrência do elemento de layout será renderizada.
**nHeight**
Especifica a altura, em unidades de 1/960 de polegada (960 dpi), do retângulo na página atual em que esta ocorrência do elemento de layout será renderizada.
**nObjectContinuationType**
Indica o estado de continuação atual para o elemento renderizado. Quando elementos de layout abrangem páginas, são renderizados em várias seções (uma vez para cada página). Observação A continuação pode ocorrer para elementos de layout do tipo Expressão (Campo), Forma ou Linha. Embora Etiquetas e Imagens possam abranger faixas em um relatório, não podem abranger páginas e ReportListener as renderiza apenas uma vez. Nem todos os tipos de faixa suportam abrangência de páginas. Consulte Faixas de relatório para obter mais informações. A tabela a seguir lista os valores possíveis para nObjectContinuationType . Valor Tipo de continuação 0 Completo (sem continuação). 1 Início da ocorrência do elemento de layout, não terminará na página atual. 2 Meio do elemento, nem iniciado nem finalizado na página atual. 3 Fim do elemento, concluído na página atual.
**cContentsToBeRendered**
Indica o texto a ser renderizado para elementos de layout Expressão (Campo) e Etiqueta. Para elementos de layout Imagem originados de um arquivo, cContentsToBeRendered contém o nome do arquivo. Ao especificar um nome de arquivo para uma imagem, ReportListener fornece cContentsToBeRendered como uma cadeia de caracteres DBCS, que é o formato padrão para cadeias de caracteres no Visual FoxPro. No entanto, ao indicar texto a ser renderizado, ReportListener fornece cContentsToBeRendered como uma cadeia de caracteres Unicode, traduzida adequadamente para o local correto usando qualquer informação de script regional associada a este controle de layout em seu registro de arquivo de definição de relatório (frx). Se sua classe derivada envia o valor de texto por algum processamento adicional, como armazenamento em uma tabela, você pode usar a função STRCONV() e seu parâmetro opcional de script regional para converter a cadeia de caracteres para DBCS primeiro. Para obter mais informações, consulte Função STRCONV( ) . Observação Você define o script regional padrão para um relatório na caixa de diálogo Propriedades do relatório. Para obter mais informações, consulte Guia Layout da página, caixa de diálogo Propriedades do relatório (Construtor de relatórios) . Você também pode definir configurações de script regional para controles de layout individuais, ao selecionar outros atributos de fonte. Para obter mais informações, consulte Como: alterar configurações de fonte em controles de relatório .
**GDIPlusImage**
Fornece um identificador para o identificador gráfico GDI+ quando um layout de Imagem é originado de uma imagem não baseada em arquivo (um campo General ou um controle Image). Quando ReportListener renderiza um tipo diferente de elemento de layout, ou quando você não define o valor de sua propriedade SendGDIPlusImage como 1 ou superior, este parâmetro tem o valor 0. Para obter mais informações, consulte Propriedade SendGDIPlusImage .

# Valor de retorno

Nenhum.

# Observações

Aplica-se a: objeto ReportListener.

ReportListener chama Render uma vez para cada ocorrência de cada elemento de layout a ser renderizado, potencialmente várias vezes para alguns tipos de elemento de layout que abrangem páginas.

> **Observação:** Durante o processamento do relatório, se você usar uma expressão Imprimir quando em um elemento de layout, o Sistema de relatórios avalia esta expressão para decidir se cada ocorrência de um elemento de layout deve aparecer. Se Imprimir quando avaliar como False ( .F. ) para uma ocorrência específica de um objeto de layout, o elemento não aparece e ReportListener não chama Render.

> **Observação:** Se Imprimir quando avaliar como True ( .T. ), você pode alterar o conteúdo renderizado de alguns elementos de layout usando AdjustObjectSize e EvaluateContents (por exemplo, alterando o texto de um controle de layout Expressão para uma cadeia de caracteres de comprimento nulo ou tornando-o transparente). Como resultado desta atividade, você pode não ver nenhum resultado renderizado na saída do relatório. No entanto, ReportListener ainda chama Render nesta situação.

### Recursos especiais da renderização GDI+ do Visual FoxPro

Objetos ReportListener usam Microsoft Windows GDI+ para renderizar em dispositivos de saída. GDI+ permite que a saída seja independente de dispositivo, o que significa que o mesmo mecanismo de renderização é usado se você estiver visualizando o conteúdo do relatório, imprimindo-o ou salvando-o em um arquivo de imagem.

ReportListener expõe alguns recursos especiais do GDI+ que fornecem oportunidades para personalizar a renderização de texto. Por exemplo, a propriedade DynamicLineHeight do ReportListener permite aproveitar o espaçamento dinâmico de linhas do GDI+ para renderizar texto. ReportListener também expõe opções StringTrimming do GDI+, que permitem determinar como o texto é renderizado quando não cabe no espaço que você alocou para um controle de expressão no layout do relatório. Para obter mais informações, consulte Propriedade DynamicLineHeight e Usando GDI+ em relatórios.

# Exemplo

Alguns parâmetros são apropriados apenas para alguns tipos de elemento de layout. Você pode usar o primeiro parâmetro, nFRXRecno, para verificar o arquivo de definição de relatório (frx) e determinar o tipo de elemento de layout. Você pode então aumentar o processo Render adequadamente para o tipo de elemento atual.

O exemplo a seguir é semelhante ao código usado pela classe básica ReportListener XML Display-Style para copiar imagens baseadas em arquivo para o disco quando ReportListener as renderiza. Ele usa o parâmetro nFRXRecNo para determinar o tipo de elemento de layout. Se o elemento é uma Imagem, verifica o parâmetro cContentsToBeRendered para ver se o arquivo está disponível para cópia. Em seguida, delega ao código da classe ReportListener nativa para continuar renderizando a imagem no dispositivo de saída padrão.

```foxpro
PROCEDURE Render(nFRXRecNo,;
                 nLeft,nTop,nWidth,nHeight,;
                 nObjectContinuationType, ;
                 cContentsToBeRendered, GDIPlusImage)
   LOCAL llCopyImage, lcFile
   IF THIS.CopyImageFilesToExternalFileLocation
      THIS.SetFRXDataSession()
      GO nFRXRecNo IN FRX
      IF FRX.ObjType = FRX_OBJTYP_PICTURE AND ;
         FRX.Offset # FRX_PICTURE_SOURCE_GENERAL AND ;
         FILE(cContentsToBeRendered)
         llCopyImage = .T.
      ENDIF
      THIS.SetCurrentDataSession()
   ENDIF

   IF llCopyImage
      lcFile = FORCEPATH(cContentsToBeRendered, ;
          FULLPATH(THIS.ExternalFileLocation, ;
          ADDBS(JUSTPATH(THIS.TargetFileName))))
      IF NOT FILE(lcFile)
         COPY FILE (cContentsToBeRendered) TO (lcFile)
      ENDIF
   ENDIF

   DODEFAULT(nFRXRecNo,;
             nLeft,nTop,nWidth,nHeight,;
             nObjectContinuationType, ;
             cContentsToBeRendered, GDIPlusImage)
ENDPROC
```
