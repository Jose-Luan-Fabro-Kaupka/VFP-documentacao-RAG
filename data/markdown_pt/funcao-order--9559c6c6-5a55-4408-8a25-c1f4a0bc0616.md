# Função ORDER( )

Retorna o nome do arquivo de índice controlador ou tag para a tabela atual ou especificada.

```foxpro
ORDER([nWorkArea | cTableAlias [, nPath]])
```

#### Parâmetros
 **nWorkArea**
Especifica a área de trabalho de uma tabela cujo nome de arquivo de índice controlador ou nome de tag controladora ORDER( ) retorna.
**cTableAlias**
Especifica um alias de tabela cujo nome de arquivo de índice controlador ou nome de tag controladora ORDER( ) retorna.
**nPath**
Especifica que a unidade e o diretório são retornados junto com o nome do arquivo de índice de entrada única ou composto. A expressão numérica nPath pode ter qualquer valor.

# Valor de retorno

Caractere

# Observações

Uma tabela pode ter vários arquivos de índice abertos simultaneamente. No entanto, apenas um arquivo de índice de entrada única (o arquivo de índice controlador) ou tag de um arquivo de índice composto (a tag controladora) controla a ordem em que a tabela é exibida ou acessada. Certos comandos, como SEEK, usam o arquivo de índice controlador ou a tag controladora para pesquisar registros. Esta função retorna o nome do arquivo de índice controlador ou da tag controladora.

USE e SET INDEX suportam abrir mais de um índice com uma lista de arquivos de índice. Um arquivo de índice controlador ou tag controladora pode ser designado nesta lista de arquivos de índice. SET ORDER também pode ser usado para designar um índice controlador ou tag controladora.

Por padrão, ORDER( ) retorna o nome do arquivo de índice controlador ou nome da tag controladora para a área de trabalho atual. ORDER( ) retorna a cadeia vazia se uma ordem não tiver sido definida (SET ORDER TO foi emitido ou não há arquivo de índice controlador ou tag).

# Exemplo

O exemplo a seguir exibe tags e arquivos de índice.

```foxpro
CLOSE DATABASES
OPEN DATABASE (HOME(2) + 'Data\testdata')
USE customer ORDER cust_id && Opens Customer table
? ORDER()  && Displays CUST_ID
? ORDER('customer', 1)  && Displays CUSTOMER.CDX
```
