# Função WMINIMUM( )

Determina se a janela ativa ou especificada está minimizada.

```foxpro
WMINIMUM([WindowName])
```

#### Parâmetros
 **WindowName**
Especifica o nome da janela que WMINIMUM( ) avalia. Você pode especificar o nome de uma janela de sistema do Visual FoxPro (janela Command, janela Data Session, uma janela Browse e assim por diante). Se WindowName for omitido, WMINIMUM( ) retornará um valor lógico para a janela ativa. Você também pode incluir a cadeia de caracteres vazia em WindowName para especificar a janela principal do Visual FoxPro.

# Valor de retorno

Lógico

# Observações

No Visual FoxPro para Windows, as janelas podem ser reduzidas a um ícone.

Uma janela definida pelo usuário criada com DEFINE WINDOW só poderá ser minimizada se a palavra-chave MINIMIZE estiver incluída em sua definição.

WMINIMUM( ) retorna verdadeiro (.T.) se a janela atual ou especificada estiver minimizada; caso contrário, retorna falso (.F.). No Visual FoxPro, você pode incluir o nome de uma barra de ferramentas. Entretanto, WMINIMUM( ) sempre retorna falso (.F.) para uma barra de ferramentas, pois barras de ferramentas não podem ser minimizadas.
