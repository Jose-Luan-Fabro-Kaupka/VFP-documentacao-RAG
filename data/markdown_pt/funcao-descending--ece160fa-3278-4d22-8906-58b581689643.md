# Função DESCENDING( )

Retorna um valor lógico que indica se uma tag de índice foi criada com a palavra-chave DESCENDING ou se a palavra-chave DESCENDING foi incluída em USE, SET INDEX ou SET ORDER.

```foxpro
DESCENDING([CDXFileName[, nIndexNumber [, nWorkArea | cTableAlias]]])
```

#### Parâmetros
 **CDXFileName**
Especifica o nome de um arquivo de índice composto com CDXFileName . O arquivo de índice composto que você especificar pode ser o arquivo de índice composto estrutural aberto automaticamente com a tabela ou um arquivo de índice composto independente.
**nIndexNumber**
Especifica qual tag de índice ou arquivo de índice DESCENDING( ) testa. nIndexNumber é tipicamente um inteiro que começa em 1 e é aumentado em 1 para retornar valores adicionais para cada tag de índice. Se nIndexNumber for 1, um valor para o arquivo de índice .idx de entrada única mestre ou tag de índice mestre (se houver uma) é retornado. Conforme nIndexNumber aumenta, valores para cada tag no índice composto estrutural (se houver um) são retornados. Os valores são retornados para as tags na ordem em que as tags foram criadas no índice composto estrutural. Depois que os valores para todas as tags no índice composto estrutural são retornados, valores para cada tag em quaisquer índices compostos independentes abertos são retornados. Os valores são retornados das tags na ordem em que as tags são criadas nos índices compostos independentes. A cadeia de caracteres vazia é retornada se nIndexNumber for maior que o número total de arquivos .idx de entrada única abertos e tags de índice compostos estruturais e independentes.
**nWorkArea | cTableAlias**
Retorna valores para arquivos de índice ou tags abertos em uma área de trabalho diferente da área de trabalho atual. nWorkArea especifica o número da área de trabalho e cTableAlias especifica o alias da tabela. Se nenhuma tabela tiver o alias que você especificar, o Visual FoxPro gera uma mensagem de erro.

# Valor de retorno

Logical

# Observações

Você pode ordenar registros em uma tabela em ordem decrescente de duas maneiras:
 - Você pode incluir a palavra-chave DESCENDING no comando INDEX para criar uma tag de índice em ordem decrescente em um .cdx composto.
- Você pode incluir a palavra-chave DESCENDING em USE, SET INDEX ou SET ORDER para especificar uma ordem decrescente para a tag de índice mestre ou o arquivo de índice de entrada única mestre (.idx).

DESCENDING( ) pode determinar se uma tag de índice foi criada em ordem decrescente. DESCENDING( ) retorna true (.T.) se a tag de índice que você especificar foi criada com a palavra-chave DESCENDING.

DESCENDING( ) também pode determinar se a tag de índice mestre ou o arquivo de índice mestre está em ordem decrescente. DESCENDING( ) retorna true (.T.) se a palavra-chave DESCENDING foi incluída em USE, SET INDEX ou SET ORDER para a tag de índice mestre ou um arquivo de índice de entrada única (.idx) que você especificar.

Se você não incluir nenhum dos argumentos opcionais, DESCENDING( ) retorna um valor para a tag de índice mestre ou arquivo de índice mestre. Se você não incluir nenhum dos argumentos opcionais e uma tag de índice mestre ou arquivo .idx não estiver em vigor (por exemplo, você emitiu SET ORDER TO para colocar a tabela em ordem física de registros), DESCENDING( ) retorna false (.F.).

# Exemplo

O exemplo a seguir abre a tabela `customer` no banco de dados `testdata`. FOR ... ENDFOR é usado para criar um loop no qual o status decrescente de cada tag de índice no índice estrutural `customer` é verificado. O nome de cada tag de índice estrutural é exibido com seu status decrescente.

```foxpro
CLOSE DATABASES
OPEN DATABASE (HOME(2) + 'Data\testdata')
USE Customer     && Open customer table
CLEAR
FOR nCount = 1 TO TAGCOUNT()
   IF !EMPTY(TAG(nCount))  && Checks for tags in the index
   ? TAG(nCount) + ' Descending? ' && Display tag name
   ?? DESCENDING(nCount)  && Display descending status
   ELSE
      EXIT  && Exit the loop when no more tags are found
   ENDIF
ENDFOR
```
