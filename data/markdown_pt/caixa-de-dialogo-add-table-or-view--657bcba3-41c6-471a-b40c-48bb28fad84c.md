# Caixa de diálogo Add Table or View

Aparece quando você seleciona Query ou Local View na caixa de diálogo New e depois escolhe New File. Nesta caixa de diálogo, você seleciona uma ou mais tabelas ou views existentes nas quais basear sua nova consulta ou view local.
 **Database**
Exibe o banco de dados atual por padrão e permite selecionar outro banco de dados.
**Tables/Views in database**
Exibe as tabelas ou views do banco de dados atual, dependendo se você seleciona a opção Tables ou Views.
**Alias**
Especifica um alias em vez do alias gerado automaticamente para usar na tabela ou view que você selecionar.
**Add**
Adiciona a tabela ou view.
**Other**
Exibe a caixa de diálogo Open, na qual você pode selecionar uma tabela livre para adicionar à consulta.
**Tables**
Exibe as tabelas do banco de dados atual na caixa Tables in database.
**Views**
Exibe as views do banco de dados atual na caixa Views in database.
