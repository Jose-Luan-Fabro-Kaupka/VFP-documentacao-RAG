# Caixa de diálogo Round Rectangle

Especifica a forma exata, a posição e as opções de impressão para controles de retângulo arredondado. Esta caixa de diálogo aparece quando você desenha um retângulo arredondado em um relatório ou etiqueta e depois clica duas vezes nele enquanto ele está selecionado.

> **Observação:** Dependendo da configuração da variável de sistema _REPORTBUILDER, esta caixa de diálogo pode ser substituída por uma interface de usuário alternativa. Para obter mais informações, consulte a variável de sistema _REPORTBUILDER .

# Style
 **Style**
Especifica o estilo do retângulo arredondado.

# Object Position
 **Float**
Especifica que o controle se move para baixo na página quando um controle que aparece acima dele se estende para baixo.
**Fix Relative to Top of Band**
Especifica que o controle permaneça em posição relativa ao topo da faixa que o contém.
**Fix Relative to Bottom of Band**
Especifica que o controle permaneça em posição relativa à parte inferior da faixa que o contém.

# Stretch Downwards
 **No Stretch**
Especifica que o retângulo arredondado não se estenda verticalmente conforme a faixa se estende para exibir dados de campo.
**Stretch Relative to Tallest Object In Group**
Especifica que o retângulo arredondado se estenda para acomodar o objeto mais alto no grupo.
**Stretch Relative to Height of Band**
Especifica que o retângulo arredondado se estenda para caber na faixa.

# Print When

Exibe a caixa de diálogo Print When para que você possa controlar exatamente quando o retângulo arredondado é impresso no seu relatório ou etiqueta.

# Comment

Permite adicionar comentários ao arquivo .frx ou .lbx. Os comentários servem apenas para referência e não aparecem em nenhum lugar no relatório ou etiqueta impressa.
