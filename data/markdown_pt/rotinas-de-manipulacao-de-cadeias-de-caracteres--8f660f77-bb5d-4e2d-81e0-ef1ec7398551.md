# Rotinas de manipulação de cadeias de caracteres

Essas rotinas de API permitem manipular cadeias de caracteres.
 **_StrCmp( ) API Library Routine**
Compara duas cadeias de caracteres terminadas em nulo.
**_StrCpy( ) API Library Routine**
Copia uma cadeia de caracteres terminada em nulo de src para dest.
**_StrLen( ) API Library Routine**
Retorna o comprimento em bytes de uma cadeia de caracteres terminada em nulo.
