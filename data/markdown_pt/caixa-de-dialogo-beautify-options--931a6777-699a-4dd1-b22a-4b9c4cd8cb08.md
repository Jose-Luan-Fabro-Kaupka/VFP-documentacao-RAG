# Caixa de Diálogo Beautify Options

Permite especificar estilos de capitalização e indentação para código de programa exibido em uma janela de edição. Quando um arquivo de programa está aberto na janela de edição, selecionar o comando Beautify no menu Tools abre a caixa de diálogo Beautify Options.

# Capitalization
 **Keywords**
Fornece maneiras de formatar palavras-chave: UPPERCASE, lowercase, Mixed Case ou No change
**Symbols**
Fornece maneiras de representar símbolos: UPPERCASE, lowercase, Match with first occurrence ou No change. Match with first occurrence afeta apenas os símbolos disponíveis na janela de edição atual.

# Indentation
 **Types of indent**
Fornece maneiras de indentar texto usando Tabs, Spaces ou No Change. Ao selecionar Spaces, digite ou selecione o número de espaços usados para indentar o texto.
**Text to indent**
Permite especificar quais tipos de texto devem ser indentados. Comment Indenta todas as linhas de texto que começam com o identificador de comentário (*). Continuation lines Indenta linhas após o ponto e vírgula (;), que indica a primeira marca de continuação de linha. A indentação para Continuation lines continua no mesmo nível até que uma nova linha de comando seja inserida.
**Extra indent beneath**
Fornece indentação extra para as linhas após o início de procedures e estruturas de controle DO CASE.
