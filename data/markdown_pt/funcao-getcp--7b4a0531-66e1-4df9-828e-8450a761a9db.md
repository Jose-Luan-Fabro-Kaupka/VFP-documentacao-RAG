# Função GETCP( )

Solicita uma página de código exibindo a caixa de diálogo Code Page e retorna o número da página de código escolhida.

```foxpro
GETCP([nCodePage] [, cText] [, cDialogTitle])
```

#### Parâmetros
 **nCodePage**
Especifica o número da página de código selecionada inicialmente quando a caixa de diálogo Code Page é exibida. Se nCodePage for 0 ou se você omitir nCodePage, nenhuma página de código é selecionada quando a caixa de diálogo Code Page é exibida.
**cText**
Especifica o texto exibido na caixa de diálogo Code Page. Se você omitir cText, o Visual FoxPro exibe o seguinte texto: "Please select a code page for cross-platform data sharing."
**cDialogTitle**
Especifica o título que aparece na barra de título da caixa de diálogo Code Page. Se você omitir cDialogTitle, o título "Code Page" é exibido.

# Valor de retorno

Numérico

# Observações

GETCP( ) retorna 0 se você sair da caixa de diálogo Code Page pressionando ESC, escolhendo o botão Cancel ou escolhendo Close no menu Control.

As páginas de código listadas na caixa de diálogo Code Page são determinadas por FOXPRO.INT, o arquivo de suporte a páginas de código internacionais do Visual FoxPro.

Você pode incluir GETCP( ) em comandos como MODIFY COMMAND, APPEND FROM e COPY TO que suportam a cláusula AS nCodePage. A caixa de diálogo Code Page é exibida, permitindo que você especifique a página de código do arquivo aberto, anexado ou criado. Como não existe página de código 0, você deve tratar o valor 0 caso o usuário escolha ESC, o botão Cancel ou Close no menu Control.

# Exemplo

O exemplo a seguir exibe a caixa de diálogo Code Page com a página de código 1252 (Windows ANSI) selecionada. "Select a Code Page" é exibido como a legenda na caixa de diálogo Code Page, e "Code Page Selection" é exibido na barra de título da caixa de diálogo Code Page.

```foxpro
? GETCP(1252, "Select a Code Page", "Code Page Selection")
```
