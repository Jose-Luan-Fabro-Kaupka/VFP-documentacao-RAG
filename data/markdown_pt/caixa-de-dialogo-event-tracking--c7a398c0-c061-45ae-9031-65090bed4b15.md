# Caixa de diálogo Event Tracking

Permite ver quando cada evento ocorre em relação a outros eventos. Use esta caixa de diálogo para determinar o local mais eficiente para incluir seu código.

Esta caixa de diálogo aparece quando você escolhe Event Tracking no menu Tools, Debugger Window.
 **Turn event tracking on**
Alterna o rastreamento de eventos ativado ou desativado. Quando o rastreamento de eventos está habilitado, sempre que um evento do sistema na lista Events to track ocorre, o nome do evento é exibido na janela Debug Output ou gravado em um arquivo.
**Available events**
Exibe todos os eventos disponíveis que não estão selecionados para rastreamento. Dica Se você não está trabalhando especificamente com movimentos do mouse, remova o evento MouseMove da lista Events to track. Eventos MouseMove normalmente ocorrem com muita frequência.
**Events to track**
Exibe todos os eventos que você deseja rastrear.

# Send Output To
 **Debugger Output Window**
Alterna se os eventos rastreados são listados na janela Debug Output. Se a janela Debug Output não estiver aberta, os eventos não serão listados, mesmo se a caixa Debug Output Window estiver marcada.
**File**
Especifica um arquivo para o qual os eventos rastreados serão gravados. O botão de diálogo permite selecionar um arquivo na caixa de diálogo Open.
**Append**
Especifica que os eventos rastreados são gravados após o conteúdo atual de um arquivo existente, preservando o conteúdo original.
**Overwrite**
Especifica que os eventos rastreados substituem o conteúdo do arquivo especificado.
