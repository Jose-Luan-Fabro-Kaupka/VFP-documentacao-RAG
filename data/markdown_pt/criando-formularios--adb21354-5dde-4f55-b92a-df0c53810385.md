# Criando formulários

Você pode usar formulários para dar aos seus usuários uma interface familiar para visualizar e inserir dados em um banco de dados, mas formulários fornecem muito mais do que apenas uma interface. Formulários fornecem um conjunto rico de objetos que podem responder a eventos do usuário (ou do sistema), para que você possa permitir que seus usuários realizem suas tarefas de gerenciamento de informações da forma mais fácil e intuitiva possível.

# Seções relacionadas
 **Criando a interface do usuário**
Usando formulários, classes, controles, menus e barras de ferramentas do Visual FoxPro, você pode construir interfaces que ajudam os usuários a acessar todo o potencial de seus programas.
**Trabalhando com formulários**
Depois de criar seu formulário, você pode executá-lo, ocultá-lo ou alterá-lo de diferentes maneiras.
**Usando controles**
Controles gerenciam as interações entre usuários e seu aplicativo. O Visual FoxPro oferece uma variedade de controles para aprimorar a interface do seu aplicativo.
**Projetando menus e barras de ferramentas**
Um bom sistema de menus diz muito aos seus usuários sobre o design e a estrutura do seu aplicativo. Planejar menus e barras de ferramentas com cuidado pode melhorar a usabilidade do seu aplicativo e fornecer acesso imediato a tarefas comuns.
