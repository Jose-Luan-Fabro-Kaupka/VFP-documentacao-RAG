# Como: visualizar informações de biblioteca de tipos

Bibliotecas de tipos são arquivos de definição de componentes COM que incluem informações sobre tipos e objetos expostos por uma aplicação OLE. Uma biblioteca de tipos pode ser um arquivo binário (.tlb) autônomo, compilado em um arquivo de aplicação (.exe), incorporado em um controle ActiveX (.ocx) ou incluído em um arquivo de biblioteca de vínculo dinâmico (.dll ou DLL). Arquivos DLL com uma ou mais bibliotecas de tipos são frequentemente compilados como bibliotecas de objetos (.olb).

### Para visualizar informações de biblioteca de tipos
- Na Object Browser Window, escolha Open Type Library.
- Na caixa de diálogo Open, selecione a guia que dará acesso à biblioteca desejada. A guia Recent History lista as bibliotecas abertas mais recentemente. A guia COM libraries lista as bibliotecas disponíveis e fornece um botão Browse para que você possa encontrar a biblioteca desejada. Current Selection lista quaisquer bibliotecas abertas. Na lista suspensa Files of type na caixa de diálogo Open, escolha Application, *.dll, *.ocx, *.olb ou *.tlb.
- Selecione uma biblioteca e clique em OK.

As informações da biblioteca de tipos para o arquivo selecionado são exibidas na lista Classes & Members.
