# Função ASESSIONS( )

Cria um array de IDs de data session existentes.

```foxpro
ASESSIONS(ArrayName)
```

#### Parâmetros
 **ArrayName**
Especifica o array que contém os IDs de data session.

# Valor de retorno

Numeric. Retorna o número de data sessions.

# Observações

Se o array não existir, o Visual FoxPro cria e preenche automaticamente. O Visual FoxPro redimensiona automaticamente o array para acomodar as data sessions atuais.
