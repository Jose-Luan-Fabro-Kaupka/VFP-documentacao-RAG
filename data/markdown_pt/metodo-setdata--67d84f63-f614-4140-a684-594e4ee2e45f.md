# Método SetData

Coloca dados no DataObject de arrastar e soltar OLE. Disponível somente em tempo de execução.

```foxpro
oDataObject.SetData(eData [, nFormat | cFormat])
```

#### Parâmetros
 **eData**
Especifica os dados colocados no DataObject. Se você omitir os argumentos opcionais nFormat e cFormat, o Visual FoxPro coloca os dados no DataObject nos formatos CF_TEXT e CFSTR_OLEVARIANT. Se eData for uma matriz, preceda eData com um e comercial (@). Uma matriz é colocada no DataObject no formato CFSTR_OLEVARIANTARRAY. Um erro é gerado se eData for uma referência de objeto ou um campo general, ou se a matriz contiver uma referência de objeto.
**nFormat | cFormat**
Especifica o formato dos dados colocados no DataObject. A tabela a seguir lista os valores de alguns formatos de dados comuns com uma descrição de cada formato. Você pode especificar um formato definido pelo usuário com cFormat. Nesse caso, eData deve ser do tipo character ou um tipo binário criado com CREATEBINARY( ). Formato de dados* nFormat | cFormat Descrição CF_TEXT 1 Formato de texto. CF_OEMTEXT 7 Formato de texto contendo caracteres no conjunto de caracteres OEM. CF_UNICODETEXT 13 Formato de texto Unicode. Observação Disponível somente para versões do Visual FoxPro executadas no Windows NT 4.0 ou posterior. CF_FILES ou CF_HDROP 15 Um identificador que identifica uma lista de arquivos, como um conjunto de arquivos arrastados do Windows Explorer. CFSTR_OLEVARIANTARRAY "OLE Variant Array" Uma matriz. Vários valores podem ser transferidos em uma única operação de arrastar e soltar com esse formato. Por exemplo, esse formato pode ser usado para arrastar um conjunto de itens em uma caixa de listagem para outra caixa de listagem. CFSTR_OLEVARIANT "OLE Variant" Um variant. Todos os tipos de dados no Visual FoxPro são representados como variants. Esse formato pode ser usado para arrastar e soltar dados do Visual FoxPro sem perder o tipo de dados. CFSTR_VFPSOURCEOBJECT "VFP Source Object" Uma referência ao objeto de origem de arrastar do Visual FoxPro. * Definido em FOXPRO.H.

# Observações

Aplica-se a: Objeto DataObject

O método SetData só pode ser executado nos eventos OLEStartDrag e OLESetData.
