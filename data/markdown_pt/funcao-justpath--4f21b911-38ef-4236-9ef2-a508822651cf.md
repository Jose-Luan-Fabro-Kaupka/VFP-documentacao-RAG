# Função JUSTPATH( )

Retorna a parte do caminho de um nome de arquivo e caminho completo.

```foxpro
JUSTPATH(cFileName)
```

#### Parâmetros
 **cFileName**
Especifica o nome completo (incluindo o caminho) do arquivo para o qual você deseja apenas o caminho. O comprimento máximo da cadeia de caracteres passada a cFileName é de 259 bytes.

# Valor de retorno

Character
