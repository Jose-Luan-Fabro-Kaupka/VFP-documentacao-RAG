# Não é possível localizar a biblioteca ODBC, ODBC32.DLL (Erro 1527)

O arquivo ODBC32.DLL não pode ser encontrado.
 - Este arquivo deve estar no caminho atual para usar recursos de conectividade. Se o arquivo não estiver no seu sistema, reinstale o componente ODBC do Visual FoxPro. Se presente, copie o arquivo para o diretório de sistema padrão.
