# Comando SELECT - SQL

Recupera dados de uma ou mais tabelas. Quando você usa SQL SELECT para criar uma consulta, o Visual FoxPro analisa a consulta e recupera os dados especificados das tabelas. Você pode criar uma consulta SQL SELECT na janela Command, em um programa Visual FoxPro ou usando o Query Designer. Revise o tópico de ajuda Considerations for SQL SELECT Statements para mais informações sobre o uso de SQL SELECT.

A sintaxe completa do comando SQL SELECT aparece da seguinte forma:

```foxpro
SELECT [ALL | DISTINCT] [TOP nExpr [PERCENT]] Select_List_Item [, ...]
   FROM [FORCE] Table_List_Item [, ...]
      [[JoinType] JOIN DatabaseName!]Table [[AS] Local_Alias]
      [ON JoinCondition [AND | OR [JoinCondition | FilterCondition] ...]
   [WITH (BUFFERING = lExpr)]
   [WHERE JoinCondition | FilterCondition [AND | OR JoinCondition | FilterCondition] ...]
   [GROUP BY Column_List_Item [, ...]] [HAVING FilterCondition [AND | OR ...]]
   [UNION [ALL] SELECTCommand]
   [ORDER BY Order_Item [ASC | DESC] [, ...]]
   [INTO StorageDestination | TO DisplayDestination]
   [PREFERENCE PreferenceName] [NOCONSOLE] [PLAIN] [NOWAIT]
```

# Observações

O código a seguir mostra um resumo das principais cláusulas:

```foxpro
SELECT Select_List
   FROM Table_List
   [WITH (BUFFERING = lExpr)]
   [WHERE Conditions]
   [GROUP BY Column_List]
   [UNION Clause]
   [HAVING Conditions]
   [ORDER BY Column_List]
   [INTO Clause | TO Clause ]
   [Additional_Display_Options]
```

As seções a seguir descrevem a sintaxe detalhada e os parâmetros de cada cláusula do comando SQL SELECT:
 - SELECT - SQL Command - SELECT Clause
- SELECT - SQL Command - FROM Clause
- SELECT - SQL Command - WITH Clause
- SELECT - SQL Command - WHERE Clause
- SELECT - SQL Command - GROUP BY Clause
- SELECT - SQL Command - HAVING Clause
- SELECT - SQL Command - UNION Clause
- SELECT - SQL Command - ORDER BY Clause
- SELECT - SQL Command - INTO or TO Clause
- SELECT - SQL Command - Additional Display Options

Quando você emite SET TALK ON e SET NOTIFY ON antes de executar SELECT, o Visual FoxPro exibe o tempo que a consulta levou para executar e o número de registros nos resultados. _TALLY contém o número de registros nos resultados da consulta. Para mais informações, consulte SET TALK Command, SET NOTIFY Command e _TALLY System Variable.

> **Observação:** O tempo pode não ser exibido se o tempo de execução da consulta for muito curto.

SELECT não respeita a condição de filtro atual especificada com SET FILTER. Para mais informações, consulte SET FILTER Command.

# Exemplos

Os exemplos de código a seguir mostram muitas maneiras de recuperar dados com o comando SQL SELECT e usam o banco de dados de exemplo TestData.dbc incluído no Visual FoxPro.

### Exemplo 1

O exemplo a seguir exibe dados de um campo em uma tabela usando a cláusula FROM. O exemplo exibe todos os nomes de empresa no campo Company da tabela Customer:

```foxpro
CLOSE ALL
CLOSE DATABASES
OPEN DATABASE (HOME(2) + 'Data\TestData')
SELECT customer.company ;
   FROM customer
```

### Exemplo 2

O exemplo a seguir exibe todos os registros de uma consulta em uma coluna especificada usando a cláusula AS Column_Name. O exemplo exibe todos os nomes no campo City da tabela Customer em maiúsculas usando a função UPPER( ) e em uma coluna chamada CityList.

```foxpro
CLOSE ALL
CLOSE DATABASES
OPEN DATABASE (HOME(2) + 'Data\TestData')
SELECT UPPER(city) AS CityList FROM customer
```

### Exemplo 3

O exemplo a seguir exibe dados exclusivos de uma consulta usando a opção DISTINCT com uma condição de join na cláusula WHERE. O exemplo exibe os campos Company, Order_Date e Shipped_On somente para registros com dados exclusivos nas tabelas Customer e Orders. A instrução SELECT especifica aliases locais para as tabelas para distinguir o mesmo nome de campo, Cust_ID, em ambas as tabelas.

```foxpro
CLOSE ALL
CLOSE DATABASES
OPEN DATABASE (HOME(2) + 'Data\TestData')
SELECT DISTINCT TAlias1.company, TAlias2.order_date, ;
   TAlias2.shipped_on ;
   FROM customer TAlias1, orders TAlias2 ;
   WHERE TAlias1.cust_id = TAlias2.cust_id
```

### Exemplo 4

O exemplo a seguir exibe três campos de duas tabelas, mas somente registros que atendem às condições de join e filtro na cláusula WHERE. O exemplo une as tabelas Customer e Orders no campo Cust_ID e exibe os campos Company, Order_Date e Shipped_On somente para registros com data de pedido anterior a 02/16/1994. A instrução SELECT especifica aliases locais para as tabelas para distinguir o mesmo nome de campo, Cust_ID, em ambas as tabelas.

```foxpro
CLOSE ALL
CLOSE DATABASES
OPEN DATABASE (HOME(2) + 'Data\TestData')
SELECT TAlias1.company, TAlias2.order_date, TAlias2.shipped_on ;
   FROM customer TAlias1, orders TAlias2 ;
   WHERE TAlias1.cust_id = TAlias2.cust_id ;
   AND TAlias2.order_date < {^1994-02-16}
```

### Exemplo 5

O exemplo a seguir organiza os resultados de uma consulta usando a cláusula ORDER BY Order_Item. O exemplo exibe os campos Country, PostalCode e Company para registros na tabela Customer em ordem ascendente, por padrão.

```foxpro
CLOSE ALL
CLOSE DATABASES
OPEN DATABASE (HOME(2) + 'Data\TestData')
SELECT country, postalcode, company ;
   FROM customer ;
   ORDER BY country, postalcode, company
```

### Exemplo 6

O exemplo a seguir armazena o conteúdo de uma consulta em uma tabela usando a cláusula INTO TABLE TableName. O exemplo armazena o conteúdo dos campos Company, Order_Date e Shipped_On das tabelas Customer e Order, que são unidas no campo Cust_ID, em uma terceira tabela chamada CustShip. O exemplo então abre uma janela Browse para a nova tabela. A instrução SELECT especifica aliases locais para as tabelas para distinguir o mesmo nome de campo, Cust_ID, em ambas as tabelas.

```foxpro
CLOSE ALL
CLOSE DATABASES
OPEN DATABASE (HOME(2) + 'Data\TestData')
SELECT TAlias1.company, TAlias2.order_date, TAlias2.shipped_on ;
   FROM customer TAlias1, orders TAlias2 ;
   WHERE TAlias1.cust_id = TAlias2.cust_id ;
   INTO TABLE custship.dbf
BROWSE
```
