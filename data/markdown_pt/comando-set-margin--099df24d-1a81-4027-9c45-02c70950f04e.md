# Comando SET MARGIN

Define a margem esquerda da impressora e afeta toda a saída direcionada a ela.

```foxpro
SET MARGIN TO nColumns
```

#### Parâmetros
 **nColumns**
Especifica a margem esquerda em colunas. O padrão é 0 coluna; o máximo é 256.

# Observações

Se você usar SET MARGIN para ajustar a margem esquerda, o valor especificado será armazenado na variável de sistema _PLOFFSET. Também é possível definir a margem armazenando um valor diretamente em _PLOFFSET. O valor da variável de sistema _LMARGIN também afeta essa configuração.

> **Observação:** A configuração de margem esquerda especificada em SET MARGIN não afeta relatórios criados com o Designer de Relatórios ou o Designer de Etiquetas e executados com REPORT FORM ou LABEL. A configuração Left Margin da caixa de diálogo Configuração de Página do Relatório, no Designer de Relatórios, determina o deslocamento a partir da borda esquerda do papel. Para obter mais informações, consulte Caixa de diálogo Configuração de Página do Relatório e Guia Layout da Página, caixa de diálogo Propriedades do Relatório (Construtor de Relatórios).
