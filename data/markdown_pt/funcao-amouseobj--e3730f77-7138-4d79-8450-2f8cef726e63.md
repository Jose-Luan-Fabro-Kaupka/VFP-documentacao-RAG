# Função AMOUSEOBJ( )

Cria uma matriz contendo informações sobre a posição do ponteiro do mouse e o objeto sobre o qual o ponteiro do mouse está posicionado.

```foxpro
AMOUSEOBJ(ArrayName [, 1])
```

#### Parâmetros
 **ArrayName**
Especifica o nome da matriz que contém as informações do ponteiro do mouse. Se a matriz especificada não existir, o Visual FoxPro cria automaticamente uma matriz de quatro linhas. Se a matriz existir, o Visual FoxPro a dimensiona para quatro linhas. A tabela a seguir descreve o conteúdo de cada linha na matriz: Linha da matriz Descrição 1 Contém uma referência de objeto ao objeto sobre o qual o ponteiro do mouse está posicionado quando AMOUSEOBJ( ) é executado. 2 Contém uma referência de objeto ao contêiner do objeto sobre o qual o ponteiro do mouse está posicionado quando AMOUSEOBJ( ) é executado. 3 Contém a coordenada horizontal (X) em pixels do ponteiro do mouse, relativa ao contêiner do objeto sobre o qual o ponteiro do mouse está posicionado quando AMOUSEOBJ( ) é executado. 4 Contém a coordenada vertical (Y) em pixels do ponteiro do mouse, relativa ao contêiner do objeto sobre o qual o ponteiro do mouse está posicionado quando AMOUSEOBJ( ) é executado.

> **Observação:** A primeira e a segunda linhas na matriz podem conter os mesmos valores se o mouse estiver posicionado sobre um contêiner genérico, como um pageframe.
 **[, 1]**
Este parâmetro opcional especifica que as informações do ponteiro do mouse contidas na matriz são relativas ao formulário atual (THISFORM). Se você incluir esta opção, a segunda linha da matriz sempre contém uma referência de objeto ao formulário atual, e a terceira e a quarta linhas contêm as coordenadas do ponteiro do mouse relativas ao formulário atual.

# Valor de retorno

Numeric

# Observações

Você também pode usar AMOUSEOBJ( ) para determinar onde posicionar o ponteiro do mouse durante o tempo de design. A tabela a seguir lista o elemento de tempo de design e os valores contidos em cada linha da matriz:

| Elemento de tempo de design | Conteúdo da matriz |
| --- | --- |
| Form and Class Designers | Linha 1 – Referência de objeto ao controle. Linha 2 – Referência de objeto ao formulário. Linha 3 – Coordenada horizontal (X) do ponteiro do mouse relativa ao formulário. Linha 4 – Coordenada vertical (Y) do ponteiro do mouse relativa ao formulário. |
| Project Manager | Linha 1 – Referência de objeto ao projeto. Linha 2 – Referência de objeto ao projeto. Linha 3 – Zero. Linha 4 – Zero. |
| Visual FoxPro Desktop | Linha 1 – Referência de objeto à área de trabalho. Linha 2 – Referência de objeto à área de trabalho. Linha 3 – Coordenada horizontal (X) do ponteiro do mouse relativa à área de trabalho. Linha 4 – Coordenada vertical (Y) do ponteiro do mouse relativa à área de trabalho. |

AMOUSEOBJ( ) retorna 4 (o número de linhas na matriz) se você posicionar o ponteiro do mouse sobre uma área listada acima. Se você posicionar o ponteiro do mouse sobre uma área diferente das listadas acima, AMOUSEOBJ( ) retorna zero. Se a matriz especificada já existir, ela permanece inalterada. Se a matriz especificada não existir, o sistema não a cria.
