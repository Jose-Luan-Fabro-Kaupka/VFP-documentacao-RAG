# Tipo de dados Variant

Variant é um tipo de dados especial que pode conter qualquer tipo de dado, exceto dados de cadeia de caracteres de comprimento fixo. Dados Variant também podem ser os valores especiais Empty, Error e NULL. Este tipo de dados é usado em clientes extrínsecos a aplicativos Visual FoxPro porque o Visual FoxPro não é uma linguagem fortemente tipada.

Para especificações sobre o tipo de dados Variant, consulte Tipos de dados e campos do Visual FoxPro.
