# Aviso: Nenhuma informação disponível para verificar conflitos de atualização remota (Erro 1496)

O driver ODBC não relata o número de registros afetados por um comando UPDATE - SQL Command, DELETE - SQL Command ou INSERT - SQL Command. Conflitos de bloqueio otimista em views remotas que usam esta conexão não serão relatados.

Certifique-se de que seu código de atualização lide com esta limitação.
