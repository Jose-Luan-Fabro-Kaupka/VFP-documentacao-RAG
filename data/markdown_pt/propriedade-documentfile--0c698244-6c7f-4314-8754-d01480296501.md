# Propriedade DocumentFile

Retorna o nome do arquivo a partir do qual um objeto OLE vinculado foi criado. Em tempo de design, especifica o nome do arquivo vinculado. Somente leitura em tempo de design e de execução para um objeto existente, mas pode ser definida ao criar um objeto.

```foxpro
Object.DocumentFile[ = cFileName]
```

# Valor de retorno
**cFileName**
O nome do arquivo ao qual o objeto está vinculado. O nome inclui o caminho completo do arquivo.

# Observações

Aplica-se a: controle OLE Bound | controle OLE Container

DocumentFile contém a cadeia de caracteres vazia para objetos incorporados (não vinculados).

Você define a propriedade DocumentFile de um objeto OLE vinculado usando a caixa de diálogo Insert Object ao adicionar inicialmente um contêiner OLE a um formulário. Também é possível definir essa propriedade ao criar um objeto OLE com o comando APPEND GENERAL ou ao definir o objeto em código como parte de uma definição de classe.

Antes de especificar o conteúdo de um objeto OLE usando a propriedade DocumentFile, especifique o aplicativo servidor de Automation definindo a propriedade OLEClass do objeto.

# Exemplo

O exemplo a seguir adiciona um controle OLE Container a um formulário e usa as propriedades DocumentFile e OleClass para especificar uma planilha do Microsoft Excel como o arquivo a editar e o Microsoft Excel como servidor de Automation.

A propriedade DocumentFile especifica uma planilha chamada Book1.xls no diretório EXCEL da unidade C. Este exemplo não funcionará corretamente se o arquivo e o diretório indicados em DocumentFile não existirem; talvez seja necessário modificar a propriedade para especificar um diretório e um arquivo de planilha existentes.

O método DoVerb é usado para ativar a planilha para edição.

```foxpro
frmMyForm = CREATEOBJECT('form')  && Create a form
frmMyForm.Closable = .F.  && Disable the Control menu box
frmMyForm.AddObject('cmdCommand1','cmdMyCmdBtn')  && Add Command button
frmMyForm.AddObject("oleObject","oleExcelObject")  && Add OLE object
frmMyForm.cmdCommand1.Visible=.T.  && Display the "Quit" Command button
frmMyForm.oleObject.Visible=.T.  && Display the OLE control
frmMyForm.oleObject.Height = 50  && OLE control height
frmMyForm.Show  && Display the form
frmMyForm.oleObject.DoVerb(-1)  && -1 for Edit
READ EVENTS  && Start event processing
DEFINE CLASS oleExcelObject as OLEControl
   OleClass ="Excel.Sheet"  && Server name
   DocumentFile = "C:\EXCEL\BOOK1.XLS"  && This file must exist
ENDDEFINE
DEFINE CLASS cmdMyCmdBtn AS CommandButton  && Create Command button
   Caption = '\<Quit'  && Caption on the Command button
   Cancel = .T.  && Default Cancel Command button (Esc)
   Left = 125  && Command button column
   Top = 210  && Command button row
   Height = 25  && Command button height
   PROCEDURE Click
      CLEAR EVENTS  && Stop event processing, close form
ENDDEFINE
```
