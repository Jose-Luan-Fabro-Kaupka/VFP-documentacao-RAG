# Propriedade VersionProduct

As informações de nome do produto para um projeto.

```foxpro
Object.VersionProduct[ = cProductName]
```

# Valor de retorno
 **cProductName**
Especifica as informações de nome do produto para um projeto. O valor padrão é a cadeia de caracteres vazia.

# Observações

Aplica-se a: Objeto Project (Visual FoxPro)

A propriedade VersionProduct corresponde ao valor do item Product Name na caixa de diálogo EXE Version Dialog Box.
