# Como: adicionar uma definição de etiqueta usando Addlabel.app

Localizado na pasta Visual FoxPro Tools\Addlabel, Addlabel.app permite adicionar tamanhos de etiqueta personalizados à caixa de diálogo de nova etiqueta no label designer adicionando novos tamanhos ao Registro do Windows.

```foxpro
DO Addlabel.app
```

# Adicionando tamanhos de etiqueta

Se você não vir um tamanho de etiqueta de que precisa no Label Designer, pode adicionar tamanhos de etiqueta à caixa de diálogo New Label adicionando novas definições de etiqueta.

### Para adicionar uma definição de etiqueta
- Execute Addlabel.app.
- Na caixa de diálogo Custom Labels, escolha New.
- Na caixa Label Name da caixa de diálogo New Label Definition, insira um nome para a nova definição de etiqueta. Esse nome será exibido na caixa de diálogo New Label quando você criar uma nova etiqueta.
- Nas caixas de texto exibidas sobre a ilustração da etiqueta, digite valores para altura, largura e margens da etiqueta. Você também precisa especificar quantas etiquetas imprimir em uma linha no spinner Number Across.
- Escolha Add.
