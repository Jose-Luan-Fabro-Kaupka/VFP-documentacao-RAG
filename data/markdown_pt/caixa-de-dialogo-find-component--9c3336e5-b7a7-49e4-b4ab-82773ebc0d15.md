# Caixa de diálogo Find Component

Permite que você pesquise catálogos ou pastas por qualquer um de vários critérios. O critério de pesquisa é salvo como uma view que você pode usar novamente.

Esta caixa de diálogo aparece quando você clica no botão Find na barra de ferramentas do Component Gallery. Seus critérios de pesquisa são automaticamente salvos como uma descrição de view antes de você fechar a caixa de diálogo Find Component. Você pode remover quaisquer views de galeria que não precisa mais usando o botão Remove da guia Dynamic views da caixa de diálogo Options.

# Opções da caixa de diálogo
 **Containing**
Especifica uma lista separada por vírgulas de expressões para pesquisar. Você pode usar as mesmas expressões usadas em Como: filtrar a lista de classes do Class Browser .
**Look in**
Uma lista selecionável de catálogos disponíveis e uma opção "all catalogs". Você pode adicionar um novo escopo para a pesquisa.
**Keywords**
Exibe a Caixa de diálogo Keywords para seleção no campo Keywords do catálogo selecionado. Observação Todas as palavras-chave são armazenadas na tabela Keywords.dbf na pasta HOME().

### Campos de pesquisa

Essas caixas de seleção selecionam campos do catálogo destacado:
 **Item Name**
Pesquisa o Name conforme exibido na guia General da caixa de diálogo Item Properties.
**Class Name**
Pesquisa Class Name conforme exibido na guia Class Item da caixa de diálogo Item Properties.
**Description**
Pesquisa a Description conforme exibida na guia General da caixa de diálogo Item Properties.
**Properties**
Pesquisa o conteúdo de Properties conforme exibido na guia Scripts da caixa de diálogo Items Properties.
**File Name**
Pesquisa o nome do arquivo exibido como Class Library na guia Class Items da caixa de diálogo Item Properties.
**Item Types**
Uma lista dos tipos de item padrão e definidos pelo usuário disponíveis para selecionar como destinos de pesquisa.
**Find**
Inicia a pesquisa depois que todos os critérios estão definidos.
**Cancel**
Cancela uma pesquisa.
**New Search**
Limpa os critérios atuais para que você possa iniciar uma nova especificação de pesquisa.
**Result View**
Exibe o nome da view que você está criando ou editando.
