# Criação de aplicativos internacionais

Esta seção descreve como criar aplicativos compatíveis e eficazes em mercados internacionais.

# Nesta seção
 **Como: inserir dados internacionais**
Discute como entender a inserção de dados para aplicativos internacionais.
**Como: definir formatos de data, hora e moeda**
Descreve os vários métodos para localizar formatos de data, hora e moeda.
**Páginas de código no Visual FoxPro**
Explica como os dados armazenados no Visual FoxPro frequentemente são marcados com uma página de código, que é uma tabela de caracteres e números correspondentes na memória que o Microsoft Windows usa para exibir dados corretamente.
**Ordenação de dados em aplicativos internacionais**
Discute ordens de classificação e apresenta métodos para implementar e validar processos de classificação.
**Modificação de aplicativos internacionais**
Descreve como você pode evitar problemas de localização no código observando certas diretrizes.
**Recursos de relatório para aplicativos internacionais**
Discute recursos do Sistema de Relatórios do Visual FoxPro de interesse especial para desenvolvedores de aplicativos internacionais.

# Seções relacionadas
 **Desenvolvimento de aplicativos internacionais**
Descreve o planejamento e o desenvolvimento de aplicativos para distribuição internacional.
**Desenvolvimento de aplicativos Visual FoxPro**
Inclui informações conceituais sobre como desenvolver aplicativos Visual FoxPro, instruções para criar bancos de dados e a interface do usuário, e outras tarefas necessárias para criar aplicativos Visual FoxPro.
**Criação de aplicativos**
Discute como criar aplicativos Visual FoxPro, que podem incluir um ou mais bancos de dados, um programa principal que configura o ambiente do sistema do aplicativo e uma interface do usuário composta por formulários, barras de ferramentas e menus.
