# Função LASTKEY( )

Retorna um inteiro correspondente à última tecla pressionada.

```foxpro
LASTKEY()
```

# Valor de retorno

Numérico

# Observações

Os valores retornados por LASTKEY( ) são os mesmos que os valores retornados por INKEY( ). Consulte a função INKEY( ) para uma lista de teclas e seus valores de retorno.

LASTKEY( ) é atualizado quando você move entre controles.
