# Acessando a API do Visual FoxPro

Se o Visual FoxPro não inclui os recursos que você precisa para seu aplicativo, você pode ampliar as capacidades do Visual FoxPro criando bibliotecas externas, por exemplo, um arquivo de controle Microsoft ActiveX (.ocx) ou um arquivo de biblioteca de vínculo dinâmico (FLL) do Visual FoxPro.

O Visual FoxPro inclui o Library Construction Kit, que contém os arquivos Pro_Ext.h, WinAPIMS.lib e OcxAPI.lib para que você possa criar controles ActiveX e FLLs.

> **Observação:** O Library Construction Kit tem um limite de 65.000 elementos para matrizes.
