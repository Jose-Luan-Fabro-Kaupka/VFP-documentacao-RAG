# Função RATC( )

Retorna a posição numérica da última ocorrência de uma expressão de caractere ou campo memo dentro de outra expressão de caractere ou campo memo.

```foxpro
RATC(cSearchExpression, cExpressionSearched [, nOccurrence])
```

#### Parâmetros
 **cSearchExpression**
Especifica a expressão de caractere que RATC( ) procura em cExpressionSearched .
**cExpressionSearched**
Especifica a expressão de caractere que RATC( ) pesquisa. As expressões de caractere cSearchExpression e cExpressionSearched podem ser campos memo de qualquer tamanho.
**nOccurrence**
Especifica qual ocorrência, começando da direita e movendo-se para a esquerda, de cSearchExpression RATC( ) procura em cExpressionSearched . Por padrão, RATC( ) procura a última ocorrência de cSearchExpression ( nOccurrence é igual a 1). Se nOccurrence for 2, RATC( ) procura a penúltima ocorrência, e assim por diante.

# Valor de retorno

Numeric

# Observações

RATC( ) foi projetada para expressões que contêm caracteres de byte duplo. Se a expressão contém somente caracteres de byte único, RATC( ) é equivalente a RAT( ).

RATC( ) retorna a posição numérica da última ocorrência de uma expressão de caractere ou campo memo dentro de outra expressão de caractere ou campo memo. As expressões de caractere ou campos memo podem conter qualquer combinação de caracteres de byte único e byte duplo.

RATC( ) é o inverso da função AT_C( ): ela pesquisa da direita para a esquerda.

RATC( ) retorna um inteiro indicando a posição do primeiro caractere em cSearchExpression em cExpressionSearched. RATC( ) retorna 0 se cSearchExpression não for encontrado em cExpressionSearched , ou se nOccurrence for maior que o número de vezes que cSearchExpression ocorre em cExpressionSearched.

A pesquisa realizada por RATC( ) diferencia maiúsculas de minúsculas.

Esta função é útil para manipular conjuntos de caracteres de byte duplo para idiomas como Hiragana e Katakana.
