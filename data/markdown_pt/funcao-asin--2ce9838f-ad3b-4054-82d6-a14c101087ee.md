# Função ASIN( )

Retorna em radianos o arco seno de uma expressão numérica.

```foxpro
ASIN(nExpression)
```

#### Parâmetros
 **nExpression**
Especifica a expressão numérica cujo arco seno ASIN( ) retorna. O valor de nExpression pode variar de +1 a –1, e o valor que ASIN( ) retorna pode variar de –pi/2 a +pi/2 ( –1.57079 a 1.57079). O número de casas decimais na exibição do resultado pode ser especificado com SET DECIMALS.

# Valor de retorno

Numérico

# Observações

Use RTOD( ) para converter radianos em graus.

# Exemplo

```foxpro
CLEAR
? RTOD(ASIN(0))  && Returns 0.00
STORE 1 to gnArcAngle
? RTOD(ASIN(gnArcAngle))  && Returns 90.00
? RTOD(ASIN(SQRT(2)/2))  && Returns 45.00
```
