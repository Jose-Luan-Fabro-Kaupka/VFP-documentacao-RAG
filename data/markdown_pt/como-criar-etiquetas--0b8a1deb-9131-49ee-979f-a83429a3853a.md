# Como: criar etiquetas

Você pode criar etiquetas de várias maneiras:
- Crie uma etiqueta simples usando o Label Wizard. Um assistente é a maneira mais fácil de começar a criar uma etiqueta. Você também pode instalar definições de etiqueta padrão, ou modelos, usando o Label Wizard.
- Crie uma etiqueta personalizada ou modifique uma etiqueta existente usando o Label Designer. O Label Designer inicia o processo de criação com um layout de etiqueta em branco. O Label Designer e o Report Designer têm funcionalidades semelhantes, mas diferem na página e no papel padrão que utilizam.

Você pode modificar qualquer arquivo de layout de etiqueta criado com o Label Designer.

# Criando etiquetas com o Label Wizard

Você pode criar etiquetas facilmente usando o Label Wizard. O Label Wizard ajuda a configurar e criar um layout de etiqueta com base nas respostas fornecidas a uma série de perguntas.

> **Observação:** Na primeira vez que você executar o Label Wizard, ele solicitará a instalação dos modelos de etiqueta padrão. Essa operação é executada somente na primeira vez que o assistente é usado.

### Para iniciar o Label Wizard
- Abra o projeto do seu aplicativo.
- No Project Manager, expanda o nó Documents.
- No nó Documents, clique em Labels e depois em New.
- Na caixa de diálogo New Label, clique em Label Wizard.
- Siga as instruções nas telas do assistente.

Para obter mais informações, consulte Label Wizard.

Você também pode iniciar assistentes clicando em Wizards no menu Tools e selecionando um assistente. Depois de criar um layout usando um assistente, personalize-o com o Label Designer.

# Criando etiquetas com o Label Designer

Você pode criar etiquetas personalizadas começando com um layout de etiqueta em branco no Label Designer.

> **Observação:** O Label Designer e o Report Designer têm funcionalidades semelhantes, mas diferem na definição padrão de layout de página utilizada. O Label Designer também permite associar modelos de etiqueta ao Designer, possibilitando subdividir um layout de página em seções de etiqueta predefinidas. Se o Label Designer não oferecer uma seleção de modelos de etiqueta quando você criar uma nova etiqueta, execute o Label Wizard para instalá-los.

### Para iniciar o Label Designer
- Abra o projeto do seu aplicativo.
- No Project Manager, expanda o nó Documents.
- No nó Documents, clique em Labels e depois em New.
- Na caixa de diálogo New Label, clique em New Label. O Label Designer será aberto.

Para obter mais informações, consulte Label Designer.

Você também pode iniciar uma nova etiqueta em branco pelo menu File, clicando em New e, na caixa de diálogo New, em Label e depois em New File.

É possível abrir o Label Designer programaticamente usando os comandos CREATE LABEL e MODIFY LABEL. Para obter mais informações, consulte Comando CREATE LABEL e Comando MODIFY LABEL.
