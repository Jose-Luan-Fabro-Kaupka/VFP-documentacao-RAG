# Amostra Trabalhando com Microsoft Agent

Arquivo: ...\Samples\Solution\FFC\Agent.scx

Esta amostra mostra como adicionar personagens animados aos seus aplicativos usando a tecnologia Microsoft Agent. Esses personagens são semelhantes aos Assistentes do Office e podem executar diversas ações.
 Esta amostra contém as seguintes classes
| Classe | Biblioteca | Descrição |
| --- | --- | --- |
| _agent | _agent.vcx | Fornece métodos para tratar operações com o Microsoft Agent. |

Para obter detalhes sobre todas as classes disponíveis nas classes de fundação, consulte Visual FoxPro Foundation Classes A-Z.
