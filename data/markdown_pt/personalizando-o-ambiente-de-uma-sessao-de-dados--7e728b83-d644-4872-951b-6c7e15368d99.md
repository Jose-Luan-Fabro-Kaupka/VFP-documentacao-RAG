# Personalizando o ambiente de uma sessão de dados

Como as sessões de dados controlam o escopo de certos comandos SET, você pode usar sessões de dados privadas para estabelecer configurações personalizadas de comandos SET em uma única sessão do Visual FoxPro.

Por exemplo, o comando SET EXACT Command, que controla as regras usadas ao comparar cadeias de caracteres de comprimentos diferentes, tem escopo na sessão de dados atual. A configuração padrão de SET EXACT é desligada, o que especifica que, para serem equivalentes, as expressões devem corresponder, caractere por caractere, até que o final das expressões do lado direito seja atingido. Você pode querer habilitar pesquisas "aproximadas" ou equivalentes deixando SET EXACT definido como OFF para a sessão de dados padrão; no entanto, seu aplicativo pode conter um formulário específico que requer correspondências exatas. Você pode definir a propriedade DataSession do formulário que requer correspondências exatas como 2, para habilitar sessões de dados privadas, e então definir SET EXACT como ON para esse formulário. Ao emitir um comando SET apenas para o formulário que usa sessões de dados privadas, você preserva as configurações globais da sessão do Visual FoxPro enquanto habilita configurações de sessão personalizadas para um formulário específico.
