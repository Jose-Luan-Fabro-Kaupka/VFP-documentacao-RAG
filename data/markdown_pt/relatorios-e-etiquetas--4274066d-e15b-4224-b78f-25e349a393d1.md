# Relatórios e etiquetas

Estes comandos permitem criar relatórios e controlar a saída.

| Use | Para |
| --- | --- |
| _ASCIICOLS System Variable | Especificar o número de colunas em um arquivo de texto ASCII criado com a palavra-chave ASCII no comando REPORT FORM. |
| _ASCIIROWS System Variable | Especificar o número de linhas em um arquivo de texto ASCII criado com a palavra-chave ASCII no comando REPORT FORM. |
| \ | \\ Command | Imprimir ou exibir linhas de texto. |
| CREATE LABEL Command | Abrir o Label Designer para criar uma etiqueta em formato padrão ou para projetar uma etiqueta personalizada. |
| CREATE REPORT Command | Abrir o Label Designer para criar uma etiqueta em formato padrão ou para projetar uma etiqueta personalizada. |
| LABEL Command | Enviar etiquetas de um arquivo de etiqueta para o formato de saída especificado. |
| MODIFY LABEL Command | Abrir o Label Designer para criar ou modificar uma etiqueta. |
| MODIFY REPORT Command | Abrir o Report Designer para criar ou modificar um relatório. |
| REPORT FORM Command | Exibir ou imprimir um relatório especificado por um arquivo de definição de relatório (.frx), por exemplo, criado com o comando CREATE REPORT ou MODIFY REPORT. |
