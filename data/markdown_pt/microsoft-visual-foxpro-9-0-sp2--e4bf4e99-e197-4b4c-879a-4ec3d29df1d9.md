# Microsoft Visual FoxPro 9.0 SP2

Bem-vindo ao Microsoft Visual FoxPro. O Visual FoxPro é o sistema de gerenciamento de banco de dados relacional orientado a objetos que permite criar soluções de banco de dados da área de trabalho à Web. O Visual FoxPro oferece recursos poderosos de manipulação de dados, ferramentas de desenvolvimento rápido de aplicativos para máxima produtividade e a flexibilidade necessária para construir todos os tipos de soluções de banco de dados.
