# Função AUSED( )

Coloca aliases de tabela e áreas de trabalho de uma sessão de dados em um array de variáveis.

```foxpro
AUSED(ArrayName [, nDataSessionNumber [, cTableName]])
```

#### Parâmetros
 **ArrayName**
Especifica o nome do array contendo os aliases de tabela e as áreas de trabalho de uma sessão de dados. Se o array especificado não existir, o Visual FoxPro cria o array automaticamente. Se o array existir e não for grande o suficiente para conter todos os aliases de tabela e áreas de trabalho, o Visual FoxPro aumenta automaticamente o tamanho do array. Se o array for maior do que o necessário, o Visual FoxPro trunca o array. Se o array existir e AUSED( ) retornar 0 porque não há tabelas abertas na sessão de dados, o array permanece inalterado. Se o array não existir e AUSED( ) retornar 0, o array não é criado.
**nDataSessionNumber**
Especifica o número da sessão de dados para a qual AUSED( ) retorna os aliases de tabela e as áreas de trabalho. Se você omitir nDataSessionNumber, AUSED( ) retorna informações sobre a sessão de dados atual. Use SET DATASESSION para especificar a sessão de dados atual.
**cTableName**
O array conterá apenas aliases da tabela especificada com cTableName. A sessão de dados atual é usada se você definir nDataSessionNumber como o valor nulo (.NULL.). cTableName pode estar nos seguintes formatos, listados na ordem em que o Visual FoxPro procura tabelas. DatabaseName!TableName ou DatabaseName!ViewName. Path\DatabaseName!TableName ou Path\DatabaseName!ViewName. Nome de tabela ou view definido no contêiner de banco de dados (DBC) no DBC atual na sessão de dados. Nome de tabela simples ou completo.

# Valor de retorno

Numérico

# Observações

AUSED( ) retorna o número de linhas no array, que é idêntico ao número de tabelas abertas na sessão de dados.

AUSED( ) cria um array bidimensional e coloca os aliases das tabelas abertas para a sessão de dados na primeira coluna do array. A segunda coluna do array contém os números de área de trabalho correspondentes das tabelas.

Os aliases de tabela são colocados no array na ordem inversa em que foram abertos. Por exemplo, o primeiro elemento do array contém o alias da última tabela aberta, e o último elemento do array contém o alias da primeira tabela aberta. Essa ordenação é útil ao usar TABLEUPDATE( ) em views que contêm views. Por exemplo:

```foxpro
FOR x = 1 TO AUSED(aTableAliases,1)
   IF CURSORGETPROP( "Buffering", aTableAliases(x) ) > 1 && Buffered
      ? TABLEUPDATE( 0, .T., aTableAliases(x) )
   ENDIF
NEXT
```

# Exemplo

O exemplo a seguir usa AUSED( ) para criar um array chamado `gaInuse` que contém os aliases de tabela e as áreas de trabalho das tabelas abertas na sessão de dados atual. O número de tabelas abertas para a sessão de dados atual é exibido e, em seguida, os aliases de tabela e as áreas de trabalho são exibidos.

```foxpro
OPEN DATABASE (HOME(2) + 'Data\testdata') EXCLUSIVE
USE Customer IN 0
CLEAR
? AUSED(gaInuse)
DISPLAY MEMORY LIKE gaInuse
CLOSE DATABASES
```
