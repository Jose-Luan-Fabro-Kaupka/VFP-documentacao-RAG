# Referência de linguagem (Visual FoxPro)

Você pode usar a interface do Visual FoxPro para executar muitas tarefas de banco de dados e desenvolver aplicações para catalogar, rastrear e processar informações. Conhecer mais sobre a linguagem de programação do Visual FoxPro aprimora sua capacidade de acessar o poder do Visual FoxPro.

Como outras linguagens de programação, a linguagem de programação do Visual FoxPro permite trabalhar com vários tipos de dados, como números e cadeias de caracteres. Você pode armazenar dados desses vários tipos em tabelas, matrizes, variáveis e outros contêineres de dados. Para manipular dados, você pode executar operações, como adição e concatenação. Além de operadores, o Visual FoxPro fornece um conjunto rico de comandos e funções, para que você possa proteger, exibir e gerenciar seus dados.

Esta seção contém informações sobre elementos da linguagem de programação no Visual FoxPro.
