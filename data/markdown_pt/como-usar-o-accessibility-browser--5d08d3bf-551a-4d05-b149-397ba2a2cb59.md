# Como: usar o Accessibility Browser

Você pode usar o Accessibility Browser para ajudar a desenvolver aplicativos mais acessíveis a pessoas com deficiência, escrever suítes de testes automatizados ou selecionar e comprar software de teste pronto para uso. Você pode usar o Accessibility Browser para examinar as propriedades IAccessible de objetos e como os objetos se relacionam entre si.

### Para iniciar o Accessibility Browser
- No menu Program, selecione Do .
- Na caixa de diálogo Do, procure no diretório Microsoft Visual FoxPro, ..\Tools\MSAA\ , o arquivo accbrow.app .
- Selecione o arquivo e clique em Do .

Para obter mais informações, consulte Accessibility Browser Window.

Seguindo práticas de design de acessibilidade e usando Active Accessibility quando necessário, você pode tornar os aplicativos mais acessíveis. Para obter mais informações, consulte Accessibility for People with Disabilities (Visual FoxPro).
