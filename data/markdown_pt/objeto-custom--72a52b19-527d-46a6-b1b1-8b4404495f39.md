# Objeto Custom

Cria um objeto personalizado definido pelo usuário.

```foxpro
Custom
```

# Observações

Uma classe personalizada definida pelo usuário pode ser criada com DEFINE CLASS ou com o Class Designer. Emita CREATE CLASS para exibir o Class Designer.

Classes personalizadas definidas pelo usuário são classes com propriedades, eventos e métodos, mas sem representação visual. As mesmas regras gerais que se aplicam à definição de outros tipos de classes se aplicam à definição de classes personalizadas.

Consulte Object-Oriented Programming para obter informações adicionais sobre a criação de objetos personalizados como classes não visuais.
