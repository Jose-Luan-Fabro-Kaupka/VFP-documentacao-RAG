# Guia Selection, caixa de diálogo Multiple Selection (Report Builder)

Permite revisar os controles atualmente selecionados no layout do relatório. Você pode:
 - Ordenar a lista por tipo de controle ou localização.
- Remover controles da lista se decidir que não devem mais ser incluídos na seleção.
 **Object**
Lista os controles de relatório selecionados no designer.
**Start band**
Indica a banda do layout do relatório na qual a borda superior do controle de relatório está localizada. (Alguns controles podem abranger várias bandas de relatório.)
**Sort by: Type**
Reexibe a lista de objetos por tipo de controle.
**Sort by: Location**
Reexibe a lista de objetos por localização do controle, ou seja, a banda na qual o topo do controle está posicionado.
**Remove from list**
Remove elementos destacados da lista de controles de relatório atualmente selecionados. Habilitado somente se a lista tiver elementos destacados.
