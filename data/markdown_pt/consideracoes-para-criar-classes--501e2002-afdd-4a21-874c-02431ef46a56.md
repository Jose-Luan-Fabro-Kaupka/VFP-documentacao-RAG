# Considerações para criar classes

Há muitos contextos diferentes para criar e usar classes e subclasses. No entanto, usando planejamento estratégico, você pode determinar com mais eficácia quais classes precisa projetar e o tipo de funcionalidade a incluir nessas classes. Ao criar classes, lembre-se das seguintes considerações.
 - Seja seletivo ao criar classes. Embora você possa criar uma classe para cada controle e formulário que possa querer usar, essa estratégia pode não ser a forma mais eficaz de projetar sua aplicação. O resultado pode ser que você tenha muitas classes que executam a mesma tarefa, mas precisam ser mantidas separadamente.
- Crie e use classes de controle para encapsular funcionalidade genérica. Você pode fornecer funcionalidade genérica em sua aplicação criando classes de controle. Por exemplo, você pode criar botões de comando que os usuários clicam para mover ponteiros de registro em tabelas, fechar formulários ou abrir um arquivo de Help e salvá-los como classes para que possa adicionar os controles a formulários. Você pode expor propriedades e métodos em uma classe para que o usuário possa integrá-los no ambiente de dados específico de um formulário ou form set.
- Determine a funcionalidade que deseja incluir para classes no nível da classe, no nível da subclasse e no nível do objeto com antecedência. Quando você cria subclasses e objetos das classes que cria, pode incluir propriedades, métodos e eventos adicionais nessas subclasses e, por extensão, nos objetos criados a partir dessas classes. Você também pode optar por substituir valores de propriedade padrão, bem como código de métodos e eventos conforme especificado pela classe original.
- Forneça uma aparência e comportamento consistentes para sua aplicação. Você pode criar classes de formulário, form set e controle com uma aparência distintiva para que todos os componentes da sua aplicação tenham a mesma aparência. Por exemplo, você pode adicionar gráficos e padrões de cores específicos a uma classe de formulário e usar essa classe como modelo para todos os formulários que criar. Você pode criar uma classe de caixa de texto com uma aparência distintiva, como um efeito de sombra, e usar essa classe em toda a sua aplicação sempre que quiser adicionar uma caixa de texto.
