# Como: adicionar controles Label a relatórios

Você pode exibir texto que aparece da mesma forma sempre que gerar relatórios ou etiquetas adicionando controles Label ao layout de página.

Por exemplo, suponha que você tenha um controle Field que contém uma expressão para calcular um total. Você pode exibir o texto "Grand Total" em um controle Label para identificar o conteúdo de um controle Field como um total.

### Para adicionar um controle Label a um layout de relatório
- Abra o relatório ou etiqueta no designer apropriado.
- No menu Report, aponte para Insert Control e clique em Label. Um cursor de edição pisca no layout do relatório. Digite os caracteres da etiqueta. Dica Você também pode adicionar controles Label na posição desejada selecionando-os na barra de ferramentas Report Controls e desenhando-os. Depois de adicionar o controle, você pode movê-lo arrastando-o para a posição desejada.

Para obter mais informações, consulte Guia General, caixa de diálogo Report Control Properties (Report Builder).

### Para editar o caption de um controle label
- Abra o relatório ou etiqueta no designer apropriado.
- No designer, clique duas vezes no controle de relatório Label desejado. A caixa de diálogo Label Properties é aberta. Observação Se a variável de sistema _REPORTBUILDER não estiver definida para o Report Builder padrão ou estiver definida para um builder de terceiros, a caixa de diálogo Text é exibida ou uma caixa de diálogo diferente pode ser exibida. Se a caixa de diálogo Text aparecer, edite o texto no controle de relatório Label clicando em Label na barra de ferramentas Report Controls e depois no controle Label que deseja editar no designer. Quando terminar de digitar, clique fora do controle Label. Para obter mais informações, consulte Variável de sistema _REPORTBUILDER.
- Na caixa de diálogo Label Properties, clique na guia General se ela não estiver selecionada.
- Na caixa Caption na guia General, digite as alterações no texto. Para visualizar e editar o texto completo do controle de relatório Label, clique no botão de reticências ( … ) para abrir uma caixa de diálogo de editor.
- Quando terminar, clique em OK. O texto atualizado aparece no controle.

Para obter mais informações, consulte Guia General, caixa de diálogo Report Control Properties (Report Builder).
