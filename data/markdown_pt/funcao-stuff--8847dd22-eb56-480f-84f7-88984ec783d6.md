# Função STUFF( )

Retorna uma cadeia de caracteres criada substituindo um número especificado de caracteres em uma expressão de caracteres por outra expressão de caracteres.

```foxpro
STUFF(cExpression, nStartReplacement, nCharactersReplaced, cReplacement)
```

#### Parâmetros
 **cExpression**
Especifica a expressão de caracteres na qual a substituição ocorre.
**nStartReplacement**
Especifica a posição em cExpression onde a substituição começa.
**nCharactersReplaced**
Especifica o número de caracteres a serem substituídos. Se nCharactersReplaced for 0, a cadeia de substituição cReplacement é inserida em cExpression .
**cReplacement**
Especifica a expressão de caracteres de substituição. Se cReplacement for a cadeia vazia, o número de caracteres especificado por nCharactersReplaced é removido de cExpression .

# Valor de retorno

Caractere

# Exemplo

```foxpro
STORE 'abcdefghijklm' TO gcString1
STORE '12345' TO gcString2
CLEAR
? STUFF(gcString1, 4, 0, gcString2)     && insert
? STUFF(gcString1, 4, 3, gcString2)     && replace
? STUFF(gcString1, 4, 6, '')     && delete
? STUFF(gcString1, 4, 1, gcString2)     && replace and insert
? STUFF(gcString1, 4, 4, gcString2)     && replace and delete
? STUFF(gcString1, 4, LEN(gcString1), gcString2)   && replace, delete rest
```
