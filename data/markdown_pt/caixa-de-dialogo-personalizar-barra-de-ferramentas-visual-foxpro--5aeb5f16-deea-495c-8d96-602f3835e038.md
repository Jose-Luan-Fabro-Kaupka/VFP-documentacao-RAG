# Caixa de diálogo Personalizar barra de ferramentas (Visual FoxPro)

Permite adicionar e excluir botões da barra de ferramentas. Os botões disponíveis são exibidos por categoria. Clique em um botão para ver sua descrição.

Esta caixa de diálogo aparece quando você escolhe Personalizar na caixa de diálogo Barras de ferramentas.
 **Categorias**
Lista as categorias de botões.
**Botão**
Exibe os botões incluídos na categoria que você seleciona na caixa Categorias. Para adicionar o botão, arraste-o para a barra de ferramentas desejada ou solte-o na área de trabalho do Visual FoxPro para criar uma nova barra de ferramentas.
**Descrição**
Descreve o botão selecionado.

Para obter mais informações, consulte Como: configurar barras de ferramentas do Visual FoxPro.
