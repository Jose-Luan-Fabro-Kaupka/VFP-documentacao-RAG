# Função SEC( )

Retorna a parte dos segundos de uma expressão DateTime.

```foxpro
SEC(tExpression)
```

#### Parâmetros
 **tExpression**
Especifica a expressão DateTime da qual SEC( ) retorna o segundo. Se tExpression contiver somente uma data e não uma hora, o Visual FoxPro adicionará a tExpression uma hora padrão de 12:00:00 AM (se SET HOURS for 12) ou 00:00:00 (se SET HOURS for 24) para produzir um valor DateTime válido.

# Valor de retorno

Numeric

# Exemplo

O exemplo a seguir exibe a parte dos segundos da hora atual e a parte dos segundos de uma hora específica.

```foxpro
CLEAR
? SEC(DATETIME())
? SEC({^2004-02-16 10:42:16AM})  && Displays 16
```
