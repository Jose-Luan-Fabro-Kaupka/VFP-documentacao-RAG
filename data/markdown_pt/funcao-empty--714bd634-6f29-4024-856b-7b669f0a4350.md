# Função EMPTY( )

Determina se uma expressão é avaliada como vazia.

```foxpro
EMPTY(eExpression)
```

#### Parâmetros
 **eExpression**
Especifica a expressão que EMPTY( ) avalia. Você pode especificar uma expressão dos tipos Character, Numeric, Date, Varbinary, Blob ou Logical, ou o nome de um campo Memo ou General em uma tabela aberta.

# Valor de retorno

Logical. EMPTY( ) retorna True (.T.) se a expressão eExpression for avaliada como vazia; caso contrário, EMPTY( ) retorna False (.F.).

Quando os tipos de expressão são avaliados como os valores na tabela a seguir, EMPTY( ) retorna True (.T.).

| Tipo de expressão | É avaliado como |
| --- | --- |
| Blob | Vazio (0h) ou contém apenas bytes zero, por exemplo, 0h00, 0h000000, e assim por diante |
| Character | Cadeia de caracteres vazia, espaços, tabulações, retornos de carro, quebras de linha ou qualquer combinação desses |
| Currency | 0 |
| Date | Vazio, por exemplo, CTOD('') |
| DateTime | Vazio, por exemplo, CTOT('') |
| Double | 0 |
| Float | 0 |
| General | Vazio (sem objeto OLE) |
| Integer | 0 |
| Logical | False (.F.) |
| Memo | Vazio (sem conteúdo) |
| Numeric | 0 |
| Varbinary | Vazio (0h) ou contém apenas bytes zero, por exemplo, 0h00, 0h000000, e assim por diante |

# Observações

Você não pode usar EMPTY( ) para determinar se uma referência de objeto de variável está vazia. Por exemplo, uma variável pode conter uma referência de objeto para um formulário. Se o formulário for fechado clicando em Close no menu pop-up do formulário ou emitindo CLEAR WINDOWS, a variável contém o valor nulo.

O exemplo de programa a seguir demonstra como usar TYPE( ) e ISNULL( ) para determinar se uma referência de objeto de variável é válida.

```foxpro
goMyForm = CREATEOBJECT('Form')
WAIT WINDOW IIF(TYPE('goMyForm') = 'O' AND !ISNULL(goMyForm), ;
   'goMyForm has valid object reference',;
   'goMyForm does not have valid object reference')
```

# Exemplo

O exemplo a seguir abre a tabela `customer` no banco de dados `testdata`. FOR ... ENDFOR é usado para criar um loop no qual EMPTY( ) é usado para determinar se TAG( ) retorna a cadeia de caracteres vazia. O nome de cada tag de índice estrutural é exibido com seu status de candidato.

```foxpro
CLOSE DATABASES
OPEN DATABASE (HOME(2) + 'data\testdata')
USE customer     && Open customer table
FOR nCount = 1 TO TAGCOUNT()
   IF !EMPTY(TAG(nCount))  && Checks for empty string
   ? TAG(nCount)  && Display tag name
   ? CANDIDATE(nCount)  && Display candidate status
   ELSE
      EXIT  && Exit the loop when no more tags are found
   ENDIF
ENDFOR
```
