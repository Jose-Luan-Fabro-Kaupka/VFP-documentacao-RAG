# Função HOME( )

Retorna os nomes dos diretórios do Visual FoxPro e do Visual Studio.

```foxpro
HOME([nLocation])
```

#### Parâmetros
 **nLocation**
Especifica que HOME( ) retorna o nome de um diretório específico do Visual FoxPro ou do Visual Studio. Omitir nLocation é idêntico a HOME(0). A tabela a seguir lista os valores de nLocation e o diretório que HOME( ) retorna. Os diretórios listados abaixo assumem que você escolheu o diretório de instalação padrão ao instalar o Visual FoxPro ou o Visual Studio. nLocation Diretório 0 ou omitido O diretório a partir do qual o Visual FoxPro foi iniciado 1 O diretório no qual o Visual FoxPro está instalado 2 O diretório que contém os exemplos do Visual FoxPro. Este diretório é idêntico ao diretório de exemplos na variável de sistema _SAMPLES. 3 Diretório Common do Visual Studio 4 Diretório Graphics do Visual FoxPro 5 Diretório MSDN do Visual Studio 6 Diretório Tools do Visual Studio 7 Subdiretório Visual FoxPro no diretório Application Data do Visual FoxPro do usuário 8 Subdiretório Projects do Visual FoxPro no diretório My Documents do Visual FoxPro do usuário. Este diretório é o local padrão para novos projetos e arquivos criados pelo Visual FoxPro.

# Valor de retorno

Tipo de dados Character. HOME( ) retorna os nomes de diretórios específicos do Visual FoxPro e do Visual Studio.

# Exemplo

```foxpro
CLEAR
? 'Visual FoxPro startup directory:           ', HOME()
? 'Visual FoxPro installation directory:      ', HOME(1)
? 'Visual FoxPro samples directory:           ', HOME(2)
? 'Visual Studio common directory:            ', HOME(3)
? 'Visual FoxPro graphics directory:          ', HOME(4)
? 'MSDN samples directory:                    ', HOME(5)
? 'Visual Studio tools directory:             ', HOME(6)
? 'Visual FoxPro user app data subdirectory:  ', HOME(7)
? 'Visual FoxPro user documents subdirectory: ', HOME(8)
```
