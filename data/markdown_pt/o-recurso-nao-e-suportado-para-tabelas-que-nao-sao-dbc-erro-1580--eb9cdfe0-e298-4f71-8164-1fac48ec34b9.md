# O recurso não é suportado para tabelas que não são .DBC (Erro 1580)

Você tentou implementar um recurso, como um campo anulável, uma chave primária, um relacionamento persistente, um valor padrão, uma regra de validação ou um trigger, em uma tabela livre. Esses recursos estão disponíveis apenas para tabelas contidas em um banco de dados (.dbc).

Use o Comando ADD TABLE para adicionar uma tabela livre a um banco de dados.
