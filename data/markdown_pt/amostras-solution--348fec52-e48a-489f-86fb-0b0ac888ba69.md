# Amostras Solution

As amostras Solution do Visual FoxPro demonstram recursos específicos do Visual FoxPro e podem ser executadas independentemente. As amostras Solution também incluem exemplos baseados nas Visual FoxPro Foundation Classes A-Z.

Você pode executar amostras Solution do Visual FoxPro no Visual FoxPro Task Pane Manager, que inclui funcionalidade para pesquisar e instalar amostras adicionais. Você também pode executar as amostras Solution a partir do aplicativo de amostra Solution localizado em ...\Samples\Solution\Solution.app.
