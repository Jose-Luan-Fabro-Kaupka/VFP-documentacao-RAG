# Não é possível adicionar este objeto a um Grid (Erro 1768)

Você tentou executar o método Grid.AddObject para adicionar um objeto que não é uma coluna ao grid.
 - Você está tentando adicionar um objeto a uma coluna, em vez de adicionar uma coluna ao grid. Para adicionar um objeto a uma coluna, use a sintaxe Grid.Column com o método AddObject.
