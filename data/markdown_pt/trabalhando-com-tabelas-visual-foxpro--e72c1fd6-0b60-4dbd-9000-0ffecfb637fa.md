# Trabalhando com tabelas (Visual FoxPro)

O Visual FoxPro usa tabelas para armazenar dados em formato de linhas e colunas. Essas linhas e colunas são conhecidas como registros e campos, respectivamente. Construir bancos de dados também inclui criar tabelas. Ao projetar seu banco de dados, você determinou os itens necessários em bancos de dados, como tabelas, campos e relacionamentos, para seu aplicativo. Ao criar tabelas, você faz escolhas mais específicas sobre os detalhes desses itens, por exemplo, tipos de dados, legendas e possíveis valores padrão para cada campo, triggers para cada tabela e índices de tabela necessários para estabelecer relacionamentos entre tabelas.

# Nesta seção
 **Creating Tables**
Apresenta tabelas e considerações para criá-las.
**Managing Tables**
Descreve tarefas para gerenciar e trabalhar com tabelas.
**Working with Fields**
Apresenta a criação e o trabalho com campos em tabelas.
**Working with Records**
Apresenta registros, como visualizá-los e como usá-los para armazenar dados em tabelas.
**Working with Table Indexes**
Explica como controlar a ordem e aumentar a velocidade de processamento de registros em tabelas criando índices.
**Working with Validation Rules**
Apresenta regras de validação para controlar dados inseridos em tabelas de banco de dados.
**Trigger Usage**
Fornece uma descrição de triggers e como são usados e aponta para tópicos sobre criar, modificar, remover e excluir triggers.
