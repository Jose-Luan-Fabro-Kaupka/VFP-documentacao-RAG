# Guia Catalogs, caixa de diálogo Component Gallery Options

Exibe os nomes das views que estão atualmente disponíveis no Component Gallery. Esta é a lista exibida na lista suspensa View Type.

# Opções da guia
 **Global**
Define um catálogo para conter qualquer tipo de pasta. Você pode acessar catálogos globais e seu conteúdo independentemente de quais outros catálogos estão abertos.
**Default**
Permite que um catálogo abra automaticamente quando o Component Gallery inicia. Todos os catálogos marcados como padrão estão disponíveis sempre que você seleciona a view padrão.
**New**
Exibe a caixa de diálogo Open Catalog para que você possa adicionar um catálogo à lista.
