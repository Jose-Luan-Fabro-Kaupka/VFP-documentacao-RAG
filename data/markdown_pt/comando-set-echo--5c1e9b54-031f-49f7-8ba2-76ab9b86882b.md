# Comando SET ECHO

Abre a janela Trace para depuração de programas. Incluído para compatibilidade com versões anteriores.

```foxpro
SET ECHO ON | OFF
```

#### Parâmetros
 **ON**
Exibe o código-fonte do programa em execução na janela Trace. A linha em execução no momento é destacada.
**OFF**
(Padrão) Fecha a janela Trace em versões do FoxPro anteriores à 2.0. Dentro de um programa, a janela Trace pode ser fechada com DEACTIVATE WINDOW TRACE.

# Observações

Você também pode usar a janela Trace para definir pontos de interrupção, que suspendem a execução do programa.

Para obter mais informações sobre a janela Trace, consulte Trace Window.
