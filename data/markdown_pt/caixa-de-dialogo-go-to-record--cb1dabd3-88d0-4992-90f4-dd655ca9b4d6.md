# Caixa de diálogo Go To Record

Especifica para qual registro mover o ponteiro de registro. Digite o número do registro na caixa Record Number ou use as setas para cima e para baixo conforme necessário até que o número desejado seja exibido na caixa Record Number. Escolha OK para retornar à janela Browse com o ponteiro de registro no registro especificado.

Esta caixa de diálogo aparece quando você escolhe o comando Record # no submenu Go to Record.
