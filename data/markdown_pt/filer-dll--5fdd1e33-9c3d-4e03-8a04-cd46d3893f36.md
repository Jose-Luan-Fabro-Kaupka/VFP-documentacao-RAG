# Filer.dll

Localizado no diretório \Tools\Filer do Visual FoxPro, Filer.dll é um componente base que fornece um mecanismo de pesquisa de arquivos e texto sem interface do usuário. Você pode distribuir Filer.dll e seus arquivos complementares, Filer.ico, Filer.scx e Filer.sct, com seus aplicativos de tempo de execução do Visual FoxPro.

> **Observação:** Esses arquivos não são suportados. O suporte técnico não está disponível para problemas que você encontrar ao usar esses arquivos.

Para obter mais informações sobre como usar Filer.dll, consulte as seções a seguir:
 - Criando um objeto Filer
- Criando uma interface do usuário para o Filer
- Usando propriedades e métodos do objeto Filer

# Criando um objeto Filer

Você pode usar Filer.dll para criar programaticamente uma instância do Filer para pesquisar e manipular arquivos sem qualquer entrada do usuário. Filer.dll também inclui suporte para pesquisar cadeias de caracteres de texto em arquivos e abrir vários arquivos para edição.

Filer.dll é um objeto COM e suporta Automation. Portanto, você pode criar uma instância do Filer para outros servidores Automation, como o Microsoft Visual Basic e o Microsoft Excel.

### Para criar uma instância do mecanismo de pesquisa Filer
- Inclua a seguinte linha de código para criar uma instância do Filer. oMyFiler = CREATEOBJECT('Filer.FileUtil')

Para criar uma instância do Filer para outros servidores Automation, você pode usar sintaxe semelhante.

# Criando uma interface do usuário para o Filer

O Visual FoxPro inclui um formulário de exemplo, Filer.scx (e Filer.sct), para mostrar como você pode criar uma interface do usuário para o Filer. Quando você executa o formulário, a caixa de diálogo Localizador de arquivos aparece e o Filer é adicionado ao menu Ferramentas do Visual FoxPro para a sessão atual do Visual FoxPro.

### Para executar o formulário Filer
- Execute o comando DO FORM da seguinte forma: DO FORM (HOME(1) + 'Tools\Filer\Filer.scx')

Para obter mais informações, consulte Caixa de diálogo Localizador de arquivos.

### Para visualizar o código por trás ou modificar o formulário Filer
- Execute o comando MODIFY FORM da seguinte forma: MODIFY FORM (HOME(1) + 'Tools\Filer\Filer.scx')

# Usando propriedades e métodos do objeto Filer

O objeto Filer tem propriedades e métodos que você pode usar, por exemplo, para especificar condições de pesquisa de arquivos e executar uma pesquisa de arquivos.

Ao executar uma pesquisa de arquivos usando o método Filer, Find, um objeto de coleção Files é criado. O objeto de coleção Files tem propriedades que você pode usar para determinar informações sobre os arquivos que correspondem às condições de pesquisa. O objeto de coleção Files também tem métodos que você pode usar para abrir ou excluir arquivos correspondentes.

O exemplo a seguir demonstra como você pode pesquisar e abrir arquivos de texto do Visual FoxPro.

```foxpro
oMyFiler = CREATEOBJECT('Filer.FileUtil')
oMyFiler.SearchPath = HOME() && Point search path to home directory.
oMyFiler.FileExpression = '*.TXT' && Specify text file search.
oMyFiler.Find(0) && Search and discard last collection
FOR nFileCount = 1 TO oMyFiler.Files.Count
   oMyFiler.Files.Item(nFileCount).Edit && Open files.
ENDFOR
```

### Propriedades do objeto Filer

A tabela a seguir descreve as propriedades associadas ao objeto Filer.

| Propriedade | Tipo de dados | Descrição |
| --- | --- | --- |
| SearchPath | C | A pasta a partir da qual a pesquisa começa. Convenções de nomenclatura universal (UNC) são suportadas. Leitura/gravação. |
| FileExpression | C | A máscara de pesquisa de arquivos que pode incluir várias máscaras separadas por ponto e vírgula (;). Por exemplo, a máscara de pesquisa de arquivos *.scx; *.sct especifica pesquisar todos os arquivos com as extensões .scx e .sct. A máscara de pesquisa de arquivos padrão é *.*. Leitura/gravação. |
| SubFolder | N | Um valor numérico que especifica se uma pesquisa recursiva é executada a partir da pasta especificada com a propriedade SearchPath. Se SubFolder for 0, a pesquisa de arquivos é executada apenas na pasta especificada com a propriedade SearchPath. Se SubFolder for 1, a pesquisa de arquivos é executada na pasta especificada com a propriedade SearchPath e em todas as suas subpastas. Observe que o Filer ignora pastas do sistema. O valor padrão é 0. Leitura/gravação. |
| SearchText1 | C | Uma cadeia de caracteres de texto a pesquisar nos arquivos que correspondem à máscara de pesquisa de arquivos especificada pela propriedade FileExpression. O valor padrão é a cadeia de caracteres vazia. Leitura/gravação. |
| SearchText2 | C | Uma cadeia de caracteres de texto adicional a pesquisar nos arquivos que correspondem à máscara de pesquisa de arquivos especificada pela propriedade FileExpression. Ignorada se SearchText1 contiver a cadeia de caracteres vazia. O valor padrão é a cadeia de caracteres vazia. Leitura/gravação. |
| SearchText3 | C | Uma cadeia de caracteres de texto adicional a pesquisar nos arquivos que correspondem à máscara de pesquisa de arquivos especificada pela propriedade FileExpression. Ignorada se SearchText1 e SearchText2 contiverem a cadeia de caracteres vazia. O valor padrão é a cadeia de caracteres vazia. Leitura/gravação. |
| IgnoreCase | N | Um valor numérico que especifica se a capitalização é ignorada para o texto nas cadeias de caracteres especificadas em SearchText1, SearchText2 e SearchText3. Se IgnoreCase for 0, a capitalização não é ignorada (maiúsculas e minúsculas são significativas). Se IgnoreCase for 1, a capitalização é ignorada. O valor padrão é 1. Leitura/gravação. |
| WholeWords | N | Um valor numérico que especifica se o texto nas cadeias de caracteres especificadas em SearchText1, SearchText2 e SearchText3 deve corresponder a palavras inteiras para que a pesquisa seja bem-sucedida. Se WholeWords for 0, o texto nas cadeias de caracteres não precisa corresponder a palavras inteiras para que a pesquisa seja bem-sucedida. Se WholeWords for 1, o texto nas cadeias de caracteres deve corresponder a palavras inteiras para que a pesquisa seja bem-sucedida. O valor padrão é 0. Leitura/gravação. |
| SearchAnd | N | Um valor numérico que especifica se todo o texto nas cadeias de caracteres especificadas em SearchText1, SearchText2 e SearchText3 deve corresponder para que a pesquisa seja bem-sucedida. Se SearchAnd for 0, a pesquisa é bem-sucedida se qualquer texto nas cadeias de caracteres corresponder. Se SearchAnd for 1, a pesquisa é bem-sucedida apenas se todo o texto nas cadeias de caracteres corresponder. O valor padrão é 0. Leitura/gravação. |
| Editor | C | O editor no qual os arquivos são abertos com o método Open da coleção Files. Ignorado se a propriedade IsHostedByFox for 1. O editor padrão é o Notepad. Leitura/gravação. |
| IsHostedByFox | N | Um valor numérico que indica o cliente que instanciou Filer.dll. Se IsHostedByFox for 1, o cliente é o Visual FoxPro e o editor do Visual FoxPro é usado para abrir arquivos. Se IsHostedByFox for 0, o cliente é um aplicativo diferente do Visual FoxPro e o editor usado para abrir arquivos é especificado pela propriedade Editor. O valor padrão é 1 no Visual FoxPro. Leitura/gravação. |
| SortBy | N | Um valor numérico que especifica a ordem em que a coleção Files é ordenada. A tabela a seguir lista os valores da propriedade SortBy e a ordem em que os arquivos são ordenados. 0 Sem ordem 1 Caminho e nome de arquivo 2 Nome de arquivo 3 Extensão de arquivo 4 Tamanho de arquivo 5 Data da última gravação do arquivo 6 Data do último acesso ao arquivo 7 Data de criação do arquivo 8 Atributos de arquivo O valor padrão é 1. Leitura/gravação. |
| SortDirection | N | Um valor numérico que especifica se a coleção Files é ordenada em ordem ascendente ou descendente. Se SortDirection for 0, a coleção Files é ordenada em ordem ascendente. Se SortDirection for 1, a coleção Files é ordenada em ordem descendente. O valor padrão é 0. Leitura/gravação. |

### Métodos do objeto Filer

A tabela a seguir descreve os métodos associados ao objeto Filer.

| Método | Descrição |
| --- | --- |
| Find( nValue ) | Um método que executa a pesquisa de arquivos e cria uma coleção Files. O método Find contém um valor numérico indicando o número de arquivos na coleção Files. nValue é um valor numérico que especifica se as coleções Files de pesquisas anteriores são descartadas. Se nValue for 0, as coleções Files de pesquisas anteriores são descartadas. Se nValue for 1, a coleção Files criada pela pesquisa atual é anexada às pesquisas anteriores. Observe que nValue não é opcional. |

### Objetos de coleção Files

A tabela a seguir descreve as referências de objeto associadas à coleção Files.

| Objeto | Descrição |
| --- | --- |
| Item( nValue ) | Uma referência de objeto a um arquivo na coleção Files. nValue é um índice para um arquivo na coleção Files. nValue começa em 1 e continua até o número de arquivos na coleção Files. Você pode usar a propriedade Count, descrita abaixo, para determinar o número de arquivos na coleção Files. |

### Propriedades da coleção Files

A tabela a seguir descreve as propriedades associadas à coleção Files.

| Propriedade | Tipo de dados | Descrição |
| --- | --- | --- |
| Count | N | Contém o número de arquivos na coleção Files. Somente leitura. |
| Name | C | O nome do arquivo, excluindo o caminho. Somente leitura. |
| Size | N | O tamanho do arquivo em bytes. Somente leitura. |
| SizeHigh | N | Os 4 bytes altos do tamanho do arquivo se o tamanho do arquivo for maior que 4 gigabytes. Somente leitura. |
| Attr | N | Os atributos de arquivo do Windows para um arquivo. A seguir está uma lista de valores numéricos para atributos de arquivo típicos. 0 Nenhum atributo definido 1 Somente leitura 2 Oculto 4 Sistema 32 Arquivado O valor de Attr pode ser a soma de vários atributos de arquivo. Por exemplo, se Attr for 7 (1+2+4), o arquivo é um arquivo de sistema oculto somente leitura. Para obter mais informações sobre os outros atributos de arquivo para os quais Attr retorna valores, consulte a função GetFileAttributes descrita na biblioteca Microsoft Developer's Network. Leitura/gravação. |
| DateTime | N | O carimbo de data/hora atribuído pelo Windows a um arquivo quando ele é criado. A parte inteira do carimbo de data/hora é o número de dias desde 12/30/1899, e o restante é a fração restante do dia a partir da qual você pode determinar a hora em que o arquivo foi criado. O formulário Filer, Filer.scx, contém um método definido pelo usuário chamado GetTime que demonstra como você pode determinar a data e a hora em que um arquivo foi criado a partir da propriedade DateTime. Somente leitura. |
| LastAccessTime | N | O carimbo de data/hora atribuído pelo Windows a um arquivo quando foi acessado pela última vez. Somente leitura. |
| LastWriteTime | N | O carimbo de data/hora atribuído pelo Windows a um arquivo quando foi gravado pela última vez. Somente leitura. |
| AlternateName | C | O nome curto do arquivo se o nome do arquivo for maior que a convenção de nomenclatura MS-DOS® de 8.3 caracteres. Somente leitura. |
| Path | C | O caminho completo para o arquivo. Somente leitura. |

### Métodos da coleção Files

A tabela a seguir descreve os métodos associados à coleção Files.

| Método | Descrição |
| --- | --- |
| Edit | Abre o arquivo especificado para edição. Se a propriedade IsHostedByFox for 1 (o padrão para o Visual FoxPro), o arquivo é aberto no editor do Visual FoxPro. Se a propriedade IsHostedByFox for 0, o arquivo é aberto no editor especificado com a propriedade Editor (NotePad por padrão). |
| Delete | Exclui o arquivo especificado do disco. O arquivo não é colocado na Lixeira. |
