# Caixa de diálogo Connections

Esta caixa de diálogo permite criar e manter conexões de banco de dados. Ela aparece quando você seleciona Connections no menu Database.
 **Connections in <database>**
Lista as conexões associadas ao banco de dados aberto no momento.
**New**
Abre o designer Connection, que permite criar e modificar conexões nomeadas.
**Modify**
Abre o designer Connection, que permite modificar a conexão existente do banco de dados.
**Delete**
Permite excluir a conexão do banco de dados.
