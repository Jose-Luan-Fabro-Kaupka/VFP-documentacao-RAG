# Como: especificar expressões a avaliar ao processar bandas

Você pode especificar expressões a serem avaliadas antes ou depois de processar uma banda no layout de página do relatório ou etiqueta.

### Para especificar expressões a avaliar ao processar uma banda de relatório
- Abra o relatório ou etiqueta no designer apropriado.
- No menu Report, clique em Edit Bands. A caixa de diálogo Edit Bands é aberta.
- Na caixa de diálogo Edit Bands, selecione a banda desejada e clique em OK. A caixa de diálogo de propriedades da banda de relatório é aberta. Dica Você também pode clicar duas vezes no separador de banda no Report Designer ou Label Designer para abrir a caixa de diálogo de propriedades da banda de relatório. Observação Se a variável de sistema _REPORTBUILDER não estiver definida para o Report Builder padrão ou estiver definida para um builder de terceiros, a caixa de diálogo da banda de relatório é exibida ou uma caixa de diálogo diferente pode ser exibida. Para obter mais informações, consulte _REPORTBUILDER System Variable e Report Band Properties Dialog Box.
- Na caixa de diálogo de propriedades da banda de relatório, clique na guia General se ela não estiver selecionada.
- Na área Run expression, execute o seguinte: Para especificar uma expressão a avaliar antes de processar a banda de relatório, digite uma expressão na caixa On entry. Para especificar uma expressão a avaliar depois de processar a banda de relatório, digite uma expressão na caixa On exit. Para construir uma expressão, clique no botão de reticências ( … ) ao lado da caixa On entry ou On exit para abrir o Expression Builder. Para obter mais informações, consulte Expression Builder Dialog Box.

Para obter mais informações, consulte General Tab, Report Band Properties Dialog Box (Report Builder).
