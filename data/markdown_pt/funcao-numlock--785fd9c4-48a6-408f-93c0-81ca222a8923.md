# Função NUMLOCK( )

Retorna o modo atual da tecla NUM LOCK ou define o modo da tecla NUM LOCK como ligado ou desligado.

```foxpro
NUMLOCK([lExpression])
```

#### Parâmetros
 **lExpression**
Liga ou desliga a tecla NUM LOCK. Se lExpression for true (.T.), a tecla NUM LOCK é ligada; se lExpression for false (.F.), a tecla NUM LOCK é desligada. NUMLOCK( ) retorna um valor lógico correspondente à configuração da tecla NUM LOCK antes que NUMLOCK(.T.) ou NUMLOCK(.F.) seja emitido.

# Valor de retorno

Valor lógico

# Observações

NUMLOCK( ) retorna true (.T.) se a tecla NUM LOCK estiver ligada (pressionar uma tecla no teclado numérico retorna um número), ou false (.F.) se NUM LOCK estiver desligado (pressionar uma tecla no teclado numérico move o cursor).

# Exemplo

No exemplo a seguir, o sinal de igual (=) é usado para executar NUMLOCK( ) sem retornar um valor.

```foxpro
gcOldLock = NUMLOCK()  && Save original setting
WAIT WINDOW 'Press a key to turn Num Lock on'
= NUMLOCK(.T.)  && Turn Num Lock on
WAIT WINDOW 'Press a key to turn Num Lock off'
= NUMLOCK(!NUMLOCK())  && Toggle Num Lock to the opposite value
WAIT WINDOW 'Press a key to restore original Num Lock setting'
= NUMLOCK(gcOldLock)     && Return to original setting
```
