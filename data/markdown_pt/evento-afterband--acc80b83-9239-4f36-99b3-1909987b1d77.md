# Evento AfterBand

Ocorre diretamente depois que o Report System termina de processar uma banda de relatório.

```foxpro
PROCEDURE Object.AfterBand
LPARAMETERS nBandObjCode, nFRXRecNo
```

#### Parâmetros

O Visual FoxPro passa os parâmetros do evento AfterBand na seguinte ordem:
 **nBandObjCode**
Tipo de dados inteiro, especificando o tipo de banda, conforme armazenado no campo ObjCode do arquivo de definição de relatório ou etiqueta (frx ou lbx). Os valores numéricos reconhecidos para nBandObjCode estão documentados na tabela 60FRX.DBF no diretório FILESPEC, da seguinte forma: 0 Title 1 Page Header 2 Column Header 3 Group Header 4 Detail 5 Group Footer 6 Column Footer 7 Page Footer 8 Summary 9 Detail Header 10 Detail Footer Para obter mais informações sobre 60FRX, consulte Estruturas de tabela de arquivos de tabela (.dbc, .frx, .lbx, .mnx, .pjx, .scx, .vcx) .
**nFRXRecno**
Tipo de dados inteiro, especificando o número do registro no arquivo de definição de relatório ou etiqueta (frx ou lbx) que descreve o elemento de layout sendo renderizado.

# Observações

Aplica-se a: Objeto ReportListener.

Para cada banda no relatório, o ReportListener dispara o evento BeforeBand antes que o Report Engine execute qualquer código na expressão OnEntry. Ele dispara o evento AfterBand depois que qualquer código OnExit é executado.

> **Observação:** Antes de executar o código OnExit e disparar o evento AfterBand para uma banda Detail ou Detail Footer, o Report Engine moveu o ponteiro de registro para o próximo registro no escopo do relatório. Para obter informações sobre a ordem dos eventos em uma execução de relatório, consulte Understanding Visual FoxPro Object-Assisted Reporting .
