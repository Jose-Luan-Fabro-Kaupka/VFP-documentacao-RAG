# Grid Builder

O Grid Builder facilita a definição de propriedades para um controle grid. O controle grid permite apresentar e manipular linhas e colunas de dados em um formulário ou página. Você define propriedades do grid selecionando opções exibidas na caixa de diálogo Grid Builder.

 Para usar o Grid Builder
 - Usando a barra de ferramentas Form Controls, coloque um controle grid em um formulário.
- Selecione e clique com o botão direito no controle grid e escolha Builder no menu de atalho do Form Designer.
- Escolha as opções desejadas na caixa de diálogo e clique em OK. Quando você clica em OK, o builder é fechado, aplicando as configurações de propriedade de todas as guias. Observação Antes de executar seu formulário, certifique-se de ter dimensionado o controle grid adequadamente para exibir seus dados.

# Guias do Builder
 **Grid Items**
Especifica campos a serem exibidos no grid.
**Style**
Especifica um estilo para a exibição do grid.
**Layout**
Especifica captions de coluna e tipos de controle.
**Relationship**
Especifica relacionamentos entre campos do grid e campos da tabela.
