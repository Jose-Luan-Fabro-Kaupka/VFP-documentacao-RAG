# Como: proteger bandas de relatório

Você pode definir opções de proteção para uma banda de relatório para impedir que o usuário altere a banda ao modificar o relatório ou etiqueta no modo protegido.

### Para definir proteção para uma banda de relatório
- Abra o relatório ou etiqueta no designer apropriado.
- No menu Report, clique em Edit Bands . A caixa de diálogo Edit Bands abre.
- Na caixa de diálogo Edit Bands, selecione a banda desejada e clique em OK . A caixa de diálogo de propriedades da banda de relatório abre. Dica Você também pode clicar duas vezes no separador de banda no Report Designer ou Label Designer para abrir a caixa de diálogo de propriedades da banda de relatório. Observação Se a variável de sistema _REPORTBUILDER não está definida para o Report Builder padrão ou está definida para um builder de terceiros, a caixa de diálogo da banda de relatório é exibida ou uma caixa de diálogo diferente pode ser exibida. Não há forma de definir um caption de tempo de design usando a caixa de diálogo nativa de controle de relatório. Para mais informações, consulte Variável de sistema _REPORTBUILDER .
- Na caixa de diálogo de propriedades da banda de relatório, clique na guia Protection.
- Na guia Protection, selecione uma combinação das seguintes opções de proteção: O usuário não poderá redimensionar a banda no modo protegido. O usuário não poderá acessar a caixa de diálogo Band Properties.
- Quando terminar, clique em OK .

Para mais informações, consulte Guia Protection, caixa de diálogo Report Band Properties (Report Builder).
