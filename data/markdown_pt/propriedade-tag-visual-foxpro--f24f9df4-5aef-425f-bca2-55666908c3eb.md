# Propriedade Tag (Visual FoxPro)

Armazena quaisquer dados extras necessários para seu programa. Disponível em tempo de design e em tempo de execução.

```foxpro
Object.Tag[ = Expr]
```

# Valor de retorno
 **Expr**
Especifica qualquer cadeia de caracteres.

# Observações

Aplica-se a: CheckBox Control | Collection Class | ComboBox Control | CommandButton Control | CommandGroup Control | CursorAdapter Class | EditBox Control | Exception Class (Visual FoxPro) | Form Object | Grid Control | Image Control (Visual FoxPro) | Label Control (Visual FoxPro) | Line Control | ListBox Control | OLE Bound Control | OLE Container Control | OptionButton Control | OptionGroup Control | ProjectHook Object | ReportListener Object | _SCREEN System Variable | Session Object | Shape Control | Spinner Control | TextBox Control (Visual FoxPro) | Timer Control

Por padrão, a propriedade Tag é definida como uma cadeia de caracteres vazia (""). Você pode usar esta propriedade para atribuir qualquer cadeia de caracteres a um objeto sem afetá-lo de nenhuma forma. Diferentemente de outras propriedades, o valor da propriedade Tag não é usado pelo Visual FoxPro.
