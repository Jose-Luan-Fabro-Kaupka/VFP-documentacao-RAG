# Como: criar menus de atalho

Menus de atalho aparecem quando você clica com o botão direito do mouse em um controle ou objeto, e fornecem uma maneira rápida de expor todas as funções que se aplicam apenas a esse objeto. Você pode usar o Visual FoxPro para criar menus de atalho e, em seguida, anexar esses menus a controles. Por exemplo, você pode criar um menu de atalho contendo os comandos Cut, Copy e Paste que aparecerá quando um usuário clicar com o botão direito em dados contidos em um Grid Control.

### Para criar um menu de atalho
- Na Project Manager Window, selecione a guia Other, selecione Menus e, em seguida, escolha New.
- Escolha Shortcut. O Shortcut Designer aparece.

Quando você está no Shortcut Menu designer, o processo para adicionar itens de menu é o mesmo que para criar menus.

Para um exemplo de menus de atalho, execute Solution.app no diretório Visual FoxPro ...\Samples\Solution\Solution.
