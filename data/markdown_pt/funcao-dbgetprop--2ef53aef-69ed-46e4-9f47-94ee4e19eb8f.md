# Função DBGETPROP( )

Recupera o valor de uma propriedade do banco de dados atual ou de campos, conexões nomeadas, tabelas ou views no banco de dados atual.

> **Observação:** Você deve abrir o banco de dados antes de poder recuperar suas propriedades ou as de suas conexões, tabelas, views ou campos. No entanto, você não precisa abrir uma tabela ou view antes de recuperar suas propriedades.

```foxpro
DBGETPROP(cName, cType, cProperty)
```

#### Parâmetros
 **cName**
Especifica o nome do banco de dados aberto atual ou do campo, conexão nomeada, tabela ou view no banco de dados aberto atual para o qual DBGETPROP( ) retorna informações. Para retornar informações sobre um campo em uma tabela ou view, prefixe o nome do campo com o nome da tabela ou view que contém o campo. Por exemplo, para retornar informações sobre o campo custid na tabela customer, especifique o seguinte para cName : customer.custid
**cType**
Especifica se cName é o banco de dados atual ou um campo, conexão nomeada, tabela ou view no banco de dados atual. A tabela a seguir lista os valores para cType . cType Descrição CONNECTION cName é uma conexão nomeada no banco de dados atual. DATABASE cName é o banco de dados atual. FIELD cName é um campo no banco de dados atual. TABLE cName é uma tabela no banco de dados atual. VIEW cName é uma view no banco de dados atual.
**cProperty**
Especifica o nome da propriedade para a qual DBGETPROP( ) retorna informações. As tabelas a seguir listam os valores que você pode especificar para cProperty , os tipos de valor de retorno e descrições de cada propriedade. Cada descrição inclui os privilégios de leitura e gravação para cada propriedade. Se uma propriedade é somente leitura, seu valor não pode ser alterado com DBSETPROP( ) . Propriedades de conexão cProperty Tipo Descrição Asynchronous L O modo de conexão. (Padrão) False (.F.) especifica uma conexão síncrona. True (.T.) especifica uma conexão assíncrona. Leitura/gravação. BatchMode L O modo de processamento em lote. (Padrão) True (.T.) especifica a conexão que opera em modo de lote. Leitura/gravação. Comment C O texto do comentário da conexão. Leitura/gravação. ConnectString C A cadeia de conexão de login. Leitura/gravação. ConnectTimeout N O intervalo de timeout de conexão em segundos. O padrão é 0 (aguardar indefinidamente). Leitura/gravação. Database C O nome do banco de dados do servidor especificado com a cláusula DATABASE no comando CREATE CONNECTION ou no Connection Designer. Leitura/gravação. DataSource C O nome da fonte de dados conforme definido no arquivo Odbc.ini. Leitura/gravação. DisconnectRollback L Especifica se uma transação pendente é confirmada ou revertida quando SQLDISCONNECT( ) é chamado para o último handle de conexão. O padrão é false (.F.), indicando que uma transação pendente é confirmada quando SQLDISCONNECT( ) é chamado para o último handle de conexão. Especifique true (.T.) para reverter uma transação pendente quando SQLDISCONNECT( ) é chamado para o último handle de conexão. Conexões com processamento automático de transações não são afetadas por esta configuração. Leitura/gravação. DispLogin N Contém um valor numérico que determina quando a caixa de diálogo ODBC Login é exibida. DispLogin pode assumir os seguintes valores: 1 ou DB_PROMPTCOMPLETE (de Foxpro.h). 1 é o padrão. 2 ou DB_PROMPTALWAYS (de Foxpro.h). 3 ou DB_PROMPTNEVER (de Foxpro.h). Se 1 ou DB_PROMPTCOMPLETE for especificado, o Microsoft Visual FoxPro exibe a caixa de diálogo ODBC Login somente se alguma informação obrigatória estiver ausente. Se 2 ou DB_PROMPTALWAYS for especificado, a caixa de diálogo ODBC Login é sempre exibida, permitindo que você altere as configurações antes de conectar. Se 3 ou DB_PROMPTNEVER for especificado, a caixa de diálogo ODBC Login não é exibida e o Visual FoxPro gera um erro se as informações de login obrigatórias não estiverem disponíveis. Leitura/gravação. DispWarnings L Contém um valor lógico que determina se avisos não capturáveis da tabela remota, ODBC ou Visual FoxPro são exibidos. (Padrão) True (.T.) especifica que erros não capturáveis são exibidos. Leitura/gravação. IdleTimeout N O intervalo de timeout de inatividade em minutos. O timeout é verificado no máximo uma vez por minuto; portanto, é possível que conexões ativas sejam desativadas um ou dois minutos depois que o intervalo de tempo especificado tenha decorrido. O valor padrão é 0 (aguardar indefinidamente). Leitura/gravação. PacketSize N O tamanho do pacote de rede usado pela conexão. Ajustar este valor pode melhorar o desempenho. O valor padrão é 4096 bytes (4K). Leitura/gravação PassWord C A senha da conexão. Leitura/gravação. QueryTimeout N O intervalo de timeout de consulta em segundos. O valor padrão é 0 (aguardar indefinidamente). Leitura/gravação. Transactions N Contém um valor numérico que determina como a conexão gerencia transações na tabela remota. Transactions pode assumir os seguintes valores: 1 ou DB_TRANSAUTO (de Foxpro.h). 1 é o padrão. O processamento de transações para a tabela remota é tratado automaticamente. 2 ou DB_TRANSMANUAL (de Foxpro.h). O processamento de transações é tratado manualmente por meio de SQLCOMMIT( ) e SQLROLLBACK( ) . Leitura/gravação. UserId C A identificação do usuário. Leitura/gravação. WaitTime N A quantidade de tempo em milissegundos que decorre antes que o Visual FoxPro verifique se a instrução SQL terminou de ser executada. O padrão é 100 milissegundos. Leitura/gravação. Propriedades de banco de dados cProperty Tipo Descrição Comment C O texto do comentário do banco de dados. Leitura/gravação. DBCEventFileName C Caminho relativo e nome do arquivo do programa externo contendo código de DBC Events. DBCEvents L Estado habilitado de DBC Events. Defina como True (.T.) para habilitar. Version N O número da versão do banco de dados. Somente leitura. Propriedades de campo para tabelas cProperty Tipo Descrição Caption C O caption do campo. Se um sinal de igual (=) preceder o valor desta propriedade, o Visual FoxPro avalia o valor como uma expressão. Caso contrário, é tratado como uma cadeia de caracteres literal. Leitura/gravação. Comment C O texto do comentário do campo. Leitura/gravação. DefaultValue C O valor padrão do campo. Somente leitura. DisplayClass C Nome da classe usada para mapeamento de campo. Leitura/gravação. DisplayClassLibrary C Caminho para a biblioteca de classes especificada com a propriedade DisplayClass . Leitura/gravação. Format C O formato de exibição do campo. Consulte a propriedade Format para uma lista de configurações de formato. Leitura/gravação. InputMask C O formato de entrada do campo. Consulte a propriedade InputMask para uma lista de configurações de máscara de entrada. Leitura/gravação. RuleExpression C A expressão de regra do campo. Somente leitura. RuleText C O texto de erro da regra do campo. Somente leitura. Propriedades de campo para views cProperty Tipo Descrição Caption C O caption do campo. Se um sinal de igual (=) preceder o valor desta propriedade, o Visual FoxPro avalia o valor como uma expressão. Caso contrário, é tratado como uma cadeia de caracteres literal. Leitura/gravação. Comment C O texto do comentário do campo. Leitura/gravação. DataType C O tipo de dados de um campo em uma view. Inicialmente definido como o tipo de dados do campo na fonte de dados. Para especificar um tipo de dados diferente para um campo com DBSETPROP( ) , use a sintaxe para criar campos em CREATE TABLE – SQL . Por exemplo, para alterar o tipo de dados de um campo inteiro chamado iCost em uma tabela chamada Mytable para tipo numérico com largura 4 e 2 casas decimais, use DBSETPROP('mytable.icost', 'field', ; 'DataType', 'N(4,2)') Você também pode incluir a cláusula NOCPTRANS para impedir a tradução de campos de caractere e memo para uma página de código diferente. Leitura/gravação para views remotas. DisplayClass C Nome da classe usada para mapeamento de campo. Leitura/gravação. DisplayClassLibrary C Caminho para a biblioteca de classes especificada com a propriedade DisplayClass . Leitura/gravação. DefaultValue C O valor padrão do campo. Leitura/gravação. KeyField L Contém True (.T.) se o campo for especificado em uma expressão de chave de índice; caso contrário, contém False (.F.). Leitura/gravação. RuleExpression C A expressão de regra do campo. Leitura/gravação. RuleText C O texto de erro da regra do campo. Leitura/gravação. Updatable L Contém True (.T.) se o campo puder ser atualizado; caso contrário, contém False (.F.). Leitura/gravação. UpdateName C O nome do campo usado quando os dados no campo são atualizados na tabela remota. Por padrão, o nome do campo da tabela remota. Leitura/gravação. Propriedades de tabela cProperty Tipo Descrição Comment C O texto do comentário da tabela. Leitura/gravação. DeleteTrigger C A expressão do trigger Delete. Somente leitura. InsertTrigger C A expressão do trigger Insert. Somente leitura. Path C O caminho relativo em relação ao DBC para a tabela, incluindo o nome do arquivo. Somente leitura. UpdateTrigger C A expressão do trigger Update. Somente leitura. Propriedades de view cProperty Tipo Descrição AllowSimultaneousFetch L Aplica-se ao usar views remotas, uma conexão compartilhada e cursors criados usando ODBC. AllowSimultaneousFetch contém True (.T.) quando cursors configurados de forma semelhante que compartilham a conexão têm permissão para buscar linhas simultaneamente. Caso contrário, AllowSimultaneousFetch contém False (.F.) quando a busca simultânea de linhas não é permitida. Observação Esta propriedade está disponível no Visual FoxPro 8.0 e posterior. Views criadas no Visual FoxPro 8.0 e posterior não são compatíveis com versões anteriores. Chamar o comando VALIDATE DATABASE em uma versão anterior ao Visual FoxPro 8.0 em um contêiner de banco de dados com views remotas criadas ou modificadas no Visual FoxPro 8.0 e posterior gera um erro. Chamar VALIDATE DATABASE RECOVER em uma versão anterior ao Visual FoxPro 8.0 remove a propriedade AllowSimultaneousFetch de quaisquer views desse tipo. BatchUpdateCount N O número de instruções de atualização enviadas ao back end para views. 1 é o padrão. Ajustar este valor pode aumentar muito o desempenho de atualização. Leitura/gravação. Comment C O texto do comentário da view. Leitura/gravação. CompareMemo L Contém true (.T.) (padrão) se campos memo (do tipo Memo, General ou Picture, ou, para views remotas, tipo Timestamp) são incluídos na cláusula WHERE para atualizações; caso contrário, contém false (.F.). Leitura/gravação. ConnectName C A conexão nomeada usada quando a view é aberta. Somente leitura. FetchAsNeeded L Se True (.T.), os dados são buscados somente quando necessário, como quando o ponteiro de registro se move para uma linha que não foi buscada. Se False (.F.), dados adicionais são buscados durante o tempo ocioso. (Padrão) Observação FetchAsNeeded não se aplica quando a busca progressiva está desabilitada (FetchSize é -1). Leitura/gravação. FetchMemo L Contém true (.T.) (padrão) se campos memo e general são buscados com os resultados da view; caso contrário, contém false (.F.). Use a função ISMEMOFETCHED( ) para determinar se o campo memo foi buscado. Leitura/gravação. FetchSize N Contém o número de registros buscados de cada vez das tabelas remotas. O padrão é 100 registros. Definir FetchSize como –1 recupera o conjunto de resultados completo, limitado pela configuração MaxRecords . Observação A busca progressiva mantém a conexão até que todas as linhas sejam recuperadas. Use cautela ao codificar com FetchSize se ShareConnection for True (.T.). Leitura/gravação. MaxRecords N O número máximo de registros buscados quando conjuntos de resultados são retornados. O padrão é – 1 (todas as linhas são retornadas). Um valor de 0 especifica que a view é executada, mas nenhum resultado é buscado. Leitura/gravação. Offline L Contém true (.T.) se a view é uma view offline. Somente leitura. ParameterList C Os parâmetros da cláusula WHERE. O formato dos parâmetros é '' ParameterName1 , ' Type1 '; ParameterName2 , ' Type2 '; ...'' onde Type é um dos seguintes caracteres especificando o tipo de parâmetro: C – Caractere D – Data T – DateTime N – Numérico F – Flutuante B – Duplo I – Inteiro Y – Moeda L - Lógico Por exemplo, ''MyParam1, 'C' '' especifica um único parâmetro de tipo caractere chamado MyParam1. Para obter mais informações sobre como criar views parametrizadas, consulte Como: criar views parametrizadas . Leitura/gravação. Prepared L Contém True (.T.) se instruções SQL são preparadas para chamadas subsequentes da função REQUERY( ) . REQUERY( ) é usado para recuperar dados novamente para uma view SQL. Consulte SQLPREPARE( ) para informações adicionais sobre preparar instruções SQL. O padrão é false (.F.). Leitura/gravação. RuleExpression C A expressão de regra de linha. Leitura/gravação. RuleText C A expressão de texto de regra exibida quando ocorre um erro ao editar dados em uma janela Browse ou Edit. Leitura/gravação. SendUpdates L Contém true (.T.) se uma consulta de atualização SQL é enviada para atualizar tabelas remotas; caso contrário, contém false (.F.) (padrão). Leitura/gravação. ShareConnection L Contém true (.T.) se a view pode compartilhar seu handle de conexão com outras conexões; caso contrário, contém false (.F.). Leitura/gravação. SourceType N A origem da view. SourceType pode assumir os seguintes valores: 1 - A view usa tabelas locais. 2 - A view usa tabelas remotas. Somente leitura. SQL C A instrução SQL executada quando a view é aberta. Somente leitura. Tables C Uma lista separada por vírgulas dos nomes das tabelas. Leitura/gravação. UpdateType N O tipo de atualização. Os valores válidos são: 1 ou DB_UPDATE (de Foxpro.h). Os dados antigos são atualizados com os novos dados (padrão). 2 ou DB_DELETEINSERT (de Foxpro.h). Os dados antigos são excluídos e os novos dados são inseridos. Leitura/gravação. UseMemoSize N O tamanho mínimo (em bytes) para o qual colunas de resultado são retornadas em campos memo. Por exemplo, se a largura de um resultado de coluna for maior que o valor de UseMemoSize, o resultado da coluna é armazenado em um campo memo. UseMemoSize pode variar de 1 a 255; o valor padrão é 255. Leitura/gravação. WhereType N A cláusula WHERE para atualizações em tabelas remotas. WhereType pode assumir os seguintes valores: 1 ou DB_KEY (de Foxpro.h). A cláusula WHERE usada para atualizar tabelas remotas consiste somente nos campos primários especificados com a propriedade KeyFieldList . 2 ou DB_KEYANDUPDATABLE (de Foxpro.h). Para obter mais informações sobre a propriedade WhereType , consulte Gerenciando atualizações usando views . Leitura/gravação.

# Valor de retorno

Tipo de dados Caractere, Numérico ou Lógico. DBGETPROP( ) retorna o valor da propriedade especificada.

# Observações

Para obter mais informações sobre como definir valores de propriedade, consulte a função DBSETPROP( ).

# Exemplo

O exemplo a seguir exibe o nome do campo da chave primária para a tabela `customer`. Em seguida, exibe os comentários do campo para o campo `cust_id` na tabela `customer`. Se não houver comentários para o campo, uma mensagem é exibida indicando que não há comentários de campo. Para adicionar comentários, consulte o exemplo de DBSETPROP( ).

```foxpro
CLOSE DATABASES
CLEAR
OPEN DATABASE (HOME(2) + 'Data\testdata')
* Displays the primary key field
cResults = DBGETPROP("customer", "Table", "PrimaryKey")
=MESSAGEBOX(cResults)   && Displays    'cust_id'
* Displays comments for the field 'cust_id'
cResults = DBGETPROP("customer.cust_id", "Field", "Comment")
IF LEN(ALLTRIM(cResults)) = 0
   =MESSAGEBOX("No Comment for this field." + CHR(13) + ;
     CHR (13) + "Use DBSETPROP() to add comments.")
ELSE
   =MESSAGEBOX("Cust_id field comments: " + cRESULTS)
ENDIF
```
