# Rotinas de variável e array

Essas rotinas de API permitem manipular variáveis de memória e arrays de variáveis de memória.
 **Rotina de biblioteca de API _ALen( )**
Retorna informações sobre as dimensões do array cujo índice de tabela de nomes é nti .
**Rotina de biblioteca de API _FindVar( )**
Fornece uma maneira de inicializar um Locator para que você possa usar _Store( ) para colocar dados em uma variável de memória existente.
**Rotina de biblioteca de API _Load( )**
Obtém o valor da variável de memória ou variável de tabela especificada por loc e o coloca em val .
**Rotina de biblioteca de API _NameTableIndex( )**
Retorna o índice da tabela de nomes que corresponde a um determinado nome , ou -1 se esse nome não estiver na tabela de nomes.
**Rotina de biblioteca de API _NewVar( )**
Cria uma variável ou um array.
**Rotina de biblioteca de API _Release( )**
Libera uma variável de memória ou um array.
**Rotina de biblioteca de API _Store( )**
Substitui a variável de memória especificada por loc com o valor val .
