# Comando EJECT PAGE

Envia um avanço condicional de página para a impressora.

```foxpro
EJECT PAGE
```

# Observações

Use EJECT PAGE para avançar a saída em fluxo. O avanço depende do valor de _PADVANCE e se uma rotina ON PAGE está em vigor.

Se _PADVANCE estiver definido como FORMFEED e uma rotina ON PAGE não estiver em vigor, EJECT PAGE executa o seguinte:
 - Envia um formfeed para a impressora se a impressora estiver online.
- Envia linefeeds, conforme determinado pelas variáveis de memória do sistema _PLENGTH e _PLINENO, para a tela ou para um arquivo alternativo ou para ambos.
- Incrementa _PAGENO em 1.
- Define _PLINENO como 0.
- Se a variável de memória do sistema _PADVANCE estiver definida como LINEFEEDS, e se uma rotina ON PAGE estiver em vigor e _PLINENO for menor que o número de linha da página especificado na rotina ON PAGE, EJECT PAGE envia para a impressora, para a janela principal do Visual FoxPro, ou para um arquivo alternativo ou para ambos, tantos linefeeds quantos forem necessários para avançar até o topo da próxima página.

Se uma rotina ON PAGE não estiver em vigor, ou se _PADVANCE estiver definido como LINEFEEDS e _PLINENO for maior que o número de linha da página especificado com ON PAGE, EJECT PAGE faz o seguinte:
 - Envia linefeeds, conforme determinado pelas variáveis de memória do sistema _PLENGTH e _PLINENO, para a impressora, a janela principal do Visual FoxPro, ou para o arquivo alternativo ou para ambos.
- Incrementa _PAGENO em 1.
- Define _PLINENO como 0.
