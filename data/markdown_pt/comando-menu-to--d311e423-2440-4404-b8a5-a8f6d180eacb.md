# Comando MENU TO

Incluído para compatibilidade com versões anteriores. Use os Designers de Menu e Atalho do Visual FoxPro.

Ativa uma barra de menu.

```foxpro
MENU TO memvar
```

#### Parâmetros
 memvar

 O valor inicialmente contido na variável de memória ou elemento de matriz memvar especifica qual pad de menu é selecionado quando a barra de menu é ativada. Quando você escolhe um pad de menu, um valor é armazenado em memvar correspondente ao pad de menu que você escolhe. Se você pressionar Esc para sair do menu, memvar contém 0.

# Observações

MENU TO está incluído para compatibilidade com versões anteriores. Use o FoxPro Menu Builder para criar menus.

Use MENU TO para ativar menus pop-up criados com @ ... PROMPT.
