# Como: adicionar gráficos a Forms

Você pode adicionar uma imagem ao fundo do seu formulário ou adicionar uma imagem a uma caixa dentro do formulário.

### Para adicionar um gráfico ao seu formulário
- Escolha uma das seguintes opções: Para alterar o fundo do formulário, selecione o formulário. - OU - Para adicionar uma imagem ao seu formulário, selecione um controle Image na barra de ferramentas Form Controls e coloque-o no formulário.
- Na janela Properties, selecione a propriedade Picture.
- Escolha o botão de diálogo para exibir a caixa de diálogo Open.
- Localize a imagem ou outro arquivo que deseja usar.
- Escolha OK.
