# Comando SUM

Totaliza todos ou campos numéricos especificados na tabela atualmente selecionada.

```foxpro
SUM [eExpressionList]   [Scope] [FOR lExpression1] [WHILE lExpression2]
   [TO MemVarNameList | TO ARRAY ArrayName]   [NOOPTIMIZE]
```

#### Parâmetros
 **eExpressionList**
Especifica um ou mais campos ou expressões de campo a totalizar. Se você omitir a lista de expressões de campo, todos os campos numéricos são totalizados.
**Scope**
Especifica um intervalo de registros a incluir no total. As cláusulas de escopo são: ALL, NEXT nRecords, RECORD nRecordNumber e REST. Para obter mais informações sobre cláusulas de escopo, consulte Scope Clauses. O escopo padrão para SUM é TODOS os registros.
**FOR lExpression1**
Especifica que apenas os registros para os quais a condição lógica lExpression1 avalia para true (.T.) são incluídos no total. Incluir FOR permite totalizar registros condicionalmente, filtrando registros indesejados. A otimização de consulta Rushmore otimiza um comando SUM ... FOR se lExpression1 é uma expressão otimizável. Para melhor desempenho, use uma expressão otimizável na cláusula FOR. Para obter mais informações sobre otimização Rushmore, consulte SET OPTIMIZE Command e Using Rushmore Query Optimization to Speed Data Access.
**WHILE lExpression2**
Especifica uma condição pela qual registros da tabela atual são incluídos no total enquanto a expressão lógica lExpression2 avalia para true (.T.).
**TO MemVarNameList**
Armazena cada total em uma variável. Se você especificar uma variável em MemVarNameList que não existe, o Visual FoxPro a cria automaticamente. Separe os nomes de variáveis na lista com vírgulas.
**TO ARRAY ArrayName**
Armazena totais em uma matriz de variáveis. Se a matriz especificada em SUM não existir, o Visual FoxPro a cria automaticamente. Se a matriz existir e for muito pequena para conter todos os totais, o tamanho da matriz é automaticamente aumentado para acomodar os totais.
**NOOPTIMIZE**
Desabilita a otimização Rushmore de SUM. Para obter mais informações, consulte SET OPTIMIZE Command e Using Rushmore Query Optimization to Speed Data Access.

# Exemplo

O exemplo a seguir exibe os totais dos campos `in_stock` e `on_order` na tabela `products`, junto com uma soma dos dois totais.

```foxpro
CLOSE DATABASES
OPEN DATABASE (HOME(2) + 'data\testdata')
USE products  && Opens Products table
SUM in_stock, on_order, in_stock+on_order ;
   TO gnInStock, gnOnOrder, gnUnits
CLEAR
?
? 'Total in stock : ', gnInStock  && Displays 3119.00
? 'Total on order:  ', gnOnOrder  && Displays 780.00
? 'Total # units :  ', gnUnits  && Displays 3899.00
```
