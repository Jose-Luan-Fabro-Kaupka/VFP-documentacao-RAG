# Guia Geral, Caixa de Diálogo Personalização de Painel

A guia Geral contém informações gerais para as seções de conteúdo raiz e subconteúdo do painel.
 **ID exclusivo**
Especifica um identificador exclusivo atribuído ao painel selecionado. Um ID padrão é atribuído quando um painel é criado. Recomenda-se aceitar o valor padrão.
**Nome**
Especifica o nome da seção de conteúdo. Se a seção de conteúdo selecionada for a seção de conteúdo raiz, o nome aparece na parte superior do Gerenciador de Painéis de Tarefas. Teclas de atalho podem ser atribuídas colocando um caractere de escape na caixa Nome. Por exemplo, \<Meu Painel como o nome da seção de conteúdo raiz especifica a letra M como a tecla de atalho para este painel no Gerenciador de Painéis de Tarefas.
**URL de Ajuda**
Especifica a URL para ajuda sobre o painel selecionado. O hiperlink Ajuda para a URL aparece na caixa de diálogo Opções do Painel de Tarefas quando o painel é selecionado.
**Selecionar Imagem**
Exibe uma caixa de diálogo para selecionar uma imagem que será associada ao painel selecionado. A imagem selecionada é mostrada junto com o link para o painel na parte superior do Gerenciador de Painéis de Tarefas.
**Biblioteca de Classes**
Especifica o arquivo de programa (.prg) ou arquivo de biblioteca (.vcx) que contém a classe e o código associado para executar o painel. O arquivo é copiado automaticamente para a pasta PaneCache do painel selecionado, e os arquivos são adicionados automaticamente à lista de arquivos associados ao painel selecionado. Este campo aparece somente se o painel selecionado for baseado no tipo VFP Controls.
**Nome da Classe**
Especifica o nome da classe de contêiner a instanciar ao criar o painel da biblioteca de classes especificada. Este campo aparece somente se o painel selecionado for baseado no tipo VFP Controls.
**Modificar**
Abre a biblioteca de classes para edição. Este controle aparece somente se o painel selecionado for baseado no tipo VFP Controls.
