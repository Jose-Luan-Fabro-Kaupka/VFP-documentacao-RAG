# Propriedade UserValue

Especifica o valor passado pela instrução THROW usada para gerar uma exceção. Você pode usar este valor como referência de objeto. Leitura/gravação em tempo de execução.

```foxpro
Exception.UserValue
```

# Valor de retorno

Tipo de dados Variant

# Observações

Aplica-se a: Exception Class (Visual FoxPro)
