# Linguagem de formatação de dados

Estes comandos e funções permitem formatar e exibir dados de registros, campos, variáveis de memória ou arrays. Também permitem manipular recursos gerais de exibição de tela ou janela.

| Use | Para |
| --- | --- |
| Comando \\ | Imprimir ou exibir linhas de texto. |
| Comando ? | Avaliar uma expressão e enviar os resultados para a janela principal do Visual FoxPro, uma janela definida pelo usuário ativa ou a impressora. |
| Comando ?? | Avaliar uma expressão e enviar os resultados para a janela principal do Visual FoxPro, uma janela definida pelo usuário ativa ou a impressora. |
| Comando @ ... CLEAR | Limpar uma parte da janela principal do Visual FoxPro ou de uma janela definida pelo usuário. |
| Comando @ ... FILL | Alterar a cor do texto existente em uma área da tela. |
| Comando ACTIVATE SCREEN | Enviar toda a saída subsequente para a janela principal do Visual FoxPro em vez da janela definida pelo usuário ativa. |
| Comando APPEND | Adicionar um ou mais registros ao final de uma tabela. |
| Comando BROWSE | Abre a janela browse e exibe registros de uma tabela. |
| Comando CHANGE | Exibir campos para edição. |
| Comandos CLEAR | Liberar itens especificados da memória. |
| Comandos CLOSE | Fechar vários tipos de arquivo. |
| Comando CREATE FORM | Abrir o form designer. |
| Comando DISPLAY | Exibir conteúdo de registros e resultados de expressões para a tabela atual. |
| Função DisplayPath( ) | Truncar expressões de caminho longas para um comprimento especificado para exibição. |
| Comando EDIT | Exibir campos para edição. |
| Comando FUNCTION | Criar uma função definida pelo usuário em um arquivo de programa. |
| Função INKEY( ) | Retornar um número correspondente ao primeiro clique do mouse ou pressionamento de tecla no buffer type-ahead. |
| Comandos LIST | Exibir informações de tabela ou ambiente sem pausar a janela principal do Visual FoxPro ou definida pelo usuário. |
| Função MESSAGEBOX( ) | Exibir uma caixa de diálogo definida pelo usuário. |
| Comando MODIFY FORM | Abrir o Form Designer para modificar ou criar um formulário. |
| Função OBJTOCLIENT( ) | Retornar uma posição ou dimensão de um controle ou objeto em relação ao seu formulário. |
| Comando RESTORE SCREEN | Restaurar a janela principal do Visual FoxPro ou uma janela definida pelo usuário previamente salva no buffer de tela, uma variável ou um elemento de array. |
| Comando SAVE SCREEN | Restaurar a janela principal do Visual FoxPro ou uma janela definida pelo usuário previamente salva no buffer de tela, uma variável ou um elemento de array. |
| Função SCOLS( ) | Retornar o número de colunas disponíveis na janela principal do Microsoft Visual FoxPro. |
| Comando SCROLL | Rolar uma área da janela principal do Visual FoxPro ou de uma janela definida pelo usuário para cima, para baixo, para a esquerda ou para a direita. |
| Comando SET CARRY | Determinar se o Visual FoxPro carrega dados do registro atual para um novo registro criado com INSERT, APPEND e BROWSE. |
| Comando SET COLOR OF SCHEME | Especificar as cores de um esquema de cores ou copiar um esquema de cores para outro esquema de cores. |
| Comando SET COLOR SET | Carregar um conjunto de cores previamente definido. |
| Comando SET CONFIRM | Especificar se o usuário pode sair de uma caixa de texto digitando além do último caractere na caixa de texto. |
| Comando SET CONSOLE | Habilitar ou desabilitar saída para a janela principal do Visual FoxPro ou para a janela definida pelo usuário ativa a partir de programas. |
| Comando SET CURSOR | Determinar se o ponto de inserção é exibido quando o Visual FoxPro aguarda entrada. |
| Comando SET DECIMALS | Especificar o número de casas decimais exibidas em expressões numéricas. |
| Comando SET DEVICE | Direcionar saída de @ ... SAY para a tela, uma impressora ou um arquivo. |
| Comando SET FIXED | Especificar se o número de casas decimais usado na exibição de dados numéricos é fixo. |
| Comando SET HEADINGS | Determinar se cabeçalhos de coluna são exibidos para campos e se informações de arquivo são incluídas quando TYPE é emitido para exibir o conteúdo de um arquivo. |
| Comando SET MARK TO | Especificar um delimitador para a exibição de expressões de data. |
| Comando SET MEMOWIDTH | Especificar a largura exibida de campos memo e expressões de caractere. |
| Comando SET MESSAGE | Definir uma mensagem para exibição na janela principal do Visual FoxPro ou na barra de status gráfica, ou especificar a localização de mensagens para barras de menu e comandos de menu definidos pelo usuário. |
| Comando SET ODOMETER | Especificar o intervalo de relatório do contador de registros para comandos que processam registros. |
| Comando SET SPACE | Determinar se um espaço é exibido entre campos ou expressões quando você usa o comando ? ou ??. |
| Comando SET TEXTMERGE | Habilitar ou desabilitar a avaliação de campos, variáveis, elementos de array, funções ou expressões cercados por delimitadores de mesclagem de texto, e especificar saída de mesclagem de texto. |
| Comando SET TEXTMERGE DELIMITERS | Especificar o conjunto de caracteres delimitadores de mesclagem de texto a usar em vez do padrão. |
| Função SROWS( ) | Retornar o número de linhas disponíveis na janela principal do Visual FoxPro. |
| SYS(7) - Current Format File | Retornar o nome do arquivo de formato atual. |
| SYS(2002) - Turn Insertion Point On or Off | Ativar ou desativar o ponto de inserção. |
| Comando TEXT ... ENDTEXT | Enviar linhas de texto especificadas por TextLines para o dispositivo de saída atual. |
| Função TRANSFORM( ) | Retornar uma cadeia de caracteres de uma expressão em um formato determinado por um código de formato. |
