# Exemplo Expandindo o método SetAll

Arquivo: ...\Samples\Solution\FFC\Setallx.scx

Este exemplo usa a Foundation Class SetAllx para permitir a definição programática de propriedades de objetos com base em critérios estendidos não disponíveis com o método nativo SetAll( ).
 Este exemplo contém as seguintes classes
| Classe | Biblioteca | Descrição |
| --- | --- | --- |
| _setallx | _setallx.vcx | Fornece método wrapper chamado SetAllx que adiciona capacidades expandidas de SetAll. |

Para obter detalhes sobre todas as classes disponíveis nas foundation classes, consulte Visual FoxPro Foundation Classes A-Z.
