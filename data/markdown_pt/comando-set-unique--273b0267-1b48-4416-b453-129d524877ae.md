# Comando SET UNIQUE

Especifica se registros com valores duplicados de chave de índice são mantidos em um arquivo de índice.

```foxpro
SET UNIQUE ON | OFF
```

#### Parâmetros
 **ON**
Especifica que nenhum registro com valor duplicado de chave de índice seja incluído no arquivo de índice. Somente o primeiro registro com o valor original da chave é incluído.
**OFF**
(Padrão) Especifica que registros com valores duplicados de chave de índice sejam incluídos no arquivo de índice.

# Observações

Um arquivo de índice mantém sua configuração SET UNIQUE quando você executa REINDEX. Para obter mais informações, consulte Comando INDEX e Comando REINDEX.

SET UNIQUE tem escopo na sessão de dados atual.
