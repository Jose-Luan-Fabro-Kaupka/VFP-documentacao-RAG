# Propriedade MouseIcon

Especifica o ícone do ponteiro do mouse exibido quando o ponteiro do mouse está posicionado sobre um objeto. Disponível em tempo de design e em tempo de execução.

```foxpro
Object.MouseIcon[ = cFileName]
```

# Valor de retorno
 **cFileName**
Especifica o arquivo exibido quando o ponteiro do mouse está posicionado sobre o objeto. Você pode especificar um arquivo de ícone do mouse (.ico), um arquivo de cursor do mouse (.cur) ou um arquivo de cursor animado do mouse (.ani).

# Observações

Aplica-se a: CheckBox Control | Column Object | ComboBox Control | CommandButton Control | CommandGroup Control | Container Object | Control Object (Visual FoxPro) | EditBox Control | Form Object | Grid Control | Header Object | Image Control (Visual FoxPro) | Label Control (Visual FoxPro) | Line Control | ListBox Control | OLE Bound Control | OLE Container Control | OptionButton Control | OptionGroup Control | _SCREEN System Variable | Shape Control | Spinner Control | TextBox Control (Visual FoxPro) | ToolBar Object

Para exibir o ícone do mouse, defina a propriedade MousePointer como 99 (Custom).
