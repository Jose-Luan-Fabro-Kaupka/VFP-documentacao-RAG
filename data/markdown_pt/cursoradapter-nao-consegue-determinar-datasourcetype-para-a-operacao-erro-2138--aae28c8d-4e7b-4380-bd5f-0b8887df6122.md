# CursorAdapter não consegue determinar DataSourceType para a operação. (Erro 2138)

A propriedade DataSourceType deve ser especificada.
 - Certifique-se de que a propriedade DataSourceType foi especificada para o objeto CursorAdapter.
- Certifique-se de que a propriedade UseDeDataSource está definida como True (.T.).
- Verifique se a propriedade DataSourceType do objeto DataEnvironment associado está configurada corretamente.
