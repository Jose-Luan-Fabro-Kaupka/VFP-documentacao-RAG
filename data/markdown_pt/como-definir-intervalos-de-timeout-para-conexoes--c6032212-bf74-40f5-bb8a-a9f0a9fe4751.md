# Como: definir intervalos de timeout para conexões

Você pode definir valores de timeout para a conexão com o servidor remoto se precisar ajustar como o Visual FoxPro interage com o servidor.

### Para definir intervalos de timeout
- Abra o projeto do aplicativo contendo a view no Project Manager .
- No Project Manager , expanda o nó Data, o nó Databases e depois o nó do banco de dados que contém a conexão de fonte de dados remota desejada.
- Clique no nome da conexão e depois em Modify . O Connection Designer é aberto para a conexão.
- Na área Timeout intervals, defina os valores desejados.
- Quando terminar, no menu File, clique em Save para salvar as configurações.

Para obter mais informações, consulte Connection Designer.
