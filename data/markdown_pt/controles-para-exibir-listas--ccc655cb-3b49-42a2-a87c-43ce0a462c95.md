# Controles para exibir listas

Os controles ListBox e ComboBox fornecem caixas de listagem e caixas de listagem suspensas pelas quais o usuário pode rolar para ver opções ou partes de informação. Caixas de listagem podem exibir vários itens, enquanto caixas de listagem suspensas podem exibir um item por vez. No entanto, o usuário pode clicar na seta de rolagem para exibir e rolar por uma lista de todos os itens na caixa de listagem.

> **Dica:** Se você tem espaço no formulário e deseja enfatizar as escolhas que o usuário pode fazer, use uma lista. Para economizar espaço e enfatizar o item atualmente selecionado, use uma caixa de listagem suspensa.

Você pode preencher uma caixa de listagem ou combo box com itens de várias fontes definindo as propriedades RowSourceType e RowSource . Para mais informações, consulte Como: escolher o tipo de dados para uma lista ou ComboBox.

Para ver vários exemplos que demonstram caixas de listagem e caixas de listagem suspensas, execute Solution.app no diretório do Visual FoxPro, ...\Samples\Solution.
