# Gerenciador do Painel de Tarefas

O Gerenciador do Painel de Tarefas exibe links para informações úteis e caixas de diálogo destinadas à execução de tarefas essenciais. Os painéis individuais podem conter informações estáticas ou dinâmicas, obter conteúdo da Internet, disponibilizar assistentes para tarefas rotineiras, exibir a Ajuda e apresentar exemplos. Os usuários podem criar painéis personalizados e compartilhá-los com outros usuários.

Você pode acessar o Gerenciador do Painel de Tarefas pelo menu Ferramentas da tela principal do Visual FoxPro.
 **Iniciar**
Contém seções que exibem informações sobre o Visual FoxPro, ferramentas selecionadas pelo usuário e projetos e bancos de dados abertos recentemente.
**Comunidade**
Contém informações sobre a comunidade do Visual FoxPro. Este painel é criado com conteúdo dinâmico proveniente da Internet.
**Gerenciador de ambientes**
Especifique configurações de ambiente do Visual FoxPro e associe-as a projetos individuais. Para obter mais informações, consulte Painel de tarefas Gerenciador de ambientes.
**Exemplos de soluções**
Exibe exemplos de soluções criadas no Visual FoxPro. Outros exemplos podem ser instalados usando a opção Instalar exemplo.
**Serviços Web XML**
Auxilia os usuários a utilizar, publicar e gerenciar serviços Web XML. Também inclui links para recursos úteis.
**Filer**
Especifique critérios de pesquisa para localizar arquivos.
**Explorador de Dados**
Exiba e trabalhe com fontes de dados remotas, como bancos de dados do SQL Server. Para obter mais informações, consulte Painel de tarefas Explorador de Dados.
**Campo minado**
Faça uma pausa rápida no trabalho.
**Atualizar**
Recarrega o conteúdo do painel exibido no momento. Se esse conteúdo incluir informações dinâmicas da Internet, ele será baixado conforme especificado na caixa de diálogo Opções do Painel de Tarefas.
**Opções**
Exibe a caixa de diálogo Opções do Painel de Tarefas, na qual você pode definir opções para o Painel de Tarefas ou para painéis individuais.
