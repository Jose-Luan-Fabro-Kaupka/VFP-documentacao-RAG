# Propriedade FileClassLibrary

Contém o nome da biblioteca de classes que contém a classe na qual um formulário em um projeto é baseado. Somente leitura em tempo de design e em tempo de execução.

```foxpro
Object.FileClassLibrary
```

# Observações

Aplica-se a: Objeto File (Visual FoxPro)

A propriedade FileClassLibrary aplica-se apenas a formulários em um projeto e contém a cadeia de caracteres vazia para outros tipos de arquivo.
