# Pasta XSource

A pasta XSource no diretório \Tools do Visual FoxPro contém um arquivo .zip que se expande para pastas contendo arquivos de origem para vários componentes do Visual FoxPro. Sob sua pasta raiz VFPSource, o arquivo .zip inclui pastas contendo arquivos de origem para os aplicativos listados na tabela a seguir.
