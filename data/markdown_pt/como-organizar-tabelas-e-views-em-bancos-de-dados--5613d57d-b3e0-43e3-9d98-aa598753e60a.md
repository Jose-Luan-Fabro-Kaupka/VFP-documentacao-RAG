# Como: organizar tabelas e views em bancos de dados

Você pode alterar o layout de tabelas ou views no Database Designer. Por exemplo, depois de trabalhar no banco de dados, você pode querer retornar as tabelas à altura e largura padrão ou alinhar as tabelas.

### Para organizar tabelas ou views em um banco de dados
- Abra o banco de dados no Database Designer .
- No menu Database, clique em Arrange .
- Na caixa de diálogo Arrange Tables and Views, escolha as opções desejadas e clique em OK .

Para obter mais informações, consulte Arrange Tables and Views Dialog Box.
