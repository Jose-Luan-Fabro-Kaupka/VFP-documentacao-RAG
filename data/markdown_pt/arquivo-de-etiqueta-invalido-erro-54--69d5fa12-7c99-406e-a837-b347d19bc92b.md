# Arquivo de etiqueta inválido (Erro 54)

Foi feita uma tentativa de modificar ou imprimir etiquetas usando um arquivo de etiqueta que não foi criado com o Comando CREATE LABEL ou o Comando MODIFY LABEL, ou que tinha outros erros de definição de arquivo de etiqueta.

Observação Arquivos de etiqueta (lbx) no Visual FoxPro têm a mesma estrutura de tabela e requisitos que formulários de relatório (frx). Para exemplos de erros de definição de arquivos de relatório e layout, consulte Arquivo de relatório "name" inválido (Erro 50).
