# Caixa de diálogo New Class

Especifica informações para uma nova classe, que é usada pelo Class Designer para criar uma classe. Esta caixa de diálogo aparece quando você cria uma nova classe selecionando Class na caixa de diálogo New e então escolhendo New File ou digitando CREATE CLASS na Janela de Comando.
 **Class Name**
Especifica o nome da definição de classe a ser criada. Observação O nome que você especificar é convertido para minúsculas quando a classe é salva.
**Based On**
Especifica a classe a ser usada como classe base para a nova definição de classe. Escolha uma classe base disponível do Visual FoxPro na lista ou clique no botão de reticências (...) para selecionar um arquivo de biblioteca de classes visual (.vcx).
**From**
Exibe o caminho para a biblioteca de classes que você especificou na caixa Based On.
**Store In**
Especifica o nome da biblioteca de classes na qual salvar a nova classe. Para selecionar uma biblioteca de classes visual, clique no botão de reticências (...) para selecionar uma biblioteca de classes.
