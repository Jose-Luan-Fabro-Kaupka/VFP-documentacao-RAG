# Propriedade NewItemID

Especifica o ID do item mais recentemente adicionado a um controle ComboBox ou ListBox. Não disponível em tempo de design; somente leitura em tempo de execução.

```foxpro
 [Form.]Control.NewItemID
```

# Observações

Aplica-se a: ComboBox Control | ListBox Control

Para obter mais informações sobre as diferenças entre usar um ID de item ou um índice, consulte AddItem Method (Visual FoxPro) ou AddListItem Method.
