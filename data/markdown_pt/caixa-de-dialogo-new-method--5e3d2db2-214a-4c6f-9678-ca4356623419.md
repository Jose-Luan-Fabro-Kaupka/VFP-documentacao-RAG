# Caixa de diálogo New Method

Permite criar um método personalizado e especificar atributos para esse método.

Esta caixa de diálogo aparece quando você escolhe New Method no menu Form que aparece quando o Form Designer está aberto ou no menu Class que aparece quando o Class Designer está aberto.
 **Name**
Especifica o nome do novo método.
**Visibility (Class Designer only)**
Especifica o nível de visibilidade para o método: Public O acesso está disponível de qualquer lugar em um aplicativo. Protected Restringe o acesso ao método a membros da classe e subclasses podem acessar propriedades protected. Instâncias de objeto não podem acessar métodos protected. Hidden Restringe o acesso ao método apenas a membros da classe. Instâncias de objeto e subclasses não podem acessar métodos hidden. Para obter mais informações, consulte Protecting and Hiding Class Members .
**Description**
Contém a descrição do método a ser exibida na parte inferior da Properties Window no Class Designer e, se a propriedade não for protected, no Form Designer.
