# Como: criar um framework

Você pode criar um Application Framework usando o Application Wizard ou usando o item New Application na Component Gallery. Quando você usa a Component Gallery, um novo item de pasta de projeto é adicionado à sua pasta Favorites.

Qualquer que seja o método usado, o Visual FoxPro exibe um Application Builder para que você possa adicionar informações a serem armazenadas em uma meta table.

### Para criar uma aplicação
- No menu Tools, aponte para Wizards e clique em Application. -ou- Na pasta Catalogs da Component Gallery, dê um duplo clique no item New Application.
- Na caixa de diálogo Application Wizard: Especifique o nome do projeto. Aceite ou localize o arquivo de projeto. Escolha suas opções para Create project directory structure (padrão) e Add to Favorites catalog (padrão).

Para obter mais informações, consulte Creating Applications with the Application Framework na Ajuda.

Você também pode usar a Component Gallery para adicionar formulários, relatórios, dados e objetos de serviço ao seu novo framework de aplicação e controles a formulários. Quando você usa a Component Gallery para adicionar um formulário a uma aplicação, pode criar um novo formulário ou fazer subclass de uma classe existente.
