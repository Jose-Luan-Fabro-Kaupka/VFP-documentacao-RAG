# Exemplo Add Data Sorting and Filtering to Forms

Arquivo: ...\Samples\Solution\Ffc\DataSort.scx

Este exemplo contém as seguintes classes.

| Classe | Biblioteca | Descrição |
| --- | --- | --- |
| _sortbutton | _table2.vcx | Fornece botões para executar uma classificação de dados em ordem ascendente ou descendente. |
| _navtoolbarclass | _table2.vcx | Fornece controles de navegação de dados em uma barra de ferramentas. |
| _navmenu | _table2.vcx | Fornece um menu de atalho que pode incluir opções de navegação de dados. |

Para obter detalhes sobre todas as classes disponíveis nas classes foundation, consulte Visual FoxPro Foundation Classes A-Z.
