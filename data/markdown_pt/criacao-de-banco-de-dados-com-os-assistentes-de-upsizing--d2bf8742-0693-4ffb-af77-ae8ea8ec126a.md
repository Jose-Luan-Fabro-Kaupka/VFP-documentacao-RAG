# Criação de banco de dados com os Assistentes de Upsizing

O Assistente de Upsizing do SQL Server do Visual FoxPro cria um banco de dados SQL Server que duplica a funcionalidade de um banco de dados do Visual FoxPro da forma mais próxima possível. Você também pode redirecionar views do Visual FoxPro para que usem os dados remotos recém-criados em vez dos dados locais. Você pode usar os assistentes de Upsizing para:
 - Mover dados locais para um servidor remoto.
- Transformar tabelas base locais e views locais em tabelas base remotas e views remotas.
- Migrar uma aplicação local para uma aplicação cliente/servidor. Observação Embora o Assistente de Upsizing acessa o SQL Server, você pode criar uma aplicação cliente/servidor para qualquer fonte de dados ODBC remota. Para servidores diferentes do SQL Server, você pode usar funções SQL pass-through para criar tabelas remotas e, em seguida, usar o Visual FoxPro para criar views remotas que acessam tabelas do servidor. Para obter mais informações sobre o uso de funções SQL pass-through, consulte Enhancing Applications Using SQL Pass-Through Technology. Para obter informações sobre como criar views remotas, consulte How to: Create Remote Views.
