# Propriedade PageNo

Fornece o número da página atual para saída de relatório.

```foxpro
ReportListener.PageNo
```

# Valor de retorno

Tipo de dados Integer.

O valor padrão é 0. Esta propriedade é somente leitura.

# Observações

Aplica-se a: Objeto ReportListener.

A classe ReportListener tem duas propriedades de membro, PageTotal e PageNo, mais uma terceira propriedade, chamada OutputPageCount. Esses itens funcionam de forma diferente das globais de relatório padrão (_PAGENO e _PAGETOTAL), que podem receber valores atribuídos pelo usuário a qualquer momento e não indicam de forma confiável as páginas que foram realmente criadas.

> **Observação:** Fatores que impactam a confiabilidade de _PAGENO e _PAGETOTAL incluem o uso das cláusulas NORESET, NOPAGEEJECT e RANGE no comando REPORT FORM (e cláusula RANGE no comando LABEL) junto com possível reatribuição dos valores pelo usuário.

ReportListener.PageNo e ReportListener.PageTotal, como _PAGENO e _PAGETOTAL, não são sensíveis à cláusula RANGE no comando LABEL ou REPORT FORM. Podem ser usados para expressões de paginação na saída do relatório.

> **Dica:** Para usar essas propriedades de membro de forma confiável em expressões de relatório, você deve atribuir seu ReportListener a uma variável com escopo apropriado para que sejam visíveis durante o comando LABEL ou REPORT FORM. Se você usar o aplicativo Report Output para instanciar seu objeto ReportListener, pode usar a coleção global _oReportOutput do aplicativo para referenciar seu ReportListener. Para obter mais informações, consulte Aplicativo Report Output.

ReportListener.PageNo indica o valor real para uma determinada execução de relatório conforme o mecanismo entende essa execução. Na prática, o mecanismo assume NORESET para ReportListener.PageNo e ReportListener.PageTotal se NOPAGEEJECT foi usado no comando anterior.
