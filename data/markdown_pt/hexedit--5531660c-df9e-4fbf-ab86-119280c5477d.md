# HexEdit

Localizado na pasta Visual FoxPro Tools\Hexedit, Hexedit.app fornece uma forma de examinar valores de endereço ou examinar ou alterar valores de byte e ASCII de dados em um arquivo. HexEdit é um equivalente visual do programa MS-DOS Debug DUMP Command.

> **Cuidado:** Se você deseja editar o arquivo, certifique-se de que ele não está em uso ou bloqueado de outra forma.

```foxpro
DO HEXEDIT.app
```

# Observações

Quando você escolhe um arquivo, o HexEdit exibe uma caixa de diálogo com as seguintes opções de controle.

> **Observação:** Se você deseja editar o arquivo, certifique-se de que ele não está em uso ou bloqueado de outra forma.

# Opções da caixa de diálogo
 **Select File**
Exibe a caixa de diálogo Open para que você possa alterar o arquivo atual.
**Address**
Exibe o endereço de deslocamento do arquivo do primeiro byte de dados em um bloco de 16 bytes exibido nas colunas seguintes.
**0...F**
Exibe dezesseis números de 2 dígitos, representando o valor de byte hexadecimal nessa localização do arquivo.
**Text**
Exibe a representação ASCII do valor de byte na localização correspondente nas colunas de valor de byte.
**Save Edits**
Salva as alterações no arquivo aberto.
**Undo Edits**
Descarta todas as edições no arquivo aberto.
**Find**
Permite especificar um caractere a ser buscado no arquivo. Você também pode escolher pesquisar para frente ou para trás a partir de qualquer ponto do arquivo.
**Jump**
Permite especificar um endereço hexadecimal ou decimal para editar.
**Close**
Fecha o HexEdit e o arquivo aberto.
