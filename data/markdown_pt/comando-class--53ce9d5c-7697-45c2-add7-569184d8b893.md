# Comando @ ... CLASS

Cria um controle ou objeto que pode ser ativado com READ.

```foxpro
@ nRow, nColumn CLASS ClassName NAME ObjectName
```

#### Parâmetros
 **@ nRow , nColumn**
Especifica a posição do controle ou objeto. A altura e a largura do controle ou objeto são determinadas pelos valores padrão de altura e largura da classe. As linhas são numeradas de cima para baixo. A primeira linha é o número 0 na janela principal do Visual FoxPro ou em uma janela definida pelo usuário. A linha 0 é a linha imediatamente abaixo da barra de menu do sistema do Visual FoxPro. As colunas são numeradas da esquerda para a direita. A primeira coluna é o número 0 na janela principal do Microsoft Visual FoxPro ou em uma janela definida pelo usuário. Quando um controle ou objeto é colocado em uma janela definida pelo usuário, as coordenadas de linha e coluna são relativas à janela definida pelo usuário, não à janela principal do Visual FoxPro. Uma posição na janela principal do Visual FoxPro ou em uma janela definida pelo usuário é determinada pela fonte da janela. A maioria das fontes pode ser exibida em uma ampla variedade de tamanhos; algumas são proporcionalmente espaçadas. Uma linha corresponde à altura da fonte atual; uma coluna corresponde à largura média de uma letra na fonte atual. Você pode posicionar o controle ou objeto usando frações decimais para coordenadas de linha e coluna.
**CLASS ClassName**
Especifica a classe do controle ou objeto. ClassName pode ser uma classe base do Visual FoxPro ou uma classe definida pelo usuário. A tabela a seguir lista as classes base do Visual FoxPro que você pode especificar para ClassName .
**NAME ObjectName**
Especifica o nome da variável de referência do objeto a criar. As propriedades, eventos e métodos orientados a objetos do controle ou objeto podem ser manipulados referenciando esta variável. Para uma lista completa das classes base do Visual FoxPro, consulte Classes base no Visual FoxPro .

# Observações

@ ... CLASS fornece uma etapa intermediária para converter programas e aplicações criados em versões anteriores do FoxPro para os métodos de programação orientada a objetos preferidos do Visual FoxPro. Para informações adicionais sobre compatibilidade com versões anteriores com controles do FoxPro 2.x, consulte Controles e objetos criados em versões anteriores.

Para informações sobre programação orientada a objetos no Visual FoxPro, consulte Programação orientada a objetos.

# Exemplo

O exemplo a seguir demonstra como @ ... CLASS pode ser usado com técnicas de programação usadas em versões anteriores do FoxPro (neste exemplo, uso de READ para ativar controles). @ ... CLASS é usado para criar uma caixa de texto cujas propriedades podem ser alteradas com as técnicas de programação orientada a objetos do Visual FoxPro.

ON KEY LABEL é usado para exibir a caixa de diálogo Cor do Windows quando você pressiona CTRL+I. O TextBox é colocado na janela principal do Visual FoxPro usando @ ... CLASS, e READ ativa a caixa de texto.

```foxpro
CLEAR
ON KEY LABEL CTRL+I _SCREEN.PageFrame1.Page1.goFirstName.BackColor;
    = GETCOLOR()
@ 2,2 SAY 'Press Ctrl+I to change the background color'
@ 4,2 CLASS TextBox NAME goFirstName
READ
CLEAR
```
