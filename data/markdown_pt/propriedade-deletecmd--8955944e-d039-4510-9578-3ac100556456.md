# Propriedade DeleteCmd

Especifica o comando a usar ao excluir linhas. Leitura/gravação em tempo de design e em tempo de execução.

```foxpro
CursorAdapter.DeleteCmd [ = cCommand ]
```

# Valor de retorno
 **cCommand**
Tipo de dados caractere. A tabela a seguir lista os valores possíveis para DeleteCmd . cCommand Descrição Cadeia de caracteres ou expressão Especifica uma cadeia de comando válida para a fonte de dados na propriedade DeleteCmdDataSource. Cadeia vazia ("") O objeto CursorAdapter gera um comando SQL DELETE automaticamente se a propriedade AllowDelete estiver definida como True (.T.). Para obter mais informações sobre geração automática de comandos SQL, consulte Gerenciamento de acesso a dados usando CursorAdapters .
