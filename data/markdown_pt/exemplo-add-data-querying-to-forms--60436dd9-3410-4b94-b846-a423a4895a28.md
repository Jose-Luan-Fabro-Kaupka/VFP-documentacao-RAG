# Exemplo Add Data Querying to Forms

Arquivo: ...\Samples\Solution\Ffc\DataQry.scx

Este exemplo contém as seguintes classes.

| Classe | Biblioteca | Descrição |
| --- | --- | --- |
| _findnextbuttons | _table.scx | Fornece um conjunto de botões Localizar/Localizar próximo para navegar em uma tabela. |
| _locatebutton | _table2.vcx | Fornece um botão Locate para exibir uma caixa de diálogo de navegação em uma tabela. |
| _findbutton | _table.vcx | Fornece um botão Localizar genérico. |

Para detalhes sobre todas as classes disponíveis nas classes base, consulte Classes base do Visual FoxPro de A a Z.
