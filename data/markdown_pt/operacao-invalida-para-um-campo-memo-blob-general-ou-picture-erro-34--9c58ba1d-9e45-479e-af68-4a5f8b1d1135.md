# Operação inválida para um campo Memo, Blob, General ou Picture (Erro 34)

- Um comando INDEX não pode especificar um campo Memo ou Blob como sua expressão de chave.
- Não havia memória suficiente para o Visual FoxPro concluir uma operação.
- Uniões entre tipos de coluna diferentes não são permitidas quando uma das colunas é do tipo Memo ou General, a menos que UNION ALL seja usado.
