# Gerenciando classes e bibliotecas de classes

O Visual FoxPro usa definições armazenadas de classes em arquivos de biblioteca de classes. Você pode executar tarefas como criar bibliotecas de classes, adicionar classes e subclasses, copiar e renomear classes, redefinir relacionamentos de classe pai e remover classes de bibliotecas de classes.

O Visual FoxPro fornece vários meios para gerenciar classes e bibliotecas de classes. No entanto, usar o Class Browser para gerenciar classes também atualiza projetos e formulários, além de bibliotecas de classes. Alterações que você faz no Class Browser se propagam por cada arquivo de biblioteca de classes (.vcx) e formulário (.scx) que está aberto no Class Browser.
