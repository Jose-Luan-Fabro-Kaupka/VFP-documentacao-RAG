# Propriedades SelectedBackColor, SelectedForeColor

Especifica a cor de fundo ou de primeiro plano do texto selecionado. Disponível em tempo de design e em tempo de execução. Há duas versões da sintaxe para cada uma dessas duas propriedades.

```foxpro
Control.SelectedBackColor[ = nColor]
```

```foxpro
Control.SelectedBackColor = RGB(nRedValue, nGreenValue, nBlueValue)
```

```foxpro
Control.SelectedForeColor[ = nColor]
```

```foxpro
Control.SelectedForeColor = RGB(nRedValue, nGreenValue, nBlueValue)
```

# Valor de retorno
 **nColor**
Especifica um único número para representar a cor. Observação Na janela Propriedades, você pode clicar duas vezes em qualquer uma das propriedades de cor para exibir a caixa de diálogo Cor. Você pode escolher ou definir cores nessa caixa de diálogo. As intensidades de vermelho, verde e azul correspondentes à cor escolhida tornam-se as configurações dessas propriedades depois que você fecha a caixa de diálogo Cor.

# Observações

Aplica-se a: Controle ComboBox | Controle EditBox | Controle Spinner | Controle TextBox (Visual FoxPro)
