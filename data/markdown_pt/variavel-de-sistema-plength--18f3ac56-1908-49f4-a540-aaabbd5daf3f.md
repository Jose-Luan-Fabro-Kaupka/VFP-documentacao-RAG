# Variável de sistema _PLENGTH

Incluída para compatibilidade com versões anteriores. Use o Designer de Relatórios.

Retorna ou define o comprimento da página.

```foxpro
_PLENGTH = expN
```

# Observações

Incluída para compatibilidade com versões anteriores — use o Gerador de Relatórios.

_PLENGTH contém um valor numérico que determina o número de linhas de saída por página. O valor de _PLENGTH pode variar de 1 a 32.767, inclusive. O padrão é 66. Use _PLENGTH em conjunto com _PLINENO para determinar quando é necessário ejetar uma página.
