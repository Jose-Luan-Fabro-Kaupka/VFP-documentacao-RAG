# Comandos com escopo em uma sessão de dados

Estes comandos afetam apenas a sessão de dados em que são emitidos.

| Uso | Para |
| --- | --- |
| Comando BEGIN TRANSACTION | Iniciar uma transação. |
| Comando END TRANSACTION | Encerrar a transação atual e salvar quaisquer alterações feitas em tabelas, arquivos memo de tabela ou arquivos de índice incluídos em uma transação. |
| Comando ROLLBACK | Cancelar quaisquer alterações feitas durante a transação atual. |
| Comando SET ANSI | Especificar se uma cadeia de caracteres ou expressão binária mais curta deve ser preenchida durante a comparação em comandos SQL. |
| Comando SET AUTOINCERROR | Especificar se tentativas de atualizar ou inserir valores em um campo com valores de incremento automático geram erros. |
| Comando SET AUTOSAVE | Determinar se o Visual FoxPro grava buffers de dados no disco quando você sai de um READ ou retorna à janela Command. |
| Comando SET BLOCKSIZE | Especificar como o Visual FoxPro aloca espaço em disco para o armazenamento de campos memo. |
| Comando SET CARRY | Determinar se o Visual FoxPro transporta dados do registro atual para um novo registro criado com INSERT, APPEND e BROWSE. |
| Comando SET CENTURY | Exibir a porção do século em expressões de data e determinar como interpretar datas que especificam apenas anos com 2 dígitos. |
| Comando SET COLLATE | Especificar uma sequência de ordenação para campos de caractere em operações subsequentes de indexação e classificação. |
| Comando SET CONFIRM | Especificar se o usuário pode sair de uma caixa de texto digitando além do último caractere na caixa de texto. |
| Comando SET CURRENCY | Definir o símbolo de moeda e especificar sua posição na exibição de expressões numéricas, de moeda, float e double. |
| Comando SET DATABASE | Especificar o banco de dados atual. |
| Comando SET DATE | Especificar o formato para a exibição de expressões Date e DateTime. |
| Comando SET DECIMALS | Especificar o número de casas decimais exibidas em expressões numéricas. |
| Comando SET DELETED | Especificar se processar registros marcados para exclusão e se estão disponíveis para uso com outros comandos. |
| Comando SET EXACT | Especificar regras a serem usadas ao comparar duas cadeias de caracteres de comprimentos diferentes. |
| Comando SET EXCLUSIVE | Especificar se abrir arquivos de tabela para uso exclusivo ou compartilhado em uma rede. |
| Comando SET FIELDS | Especificar quais campos em uma tabela podem ser acessados. |
| Comando SET FIXED | Especificar se o número de casas decimais usadas na exibição de dados numéricos é fixo. |
| Comando SET HOURS | Definir o relógio do sistema para um formato de hora de 12 ou 24 horas. |
| Comando SET LOCK | Habilitar ou desabilitar bloqueio automático de arquivo em determinados comandos. |
| Comando SET MARK TO | Especificar um delimitador para a exibição de expressões de data. |
| Comando SET MEMOWIDTH | Especificar a largura exibida de campos memo e expressões de caractere. |
| Comando SET MULTILOCKS | Determinar se você pode bloquear vários registros usando LOCK( ) ou RLOCK( ). |
| Comando SET NEAR | Determinar onde o ponteiro de registro é posicionado após uma operação FIND ou SEEK sem sucesso. |
| Comando SET NULL | Determinar como valores nulos são suportados pelos comandos ALTER TABLE, CREATE TABLE e INSERT - SQL. |
| Comando SET POINT | Determinar o caractere de ponto decimal usado na exibição de expressões numéricas e de moeda. |
| Comando SET REFRESH | Especificar o intervalo de atualização para uma janela browse, janela de edição de memo ou buffers de memória local alterados por outros usuários na rede. |
| Comando SET REPROCESS | Especificar com que frequência e por quanto tempo o Visual FoxPro tenta bloquear um arquivo ou registro após uma tentativa de bloqueio sem sucesso. |
| Comando SET SAFETY | Exibir uma caixa de diálogo antes de sobrescrever um arquivo existente ou determinar se regras de tabela ou campo, valores padrão e mensagens de erro são avaliados quando alterações são feitas no Table Designer ou com ALTER TABLE. |
| Comando SET SECONDS | Especificar se os segundos são exibidos na porção de hora de um valor DateTime. |
| Comando SET SYSFORMATS | Especificar se as configurações de sistema do Visual FoxPro for Windows são atualizadas com as configurações atuais do sistema Microsoft Windows. |
| Comando SET TALK | Determinar se o Visual FoxPro exibe resultados de comandos. |
| Comando SET UNIQUE | Especificar se registros com valores de chave de índice duplicados são mantidos em um arquivo de índice. |
