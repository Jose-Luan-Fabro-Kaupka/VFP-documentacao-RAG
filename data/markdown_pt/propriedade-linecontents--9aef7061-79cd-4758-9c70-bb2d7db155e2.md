# Propriedade LineContents

Especifica o conteúdo da linha que produziu um objeto de exceção. Leitura/gravação em tempo de execução.

```foxpro
Exception.LineContents
```

# Valor de retorno

Tipo de dados Character

# Observações

Aplica-se a: Exception Class (Visual FoxPro)

Idêntico ao valor retornado pela instrução:

```foxpro
MESSAGE(1)
```
