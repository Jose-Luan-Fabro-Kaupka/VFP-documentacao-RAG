# Trabalho com servidores de Automação

Você pode expor funcionalidades que outros aplicativos podem usar criando servidores de Automação no Visual FoxPro.

Por exemplo, você pode criar um servidor de Automação que exiba formulários reutilizáveis ou encapsule uma rotina complexa em um componente mais simples que outros programadores possam usar. É possível criar classes para gerar objetos que tratem regras de negócios de toda a empresa. Um aplicativo cliente pode usar esses objetos de regras de negócios para chamar métodos e passar parâmetros ao servidor de Automação, que pode recuperar ou armazenar dados, executar operações e retornar resultados.
