# SYS(3095) - Ponteiro IDispatch

Retorna um ponteiro IDispatch de saída para um objeto COM

```foxpro
SYS(3095, oObject)
```

#### Parâmetros
 **oObject**
Representa uma referência a um objeto COM, como _VFP ou Excel.Application.

# Valor de retorno

Character

# Observações

Este ponteiro é fornecido para desenvolvedores experientes que precisam de um ponteiro de objeto para uso em rotinas de API.
