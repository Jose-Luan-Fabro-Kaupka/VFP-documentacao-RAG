# Função DTOS( )

Retorna uma data como cadeia de caracteres no formato aaaammdd a partir de uma expressão Date ou DateTime especificada.

```foxpro
DTOS(dExpression | tExpression)
```

#### Parâmetros
**dExpression**
Especifica a expressão Date que DTOS( ) converte em uma cadeia de oito dígitos.
**tExpression**
Especifica a expressão DateTime que DTOS( ) converte em uma cadeia de oito dígitos.

# Valor de retorno

Character

# Observações

Esta função é útil para indexar tabelas por um campo Date ou DateTime. Ela equivale a DTOC( ) quando o argumento opcional 1 é incluído.

A cadeia de caracteres retornada por DTOS( ) não é afetada por SET DATE nem SET CENTURY.

# Exemplo

```foxpro
CLEAR
? DTOS(DATE())
```
