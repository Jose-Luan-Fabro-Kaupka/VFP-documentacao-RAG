# Análise dos requisitos de dados

Seu primeiro passo ao projetar um banco de dados do Visual FoxPro é analisar seus requisitos de dados determinando a finalidade do banco de dados e como ele será usado. Isso indica quais informações você deseja obter do banco de dados. Com isso, você pode determinar sobre quais assuntos precisa armazenar fatos (as tabelas) e quais fatos precisa armazenar sobre cada assunto (os campos nas tabelas).

Converse com as pessoas que usarão o banco de dados. Faça um brainstorming sobre as perguntas que você gostaria que o banco de dados respondesse. Esboce os relatórios que você gostaria que ele produzisse. Reúna os formulários que você usa atualmente para registrar seus dados. Você usará todas essas informações nas etapas restantes do processo de design.

# Exemplo

Suponha que a Tasmanian Traders, uma empresa de importação/exportação que vende alimentos especiais de todo o mundo, deseja um banco de dados que possa rastrear informações sobre as vendas e o inventário da empresa.

Comece escrevendo uma lista de perguntas que o banco de dados deve ser capaz de responder. Quantas vendas do nosso produto em destaque fizemos no mês passado? Onde vivem nossos melhores clientes? Quem é o fornecedor do nosso produto mais vendido?

Em seguida, reúna todos os formulários e relatórios que contêm informações que o banco de dados deve ser capaz de produzir. A empresa atualmente usa um relatório impresso para acompanhar os produtos sendo pedidos e um formulário de pedido para receber novos pedidos. A ilustração a seguir mostra esses dois documentos.
