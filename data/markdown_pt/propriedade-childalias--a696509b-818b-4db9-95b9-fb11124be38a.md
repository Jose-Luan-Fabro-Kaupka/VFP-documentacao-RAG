# Propriedade ChildAlias

Especifica o alias da tabela filha. Somente leitura em tempo de design e em tempo de execução.

```foxpro
DataEnvironment.Relation.ChildAlias[ = cText]
```

# Valor de retorno
 **cText**
Especifica o alias da tabela filha na relação.

# Observações

Aplica-se a: Relation Object

A configuração da propriedade ChildAlias deve ser o mesmo nome que a configuração da propriedade Alias para o Cursor object que representa a tabela filha.
