# Amostras Solution de bancos de dados

Estas amostras Solution ilustram tarefas de desenvolvimento de aplicativos que você pode realizar com bancos de dados.

# Nesta seção
 **Create a Default Unique ID Value for a Field Sample**
Ilustra como usar um stored procedure em um banco de dados para fornecer um valor de chave primária padrão.
**Create Small Indexes Using BINTOC( ) Sample**
Ilustra como usar vários esquemas de indexação usando tipos de dados numéricos e inteiros para reduzir o tamanho do índice e o espaço em disco.
**Index on Expressions Sample**
Ilustra várias opções que você pode considerar ao usar um campo de caractere para representar um ID exclusivo, frequentemente composto por dados numéricos.
**Nest Transactions Sample**
Ilustra o início, o término e a reversão de transações.
**Programmatically Check Table Properties Sample**
Ilustra como recuperar informações sobre uma tabela em tempo de execução.
**Sort or Order a Table at Run Time Sample**
Ilustra como alterar a ordem em que os registros da tabela são listados.
**Use DBC Events Sample**
Ilustra como eventos de banco de dados permitem que você execute ações quando um banco de dados e seus objetos são abertos, acessados ou manipulados.
