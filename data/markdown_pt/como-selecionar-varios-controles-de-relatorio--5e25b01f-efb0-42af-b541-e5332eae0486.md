# Como: selecionar vários controles de relatório

Você pode selecionar vários controles de relatório no Report Designer ou Label Designer para manipulá-los temporariamente como um grupo. Você também pode limpar a seleção de controles específicos quando não deseja mais que façam parte do grupo de controles selecionados no designer.

### Para selecionar vários controles de relatório
- Abra o relatório ou label no designer apropriado.
- No designer, escolha uma das seguintes opções: Para selecionar vários controles de relatório, pressione e mantenha pressionada a tecla SHIFT enquanto seleciona cada controle; ou arraste uma caixa de seleção ao redor dos controles que deseja selecionar. -OU- Para selecionar todos os controles de relatório em uma faixa de relatório, pressione e mantenha pressionada a tecla SHIFT e clique duas vezes na faixa de relatório que contém os controles que deseja selecionar. -OU- Para selecionar todos os controles de relatório no designer, no menu Edit, clique em Select All . Dica Às vezes, controles de relatório podem estar posicionados fora da tela. Você pode selecionar esses controles junto com todos os outros controles de relatório no designer escolhendo Select All . Conforme os controles são selecionados, alças de seleção aparecem nas bordas de cada controle.

Agora você pode manipular os controles de relatório selecionados temporariamente como um grupo.

### Para limpar a seleção de um controle de relatório de um grupo de controles selecionados usando o mouse
- No designer, pressione e mantenha pressionada a tecla SHIFT enquanto usa o mouse para clicar no controle de relatório que deseja remover da seleção atual.

### Para limpar a seleção de um controle de relatório de um grupo de controles selecionados usando a caixa de diálogo Multiple Selection do Report Builder
- Clique com o botão direito em um dos controles selecionados e selecione Properties no menu de contexto. A caixa de diálogo Multiple Selection é aberta. Dica Você também pode clicar duas vezes no grupo de controles de relatório selecionados no designer para abrir a caixa de diálogo Multiple Selection. Observação Se a variável de sistema _REPORTBUILDER não estiver definida para o Report Builder padrão ou estiver definida para um builder de terceiros, uma caixa de diálogo de controle de relatório é exibida ou uma caixa de diálogo diferente pode ser exibida. Para obter mais informações, consulte _REPORTBUILDER System Variable .
- Na caixa de diálogo Multiple Selection, clique na guia Selection se ela não estiver selecionada.
- Na lista Object na guia Selection, clique no controle de relatório desejado e depois em Clear selection . Dica Para selecionar vários controles na lista Object, pressione e mantenha pressionada a tecla CTRL enquanto clica no nome de cada controle de relatório.
- Quando terminar, clique em OK .

Para obter mais informações, consulte Selection Tab, Multiple Selection Dialog Box (Report Builder).
