# GO | GOTO Comando

Move o ponteiro do registro para o número de registro especificado. Existem várias versões da sintaxe.

```foxpro
GO [RECORD] nRecordNumber [IN nWorkArea | IN cTableAlias]
```

```foxpro
GO TOP | BOTTOM [IN nWorkArea | IN cTableAlias]
```

```foxpro
GOTO [RECORD] nRecordNumber [IN nWorkArea | IN cTableAlias]
```

```foxpro
GOTO TOP | BOTTOM [IN nWorkArea | IN cTableAlias]
```

#### Parâmetros
 **RECORD nRecordNumber**
Especifica o número do registro físico para o qual você move o ponteiro do registro. Você pode omitir GO ou GOTO totalmente e especificar apenas o número do registro. Se você especificar apenas o número do registro, poderá mover o ponteiro do registro somente dentro da área de trabalho atual.
**IN nWorkArea**
Especifica a área de trabalho da tabela na qual você move o ponteiro do registro.
**IN cTableAlias**
Especifica o alias da tabela na qual você move o ponteiro do registro.
**TOP**
Posiciona o ponteiro do registro no primeiro registro da tabela. Se a tabela tiver um índice ascendente em uso, o primeiro registro será o registro com o menor valor de chave. Se o índice estiver em ordem decrescente, o primeiro registro será o registro com o valor de chave mais alto.
**BOTTOM**
Posiciona o ponteiro do registro no último registro da tabela. Se a tabela tiver um índice ascendente em uso, o último registro será o registro com o valor de chave mais alto. Se o índice estiver em ordem decrescente, o último registro será o registro com o menor valor de chave.

# Observações
Você pode usar GO e GOTO alternadamente. Esses comandos operam na tabela da área de trabalho atual, a menos que você especifique outra área de trabalho com a cláusula IN.

Se você usar o argumento nRecordNumber com GOTO e o registro físico especificado não existir na tabela, o sistema gerará um erro "O registro está fora do intervalo". O ponteiro de registro não se moverá.

> **Observação:** GOTO [RECORD] nRecordNumber trabalha com registros físicos. Assim, ele ignora as configurações SET DELETED ou SET FILTER. Se o número do registro físico especificado existir na tabela, o sistema moverá o ponteiro para o registro. Isso ocorre mesmo que esse registro tenha sido marcado para exclusão ou possa estar marcado para exclusão por qualquer filtro em vigor na tabela. No entanto, GOTO TOP/BOTTOM funciona com posições de registros lógicos. Portanto, você deve respeitar as configurações SET DELETED, SET FILTER e SET ORDER.

# Exemplo
```foxpro
CLOSE DATABASES
OPEN DATABASE (HOME(2) + 'data\testdata')
USE products  && Opens Products table
USE customer IN 0  && Opens Customer table
GO BOTTOM IN products
CLEAR
? RECNO('products')
GO TOP
? RECNO()     && Displays 1
GO 5
? RECNO()     && Displays 5
```
