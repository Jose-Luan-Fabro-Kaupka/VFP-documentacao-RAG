# Guia Forms, Application Builder

Nesta guia do Application Builder, você pode especificar tipos de menu, o menu do qual um formulário é chamado, barras de ferramentas e se um formulário pode ser instanciado várias vezes.

Para cada formulário listado, marque as opções que deseja aplicar.
 **Name**
Permite especificar o nome amigável do formulário selecionado.
**Add**
Permite selecionar um formulário para adicionar à sua aplicação. Quando você seleciona um formulário para adicionar, as opções de caixa de seleção são habilitadas. O Application Builder cria automaticamente uma lista de todos os formulários que você gerou na guia Data do Application Builder.
**Edit**
Permite modificar o formulário selecionado no Form Designer. Você pode querer fazer isso para modificar o tamanho ou a forma de imagens em um formulário. Para obter mais informações, consulte Form Designer.
**Remove**
Remove um formulário da sua aplicação.
**Single Instance**
Especifica se você pode abrir apenas uma única instância de um formulário na aplicação. Se você não marcar esta caixa, pode abrir o mesmo formulário em registros diferentes para fazer comparações.
**Use Navigation Toolbar**
Especifica que o builder inclua uma barra de ferramentas de navegação para o formulário selecionado.
**Use Navigation Menu**
Especifica que o builder inclua um menu de navegação para o formulário selecionado.
**Appear in File New dialog**
Especifica que o nome do formulário apareça na caixa de diálogo New da aplicação compilada.
**Appear in File Open dialog**
Especifica que o nome do formulário apareça na caixa de diálogo Open da aplicação compilada.

Se você escolher OK, o builder fecha, aplicando as configurações de propriedade de todas as guias.
