# Variável de sistema _FOXCODE

Especifica o nome do arquivo de tabela usado pelo IntelliSense do Visual FoxPro.

```foxpro
_FOXCODE [= cDBFFileName]
```

#### Parâmetros
 **cDBFFileName**
Especifica o nome do arquivo que contém a tabela que define a funcionalidade do IntelliSense. Por padrão, _FOXCODE especifica FoxCode.dbf, armazenado na pasta de aplicativos do usuário do Windows ou no local HOME(1).

# Observações

Assim como FoxUser.dbf, FoxCode.dbf é aberto na inicialização do Visual FoxPro.

Para acessar suas informações, consulte Personalização do IntelliSense no Visual FoxPro.
