# Como: ativar ou desativar IntelliSense

Você pode ativar ou desativar a funcionalidade IntelliSense usando o IntelliSense Manager ou programaticamente. Por padrão, a funcionalidade IntelliSense está ativada.

### Para desativar ou ativar IntelliSense
- No menu Tools, clique em IntelliSense Manager .
- Na caixa de diálogo IntelliSense Manager, clique na guia General.
- Para desativar IntelliSense, desmarque a caixa de seleção Enable IntelliSense. -OU- Para ativar IntelliSense, selecione a caixa de seleção Enable IntelliSense.

Você também pode ativar ou desativar a funcionalidade IntelliSense programaticamente definindo os valores apropriados na propriedade EditorOptions usando a variável de sistema _VFP. Para obter mais informações, consulte Visual FoxPro IntelliSense Manager Window e EditorOptions Property.

Você também pode definir níveis de disponibilidade para diferentes partes da funcionalidade IntelliSense. Por exemplo, quando IntelliSense está definido como Manual, você pode ativar IntelliSense usando atalhos de teclado. Para obter mais informações, consulte How to: Set IntelliSense Options.
