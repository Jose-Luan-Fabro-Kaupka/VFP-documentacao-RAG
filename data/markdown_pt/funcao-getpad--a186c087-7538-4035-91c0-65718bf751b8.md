# Função GETPAD( )

Retorna o título do menu para uma posição determinada na barra de menus.

```foxpro
GETPAD(cMenuBarName, nMenuBarPosition)
```

#### Parâmetros
 **cMenuBarName**
Especifica o nome da barra de menus.
**nMenuBarPosition**
Especifica uma posição na barra de menus. nMenuPosition pode variar de 1 (o título de menu mais à esquerda na barra de menus) até o número de títulos de menu na barra de menus.

# Valor de retorno

Character

# Observações

Nomes de menu em uma barra de títulos podem ser adicionados, removidos ou reorganizados. Use DEFINE PAD para adicionar um nome de menu a uma barra de títulos ou RELEASE PAD para remover um título de menu.

# Exemplo

O programa a seguir usa GETPAD( ) para testar se o nome do menu Edit está na barra de menus do sistema do Visual FoxPro. Se estiver, GETPAD( ) retorna o nome do menu. (Para restaurar a barra de menus Edit ao estado padrão, execute o comando SET SYSMENU TO DEFAULT.)

```foxpro
FOR gnCount = 1 TO CNTPAD('_msysmenu')      && Number of pads
   IF PRMPAD('_msysmenu', GETPAD('_msysmenu', gnCount)) = 'Edit'
      RELEASE PAD (GETPAD('_msysmenu', gnCount)) OF _msysmenu
      EXIT
   ENDIF
ENDFOR
```
