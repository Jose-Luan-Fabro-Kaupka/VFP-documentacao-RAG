# Guia Standard, caixa de diálogo Component Gallery Options

Permite especificar configurações de comportamento padrão que são globais para todos os catálogos e pastas ou itens. As seguintes configurações estão disponíveis nesta guia:

# Padrões globais
 **Enable item renaming**
Habilita a edição de etiqueta com seleção e atraso nos painéis da Component Gallery. A renomeação está sempre disponível no menu de atalho.
**FFC Builder Lock**
Permite especificar que um builder é aberto quando você solta uma classe em um formulário.
**Drag and drop to desktop**
Permite que itens da galeria sejam abertos como amostras na janela da área de trabalho do Visual FoxPro.
**Advanced editing enabled**
Habilita as guias de edição avançada Type , Scripts , Views e Comments de todas as caixas de diálogo Item Properties .

# Comportamento padrão do catálogo
 **Open file as new view**
Altera o comportamento padrão de clique duplo de itens da galeria de Modify para Run .
**Add file to current view**
Altera o comportamento padrão de clique duplo de itens da galeria de Open para Add .

# Comportamento padrão do item
 **Modify item file**
Define o comportamento padrão de clique duplo de itens da galeria como Modify .
**Run item file**
Define o comportamento padrão de clique duplo de itens da galeria como Run .
