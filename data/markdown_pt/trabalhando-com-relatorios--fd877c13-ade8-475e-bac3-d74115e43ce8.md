# Trabalhando com relatórios

Depois de coletar e organizar dados na sua aplicação, você pode projetar, criar e adicionar relatórios ao seu projeto de aplicação. Para criar um relatório, siga estas etapas gerais:
 - Determine o tipo de relatório que deseja criar.
- Crie o layout de página do relatório.
- Modifique e personalize o arquivo de layout de página.
- Inclua e gerencie dados para o seu relatório.
- Defina opções de saída para o seu relatório.
- Execute o relatório.
