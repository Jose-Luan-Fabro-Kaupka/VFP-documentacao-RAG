# Como: Abrir Tabelas (Visual FoxPro)

Para trabalhar com tabelas e adicionar dados a tabelas, você deve primeiro abri-las.

### Para abrir uma tabela livre
- No menu File, clique em Open .
- Na caixa de diálogo Open, navegue até e selecione o arquivo de tabela (.dbf) que deseja abrir e clique em OK . A tabela abre mesmo que a tabela não apareça.

Para exibir os registros na tabela, abra uma janela browse. Para exibir a estrutura da tabela, abra o Table Designer. Para obter mais informações, consulte Como: Visualizar Registros em Tabelas e Como: Editar Estrutura de Tabela.

### Para abrir uma tabela de banco de dados
- Abra o banco de dados no Database Designer .
- Clique na tabela que deseja abrir.
- Para abrir a tabela, execute uma das seguintes ações: Abra uma janela browse para a tabela. -OU- No menu Window, clique em Data Session . Na janela Data Session, clique em Open . A caixa de diálogo Open aparece. Na lista Tables in database, clique na tabela que deseja abrir e, em seguida, OK . A tabela selecionada abre e aparece na janela Data Session.

Para obter mais informações, consulte Como: Visualizar Registros em Tabelas e Gerenciando Tabelas em Sessões de Dados.

### Para abrir uma tabela em um projeto
- Abra o projeto no Project Manager .
- No Project Manager , expanda o nó Data.
- Selecione uma tabela de banco de dados ou uma tabela livre: Para abrir uma tabela de banco de dados, expanda o nó Databases, depois o nó do banco de dados contendo a tabela, depois o nó Tables, e clique na tabela que deseja abrir. Observação Clicar duas vezes na tabela abre o Table Designer . Para obter mais informações, consulte Criando Tabelas . -OU- Para abrir uma tabela livre, expanda o nó Free Tables, e clique na tabela que deseja abrir.
- Para navegar na tabela, no menu View, clique em Browse . Para abrir a tabela em uma sessão de dados, execute o seguinte: No menu Window, clique em Data Session . Na janela Data Session, clique em Open . A caixa de diálogo Open aparece. Na lista Tables in database, clique na tabela que deseja abrir e, em seguida, OK . A tabela selecionada abre e aparece na janela Data Session.

Para obter mais informações, consulte Como: Visualizar Registros em Tabelas e Gerenciando Tabelas em Sessões de Dados.

### Para abrir uma tabela programaticamente
- Use o comando USE.

Para obter mais informações, consulte Comando USE.
