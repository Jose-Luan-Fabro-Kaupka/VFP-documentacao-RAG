# Comando SET MACKEY

Especifica uma tecla ou combinação de teclas que exibe a caixa de diálogo Macro Key Definition.

```foxpro
SET MACKEY TO [KeyLabelName]
```

#### Parâmetros
 **KeyLabelName**
Especifica a tecla ou combinação de teclas que exibe a caixa de diálogo Macro Key Definition. Consulte ON KEY LABEL para os rótulos de tecla a usar.

# Observações

Use SET MACKEY para alterar a combinação de teclas padrão para exibir a caixa de diálogo Macro Key Definition. Escolha Macros no menu Tools para exibir esta caixa de diálogo.
