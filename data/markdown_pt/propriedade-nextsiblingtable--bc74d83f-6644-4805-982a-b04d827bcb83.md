# Propriedade NextSiblingTable

Especifica o próximo objeto XMLTable irmão para um objeto XMLTable aninhado em uma hierarquia. Somente leitura em tempo de design e em tempo de execução.

```foxpro
XMLTable.NextSiblingTable = oXMLTable
```

# Valor de retorno
 **oXMLTable**
Uma referência de objeto a um objeto XMLTable irmão.
**null (.NULL.)**
Propriedade não preenchida. Indica que não há objeto XMLTable irmão.

# Observações

Aplica-se a: XMLTable Class
