# Tipos de dados e de campos

Esta seção contém uma lista de tipos de dados e funções que você pode usar para operar em tipos de dados.

# Nesta seção
 **Visual FoxPro Data and Field Types**
Fornece informações sobre tipos de dados do Visual FoxPro, incluindo descrições e valores permitidos e o intervalo e o tamanho desses valores.
**XML Data in Visual FoxPro**
Introduz dados XML no Visual FoxPro.
**Visual FoxPro and XML Schema Data Type Mapping**
Descreve tipos de dados XML Schema e mostra como eles mapeiam para tipos de dados do Visual FoxPro e o inverso.
**Blob Data Type**
Descreve o tipo de dados Blob, que armazena dados binários com comprimento indeterminado.
**Character Data Type**
Descreve o tipo de dados Character, que armazena texto alfanumérico. O tipo de campo Character (Binary) armazena texto alfanumérico que você não deseja traduzir entre páginas de código.
**Currency Data Type**
Descreve o tipo de dados Currency, que armazena valores monetários ou cálculos financeiros precisos.
**Date Data Type (Visual FoxPro)**
Descreve o tipo de dados Date, que armazena valores de data sem valores de hora.
**DateTime Data Type**
Descreve o tipo de dados DateTime, que armazena valores de data e hora ou apenas valores de data.
**Double Field Type**
Descreve o tipo de campo Double, que oferece mais precisão que o tipo Numeric.
**Float Field Type**
Descreve o tipo de dados Float, que está incluído para compatibilidade e é funcionalmente equivalente a Numeric.
**General Field Type**
Descreve o tipo de campo General, que armazena objetos OLE.
**Integer Field Type**
Descreve o tipo de campo Integer, que armazena valores numéricos não decimais e pode ser usado quando desempenho e limitações de armazenamento de tabela são importantes.
**Logical Data Type**
Descreve o tipo de dados Logical, que fornece uma maneira eficiente de armazenar dados que possuem apenas dois valores.
**Memo Field Type**
Descreve o tipo de campo Memo, que armazena blocos de dados. A versão Memo (Binary) do tipo de campo Memo armazena blocos de dados que você não deseja traduzir entre páginas de código.
**Numeric Data Type**
Descreve o tipo de dados Numeric, que armazena valores indicando magnitude.
**Varbinary Data Type**
Descreve o tipo de dados Varbinary, que armazena valores binários e literais com comprimento fixo sem preenchimento adicional e truncamento de espaços.
**Varchar Field Type**
Descreve o tipo de campo Varchar, que armazena texto alfanumérico sem preenchimento adicional e truncamento de espaços à direita. O tipo de campo Varchar (Binary) armazena texto alfanumérico que você não deseja traduzir entre páginas de código e sem preenchimento adicional e truncamento de espaços à direita.
**Variant Data Type**
Descreve o tipo de dados Variant, que armazena qualquer tipo de dados, exceto dados de comprimento fixo.
