# Rotinas de instrução e expressão

Essas rotinas de API permitem compilar e executar comandos do Visual FoxPro.
 **_Execute( ) API Library Routine ,**
Compila e executa a instrução terminada em nulo em stmt .
**_Evaluate( ) API Library Routine**
Compila e executa uma expressão do Visual FoxPro contida em expr , colocando o resultado em res .
