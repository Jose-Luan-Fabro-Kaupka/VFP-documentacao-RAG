# Como: fechar bancos de dados

Você pode fechar um banco de dados aberto de forma interativa ou programaticamente.

### Para fechar um banco de dados
- Execute uma das seguintes opções: No Project Manager, se o nó do banco de dados estiver expandido, recolha o nó. -OU- No Project Manager, clique no nome do banco de dados aberto e, em seguida, em Close. -OU- No Database Designer, feche a janela do designer. O banco de dados é fechado.

### Para fechar um banco de dados programaticamente
- Use o comando CLOSE DATABASES.

Para obter mais informações, consulte Comandos CLOSE.

> **Observação:** Usar CLOSE DATABASES na janela Command não fecha um banco de dados se o banco de dados foi aberto no Project Manager expandindo seu nó ou quando um formulário está em execução em sua própria sessão de dados. Nessas circunstâncias, o banco de dados permanece aberto até ser fechado no Project Manager ou até o formulário que usa o banco de dados ser fechado.
