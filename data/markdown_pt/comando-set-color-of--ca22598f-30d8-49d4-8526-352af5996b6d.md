# Comando SET COLOR OF

Incluído para compatibilidade com versões anteriores. Use o Comando SET COLOR OF SCHEME em vez disso.

Especifica as cores de sistemas de menu e janelas definidos pelo usuário.

```foxpro
SET COLOR OF NORMAL | MESSAGES
	| TITLES | BOX | HIGHLIGHT
	|INFORMATION
	| FIELDS TO [standard]
```

# Observações

Incluído para compatibilidade com versões anteriores — use SET COLOR OF SCHEME em vez disso.

SET COLOR OF afeta as configurações de cor dos esquemas de cor 1 e 2. Com esse comando, você pode definir atributos de cor selecionados de janelas definidas pelo usuário e atributos de cor selecionados de menus definidos pelo usuário.
