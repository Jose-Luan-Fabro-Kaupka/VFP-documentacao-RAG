# Função SKPPAD( )

Determina se um título de menu está habilitado ou desabilitado por SET SKIP OF.

```foxpro
SKPPAD(cMenuBarName, cMenuTitleName)
```

#### Parâmetros
 **cMenuBarName**
Especifica o nome da barra de menus que contém o título.
**cMenuTitleName**
Especifica o nome do título de menu cujo estado SKPPAD( ) retorna.

# Valor de retorno

Logical

# Observações

SKPPAD( ) retorna verdadeiro (.T.) se o título estiver desabilitado e falso (.F.) se estiver habilitado.
