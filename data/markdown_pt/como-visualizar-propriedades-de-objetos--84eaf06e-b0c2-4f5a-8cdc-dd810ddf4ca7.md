# Como: visualizar propriedades de objetos

Você pode visualizar propriedades, métodos e eventos para certos objetos, por exemplo, para um formulário ou um objeto em um formulário, exibindo-os na Properties window. Para obter mais informações, consulte Properties Window (Visual FoxPro).

### Para visualizar propriedades de um objeto
- Selecione o objeto para o qual deseja visualizar propriedades.
- No menu Window, clique em Properties Window.

Você também pode visualizar propriedades de um objeto clicando com o botão direito no objeto e escolhendo Properties, quando disponível, no menu de atalho. Quando a Properties window está aberta, você pode visualizar propriedades selecionando objetos na lista de objetos da Properties window. A Properties window é atualizada para exibir as propriedades, eventos e métodos do objeto selecionado.

> **Dica:** Para visualizar propriedades que múltiplos objetos têm em comum, pressione e segure SHIFT enquanto seleciona vários objetos no formulário. A lista de propriedades mostra propriedades comuns para os objetos selecionados.

# Visualizando valores truncados na Properties window

Às vezes, valores de propriedades, eventos e métodos podem aparecer truncados na lista de propriedades se os valores se estenderem além da borda direita da Properties window. No entanto, você ainda pode visualizar esses valores truncados.

### Para visualizar um valor truncado na lista de propriedades
- Expanda a Properties window.

-OU-
 - Mova o mouse sobre a propriedade, evento ou método na lista de propriedades para exibir a dica de valor.

Dicas de valor mostram as bibliotecas de classes visuais, se existirem, das quais métodos e eventos são herdados e configurações para propriedades somente leitura.

# Visualizando valores de propriedades somente leitura

Você pode visualizar o valor de uma propriedade somente leitura que aparece truncada na Properties window sem expandir a Properties window.

### Para visualizar o valor de uma propriedade somente leitura
- Na Properties window, clique com o botão direito na propriedade que deseja visualizar.
- No menu de atalho, selecione Zoom.

Para obter mais informações, consulte Zoom <property> Dialog Box.
