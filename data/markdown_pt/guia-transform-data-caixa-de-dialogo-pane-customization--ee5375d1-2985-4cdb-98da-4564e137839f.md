# Guia Transform Data, caixa de diálogo Pane Customization

A guia Transform Data contém a transformação XML usada para renderizar uma seção de conteúdo.
 **Type**
Especifica o tipo de dados de transformação. Os dois tipos de dados de transformação são: Tipo Descrição XML Especifica que a transformação é Extensible Stylesheet Language (XSL). Script Especifica que a transformação é código Visual FoxPro.
**Source**
Especifica a origem dos dados de transformação. Os dados de transformação XML podem vir das mesmas origens especificadas na guia Data, caixa de diálogo Pane Customization.
**Modify**
Abre uma janela para modificar o código Visual FoxPro ou os dados XSL.
**Edit Box**
Exibe código Visual FoxPro ou dados XSL.
