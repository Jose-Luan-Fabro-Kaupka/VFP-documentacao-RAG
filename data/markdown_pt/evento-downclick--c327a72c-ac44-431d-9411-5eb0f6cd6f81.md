# Evento DownClick

Ocorre quando o usuário clica na seta para baixo de um controle Spinner ou na seta para baixo na lista suspensa de um controle ComboBox.

```foxpro
PROCEDURE Control.DownClick
```

# Observações

Aplica-se a: ComboBox Control | Spinner Control

Use o evento DropDown para executar código quando a seta suspensa de um controle ComboBox for clicada.
