# Exemplos da Solution de automação

Estes exemplos da Solution ilustram como você pode realizar automação com arquivos de outros aplicativos.

# Nesta seção
 **Exemplo Automatizar uma planilha do Microsoft Excel**
Descreve como chamar uma planilha do Excel por meio de automação.
**Exemplo Automatizar um documento do Microsoft Word em um formulário**
Descreve como automatizar um objeto Word incorporado em um formulário, inserir rich text e formatar o texto.
**Exemplo Automatizar Microsoft Word e Excel**
Descreve como usar o Visual FoxPro como controlador de automação para selecionar dados de um banco de dados Visual FoxPro, inserir os dados em uma planilha do Excel, criar um gráfico dos dados e exibir os dados no Word.
**Exemplo Manipular características de exibição de um gráfico**
Descreve como incorporar o MS Graph 5.0, que é um servidor Automation, em seus aplicativos.
**Exemplo Atualizar um gráfico em um formulário**
Descreve como selecionar dados de uma tabela Visual FoxPro e passar os dados ao MS Graph para atualizar valores em um gráfico.

# Referência
