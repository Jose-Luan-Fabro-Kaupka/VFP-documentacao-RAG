# Comando MENU

Incluído para compatibilidade com versões anteriores. Use os Designers de Menu e Atalho em vez disso.

Cria um sistema de menu.

```foxpro
MENU BAR array1, expN1
	MENU expN2, array2, expN3
	[, expN4]
READ MENU BAR TO memvar1 memvar2
	[SAVE]
```

# Observações

MENU está incluído para compatibilidade com versões anteriores. Use o FoxPro Menu Builder para criar menus.

Esses comandos criam um sistema de menu. Um sistema de menu consiste em uma barra de menu na parte superior da janela principal do FoxPro ou da janela definida pelo usuário ativa, com pads de menu. Cada pad de menu possui um menu pop-up associado contendo uma lista de opções.

Comandos

--------

MENU BAR array1, expN1

 MENU BAR é usado para criar a barra de menu e os pads. Crie um array bidimensional de variáveis de memória para conter os prompts dos pads de menu e as mensagens exibidas quando os pads de menu são selecionados. Os elementos na primeira coluna do array especificado com array1 são os prompts dos pads de menu, e os elementos na segunda coluna do array são as mensagens. Especifique onde as mensagens são exibidas com SET MESSAGE.

 O número de pads de menu que aparecem na barra de menu é especificado com expN1.

MENU expN2, array2, expN3 [, expN4]

 Use uma série de comandos MENU para criar os menus pop-up exibidos quando um pad de menu é selecionado.

 A expressão numérica expN2 especifica a qual pad de menu na barra de menu o pop-up é atribuído. O array unidimensional array2 contém os prompts das opções nos pop-ups.

 Se o primeiro caractere de um elemento do array for uma barra invertida (\), a opção correspondente não pode ser selecionada. Se o elemento contiver uma barra invertida e um hífen (\-), um separador é desenhado entre os prompts das opções do pop-up. Você pode criar uma tecla de atalho para uma opção colocando uma barra invertida e um sinal de menor que (\<) antes do caractere desejado do prompt da opção. Uma tecla de atalho é uma letra destacada no FoxPro para MS-DOS ou uma letra sublinhada no FoxPro para Windows que você pode digitar para escolher imediatamente a opção desejada. No FoxPro para Macintosh, a configuração KEYCOMP determina se uma tecla de atalho é sublinhada.

 O número de opções no pop-up é especificado com expN3.

 O número de opções exibidas no pop-up é especificado com expN4. Se houver mais opções no pop-up do que podem ser exibidas de uma vez, você pode rolar pelas opções no pop-up.

READ MENU BAR TO memvar1, memvar2

 Este comando ativa a barra de menu. Os valores inicialmente contidos nas variáveis de memória ou elementos de array memvar1 e memvar2 especificam qual pad de menu e opção de pop-up são selecionados quando a barra de menu é ativada. Quando você escolhe uma opção de um pop-up, os valores armazenados em memvar1 e memvar2 correspondem ao pop-up e à opção de pop-up que você escolheu. Se você pressionar Esc para sair do menu, memvar1 e memvar2 contêm 0.

SAVE

 Inclua SAVE para exibir uma imagem do menu após uma opção ser selecionada.

# Exemplo

```foxpro
*** A program example of popup MENUS ***
SET STATUS OFF
SET ECHO OFF
SET TALK OFF
SET MESSAGE TO 24
*** Initialize the array for the menu bar ***
DIMENSION TOP(3,2)
TOP(1,1) = '  FILE  '
TOP(2,1) = '  EDIT  '
TOP(3,1) = '  DATA  '
TOP(1,2) = 'FILE SELECTIONS'
TOP(2,2) = 'EDIT SELECTIONS'
TOP(3,2) = 'DATA SELECTIONS'
*** Dimension and initialize an array for the File menu ***
DIMENSION M_FILE(7)
M_FILE(1) = '\
```
