# Configurando uma Aplicação

Você precisa configurar sua aplicação Visual FoxPro adequadamente para que ela funcione conforme as especificações definidas durante o planejamento da aplicação. Normalmente, você pode criar um objeto de aplicação para executar essas tarefas. Você também pode usar um arquivo principal para lidar com essas tarefas.

# Nesta Seção

Explica como designar um arquivo como arquivo principal e ponto de partida de sua aplicação.
**Main Files in Applications**
Introduz o uso de arquivos principais em aplicações.
**How to: Initialize the Environment**
Descreve como configurar o ambiente da aplicação.
**How to: Control the Event Loop**
Descreve como iniciar e parar o loop de eventos de uma aplicação.
**How to: Customize the Appearance of Applications**
Descreve como você pode alterar a aparência de sua aplicação, por exemplo, o ícone ou título da aplicação, sem alterar código.
