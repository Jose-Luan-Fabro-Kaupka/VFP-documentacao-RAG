# Caixa de diálogo Salvar como (Visual FoxPro)

Salva um novo arquivo ou salva um arquivo existente com um nome diferente. Corresponde à função PUTFILE( ).

O comando Save As está habilitado para os seguintes tipos de arquivo:
 - Project
- Query
- Connection (consulte a observação a seguir)
- View (consulte a observação a seguir)
- Form
- Report
- Label
- Program
- Text File
- Menu Observação Quando você escolhe Save ou Save As para uma connection ou view, a caixa de diálogo Save é exibida.

Esta caixa de diálogo aparece quando você seleciona Save As no menu File.
 **Code Page**
Esta opção está disponível se você estiver salvando um arquivo de texto ou uma tabela que não tenha code page. A caixa de diálogo Code Page é exibida para que você possa anexar o code page correto. Se seu arquivo de texto existente usa o conjunto de caracteres estendido, escolha Code Page e faça as seleções apropriadas.
