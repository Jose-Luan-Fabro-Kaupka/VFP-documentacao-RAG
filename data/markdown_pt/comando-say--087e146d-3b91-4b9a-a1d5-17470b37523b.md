# Comando @ ... SAY

Incluído para compatibilidade com versões anteriores. Use o controle Label para exibir texto e o controle TextBox para exibir o conteúdo de campos e variáveis.

Exibe a saída em uma posição especificada de linha e coluna.

```foxpro
@ row, column
SAY expr
	[FUNCTION expC1]
	[PICTURE expC2]
	[SIZE expN1, expN2]
	[FONT expC3 [, expC4
```

]
	[COLOR SCHEME expN4
	| COLOR color pair list]
#### Parâmetros
 row, column

 Row e column são expressões numéricas com valores iguais ou superiores a 0 que determinam onde a saída de @ ... SAY aparece.

 A primeira linha é a de número 0 na janela principal do FoxPro ou em uma janela definida pelo usuário. As linhas são numeradas de cima para baixo. No FoxPro para Windows, a linha 0 fica imediatamente abaixo da barra de menus do sistema FoxPro. No FoxPro para Macintosh, fica imediatamente abaixo da barra de título. No FoxPro para MS-DOS, é a linha ocupada pela barra de menus do sistema. Consulte SET SYSMENU para saber como manipular a barra de menus e colocar a saída na linha 0 no FoxPro para MS-DOS. Para impressoras, a primeira linha é 1, e o tamanho físico da página e a quantidade de linhas por página determinam o número máximo da linha.

 A primeira coluna é a de número 0 na janela principal do FoxPro ou em uma janela definida pelo usuário. As colunas são numeradas da esquerda para a direita. Para impressoras, a primeira coluna é 1, e o tamanho físico da página determina seu número máximo.

 Quando a saída de @ ... SAY é direcionada a uma janela definida pelo usuário, as coordenadas de linha e coluna são relativas a essa janela, não à janela principal do FoxPro.

 No FoxPro para Windows e no FoxPro para Macintosh, uma posição na janela principal ou em uma janela definida pelo usuário é determinada pela fonte dessa janela. A maioria das fontes pode ser exibida em vários tamanhos, e algumas têm espaçamento proporcional. Uma linha corresponde à altura da fonte atual; uma coluna corresponde à largura média de uma letra nessa fonte.

 No FoxPro para Windows e no FoxPro para Macintosh, você pode posicionar a saída de @ ... SAY usando frações decimais nas coordenadas. No FoxPro para MS-DOS, essas frações são arredondadas para o inteiro mais próximo.

 expr
 expr é avaliada e exibida ou impressa a partir de row, column. Pode ser uma função definida pelo usuário.

 FUNCTION expC1 | PICTURE expC2

 Você pode incluir a cláusula FUNCTION, a cláusula PICTURE ou ambas para controlar como expr é exibida ou impressa.

 Códigos FUNCTION podem ser incluídos em uma cláusula PICTURE. Nesse caso, a cláusula PICTURE deve começar com @. Uma cláusula PICTURE pode conter códigos FUNCTION, códigos PICTURE ou ambos. Como uma cláusula FUNCTION afeta toda a expressão, ela pode conter somente códigos FUNCTION.

 C Exibe CR após um número positivo para indicar crédito. Pode ser usado somente com dados numéricos.

 O exemplo a seguir combina dois códigos FUNCTION para formatar um valor numérico. Os códigos $$ criam um cifrão flutuante, e o código C coloca CR após o número.

 CLEAR

 @ 2, 2 SAY 1.15 FUNCTION 'C$$'

 SIZE expN1, expN2

 A cláusula SIZE permite controlar o comprimento e a altura de uma região de exibição ou impressão de @ ... SAY.

 Por padrão, o FoxPro cria uma região com uma linha de altura. Inclua a cláusula opcional SIZE para criar uma região com mais de uma linha. A altura em linhas é especificada por expN1 e a largura em colunas por expN2. A saída de @ ... SAY é quebrada automaticamente na largura especificada por expN2 durante expN1 linhas.

 No FoxPro para Windows e no FoxPro para Macintosh, a fonte de @ ... SAY determina o tamanho da região de edição. Ela é especificada com a cláusula FONT. Se FONT for omitida, a saída usa a fonte da janela pai.

 FONT expC3 [, expN3]

 A expressão de caracteres expC3 é o nome da fonte, e a expressão numérica expN3 é o tamanho. Por exemplo, o comando a seguir exibe o texto de @ ... SAY na fonte Courier de 16 pontos:

 @ 2, 2 SAY 'Font clause example' FONT 'Courier', 16

 Se você incluir FONT, mas omitir expN3, será usada uma fonte de 10 pontos.

 No FoxPro para Windows, se a fonte especificada não estiver disponível, será substituída por uma fonte de características semelhantes.

 No FoxPro para Macintosh, se a fonte não estiver disponível, será usada a fonte Chicago.

 No FoxPro para MS-DOS, a cláusula FONT é ignorada.

 STYLE expC4

 No FoxPro para Windows e no FoxPro para Macintosh, inclua STYLE para especificar um estilo de fonte para a saída de @ ... SAY.

 O estilo é especificado por expC4. Se STYLE for omitida, será usado o estilo normal.

 No FoxPro para Windows, se o estilo especificado não estiver disponível, será substituído por um estilo de características semelhantes.

 No FoxPro para Macintosh, se a fonte especificada não estiver disponível, será usado o estilo normal.

 A cláusula STYLE é ignorada no FoxPro para MS-DOS.

 Você pode incluir mais de um caractere para especificar uma combinação de estilos. Por exemplo, o comando a seguir especifica negrito e itálico:

 @ 2, 2 SAY 'Font clause example' STYLE 'BI'

COLOR SCHEME expN4 | COLOR color pair list

 Se você não incluir COLOR, a cor da saída será determinada pelo esquema de cores da janela principal; se a saída for direcionada a uma janela definida pelo usuário, seu esquema determinará a cor.

 Somente o primeiro par de cores de um esquema ou lista afeta a saída de @ ... SAY.

 A cor pode ser especificada incluindo o número de um esquema existente em COLOR SCHEME ou um conjunto de pares em COLOR.

 Um esquema de cores é um conjunto de 10 pares predefinidos. Os pares podem ser alterados com SET COLOR OF SCHEME. No FoxPro para MS-DOS, também podem ser alterados no Seletor de Cores.

 Um par de cores é um conjunto de duas letras separadas por uma barra. A primeira especifica a cor do primeiro plano e a segunda, a cor de fundo.

 Por exemplo, este par especifica primeiro plano vermelho sobre fundo branco:

 R/W

 Para obter uma lista de cores e suas letras correspondentes, consulte Visão geral de SET COLOR ou Tabela de cores por par de cores.

 Um par também pode ser especificado por seis valores RGB (vermelho, verde, azul) separados por vírgulas. Os três primeiros especificam a cor do primeiro plano, e os três últimos, a cor de fundo. Os valores podem variar de 0 a 255.

 O par R/W do exemplo acima também pode ser especificado assim:

 RGB(255,0,0,255,255,255)

 Por exemplo:

 @ 2, 2 SAY 'This is red on white' COLOR R+/W*

 @ 4, 2 SAY 'This is Color Scheme 16' COLOR SCHEME 16

 @ 6, 2 SAY 'This is red on white' COLOR RGB(255,0,0,255,255,225)

# Observações

Use este comando para exibir saída formatada na janela principal do FoxPro ou em uma janela definida pelo usuário. Também pode ser usado para formatar a saída para uma impressora.

Se você usar o Construtor de Telas para criar telas de entrada de dados, talvez não precise usar @ ... SAY. O Construtor de Telas gera automaticamente os comandos @ ... SAY.

Você pode combinar @ ... SAY e @ ... GET em um único comando. Se as cláusulas SAY e GET forem incluídas, especifique um único conjunto de coordenadas row, column para o início da saída. Um espaço é inserido automaticamente entre a saída de @ ... SAY e a região de edição de texto de @ ... GET.

Se você emitir SET DEVICE TO SCREEN, a saída de @ ... SAY aparecerá na janela principal do FoxPro ou em uma janela definida pelo usuário que esteja ativa. SET DEVICE TO SCREEN é o padrão de inicialização. Se você emitir SET DEVICE TO PRINTER, a saída será direcionada à impressora.
