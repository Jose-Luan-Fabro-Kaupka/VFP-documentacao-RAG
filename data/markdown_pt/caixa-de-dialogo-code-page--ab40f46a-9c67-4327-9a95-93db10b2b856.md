# Caixa de diálogo Code Page

Permite atribuir um code page a um arquivo .dbf ou de texto que não possui um.

Arquivos .dbf e de texto são exibidos corretamente apenas se tiverem os code pages corretos. O Visual FoxPro atribui automaticamente code pages a esses arquivos quando você os cria. No entanto, arquivos .dbf e de texto criados em versões anteriores do FoxPro ou em outros produtos podem não ter code pages.

Se você marcar Prompt for Code Page na guia Data da caixa de diálogo Options, o Visual FoxPro solicita que você especifique um code page ao abrir tabelas ou arquivos de texto que não estão marcados com um code page. Você também pode exibir a caixa de diálogo Code Page com a função GETCP( ).
 **Platform**
Refere-se ao tipo de sistema operacional que você está usando. Sua seleção determina quais code pages são exibidos na caixa Code Page. All Exibe code pages para todas as plataformas. Windows Exibe apenas code pages do Windows. MS-DOS Exibe apenas code pages do MS-DOS. Macintosh Exibe apenas code pages do Macintosh.
**Code Page**
Lista todos os code pages para a plataforma selecionada.
**Select**
Designa o code page atualmente selecionado como padrão.
