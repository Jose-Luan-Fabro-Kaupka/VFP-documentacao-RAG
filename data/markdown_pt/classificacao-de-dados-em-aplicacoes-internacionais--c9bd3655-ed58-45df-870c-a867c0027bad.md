# Classificação de dados em aplicações internacionais

Depois de criar uma tabela de dados internacionais, verifique se sua aplicação classifica os dados corretamente. A página de código associada à tabela determina a ordem de classificação, porque a página de código especifica as ordens de classificação ou sequências de ordenação disponíveis.

# Nesta seção
 **Understanding Sort Orders**
Descreve como usar ordens de classificação para tornar possível classificar dados adequadamente para vários idiomas.
**How to: Specify a Sort Order**
Explica como especificar uma ordem de classificação em sua aplicação, para operações subsequentes de indexação e classificação.
**Application Creation with Double-Byte Character Sets**
Discute como usar conjuntos de caracteres de byte duplo, para idiomas que exigem mais de um byte para representar caracteres, em sua aplicação.
