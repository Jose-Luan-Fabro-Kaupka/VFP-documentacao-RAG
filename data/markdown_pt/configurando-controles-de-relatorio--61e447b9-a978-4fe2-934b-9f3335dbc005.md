# Configurando controles de relatório

Ao adicionar ou editar controles de relatório, você pode adicionar comentários e alterar configurações de formato. Quando um controle de relatório é selecionado no Report Designer ou no Label Designer, o Visual FoxPro exibe muitas opções de formatação de controle de relatório que você pode escolher no menu Formatar.
