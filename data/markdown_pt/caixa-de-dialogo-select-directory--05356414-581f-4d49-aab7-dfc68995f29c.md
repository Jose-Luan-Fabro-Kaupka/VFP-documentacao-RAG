# Caixa de diálogo Select Directory

Permite definir o diretório inicial do projeto. Esta caixa aparece quando você escolhe o botão de diálogo na guia Project da caixa Project Information. O botão está associado à opção Home.
 **Directory**
Exibe uma árvore de diretórios na qual você seleciona o diretório inicial do projeto.
**Drive**
Permite selecionar uma unidade e escolher um diretório nela.
**Select**
Torna a combinação selecionada de unidade e diretório o diretório inicial do projeto. Ele é então exibido na caixa Home da guia Project.
**New Folder**
Disponível quando o valor nflag da função GETDIR( ) é 64. Permite criar uma pasta na caixa de diálogo.
