# Comando SET DECIMALS

Especifica o número de casas decimais exibidas em expressões numéricas.

```foxpro
SET DECIMALS TO [nDecimalPlaces]
```

#### Parâmetros
 **nDecimalPlaces**
Especifica o número mínimo de casas decimais a exibir. O padrão é duas casas decimais. O número máximo de casas decimais é 18; o mínimo é zero.

# Observações

SET DECIMALS especifica o número mínimo de casas decimais usado para exibir os resultados de divisão, multiplicação e funções trigonométricas e financeiras.

SET DECIMALS tem escopo na sessão de dados atual.
