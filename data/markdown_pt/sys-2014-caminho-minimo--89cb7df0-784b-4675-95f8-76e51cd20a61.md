# SYS(2014) - Caminho mínimo

Retorna o caminho mínimo relativo ao diretório atual ou especificado para um arquivo especificado.

```foxpro
SYS(2014, cFileName [, Path])
```

#### Parâmetros
 **cFileName**
Especifica o nome do arquivo para o qual SYS(2014) retorna o caminho mínimo. Se você omitir Path , SYS(2014) retorna o caminho mínimo entre o arquivo e o diretório atual. Você pode alterar o diretório atual com SET DEFAULT.
**Path**
Especifica um diretório para o qual SYS(2014) retorna o caminho mínimo entre o diretório especificado e o arquivo especificado com cFileName .

# Valor de retorno

Caractere

# Observações

SYS(2014) pode ser usado com FULLPATH( ) para tornar aplicativos portáveis. Ou seja, quando fornecida a localização do programa atual e a localização de outros arquivos usados pelo programa, FULLPATH( ) e SYS(2014) obtêm os caminhos apropriados para esses arquivos. Uma vez determinados os caminhos dos arquivos, os arquivos podem ser acessados pelo programa.
