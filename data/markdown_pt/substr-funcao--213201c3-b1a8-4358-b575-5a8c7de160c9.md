# SUBSTR( ) Função

Retorna uma sequência de caracteres da expressão de caracteres ou campo de memorando fornecido, começando em uma posição especificada na expressão de caracteres ou no campo de memorando e continuando por um número especificado de caracteres.

```foxpro
SUBSTR(cExpression, nStartPosition [, nCharactersReturned])
```

#### Parâmetros
 **cExpression**
Especifica a expressão de caracteres ou o campo de memorando do qual a sequência de caracteres é retornada.
**nStartPosition**
Especifica a posição na expressão de caracteres ou no campo de memorando cExpression de onde a sequência de caracteres é retornada. O primeiro caractere de cExpression é a posição 1. Nota Se nStartPosition for maior que o número de caracteres em cExpression , SUBSTR( ) retornará uma string vazia ("").
**nCharactersReturned**
Especifica o número de caracteres a serem retornados de cExpression . Se você omitir nCharactersReturned , os caracteres serão retornados até que o final da expressão do caractere seja alcançado.

# Valor de retorno
Personagem. SUBSTR( ) retorna uma sequência de caracteres.

> **Observação:** SUBSTR( ) não retornará um valor para um campo de memorando quando emitido na janela Debug. Para retornar um valor na janela Debug, coloque o nome do campo de memorando dentro de ALLTRIM( ) e coloque ALLTRIM( ) dentro de SUBSTR( ) .

# Observações
Ao usar SUBSTR( ) com campos de memorando em um comando SQL SELECT, inclua a função PADR( ) em SUBSTR( ) para que campos de memorando vazios ou de comprimento variável produzam resultados consistentes quando convertidos em cadeias de caracteres.

# Exemplo
O exemplo a seguir armazena a string 'abcdefghijklm' na variável myString usando o comando STORE. CLEAR limpa a janela principal do Visual FoxPro. Começando com o primeiro caractere conforme especificado por nStartPosition = 1, SUBSTR( ) exibe a string 'abcde' com cinco caracteres conforme especificado por nCharactersReturned = 5. SUBSTR( ) então exibe a string 'fghijklm' começando com o sexto caractere na string conforme especificado por nStartPosition = 6 até que o final da expressão do caractere seja alcançado conforme especificado pela omissão de um valor para nCharactersReturned.

```foxpro
STORE 'abcdefghijklm' TO myString
CLEAR
? SUBSTR(myString, 1, 5)
? SUBSTR(myString, 6)
```
