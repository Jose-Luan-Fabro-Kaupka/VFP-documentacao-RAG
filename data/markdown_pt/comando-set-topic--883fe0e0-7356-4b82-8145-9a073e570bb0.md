# Comando SET TOPIC

Especifica o tópico ou os tópicos da Ajuda a abrir quando você invoca o sistema de Ajuda do Visual FoxPro.

```foxpro
SET TOPIC TO [cHelpTopicName | lExpression]
```

#### Parâmetros
 **cHelpTopicName**
Especifica o nome do tópico da Ajuda que você deseja exibir.
**lExpression**
Uma expressão lógica que é a base para abrir um tópico ou tópicos específicos.
