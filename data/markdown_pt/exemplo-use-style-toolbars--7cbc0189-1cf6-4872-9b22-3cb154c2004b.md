# Exemplo Use Style Toolbars

Arquivo: ...\Samples\Solution\Sedona\Newtbars.scx

Este exemplo mostra uma barra de ferramentas personalizada que tem um botão de imagem com menu suspenso semelhante aos das barras de ferramentas no estilo do Microsoft Office. Esses menus suspensos podem ser criados facilmente combinando dois botões de comando e usando a propriedade VisualEffect para mostrá-los funcionando juntos em conjunto. Um menu popup padrão pode ser usado para o menu suspenso em si.
 Este exemplo contém as seguintes classes
| Classe | Biblioteca | Descrição |
| --- | --- | --- |
| tbar1 | newtbars.vcx | Contém classe de barra de ferramentas mostrando exemplo de menu suspenso de imagem usando botões de comando simples. |

Para obter detalhes sobre todas as classes disponíveis nas classes foundation, consulte Visual FoxPro Foundation Classes A-Z.
