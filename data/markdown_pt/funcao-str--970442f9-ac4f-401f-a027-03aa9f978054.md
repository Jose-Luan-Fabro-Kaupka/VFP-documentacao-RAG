# Função STR( )

Retorna o equivalente em caractere de uma expressão numérica.

```foxpro
STR(nExpression [, nLength [, nDecimalPlaces]])
```

#### Parâmetros
 **nExpression**
Especifica a expressão numérica a avaliar.
**nLength**
Especifica o comprimento da cadeia de caracteres retornada. Se nLength for omitido, nLength assume o padrão de 10 caracteres. Observação Se a expressão contiver um ponto decimal, o comprimento inclui um caractere para o ponto decimal e um caractere para cada dígito na cadeia de caracteres.
**nDecimalPlaces**
Especifica o número de casas decimais na cadeia de caracteres retornada. Para especificar o número de casas decimais usando nDecimalPlaces , você deve incluir nLength . Se nDecimalPlaces for omitido, o número de casas decimais assume o padrão zero (0). Observação O Visual FoxPro contém um limite de 16 dígitos de precisão em cálculos numéricos. Para obter mais informações sobre precisão numérica no Visual FoxPro, consulte Visual FoxPro System Capacities .

# Valor de retorno

Tipo de dados caractere. STR( ) retorna uma cadeia de caracteres equivalente à expressão numérica especificada.

Dependendo de certas condições, STR( ) pode retornar o seguinte:
 - Se você especificar menos casas decimais do que existem em nExpression , o valor de retorno é arredondado para cima. Para arredondar resultados para a casa decimal mais próxima em vez de para cima, inclua a função ROUND( ). Para obter mais informações, consulte ROUND( ) Function .
- Se nExpression for um inteiro e nLength for menor que o número de dígitos em nExpression , STR( ) retorna uma cadeia de asteriscos, indicando overflow numérico.
- Se nExpression contiver um ponto decimal e nLength for igual ou menor que o número de dígitos à esquerda do ponto decimal, STR( ) retorna uma cadeia de asteriscos, indicando overflow numérico.
- Se nLength for maior que o comprimento do valor avaliado por nExpression , STR( ) retorna uma cadeia de caracteres preenchida com espaços à esquerda.
- Se nExpression tiver tipo Numeric ou Float, e nLength for menor que o número de dígitos em nExpression , STR( ) retorna um valor usando notação científica.

# Exemplos

### Exemplo 1

No exemplo a seguir, STR( ) avalia 1.154994 como uma expressão de caractere, especifica um comprimento de 8 caracteres e o mesmo número de casas decimais que a expressão especificada contém, e exibe 1.154994 usando o comando ?.

```foxpro
? STR(1.154995,8,6)
```

### Exemplo 2

No exemplo a seguir, STR( ) avalia 1.154994 como uma expressão de caractere e especifica um comprimento de 8 caracteres e 2 casas decimais, quatro casas decimais a menos do que a expressão especificada contém. STR( ) exibe 1.16 usando o comando ?, que representa 1.154994 arredondado para cima.

```foxpro
? STR(1.154995,8,2)
```

### Exemplo 3

No exemplo a seguir, STR( ) inclui a função ROUND( ), avalia 1.154994 como uma expressão de caractere e especifica um comprimento de 8 caracteres e 2 casas decimais, quatro casas decimais a menos do que a expressão especificada contém. STR( ) exibe 1.15 usando o comando ?, que representa 1.154994, arredondado para o dígito significativo mais próximo.

```foxpro
? STR(ROUND(1.154995,2),8,2)
```
