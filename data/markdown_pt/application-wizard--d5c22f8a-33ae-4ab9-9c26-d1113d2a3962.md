# Application Wizard

O Application Wizard cria um Project e um Visual FoxPro Enhanced Application Framework e abre o Application Builder, para que você possa adicionar um banco de dados, tabelas, formulários ou relatórios que já criou. Você também pode criar um novo aplicativo no Application Builder usando modelos de banco de dados ou tabelas.

Para acessar o Application Wizard no menu Tools, escolha Wizards e clique em Application.

O assistente exibirá uma caixa de diálogo na qual você pode especificar o nome e o local do seu novo aplicativo.
 **Caixa de edição Project name**
Permite especificar o nome do projeto exibido na barra de título do Project.
**Caixa de edição Project file**
Permite especificar o nome do arquivo e o local do novo projeto.
**Botão Browse**
Permite localizar um arquivo de projeto existente para usar no Application Builder.
**Caixa de seleção Create project directory structure**
Permite determinar se o Visual FoxPro deve criar automaticamente a estrutura de diretórios do projeto para você. O assistente cria um modelo que inclui todos os arquivos de aplicativo possíveis, embora você possa não precisar de todos. Se você já criou seus arquivos de aplicativo, deixe esta caixa desmarcada.

O Application Wizard exibirá uma janela de espera solicitando que você aguarde enquanto gera a estrutura de arquivos do framework de aplicativo necessária, o framework de aplicativo do Visual FoxPro, para seu aplicativo. Quando o processo for concluído, o assistente exibirá a nova janela do projeto e o Application Builder para que você possa completar os detalhes do seu novo aplicativo.
