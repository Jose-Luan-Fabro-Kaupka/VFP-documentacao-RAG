# Guia List Items, List Box Builder

Esta guia no List Box Builder especifica itens para preencher a caixa de listagem.

Na caixa Fill the List With, você especifica o tipo de dados com o qual preencher a lista. A seleção que você fizer aqui determina quais opções aparecem nesta guia. As opções são Fields from a Table or View, Data Entered by Hand e Values from an Array.

# Fields from a Table or View
 **Databases and Tables**
Lista os bancos de dados disponíveis e a opção de selecionar tabelas livres. Para encontrar um banco de dados ou tabela, clique no botão de diálogo, que exibe a caixa de diálogo Open.
**List of Tables**
Exibe tabelas e views no banco de dados selecionado ou tabelas livres.
**Available Fields**
Mostra todos os campos na tabela ou view selecionada. Selecione os campos cujos dados você deseja na sua caixa de listagem.
**Arrow Buttons**
Adiciona campos a e remove campos da lista Selected Fields.
**Selected Fields**
Exibe os campos que serão usados para preencher a lista. Esta opção corresponde à propriedade RowSource. Observação Você deve escolher esta opção para ocultar a coluna na guia Layout.

# Data Entered by Hand
 **Columns**
Especifica o número de colunas na lista. Esta opção corresponde à propriedade ColumnCount.
**Column Grid**
Exibe as colunas nas quais inserir dados. Digite os dados nas células da grade. Você pode dimensionar as colunas arrastando as linhas entre os cabeçalhos de coluna com o mouse. Use as teclas de seta para mover-se pelas colunas. Esta opção corresponde à propriedade RowSource.

# Values from an Array
 **Array Name**
Especifica o nome de um array. Esta opção corresponde à propriedade RowSource.
**Entire Array**
Especifica que o array inteiro preencherá a lista.
**Range of the Array**
Especifica que uma parte do array preencherá a lista.
**Column and Row Range**
Especifica a coluna e linha inicial e final como intervalo do array. Estas opções estão disponíveis quando você seleciona Range of the Array. Esta opção corresponde à propriedade FirstElement, NumberOfElements e ColumnCount.

Para obter mais informações, consulte Creating Forms.
