# Style Propriedade

Especifica o estilo do controle a. Leitura/gravação em tempo de design e execução.

```foxpro
[Form.]Control.Style [= nType]
```# Valor de retorno
 **nType**
Especifica um valor numérico que determina o estilo do controle a. Para controles CheckBox e OptionButton, a tabela a seguir lista os valores para nType . nType Descrição 0 Padrão (Padrão) 1 Gráfico. O botão se parece com o botão de comando a e pode conter gráficos e texto. Quando o botão contém ambos, a posição do texto e do gráfico é determinada pela propriedade PicturePosition. Para obter mais informações, consulte PicturePosition Propriedade. Para controles ComboBox, a tabela a seguir lista os valores para nType . nType Descrição 0 Caixa de combinação suspensa, que inclui uma caixa de listagem e uma caixa de edição. (Padrão) O usuário pode selecionar na caixa de listagem ou digitar caracteres na caixa de edição. 2 Caixa de listagem suspensa. O usuário deve selecionar itens da caixa de listagem. Para decidir qual configuração escolher para caixas de combinação, siga estas diretrizes: Para fornecer uma lista de opções e permitir que o usuário digite uma seleção na caixa de edição, defina Estilo como 0 (caixa de combinação suspensa). Essa configuração economiza espaço em um formulário porque a caixa de listagem fecha quando o usuário faz uma seleção. Para exibir uma lista fixa de opções das quais o usuário pode selecionar um item, defina Estilo como 2 (caixa de listagem suspensa). A caixa de listagem fecha quando o usuário seleciona um item. Para controles CommandButton, a tabela a seguir lista os valores para nType . nType Descrição 0 Padrão (Padrão) 1 Invisível Para controles TextBox, a tabela a seguir lista os valores para nType . nType Descrição 0 Normal (Padrão) 1 Incluído para compatibilidade com versões anteriores do comando FoxPro versão 2.x @ ... SAY. A caixa de texto é somente leitura e não pode receber foco. Para objetos Separadores da barra de ferramentas, a tabela a seguir lista os valores para nType . nType Descrição 0 Normal (Padrão). Nenhuma linha vertical ou horizontal aparece como o objeto separator nas barras de ferramentas. 1 Especifica que uma linha vertical ou horizontal aparece como o objeto separator nas barras de ferramentas e fica visível somente em tempo de execução. Quando a barra de ferramentas é exibida horizontalmente, a linha aparece verticalmente. Quando a barra de ferramentas é exibida verticalmente, a linha aparece horizontalmente. Nota Nas versões anteriores ao Visual FoxPro 9.0, o sistema vertical desencaixado e as barras de ferramentas definidas pelo usuário não exibiam separadores horizontais. No entanto, os separadores horizontais agora são exibidos para barras de ferramentas verticais desencaixadas. Para controles Label e Shape e objetos de controle Container and, a tabela a seguir lista os valores para nType . nType Descrição 0 Normal (Padrão) 3 Temático Em um controle Label, Estilo controla a cor do texto. Você pode usar essa configuração para legendas em caixas de grupo que cercam outros controles. Se o rótulo temático estiver hospedado em um contêiner, talvez seja necessário definir o estilo do contêiner como 3. Se Temas estiver ativado para um rótulo, o Visual FoxPro desconsiderará as propriedades Enabled e FontCharSet. Para obter mais informações, consulte Enabled Propriedade e FontCharSet Propriedade . Em um controle Shape, objeto Container or Control, Style controla a cor e o estilo da borda. Você pode usar essa configuração para bordas em caixas de grupo que circundam outros controles. Se Temas estiver ativado para um controle Shape, o Visual FoxPro desconsiderará a propriedade Curvature.Para obter mais informações, consulte Curvature Propriedade. Se um sistema operacional não suportar Temas XP do Windows ou se Temas estiver desativado, o Visual FoxPro usará as configurações para outras propriedades, como SpecialEffect . Para obter mais informações, consulte SpecialEffect Propriedade. 4 Apenas plano de fundo temático Nos controles Etiqueta, Estilo controla apenas a cor do plano de fundo. A cor de fundo do rótulo é a mesma do contêiner pai do rótulo. Você pode usar essa configuração principalmente para rótulos em páginas temáticas. Esta configuração não é suportada para controles Shape, Container , and objetos Control.
