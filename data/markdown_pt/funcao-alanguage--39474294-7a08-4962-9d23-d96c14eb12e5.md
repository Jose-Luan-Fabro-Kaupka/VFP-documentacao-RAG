# Função ALANGUAGE( )

Retorna uma matriz contendo os nomes de todos os comandos, funções ou classes base válidos do Visual FoxPro.

```foxpro
ALANGUAGE(ArrayName, nType)
```

#### Parâmetros
 **ArrayName**
Especifica o nome da matriz que conterá os itens de linguagem. Se a matriz não existir, o Visual FoxPro a cria automaticamente. Se a matriz existir e não for grande o suficiente para conter todos os dados, o Visual FoxPro aumenta automaticamente o tamanho da matriz para acomodar as informações. Se a matriz for maior do que o necessário, o Visual FoxPro a trunca.
**nType**
Especifica o tipo de item de linguagem retornado, conforme a lista a seguir: Value Description Array Type 1 Commands One-dimensional: Command name 2 Functions Two-dimensional: Function name [M] nParamR [- nParamT ] The matchFlag, M, specifies that you must use the full function name in code. nParamR specifies the number of required parameters. nParamT specifies total number of possible parameters. 3 Base classes One-dimensional: Base Class name 4 DBC Events One-dimensional: DBC event name (The displayed name omits the "DBC_" prefix of the event name.)

# Observações

A função ALANGUAGE( ) retorna uma matriz de todos os comandos e funções válidos do Visual FoxPro. Para retornar informações de objetos, use a função AMEMBERS( ).

# Exemplos

Use a função ALANGUAGE( ) para acessar funções do Visual FoxPro, como no código a seguir:

```foxpro
   ALANGUAGE(FuncArr,2)
```

A matriz resultante, FuncArr, conterá os valores a seguir:

```foxpro
   JUSTSTEM, M1
```

JUSTSTEM( ) não pode ser abreviado e requer um parâmetro.

```foxpro
   KEYMATCH, 1-4
```

KEYMATCH( ) pode ser abreviado para quatro caracteres e tem um parâmetro obrigatório e três opcionais (total = 4).

```foxpro
   LASTKEY, 0
```

LASTKEY( ) pode ser abreviado e não requer parâmetros.
