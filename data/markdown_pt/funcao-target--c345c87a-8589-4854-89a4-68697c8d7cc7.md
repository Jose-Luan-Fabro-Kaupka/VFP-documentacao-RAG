# Função TARGET( )

Retorna o alias de uma tabela que é o destino de uma relação, conforme especificado na cláusula INTO de SET RELATION.

```foxpro
TARGET(nRelationshipNumber [, nWorkArea | cTableAlias])
```

#### Parâmetros
 **nRelationshipNumber**
Especifica o número de uma relação. Inclua um número de 1 até o número de relações da área de trabalho especificada. Os aliases das tabelas de destino são retornados (sem ordem específica) até que nRelationshipNumber seja maior que o número de relações. Quando nRelationshipNumber for maior que o número de relações, a cadeia de caracteres vazia é retornada.
**nWorkArea | cTableAlias**
Retorna o alias da tabela de destino em outra área de trabalho. nWorkArea especifica um número de área de trabalho e cTableAlias especifica um alias de tabela. Por padrão, o alias da tabela de destino da área de trabalho atual é retornado se você não especificar a área de trabalho ou o alias.

# Valor de retorno

Character

# Exemplo

No exemplo a seguir, uma relação é definida no campo `order_id` de `orders` para `customer`. A função TARGET( ) é então usada para retornar o alias da tabela de destino.

```foxpro
CLOSE DATABASES
OPEN DATABASE (HOME(2) + 'Data\testdata')
USE orders IN 0 ORDER order_id
USE customer IN 0 ORDER cust_id
SELECT orders
SET RELATION TO cust_id INTO customer
? TARGET(1)  && Displays customer
? TARGET(2)  && Empty string
```
