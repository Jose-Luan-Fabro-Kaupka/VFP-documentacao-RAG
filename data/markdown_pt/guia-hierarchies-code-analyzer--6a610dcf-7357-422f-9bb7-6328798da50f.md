# Guia Hierarchies, Code Analyzer

Esta guia fornece a exibição da hierarquia da árvore de chamadas ou do diagrama de classes do seu programa. A guia contém os seguintes controles:

# Opções da guia
 **Files**
Exibe a hierarquia da árvore de chamadas ou o diagrama de classes do seu programa.
**Option**
Seleciona as exibições alternativas do controle de estrutura Files.
