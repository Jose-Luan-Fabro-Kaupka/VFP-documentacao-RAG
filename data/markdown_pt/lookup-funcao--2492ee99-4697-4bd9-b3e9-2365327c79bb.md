# LOOKUP( ) Função

Procura uma tabela para o primeiro registro com um campo correspondente à expressão especificada.

```foxpro
LOOKUP(ReturnField, eSearchExpression, SearchedField [, cTagName])
```

Parâmetros
**ReturnField**
Especifica o campo cujo conteúdo LOOKUP( ) retorna quando a pesquisa é bem sucedida. Se a pesquisa não for bem sucedida, LOOKUP( ) retorna o valor padrão do tipo de dados ReturnField.
**eSearchExpression**
Especifica a expressão de pesquisa. A expressão de pesquisa é geralmente o conteúdo de um campo na tabela. Além disso, pode corresponder à expressão do índice ativo ou tag do índice composto.
**ProcuradoCampo**
Especifica o campo a procurar. Se a tabela não tiver um índice ativo, LOOKUP( ) realiza uma busca sequencial através do campo especificado com SearchedField. Se um arquivo de índice ou tag de índice estiver aberto cuja expressão de chave de índice é o campo de pesquisa que você especifica, LOOKUP( ) usa o arquivo de índice ou tag de índice para realizar uma busca mais rápida.
**cTagName**
Especifica o nome de uma tag de índice composto para LOOKUP( ) usar na pesquisa. Uma pesquisa de índice composto é a pesquisa mais rápida LOOKUP( ) pode executar.

# Valor de Retorno

Caracter, Numérica, Moeda, Flutuante, Inteiro, Duplo, Data, DataTime, ou Lógico.

Observações

Se a pesquisa for bem sucedida, LOOKUP( ) move o ponteiro de registro para o registro correspondente e retorna o conteúdo de um campo especificado no registro.

Se LOOKUP( ) não encontrar a expressão de pesquisa, retorna um valor em branco do mesmo comprimento e tipo de dados que o ReturnField. O ponteiro de registro está posicionado no final do arquivo.

Se você usar LOOKUP( ) para pesquisar uma tabela pai, os ponteiros de registro em todas as tabelas de filhos relacionadas são movidos para os registros relacionados.

Esta função não pode ser otimizada com Rushmore Consulta Otimização.

Exemplo

In the following example, LOOKUP( ) uses the index tag `company` to search for the first occurrence of the string "Ernst Handel." If the search is successful, LOOKUP( ) returns the contents of the `contact` field and @ ... SAY displays the return value.

```foxpro
CLOSE DATABASES
OPEN DATABASE (HOME(2) + 'data\testdata')
USE customer ORDER company  && Open Customer table
CLEAR
@ 2,2 SAY LOOKUP(contact, 'Ernst Handel', company, 'company')
```
