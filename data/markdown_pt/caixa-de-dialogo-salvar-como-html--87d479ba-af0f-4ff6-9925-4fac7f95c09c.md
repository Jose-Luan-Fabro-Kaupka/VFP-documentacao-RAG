# Caixa de Diálogo Salvar como HTML

Permite criar uma nova versão HTML (Hypertext Markup Language) do formulário, menu, relatório ou tabela atual. Disponível no Form Designer, Menu Designer e Report Designer quando o formulário, menu ou relatório ativo foi salvo, ou em uma janela Browse.
 **Salvar arquivo para uso posterior**
Salva o arquivo em disco como um arquivo .htm.
**Salvar e editar arquivo**
Salva o arquivo em disco como um arquivo .htm e abre o arquivo em uma janela de edição.
**Salvar arquivo e visualizar no navegador Web**
Salva o arquivo como um arquivo .htm e exibe o arquivo no seu navegador Web.
