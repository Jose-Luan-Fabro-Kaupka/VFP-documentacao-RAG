# Manipulação de campos e registros

Você acessa dados em campos especificando um ou mais registros que contêm os dados desejados. Você pode acessar um registro específico movendo o ponteiro de registro usando o comando GO | GOTO Command ou pode especificar um intervalo ou grupo de registros usando cláusulas scope, FOR ou WHILE em um comando.

# Nesta seção
 **Cláusulas Scope**
Descreve cláusulas scope que você pode usar para especificar um intervalo de registros.
**Cláusulas FOR**
Descreve cláusulas FOR que você pode usar para especificar condições lógicas para controlar os registros que deseja incluir.
**Cláusulas WHILE**
Descreve cláusulas WHILE que você pode usar para especificar condições lógicas que controlam se deve continuar realizando operações em registros.
