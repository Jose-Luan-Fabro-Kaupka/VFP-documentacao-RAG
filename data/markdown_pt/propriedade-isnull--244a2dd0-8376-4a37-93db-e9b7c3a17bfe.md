# Propriedade IsNull

Especifica se o campo no documento XML suporta valores nulos.

```foxpro
XMLField.IsNull [= lValue]
```

# Valor de retorno
 **IValue**
Tipo de dados lógico. A tabela a seguir lista os valores de lValue. lValue Descrição False (.F.) O campo não suporta valores nulos. (Padrão) True (.T.) O campo suporta valores nulos.

# Observações

Aplica-se a: XMLField Class
