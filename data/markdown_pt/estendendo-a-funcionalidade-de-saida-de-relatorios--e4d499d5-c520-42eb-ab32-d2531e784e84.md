# Estendendo a funcionalidade de saída de relatórios

No Sistema de Relatórios do Visual FoxPro 9, o Report Output Application fornece instâncias de classes derivadas de ReportListener para uso em execuções de relatório assistidas por objetos. Os tópicos nesta seção discutem o Report Output Application padrão e recursos relacionados.

# Nesta seção
 **Report Output Application**
Discute como aproveitar os recursos do Report Output Application padrão e como personalizá-lo para seus aplicativos.
**Usando VFP Report Output XML**
Especifica o esquema XML base de saída de relatórios do Visual FoxPro e seus muitos elementos opcionais. Você pode usar o Report Output Application padrão para gerar VFP Report Output XML. Em seu aplicativo ou em ferramentas externas, o XML pode fornecer muitas formas adicionais de resultados de saída.
**Considerações para criar novos tipos de saída de relatórios**
Lista alguns critérios de design para desenvolver novos componentes geradores de saída a serem registrados no Report Output Application.
