# Chamada inválida emitida durante a execução de uma sequência SQLEXEC( ) (Erro 1474)

Uma chamada inválida de função SQL pass-through (SPT) foi feita enquanto era esperada uma chamada SQLEXEC( ) Function para continuar a sequência de chamadas SPT em andamento.

Chame SQLCANCEL( ) Function para cancelar a sequência SPT ou faça chamadas SPT válidas para concluir a sequência de chamadas.
