# Função PROMPT( )

Retorna o texto de um título de menu escolhido de uma barra de menu ou de um item de menu escolhido de um menu.

```foxpro
PROMPT()
```

# Valor de retorno

Caractere

# Observações

PROMPT( ) retorna o texto do título de menu escolhido por último de uma barra de menu ou o item de menu escolhido por último de um menu. A barra de menu ou menu pode ser definida pelo usuário ou uma barra de menu ou menu do sistema Visual FoxPro. Se uma barra de menu ou menu não estiver ativa ou você pressionar ESC para sair de uma barra de menu ou menu, PROMPT( ) retorna uma cadeia vazia.

Uma barra de menu é criada com DEFINE MENU, e cada título de menu na barra de menu é criado com DEFINE PAD. Um menu é criado com DEFINE POPUP, e os itens de menu no menu são criados com DEFINE BAR.

MENU( ) e POPUP( ) podem ser usados para retornar o nome da barra de menu ou menu do qual o título de menu ou item de menu é escolhido.
