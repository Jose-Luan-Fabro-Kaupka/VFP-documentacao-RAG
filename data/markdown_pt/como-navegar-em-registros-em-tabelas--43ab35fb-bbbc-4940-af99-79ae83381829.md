# Como: navegar em registros em tabelas

Você pode navegar em registros ao visualizá-los em uma janela de navegação usando barras de rolagem, teclas de seta ou a tecla TAB. Você também pode especificar um grupo de registros a localizar.

### Para navegar em registros em uma janela de navegação
- Abra a tabela em uma janela de navegação.
- No menu Table, aponte para Go to Record e escolha uma das seguintes opções: Para mover para o primeiro registro, clique em Top. Para mover para o último registro, clique em Bottom. Para mover para o próximo registro, clique em Next. Para mover para o registro anterior, clique em Previous. Para especificar um número de registro, clique em Record # para abrir a caixa de diálogo Go to Record, digite um número e clique em OK.

Para obter mais informações, consulte Go To Record Dialog Box.

### Para especificar um grupo de registros a localizar
- Abra a tabela em uma janela de navegação.
- No menu Table, aponte para Go to Record e clique em Locate. A caixa de diálogo Locate abre.
- Na caixa Scope da caixa de diálogo Locate, selecione o intervalo de registros que deseja localizar.
- Na caixa For, digite uma expressão que os registros devem satisfazer para serem localizados. Para construir uma expressão, clique no botão de reticências (...).
- Na caixa While, digite uma expressão que avalia para true para continuar localizando registros.
- Quando terminar, clique em Locate.
