# Como: ingressar em um projeto existente sob controle de código-fonte

Se você é um novo desenvolvedor em um projeto que já está sob controle de código-fonte, deve ingressar no projeto antes de poder fazer check-out e check-in de arquivos. Ao ingressar em um projeto, o Visual FoxPro cria um arquivo local de lista de projetos e gera para você um arquivo de projeto atual (.pjx).

### Para ingressar em um projeto existente
- No menu File, escolha Join Source Control Project.
- Na caixa de diálogo Open Project, selecione o servidor e o diretório que contêm o arquivo de projeto do Visual FoxPro no qual deseja ingressar.
- Defina o diretório de trabalho no computador local; ele especifica onde o sistema de controle de código-fonte colocará os arquivos ao fazer check-out e onde os procurará ao fazer check-in. Por exemplo, se estiver usando o Visual SourceSafe como provedor de controle de código-fonte, escolha Browse na área Directory e selecione um diretório existente ou digite o nome de um novo diretório. Dica: todos os desenvolvedores de um projeto devem usar a mesma estrutura de diretórios para os arquivos do projeto, embora os nomes dos subdiretórios individuais possam ser diferentes.
