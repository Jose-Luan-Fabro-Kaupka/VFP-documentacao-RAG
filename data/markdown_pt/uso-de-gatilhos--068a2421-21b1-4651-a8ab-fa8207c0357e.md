# Uso de gatilhos

Um gatilho é uma expressão vinculada a uma tabela de banco de dados e acionada quando qualquer registro da tabela é modificado por um dos comandos de modificação de dados especificados no gatilho. Você pode usar gatilhos para executar operações exigidas por um aplicativo de banco de dados ao modificar dados. A lista a seguir contém exemplos de tarefas que podem ser executadas com gatilhos:
 - Registrar modificações no banco de dados.
- Impor integridade referencial.
- Criar uma reposição automática para um produto com estoque baixo.

Os gatilhos são criados e armazenados como propriedades de uma tabela específica. Se você remover uma tabela de um banco de dados, os gatilhos associados a ela serão excluídos. Os gatilhos são disparados depois que todas as demais verificações, como regras de validação, imposição da chave primária e imposição de valores nulos, são realizadas. Entretanto, ao contrário das regras de validação em nível de campo e registro, os gatilhos não são disparados em dados armazenados em buffer.
