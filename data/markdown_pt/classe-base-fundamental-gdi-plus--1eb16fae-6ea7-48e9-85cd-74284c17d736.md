# Classe base fundamental GDI Plus

A classe gpBase é a classe base abstrata de todas as demais classes _GDIPLUS e fornece alguns métodos utilitários básicos.

| Categoria | Relatórios |
| --- | --- |
| Catálogo padrão | Visual FoxPro Catalog\Foundation Classes\Output\GDIplus |
| Classe | gpBase |
| Classe base | Custom |
| Biblioteca de classes | _GDIPLUS.vcx |
| Classe pai | Custom ( Custom Object ) |

# Observações

A tabela a seguir lista as propriedades e os métodos públicos adicionados por esta classe à classe pai, Custom.

| Propriedades e métodos | Descrição |
| --- | --- |
| AllowModalMessages Property | Determina se a classe pode exibir caixas de diálogo modais para fornecer feedback ao usuário. Padrão: INLIST(_VFP.StartMode,0,4). Observações: afeta a interface apresentada pelo manipulador de erros quando QuietOnError é false. Se AllowModalMessages= .T. , uma caixa de mensagem modal será exibida e o processamento será interrompido. Se AllowModalMessages= .F. , será usado um comando WAIT WINDOW ... NOWAIT e o processamento continuará. |
| AppName Property | Nome do aplicativo usado no feedback ao usuário. Padrão: " GDI+ FFC Library" |
| ClearErrors Method | Redefine o status de erro do objeto. Sintaxe: THIS.ClearErrors() Valores de retorno: nenhum. Parâmetros: nenhum. |
| Clone Method | Cria um novo objeto como cópia exata de um objeto existente. Sintaxe: THIS.Clone() Valores de retorno: nenhum. Parâmetros: toClone , obrigatório, objeto do qual este objeto será um clone. Observações: esta função não tem significado na classe GpBase. Ela é implementada na maioria das subclasses. Para objetos que encapsulam um objeto GDI+ subjacente, o objeto subjacente também é clonado. |
| GetErrorStatus Method | Indica se ocorreu um erro. Sintaxe: lError = THIS.GetErrorStatus() Valores de retorno: Logical. Parâmetros: nenhum. Observações: retorna True ( .T. ) se tiver ocorrido um erro desde a última chamada a ClearError(). |
| GetLastErrorMessage Method | Fornece informações sobre o último erro ocorrido. Sintaxe: cErrorMessage = THIS.getLastErrorMessage() Valores de retorno: String. cErrorMessage é o texto do último erro ocorrido. Parâmetros: nenhum. Observações: o valor de cErrorMessage só é válido quando GetErrorStatus() retorna True ( .T. ). |
| GUIDToString Method | Converte um GUID ou CLSID da forma binária em uma representação de cadeia de caracteres legível. Sintaxe: cGUIDString = THIS.GUIDToString(tqGUID) Valores de retorno: String, no formato padrão {abcdefab-cdef–abcd-efab-cdefabcdefab}. Retorna null ( .NULL. ) se ocorrer um erro. Parâmetros: tqQUID é o GUID ou CLSID a ser convertido. |
| IgnoreErrors Property | Indica se os erros devem interromper o processamento. Padrão: .F. |
| MakeGdipArrayF Method | Converte valores numéricos de um array do Visual FoxPro em uma cadeia binária que representa um array unidimensional ou bidimensional de valores float (precisão simples), adequada para ser passada diretamente a funções nativas GDI ou GDI+. Sintaxe: cArrayString = THIS.MakeGdipArrayF(taArray[, tnCols[, tnFirstCol]]) Valores de retorno: array representado em uma cadeia. Cada valor ocupa quatro bytes. Portanto, o comprimento total da cadeia é ( ALEN(taArray,1) * tnCols*4 ). Retorna null ( .NULL. ) se ocorrer um erro. Parâmetros: taArray , obrigatório, é um array de valores numéricos e deve ter pelo menos tnCols. tnCols , opcional, é o número de colunas a converter; o padrão é o número de valores no array. tnFirstCol , opcional, é o número da primeira coluna para iniciar a conversão; o padrão é 1. |
| MakeGdipArrayFFromCursor Method | Converte valores numéricos de um cursor do Visual FoxPro em uma cadeia binária que representa um array unidimensional ou bidimensional de valores float (precisão simples), adequada para ser passada diretamente a funções nativas GDI ou GDI+. Sintaxe: cArrayString = THIS.MakeGdipArrayFFromCursor(tcAlias, tnCols, tcExpr1[, tcExpr2[, tcExpr3[, tcExpr4[, tcExpr5[, tcExpr6[, tcExpr7[, tcExpr8]]]]]]]) Valores de retorno: array representado em uma cadeia. Cada valor ocupa quatro bytes. Portanto, o comprimento total da cadeia é (RECCOUNT(tcAlias) * tnCols*4) . Retorna null ( .NULL. ) se ocorrer um erro. Parâmetros: tcAlias , obrigatório, é o alias de um cursor e deve ter pelo menos tnCols campos. tnCols , obrigatório, é o número de colunas que o array deve ter. Pelo menos tnCols expressões devem ser especificadas nos parâmetros seguintes. tcExpr1 , obrigatório, é a expressão da primeira coluna (geralmente um nome de campo). tcExpr2 , obrigatório se tnCols for >=2, é a expressão da segunda coluna. tcExpr3 , obrigatório se tnCols for >=3, é a expressão da terceira coluna. tcExpr4 , obrigatório se tnCols for >=4, é a expressão da quarta coluna. tcExpr5 , obrigatório se tnCols for >=5, é a expressão da quinta coluna. tcExpr6 , obrigatório se tnCols for >=6, é a expressão da sexta coluna. tcExpr7 , obrigatório se tnCols for >=7, é a expressão da sétima coluna. tcExpr8 , obrigatório se tnCols for >= 8, é a expressão da oitava coluna. |
| MakeGdipPointF Method | Cria uma estrutura GDI+ PointF como cadeia, a partir de parâmetros x,y separados. Sintaxe: cString = MakeGdipPointF(tX, tY) Valores de retorno: cadeia de 8 bytes que representa dois valores float. Retorna null ( .NULL. ) em caso de erro. Parâmetros: tX , obrigatório, numérico, é a coordenada X do ponto. tY , obrigatório, numérico, é a coordenada Y do ponto. |
| MakeGdipRectF Method | Cria uma estrutura GDI+ RectF como cadeia, a partir de parâmetros x,y,w,h separados. Sintaxe: cString = MakeGdipRectF(tX, tY, tW, tH) Valores de retorno: cadeia de 16 bytes que representa quatro valores float. Retorna null ( .NULL. ) em caso de erro. Parâmetros: tX , obrigatório, numérico, é a coordenada X do ponto. tY , obrigatório, numérico, é a coordenada Y do ponto. tW , obrigatório, numérico, é o valor Width (dimensão horizontal). tH , obrigatório, numérico, é o valor Height (dimensão vertical). |
| MakeGdipSizeF Method | Cria uma estrutura GDI+ SizeF como cadeia, a partir de parâmetros x e y separados. Sintaxe: cString = MakeGdipSizeF(tW, tH) Valores de retorno: cadeia de 8 bytes que representa dois valores float. Retorna null ( .NULL. ) em caso de erro. Parâmetros: tW , obrigatório, numérico, é o valor Width (dimensão horizontal). tH , obrigatório, numérico, é o valor Height (dimensão vertical). |
| ObjFactory Method | Função interna para criar objetos _GDIPLUS. Usada principalmente pelos métodos de objetos derivados de _GDIPLUS que retornam valores de objeto. Sintaxe: oObject = ; THIS.ObjFactory( tcContext, tcClassname [, p1,p2,p3...p10 ] ) Valores de retorno: o objeto criado. Retorna null ( .NULL. ) em caso de erro. Parâmetros: tcContext , cadeia, é o contexto da criação do objeto, geralmente um valor no formato "class.methodname" . tcClassName , cadeia, é o nome da classe a instanciar. É sempre uma das classes base _GDIPLUS (como "gprect" ). Observações: esta função, junto com ObjFactoryHook(), pode ser usada para alterar as classes utilizadas pelas classes fundamentais GDI+. Consulte as constantes GDIPLUS_CLASS_* definidas em GDIPLUS.H para obter os valores padrão. |
| ObjFactoryHook Method | Permite modificações na classe que será criada por ObjFactory(). Sintaxe: THIS.ObjFactoryHook( tcContext, @rcClassName, @rcClassLibrary, @rcModule ) Valores de retorno: nenhum. Parâmetros: tcContext , cadeia, é o valor de contexto passado a ObjFactory(). rcClassName , cadeia, é a classe que será criada. Atribua um valor a esse parâmetro para alterar a classe que será instanciada. rcClassLibrary , cadeia, é a biblioteca de classes padrão na qual a classe a ser criada deve ser encontrada. rcModule , cadeia, é o módulo (arquivo .app, .dll ou .exe). Por padrão, será uma cadeia vazia ( "" ). |
| QuietOnError Property | Se True ( .T. ), faz com que as mensagens de erro sejam suprimidas. Padrão: NOT INLIST(_VFP.StartMode,0,4) |
| StringToGUID Method | Converte uma representação legível em cadeia de um GUID ou CLSID para a forma binária. Sintaxe: qGUID = THIS.StringToGUID(tcString) Valores de retorno: qQUID é o GUID ou CLSID como um valor varbinary de 16 bytes. Retorna null ( .NULL. ) se ocorrer um erro. Parâmetros: tcString é um GUID ou CLSID legível no formato padrão {abcdefab-cdef–abcd-efab-cdefabcdefab}. |
