# Rotina de biblioteca de API _WGetObjectWindow( )

Retorna o identificador da janela de quadro na qual o objeto especificado está contido.

```foxpro
WHANDLE _WGetObjectWindow(Value FAR *objct)
```

# Observações

Use a função da rotina de biblioteca de API _WhToHwnd( ) para converter WHANDLE em um HWND do Windows.
