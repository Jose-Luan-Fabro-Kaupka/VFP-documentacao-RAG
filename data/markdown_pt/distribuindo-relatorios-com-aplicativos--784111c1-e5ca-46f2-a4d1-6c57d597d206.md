# Distribuindo relatórios com aplicativos

Quando você terminar de criar, desenvolver e executar relatórios no Visual FoxPro, pode incluí-los para distribuição com seus aplicativos.

# Nesta seção
 **Integrando relatórios com aplicativos**
Discute funções de relatório e design de relatório no contexto do desenvolvimento de aplicativos.
**Definindo proteção para relatórios**
Contém tópicos sobre como configurar proteção para relatórios para que os usuários não possam alterar certas partes ao modificá-los no modo protegido.
**Incluindo arquivos de relatório para distribuição**
Fornece informações sobre a distribuição de tabelas de definição de relatório e etiqueta (.frx e .lbx) bem como componentes externos do Sistema de Relatórios do Visual FoxPro (como ReportBuilder.app) com seus aplicativos.

Apresenta relatórios e etiquetas do Visual FoxPro.
**Recursos de relatório para aplicativos internacionais**
Cobre recursos de interesse para desenvolvedores que distribuem seus aplicativos internacionalmente.
**Distribuindo aplicativos**
Fornece informações sobre como preparar seu aplicativo para distribuição.
