# Objeto Separator

Cria um objeto Separator que coloca espaço entre controles em uma barra de ferramentas.

```foxpro
Separator
```

# Observações

Os controles em uma barra de ferramentas são posicionados imediatamente uns ao lado dos outros, a menos que você inclua um Separator entre os controles. Um Separator é um objeto especial que adiciona espaço entre os controles e cria um grupo de controles.

Para obter informações adicionais sobre como criar barras de ferramentas e separadores, consulte Designing Menus and Toolbars.
