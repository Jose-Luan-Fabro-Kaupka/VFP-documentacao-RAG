# Função MEMORY( )

Retorna a quantidade de memória disponível para executar um programa externo.

```foxpro
MEMORY()
```

# Valor de retorno

Numeric

# Observações

No Visual FoxPro, MEMORY( ) sempre retorna 640.

MEMORY( ) é semelhante a SYS(12), com duas exceções:
 - MEMORY( ) retorna a quantidade de memória disponível em kilobytes; SYS(12) retorna a quantidade de memória em bytes.
- MEMORY( ) retorna uma expressão numérica. SYS(12) retorna seu valor como uma cadeia de caracteres.
