# Funções

O Visual FoxPro contém funções nas seguintes categorias, bem como funções adicionais.
 **Character Functions**
Lista funções que operam em dados de caractere.
**Data Conversion Functions**
Lista funções que convertem dados de um tipo de dados para outro.
**Date and Time Functions**
Lista funções que geram e manipulam dados de data e hora.
**COM Functions**
Lista os comandos e funções que permitem acessar objetos e servidores COM.
**Numeric Functions**
Lista funções que operam ou retornam dados numéricos.
**XML Functions**
Descreve funções que permitem manipulações de dados entre Visual FoxPro e dados em Extensible Markup Language (XML).
**Supported Visual FoxPro Commands and Functions in OLE DB Provider**
Lista comandos e funções que você pode usar no OLE DB Provider.
**Unsupported Visual FoxPro Commands and Functions in OLE DB Provider**
Lista comandos e funções não suportados no OLE DB Provider.

Para obter informações sobre referência de linguagem compatível apenas com versões anteriores, consulte Backward-Compatible Language Elements.
