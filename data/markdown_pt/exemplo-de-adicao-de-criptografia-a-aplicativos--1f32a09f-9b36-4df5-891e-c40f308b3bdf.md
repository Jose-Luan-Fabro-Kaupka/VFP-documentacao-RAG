# Exemplo de adição de criptografia a aplicativos

Arquivo: ...\Samples\Solution\FFC\Crypto.scx

Este exemplo mostra o uso da classe fundamental Crypto, que estende as rotinas da API Crypto do Windows. Você pode adicionar criptografia a textos, arquivos e dados dos aplicativos. São mostrados vários estilos de criptografia, bem como a assinatura de arquivos.

Este exemplo contém as seguintes classes.

| Classe | Biblioteca | Descrição |
| --- | --- | --- |
| _cryptapi | _ crypt.vcx | A classe fundamental contém propriedades e métodos estendidos para adicionar criptografia aos aplicativos. Ela usa as rotinas da API Crypto do Windows. |

Para obter detalhes sobre todas as classes fundamentais disponíveis, consulte Classes fundamentais do Visual FoxPro de A a Z.
