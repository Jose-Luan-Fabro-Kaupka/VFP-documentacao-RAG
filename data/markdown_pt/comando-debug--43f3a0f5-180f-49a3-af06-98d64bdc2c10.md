# Comando DEBUG

Abre o depurador do Visual FoxPro.

```foxpro
DEBUG
```

# Observações

A configuração de ambiente do depurador (FoxPro Frame ou Debugger Frame) determina se o depurador é colocado na área de trabalho do Visual FoxPro ou em uma janela separada. Alterne essa configuração na guia Debugging da caixa de diálogo Options.

Se você emitir DEBUG quando o depurador estiver aberto, o depurador se torna a janela ativa.
