# Como: abrir relatórios e etiquetas

Você pode abrir um relatório ou etiqueta existente para modificá-lo. Você também pode abrir um relatório em modo protegido para impedir que usuários alterem parte do relatório ou etiqueta que você especificar.

### Para abrir um relatório ou etiqueta
- No menu File, clique em Open .
- Na caixa de diálogo Open, navegue até a pasta que contém o relatório ou etiqueta que deseja abrir. Dica Para mostrar apenas arquivos de relatório ou arquivos de etiqueta, selecione Report (*.frx) ou Label (*.lbx) na caixa Files of type da caixa de diálogo Open.
- Clique no arquivo de relatório ou etiqueta que deseja abrir. O nome do arquivo aparece na caixa File name.
- Clique em OK . O designer correspondente abre para o relatório ou etiqueta.

### Para abrir um relatório ou etiqueta em um projeto
- Abra o projeto do seu aplicativo.
- No Project Manager , expanda o nó Documents.
- No nó Documents, expanda o nó Reports ou Labels.
- No nó Reports ou Labels, selecione o relatório ou etiqueta que deseja editar.
- No Project Manager , clique em Modify . O designer correspondente abre para o relatório ou etiqueta.

### Para abrir um relatório ou etiqueta programaticamente
- Use o comando MODIFY REPORT ou MODIFY LABEL. O designer apropriado abre para o relatório ou etiqueta.

Para obter mais informações, consulte MODIFY REPORT Command e MODIFY LABEL Command.

### Para abrir um relatório ou etiqueta em modo protegido
- Use o comando MODIFY REPORT ou MODIFY LABEL com a palavra-chave PROTECTED. O designer apropriado abre para o relatório ou etiqueta.
