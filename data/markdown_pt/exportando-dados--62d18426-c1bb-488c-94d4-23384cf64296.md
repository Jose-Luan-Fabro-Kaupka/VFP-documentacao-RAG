# Exportando dados

Você pode exportar dados de suas tabelas Visual FoxPro para arquivos de texto, planilhas ou tabelas usadas em outros aplicativos. O processo de exportação requer uma tabela de origem e o tipo e nome do arquivo de destino. Se desejar, você pode selecionar quais campos e registros exportar. Você pode usar o novo arquivo em qualquer aplicativo que suporte o tipo de arquivo que você selecionar.

# Escolhendo um tipo de arquivo para exportar

A tabela a seguir lista os tipos de arquivo que você pode exportar do Visual FoxPro.

| Tipo de arquivo | Extensão de arquivo | Descrição |
| --- | --- | --- |
| Delimitado por tabulações | txt | Um arquivo de texto com uma tabulação separando cada campo. |
| Delimitado por vírgulas | txt | Um arquivo de texto com uma vírgula separando cada campo. |
| Delimitado por espaços | txt | Um arquivo de texto com um espaço separando cada campo. |
| System Data Format | sdf | Um arquivo de texto com registros de comprimento fixo terminando com retorno de carro e avanço de linha. |
| Tabela | dbf | Uma tabela Visual FoxPro, FoxPro, FoxBASE+®, dBASE ou Paradox 3.5 ou 4.0. |
| Microsoft Excel | xls | Um formato de planilha Microsoft Excel (versões 2.0, 3.0, 4.0, 5.0 e 97). As células de coluna tornam-se campos e as linhas tornam-se registros. Você pode exportar no máximo 65.535 linhas, que incluem uma linha reservada para o cabeçalho do campo. |
| Lotus 1-2-3 | wks wk1 | Uma planilha Lotus 1-2-3 para releases 1-A, 2.x e 3.x. As células de coluna tornam-se campos e as linhas tornam-se registros. |

Para obter mais informações sobre exportação, consulte o comando COPY TO .
