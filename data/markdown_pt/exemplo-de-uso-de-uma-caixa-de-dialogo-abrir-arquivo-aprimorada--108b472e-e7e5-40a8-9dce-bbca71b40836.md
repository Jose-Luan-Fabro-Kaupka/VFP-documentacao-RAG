# Exemplo de uso de uma caixa de diálogo Abrir Arquivo aprimorada

Arquivo: ...\Samples\Solution\FFC\Getfilex.scx

Os comandos padrão GETFILE() e PUTFILE() do Visual FoxPro fornecem caixas de diálogo para seleção de arquivos que não têm a aparência das caixas mais recentes. Este exemplo mostra o uso da Classe Base de Caixa de Diálogo Comum. Com essa classe, você pode usar recursos de interface estendidos nessas caixas de diálogo, incluindo a barra Locais à esquerda, que fornece acesso rápido a outros locais de pesquisa, como Histórico, Área de Trabalho e Meus Documentos.
 Este exemplo contém as seguintes classes
| Classe | Biblioteca | Descrição |
| --- | --- | --- |
| _comdlg | _ system.vcx | Contém um conjunto de propriedades e métodos para que você possa usar as caixas de diálogo nativas do Windows para abrir e salvar arquivos. |

Para obter detalhes sobre todas as classes disponíveis nas classes base, consulte Classes Base do Visual FoxPro de A a Z.
