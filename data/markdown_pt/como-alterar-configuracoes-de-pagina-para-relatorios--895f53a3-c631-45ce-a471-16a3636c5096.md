# Como: alterar configurações de página para relatórios

Você pode alterar as configurações de página padrão para um relatório ou etiqueta. Por exemplo, você pode alterar a margem esquerda, a fonte padrão para o layout da página, o tamanho e a origem do papel e a orientação da página.

> **Observação:** Ao alterar o tamanho do papel e a orientação da página, certifique-se de que a orientação da página corresponda ao tamanho do papel. Por exemplo, se você selecionar um envelope, deve definir a orientação da página como Landscape.

> **Observação:** Ao definir a fonte padrão para o layout da página, a configuração se aplica apenas a novos controles de relatório que você adicionar ao relatório. Para obter mais informações, consulte Como: alterar configurações de fonte em controles de relatório .

### Para definir a margem esquerda da página
- Abra o relatório ou etiqueta no designer apropriado.
- No menu Report, clique em Properties . A caixa de diálogo Report Properties abre. Observação Se a variável de sistema _REPORTBUILDER não estiver definida para o Report Builder padrão, a caixa de diálogo Configuração de página do relatório abre em vez disso. Se _REPORTBUILDER estiver definida para um builder de terceiros, uma caixa de diálogo diferente pode ser exibida. Para obter mais informações, consulte Variável de sistema _REPORTBUILDER e Caixa de diálogo Configuração de página do relatório .
- Na caixa de diálogo Report Properties, clique na guia Page Layout se ela não estiver selecionada.
- Na caixa Left margin, digite ou selecione um valor para a margem esquerda.
- Clique em OK . Observação Ao alterar a margem esquerda de uma página com colunas, a largura da coluna é alterada automaticamente para acomodar a nova margem.

Para obter mais informações, consulte Guia Page Layout, Caixa de diálogo Report Properties (Report Builder).

### Para alterar a fonte padrão para o layout da página
- Abra o relatório ou etiqueta no designer apropriado.
- No menu Report, clique em Default Font .
- Na caixa de diálogo Font, selecione o estilo e o tamanho de fonte desejados e clique em OK .

Para obter mais informações, consulte Caixa de diálogo Font.

Você também pode alterar a fonte padrão no menu Report clicando em Properties para abrir a caixa de diálogo Report Properties. Clique na guia Page Layout e, na área Default font, clique no botão de reticências (…) para abrir a caixa de diálogo Font.

> **Observação:** Ao usar este método para ajustar a fonte padrão de um relatório, o Report Builder registra o Script que você selecionou para a fonte na caixa de diálogo e adiciona esta informação ao layout do relatório. Você vê a caixa de seleção Use font script marcada quando retorna à guia Page Layout da caixa de diálogo Report Properties, e o rótulo mostrando sua fonte, tamanho de fonte e estilo selecionados também mostra o valor numérico representando este script. Se não desejar salvar esta informação, desmarque a caixa de seleção. Para obter mais informações, consulte Guia Page Layout, Caixa de diálogo Report Properties (Report Builder) .

> **Observação:** Se a variável de sistema _REPORTBUILDER não estiver definida para o Report Builder padrão ou estiver definida para um builder de terceiros, a caixa de diálogo Configuração de página do relatório é exibida ou uma caixa de diálogo diferente pode ser exibida. Para obter mais informações, consulte Variável de sistema _REPORTBUILDER e Caixa de diálogo Configuração de página do relatório .

### Para alterar o tamanho ou a origem do papel
- Abra o relatório ou etiqueta no designer apropriado.
- No menu Report, clique em Properties . A caixa de diálogo Report Properties abre. Observação Se a variável de sistema _REPORTBUILDER não estiver definida para o Report Builder padrão, a caixa de diálogo Configuração de página do relatório abre em vez disso. Se _REPORTBUILDER estiver definida para um builder de terceiros, uma caixa de diálogo diferente pode ser exibida. Para obter mais informações, consulte Variável de sistema _REPORTBUILDER e Caixa de diálogo Configuração de página do relatório .
- Na caixa de diálogo Report Properties, clique na guia Page Layout.
- Na guia Page Layout, clique em Page setup . A caixa de diálogo Page Setup abre.
- Na caixa Size, selecione o tamanho de papel desejado.
- Na caixa Source, selecione a origem de papel desejada.
- Quando terminar, clique em OK .

Para obter mais informações, consulte Guia Page Layout, Caixa de diálogo Report Properties (Report Builder).

### Para alterar a orientação da página
- Abra o relatório ou etiqueta no designer apropriado.
- No menu Report, clique em Properties . A caixa de diálogo Report Properties abre. Observação Se a variável de sistema _REPORTBUILDER não estiver definida para o Report Builder padrão, a caixa de diálogo Configuração de página do relatório abre em vez disso. Se _REPORTBUILDER estiver definida para um builder de terceiros, uma caixa de diálogo diferente pode ser exibida. Para obter mais informações, consulte Variável de sistema _REPORTBUILDER e Caixa de diálogo Configuração de página do relatório .
- Na caixa de diálogo Report Properties, clique na guia Page Layout.
- Clique em Page setup . A caixa de diálogo Page Setup abre.
- Na área Orientation, clique em Portrait ou Landscape e depois OK .

Para obter mais informações, consulte Guia Page Layout, Caixa de diálogo Report Properties (Report Builder).
