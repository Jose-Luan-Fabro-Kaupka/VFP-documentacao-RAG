# Forms Solution Samples

Estas amostras Solution ilustram tarefas de desenvolvimento de aplicativos que você pode realizar com formulários.

# Nesta seção
 **Create a One-To-Many Data Entry Form Sample**
Ilustra tarefas básicas associadas a um formulário de entrada de dados one-to-many.
**Create a Query-By-Example Form Sample**
Ilustra como fornecer recursos de pesquisa e filtragem para registros na mesma interface que exibe esses registros.
**Create a Single Table Data Entry Form Sample**
Ilustra um cenário simples para um formulário de entrada de dados de usuário único e tabela única.
**Create an SDI Form Sample**
Ilustra o suporte do Visual FoxPro para formulários single document interface (SDI).
**Create an Irregularly Shaped Window Sample**
Ilustra como você pode usar a função Windows API SetLayeredWindowAttributes para alterar a área de cliente retangular padrão da janela principal do Visual FoxPro ou de quaisquer formulários que você criar.
**Display Line Animation on a Form Sample**
Ilustra como desenhar linhas em um formulário.
**Display Pictures in an Image Control Sample**
Ilustra como exibir bitmaps ou ícones em um controle Image em um formulário.
**Draw Lines and Shapes on a Form Sample**
Ilustra como usar métodos de formulário para desenhar figuras e formas em formulários.
**Graph Equations on a Form Sample**
Ilustra como grafar equações em formulários.
**Manipulate Objects Programmatically Sample**
Ilustra como passar parâmetros para formulários e recuperar valores.
**Pass Parameters Between Forms Sample**
Ilustra como passar parâmetros para formulários e recuperar valores.
**Provide What's This? Help on a Form Sample**
Ilustra como fornecer o botão de Ajuda "What's This?" em um formulário.
**Return a Value from a Form Sample**
Ilustra como retornar um valor de um formulário de logon.
**Run Multiple Instances of a Form Sample**
Ilustra como executar várias instâncias de um formulário.
**Transparent Forms Sample**
Ilustra como usar janelas em camadas para melhorar o desempenho e os efeitos visuais com formas complexas.
**Use Access/Assign Methods on a Form Sample**
Ilustra como usar métodos Access e Assign em um formulário.
