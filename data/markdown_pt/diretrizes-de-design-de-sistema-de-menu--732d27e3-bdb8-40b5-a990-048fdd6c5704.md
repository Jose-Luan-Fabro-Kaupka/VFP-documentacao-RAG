# Diretrizes de design de sistema de menu

A utilidade de um aplicativo pode depender da qualidade de seus sistemas de menu. Se você investir tempo de planejamento em seus menus, os usuários os aceitarão prontamente e aprenderão rapidamente.

Ao projetar seu sistema de menu, considere as seguintes diretrizes:
 - Organize o sistema de acordo com as tarefas que os usuários executarão, e não de acordo com a hierarquia de programas no aplicativo. Os usuários podem formar um modelo mental de como o aplicativo está organizado olhando para os menus e itens de menu. Para projetar esses menus e itens de menu de forma eficaz, você deve saber como seus usuários pensarão e realizarão seu trabalho.
- Dê a cada menu um título significativo.
- Organize os itens de menu de acordo com sua frequência esperada de uso, sua sequência lógica ou sua ordem alfabética. Se você não puder prever a frequência e não puder determinar uma ordem lógica, organize os itens de menu em ordem alfabética. A ordenação alfabética é particularmente eficaz quando um menu contém mais de oito itens. Com tantos itens, o usuário gasta tempo examinando-os; a ordenação alfabética facilita a varredura.
- Coloque linhas separadoras entre grupos lógicos de itens de menu.
- Limite o número de itens em um menu a uma tela.
- Se o número exceder o tamanho de uma tela, crie submenus para os itens de menu apropriados.
- Escolha teclas de acesso e atalhos de teclado para menus e itens de menu. Por exemplo, ALT+F pode ser uma tecla de acesso para um menu File.
- Use palavras que descrevam claramente os itens de menu. Use palavras comuns em vez de jargão de computador, e use verbos simples e ativos para indicar quais ações resultarão da escolha de cada item de menu. Não use substantivos como verbos. Além disso, descreva os itens de menu usando construção paralela. Por exemplo, se você usar palavras únicas para todos os itens, use a mesma classe gramatical para todos eles.
- Use letras maiúsculas e minúsculas mistas nos itens de menu.
