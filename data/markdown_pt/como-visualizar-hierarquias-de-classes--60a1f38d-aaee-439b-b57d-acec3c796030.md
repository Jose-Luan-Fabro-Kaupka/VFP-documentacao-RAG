# Como: visualizar hierarquias de classes

Você pode visualizar a hierarquia em uma biblioteca de classes, membros definidos pelo usuário em uma classe e herança de membros entre classes relacionadas usando o Class Browser.

### Para visualizar membros e hierarquias de classes
- No Class Browser , abra a biblioteca de classes que deseja visualizar. Para obter informações sobre como abrir o Class Browser, consulte Como: executar o Class Browser .
- Na lista de classes do Class Browser , selecione a classe desejada.

Quando uma classe é selecionada, um ícone para a classe aparece ao lado da lista de tipos, que aparece acima da lista de classes. Quaisquer membros de classe definidos pelo usuário que existam aparecem na lista de membros. Subclasses aparecem recuadas abaixo das classes pai quando o modo Hierárquico está selecionado no menu de atalho do Class Browser.

Quando uma classe é selecionada, você pode visualizar sua classe pai, se disponível.

### Para visualizar a classe pai
- Clique com o botão direito na classe e, no menu de atalho, escolha Select ParentClass . A classe pai aparece selecionada.

Se um chevron (<<) aparecer ao lado de uma classe, sua classe pai está localizada em uma biblioteca de classes (.vcx) que não é exibida na lista de classes. Se você escolher Select ParentClass no menu de atalho da classe, a biblioteca de classes que contém a classe pai é adicionada à lista de classes e a classe pai é selecionada.

Você pode visualizar várias bibliotecas de classes ou arquivos de formulário abrindo outro arquivo na janela atual do Class Browser ou abrindo outra janela do Class Browser. Você também pode abrir o mesmo arquivo em várias janelas do Class Browser.
