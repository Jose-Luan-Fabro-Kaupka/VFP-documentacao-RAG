# Não é possível compilar uma DLL sem classes públicas OLE (Erro 2002)

O comando BUILD DLL exige que classes públicas OLE estejam definidas.
 - Você escolheu a opção errada na caixa de diálogo Opções de Compilação. Escolha outra ação, como Compilar Aplicativo .
- Nenhuma classe pública OLE está definida. Defina uma ou mais classes públicas OLE. Para obter mais informações, consulte a caixa de diálogo Informações da Classe ou a cláusula OLEPUBLIC do comando DEFINE CLASS.
