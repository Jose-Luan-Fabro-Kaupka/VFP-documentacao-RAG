# Interação com outros aplicativos

Com o Visual FoxPro você pode compartilhar dados com outros aplicativos como Microsoft Excel e Word, usar objetos de outros aplicativos e controlar outros aplicativos usando Automation.

# Compartilhando dados com outros aplicativos

Você pode aproveitar todas as ferramentas de software em sua área de trabalho com o Visual FoxPro.

Use seus dados FoxPro em outros aplicativos Compartilhar dados com outros aplicativos é fácil – por exemplo, você pode compartilhar dados do Visual FoxPro com o Microsoft Excel usando o PivotTable Wizard ou com o Microsoft Word usando o assistente Mail Merge.

Exibir ou armazenar objetos de outros aplicativos Você pode incluir objetos de outro aplicativo vinculando ou incorporando-os em tabelas ou formulários. Então você pode editar os objetos diretamente, sem sair do Visual FoxPro.
 Editar objetos incluídos é fácil no Visual FoxPro.

# Importando e exportando dados

Você pode importar e exportar dados entre o Visual FoxPro e muitos outros aplicativos usando uma variedade de formatos de arquivo: texto, planilhas e tabelas, para citar alguns. Os dados podem ser anexados ou copiados de tabelas existentes com facilidade. O Import Wizard ajuda você a tomar decisões sobre a estrutura que deseja que os dados assumam no Visual FoxPro.

Para obter mais informações, consulte Importando e exportando dados.

# Integração com Automation

Com o Visual FoxPro você tem o poder de integrar totalmente seu aplicativo com outros aplicativos.

Controlar outros aplicativos Você pode ampliar o poder de seu aplicativo controlando outros aplicativos programaticamente. Por exemplo, você pode direcionar o Microsoft Excel para executar alguns cálculos, instruir o Microsoft Graph a criar um gráfico dos resultados e armazenar o gráfico em um campo General de uma tabela do Visual FoxPro, tudo a partir de código do Visual FoxPro. Ou você pode adicionar controles ActiveX que você ou outra pessoa desenvolveu.

Otimizar solicitações de Automation Você pode determinar quanto tempo seu sistema usa para solicitações e quanto tempo leva para mensagens aparecerem para seu usuário. Por exemplo, você pode controlar quanto tempo seu sistema gasta tentando novamente solicitações de Automation antes de exibir uma mensagem "servidor ocupado".

Você também pode controlar o número de milissegundos que passam durante a entrada do usuário, como usar o mouse ou o teclado enquanto uma solicitação de Automation está pendente, e uma mensagem "ocupado" aparecendo.

Controlar o Visual FoxPro a partir de outros aplicativos Usando o Visual FoxPro como servidor de Automation, você pode criar referências a objetos do Visual FoxPro, executar comandos do Visual FoxPro e executar programas do Visual FoxPro a partir de outros aplicativos.

Para obter mais informações sobre Automation, consulte Compartilhando informações e adicionando OLE.
