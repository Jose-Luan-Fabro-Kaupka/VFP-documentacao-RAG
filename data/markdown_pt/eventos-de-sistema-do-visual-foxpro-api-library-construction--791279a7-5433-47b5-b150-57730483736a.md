# Eventos de sistema do Visual FoxPro (API Library Construction)

Nesta tabela, cada evento do Visual FoxPro é listado junto com o layout de seus campos de registro de evento e uma descrição de quando o evento ocorre.

| Event | EventRec Fields | Description |
| --- | --- | --- |
| nullEvent | what = nullEvent where.h = horizontal mouse location where.v = vertical mouse location when = ticks since startup | Ocorre quando nenhum outro evento está pendente. Este é o evento que ocorre com mais frequência e, por motivos de desempenho, deve ser usado com moderação. |
| mouseDownEvent | what = mouseDownEvent where.h = horizontal mouse location where.v = vertical mouse location mbState = left mouse button when = ticks since startup | Ocorre sempre que o botão esquerdo do mouse é pressionado. Capture o mouseDownEvent e use-o em combinação com o ponto where e a função _FindWindow para verificar se o usuário clicou na caixa de menu fechar ou em outras partes de uma janela. (Um closeEvent não é gerado quando você clica na caixa de menu fechar de uma janela.) |
| keyDownEvent | what = keyDownEvent where.h = horizontal mouse location where.v = vertical mouse location message = key code (see Appendix A) modifier = modifier key when = ticks since startup | Ocorre sempre que uma tecla é pressionada no teclado ou sempre que o buffer do teclado é reproduzido. |
| deactivateEvent | what = deactivateEvent where.h = horizontal mouse location where.v = vertical mouse location message = WHANDLE to window when = ticks since startup | Ocorre sempre que uma janela é desativada clicando na caixa de menu fechar, ativando outra janela ou usando o comando DEACTIVATE WINDOW. Um deactivateEvent geralmente é seguido por um activateEvent. |
| activateEvent | what = activateEvent where.h = horizontal mouse location where.v = vertical mouse location message = WHANDLE to window when = ticks since startup | Ocorre sempre que uma janela é ativada. Isso inclui janelas do sistema e do usuário, bem como caixas de diálogo; portanto, é recomendado que, sempre que receber este tipo de evento, verifique se ele se refere à sua janela. Um activateEvent geralmente é precedido por um deactivateEvent. |
| menuHitEvent | what = menuHitEvent misc = MENUID misc2 = BAR # when = ticks since startup modifier = modifier key | Ocorre quando um usuário faz uma seleção em um item do tipo menu. Itens do tipo menu incluem menus, popups e listas roláveis. Como menuHitEvents ocorrem com muita frequência, é melhor usar a função _OnSelection para executar uma determinada tarefa após uma seleção de menu, eliminando muita verificação extra de eventos. |
| closeEvent | what = closeEvent message = WHANDLE to window when = ticks since startup | Ocorre quando uma janela é removida da memória com o comando RELEASE WINDOW ou ao sair do Visual FoxPro. Para verificar se um usuário fechou uma janela clicando na caixa de menu fechar, verifique um mouseDownEvent. |
| hideEvent | what = hideEvent when = ticks since startup | Ocorre quando uma janela é ocultada com o comando HIDE WINDOW. |
| showEvent | what = showEvent when = ticks since startup | Ocorre quando uma janela é exibida com o comando SHOW WINDOW. |
| hotkeyEvent | what = hotkeyEvent where.h = horizontal mouse location where.v = vertical mouse location message = key code (see FoxPro Key Codes chapter) modifier = modifier key when = ticks since startup | Ocorre quando o usuário pressiona uma tecla que tem ações atribuídas com o comando ON KEY LABEL. |
| sizeEvent | what = sizeEvent when = ticks since startup | Ocorre somente quando um comando ZOOM WINDOW ou SIZE WINDOW é emitido. Para verificar uma instância de um usuário clicando no controle de tamanho de uma janela, verifique um mouseDownEvent. |
| zoomEvent | what = zoomEvent when = ticks since startup | Ocorre somente quando o comando ZOOM WINDOW é executado. Para verificar a instância de um usuário clicando no controle de zoom, verifique um mouseDownEvent. |
