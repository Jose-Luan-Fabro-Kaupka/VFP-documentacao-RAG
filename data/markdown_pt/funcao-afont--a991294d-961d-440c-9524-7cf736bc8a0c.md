# Função AFONT( )

Coloca informações sobre fontes disponíveis, como seus nomes, em um array.

> **Dica:** Você também pode usar AFONT( ) para determinar tamanhos de fonte disponíveis ou se uma fonte é escalável. Para exibir uma caixa de diálogo contendo fontes disponíveis, tamanhos de fonte e estilos, use a função GETFONT( ). Para obter mais informações, consulte GETFONT( ) Function .

```foxpro
AFONT(ArrayName [, cFontName [, nFontSize | nFontCharSet [, nFlags]]])
```

#### Parâmetros
 **ArrayName**
Especifica o array de variáveis no qual os nomes das fontes disponíveis são colocados. Se o array não for grande o suficiente para conter todas as fontes, o Visual FoxPro aumenta automaticamente o tamanho do array. Se você especificar um array bidimensional existente, o Visual FoxPro altera o array para um array unidimensional.
**cFontName**
Especifica uma fonte para a qual as informações são colocadas no array. Se a fonte que você especificar suporta apenas tamanhos de fonte discretos (8 pontos, 10 pontos, ...), os tamanhos de fonte são armazenados no array, e AFONT( ) retorna True (.T.). Se a fonte que você especificar em cFontName é escalável (suporta valores de tamanho de fonte fracionários), o array tem um único elemento contendo –1, e AFONT( ) retorna True (.T.). Se a fonte que você especificar não estiver disponível, o array não é criado, e AFONT( ) retorna False (.F.).
**nFontSize**
Especifica um tamanho para a fonte especificada em cFontName . Se o tamanho de fonte nFontSize estiver disponível para a fonte especificada em cFontName, o array tem um único elemento contendo um valor True (.T.), e AFONT( ) retorna True (.T.). Se o tamanho de fonte não estiver disponível para a fonte especificada, o array não é criado, e AFONT( ) retorna False (.F.).
**nFontCharSet**
Especifica um conjunto de caracteres para a fonte especificada em cFontName . Se o conjunto de caracteres da fonte especificado estiver disponível para a fonte especificada em cFontName , o array tem um único elemento contendo um valor True (.T.), e AFONT( ) retorna True (.T.). Se o conjunto de caracteres da fonte não estiver disponível para a fonte especificada, o array não é criado, e AFONT( ) retorna False (.F.).
**nFlags**
Controla se o terceiro parâmetro passado é tratado como o tamanho da fonte ou conjunto de caracteres da fonte. A tabela a seguir descreve o comportamento para vários valores de nFlags especificados. nFlags Descrição Omitido ou 0 para o primeiro bit O terceiro parâmetro é tratado como um valor de tamanho de fonte. Se o terceiro parâmetro for -1, o array é atualizado com todos os tamanhos de fonte disponíveis para a fonte especificada em cFontName para fontes não proporcionais, como MS Sans Serif, e AFONT( ) retorna True (.T.). Este comportamento no Visual FoxPro 8.0 e posterior é equivalente a passar apenas os dois primeiros parâmetros. Observação Em versões anteriores ao Visual FoxPro 8.0, se você especificasse qualquer tamanho de fonte negativo ou positivo para uma fonte não proporcional, AFONT( ) retornava False (.F.). Se o terceiro parâmetro passado for 0, para fontes não proporcionais, AFONT( ) retorna False (.F.) para Visual FoxPro 8.0 e posterior. No entanto, o comportamento para fontes proporcionais como TrueType ou OpenType (Arial) não mudou. 1 O terceiro parâmetro é tratado como um conjunto de caracteres da fonte. O array é preenchido com conjuntos de caracteres disponíveis para a fonte especificada. Se o terceiro parâmetro passado for -1, o array é atualizado com todos os conjuntos de caracteres de fonte disponíveis para a fonte especificada em cFontName .

# Valor de retorno

Tipo de dados Logical. AFONT( ) retorna True (.T.) se o array for criado com sucesso. Caso contrário, AFONT( ) retorna False (.F.).

# Observações

Se apenas ArrayName foi passado em versões anteriores ao Visual FoxPro 8.0, o array preenchido em AFONT( ) incluía fontes extras que eram realmente parte de uma única família de fontes. Por exemplo, o array poderia incluir as seguintes fontes Arial no Visual FoxPro 7.0:
 - Arial
- Arial Baltic
- Arial Black
- Arial CE
- Arial CYR
- Arial Greek
- Arial Narrow
- Arial Tur

Muitas dessas fontes não estão incluídas em uma caixa de diálogo Font Picker padrão, como a função GETFONT( ). Nesta versão do Visual FoxPro, o array em AFONT( ) exclui essas fontes extras. Por exemplo, o array inclui apenas as seguintes fontes:
 - Arial
- Arial Baltic
- Arial Black

# Exemplo

O exemplo a seguir usa AFONT( ) para criar um array contendo os nomes de todas as fontes disponíveis. O nome de cada fonte é exibido, junto com um exemplo da fonte. Se houver mais de 10 fontes instaladas, apenas as primeiras 10 são exibidas.

```foxpro
CLEAR
=AFONT(gaFontArray)  && Array containS font names.
gnNumFonts = ALEN(gaFontArray)  && Number of fonts
IF gnNumFonts > 10
   gnNumFonts = 10  && Display first 10 fonts.
ENDIF
FOR nCount = 1 TO gnNumFonts
   ? ALLTRIM(gaFontArray(nCount))  && Display font name.
   ?? '  This is an example of ' ;
      + ALLTRIM(gaFontArray(nCount)) FONT gaFontArray(nCount), 8
ENDFOR
```
