# Guia Value, Edit Box Builder

Esta guia no Edit Box builder especifica um campo no qual armazenar o valor da caixa de edição.
 **Field Name**
Especifica um campo de tabela ou view no qual armazenar o valor da caixa de edição. Digite o nome do campo ou clique no botão de diálogo para exibir a caixa de diálogo Open, onde você pode selecionar outra tabela ou view. No Edit Box builder, clique na seta suspensa ao lado da caixa de listagem Field Name para selecionar um campo. O conteúdo padrão desta guia são todos os campos no ambiente de dados. Esta opção corresponde à propriedade ControlSource.

Para obter mais informações, consulte Creating Forms.
