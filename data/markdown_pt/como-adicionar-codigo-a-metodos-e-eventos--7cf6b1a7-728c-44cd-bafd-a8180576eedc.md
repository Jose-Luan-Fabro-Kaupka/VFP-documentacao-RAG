# Como: adicionar código a métodos e eventos

Você pode adicionar código para métodos que adiciona a classes ou eventos de classe usando o Class Designer ou programaticamente.

### Para adicionar código para um método ou evento
- Abra a classe no Class Designer. Para obter mais informações sobre como abrir classes, consulte Como: modificar classes.
- Na barra de ferramentas do Visual FoxPro, clique em Properties Window.
- Na lista de propriedades da janela Properties, clique duas vezes no método ou evento para o qual deseja adicionar código para abrir uma janela de código. Observação Métodos personalizados aparecem no final da lista de propriedades.
- Na janela de código, adicione código para o método ou evento.
- Quando terminar de adicionar código, feche a janela de código.

Para obter mais informações, consulte Janela Properties (Visual FoxPro) e Janela Code.

### Para adicionar código a métodos e eventos programaticamente
- Use o comando DEFINE CLASS e inclua a cláusula FUNCTION ou PROCEDURE.

Para obter mais informações, consulte Comando DEFINE CLASS.
