# Guia Operations, XML Web Service Builder

Especifica as operações de serviço Web XML, ou chamadas de método, que você deseja usar em seu formulário ou classe. Você pode fornecer informações de parâmetro para as chamadas de operação antecipadamente e especificar um controle, ou cliente, ao qual deseja associar os resultados da chamada de operação.

> **Observação:** As configurações das guias Operations e Clients são armazenadas no método personalizado SetupOperations.
 **Operations**
Lista todas as operações registradas para o serviço Web XML. Você pode chamar essas operações automaticamente quando o formulário ou a classe é instanciado ou programaticamente quando necessário. Você pode associar cada operação a vários clientes. Add Exibe uma caixa de diálogo com opções para adicionar uma nova operação. Para obter mais informações, consulte XML Web Service - Operation Detail Dialog Box. Edit Exibe uma caixa de diálogo com opções para editar a operação selecionada. Para obter mais informações, consulte XML Web Service - Operation Detail Dialog Box. Remove Remove a operação selecionada. Se você remover uma operação, será solicitado que remova quaisquer clientes associados à operação.
**Clients**
Lista todos os clientes registrados para a operação selecionada. Clientes são controles ou objetos em um formulário ou em uma classe que usam a operação de serviço Web XML. Você pode especificar quando a associação ocorre entre a operação e o cliente e a qual propriedade do controle os resultados da operação são atribuídos. Para serviços Web XML que retornam DataSets ADO.NET, você também pode especificar informações de tipo complexo, como configurações de tabela ou campo. Add Exibe uma caixa de diálogo com opções para adicionar um novo cliente. Para obter mais informações, consulte XML Web Service - Client Detail Dialog Box. Edit Exibe uma caixa de diálogo com opções para editar o cliente selecionado. Para obter mais informações, consulte XML Web Service - Client Detail Dialog Box. Remove Remove o cliente selecionado.
