# Guia Projeto, caixa de diálogo Informações do projeto

Exibe informações de status sobre o projeto.
 **Autor**
Exibe o nome do autor, que você pode alterar digitando-o na caixa.
**Empresa**
Exibe o nome da empresa, que você pode alterar digitando-o na caixa.
**Endereço/Cidade/Estado/País/Código postal**
Exibe as informações de endereço da empresa, que você pode alterar digitando-as nas caixas.
**Início**
Exibe o diretório que contém o arquivo do projeto. Para alterar o diretório, digite outro nome na caixa ou clique no botão de diálogo para exibir a caixa de diálogo Selecionar diretório.
**Última compilação**
Exibe a data e a hora da última compilação do projeto. Essas informações não podem ser editadas.
**Arquivos**
Exibe o número de arquivos no projeto. Essas informações não podem ser editadas.
**Info de depuração**
Especifica se as informações de depuração são incluídas com o arquivo compilado. Se esta opção não estiver marcada, você não pode visualizar a execução do programa na janela Trace. Corresponde ao argumento NODEBUG no comando COMPILE.
**Criptografado**
Especifica se os arquivos compilados devem ser embaralhados para segurança.
**Anexar ícone**
Especifica se um ícone selecionado deve ser exibido quando o aplicativo é executado. Quando marcada, exibe a caixa de diálogo Abrir se um ícone nunca foi atribuído ao aplicativo.
**Ícone**
Exibe a caixa de diálogo Abrir para que você possa escolher um ícone. Este botão está disponível somente se você selecionar a caixa de seleção Anexar ícone. Para exibir o ícone corretamente no Windows Explorer, o arquivo de ícone deve conter imagens de ícone de 32 x 32 e 16 x 16. A imagem de 32 x 32 é usada na exibição Ícones grandes do Explorer, e a imagem de 16 x 16 é usada nas exibições Ícones pequenos, Lista e Detalhes do Explorer. A tabela a seguir lista os formatos de imagem de ícone que o Visual FoxPro suporta. **Classe do projeto**
Exibe a caixa de diálogo Referência do projeto, permitindo que você especifique uma classe ProjectHook padrão como modelo para novos projetos.
