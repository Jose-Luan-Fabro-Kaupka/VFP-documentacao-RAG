# Caixa de diálogo Toolbars

Permite criar, editar, ocultar e personalizar barras de ferramentas.
 **Toolbars**
Lista as barras de ferramentas disponíveis. As barras de ferramentas selecionadas são dispostas lado a lado ou exibidas na janela de saída ativa.
**New**
Exibe a caixa de diálogo NewToolbar, na qual você pode inserir um nome para sua nova barra de ferramentas.
**Reset**
Restaura a barra de ferramentas selecionada à versão integrada. Este botão muda para Delete se você selecionar uma barra de ferramentas personalizada. Você não pode redefinir uma barra de ferramentas personalizada.
**Delete**
Exclui a barra de ferramentas personalizada selecionada. Este botão muda para Reset se você selecionar uma barra de ferramentas integrada. Você não pode excluir uma barra de ferramentas integrada.
**Customize**
Exibe a Caixa de diálogo Customize Toolbar para que você possa adicionar e excluir botões da barra de ferramentas.

# Display
 **Color Buttons**
Exibe botões coloridos nas barras de ferramentas integradas e personalizadas. Desmarque esta caixa de seleção se estiver usando um monitor em preto e branco.
**Large Buttons**
Exibe botões da barra de ferramentas maiores que o tamanho padrão. Se o monitor tiver alta resolução, talvez você deseje exibir botões maiores.
**Show ToolTips**
Exibe o nome do botão quando você posiciona o ponteiro sobre qualquer botão em uma barra de ferramentas.
