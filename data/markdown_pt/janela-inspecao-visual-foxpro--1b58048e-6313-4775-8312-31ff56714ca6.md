# Janela Inspeção (Visual FoxPro)

Permite exibir expressões e seus valores atuais e definir pontos de interrupção em uma expressão. Essa janela é ativada quando você escolhe Inspeção no menu Janela, janela Depurador. O Visual FoxPro habilita o IntelliSense na janela Inspeção, mas limita o suporte somente a Listar membros.

No Visual FoxPro 9.0, os itens de menu Localizar e Localizar novamente estão disponíveis para pesquisar itens na coluna Nome da janela Inspeção.
 **Inspeção**
O valor ou a expressão que você deseja examinar. Digite expressões aqui para adicioná-las à grade de expressões de inspeção ativas abaixo.
**Nome**
Exibe os nomes das expressões de inspeção atuais.
**Valor**
Exibe os valores das expressões de inspeção atuais.
**Tipo**
Exibe caracteres que representam os tipos de dados das expressões de inspeção atuais.

Você pode selecionar expressões, excluí-las ou adicionar pontos de interrupção a elas.

 Para criar uma nova expressão de inspeção
 - Selecione o texto em qualquer janela do Visual FoxPro e arraste-o para a janela Inspeção.

 Para editar uma expressão de inspeção
 - Clique duas vezes na expressão de inspeção.
