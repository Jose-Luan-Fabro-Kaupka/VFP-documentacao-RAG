# Função NTOM( )

Retorna um valor Currency a partir de uma expressão numérica.

```foxpro
NTOM(nExpression)
```

#### Parâmetros
 **nExpression**
Especifica uma expressão numérica cujo valor Currency NTOM( ) retorna. Se nExpression tiver mais de quatro casas decimais, é arredondado para quatro casas decimais. Se nExpression tiver menos de quatro casas decimais, é preenchido com zeros até que quatro casas decimais sejam criadas.

# Valor de retorno

Tipo Currency. NTOM( ) retorna um valor do tipo Currency com quatro casas decimais.

# Exemplo

O exemplo a seguir cria uma variável de tipo numérico chamada `gnNumeric`. TYPE( ) exibe N, indicando que a variável é de tipo numérico. NTOM( ) é usado para converter a variável para um tipo currency, e TYPE( ) agora exibe Y, indicando que a variável é de tipo currency após a conversão.

```foxpro
STORE 24.95 TO gnNumeric  && Creates a numeric type memory variable
CLEAR
? "gnNumeric is type: "
?? TYPE('gnNumeric')  && Displays N, numeric type value
gnNumeric= NTOM(gnNumeric)     &&  Converts gnNumeric to a currency value
? "gnNumeric is now type: "
?? TYPE('gnNumeric')  && Displays Y, currency type value
```
