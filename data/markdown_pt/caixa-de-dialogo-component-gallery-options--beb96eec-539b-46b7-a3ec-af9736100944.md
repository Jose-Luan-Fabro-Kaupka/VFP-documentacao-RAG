# Caixa de diálogo Component Gallery Options

Permite especificar configurações globais para catálogos e views no Component Gallery.

# Opções de guia

As opções disponíveis na caixa de diálogo Component Gallery Options estão agrupadas nas seguintes guias.

| Guia | Para acessar estes recursos |
| --- | --- |
| Standard Tab, Component Gallery Options Dialog Box | Permite especificar padrões globais. Esta guia está sempre disponível. |
| Catalogs Tab, Component Gallery Options Dialog Box | Permite adicionar catálogos ao Component Gallery e especificar se os catálogos são globais ou padrão. |
| Dynamic Views Tab, Component Gallery Options Dialog Box | Permite adicionar, editar ou remover views da sua lista de views. Esta guia está sempre disponível. |
