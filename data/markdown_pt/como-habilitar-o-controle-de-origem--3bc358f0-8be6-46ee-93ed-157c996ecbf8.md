# Como: habilitar o controle de origem

Para habilitar o controle de origem, primeiro instale o programa de controle de origem conforme a documentação fornecida com ele. Normalmente, você instala uma versão de administrador em um servidor onde o código-fonte será mantido e, em seguida, instala a versão cliente do produto nas máquinas locais.

> **Observação:** Todos os desenvolvedores de um projeto devem usar o mesmo software de controle de código-fonte.

Após instalar o software de controle de origem, você pode definir opções para que o Visual FoxPro o reconheça e especificar padrões para seus projetos.

### Para habilitar o controle de origem no Visual FoxPro
- No menu Tools, escolha Options .
- Na caixa de diálogo Options, escolha a guia Projects.
- Na área Source control options, selecione o nome do seu programa de controle de origem na lista Active source control provider.
- Para que o Visual FoxPro solicite que você adicione novos projetos ao controle de origem, selecione Automatically add new projects to source control .

Cada vez que você inicia o Visual FoxPro, ele verifica se há um provedor de controle de origem. Se um for encontrado, você pode colocar ou gerenciar projetos sob controle de origem.
