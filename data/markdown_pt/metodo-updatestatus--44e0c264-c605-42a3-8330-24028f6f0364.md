# Método UpdateStatus

Aciona uma alteração de informações nos elementos da interface do usuário fornecidos por DoStatus.

```foxpro
oReportListener.UpdateStatus()
```

#### Parâmetros

Nenhum.

# Valor de retorno

Nenhum.

# Observações

Aplica-se a: ReportListener Object.

Este método fornece uma oportunidade para o objeto ReportListener avaliar se as condições no relatório mudaram de alguma forma que justifique chamar o método DoStatus para exibir novas informações ao usuário.

A frequência com que você chama este método e em quais pontos durante a execução do relatório você escolhe chamá-lo dependem do tipo de feedback que seu ReportListener fornece.

> **Dica:** Você escolhe a frequência ou o cronograma com que mostra feedback durante uma execução de relatório, bem como a mensagem de feedback que mostra, substituindo este método. Você determina a maneira como exibe a mensagem de feedback substituindo o método DoStatus.

O ReportListener nativo mostra o progresso do relatório invocando UpdateStatus cada vez que renderiza uma nova página. A ReportListener User Feedback Class, no entanto, avalia o registro atual no alias de condução do relatório e atualiza sua barra de progresso cada vez que este registro muda.
