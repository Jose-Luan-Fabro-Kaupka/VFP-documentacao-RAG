# Como: restaurar a tabela IntelliSense padrão

Você pode restaurar a funcionalidade IntelliSense para elementos de linguagem nativos do Visual FoxPro na tabela IntelliSense para sua configuração padrão. No entanto, registros IntelliSense definidos pelo usuário permanecem a menos que você os exclua manualmente.

### Para restaurar a configuração da tabela IntelliSense para elementos de linguagem nativos do Visual FoxPro
- No menu Tools, clique em IntelliSense Manager.
- No IntelliSense Manager, clique na guia Advanced.
- Na guia Advanced, clique em Clean Up.
- Na caixa de diálogo Maintenance, clique em Restore FoxCode. O Visual FoxPro solicita que você confirme a restauração da tabela IntelliSense para a tabela original.
- Para confirmar a restauração, clique em Yes. O Visual FoxPro confirma que restaurou uma cópia limpa da tabela IntelliSense.
- Para concluir a restauração, clique em OK.

### Para excluir registros IntelliSense definidos pelo usuário
- No menu Tools, clique em IntelliSense Manager.
- No IntelliSense Manager, clique na guia Custom.
- Na guia Custom, selecione o registro IntelliSense definido pelo usuário que deseja excluir.
- Clique em Delete.
- Quando solicitado a confirmar a exclusão, clique em Yes para marcar o registro para exclusão.
- Quando terminar de marcar todos os registros que deseja excluir, clique na guia Advanced.
- Na guia Advanced, clique em Clean Up.
- Na caixa de diálogo Maintenance, clique em Clean Up FoxCode para remover registros marcados para exclusão.
