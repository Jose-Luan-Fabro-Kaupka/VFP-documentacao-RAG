# Exemplo Adicionar caixas de combinação de pesquisa de dados

Arquivo: ...\Samples\Solution\Ffc\DataLook2.scx

Este exemplo contém as seguintes classes.

| Classe | Biblioteca | Descrição |
| --- | --- | --- |
| _cbodistinctvalues | _dataquery.vcx | Executa uma pesquisa de valores únicos no campo controlsource para preencher uma caixa de combinação. |
| _cbolookup | _dataquery.vcx | Executa uma pesquisa de valores em um campo para preencher uma caixa de combinação. |
| _nav2buttons | _table.vcx | Exibe um par de botões que fornecem as funções GoNext( ) e GoPrevious( ). |

Para detalhes sobre todas as classes disponíveis nas classes básicas, consulte Classes básicas do Visual FoxPro A-Z.
