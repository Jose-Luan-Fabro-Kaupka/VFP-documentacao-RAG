# Classe base Locate Button

Este botão exibe uma caixa de diálogo para localizar um registro.

| Categoria | Consulta de dados |
| --- | --- |
| Catálogo padrão | Visual FoxPro Catalog\Foundation Classes\Data Query |
| Classe | _locatebutton |
| Classe base | CommandButton |
| Biblioteca de classes | _table2.vcx |
| Classe pai | _dialogbutton |
| Exemplo | ...\Samples\Solution\Ffc\dataqry.scx |

# Observações

Para usar, solte a classe em um projeto ou formulário ou selecione Add to Form no menu de atalho do item da Component Gallery. Ao adicionar a classe a um formulário, o Visual FoxPro insere um botão que abre a caixa de diálogo Locate. Ao soltá-la em um projeto, você pode escolher entre adicionar a classe ou criar uma subclasse.
