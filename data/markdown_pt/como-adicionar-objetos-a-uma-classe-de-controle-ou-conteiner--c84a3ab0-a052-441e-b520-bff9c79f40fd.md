# Como: adicionar objetos a uma classe de controle ou contêiner

Se você basear uma nova classe em uma classe de controle ou contêiner, pode adicionar controles a ela usando o Class Designer da mesma forma que adiciona controles no Form Designer.

### Para adicionar controles a uma classe
- Abra a classe no Class Designer.
- Na barra de ferramentas Form Controls, arraste um controle para a classe de controle ou contêiner no Class Designer. Dica Para desativar a funcionalidade snap-to-grid, pressione e segure a tecla CTRL enquanto arrasta objetos da barra de ferramentas.
