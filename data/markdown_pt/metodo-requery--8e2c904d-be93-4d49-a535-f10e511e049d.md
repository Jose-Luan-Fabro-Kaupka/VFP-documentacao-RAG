# Método Requery

Reconsulta a fonte de linhas à qual o controle ListBox ou ComboBox está vinculado.

```foxpro
Control.Requery
```

# Observações

Aplica-se a: ComboBox Control | ListBox Control

Use o método Requery para garantir que um controle contenha os dados mais recentes. O método Requery reconsulta a propriedade RowSource e atualiza a lista com os novos valores.
