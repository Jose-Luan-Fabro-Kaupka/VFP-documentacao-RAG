# Trabalhando com classes no Visual FoxPro

O Visual FoxPro inclui a capacidade de trabalhar com classes como parte do fornecimento dos recursos de programação orientada a objetos. Quando você projeta e cria uma classe, está construindo um modelo para poder criar objetos a partir dessa classe. O Visual FoxPro inclui designers e outras ferramentas para criar e gerenciar classes.
