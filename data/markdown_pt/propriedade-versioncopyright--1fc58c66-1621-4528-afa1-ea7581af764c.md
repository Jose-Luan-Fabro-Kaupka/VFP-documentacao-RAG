# Propriedade VersionCopyright

As informações de direitos autorais de um projeto.

```foxpro
Object.VersionCopyright[ = cCopyRight]
```

# Valor de retorno
 **cCopyRight**
Especifica as informações de direitos autorais de um projeto. O valor padrão é a cadeia vazia.

# Observações

Aplica-se a: objeto Project (Visual FoxPro)

A propriedade VersionCopyRight corresponde ao valor do item Direitos autorais na caixa de diálogo Versão do EXE.
