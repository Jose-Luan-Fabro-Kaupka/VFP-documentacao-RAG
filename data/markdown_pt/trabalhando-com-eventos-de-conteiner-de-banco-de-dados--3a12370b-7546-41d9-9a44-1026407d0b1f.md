# Trabalhando com eventos de contêiner de banco de dados

Você pode usar eventos de contêiner de banco de dados (DBC) para executar código de procedimento quando esses eventos ocorrem.

> **Observação:** Eventos DBC não estão disponíveis em versões anteriores ao Visual FoxPro 7.0. Tentar acessar um banco de dados com eventos DBC habilitados usando uma versão anterior ao Visual FoxPro 7.0 gera um erro.
