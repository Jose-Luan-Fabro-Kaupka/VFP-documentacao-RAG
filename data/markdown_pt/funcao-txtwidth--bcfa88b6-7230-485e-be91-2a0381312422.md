# Função TXTWIDTH( )

Retorna o comprimento de uma expressão de caractere em relação à largura média de caractere de uma fonte.

```foxpro
TXTWIDTH(cExpression [, cFontName, nFontSize [, cFontStyle]])
```

#### Parâmetros
 **cExpression**
Especifica uma expressão de caractere para a qual TXTWIDTH( ) retorna o comprimento. Se você incluir apenas cExpression, o comprimento da expressão de caractere é retornado para a fonte atual da janela principal do Visual FoxPro ou da janela de saída ativa. Uma fonte não proporcional sempre retorna um valor igual ao número de caracteres em cExpression. Inclua os argumentos opcionais cFontName, nFontSize e cFontStyle para determinar o comprimento de uma expressão de caractere com uma fonte, tamanho de ponto ou estilo de fonte específico.
**cFontName**
Especifica o nome da fonte. Inclua cFontName para retornar o comprimento de uma expressão de caractere com uma fonte específica.
**nFontSize**
Especifica um número que corresponde ao tamanho em pontos da fonte. Inclua nFontSize para retornar o comprimento de uma expressão de caractere com um tamanho de ponto específico.
**cFontStyle**
Especifica um estilo de fonte especial para a expressão de caractere. cFontStyle é um código de estilo de fonte especificado por um caractere ou um conjunto de caracteres. O estilo de fonte Normal é usado se cFontStyle não for incluído. Aqui estão os caracteres para cada estilo de fonte: Caractere Estilo de fonte B Bold I Italic N Normal O Outline Q Opaque S Shadow - Strikeout T Transparent U Underline Você pode incluir mais de um caractere para especificar uma combinação de estilos de fonte. Por exemplo, BI especifica um estilo de fonte Bold Italic. O comando a seguir exibe uma mensagem em uma fonte Courier normal de 24 pontos, centralizada horizontalmente na janela principal do Visual FoxPro: @ 25,(WCOLS( )-TXTWIDTH('Hello!','Courier ',24)* ; FONTMETRIC(6,'Courier ',24)/FONTMETRIC(6))/2 ; SAY 'Hello!' FONT 'Courier ',24

# Valor de retorno

Numérico

# Observações

TXTWIDTH( ) retorna o número de caracteres que uma expressão de caractere cExpression ocupa, com base na largura média de caractere de uma fonte especificada (a largura média de caractere de uma fonte é chamada de foxel). Use FONTMETRIC(6) para determinar a largura média de caractere de uma fonte.

Se você não incluir uma fonte em TXTWIDTH( ), o valor retornado por TXTWIDTH( ) é determinado pela fonte atual da janela principal do Visual FoxPro, desde que a saída seja direcionada para a janela principal do Visual FoxPro quando TXTWIDTH( ) é emitido. Se a saída estiver sendo direcionada para uma janela definida pelo usuário, o valor retornado é determinado pela fonte atual da janela.
