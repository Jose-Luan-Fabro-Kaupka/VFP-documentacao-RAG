# Função CURSORGETPROP( )

Recupera as configurações de propriedade atuais para uma tabela ou cursor do Visual FoxPro.

> **Dica:** Para definir uma propriedade específica para uma tabela ou cursor do Visual FoxPro, use CURSORSETPROP( ) . Para obter informações adicionais sobre cada uma das propriedades e suas configurações, consulte Função CURSORSETPROP( ) .

```foxpro
CURSORGETPROP(cProperty [, nWorkArea | cTableAlias])
```

**nWorkArea**
Especifica a área de trabalho da tabela ou cursor da qual a configuração de propriedade é retornada. Se você especificar 0 para nWorkArea , CURSORGETPROP( ) retorna a configuração do ambiente.
**cTableAlias**
Especifica o alias da tabela ou cursor da qual a configuração de propriedade é retornada.

# Valor de retorno

Tipo de dados Character, Numeric ou Logical

# Observações

As configurações de propriedade atuais são retornadas para a tabela ou cursor aberta na área de trabalho atualmente selecionada se CURSORGETPROP( ) for emitido sem os argumentos opcionais cTableAlias ou nWorkArea. Se você usar CURSORGETPROP( ) sem uma tabela selecionada, um cursor aberto ou um alias especificado, você obtém o Erro 52 (No table is open in current work area.) a menos que uma área de trabalho seja especificada como neste exemplo, CURSORSETPROP("Refresh",-2,0).

# Exemplo

Quando um cursor é aberto, o valor padrão para a propriedade AutoIncError é lido do valor padrão da sessão, que é a configuração padrão da sessão de dados atual. O exemplo a seguir mostra como você pode recuperar o valor padrão AutoIncError para cada sessão especificando 0 (sessão padrão) como o último parâmetro:

```foxpro
CURSORGETPROP("AutoIncError", 0)
```

A sessão padrão é usada ao abrir uma nova sessão de dados privada ou cursor. O exemplo a seguir mostra como você pode recuperar a configuração AutoIncError do cursor ou tabela para cada tabela usando o parâmetro nWorkArea ou cTableAlias como o último parâmetro:

```foxpro
CURSORGETPROP("AutoIncError", nWorkArea | cTableAlias)
```

O exemplo a seguir abre uma tabela "Customer" no banco de dados "Testdata" e usa CURSORGETPROP( ) para exibir o modo de buffering da tabela e o nome do banco de dados no qual a tabela está contida:

```foxpro
CLOSE DATABASES
CLEAR
OPEN DATABASE (HOME(2) + 'data\testdata')
USE customer     && Open customer table
? CURSORGETPROP("Buffering") && Displays buffering mode
? CURSORGETPROP("Database")  && Displays database name
```
