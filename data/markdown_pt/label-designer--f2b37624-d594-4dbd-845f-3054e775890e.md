# Label Designer

Você pode criar e modificar etiquetas usando o Label Designer. O Label Designer é o mesmo que o Report Designer e usa os mesmos menus e barras de ferramentas. A principal diferença é que o Label Designer define automaticamente o layout de página e suas colunas com base no tamanho da etiqueta que você selecionar. Para obter informações sobre como abrir o Label Designer, consulte How to: Create Labels.

O Label Designer usa bandas e controles para gerenciar o layout de dados em uma página de etiqueta.

# Bandas

As bandas permitem especificar onde e quando os dados são exibidos na página de etiqueta. O Label Designer contém três bandas por padrão:
 - Page Header Exibe informações ou dados que são exibidos uma vez por página no início da página.
- Detail Exibe informações ou dados que são exibidos uma vez por registro na tabela subjacente.
- Page Footer Exibe informações ou dados que são exibidos uma vez por página no final da página.

Cada banda é seguida por um separador, que contém o nome da banda e uma seta apontando para cima indicando o espaço que a banda ocupa. Bandas Detail são indicadas por setas preenchidas, enquanto todas as outras bandas são indicadas por setas vazias.

Você pode adicionar outras bandas ao seu layout. Para obter mais informações, consulte Working with Report Bands.

### Régua

O Label Designer exibe uma régua vertical e horizontal que você pode usar para posicionar objetos com mais precisão nas bandas. A escala da régua é determinada pelas configurações de medida do seu sistema.
