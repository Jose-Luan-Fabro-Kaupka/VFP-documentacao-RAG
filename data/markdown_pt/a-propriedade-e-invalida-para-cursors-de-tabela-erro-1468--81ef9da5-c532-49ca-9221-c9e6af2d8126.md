# A propriedade é inválida para cursors de tabela (Erro 1468)

A propriedade não é suportada para cursors baseados em tabelas; aplica-se apenas a cursors baseados em views. Use a propriedade somente para cursors de view.

Para um cursor criado por um objeto CursorAdapter, a propriedade SQL para CURSORGETPROP( ) não é válida para cursors de tabela quando a propriedade DataSourceType é especificada como "XML".
