# Método CheckIn

Faz check-in das alterações feitas em um arquivo em um projeto sob controle de código-fonte.

```foxpro
Object.CheckIn()
```

# Observações

Aplica-se a: File Object (Visual FoxPro)

True (.T.) é retornado se o arquivo for verificado com sucesso. False (.F.) é retornado se o arquivo não pôde ser verificado no controle de código-fonte ou se o projeto não está sob controle de código-fonte.
