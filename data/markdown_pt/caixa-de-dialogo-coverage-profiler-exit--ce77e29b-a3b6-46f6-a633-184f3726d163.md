# Caixa de diálogo Coverage Profiler Exit

Interrompe a aplicação Coverage Profiler e permite escolher como continuar ou encerrar o registro de cobertura. Esta caixa de diálogo é exibida se você emitiu SET COVERAGE Command FileName antes de executar a aplicação Coverage Profiler.

A caixa de diálogo fornece as seguintes opções:

| Botão | Resultado |
| --- | --- |
| Yes | Permite continuar registrando dados anexando mais registros ao arquivo .log atual para uso na aplicação Coverage Profiler. |
| No | Permite continuar registrando dados, mas sobrescreve os registros no arquivo .log atual. |
| Cancel | Deixa o registro desativado depois de fechar a aplicação Coverage Profiler. |
