# Como: salvar programas

Depois de criar ou modificar um programa, salve suas alterações.

### Para salvar um programa
- No menu File, clique em Save.

O Visual FoxPro salva programas com a extensão de nome de arquivo .prg. Depois de salvar seu programa, você poderá executá-lo ou modificá-lo.

> **Observação:** Se você salvar um programa sem nome, o Visual FoxPro exibirá a caixa de diálogo Save As para que você especifique um nome. Se salvar um programa criado no Project Manager, o Visual FoxPro adicionará o programa ao projeto.
