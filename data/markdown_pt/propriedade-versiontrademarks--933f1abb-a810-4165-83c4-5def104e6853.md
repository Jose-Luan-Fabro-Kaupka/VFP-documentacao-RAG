# Propriedade VersionTrademarks

As informações de marcas registradas de um projeto.

```foxpro
Object.VersionTrademarks[ = cTradeMarks]
```

# Valor de retorno
 **cTradeMarks**
Especifica as informações de marcas registradas de um projeto. O valor padrão é a cadeia de caracteres vazia.

# Observações

Aplica-se a: Project Object (Visual FoxPro)

A propriedade VersionTrademarks corresponde ao valor do item Legal Trademarks na caixa de diálogo EXE Version Dialog Box.
