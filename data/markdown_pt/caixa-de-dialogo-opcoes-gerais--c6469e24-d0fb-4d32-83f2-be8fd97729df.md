# Caixa de diálogo Opções gerais

Permite especificar código para um sistema de menu inteiro. Você pode acessar esta caixa de diálogo selecionando General Options no menu View nos Menu and Shortcut Designers.
 **Procedure**
Cria código de procedimento de menu. Se o código exceder a região de edição exibida, a barra de rolagem é ativada.
**Edit**
Abre uma janela de edição para que você possa criar código ali em vez de na caixa de diálogo GeneralOptions. Para ativar a janela de edição, clique em Edit e depois em OK na caixa de diálogo GeneralOptions.

# Localização
 **Replace**
Substitui o sistema de menu existente por um novo sistema de menu.
**Append**
Adiciona um novo sistema de menu à direita do sistema de menu ativo.
**Before**
Insere um novo menu antes do menu especificado. Esta opção exibe uma lista suspensa contendo os nomes no sistema de menu ativo. Para inserir o novo menu, selecione o nome do menu que você deseja que o novo menu preceda.
**After**
Insere um novo menu após o menu especificado. Esta opção exibe uma lista suspensa contendo os nomes no sistema de menu ativo. Para inserir o novo menu, selecione o nome do menu que você deseja que o novo menu siga.

# Código de menu
 **Setup**
Abre uma janela de edição na qual você pode adicionar código de configuração a um sistema de menu. Para tornar a janela de edição ativa, clique em OK na caixa de diálogo GeneralOptions.
**Cleanup**
Abre uma janela de edição na qual você pode adicionar código de limpeza a um sistema de menu. Para tornar a janela de edição ativa, clique em OK na caixa de diálogo GeneralOptions.
**Top-Level Form**
Se marcada, permite que o menu seja usado em um formulário de nível superior (SDI). Se não marcada, permite que o menu seja usado somente no frame do Visual FoxPro.

Para obter mais informações, consulte Projetando menus e barras de ferramentas.
