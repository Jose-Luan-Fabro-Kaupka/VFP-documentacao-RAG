# Compreendendo o modelo de eventos

O modelo de eventos do Visual FoxPro é extenso e fornece muito controle sobre como os componentes em sua aplicação respondem a uma ampla variedade de ações do sistema e do usuário. O Visual FoxPro gerencia o processamento de eventos para que você possa fornecer um ambiente interativo mais rico para os usuários da aplicação.
