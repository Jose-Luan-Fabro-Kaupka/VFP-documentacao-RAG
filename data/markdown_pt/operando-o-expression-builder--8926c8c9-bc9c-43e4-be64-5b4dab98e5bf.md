# Operando o Expression Builder

Você pode construir expressões usando o Expression Builder quando o acesso é fornecido na interface de usuário do Visual FoxPro. Nos locais onde você precisa especificar uma expressão na interface de usuário do Visual FoxPro, um botão de reticências (...) geralmente é fornecido para que você possa abrir o Expression Builder.
