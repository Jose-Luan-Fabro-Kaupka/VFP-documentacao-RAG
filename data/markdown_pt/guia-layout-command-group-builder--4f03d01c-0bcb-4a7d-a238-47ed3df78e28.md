# Guia Layout, Command Group Builder

Esta guia no Command Group builder especifica o layout dos botões (vertical ou horizontal), o espaçamento e o estilo da borda.
 **Layout dos botões**
Especifica o layout vertical ou horizontal dos botões do grupo de comandos. Você também pode personalizar a localização dos botões dentro de um Command Group selecionando Editar no menu de atalho e arrastando os botões dentro do limite do Command Group. Retorne à edição do Command Group clicando primeiro fora do limite do Command Group. Se você personalizou o layout dos botões, nem Vertical nem Horizontal está selecionado. Se você então selecionar Vertical ou Horizontal, os botões se alinham e você perde o padrão personalizado. Escolha Cancelar para recuperar o padrão personalizado.
**Espaçamento entre botões**
Especifica o espaçamento entre os botões. Se você personalizou o espaçamento dos botões, esta opção está desabilitada. Se você alinhar os botões horizontalmente ou verticalmente, esta opção é habilitada.
**Estilo da borda**
Especifica uma borda de linha única ou nenhuma borda ao redor do grupo de comandos.
