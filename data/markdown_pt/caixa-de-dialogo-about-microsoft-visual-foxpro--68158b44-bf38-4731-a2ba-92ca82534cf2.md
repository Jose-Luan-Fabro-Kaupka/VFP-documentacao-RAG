# Caixa de diálogo About Microsoft Visual FoxPro

Exibe os direitos autorais, licenciamento e informações de versão do Visual FoxPro, bem como seu número de identificação do produto.

Para exibir esta caixa de diálogo no menu Help, escolha About Microsoft Visual FoxPro.
 **System Info**
Exibe a ferramenta Microsoft System Information, que contém as informações de configuração do sistema. Para acessar informações de ajuda sobre o Microsoft System Information, pressione F1 ou escolha Help Topics no menu Help do Microsoft System Information.
