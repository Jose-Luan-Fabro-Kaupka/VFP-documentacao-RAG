# Guia Indexes, Table Designer

A guia Indexes no Table Designer permite criar índices para uma tabela.
 **Botão Mover**
Move uma entrada de índice para cima ou para baixo na lista. Aparece como um botão com uma seta de duas pontas à esquerda da linha do índice depois que você inserir duas ou mais linhas.
**Order**
Especifica a ordem de classificação do índice. Uma seta para cima indica classificação ascendente; uma seta para baixo, descendente.
**Name**
Especifica o nome da tag de índice. O botão de seta à esquerda do nome do índice especifica ordem ascendente ou descendente. Selecione o índice e clique no botão de seta para alterar a ordem.
**Type**
Especifica um tipo de índice opcional. Uma tabela pode ter apenas um índice definido como índice primário na coluna Type. Observação Se uma tabela contém um índice com o tipo Unique, o Table Designer exibe esse tipo; no entanto, o designer não oferece mais o tipo Unique como opção disponível. Para obter mais informações sobre tipos de índice, consulte Visual FoxPro Index Types.
**Expression**
Especifica a expressão de índice, como um nome de campo. Clique no botão para criar ou editar uma expressão na Expression Builder Dialog Box. Uma expressão pode ter até 240 caracteres.
**Filter**
Especifica a expressão de filtro. Clique no botão para criar ou editar uma expressão na caixa de diálogo Expression Builder.
**Collate**
Especifica uma sequência de ordenação para a tag de índice. Clique na seta para selecionar uma sequência de ordenação do Visual FoxPro na lista suspensa. A configuração padrão é "Machine".
**Insert Button**
Insere um novo índice acima do índice selecionado na grade.
**Delete button**
Exclui o índice selecionado da grade.
