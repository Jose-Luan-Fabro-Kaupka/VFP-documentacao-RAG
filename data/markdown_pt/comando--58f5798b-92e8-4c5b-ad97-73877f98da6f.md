# Comando &

Executa substituição de macro.

```foxpro
& VarName[.cExpression]
```

#### Parâmetros
 **& VarName**
Especifica o nome da variável ou elemento de matriz a referenciar na substituição de macro. Não inclua o prefixo M. que distingue variáveis de campos. Essa inclusão causa um erro de sintaxe. A macro não deve exceder o comprimento máximo de instrução permitido no Visual FoxPro. Uma variável não pode referenciar a si mesma recursivamente em substituição de macro. Por exemplo, o seguinte gera uma mensagem de erro: STORE '&gcX' TO gcX ? &gcX Instruções de substituição de macro que aparecem em DO WHILE, FOR e SCAN são avaliadas somente no início do loop e não são reavaliadas em iterações subsequentes. Quaisquer alterações na variável ou elemento de matriz que ocorram dentro do loop não são reconhecidas.
**[. cExpression ]**
O delimitador de ponto (.) opcional e . cExpression são usados para anexar caracteres adicionais a uma macro. cExpression anexado à macro com . cExpression também pode ser uma macro. Se cExpression é um nome de propriedade, inclua um ponto extra ( cExpression .. PropertyName ).

# Observações

A substituição de macro trata o conteúdo de uma variável ou elemento de matriz como um literal de cadeia de caracteres. Quando um e comercial (&) precede uma variável ou elemento de matriz de tipo caractere, o conteúdo da variável ou elemento substitui a referência de macro. Você pode usar substituição de macro em qualquer comando ou função que aceite um literal de cadeia de caracteres.

> **Dica:** Sempre que possível, use uma expressão de nome em vez de substituição de macro. Uma expressão de nome opera como substituição de macro. No entanto, uma expressão de nome é limitada a passar cadeias de caracteres como nomes. Use uma expressão de nome para processamento significativamente mais rápido se um comando ou função aceitar um nome (um nome de arquivo, nome de janela, nome de menu e assim por diante). Para obter informações adicionais sobre expressões de nome, consulte Name Expression Creation .

Embora os seguintes comandos sejam aceitáveis:

```foxpro
STORE 'customer' TO gcTableName
STORE 'company'  TO gcTagName
USE &gcTableName ORDER &gcTagName
```

use uma expressão de nome em vez disso:

```foxpro
USE (gcTableName) ORDER (gcTagName)
```

A substituição de macro é útil para substituir uma palavra-chave em um comando. No exemplo a seguir, a configuração TALK é salva em uma variável para que a configuração possa ser restaurada posteriormente no programa. A configuração TALK original é restaurada com substituição de macro.

> **Observação:** Realizar concatenação com um único e comercial (&) ao tentar incluir e comerciais duplos (&&) em um literal de cadeia de caracteres pode produzir resultados indesejáveis. Por exemplo, suponha que você atribua a cadeia de caracteres "YYY" a uma variável, BBB . Realizar concatenação usando "AAA&" e "&BBB" substitui "BBB" por "YYY", então em vez de obter o resultado "AAA&&BBB" , o resultado é "AAA&YYY" . Para obter mais informações, consulte o comando && .

# Exemplo

```foxpro
STORE SET('TALK') TO gcSaveTalk
SET TALK OFF
*
*  Additional program code
*
SET TALK &gcSaveTalk  && Restore original TALK setting
```
