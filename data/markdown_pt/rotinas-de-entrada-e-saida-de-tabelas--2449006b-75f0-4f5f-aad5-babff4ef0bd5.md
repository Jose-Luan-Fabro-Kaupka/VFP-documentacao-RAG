# Rotinas de entrada e saída de tabelas

Essas rotinas de API permitem manipular tabelas do Visual FoxPro.
 **_DBAppend( ) API Library Routine**
Tenta acrescentar um novo registro à tabela na área de trabalho especificada.
**_DBLock( ) API Library Routine**
Tenta bloquear o registro ou o arquivo da tabela atual em uma área de trabalho especificada por workarea.
**_DBRead( ) API Library Routine**
Move o ponteiro do registro atual para o registro especificado na área de trabalho especificada.
**_DBRecCount( ) API Library Routine**
Retorna o número total de registros na tabela aberta na área de trabalho especificada.
**_DBRecNo( ) API Library Routine**
Retorna o número do registro atual na tabela na área de trabalho especificada.
**_DBReplace( ) API Library Routine**
Coloca um novo valor em um campo.
**_DBRewind( ) API Library Routine**
Executa um GOTO TOP na área de trabalho especificada e retorna o número do registro resultante.
**_DBSeek( ) API Library Routine**
Pesquisa uma tabela indexada na área de trabalho atual pelo primeiro registro cuja chave de índice corresponda ao valor val.
**_DBSkip( ) API Library Routine**
Executa um SKIP na área de trabalho especificada pela distância especificada.
**_DBStatus( ) API Library Routine**
Retorna sinalizadores de status para a área de trabalho especificada.
**_DBUnlock( ) API Library Routine**
Libera todos os bloqueios obtidos pelo usuário em registros ou no arquivo na área de trabalho especificada por workarea.
**_DBUnwind( ) API Library Routine**
Executa um GOTO BOTTOM na área de trabalho especificada e retorna o número do registro resultante.
**_DBWrite( ) API Library Routine**
Grava no disco o registro atual na área de trabalho especificada e atualiza quaisquer índices afetados.
