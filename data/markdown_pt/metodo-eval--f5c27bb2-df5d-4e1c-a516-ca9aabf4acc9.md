# Método Eval

Avalia uma expressão e retorna o resultado para uma instância do servidor de automação do aplicativo Visual FoxPro.

```foxpro
ApplicationObject.Eval(cExpression)
```

# Valor de retorno

Character, Numeric, Currency, Date ou Logical

# Valor de retorno
 **cExpression**
Especifica a expressão a ser avaliada. cExpression pode ser uma cadeia de caracteres literal ou uma expressão, variável, elemento de matriz ou campo do Visual FoxPro válido de qualquer tipo de dados, entre aspas.

# Observações

Aplica-se a: objeto Application | variável de sistema _VFP

cExpression deve ser uma expressão de caracteres legal do Visual FoxPro.
