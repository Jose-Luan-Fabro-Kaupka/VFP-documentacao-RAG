# Classe básica de botão da caixa de diálogo Sort

Quando colocada em um projeto ou formulário, esta classe fornece um botão que exibe uma caixa de diálogo que permite classificar dados em ordem crescente ou decrescente em um campo específico. Para obter detalhes, abra _dialogbutton na biblioteca de classes _table2.vcx no Class Browser.

| Categoria | Data Query |
| --- | --- |
| Catálogo padrão | Visual FoxPro Catalog\Foundation Classes\Buttons |
| Classe | _sortbutton |
| Classe base | CommandButton |
| Biblioteca de classes | _table2.vcx |
| Classe pai | _dialogbutton |
| Amostra | ...\Samples\Solution\Ffc\datasort.scx |

# Observações

Para usar, solte a classe em um projeto ou formulário em um ambiente de dados ou, no menu de atalho Item da Component Gallery, selecione Add to Project ou Add to Form. Quando você adiciona a classe a um formulário, o Visual FoxPro coloca o botão no formulário. Quando você solta a classe em um projeto, você pode escolher entre adicionar a classe ou criar uma subclasse.
