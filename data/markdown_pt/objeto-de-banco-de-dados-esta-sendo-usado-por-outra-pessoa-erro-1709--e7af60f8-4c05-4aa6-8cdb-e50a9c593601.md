# Objeto de banco de dados está sendo usado por outra pessoa. (Erro 1709)

Outro usuário está acessando este objeto de banco de dados.
 - O Visual FoxPro está acessando registros temporariamente em resposta às ações de outro usuário. Aguarde alguns minutos e tente novamente.
- Outro usuário está modificando uma tabela ou conexão. Entre em contato com o usuário. Se você estiver modificando uma tabela ou uma conexão, está impedindo que outros tenham acesso enquanto estiver no designer. Para obter mais informações, consulte MODIFY STRUCTURE, MODIFY CONNECTION e assim por diante.
- Outro usuário está modificando uma view. Você ainda pode usar a view. Se quiser modificá-la, entre em contato com o usuário. Para obter mais informações, consulte MODIFY VIEW .
