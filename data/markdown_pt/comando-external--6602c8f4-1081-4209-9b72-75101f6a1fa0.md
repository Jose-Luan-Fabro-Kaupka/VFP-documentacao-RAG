# Comando EXTERNAL

Alerta a janela Project Manager sobre uma referência indefinida.

```foxpro
EXTERNAL FILE FileList | ARRAY ArrayList
   | CLASS | FORM | LABEL | LIBRARY | MENU
   | PROCEDURE | QUERY | REPORT | SCREEN | TABLE
```

#### Parâmetros
 **FILE FileList**
Especifica que o arquivo que você inclui em uma referência de arquivo indireta ou substituição de macro é um arquivo autônomo, como um arquivo de texto, arquivo bitmap .BMP e assim por diante. FileList pode conter uma lista de nomes de arquivo separados por vírgulas.
**ARRAY ArrayList**
Quando um array é criado em um programa e depois usado em um programa de nível inferior, inclua ARRAY com o nome do array no programa de nível inferior. ArrayList pode conter uma lista de nomes de array separados por vírgulas. No exemplo a seguir, o primeiro programa cria um array chamado gaInvoice . O array é inicializado e um programa de nível inferior chamado dispinvo é chamado. dispinvo exibe o conteúdo do array criado no programa de nível superior. O comando EXTERNAL ARRAY GAINVOICE é incluído para alertar o Project Manager. DIMENSION gaInvoice(4) STORE 'Paid' TO gaInvoice DO dispinvo *** Program dispinvo *** PROCEDURE dispinvo EXTERNAL ARRAY gaInvoice ? gaInvoice(1) ? gaInvoice(2) ? gaInvoice(3) ? gaInvoice(4) RETURN *** End of dispinvo program *** Quando um array é passado para uma função ou procedimento definido pelo usuário, o array correspondente na função ou procedimento definido pelo usuário deve ser identificado para o Project Manager. Inclua a opção ARRAY com o nome do array incluído na instrução PARAMETER. DIMENSION gaArrayOne(2) && Create an array EXTERNAL ARRAY gaArrayTwo && Name of the array used in the UDF SET TALK OFF STORE 10 TO gaArrayOne(1) STORE 2 TO gaArrayOne(2) = ADDTWO(@gaArrayOne) && Pass the array by reference to a UDF FUNCTION ADDTWO PARAMETER gaArrayTwo CLEAR gaArrayTwo(1) = gaArrayTwo(1) + 2 gaArrayTwo(2) = gaArrayTwo(2) + 2 ? gaArrayTwo(1) ? gaArrayTwo(2)
**CLASS**
Especifica que o arquivo que você inclui em uma referência de arquivo indireta ou substituição de macro é uma biblioteca de classes visual. EXTERNAL CLASS myvclass && CLASS myvclass must exist STORE 'myvclass' TO gcClassFile MODIFY CLASS (gcClassFile)
**FORM**
Se um arquivo de definição de Form for incluído em uma referência de arquivo indireta ou substituição de macro, inclua FORM e o nome do arquivo Form. FORM é idêntico a SCREEN. EXTERNAL FORM dataentr && FORM dataentr must exist STORE 'dataentr' TO gcFormFile DO FORM (gcFormFile)
**LABEL**
Especifica que o arquivo que você inclui em uma referência de arquivo indireta ou substituição de macro é um arquivo de definição de etiqueta. EXTERNAL LABEL Maillabl && LABEL FORM Maillabl must exist STORE 'Maillabl' TO gcLabelFile LABEL FORM (gcLabelFile) PREVIEW
**LIBRARY**
Inclua LIBRARY quando um arquivo de biblioteca for referenciado por referência de arquivo indireta ou substituição de macro em SET LIBRARY. EXTERNAL LIBRARY regress && LIBRARY regress must exist STORE 'regress' TO gcStatFunc SET LIBRARY TO (gcStatFunc)
**MENU**
Se um arquivo de definição de menu for incluído em uma referência de arquivo indireta ou substituição de macro, inclua MENU e o nome do arquivo de menu. EXTERNAL MENU pickfile && MENU pickfile must exist STORE 'pickfile' TO gcSysMenPad MODIFY MENU (gcSysMenPad)
**PROCEDURE**
Identifica um procedimento externo ou função definida pelo usuário. EXTERNAL PROCEDURE delblank && PROCEDURE delblank must exist STORE 'delblank' TO gcTrimBlanks DO (gcTrimBlanks) WITH 'A B C D E'
**QUERY**
Especifica que o arquivo que você inclui em uma referência de arquivo indireta ou substituição de macro é um arquivo de consulta. EXTERNAL QUERY sales && QUERY sales must exist STORE 'sales.qpr' TO gcSalesFile DO (gcSalesFile)
**REPORT**
Especifica que o arquivo que você inclui em uma referência de arquivo indireta ou substituição de macro é um arquivo de definição de relatório. EXTERNAL REPORT overdue && REPORT overdue must exist STORE 'overdue' TO gcReportFile REPORT FORM (gcReportFile) PREVIEW
**SCREEN**
Se um arquivo de definição de formulário for incluído em uma referência de arquivo indireta ou substituição de macro, inclua SCREEN e o nome do arquivo de tela. SCREEN é idêntico a FORM. EXTERNAL SCREEN dataentr && SCREEN dataentr must exist STORE 'dataentr' TO gcScreenFile MODIFY SCREEN (gcScreenFile)
**TABLE**
Especifica que o arquivo que você inclui em uma referência de arquivo indireta ou substituição de macro é uma tabela do Visual FoxPro. EXTERNAL TABLE customer && Table customer must exist STORE 'customer' TO gcMyTable USE (gcMyTable)

# Observações

Use EXTERNAL para incluir arquivos e resolver referências indefinidas em um projeto criado pelo Project Manager. EXTERNAL é usado somente pelo Project Manager e é ignorado durante a execução do programa.

Para obter mais informações sobre como criar projetos com o Project Manager, consulte Compiling an Application.

Os arquivos cujos nomes você especifica com EXTERNAL são incluídos em um projeto pelo Project Manager. Você deve incluir CLASS, FILE, FORM, LABEL, LIBRARY, MENU, PROCEDURE, QUERY, REPORT, SCREEN ou TABLE antes do nome do arquivo ou de um conjunto de nomes de arquivo separados por vírgulas para informar ao Project Manager o tipo de arquivos a incluir no projeto.

O Project Manager também deve ser alertado sobre nomes de arquivo contidos em uma expressão de nome ou substituição de macro. Isso garante que todos os arquivos necessários sejam incluídos em um projeto quando o projeto é compilado. Ele também deve ser alertado sobre arrays que são criados em outro procedimento ou função definida pelo usuário.

Para obter mais informações sobre expressões de nome e substituição de macro, consulte & Command. Sempre que possível, use uma expressão de nome em vez de substituição de macro para melhorar o desempenho.
