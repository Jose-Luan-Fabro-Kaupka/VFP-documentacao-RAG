# Comando QUIT

Encerra a sessão atual do Visual FoxPro e devolve o controle ao sistema operacional.

```foxpro
QUIT
```

# Observações

Sempre use QUIT para encerrar uma sessão do Visual FoxPro. Se você desligar o computador sem emitir QUIT, arquivos abertos podem ser danificados e dados perdidos, e arquivos de trabalho temporários que normalmente seriam excluídos podem permanecer no disco.
