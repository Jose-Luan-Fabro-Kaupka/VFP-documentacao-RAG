# Função LEN( )

Determina o número de caracteres em uma expressão de caracteres, indicando o comprimento da expressão.

```foxpro
LEN(cExpression)
```

#### Parâmetros
 **cExpression**
Especifica a expressão de caracteres para a qual LEN( ) retorna o número de caracteres.

# Valor de retorno

Numérico. LEN( ) retorna o número de caracteres em uma expressão de caracteres.

# Exemplo

O exemplo a seguir limpa a janela principal do Visual FoxPro usando o comando CLEAR e abre a tabela Customer no banco de dados de exemplo Testdata localizado no diretório Visual FoxPro ..\Samples\Data usando os comandos OPEN DATABASE e USE. Combinada com os comandos ? e ??, LEN( ) exibe o número de caracteres nos campos Cust_ID e Contact.

```foxpro
CLEAR
OPEN DATABASE (HOME(2) + 'Data\testdata')
USE Customer
? 'Width of contact field: '
?? LEN(contact)
? 'Width of cust_id field: '
?? LEN(cust_id)
```
