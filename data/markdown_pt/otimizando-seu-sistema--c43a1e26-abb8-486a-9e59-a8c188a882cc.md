# Otimizando seu sistema

O Visual FoxPro foi projetado para ser um sistema rápido de desenvolvimento de banco de dados relacional. No entanto, os aplicativos que você cria com o Visual FoxPro podem ter requisitos e propósitos variados. Portanto, você pode querer otimizar o sistema operacional, o Visual FoxPro ou seu aplicativo para obter o máximo desempenho.

# Nesta seção
 **Optimizing the Operating Environment**
Descreve como otimizar o hardware do computador e o ambiente operacional para executar o Visual FoxPro.
**Optimizing Visual FoxPro Startup Speed**
Descreve como otimizar a velocidade de inicialização e operação no Visual FoxPro.
**Optimizing Visual FoxPro in a Multiuser Environment**
Descreve como melhorar o desempenho ao executar o Visual FoxPro em um ambiente multiusuário.
