# Extensões de arquivo e tipos de arquivo

Esta tabela lista as extensões e seus tipos de arquivo associados usados com o Visual FoxPro.

| Extensão | Tipo de arquivo |
| --- | --- |
| .act | Diagrama de ação do Documenting Wizard |
| .app | Aplicativo gerado |
| .cdx | Índice composto |
| .chm | Compiled HTML Help |
| .cur | Cursor |
| .dbc | Banco de dados |
| .dbf | Tabela |
| .dbg | Configuração do depurador |
| .dct | Memo de banco de dados |
| .dcx | Índice de banco de dados |
| .dll | Biblioteca de vínculo dinâmico do Windows |
| .err | Erro de compilação |
| .exe | Programa executável |
| .fky | Macro |
| .fll | Biblioteca de vínculo dinâmico do Visual FoxPro |
| .fmt | Arquivo de formato |
| .fpt | Memo de tabela |
| .frt | Memo de relatório |
| .frx | Relatório |
| .fxp | Programa compilado |
| .h | Arquivo de cabeçalho (para inclusão em um programa Visual FoxPro ou C/C++) |
| .hlp | WinHelp |
| .htm | HTML |
| .ico | Arquivo de ícone |
| .idx | Índice simples |
| .lbt | Memo de etiqueta |
| .lbx | Etiqueta |
| .log | Log de cobertura |
| .lst | Lista do Documenting Wizard |
| .mem | Salvamento de variáveis |
| .mnt | Memo de menu |
| .mnx | Menu |
| .mpr | Programa de menu gerado |
| .mpx | Programa de menu compilado |
| .ocx | Controle ActiveX |
| .pjt | Memo de projeto |
| .pjx | Projeto |
| .prg | Programa |
| .qpr | Programa de consulta gerado |
| .qpx | Programa de consulta compilado |
| .sct | Memo de formulário |
| .scx | Formulário |
| .spr | Programa de tela gerado (apenas versões anteriores do FoxPro) |
| .spx | Programa de tela compilado (apenas versões anteriores do FoxPro) |
| .tbk | Backup de memo |
| .txt | Texto |
| .vct | Memo de biblioteca de classes visual |
| .vcx | Biblioteca de classes visual |
| .vue | View do FoxPro 2. x |
| .win | Arquivo de janela |
| .xml | XML |
