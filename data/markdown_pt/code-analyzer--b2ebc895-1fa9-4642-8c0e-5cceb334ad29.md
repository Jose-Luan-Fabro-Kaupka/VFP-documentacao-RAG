# Code Analyzer

Localizado na pasta Visual FoxPro Tools\Analyzer, Analyzer.app fornece uma maneira de rastrear dinamicamente a estrutura e os símbolos em arquivos de aplicativo do Visual FoxPro. O Code Analyzer fornece controles visuais, um menu e opções de teclado para navegar pelo código de arquivos de aplicativo usando a saída do Documenting Wizard.

```foxpro
DO HOME() + 'tools\analyzer\analyzer' WITH 'DocWizTargetDirectory'
```

# Parâmetros
 **DocWizTargetDirectory**
Especifica o nome do diretório de destino do Documenting Wizard.

# Observações

Na guia Symbols, o Code Analyzer fornece acesso a todos os símbolos do usuário no documento de código aberto. Na guia Hierarchies, o Code Analyzer fornece a exibição da hierarquia da árvore de chamadas ou da hierarquia de classes do seu programa.
