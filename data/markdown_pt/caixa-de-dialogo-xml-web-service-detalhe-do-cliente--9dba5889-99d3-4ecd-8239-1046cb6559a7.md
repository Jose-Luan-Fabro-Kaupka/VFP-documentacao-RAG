# Caixa de diálogo XML Web Service - Detalhe do cliente

Permite especificar o controle, ou cliente, ao qual você deseja associar os resultados da operação do serviço Web XML. Ao chamar uma operação de serviço Web XML, os resultados podem ser associados a um controle específico no formulário. Você pode então atribuir o valor de retorno, ou o parâmetro passado por referência, a uma propriedade do controle. Normalmente, você atribui este valor de retorno à propriedade Value ou Caption para que o usuário possa ver os resultados.

Esta caixa de diálogo aparece quando você clica em Add ou Edit no grupo Clients na guia Operations do XML Web Service Builder. Para obter mais informações, consulte Guia Operations, XML Web Service Builder.
 **Selecionar controle**
Exibe e especifica controles ou objetos disponíveis no formulário atual aos quais você deseja associar os resultados da operação do serviço Web XML. Se seu serviço Web XML retorna um tipo de dados simples, você pode querer selecionar uma caixa de texto ou etiqueta. Você pode associar uma operação que retorna um ADO.NET DataSet, que é um tipo complexo, a uma grade. Para objetos DataEnvironment, você pode selecionar um objeto CursorAdapter e associar os resultados da operação ao seu método CursorFill, o que é típico para operações de serviço Web XML que retornam ADO.NET DataSets.
**Propriedade do controle usada para atribuir os resultados do serviço Web**
Exibe e especifica a propriedade do controle selecionado à qual você deseja associar os resultados da operação. Quando a operação é chamada, os resultados são atribuídos à propriedade. Para um controle TextBox, você geralmente escolhe a propriedade Value; no entanto, se a operação retorna um ADO.NET DataSet, você pode querer usar a propriedade ControlSource. Para um controle Label, a propriedade Caption é selecionada por padrão. Para um controle Grid, e se a operação retorna um ADO.NET DataSet, você pode querer usar a propriedade RecordSource.
**Associando controle ao valor de retorno ou parâmetro do serviço Web**
Especifica a fonte do parâmetro do serviço Web XML à qual a propriedade do controle está associada. A configuração ReturnValue é selecionada como padrão. No entanto, você também pode especificar um parâmetro de operação como fonte. Isso pode ser útil para operações que têm parâmetros passados por referência. Também é útil às vezes exibir o valor de entrada original, por exemplo, usando a propriedade Caption do Label.
**Descrição do cliente**
Especifica um nome que você deseja usar para o cliente. (Opcional)
**Nome da propriedade de associação**
Especifica o nome de uma propriedade personalizada que você deseja usar como fonte de evento para acionar a chamada da operação do serviço Web XML e a associação subsequente do controle. Esta opção é definida como BindMe por padrão. No entanto, todas as propriedades e métodos personalizados do controle estão incluídos na lista para você selecionar outro, se desejado. Se um objeto CursorAdapter for selecionado, o método CursorFill é selecionado por padrão para que o evento cause a criação de um cursor após chamar o serviço Web XML. Isso é útil para operações que retornam um ADO.NET DataSet porque o serviço Web XML permite que o DataSet seja importado no objeto CursorAdapter, através de um objeto XMLAdapter, que é usado pelo método CursorFill do CursorAdapter. As operações de serviço Web XML são chamadas usando os recursos de associação de eventos do Visual FoxPro. Em tempo de execução, uma propriedade especificada pela opção Name of binding property é adicionada ao controle. A propriedade adicionada serve como fonte de evento e está associada ao método InvokeClient do serviço Web XML. Quando o valor da propriedade de associação é definido como True (.T.), um evento ocorre e chama o método InvokeClient, que por sua vez chama a operação do serviço Web XML. Após a operação ser chamada, o valor de retorno é definido na propriedade do controle especificada. Você também pode especificar um método personalizado em vez de uma propriedade personalizada. Chamar este método personalizado aciona um evento que chama o delegado InvokeClient.
**Invocar na inicialização**
Especifica que o serviço Web XML é chamado e o controle é associado quando o formulário ou classe é instanciado pela primeira vez.
**Sempre chamar serviço Web**
Especifica que cada controle faz sua própria chamada à operação do serviço Web XML à qual está associado. O controle de serviço Web XML (wshandler) tem a capacidade de detectar quando múltiplas chamadas de cliente ocorrem para a mesma operação. Para desempenho, múltiplos clientes reutilizam os resultados de uma operação quando esses clientes são chamados simultaneamente, como quando o formulário ou classe é instanciado pela primeira vez. Por exemplo, suponha que você tenha um controle TextBox que associa os resultados de uma operação à sua propriedade Value e um controle Label que associa o primeiro parâmetro, um valor de entrada, da mesma operação à sua propriedade Caption. Quando o formulário ou classe é instanciado, e ambos os clientes são chamados, geralmente ocorre somente uma única chamada à operação do serviço Web XML. No entanto, ao selecionar Always call Web service, você pode especificar que todos os clientes façam suas próprias chamadas à mesma operação. Isso também ocorre se um cliente chamar manualmente a operação quando o formulário ou classe é instanciado.
**Tipos complexos**
Exibe uma caixa de diálogo que permite definir opções adicionais ao associar a operações que retornam tipos complexos, como um ADO.NET DataSet ou XMLDOMNodeList. Para obter mais informações, consulte Caixa de diálogo XML Web Service - Tipos complexos .
