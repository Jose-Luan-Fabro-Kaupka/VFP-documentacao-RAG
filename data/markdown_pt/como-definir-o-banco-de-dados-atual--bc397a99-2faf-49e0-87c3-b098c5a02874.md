# Como: definir o banco de dados atual

Você pode definir um banco de dados diferente como o banco de dados atual quando mais de um banco de dados está aberto. No entanto, você pode definir apenas um banco de dados aberto como o banco de dados atual.

### Para definir o banco de dados atual
- Execute uma das seguintes opções: Na lista de bancos de dados na barra de ferramentas padrão, selecione um banco de dados. -OU- Use o comando SET DATABASE.

O banco de dados que você selecionar é definido como o banco de dados atual.

Para obter mais informações, consulte SET DATABASE Command.
