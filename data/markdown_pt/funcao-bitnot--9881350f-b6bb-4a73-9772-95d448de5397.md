# Função BITNOT( )

Executa uma operação NOT bit a bit em um valor do tipo Numeric, Varbinary ou Blob e retorna o complemento bit a bit do valor especificado. Há uma versão numérica e uma versão binária da sintaxe.

> **Observação:** Se a expressão especificada não for um inteiro, ela é convertida em inteiro antes de executar a operação.

```foxpro
BITNOT(nNumericExpression)
```

```foxpro
BITNOT(BinaryExpression [, nStartBit [, nBitCount]])
```

#### Parâmetros
 **nNumericExpression**
Especifica um valor Numeric para executar a operação NOT bit a bit.
**BinaryExpression**
Especifica um valor Varbinary ou Blob para executar a operação NOT bit a bit.
**[ nStartBit [, nBitCount ]]**
Especifica nStartBit como o número base zero do primeiro bit para executar a operação e nBitCount como o número de bits para executar a operação. Se você não especificar nStartBit e nBitCount, a operação se aplica a todos os bits na expressão. Se você especificar apenas nStartBit, a operação se aplica apenas a nStartBit.

# Valor de retorno

Numeric, Varbinary ou Blob. BITNOT( ) retorna o complemento bit a bit da expressão especificada. Em outras palavras, o valor de retorno representa a expressão especificada com cada bit 0 alterado para 1 e cada bit 1 alterado para 0.

# Exemplo

```foxpro
x = 5  && 0101 binary
? BITNOT(x) && Returns -6
```
