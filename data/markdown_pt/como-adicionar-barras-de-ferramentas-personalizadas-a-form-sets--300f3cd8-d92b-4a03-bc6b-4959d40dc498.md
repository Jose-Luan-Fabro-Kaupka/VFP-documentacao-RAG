# Como: adicionar barras de ferramentas personalizadas a form sets

Depois de definir uma classe de barra de ferramentas, você pode criar uma barra de ferramentas a partir dela. Você pode coordenar barras de ferramentas e formulários usando o Form Designer ou escrevendo código.

# Coordenando barras de ferramentas e formulários no Form Designer

Você pode adicionar uma barra de ferramentas a um form set para que a barra de ferramentas abra junto com os formulários no form set. Você não pode adicionar a barra de ferramentas diretamente ao formulário.

### Para adicionar uma barra de ferramentas a um form set usando o Form Designer
- Registre e selecione a biblioteca que contém a classe de barra de ferramentas.
- Abra o form set com o qual deseja usar a classe de barra de ferramentas, clique no botão View Classes na barra de ferramentas Form Controls e selecione a classe de barra de ferramentas na lista exibida.
- Na barra de ferramentas Form Controls, escolha a classe de barra de ferramentas.
- Clique no Form Designer para adicionar a barra de ferramentas e arraste a barra de ferramentas para o local apropriado. O Visual FoxPro adiciona a barra de ferramentas ao form set. Se um form set não estiver aberto, o Visual FoxPro solicitará um.
- Defina as ações da barra de ferramentas e de seus botões. Dica Para determinar a classe de um objeto, observe seu ToolTip na barra de ferramentas Form Controls.
