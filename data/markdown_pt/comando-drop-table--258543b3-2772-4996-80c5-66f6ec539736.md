# Comando DROP TABLE

Remove uma tabela do banco de dados atual e a exclui do disco.

```foxpro
DROP TABLE TableName | FileName | ? [RECYCLE]
```

# Valor de retorno
 **TableName**
Especifica a tabela a remover do banco de dados atual e excluir do disco.
**FileName**
Especifica uma tabela livre a excluir do disco.
**?**
Exibe a caixa de diálogo Remove, na qual você pode escolher uma tabela para remover do banco de dados atual e excluir do disco.
**RECYCLE**
Especifica que a tabela não será excluída imediatamente do disco, mas colocada na Lixeira do Microsoft Windows.

# Observações

Quando DROP TABLE é emitido, todos os índices primários, valores padrão e regras de validação associados à tabela também são removidos. DROP TABLE também afeta outras tabelas do banco de dados atual se elas tiverem regras ou relações associadas à tabela removida. Essas regras e relações deixam de ser válidas quando a tabela é removida do banco de dados.

Uma tabela excluída com este comando não pode ser recuperada. Mesmo que SET SAFETY esteja definido como ON, nenhum aviso é exibido antes da exclusão.
