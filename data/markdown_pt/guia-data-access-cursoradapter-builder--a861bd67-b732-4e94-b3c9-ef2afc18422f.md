# Guia Data Access, CursorAdapter Builder

Define o comando Select e os valores de schema do CursorAdapter object e outras propriedades de acesso a dados.
 **Select command**
Digite ou construa um comando Select apropriado. Quando o tipo de fonte de dados é XML, digite o comando Select. Neste caso, o comando Select deve ser uma expressão que se resolve em uma cadeia de caracteres XML válida e bem formada. Quando o tipo de fonte de dados é Native, ODBC ou ADO, o botão Build está disponível. Clicar no botão Build abre a caixa de diálogo Select Command Builder. Select Command Builder Especifica tabelas e campos a incluir no comando Select. Table Especifica uma tabela que você deseja usar. As tabelas na lista correspondem às tabelas na fonte de dados selecionada. Add table Disponível quando o tipo de fonte de dados é Native e pode ser usado para adicionar tabelas que não estão no banco de dados atual à lista de tabelas. Available fields list Especifica campos a incluir no comando Select depois de selecionar uma tabela ou view, se apropriado. Esta lista aparece no lado esquerdo da caixa de diálogo Select Command Builder. Add single/Add all/Remove single/Remove all Adiciona um único campo ou todos os campos à lista de campos selecionados ou remove um único ou todos os campos da lista de campos selecionados. Selected fields list Exibe os campos selecionados, que podem ser reorganizados clicando e arrastando os botões mover que aparecem ao longo do lado esquerdo da lista de campos selecionados. Esta lista aparece no lado direito da caixa de diálogo Select Command Builder.
**Schema**
Digite o schema para o CursorAdapter object, se necessário. O schema é gerado automaticamente quando o comando Select é construído usando o Select Command Builder. Se você digitou o comando Select, pode clicar no botão Build, e o builder tenta construir o schema correspondendo os nomes de tabela e coluna com as tabelas disponíveis. Quando o tipo de fonte de dados é XML, você não pode construir um comando Select, e nenhum schema é gerado automaticamente. Quando você clica no botão Build, a caixa de diálogo Open aparece, e você pode especificar um arquivo XML a partir do qual construir o schema. Este arquivo XML deve ser um XML Schema Definition (XSD) schema válido, um XML válido com schema XSD inline ou um XML válido com referência a um schema XSD externo válido.
**Use CursorSchema when filling cursor**
Especifica a configuração padrão a usar para o parâmetro lUseCursorSchema no CursorFill Method. Para obter mais informações, consulte UseCursorSchema Property.
**Data fetching**
Especifica propriedades relacionadas a como recuperar dados remotos ao usar o tipo de fonte de dados Open Database Connectivity (ODBC). As configurações a seguir estão disponíveis: Number of records to fetch at a time Recuperar todos ou um número de registros de cada vez. Para obter mais informações, consulte FetchSize Property. Maximum number of records to fetch Recuperar todos ou um número máximo de registros. Para obter mais informações, consulte MaxRecords Property. Use memo when character field length >= Usar tamanho de campo memo quando o comprimento do campo de caracteres exceder o valor especificado. Para obter mais informações, consulte UseMemoSize Property. Fetch remote data as needed Recuperar dados somente quando necessário. Para obter mais informações, consulte FetchAsNeeded Property. Precompile SQL on backend server Especifica se deve preparar instruções SQL para chamadas subsequentes da função REQUERY( ). Para obter mais informações, consulte Prepared Property e a função REQUERY( ). Map Varchar Habilita o mapeamento padrão de tipos de dados de tipos de dados ODBC e ADO para o tipo de dados Varchar do Visual FoxPro. Para obter mais informações, consulte MapVarchar Property. Initially open with no data Especifica a configuração padrão a usar para o parâmetro lNoData no CursorFill Method. Para obter mais informações, consulte NoData Property. Fetch memo fields Especifica se deve recuperar campos memo. Para obter mais informações, consulte FetchMemo Property. Memo… Abre a caixa de diálogo Memo Fetching. Allow simultaneous fetch Especifica se deve permitir recuperação simultânea de dados. Para obter mais informações, consulte AllowSimultaneousFetch Property. Map Binary Habilita o mapeamento padrão de tipos de dados de tipos de dados ODBC e ADO para os tipos de dados Varbinary e Blob do Visual FoxPro. Para obter mais informações, consulte MapBinary Property. A caixa de diálogo Memo Fetching Properties permite especificar como o DelayedMemoFetch Method busca campos Memo. As configurações a seguir estão disponíveis: Memo fetch command Especifica os comandos a usar para a busca de campos Memo realizada pelo método DelayedMemoFetch. Para obter mais informações, consulte FetchMemoCmdList Property. Memo fetch data source type Especifica o tipo de fonte de dados usado para o método DelayedMemoFetch. Para obter mais informações, consulte FetchMemoDataSourceType Property. Connection Settings Estes três botões de opção permitem especificar a fonte de dados para o método DelayedMemoFetch. Para obter mais informações, consulte FetchMemoDataSource Property.
**Buffer mode override**
Especifica um modo de buffer. Optimistic row buffering Permite edições em um único registro e bloqueia o registro somente quando gravado em disco. Esta é a configuração padrão. Optimistic table buffering Permite edições em todos os registros e não os bloqueia até serem gravados em disco.
**Break on error**
Especifica se deve permitir que erros interrompam a execução do programa no local onde ocorreram ou enviá-los ao CursorAdapter object. Para obter mais informações, consulte BreakOnError Property.
**XML flags**
Especifica as configurações de flag a passar para a função XMLUPDATEGRAM( ), que é chamada quando o tipo de fonte de dados é XML e ocorre atualização. Para obter mais informações sobre atualização automática, consulte Data Access Management Using CursorAdapters e a função XMLUPDATEGRAM( ).
