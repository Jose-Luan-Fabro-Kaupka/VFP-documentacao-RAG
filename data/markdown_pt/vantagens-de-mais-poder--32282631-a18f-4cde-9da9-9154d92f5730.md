# Vantagens de mais poder

O Visual FoxPro é muito mais poderoso que seus predecessores. A programação orientada a objetos acelera o desenvolvimento de aplicativos por meio de recursos como subclassing. O modelo de eventos do Visual FoxPro elimina a necessidade de usar um Foundation READ ou de escrever manipuladores de eventos. Otimizar as configurações do sistema e aproveitar a tecnologia Rushmore Query Optimization melhora o desempenho do Visual FoxPro.

# Aproveitando o poder da programação orientada a objetos

Usando o modelo de objetos do Visual FoxPro, você pode empregar todos os recursos da programação orientada a objetos, incluindo herança, encapsulamento, polimorfismo e subclassing. Para detalhes sobre programação orientada a objetos com Visual FoxPro, consulte Programação orientada a objetos.

Você pode acelerar o desenvolvimento de aplicativos usando classes. Por exemplo, você pode criar um formulário, barra de ferramentas ou page frame básico usando a classe base de formulário, barra de ferramentas ou page frame fornecida com o Visual FoxPro.

Em seguida, você pode reutilizar seu código e formulários fazendo subclassing das classes que definiu. Por exemplo, você pode fazer subclassing da classe base Form para criar uma classe personalizada que automaticamente dá a todos os formulários em seu aplicativo a aparência e o comportamento que você deseja.

O modelo de classes do Visual FoxPro oferece controle extensivo sobre os objetos em seu aplicativo. Você tem tanto controle sobre a aparência e o comportamento dos objetos em formulários em tempo de execução quanto no Form Designer em tempo de design.

Com o Visual FoxPro, você pode criar classes visualmente com o Class Designer ou programaticamente com o comando DEFINE CLASS. Para obter mais informações, consulte Programação orientada a objetos.

# Tratando eventos com facilidade

Com o Visual FoxPro você pode criar aplicativos totalmente orientados a eventos. Você pode acessar todos os eventos padrão do Windows, como movimentos do mouse que permitem arrastar ou soltar objetos. Você pode controlar eventos visualmente pela janela Properties ou programaticamente pela linguagem Visual FoxPro. Para obter mais informações sobre o modelo de eventos, consulte Compreendendo o modelo de eventos.

# Testando e depurando imediatamente

Usando o ambiente de depuração, você pode testar e depurar seu código ao mesmo tempo em que projeta cada componente de seu aplicativo e escreve o código. A linguagem Visual FoxPro foi aprimorada para incluir suporte a recursos de depuração, propriedades de coleção, verificação do status de bloqueio de arquivos e do registro atual, Value tips e muito mais. Além disso, as ferramentas de depuração funcionam independentemente do aplicativo principal e não interferem na interface que você está tentando testar.

Teste enquanto projeta O ambiente de desenvolvimento aprimorado do Visual FoxPro oferece mais poder para testar o design de componentes e o código. Por exemplo, se você estiver projetando um formulário, pode clicar no botão Run para executar o código. Se quiser alterar algo, basta clicar no botão Design e fazer suas alterações.

Detecte erros de sintaxe cedo O editor agora oferece edição com código de cores: você pode especificar cores para sintaxe, texto normal, variáveis, comentários e muito mais na caixa de diálogo Edit Properties. Se você digitar incorretamente um comando ou palavra-chave, saberá imediatamente porque estará na cor errada.

# Depure com poder

Você pode depurar e monitorar os componentes de seu aplicativo com mais facilidade nesta versão do Visual FoxPro usando a janela Debugger.
 - Exibir propriedades de um objeto No depurador, você pode exibir os elementos dentro de uma coleção ou matriz usando a janela Watch para mostrar uma exibição hierárquica das propriedades de um objeto.
- Rastrear o processo de execução de seu código Na janela Trace, você pode ver cada linha de código conforme ela é executada e verificar os valores de todas as variáveis, propriedades e configurações de ambiente.
- Controlar a execução com breakpoints Usando breakpoints, você pode controlar quando a execução para usando um dos quatro tipos de breakpoints. Você pode parar em uma linha específica, quando um determinado valor mudar, se uma condição for avaliada como verdadeira ou se uma condição para uma determinada linha for verdadeira.
- Definir asserts e exibir mensagens de assert Você pode usar o comando ASSERT para especificar condições que verificam se o código está sendo executado corretamente. Quando ocorre um erro, a janela Debug Output registra a mensagem.
- Verificar o valor atual de uma variável Para verificar valores rapidamente, você pode posicionar o cursor sobre uma variável na janela Trace para exibir um Value Tip.
- Observar e alterar valores Nas janelas Watch e Locals, você pode alterar valores de propriedades ou variáveis enquanto executa o código.
- Exibir saída de solicitações de mensagem Na janela Debug Output, você pode exibir convenientemente solicitações de informações interativas ou codificadas em uma janela separada da janela ou tela ativa.
- Usar um arquivo de log de cobertura Na janela Debugger, você pode usar a opção de cobertura para registrar informações de execução sobre seu código, como quanto tempo a linha levou para ser executada, o número da linha e muito mais.
- Usar a pilha de chamadas Na janela Call Stack, você pode exibir o caminho de chamada do programa. Ler a Call Stack é uma das técnicas mais eficazes para depuração.

Para obter mais informações sobre testar e depurar seu aplicativo, consulte Testando e depurando aplicativos.

### Otimizando seu sistema

O Visual FoxPro oferece desempenho aprimorado em todas estas áreas do produto:
 - Engine
- Form/Object
- OLE
- Client/Server
- Wizards/Builders
- Language

Você também pode melhorar o desempenho aprimorando a velocidade de inicialização e otimizando comandos SET. Para obter mais informações sobre otimizar seu sistema, consulte Otimizando seu sistema.

### Otimizando aplicativos com a tecnologia Rushmore Query Optimization

Você pode melhorar dramaticamente o desempenho de consultas usando a tecnologia Rushmore. Rushmore Query Optimization é uma tecnologia para selecionar rapidamente conjuntos de registros de tabelas. Ela pode reduzir os tempos de resposta de consultas de minutos ou horas para segundos. Para obter mais informações sobre o uso da tecnologia Rushmore, consulte Otimizando aplicativos.
