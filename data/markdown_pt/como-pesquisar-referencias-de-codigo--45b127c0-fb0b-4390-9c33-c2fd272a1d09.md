# Como: pesquisar referências de código

Você pode pesquisar referências de código e texto específicos em seus projetos e pastas no Visual FoxPro.

### Para pesquisar uma referência de código
- Se você está pesquisando um projeto, abra o projeto ou projetos que deseja pesquisar.
- No menu Tools, selecione Code References . Se você não realizou uma pesquisa anterior no projeto, a caixa de diálogo Look Up Reference aparece. Caso contrário, a janela Code References aparece e exibe os resultados da pesquisa anterior.
- Na caixa Look for da caixa de diálogo Look Up Reference, digite o código ou texto que deseja pesquisar.
- Escolha uma das seguintes opções: Para pesquisar projetos, certifique-se de que a caixa Scope está definida como Entire project e o nome do projeto que deseja pesquisar. Para selecionar um projeto aberto diferente, clique na seta Scope para exibir uma lista de projetos abertos. Dica Para restringir sua pesquisa ao diretório home do projeto e subpastas, selecione a caixa de seleção Limit search to project home directory and subfolders. Para pesquisar uma pasta, certifique-se de que a caixa Scope está definida como Folder e que a caixa Look in está definida para a pasta que deseja pesquisar. Dica Para expandir sua pesquisa para as subpastas da pasta, selecione a caixa de seleção Search subfolders.
- Escolha qualquer uma das seguintes opções: Para especificar tipos de arquivo diferentes dos tipos padrão em sua pesquisa, clique na seta File Types para exibir uma lista de tipos de arquivo. Para especificar opções adicionais para sua pesquisa, selecione configurações no grupo Options ou clique no botão Options para abrir a caixa de diálogo Options.
- Clique em Search para iniciar a pesquisa.

Para obter mais informações, consulte Look Up Reference Dialog Box e Look Up Reference Dialog Box, Options Dialog Box.

Se a pesquisa for bem-sucedida, a janela Code References exibe a cadeia de caracteres de pesquisa como um nó no painel de pesquisa e quaisquer resultados de sua pesquisa no painel de resultados. Você pode visualizar todos os resultados selecionando o nó de referência de código no painel de pesquisa, ou pode filtrar seus resultados para cada arquivo selecionando um nome de arquivo no painel de pesquisa. Você pode abrir o arquivo e ir diretamente a uma referência de código clicando duas vezes em um resultado no painel de resultados. Para obter mais informações, consulte Code References Window.

Depois de localizar o código ou texto desejado, você pode substituí-lo. Para obter mais informações, consulte Como: substituir referências de código. Você também pode visualizar definições de código. Para obter mais informações, consulte Como: visualizar definições de código.
