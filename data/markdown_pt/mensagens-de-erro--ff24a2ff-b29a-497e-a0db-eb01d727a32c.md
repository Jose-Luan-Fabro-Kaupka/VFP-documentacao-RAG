# Mensagens de erro

Este tópico contém informações sobre algumas das mensagens de erro mais comuns no Visual FoxPro.

# Nesta seção
 **Mensagens de erro listadas alfabeticamente**
Contém uma lista de tópicos de mensagens de erro em ordem alfabética.
**Mensagens de erro listadas numericamente**
Contém uma lista numérica de mensagens de erro.

# Seções relacionadas
 **Referência (Visual FoxPro)**
Inclui tópicos sobre ferramentas de produtividade, bem como os controles, objetos, propriedades, métodos, eventos, instruções, funções e constantes disponíveis.
**Referência geral**
Fornece informações técnicas relacionadas ao Visual FoxPro, incluindo tipos de arquivo, estruturas de arquivo e outras informações de referência sobre elementos do Visual FoxPro.
**Referência de linguagem (Visual FoxPro)**
Fornece uma lista de tópicos de referência de linguagem em ordem alfabética.
**Referência da interface do usuário (Visual FoxPro)**
Explica as opções que aparecem em várias caixas de diálogo, janelas e outras interfaces do usuário. Esses tipos de tópicos geralmente aparecem quando você pressiona F1 em uma caixa de diálogo ou janela.
