# Função EXP( )

Retorna o valor de e x onde x é uma expressão numérica especificada.

```foxpro
EXP(nExpression)
```

#### Parâmetros
 **nExpression**
Especifica o expoente, x , na expressão exponencial e x.

# Valor de retorno

Numeric

# Observações

O valor de e, a base dos logaritmos naturais, é aproximadamente 2,71828. O número de casas decimais retornado por EXP( ) é especificado com SET DECIMALS.

# Exemplo

```foxpro
? EXP(0)  && Displays 1.00
? EXP(1)  && Displays 2.72
```
