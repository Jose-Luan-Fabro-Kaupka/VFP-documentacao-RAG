# Função ON( )

Retorna o comando atribuído a cada um destes comandos de tratamento de eventos: ON ERROR, ON ESCAPE, ON KEY LABEL ou ON PAGE.

```foxpro
ON(cONCommand [, KeyLabelName])
```

#### Parâmetros
 **cONCommand**
Especifica um dos comandos de tratamento de eventos. Aqui estão os comandos e as expressões de caractere correspondentes para usar com ON( ): Comando cONCommand ON ERROR ERROR ON ESCAPE ESCAPE ON KEY LABEL KEY ON PAGE PAGE Por exemplo, para retornar o comando atualmente atribuído a ON ERROR, use o seguinte: ? ON('ERROR')
**KeyLabelName**
Usado em ON KEY LABEL para especificar uma tecla ou combinação de teclas à qual o comando está atribuído. Especifique KEY em cONCommand e o nome da etiqueta de tecla da tecla ou combinação de teclas em KeyLabelName. Para uma lista completa de nomes de etiquetas de tecla, consulte ON KEY LABEL. Por exemplo, para retornar o comando atualmente atribuído à tecla de função F7 com ON KEY LABEL, use o seguinte: ? ON('KEY', 'F7')

# Valor de retorno

Character

# Observações

Quando ocorre um evento capturado por um dos comandos de tratamento de eventos, o comando atribuído pelo comando de tratamento de eventos é executado. ON( ) retorna o comando que você atribuiu a um comando de tratamento de eventos. ON( ) retorna uma cadeia vazia se nenhum comando estiver atualmente atribuído ao comando de tratamento de eventos que você especifica.

# Exemplo

O exemplo a seguir usa ON( ) para exibir as configurações de ON ERROR e ON KEY LABEL.

```foxpro
ON ERROR DO errorhand
ON KEY LABEL CTRL+F2 WAIT WINDOW 'You pressed ^F2'
ON KEY LABEL ALT+Z DISPLAY MEMORY
CLEAR
? ON('ERROR')  && Displays DO errorhand
? ON('KEY', 'CTRL+F2')  && Displays WAIT WINDOW 'You pressed ^F2'
? ON('KEY', 'ALT+Z')  && Displays DISPLAY MEMORY
ON ERROR
ON KEY LABEL CTRL+F2
ON KEY LABEL ALT+Z
```
