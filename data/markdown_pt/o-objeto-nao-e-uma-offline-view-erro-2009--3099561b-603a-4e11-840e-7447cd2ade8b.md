# O objeto não é uma offline view (Erro 2009)

Alguns comandos e cláusulas exigem uma offline view.
 - Você tentou usar as cláusulas ONLINE ou ADMIN. Você deve fornecer uma offline view com essas cláusulas. Para obter mais informações, consulte o comando USE.
- Você tentou excluir uma view. Use DROPOFFLINE( ) somente com offline views.
