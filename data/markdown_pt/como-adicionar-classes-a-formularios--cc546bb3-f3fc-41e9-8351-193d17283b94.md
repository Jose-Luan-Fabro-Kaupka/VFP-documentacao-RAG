# Como: adicionar classes a formulários

Você pode arrastar uma classe da janela Project Manager para o Form Designer ou para o Class Designer. Você também pode registrar suas classes para que possam ser exibidas diretamente na barra de ferramentas Form Controls no Class Designer ou Form Designer e adicionadas a contêineres da mesma forma que os controles padrão são adicionados.

### Para adicionar uma classe a um formulário
- Na janela Project Manager, selecione uma classe para adicionar a um formulário.
- Clique e arraste a classe da janela Project Manager para um Form Designer aberto.
