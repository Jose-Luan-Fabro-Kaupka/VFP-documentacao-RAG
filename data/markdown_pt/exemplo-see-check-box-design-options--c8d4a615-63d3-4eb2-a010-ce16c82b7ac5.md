# Exemplo See Check Box Design Options

Arquivo: ...\Samples\Solution\Controls\Checkbox\Checkbox.scx

Este exemplo ilustra uma variedade de propriedades que podem ser definidas para personalizar a exibição da caixa de seleção.

| Propriedade | Descrição |
| --- | --- |
| ControlSource | Uma variável ou campo de tabela que é numérico ou lógico. |
| Picture | Bitmap exibido se Style for Graphical. |
| Style | Graphical para imagens ou standard para uma caixa. |
| Value | .T., .F., 0, 1, 2 ou .NULL. |
