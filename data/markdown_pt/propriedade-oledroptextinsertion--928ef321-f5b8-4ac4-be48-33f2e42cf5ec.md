# Propriedade OLEDropTextInsertion

Especifica se você pode soltar texto no meio de uma palavra na porção de caixa de texto de um controle.

```foxpro
Object.OLEDropTextInsertion[= lExpression]
```

#### Parâmetros
 **lExpression**
As configurações para a propriedade OLEDropTextInsertion são: Setting Description 0 (Default) O texto pode ser solto dentro de uma palavra. 1 O texto só pode ser solto antes ou depois de uma palavra.

# Observações

Aplica-se a: ComboBox Control | EditBox Control | Spinner Control | TextBox Control (Visual FoxPro)

A propriedade OLEDropMode de um controle deve ser definida como 1 – Enabled para soltar texto na porção de caixa de texto do controle.
