# Função GETWORDNUM( )

Retorna uma palavra especificada de uma cadeia de caracteres.

```foxpro
GETWORDNUM(cString, nIndex[, cDelimiters])
```

#### Parâmetros
 **cString**
Especifica a cadeia de caracteres a ser avaliada.
**nIndex**
Especifica a posição de índice da palavra a ser retornada. Por exemplo, se nIndex for 3, GetWordNum( ) retornará a terceira palavra (se cString contiver três ou mais palavras).
**cDelimiters**
Opcional. Especifica um ou mais caracteres opcionais usados para separar palavras em cString. Os delimitadores padrão são espaço, tabulação, retorno de carro e avanço de linha. Observe que GetWordNum( ) usa cada caractere de cDelimiters como um delimitador individual, e não a cadeia inteira como um único delimitador.

# Valor de retorno

Caractere

# Observações

Retorna a palavra na posição especificada por nIndex na cadeia de caracteres de destino, cString. Se cString contiver menos de nIndex palavras, GetWordNum( ) retornará uma cadeia de caracteres vazia.
