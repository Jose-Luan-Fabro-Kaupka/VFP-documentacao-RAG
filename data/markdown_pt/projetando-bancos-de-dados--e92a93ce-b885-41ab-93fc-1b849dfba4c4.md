# Projetando bancos de dados

Antes de começar a criar e trabalhar com bancos de dados, certifique-se de entender as considerações de design envolvidas na criação de bancos de dados.

# Nesta seção
 **Database Design Process**
Fornece uma introdução sobre como criar um banco de dados bem projetado e lista as etapas importantes no processo de design.
**Analyzing Data Requirements**
Concentra-se na primeira etapa no design de um banco de dados do Microsoft Visual FoxPro, que envolve descobrir o motivo do banco de dados e como ele será usado.
**Organizing Requirements into Tables**
Descreve como selecionar as tabelas no seu banco de dados, que pode ser a etapa mais difícil no processo de design de banco de dados.
**Determining the Fields You Need**
Explica a importância de determinar o que você precisa saber sobre as pessoas, coisas ou eventos registrados na tabela.
**Identifying Relationships**
Contém informações e exemplos sobre como o sistema de gerenciamento de banco de dados relacional do Microsoft Visual FoxPro pode ser usado para vincular informações de maneiras significativas.
**Refining the Design**
Depois que as tabelas, campos e relacionamentos foram estabelecidos, detalha a etapa importante de revisar o design do seu banco de dados para localizar falhas restantes.
**Sample Database Diagrams**
Oferece diagramas de banco de dados como uma forma de estimular ideias para criar seu próprio banco de dados.

# Seções relacionadas
 **Working with Data**
Discute como criar aplicações eficazes com índices, tabelas e bancos de dados baseados nos seus requisitos de dados.
**Developing Databases**
Mostra como usar bancos de dados no Microsoft Visual FoxPro para estabelecer relacionamentos entre tabelas, impor integridade referencial e gerenciar dados locais e remotos.
**Working with Tables (Visual FoxPro)**
Descreve como garantir que suas tabelas tenham a estrutura que sua aplicação requer. As escolhas de tipo de dados e índice são essenciais para o sucesso da sua aplicação.
**Importing and Exporting Data**
Descreve como as informações são copiadas entre o Microsoft Visual FoxPro e outras aplicações importando para e exportando do Visual FoxPro.
