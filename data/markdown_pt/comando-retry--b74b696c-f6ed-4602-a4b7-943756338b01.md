# Comando RETRY

Executa o último comando da pilha de memória e retorna o controle ao programa chamador. RETRY é semelhante a RETURN, exceto que RETURN executa a próxima linha no programa chamador.

```foxpro
RETRY
```

# Observações

RETRY é útil em rotinas de tratamento de erros. É frequentemente usado para executar um comando até que uma função de bloqueio de registro ou arquivo consiga bloquear o registro ou arquivo. Você pode usar SET REPROCESS para controlar novas tentativas de uma função de bloqueio de registro ou arquivo. SET REPROCESS é preferível na maioria das situações de rede.
