# Como: definir a ordem de tabulação dos controles

A ordem de tabulação de um formulário determina a sequência na qual os controles são selecionados quando um usuário pressiona a tecla TAB para mover pelo formulário.

Você pode escolher dois métodos diferentes para definir a ordem de tabulação: de forma interativa, clicando nos controles na ordem em que deseja que sejam selecionados quando o formulário é usado; ou organizando uma lista de controles em uma caixa de diálogo.

### Para escolher um método de ordenação de tabulação
- No menu Tools, escolha Options.
- Na caixa de diálogo Options, escolha a guia Forms.
- Na opção Tab Ordering, selecione Interactive ou By List.

Este procedimento descreve como escolher um método de ordenação de tabulação para o botão Set Tab Order na Form Designer Toolbar. Você também pode escolher um método de ordenação de tabulação na opção Tab Order no menu View.

# Definindo a ordem de tabulação de forma interativa

No modo interativo, você define a ordem de tabulação clicando duas vezes no controle que deseja que seja o primeiro na ordem de tabulação e, em seguida, clicando uma vez nos demais controles na ordem em que deseja que sejam selecionados no formulário. O último controle selecionado é indicado com um número de ordem de tabulação destacado.

### Para alterar a ordem de tabulação de forma interativa
- No menu View, escolha Tab Order.
- Escolha Assign Interactively.
- Clique duas vezes na caixa de ordem de tabulação ao lado do controle que deseja que seja o primeiro controle na ordem de tabulação.
- Clique na caixa de ordem de tabulação para cada um dos outros controles.
- Clique em qualquer lugar do formulário para salvar suas alterações e sair do modo Tab Order, ou pressione ESC para sair do modo Tab Order sem salvar suas alterações.

# Definindo a ordem de tabulação por lista

No modo de lista, você define a ordem de tabulação reorganizando os nomes dos controles na caixa de diálogo Tab Order. Você pode definir a ordem por linha (descendo o formulário) ou por coluna (atravessando o formulário).

### Para definir a ordem de tabulação usando uma lista
- No menu View, escolha Tab Order.
- Escolha Assign by List.
- Escolha By Row ou By Column.
- Na caixa de diálogo Tab Order, use o ponteiro para reorganizar a lista.
- Escolha OK.
