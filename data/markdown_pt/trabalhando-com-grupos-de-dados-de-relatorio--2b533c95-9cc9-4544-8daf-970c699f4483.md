# Trabalhando com grupos de dados de relatório

Em um layout de relatório ou etiqueta, agrupar registros por determinados campos ou outros critérios pode tornar o relatório mais fácil de ler. Adicionar grupos de dados aos relatórios permite agrupar registros visualmente e exibir dados introdutórios e de resumo para cada grupo.
