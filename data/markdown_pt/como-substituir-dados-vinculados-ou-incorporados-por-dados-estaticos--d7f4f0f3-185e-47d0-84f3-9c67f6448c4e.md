# Como: substituir dados vinculados ou incorporados por dados estáticos

Você pode substituir dados vinculados ou incorporados por bitmaps independentes usando o aplicativo que criou os dados.

### Para substituir dados vinculados ou incorporados por um bitmap
- Inicie o aplicativo que criou os dados escolhendo o objeto que contém os dados.
- No aplicativo, copie a apresentação do objeto para a Área de transferência. Por exemplo, se o aplicativo tem um comando Copiar imagem, use-o para copiar a apresentação do objeto.
- No menu Editar no Visual FoxPro, escolha Colar especial .
- Na caixa de diálogo Colar especial, escolha Opção de colagem .
- Escolha a opção Imagem (Metafile).
