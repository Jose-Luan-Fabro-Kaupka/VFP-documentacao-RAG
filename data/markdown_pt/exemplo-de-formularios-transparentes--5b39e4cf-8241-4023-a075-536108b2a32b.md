# Exemplo de formulários transparentes

Arquivo: ...\Samples\Solution\Sedona\Fadeaway.scx

O Microsoft Windows 2000 tem suporte para janelas em camadas. Usar uma janela em camadas pode melhorar significativamente o desempenho e os efeitos visuais para uma janela que tem uma forma complexa, anima sua forma ou deseja usar efeitos de mesclagem alfa. O sistema compõe e repinta automaticamente janelas em camadas e as janelas de aplicações subjacentes. Como resultado, janelas em camadas são renderizadas suavemente, sem o flickering típico de regiões de janela complexas. Além disso, janelas em camadas podem ser parcialmente translúcidas, ou seja, com mesclagem alfa. Este exemplo mostra como você pode usar janelas em camadas no Visual FoxPro para adicionar efeitos especiais de opacidade e transparência.

Para detalhes sobre todas as classes disponíveis nas classes base, consulte Classes base do Visual FoxPro de A a Z.
