# Propriedade OLEServerBusyTimeout

Especifica por quanto tempo uma solicitação Automation é repetida enquanto um servidor está ocupado. Leitura/gravação em tempo de execução.

```foxpro
ApplicationObject.OLEServerBusyTimeout[ = nMilliseconds]
```

# Valor de retorno
 **nMilliseconds**
Especifica o número de milissegundos durante os quais uma solicitação Automation é repetida antes que uma mensagem de servidor ocupado seja exibida.

# Observações

Aplica-se a: Application Object | Variável de sistema _VFP
