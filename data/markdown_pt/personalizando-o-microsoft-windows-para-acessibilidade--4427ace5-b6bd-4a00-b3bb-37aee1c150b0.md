# Personalizando o Microsoft Windows para Acessibilidade

Existem muitas maneiras de personalizar o Microsoft Windows para tornar seu computador mais acessível.
 - O Windows inclui recursos de acessibilidade que são úteis para pessoas que têm dificuldade para digitar ou usar o mouse, têm visão moderadamente prejudicada ou são surdas ou com deficiência auditiva. Você pode instalar esses recursos durante o processo de instalação ou adicioná-los posteriormente a partir dos discos de instalação do Windows. Consulte "accessibility" no índice da Ajuda do Windows para obter informações sobre como instalar e usar esses recursos.
- Você pode adicionar muitos dos recursos que tornam as versões atuais do Windows mais acessíveis a versões anteriores do Windows e ao MS-DOS por meio dos Access Packs. Você pode baixar esses arquivos por modem ou solicitar-os em discos da Microsoft.
- Você pode usar o Painel de Controle e outros recursos integrados para ajustar a aparência e o comportamento do Windows para atender a diferentes capacidades visuais e motoras. Isso inclui ajustar cores e tamanhos, volume do som e o comportamento do mouse e do teclado.
- Se você tem dificuldade em usar o layout de teclado QWERTY padrão, os layouts de teclado Dvorak tornam os caracteres digitados com mais frequência em um teclado mais acessíveis. Você pode escolher entre três layouts Dvorak: para duas mãos, somente mão esquerda e somente mão direita. Você não precisa adquirir nenhum equipamento especial para usar esses recursos.

Os recursos específicos disponíveis e se eles são integrados ou devem ser obtidos separadamente dependem do sistema operacional que você está usando.

# Para baixar os Access Packs, Application Notes e layouts de teclado alternativos por modem

Se você tem um modem, pode baixar esses arquivos dos seguintes serviços de rede:
 - Site da Microsoft. Acesse Microsoft Windows XP Accessibility Resources em http://www.microsoft.com/enable/products/windowsxp/default.aspx .
- Servidor FTP da Microsoft, ftp://ftp.microsoft.com/Softlib/MSLFILES/ .
- MSN, o serviço online Microsoft Network.
- CompuServe. Digite GO MSL .
- Vários quadros de avisos de grupos de usuários.

# Para solicitar os Access Packs, Application Notes e layouts de teclado alternativos em discos por telefone

Se você não tem um modem, pode solicitar os Access Packs, Application Notes e Alternative Layouts em discos nos Estados Unidos ligando para o Microsoft Sales Information Center em (800) 426-9400 (voz) ou (800) 892-5234 (TTY).

No Canadá, você pode ligar para (905) 568-3503 ou (905) 568-9641 (telefone de texto).
