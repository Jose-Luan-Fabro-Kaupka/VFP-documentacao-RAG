# Guia Layout, Grid Builder

Esta guia no Grid builder especifica legendas de coluna e o tipo de controle que você pode adicionar ao Grid.

> **Observação:** Você deve selecionar uma coluna antes de poder alterar seu cabeçalho.
 **Caption**
Especifica a legenda da coluna selecionada. Digite uma legenda na caixa. Se você não especificar uma legenda, os nomes dos campos serão os cabeçalhos das colunas.
**Control Type**
Especifica o tipo de controle a adicionar à coluna selecionada. Caixas de texto ou de edição estão disponíveis para dados de caractere, caixas de texto ou de seleção estão disponíveis para dados lógicos, e caixas de texto ou spinners estão disponíveis para dados numéricos.
**Grid Display**
Mostra as colunas do grid conforme especificadas atualmente. A exibição é atualizada automaticamente de acordo com suas seleções de Caption e Control Type. Você pode definir as colunas na largura desejada arrastando a borda direita de um cabeçalho.
