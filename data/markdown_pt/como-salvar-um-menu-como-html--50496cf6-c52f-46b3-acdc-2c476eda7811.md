# Como: salvar um menu como HTML

Você pode usar a opção Save As HTML no menu File quando estiver criando um menu para salvar o conteúdo de um menu como um arquivo HTML (Hypertext Markup Language).

### Para salvar um formulário como HTML
- Abra o menu.
- Escolha Save As HTML no menu File. (Você será solicitado a salvar o menu se ele foi modificado.)
- Digite o nome do arquivo HTML a criar e escolha Save .
