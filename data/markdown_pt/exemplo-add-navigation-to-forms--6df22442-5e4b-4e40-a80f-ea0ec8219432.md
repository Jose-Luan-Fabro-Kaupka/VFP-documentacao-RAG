# Exemplo Add Navigation to Forms

Arquivo: ...\Samples\Solution\Ffc\DataNav.scx

Este exemplo contém as seguintes classes.

| Classe | Biblioteca | Descrição |
| --- | --- | --- |
| _nav2buttons | _table2.vcx | Exibe um par de botões que fornecem as funções GoNext( ) e GoPrevious( ). |
| _nav4buttons | _table2.vcx | Exibe dois botões adicionais que fornecem as funções GO TOP e GO BOTTOM à classe _Nav2Button. |
| _tablenav | _table.vcx | Uma classe não visual que fornece navegação de dados a outros controles. |
| _nav2picbuttons | _table2.vcx | Exibe um par de botões de imagem que fornecem as funções GoNext( ) e GoPrevious( ). |
| _gotobutton | _table2.vcx | Fornece um botão que exibe uma caixa de diálogo Go To. |

Para detalhes sobre todas as classes disponíveis nas classes base, consulte Visual FoxPro Foundation Classes A-Z.
